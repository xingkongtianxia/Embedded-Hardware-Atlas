# PCB 通用工程方法（分卷 01）

本分卷承接汇总稿 `硬件/PCB/PCB通用工程方法.md`，事实来源沿用 frontmatter 中列出的原始资料。

## 从需求到可检查输入
- 在布局前记录板框、禁布区、安装方式、连接器方向、环境温度、供电来源、功耗状态、接口速率、法规、成本、层数、测试和交期要求。
- 每条电源网络记录最小/最大电压、连续与峰值电流、允许纹波、上电顺序、负载类型和测量点；每条高速网络记录协议、速率、阻抗、长度关系、拓扑、端接和参考面要求。
- 将不确定项显式标为待确认，注明责任人、截止时间和受影响模块。缺少层叠、电流或接口规范时，默认规则不能替代工程确认。

## 规则矩阵与版本控制
- 按电源、模拟敏感、普通 GPIO、低速时钟、高速单端、差分、射频/天线、机壳地建立网络类别，并给出线宽、间距、过孔、参考层、阻抗、长度、串扰和禁布规则。
- 每条规则标注来源和验证方法：数据手册、接口规范、板厂能力或仿真报告；验证可为 DRC、阻抗报告、示波器、TDR、眼图、热像或实验室测试。
- 原理图、PCB、封装库、BOM、制造输出和变更记录必须使用同一版本标识。飞线、割线、换料和规则例外应回写，避免下一版重复问题。

## 原理图与封装审查
- 核对电源、地、时钟、复位、启动、未用脚、接口保护、测试点和可生产性；ERC 只发现规则能描述的问题，不能替代数据手册与系统审查。
- 封装来源可追溯，焊盘、阻焊、钢网、庭院、极性、pin 1 和 3D 模型与数据手册一致；高电流、热焊盘、细间距和连接器还需结合装配工艺验证。
- 关键器件检查完整料号、封装、额定值、生命周期、替代料和 BOM 一致性。库修改版本化，项目冻结后不使用无记录替换。

## 叠层与板厂协同
- 布局前与板厂确认材料、成品铜厚、介质厚度、板厚、公差、最小线宽线距、孔径、环宽及阻抗能力；阻抗来自实际叠层而非经验线宽。
- 为电源、普通信号、高速单端、差分、时钟和敏感模拟建立对应层与参考面。规则来自电流、温升、阻抗、时序、串扰和制造能力，而非视觉偏好。
- 对超出常规能力的线宽、BGA 扇出、槽孔、阻抗或拼板要求，取得板厂书面确认并保留在制造包中。

## 布局评审方法
1. 固定板框、安装孔、连接器、天线和结构件，并定义禁布区和可达性。
2. 放置电源入口、保护、主要电源模块，先建立高 di/dt 回路与散热路径。
3. 放置主控、时钟、复位、存储和高速接口，保证关键逃线、回流和端接空间。
4. 放置模拟链路、普通外设和剩余阻容，按信号流、能量流和敏感度分区。
5. 检查测试探针、返修、器件极性、丝印可见性、风道和装配干涉后再进入大规模布线。

## 布线、过孔与铺铜
- 优先处理关键时钟、高速差分、存储和敏感模拟网络；每类网络检查拓扑、端接、连续参考、过孔 stub、串扰和长度依据，再处理电源和普通信号。
- 高速线换层时让信号过孔与参考地过孔配对；大电流网络同时核对线宽、铜厚、过孔电流能力、并联数量与温升，不能只看线宽。
- 走线转角、焊盘出口、过孔颈缩和连接器过渡都可能造成阻抗不连续。长度匹配应建立在拓扑、端接和回流正确之后。
- 铺铜前后检查地平面连续性、孤岛、狭缝、热焊盘、开窗和板边距离。铜皮不能修复错误拓扑或回流中断，反而可能形成谐振或制造问题。
- 丝印不压焊盘、测试点和连接器接触区；极性、pin 1、版本、接口名和高压警示在装配后仍应可读。

## DFM、DFA 与制造包
- DFM 复核最小线宽线距、孔径、环宽、槽孔、表面处理、阻焊桥、铜到板边、拼板、翘曲和阻抗公差。
- DFA 复核贴装方向、器件间距、钢网开口、回流焊阴影、高器件遮挡、可视检查和返修可达性；装配图要让生产人员无需猜测极性和未装位。
- 从同一冻结设计一次导出并可视化审查 Gerber/ODB++、钻孔/槽孔、IPC 网表、坐标、BOM、装配图、叠层、阻抗表和特殊工艺说明。
- 不同版本的制造文件不得人工混用；输出包中应有版本号、日期、变更摘要和受控文件清单。

## Bring-up 与问题闭环
- 初次上电使用可限流电源，先测输入阻抗和无电短路，再按电源树分级加载。异常电流时先隔离负载或分区，而不是提高限流继续尝试。
- 启动验证按“电源、复位、时钟、下载/调试、最小外设、全部接口”进行，记录电压、纹波、温升、波形、固件版本和板号。
- 问题单包含现象、触发条件、受影响批次、根因假设、测量证据、临时措施、永久改动和验证结果；关闭后更新规则、库或审查清单。

## 发布前检查清单

- [ ] 原理图、PCB、封装库、BOM 与制造包版本一致，未使用本地未受控封装。
- [ ] 结构、装配、测试、热、SI/PI、EMC 和制造评审均已完成，未决风险已记录。

+### PCB工程方法知识条目 1
DDR 第四集：**电源完整性（PDN）、VREF/VTT 与验证方法**。很多"布线看起来完美但跑不稳"的板子，问题都在电源上。

DDR3 典型电源：

| 电源 | 电压 | 用途 | 要求 |
|---|---|---|---|
| VDD/VDDQ | 1.5V (DDR3) / 1.35V (DDR3L) / 1.2V (DDR4) | 核心与 IO | 纹波 <±3%，大电流 |
| VTT | VDDQ/2 = 0.75V | 地址线端接 | 可 source/sink，±3% |
| VREF (VREFDQ/VREFCA) | VDDQ/2 | 接收比较基准 | **纹波 <±1%**，极静 |
| VPP (DDR4) | 2.5V | 字线升压 | 小电流 |

🔬 **深入原理**

**为什么 VREF 要求这么严？** VREF 是接收器判决门限。DDR3 的输入摆幅可能只有 ±100mV，若 VREF 漂移 25mV，就吃掉了 25% 的电压裕量。所以：

$$\text{Noise Margin} = \frac{V_{swing}}{2} - V_{REF\_noise} - V_{ISI} - V_{xtalk} - V_{SSN}$$

VREF 设计要点：
- 用 **1% 精度电阻分压**（如 2×1kΩ），或用 VTT 芯片提供的 VREF 输出（更好，能跟踪 VDDQ）；
- **就近去耦**：分压点 100nF + 每个 VREF 引脚 100nF；
- 走线宽度 ≥ 15～20mil（降低阻抗）但不必很宽（电流极小，μA 级）；
- **VREF 走线必须远离 DQ/CK，且下方参考面完整**；
- 多颗粒时 VREF 用**星型分配**，每颗粒单独一段并各自去耦。

**SSN（同步开关噪声）**：16 位数据同时翻转时，瞬态电流巨大。

$$\Delta V=L_{eff}\cdot N\cdot\frac{di}{dt}$$

对策：VDDQ 去耦电容数量要足（经验：**每个 VDDQ 引脚配 1 个 100nF**，另加 2～4 个 10μF），且 VDDQ 与 GND 平面相邻、介质薄。

**PDN 目标阻抗**：DDR3 1.5V、允许 5% 纹波、瞬态电流 2A：

$$Z_{target}=\frac{1.5\times0.05}{2}=37.5\ \text{m}\Omega$$

需要在 DC～数百 MHz 内维持这个阻抗，靠"稳压器（<100kHz）+ 大电容（100k～1MHz）+ 陶瓷电容（1M～100MHz）+ 平面电容（>100MHz）"四级接力。

🛠 **设计实例/操作**

*例1：去耦布局。*
```
 SoC 侧            DDR 颗粒侧
 [10μF]×2         [10μF]×1
 [100nF]×N        [100nF]×N  （N = VDDQ 引脚数）
  ↑贴引脚，双过孔   ↑贴引脚，最好放在颗粒背面正下方
 VDDQ 平面：整块铺，避免细长条；与 GND 平面相邻，介质 ≤0.1mm
```

*例2：验证方法（层层递进）。*

1. **DRC/规则检查**：等长、间距、阻抗、过孔数。
2. **SI 仿真**：HyperLynx / SIwave / ADS，看眼图、过冲、串扰。DDR3-1600 眼高应 >150mV、眼宽 >0.4UI。
3. **硬件调试**：
   - 先降频跑（DDR3-800）确认基本功能；
   - 用 **memtester / stressapptest / Linux memtest** 长时间压测（≥8 小时）；
   - 高低温循环测试（−20℃～70℃），温度会改变时序；
   - 读取控制器的 **训练结果寄存器**（write leveling delay、read gate delay、DQ deskew 值），看各 bit 的窗口是否居中、是否有异常离群值——**离群的那一位往往就是布线有问题的那根线**。
4. **示波器实测**：用高带宽差分探头量 DQS/CK 眼图（注意探头本身会引入负载）。

*例3：常见故障对照。*

| 现象 | 可能原因 |
|---|---|
| 完全跑不起来 | 电源时序、复位、ZQ 电阻（240Ω 1%）、初始化配置 |
| 降频可以，高频不行 | 等长/串扰/阻抗/VREF 噪声 |
| 个别 bit 错误 | 该 bit 走线异常（跨分割、串扰、虚焊） |
| 高温不稳 | 时序裕量不足，温度使延时变化 |
| 偶发死机 | SSN、去耦不足、地弹 |

⚠️ **常见误区**

1. VREF 用普通 5% 电阻分压且不去耦。
2. VREF 与 VTT 共用走线或共用分压点（VTT 有大电流，会污染 VREF）。
3. 忘记 **ZQ 校准电阻 240Ω 1%**，或走线太长（应 <10mm，且接 GND）。
4. VDDQ 平面被走线切成细长条，等效电感大。
5. 去耦电容数量够但过孔共用/距离远。
6. 只做功能测试不做压力与高低温测试，量产后批量返修。

📌 **要点速记**

- VREF 纹波 <±1%，1% 电阻分压或用 VTT 芯片输出，星型分配 + 就近去耦。
- VTT 需可 source/sink，端接在链路最远端。
- 每个 VDDQ 引脚配 100nF，VDDQ 与 GND 平面相邻薄介质。
- ZQ 电阻 240Ω 1%，靠近颗粒接 GND。
- 验证：仿真 → 降频 → 压测 → 高低温 → 读训练寄存器定位坏 bit。

### PCB工程方法知识条目 2
**① 建库(封装 / 原理图符号)**
- 打开嘉立创 EDA → 新建「元件库」→ 根据器件数据手册绘制封装(焊盘尺寸、间距、丝印)。
- 常见坑:按"推荐 land pattern"而非"芯片尺寸"画焊盘;QFP/BGA 注意 1pin 标记;连接器留足禁布区。

**② 原理图与导入**
- 放置元件、连线、标网络名;用"网络标号"区分电源/地/高速网。
- 设计 → 更新/转换到 PCB,把网表一次性导入。

**③ 叠层与阻抗(关键)**
- 在「层管理」里设定板层(如 4 层:Top-GND-PWR-Bottom 或 6 层)。
- 用「阻抗计算工具」输入板材 $\varepsilon_r$、铜厚、介质厚,反推目标线宽。例如要 50Ω 微带线,工具会告诉你线宽约多少 mil。

**④ 布局(Layout)**
- 先摆放接口、接插件、大器件;再按"模块化"就近摆放(电源模块、MCU、DDR、射频)。
- 原则:高频/高速器件靠近其对应接口;去耦电容紧贴电源引脚;晶振远离干扰源并包地。

**⑤ 布线(Routing)—— 实例:一个 USB 差分对怎么走**
USB 2.0 是 90Ω 差分对,USB 3.0 还含更高速差分对。具体步骤:
1. 在「设计规则」里建差分对(快捷键可框选两根网设为差分),目标阻抗 90Ω,线宽/线距由阻抗工具给出(常见 7/8 mil 线宽、间距约 6~8 mil,随叠层变)。
2. 两根线**等长、等距、同层**走,避免中途换层;若必须换层,在旁边打"地过孔"陪同步进。
3. 走线尽量短、少打过孔、少拐 90°(用 45° 或圆弧),长度差控制在几十 mil 内。
4. 两侧加地保护、远离时钟和电源噪声源,遵守 3W 间距。
5. 终端 90Ω 匹配由芯片内部或端接电阻完成,板上主要保证走线阻抗连续。

```
   GND ─┐   ┌─ USB_D−  ═════╗ (90Ω 差分, 紧耦合等距)
        │   │
   GND ─┤   ├─ USB_D+  ═════╝
        │   │
   GND ─┘   └─ 地过孔(回流/屏蔽)
```

**⑥ 等长与检查**
- 对 DDR 等总线用「等长调节(蛇形线)」把组内长度差压进容差。
- 运行 DRC(设计规则检查),清掉短路、间距不足、未连接。

**⑦ 生产资料输出**
- 「制造」→ 一键生成 Gerber、钻孔、坐标文件、BOM、贴片坐标;
- 直接对接嘉立创下单,填层数、板材、阻焊颜色、是否阻抗控制(务必勾选"阻抗",并附上你的阻抗要求表)。
### PCB工程方法知识条目 3
- 建立"高速 = 边沿速率 + 走线长度"的正确直觉,而非只盯时钟频率。
- 理解特性阻抗 $Z_0$ 的物理来源 ($Z_0=\sqrt{L/C}$) 及其与线宽/介质厚/介电常数的关系。
- 能用微带线/带状线经验公式估算或借助工具反推目标线宽。
- 懂得反射与阻抗匹配:反射系数 $\Gamma=(Z_L-Z_0)/(Z_L+Z_0)$,末端匹配消除振铃。
- 掌握等长与时序:传播延迟约 55~65 ps/cm(FR-4),DDR 组内长度差需压到容差内。
- 理解串扰的电容/电感耦合机理,会用 3W 原则和包地降低干扰。
- 深刻认识回流路径:高频回流紧贴参考平面,换层必须打伴随地过孔。
- 熟悉嘉立创 EDA 全流程:建库 → 原理图 → 叠层阻抗 → 布局 → 布线 → 等长 → DRC → 生产资料。
- 能独立走出一条符合 90Ω 的 USB 差分对(等距等长、少过孔、加地保护)。
- 避开新手七大误区(频率误区、线宽误区、连通误区、地误区等)。
- 知道差分/单端常见阻抗目标(50Ω、90Ω、100Ω)及其典型应用场景。
- 明确本概览课与 6 层板实战教程的分工:先懂"为什么",再练"怎么做"。
### PCB工程方法知识条目 4
本项目的目标板是"逻辑派 FPGA-G1 开发板"——一块以 FPGA 为核心、外挂 DDR3 内存、带 HDMI 输出、带 MCU 协处理、带 TF 卡与各类排针外设、由多路 DC-DC/LDO 供电的开发板。这种板子有三个典型特征：**BGA 封装（引脚在芯片底下，出不来线）**、**DDR3 高速并行总线（几百 Mbps~1.6Gbps 每根线，要等长）**、**HDMI 高速差分（Gbps 级，要阻抗控制）**。这三条任意一条，都足以让双面板"做不出来"。

所谓"全链路"，指的是下面这条不可跳步的流水线：

```
原理图分析 → 电源树梳理 → 网表/器件导入 → 板框结构导入 → 环境与快捷键
   → 模块抓取/接口定位 → 模块化预布局 → 3D 结构校验
   → 层数分析与叠层设置 → 阻抗理解与计算 → 规则（线宽/间距/过孔/网络类/差分）
   → BGA 扇孔 → 分模块布线 → 电源连通性 → 布线优化 → 时序等长
   → 缝合地过孔 → DRC → 丝印/LOGO → 生产资料输出 → 下单
```

| `05_生产资料` | Gerber/钻孔/坐标/BOM | 最后打包下单 |

**例：先确认三条"硬约束"。** ①板框尺寸与安装孔位置（决定布局边界）；②接口器件位置（HDMI、TF、USB、电源座、排针必须落在指定边缘）；③BGA pitch（决定过孔工艺与最小线宽）。这三条一旦后期变更，布局布线基本要推倒重来。
### PCB工程方法知识条目 6
**网表（Netlist）到底是什么？** 本质上是一张两列表：`网络名 ↔ 器件位号.引脚号`。例如：

```
NET "DDR3_DQ0"   U1.A3   U5.G7
NET "3V3"        U2.5    C12.1   C13.1   R7.2  ...
```

PCB 软件靠它建立"连接关系"，DRC 才知道你有没有漏连、错连。所以**网表的准确性 = 原理图的准确性**，任何原理图里的错连都会 1:1 复制到 PCB。

**封装（Footprint）为什么是命门？** 封装的三个要素必须核对：
1. **焊盘尺寸与间距**：BGA 的 pitch（如 0.8mm）、QFN 的散热焊盘、连接器的定位孔；
2. **引脚编号映射**：BGA 的 A1 位置标识必须与 Datasheet 一致，弄反 180° 是最经典的报废原因；
3. **3D 模型与高度**：影响后续结构校验。

导入完成后必须做一次**"数量对账"**：原理图器件数 = PCB 器件数；原理图网络数 = PCB 网络数。少了就是没导入完，多了就是有重复位号。
### PCB工程方法知识条目 7
**为什么板框必须闭合？** 因为 EDA 靠闭合轮廓判断"板内/板外"，从而进行铺铜、DRC 边距检查、以及生成 Gerber 的外形层（GKO）。如果轮廓有 0.001mm 的缝隙，铺铜会漏到板外，或者铺不出来，工厂也可能按错误外形开模。

**几个关键的结构约束：**

| 约束 | 典型值 | 原因 |
|---|---|---|
| 走线距板边 | ≥ 0.3mm（推荐 0.5mm） | 锣板/V-CUT 公差 ±0.2mm，防止铣断 |
| 铜皮距板边 | ≥ 0.3mm | 防止边缘铜箔翘起、短路 |
| 定位孔周围禁布 | 孔径 + 0.5mm 环 | 防螺丝/铜柱压伤走线 |
| 器件距板边 | ≥ 1mm（贴片）| 贴片机夹持边（工艺边）要求 |
| 拼板工艺边 | 5mm | 无器件区，供贴片机传送 |

**20H规则的边界：** 电源平面相对地平面内缩20倍介质间距属于特定平面对的历史经验，不能保证辐射改善，也没有统一“内缩0.5–1 mm即可”的结论。先保留必要载流铜与连续信号参考，再依据结构和EMC验证决定是否内缩。
### PCB工程方法知识条目 8
**例1：导入后的三步校验。**
1. 用测量工具量一下板框长宽，是否等于结构图标注（防止单位被当成 inch，一导入就大了 25.4 倍）；
2. 量定位孔中心距，是否与外壳螺柱一致；
3. 看有没有多余的 DXF 图层（标注线、尺寸线）被一起导进来 → 全部删掉，否则会进 Gerber。

**例2：设置原点与栅格。**
- 原点设在板框左下角，这样所有坐标都是正数，输出贴片坐标文件时最直观；
- 栅格：布局阶段用 0.5mm 或 1mm（对齐好看），布线阶段切到 0.025mm（1mil）或更细。

**ASCII 示意：**

```
   +---------------------------------------+  <- 板框层(闭合)
   | ○(M3)                          (M3)○  |  <- 定位孔 NPTH
   |   ┌───禁布区(距边0.5mm)──────────┐    |
   |   │                              │    |
   |   │        器件布局区域           │    |
   |   │                              │    |
   |   └──────────────────────────────┘    |
   | ○(M3)                          (M3)○  |
   +---------------------------------------+
   ↑原点(0,0)
```
### PCB工程方法知识条目 9
快捷键之外，真正影响画板质量的是这几项**环境设置**：

1. **栅格（Grid）**：布局用 0.5/1mm，布线用 1mil 或 0.5mil。栅格太粗会导致 BGA 扇孔对不齐，太细会导致布局歪斜。
2. **捕捉（Snap）**：开启"捕捉到焊盘中心/线端点"，避免出现肉眼看不见的 0.001mm 断点。
3. **层颜色与可见性**：6 层板必须给 L1~L6 设置**区分度高**的颜色，且养成"只显示当前布线层 + 参考层"的习惯。
4. **交互式布线模式**：设置"推挤（Push）"或"忽略障碍"，并打开**在线 DRC**——边画边报错，比最后统一 DRC 效率高得多。
5. **默认线宽/过孔尺寸**：先设成规则里的常用值（如线宽 5mil、过孔 0.2/0.4mm），减少每次手动改。
### PCB工程方法知识条目 10
**例1：为排针补 3D 模型。** 若库里的排针没有 3D 模型，3D 视图看不到高度，很容易漏检。做法是给封装挂上 STEP 模型（或用 EDA 内置的简易 3D 体，设置高度）。2.54mm 单排针常见参数：塑胶体 2.54mm 宽 × 2.5mm 高，针总长 11mm（上 6mm / 下 3mm）。

**例2：排针的丝印与防呆。**
```
 ┌─────────────────────────────┐
 │ ▣ ○ ○ ○ ○ ○ ○ ○ ○ ○  J1     │  ▣ = 1脚方形焊盘 (防呆)
 └─────────────────────────────┘
   ↑ 1 脚丝印三角/数字标识
   ↑ 每 5 脚加一个刻度点，方便数脚
```
- 1 脚必须做成**方形焊盘**并有丝印标识；
- 排针旁标注信号名（如 `IO0 IO1 ... 3V3 GND`），这是开发板的核心易用性；
- 丝印不能压在焊盘上（DRC 会报"丝印开窗"）。
