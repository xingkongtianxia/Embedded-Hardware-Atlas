# 隔离开关电源设计分类稿

## 来源边界

原件自述由标题/简介大纲与通用领域知识整理，并非逐句核验记录。保留原件，以下仅抽取设计方法；所有安规数值、功率分界和器件算例均需按产品标准/手册重新核验，状态为 `needs-review`。定位按原件章节号，不依赖临时提取页码。

## 可复用方法

- 能量路径与分区（原件§1、§3–8）：输入保护/EMI、整流母线、开关/磁件、整流输出和反馈分别识别；按开通/关断状态追踪电流，缩小高di/dt环路并控制高dv/dt铜面。
- EMI滤波（§2）：噪声源、耦合路径、差模/共模分别判断；滤波器输入/输出避免空间旁路，Y电容回路同时核查泄漏电流和绝缘等级。
- 反馈和采样（§9–11）：反馈远离开关节点，电流/电压采样用Kelvin引出，控制地与功率地按控制器推荐回流连接，不把“单点接地”当作全板规则。
- 载流、热和并联（§12–14、§21–22）：输入RMS/峰值/占空比、铜厚、环境温度、允许温升、端子和过孔共同决定截面；并联开关还需检查驱动、阻抗与热耦合均衡。
- 功率架构（§19–24）：反激、PFC+隔离变换级、交错、模块化/母排属于候选架构；按效率、谐波、体积、成本和控制复杂度选择，功率不是唯一判据。
- 工程闭环（§15–18、附录B）：DRC后仍须做隔离距离、变压器/光耦认证、满载温升、启动/短路/突卸载、环路与EMC验证，保留版本和测试条件。

## 原文纠错与待核验

| 原文定位/表述 | 分类判断 |
|---|---|
| §1.2/附录A将 `Vout=Vin×(Ns/Np)×D/(1−D)` 标为DCM | 理想CCM（或临界边界）伏秒平衡关系；一般DCM另有第三段零电流时间，输出还依赖负载、磁化电感和频率。不能照该标签使用。 |
| §19.1 `0.5 V×2 A≈0.7 W` | 算术应为1 W；真实整流损耗还应积分波形，不由错误结果选散热。 |
| §2.2以250 V/50 Hz/0.25 mA求约3.2 nF后又说总容量可2×2.2 nF | 同条件若并联总4.4 nF，则约0.346 mA；实际网络/测量方法/限值另按标准，不能直接宣称满足0.25 mA。 |
| 固定6.4 mm/4 mm、统一耐压电压、固定Y电容类别 | 需产品标准、工作电压/冲击、绝缘类型、污染等级、材料组/CTI和海拔；不是通用门槛。 |
| “>75 W必须做PFC”“300 W必须放弃反激” | 谐波限制取决于标准适用范围与设备类别，合规方法/拓扑不能只按瓦数判定。 |
| “每一颗BUCK都是mini反激” | Buck为非隔离降压，反激用耦合电感储能/传输；只能迁移回路/热/测量方法，不能混同拓扑。 |
