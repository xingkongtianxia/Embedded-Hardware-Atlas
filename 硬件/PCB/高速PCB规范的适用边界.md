# 高速PCB规范的适用边界

来源为用户新增《高速PCB设计.md》，原件仅只读登记。覆盖材料、叠层、布局、去耦、存储器和接口；以下是清洗后的原则与纠偏，不把课程式经验数字直接升格为设计规则。

## 可复用原则

- 板材选择需同时考虑Dk/Df测试条件、CTE、热性能、吸湿和铜粗糙度；供应商典型值不是保证限值。
- 关键信号保留连续参考面，避免跨分割；换参考层需提供就近回流路径。四层板先确定参考层，再分配电源铜和信号。
- 功能分区服务于电流与信号路径，不按器件外形简单排队；输入/输出滤波与局部去耦分工。
- 去耦应缩小引脚—电容—回流的整个环路，不只看电容离芯片的直线距离。大储能与高频陶瓷不能互相代替。
- SDRAM/DDR按数据组、时钟/选通和控制组组织，等长预算依目标控制器、器件与叠层，不跨代套用。
- USB/以太网/PCIe等根据确切接口版本、速率、阻抗和连接器布局；ESD器件贴接口并安排短泄放路径。

## 明确不照抄的条目

| 原笔记表述 | 使用边界 |
|---|---|
| 1 oz对应500 µm的表格文字 | OCR/排版错误，1 oz通常约35 µm铜厚；向板厂确认成品厚度和公差。 |
| 滤波电容“先大后小” | 不能覆盖开关热环路设计；高频旁路必须贴换流器件，按实际电流路径决定位置。 |
| USB供电500/900 mA对应30/50 mil | 仅特定旧接口背景，不能用于3–6 A快充。按铜厚、压降、温升、线长、过孔与连接器计算。 |
| USB信号脚可按走线调换 | 不能任意调换CC、D+/D-或高速通道；仅在规范/PHY明确支持时按规则处理翻转、极性或lane交换。 |
| 3W、固定20 mil间距、固定等长误差 | 经验起点而非通用合格阈值；依边沿速度、耦合长度、介质高度与时序/串扰预算核算。 |
| 存储器25 V等OCR文字 | 不能作供电规格；与各器件手册、代际标准核对小数点。 |

## 对车载快充的应用

上路两桥换流环、下路Buck输入环路、Kelvin采样和完整参考面优先；低频工作不代表没有高频开关边沿。四层1oz不能替代功率预算、引脚正确性与散热验证。
