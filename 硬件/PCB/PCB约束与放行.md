# PCB约束与放行分类稿

## 来源与可引用边界

按原件§1–8、附录A–C提取。该资料为二次笔记，尚未与接口规范、器件指南、板厂参数及产品标准逐项比对；保留方法，经验数值不晋升为已核验规则。

## 设计输入到放行证据

1. 接口/SI（§1）：边沿而非单看时钟频率决定传输线问题；按真实叠层、源/负载阻抗、拓扑、过孔和损耗确定端接，保留连续参考与换层回流。
2. 布局（§2）：先锁结构/连接器/安装/禁布，再按信号流与功率流定位关键器件；同时考虑散热、插拔、装配、返修和探测空间。
3. 规则（§3、§7）：每个网络类别记录来源、单位、优先级、作用层和验证方法。DRC=0不能证明规则覆盖完整，也不能证明SI、PI或功能正确。
4. PI（§4）：`Ztarget=ΔVallowed/ΔI` 用于目标阻抗预算；必须进一步检查频域阻抗、反谐振、偏压有效电容、ESL/回流和实测负载阶跃。
5. 存储接口（§5）：DDR按DQ/DQS字节组、地址/命令/时钟拓扑和控制器规范分组；长度仅是时延代理，不能把等长公差跨DDR代际/速率照搬。SPI/eMMC按实际模式与器件要求约束。
6. 绝缘（§6）：爬电是沿表面的路径，电气间隙是空气路径；工作电压、冲击、绝缘类型、污染等级、CTI、海拔和产品标准共同决定距离，阻焊不自动构成合格绝缘。
7. 交付（§7–8）：固定原理图/PCB/库/BOM版本，复查制造与装配输出、阻抗叠层、测试点、器件极性、热/EMC与设计例外，形成可追溯放行证据。

## 纠错与不可外推项

| 定位 | 处理 |
|---|---|
| §1.1称“1/6判据”，却写 `Lcrit=tr/(2×tpd)` | 二者不同；采用经验比例k时应写 `Lcrit=k×tr/tpd`。k不是硬物理阈值，仍需按波形/拓扑仿真。 |
| §1.2将3W与固定场能量百分比/串扰dB绑定 | 串扰还取决于距参考面高度、并行长度、边沿和端接；不登记为保证值。 |
| §1.2跨地分割用0.1µF桥接 | 优先恢复完整参考/调整走线；桥接要审查两地功能及绝缘要求，不能跨安全隔离带套用。 |
| §5 DDR固定mm公差、§8固定铜面积温升 | 留作待核验例子；按实际时序预算/层叠和热边界计算。 |
| §8.3固定USB3交流耦合电容放连接器端 | 应按控制器/接口规范明确TX侧与通道要求，不能按连接器位置一概决定。 |
