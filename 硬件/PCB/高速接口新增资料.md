# 高速接口新增资料

## 可复用工程要点

- 高速项目先用层级原理图和模块边界定义信号作用域，再把差分对、Net Class、PCB Rule Directive 和 Parameter Set 传递到 PCB 工程；编译结果是约束是否生效的第一道检查。
- xSignal 表示从驱动端到接收端的完整路径，包含器件引脚、封装和过孔；跨串联电阻或多段网络时，不能只按单个 Net 做长度匹配。
- 叠层、参考平面、回流路径和过孔结构必须在布线前冻结。阻抗目标应以板厂叠层与阻抗报告为准，公式只用于估算和敏感性分析。
- 评审应同时覆盖层级连接、差分配对、xSignal 分组、等长容差、回流连续性、串扰间距和编译/DRC 结果，避免把“能连通”误认为“高速可用”。
- 新增详解版进一步覆盖电源、时钟、射频、接口、隔离和继电器模块；这些规则作为检查清单输入，仍需按具体器件手册、协议和板厂叠层复核。

## 与既有来源的关系

本页补充 [[wiki/PCB/高速接口模块|高速接口模块]] 与 [[wiki/PCB/模块化布局|PCB 模块化布局]] 的约束输入、层叠阻抗、xSignals 和验证流程，不替代既有章节。JHP11 资料偏模块化设计与评审边界，Altium 资料偏工具化约束和 xSignals 操作；两者结论应在目标板叠层和协议规范下复核。
