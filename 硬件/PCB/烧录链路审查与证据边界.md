# 烧录链路审查与证据边界

## 来源分层

本稿把两篇用户已新增、待发布的工程审查记录整理为可引用边界。本轮未重新访问EasyEDA工程、未执行PCB/电气测试。原审查中报告的逐脚回读、现场读数和工具结果属于历史观察转录，没有在本轮取得可独立复核的原始工程快照；它们保持needs-review，不能凭分类稿反向当作独立证据。

现存RP2354手册按原文重新核对：PDF物理p.375（印刷p.374）§5.2.8与PDF物理p.1327（印刷p.1326）§14.3。其余工程事实不能由此手册证明。

## RP2354事实与假设

- RP2354A/B叠封2MB Winbond W25Q16JVWI，分别QFN-60/QFN-80；QSPI焊盘同时连接内部Flash和封装引脚。第二外部QSPI器件需要独立的Bank0 GPIO片选（§14.3）。
- Bootrom将CSn输出禁用并内部上拉，外部低阻拉低可选BOOTSEL，原文4.7kΩ是兼顾采样/正常驱动的示例值（§5.2.8）。外部上拉未装不能单独证明缺陷，内部上拉也不能证明任何板都不需外部上拉。
- 原记录称故障工程为RP2354B、对照工程为RP2354A+GD25Q128；本轮没有重新导出网表，无法确认外部Flash是否用独立片选，也不能宣称全部硬件正确。
- “断电不能运行”兼容RAM装载、Flash写入/校验失败、镜像链接/分区/启动配置、供电/复位/晶振等多个原因。缺少命令、ELF/UF2目标地址和Flash回读，不能判“根因是写RAM”。
- `load/run`语义依工具和镜像而定，OpenOCD/IDE可按脚本写Flash；不能把`picotool -t`当RAM/Flash选择参数，应以本机版本help核对，使用目标地址与校验证明落点。

## C2电压与连通性

原记录称C2CK有10kΩ接3.3V，C2D无外部上拉，两线无串联电阻；接口用5V Nano。没有准确EFM8后缀的引脚耐压表、Nano固件/配置与波形，不能从供电3.3V推出全部引脚不耐5V，也不能从无外部上拉/TVS直接认定烧录根因。

若只有10kΩ→3.3V和20–50kΩ→5V两条理想电阻上拉，节点为 `(3.3/R1+5/R2)/(1/R1+1/R2)`，约3.58–3.87V。实测还受输出模式、钳位、其它支路与时序影响；3.3V不能证明导线未接，3.5V不能证明过压钳位。

两个不同节点电压相等不能证明导通；共地两点读0V也不能证明可靠低阻连接。断电隔离电源后通断/电阻核对，再在合法电平下观察动态握手。串阻只能限流/缓边沿，不能自动实现电平转换。

内层CAD类型为SIGNAL仍可铺连续GND铜，不等于没有参考平面。铺铜bbox越界不等于最终制造铜越界；需原生填充/裁剪/制造输出验证。

## 验证闭环

RP：确认料号与供电 → 记录工具版本/命令/镜像地址 → 写入校验并回读Flash → 切断所有供电路径再冷启动 → 查RUN、BOOTSEL、时钟与电源波形。

C2：断电认针/通断 → 核供电/耐压与接口固件映射 → 无争用地检查空闲电平和握手波形 → 再按官方接口建议决定上拉/保护与布局。禁止用带电直接短接信号来证明接口能检测。
