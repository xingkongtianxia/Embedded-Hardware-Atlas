## 第1讲：第一讲：课程介绍

### 📖 这一集讲什么

这一讲是整套课程的"路线图"。它要回答三个问题：**我们要做什么板？为什么必须用6层？整个流程分几步？**

本项目的目标板是"逻辑派 FPGA-G1 开发板"——一块以 FPGA 为核心、外挂 DDR3 内存、带 HDMI 输出、带 MCU 协处理、带 TF 卡与各类排针外设、由多路 DC-DC/LDO 供电的开发板。这种板子有三个典型特征：**BGA 封装（引脚在芯片底下，出不来线）**、**DDR3 高速并行总线（几百 Mbps~1.6Gbps 每根线，要等长）**、**HDMI 高速差分（Gbps 级，要阻抗控制）**。这三条任意一条，都足以让双面板"做不出来"。

所谓"全链路"，指的是下面这条不可跳步的流水线：

```
原理图分析 → 电源树梳理 → 网表/器件导入 → 板框结构导入 → 环境与快捷键
   → 模块抓取/接口定位 → 模块化预布局 → 3D 结构校验
   → 层数分析与叠层设置 → 阻抗理解与计算 → 规则（线宽/间距/过孔/网络类/差分）
   → BGA 扇孔 → 分模块布线 → 电源连通性 → 布线优化 → 时序等长
   → 缝合地过孔 → DRC → 丝印/LOGO → 生产资料输出 → 下单
```

### 🔬 深入原理

为什么"层数"不是随便定的？核心不是"线走不走得开"，而是**回流路径（Return Path）**。任何高速信号电流都必须形成回路，高频时回流电流会自动选择**阻抗最低**的路径，也就是紧贴信号线正下方的参考平面。判断一条线要不要按"传输线"对待，用临界长度：

$$L_{crit}=\frac{t_r}{2\,t_{pd}}$$

其中 $t_r$ 是信号上升沿时间，$t_{pd}$ 是单位长度传播延时（FR4 表层微带约 $5.6\ \mathrm{ps/mm}$，内层带状线约 $7.0\ \mathrm{ps/mm}$）。以 DDR3-800 为例，上升沿约 $t_r\approx 300\ \mathrm{ps}$，内层走线的临界长度约

$$L_{crit}=\frac{300}{2\times 7.0}\approx 21\ \mathrm{mm}$$

也就是说，**只要走线超过约 2 厘米，它就是一根传输线**，必须有连续的参考平面、必须控阻抗。一块 FPGA 开发板上几乎没有短于 2cm 的关键线，所以 6 层（至少 2 个完整地平面）是刚需，不是"炫技"。

### 🛠 设计实例/操作

开工前建议先建立工程目录，把整个项目的"资产"归位：

| 目录 | 内容 | 作用 |
|---|---|---|
| `01_原理图` | SCH 源文件、PDF | 布局布线时随时查 |
| `02_数据手册` | FPGA/DDR3/HDMI/DCDC 的 Datasheet | 查 pinout、封装、布线要求 |
| `03_结构` | 板框 DXF、3D STEP | 导入板框、装配校验 |
| `04_PCB` | PCB 工程 + 版本备份 | 每完成一个阶段存一版 |
| `05_生产资料` | Gerber/钻孔/坐标/BOM | 最后打包下单 |

**例：先确认三条"硬约束"。** ①板框尺寸与安装孔位置（决定布局边界）；②接口器件位置（HDMI、TF、USB、电源座、排针必须落在指定边缘）；③BGA pitch（决定过孔工艺与最小线宽）。这三条一旦后期变更，布局布线基本要推倒重来。

### ⚠️ 常见误区

- **误区一：先画完再想叠层。** 叠层决定阻抗线宽，线宽定不下来，布线全是白干。
- **误区二：把"6层"当成"多两层随便走线"。** 6 层的价值在两个完整 GND 参考面，如果把内层切得七零八落，还不如规规矩矩的 4 层板。
- **误区三：跳过原理图分析直接布局。** 不知道哪路电源给谁供、哪组线是同一 byte lane，布局必然错位。

### 📌 要点速记

1. 本项目 = FPGA + DDR3 + HDMI + MCU + 多路电源，属于典型"入门级高速板"。
2. 选 6 层的根本原因是**需要连续完整的参考平面**，不是走线密度。
3. 临界长度 $L_{crit}=t_r/(2t_{pd})$，超过它就必须当传输线处理。
4. 全链路顺序不可颠倒：叠层与规则一定要在大规模布线之前定死。
5. 工程目录与版本备份，是避免"改崩了回不去"的最低成本保险。

## 第2讲：第二讲：逻辑派原理图分析

### 📖 这一集讲什么

这一讲教你**怎么"读"一张开发板原理图**。很多人打开原理图只会看"这里连那里"，正确做法是先做**功能分块**，再做**信号流梳理**，最后落到**物理约束**。

逻辑派 FPGA-G1 的原理图通常按页组织，典型分页如下：

| 页面 | 模块 | 关键关注点 |
|---|---|---|
| P1 | 封面/框图 | 系统总览、模块间接口 |
| P2 | FPGA 核心（BANK0~BANK7） | 每个 BANK 的电平标准与 VCCIO |
| P3 | 配置电路（FLASH/JTAG） | 配置模式引脚、上下拉 |
| P4 | DDR3 | 数据/地址/控制分组、VREF、端接 |
| P5 | HDMI | TMDS 差分对、ESD、DDC |
| P6 | MCU | 晶振、下载口、与 FPGA 的通信 |
| P7 | 外设（TF、LED、按键、排针） | IO 归属哪个 BANK |
| P8 | 电源 | DC-DC / LDO / 上电时序 |

读图的正确顺序是：**先看电源 → 再看时钟 → 再看总线 → 最后看杂散 IO**。因为电源决定布局重心，时钟决定关键路径，总线决定等长分组。

### 🔬 深入原理

FPGA 原理图里最容易被初学者忽略的概念是 **BANK**。FPGA 的 IO 引脚按物理位置分成若干个 BANK，同一 BANK 共用一组 `VCCIO`，因此同一 BANK 内的 IO **电平标准必须一致**（3.3V LVCMOS 就不能和 1.5V SSTL15 混在一起）。这一点直接决定 PCB：

- 同一 BANK 的信号在芯片上是**物理相邻**的，出线方向天然一致 → 该 BANK 对应的外设应该布在芯片的那一侧；
- DDR3 通常独占一个（或两个）BANK，且该 BANK 的 VCCIO = 1.5V，需要单独的电源平面/铺铜块；
- 差分对必须使用同一 BANK 内成对的 `_P/_N` 引脚，不能随便凑。

另外要建立"**网络类（Net Class）**"的意识：原理图里的网络名会带有规律，例如 `DDR3_DQ0..DQ15`、`DDR3_DQS_P/N`、`DDR3_A0..A14`、`HDMI_TX0_P/N`。这些命名是后面在 PCB 里**批量建类、批量加规则、批量等长**的抓手。

### 🛠 设计实例/操作

**例1：给 DDR3 做信号分组表（后面等长直接用）。**

```
Byte Lane 0 : DQ0-DQ7   + DQS0_P/N + DQM0     -> 与 DQS0 组内等长
Byte Lane 1 : DQ8-DQ15  + DQS1_P/N + DQM1     -> 与 DQS1 组内等长
Address/CMD : A0-A14, BA0-BA2, RAS#, CAS#, WE#, CS#, CKE, ODT -> 与 CK 等长
Clock       : CK_P / CK_N                      -> 差分, 组内 ±5mil
Power/Ref   : VDD/VDDQ(1.5V), VREFCA/VREFDQ(0.75V), VTT(可选)
```

**例2：确认原理图有没有"漏项"。** 逐项打勾：BGA 每个电源球是否都有去耦电容？JTAG 是否有上拉？复位是否有 RC？未使用的 IO 是否处理？晶振负载电容是否给了？这些在原理图阶段花 10 分钟，能省掉 PCB 阶段的一次改板。

### ⚠️ 常见误区

- **只看连线不看电平标准**：把 1.5V BANK 的 IO 拿去接 3.3V 外设，板子做出来直接烧。
- **忽略网络命名规律**：命名混乱会导致 PCB 里无法用通配符批量建类，后面等长要一根根点，效率极低。
- **以为差分对随便选引脚**：差分必须用 FPGA 指定的 `_P/_N` 对，否则不能用作高速差分输出。

### 📌 要点速记

1. 读图顺序：电源 → 时钟 → 总线 → 杂散 IO。
2. BANK 是 FPGA 的 IO 分组单位，同 BANK 共用 VCCIO，决定外设布局方位。
3. 提前整理"信号分组表"，是后面建网络类和等长的基础。
4. 网络命名要有规律，方便 PCB 中用通配符（如 `DDR3_DQ*`）批量操作。
5. 原理图阶段的检查（去耦、上下拉、复位、晶振）成本最低。

## 第3讲：第三讲：原理图电源分析

### 📖 这一集讲什么

这一讲做一件极其重要但常被跳过的事：**画出这块板的电源树（Power Tree）**。电源树就是"电从哪来 → 经过谁 → 到谁去 → 要多大电流"的一张图。它同时决定了三件事：DC-DC 模块放哪、电源平面怎么分割、铜皮/过孔要多粗。

一块 FPGA 开发板的典型电源树（数值为示例量级，实际以原理图与器件手册为准）：

```
DC 5V 输入 (Type-C / DC 座)
   |
   +-- DCDC1 --> 1.0V / 1.2V  VCCINT   (FPGA 内核, 电流最大, 1~3A)
   |
   +-- DCDC2 --> 1.5V         VCCIO_DDR + DDR3 VDD/VDDQ (0.5~1.5A)
   |                  |
   |                  +-- 分压/专用芯片 --> 0.75V VREF (小电流, mA 级)
   |
   +-- DCDC3 --> 3.3V         VCCIO(3.3V BANK) / MCU / HDMI 5V逻辑周边 (1~2A)
   |                  |
   |                  +-- LDO --> 2.5V / 1.8V  VCCAUX 等 (低噪声小电流)
   |
   +-- 直通 --> HDMI +5V (给 HDMI 连接器 5V 供电, 需限流/ESD)
```

### 🔬 深入原理

**为什么必须先画电源树？** 因为电源决定了 PCB 的"重量分布"：

1. **DC-DC 是噪声源**，其开关节点（SW）是 dv/dt 极高的地方，必须远离 HDMI、DDR3、晶振等敏感区；
2. **VCCINT 电流最大**，铜皮宽度与过孔数量要按电流算；
3. **上电时序**：FPGA 通常要求内核电压先于 IO 电压建立（或有特定顺序），这决定了要不要加使能链、要不要 RC 延时；
4. **去耦网络**决定 PDN（电源分配网络）阻抗，是高速板成败的一半。

铜皮载流可用 IPC-2152 的工程近似（外层 1oz，温升 10℃）：

$$I \approx 0.0647 \cdot \Delta T^{0.4281} \cdot A^{0.6732}$$

其中 $A$ 为截面积（mil²），$\Delta T$ 为温升（℃）。工程上更常用的速记是：**外层 1oz 铜，10mil 线宽 ≈ 1A（温升 10℃）；内层 0.5oz，同宽度按一半估**。

过孔载流速记：**0.3mm 孔径的过孔约 1A**，所以 3A 的 VCCINT 换层至少要 4~6 个过孔并联（并留裕量）。

去耦电容的作用可以用阻抗理解，电容的自谐振频率：

$$f_{SRF}=\frac{1}{2\pi\sqrt{L_{ESL}C}}$$

超过 $f_{SRF}$ 后电容呈感性、失去去耦作用，所以要用 **10µF（低频）+ 0.1µF（中频）+ 0.01µF/1nF（高频）** 的组合，且高频小电容必须**离引脚最近**。

### 🛠 设计实例/操作

**例1：为 VCCINT（假设 2A）算铜宽与过孔。**
- 外层走线：需 ≈20mil 宽（1oz，ΔT=10℃）；实际直接用**铺铜块**代替走线更稳妥。
- 内层平面到 BGA 的换层：用 0.3mm 过孔，$2\text{A}/1\text{A} = 2$ 个，工程上取 **4 个以上**，分散在电源球周围。

**例2：给 DC-DC 定"电流回路最小环"。** DC-DC 的关键小环路是 `输入电容 → 上管 → 下管 → 地`，这个环路面积必须最小。原理图阶段就要标出 `Cin` 是哪几颗，布局时它们要紧贴芯片 VIN/GND 引脚，环路面积目标 < 5mm²。

### ⚠️ 常见误区

- **把电源当"随便连"**：细线连 2A 电源，板子一跑起来就压降/发热。
- **去耦电容堆数量不看位置**：100 颗放得远，不如 10 颗放得近。
- **忽略 VREF**：DDR3 的 VREF 是 0.75V 高精度参考，要用 1% 电阻分压且**就近每个 VREF 脚配 0.1µF**，走线宽度 ≥10mil 且远离高速线。
- **忽略上电时序**：FPGA 上电顺序错误可能导致配置失败甚至闩锁。

### 📌 要点速记

1. 先画电源树，再动布局；电源树 = 输入 → 变换 → 输出 → 负载 + 电流。
2. 速记：外层 1oz，10mil ≈ 1A；0.3mm 过孔 ≈ 1A。
3. 去耦要"大中小"搭配，位置比数量重要，高频小电容离引脚最近。
4. DC-DC 输入环路面积最小化，SW 节点面积最小化。
5. VREF、VCCAUX 这类"小电源"精度要求高，别当普通网络处理。

电源树理清后，模块的"物理重心"已经心里有数。下一讲开始动手：把原理图的**网表和器件导入 PCB**。

## 第4讲：第四讲：原理图网表器件导入

### 📖 这一集讲什么

这一讲把"图纸"变成"实物摆件"：**从原理图生成网表 + 器件封装，一次性推送到 PCB**。在嘉立创EDA专业版里，这一步就是原理图界面的"**设计 → 更新/转换原理图到 PCB**"（Altium 里叫 Update PCB Document / Import Changes）。

流程可以拆成四步：

```
① 编译原理图 (查错)  ->  ② 检查每个器件的封装是否已分配、是否正确
        ->  ③ 执行"更新到PCB"，生成变更清单  ->  ④ 逐条确认并应用
```

导入成功的标志是：PCB 里出现了一堆器件 + 一团"飞线"（Ratsnest，也叫鼠线）。飞线就是网表告诉你的"哪两个焊盘应该连在一起"。

### 🔬 深入原理

**网表（Netlist）到底是什么？** 本质上是一张两列表：`网络名 ↔ 器件位号.引脚号`。例如：

```
NET "DDR3_DQ0"   U1.A3   U5.G7
NET "3V3"        U2.5    C12.1   C13.1   R7.2  ...
```

PCB 软件靠它建立"连接关系"，DRC 才知道你有没有漏连、错连。所以**网表的准确性 = 原理图的准确性**，任何原理图里的错连都会 1:1 复制到 PCB。

**封装（Footprint）为什么是命门？** 封装的三个要素必须核对：
1. **焊盘尺寸与间距**：BGA 的 pitch（如 0.8mm）、QFN 的散热焊盘、连接器的定位孔；
2. **引脚编号映射**：BGA 的 A1 位置标识必须与 Datasheet 一致，弄反 180° 是最经典的报废原因；
3. **3D 模型与高度**：影响后续结构校验。

导入完成后必须做一次**"数量对账"**：原理图器件数 = PCB 器件数；原理图网络数 = PCB 网络数。少了就是没导入完，多了就是有重复位号。

### 🛠 设计实例/操作

**例1：导入前的封装自检清单**

| 检查项 | 怎么查 | 典型坑 |
|---|---|---|
| BGA pitch / 球数 | 对 Datasheet 的 Package Drawing | 用了错误的 pitch 版本 |
| A1 角标识 | 封装丝印上是否有 A1 圆点/切角 | 方向反 180° |
| 0402/0603 焊盘 | 是否用手工焊/回流焊规格 | 焊盘过小不好焊 |
| 连接器定位孔 | 是否为 NPTH（非金属化） | 做成金属化导致短路 |
| 排针 | 2.54mm 间距、孔径 ≥1.0mm | 孔径太小插不进去 |

**例2：处理导入报错。** 常见三类：
- *Footprint not found*：封装库路径丢失 → 重新指定或从立创商城元件库重新关联；
- *Duplicate designator*（位号重复）→ 回原理图执行"位号重新编号"；
- *Net has only one pin*（单端网络）→ 检查是不是漏连或测试点，确认无误可忽略。

导入完成后建议**立刻另存一版**（如 `PCB_v01_导入完成.epro`），这是整个项目的第一个还原点。

### ⚠️ 常见误区

- **不编译原理图直接导入**：错误会被原样带进 PCB，越到后面越难查。
- **封装从网上随便下**：一定要与实际采购的物料型号一一对应（同一芯片有多种封装）。
- **忽略"隐藏引脚"**：某些库把 VCC/GND 设为隐藏自动连接，导致网表和你想的不一样。
- **导入后不对账**：少导入几个器件，往往到布线中期才发现。

### 📌 要点速记

1. 网表 = "网络名 ↔ 位号.引脚"，是 PCB 建立连接关系与 DRC 的唯一依据。
2. 导入前必须编译原理图并逐个核对封装（尺寸、pitch、A1 方向、3D 高度）。
3. 导入后立即做数量对账：器件数、网络数、飞线是否合理。
4. BGA 方向弄反是最经典、最贵的错误，核对 A1 角标识。
5. 导入完成即另存版本，建立第一个还原点。

### 🔗 承上启下

器件已经进 PCB，但还是散落一堆。下一讲把**板框（结构边界）**导进来，先划定"地皮"，才能开始布局。

## 第5讲：第五讲：板框结构的导入

### 📖 这一集讲什么

板框（Board Outline）就是这块 PCB 的物理外形轮廓，加上安装孔、禁布区、接口开孔位置。开发板通常有结构工程师给的 **DXF** 文件（或你自己按外壳尺寸画）。这一讲讲**怎么把 DXF 导入 PCB、放到正确的层、并设定坐标原点**。

标准操作步骤：

```
① 结构给 DXF (单位 mm, 只保留必要图层)
② EDA 中 "文件 → 导入 → DXF"，选择单位 mm、指定放置层
③ 外形轮廓 -> 放到「板框层 / Board Outline」
   定位孔     -> 放置实际的 NPTH 孔（不是画个圆就行）
   限高/禁布  -> 放到「禁止布线层 / Keep-Out」
④ 设置原点：一般取板框左下角，或某个定位孔中心
⑤ 检查板框是否为「闭合曲线」
```

### 🔬 深入原理

**为什么板框必须闭合？** 因为 EDA 靠闭合轮廓判断"板内/板外"，从而进行铺铜、DRC 边距检查、以及生成 Gerber 的外形层（GKO）。如果轮廓有 0.001mm 的缝隙，铺铜会漏到板外，或者铺不出来，工厂也可能按错误外形开模。

**几个关键的结构约束：**

| 约束 | 典型值 | 原因 |
|---|---|---|
| 走线距板边 | ≥ 0.3mm（推荐 0.5mm） | 锣板/V-CUT 公差 ±0.2mm，防止铣断 |
| 铜皮距板边 | ≥ 0.3mm | 防止边缘铜箔翘起、短路 |
| 定位孔周围禁布 | 孔径 + 0.5mm 环 | 防螺丝/铜柱压伤走线 |
| 器件距板边 | ≥ 1mm（贴片）| 贴片机夹持边（工艺边）要求 |
| 拼板工艺边 | 5mm | 无器件区，供贴片机传送 |

**20H 规则**：电源平面相对地平面向内收缩 20 倍层间距 $H$，可显著抑制平面边缘辐射。6 层板中，L4 电源层相对 L2/L5 地层内缩，是低成本的 EMC 改善手段。实际工程中常取内缩 0.5~1mm 即可（完整照搬 20H 有时会牺牲过多平面面积）。

### 🛠 设计实例/操作

**例1：导入后的三步校验。**
1. 用测量工具量一下板框长宽，是否等于结构图标注（防止单位被当成 inch，一导入就大了 25.4 倍）；
2. 量定位孔中心距，是否与外壳螺柱一致；
3. 看有没有多余的 DXF 图层（标注线、尺寸线）被一起导进来 → 全部删掉，否则会进 Gerber。

**例2：设置原点与栅格。**
- 原点设在板框左下角，这样所有坐标都是正数，输出贴片坐标文件时最直观；
- 栅格：布局阶段用 0.5mm 或 1mm（对齐好看），布线阶段切到 0.025mm（1mil）或更细。

**ASCII 示意：**

```
   +---------------------------------------+  <- 板框层(闭合)
   | ○(M3)                          (M3)○  |  <- 定位孔 NPTH
   |   ┌───禁布区(距边0.5mm)──────────┐    |
   |   │                              │    |
   |   │        器件布局区域           │    |
   |   │                              │    |
   |   └──────────────────────────────┘    |
   | ○(M3)                          (M3)○  |
   +---------------------------------------+
   ↑原点(0,0)
```

### ⚠️ 常见误区

- **单位搞错**：DXF 默认单位是 inch，导入时不选 mm，板子直接变成 25.4 倍大。
- **板框画在丝印层**：Gerber 输出没有外形层，工厂无法开料。
- **轮廓不闭合 / 有重叠线段**：铺铜异常、DRC 报错、工厂发来确认单。
- **定位孔画成圆圈没打孔**：结果板上没孔，装不上。
- **忘了工艺边**：SMT 贴片时无法夹持，产线拒收。

### 📌 要点速记

1. 板框必须放在板框层、必须**闭合**、必须**单一轮廓**（内部挖槽另算）。
2. 导入 DXF 注意单位（mm），并删除多余标注图层。
3. 走线/铜皮距板边 ≥0.3mm，推荐 0.5mm；器件距边 ≥1mm。
4. 原点建议放板框左下角，方便后续坐标文件输出。
5. 20H 规则：电源层相对地层内缩，改善边缘辐射。

### 🔗 承上启下

"地皮"划好了。下一讲配置**工作环境和快捷键**，把画板效率先提上来，再进入真正吃时间的布局环节。

## 第6讲：第六讲：PCB 快捷键导入与设置

### 📖 这一集讲什么

这一讲是纯效率课：**导入并熟记一套快捷键，设置好栅格、层显示、交互式布线参数**。多层板设计动辄几千根飞线，鼠标点菜单和敲快捷键的效率差距是 3~5 倍。

嘉立创EDA专业版支持在"**设置 → 快捷键**"中导入/导出快捷键配置文件，很多教程会附一份配置好的方案（常见是模仿 Altium 习惯）。导入后建议自己再改几个最顺手的。

**高频快捷键（以常见配置为例，具体以你导入的方案为准）：**

| 功能 | 常见键位 | 使用场景 |
|---|---|---|
| 交互式布线 | `W` | 拉线 |
| 差分对布线 | `Shift+W` / `UD` | HDMI、DQS、CLK |
| 放置过孔 | 布线中按 `数字键/中键` | 换层 |
| 切换层 | `+` / `-` / `Tab` | 顶底层切换 |
| 单层显示 | `Shift+S` | 看内层、检查参考面 |
| 测量距离 | `Ctrl+M` | 量线距、量间距 |
| 布局传递 | `Shift+F` / 面板按钮 | 按模块抓器件 |
| 3D 视图 | `3` | 结构校验 |
| 铺铜/重铺 | `T+G` 系列 | 铺 GND |
| 全局编辑 | 右键→查找相似 | 批量改属性 |

### 🔬 深入原理

快捷键之外，真正影响画板质量的是这几项**环境设置**：

1. **栅格（Grid）**：布局用 0.5/1mm，布线用 1mil 或 0.5mil。栅格太粗会导致 BGA 扇孔对不齐，太细会导致布局歪斜。
2. **捕捉（Snap）**：开启"捕捉到焊盘中心/线端点"，避免出现肉眼看不见的 0.001mm 断点。
3. **层颜色与可见性**：6 层板必须给 L1~L6 设置**区分度高**的颜色，且养成"只显示当前布线层 + 参考层"的习惯。
4. **交互式布线模式**：设置"推挤（Push）"或"忽略障碍"，并打开**在线 DRC**——边画边报错，比最后统一 DRC 效率高得多。
5. **默认线宽/过孔尺寸**：先设成规则里的常用值（如线宽 5mil、过孔 0.2/0.4mm），减少每次手动改。

### 🛠 设计实例/操作

**例1：配置"单层高亮"工作流。** 布 DDR3 内层线时，把显示模式设为"当前层实色 + 其他层半透明"，这样能一眼看出：这根线下面的参考面是否连续、有没有跨越平面分割。这是高速板最重要的可视化习惯。

**例2：预设三套线宽。**

```
默认信号线 : 4~5 mil   (受阻抗规则约束)
一般电源线 : 15~20 mil
大电流电源 : 铺铜块 (不用走线)
```

在"布线宽度"里预设好，布线时用快捷键在几个宽度间循环切换。

### ⚠️ 常见误区

- **不开在线 DRC**：画到最后 DRC 报几百个错，返工量巨大。
- **栅格太粗**：BGA 0.8mm pitch 下，1mm 栅格会让过孔完全对不上焊盘。
- **层颜色相近**：L3 和 L5 都是深蓝，布线时经常走错层而不自知。
- **快捷键与系统输入法冲突**：中文输入法下部分单键失效，画板时切到英文。

### 📌 要点速记

1. 先花 20 分钟配快捷键和环境，后面能省几十小时。
2. 布局栅格 0.5~1mm，布线栅格 1mil；必须开启焊盘中心捕捉。
3. 6 层板务必设置高区分度的层颜色，并养成单层查看习惯。
4. 打开**在线 DRC**，边画边纠错。
5. 预设常用线宽/过孔尺寸，减少重复操作。

### 🔗 承上启下

工具磨好了。从下一讲开始进入本套课程最见功力的部分——**布局**，先从"模块抓取"和"接口器件定位"开始。

## 第7讲：第七讲：模块抓取以及接口器件布局

### 📖 这一集讲什么

导入后的 PCB 是一堆散落器件。这一讲教两件事：

1. **模块抓取（布局传递）**：在原理图里框选某一页/某个模块的全部器件，PCB 中自动把这些器件"抓"到一起并成组，避免手工大海捞针。
2. **接口器件优先定位**：把所有"对外接口"先钉死在板边正确位置，因为它们受**结构**约束，不可移动。

顺序永远是：**结构件 → 接口 → 主芯片 → 模块外围 → 小器件**。这叫"由外向内、由大到小"。

### 🔬 深入原理

**为什么接口先放？** 因为接口位置是唯一由外部世界（外壳、插头、面板）决定的，属于硬约束。主芯片位置是"软约束"，可以为接口让路。如果先放主芯片，往往会发现 HDMI 走不过去，只能重来。

**接口布局的三条准则：**

| 准则 | 说明 |
|---|---|
| 就近原则 | 接口的 ESD/滤波/端接器件紧贴接口，不能拉长走线 |
| 出线方向 | 接口引脚朝板内，走线不绕大弯 |
| 隔离原则 | 高速接口（HDMI）与电源输入、DC-DC 分区放，避免噪声耦合 |

**HDMI 接口的特殊要求**：TMDS 差分线从连接器出来后应**尽快、笔直**地进入 FPGA 侧，ESD 保护器件（如 TVS 阵列）必须紧贴连接器焊盘（走线 stub < 5mm），否则 ESD 电流会先进板内再被泄放，起不到保护作用；同时 TVS 的寄生电容会影响 Gbps 信号，必须选低容值（≤1pF 级）器件。

### 🛠 设计实例/操作

**例1：逻辑派 FPGA-G1 的接口分边规划（示例思路）**

```
        ┌──────────── 上边缘: 排针 IO / 扩展口 ────────────┐
        │                                                  │
 左边缘 │   [FPGA BGA]        [DDR3]                       │ 右边缘
 电源座 │        ↑              ↑                          │ HDMI
 +DCDC  │     核心区(板中)                                  │ TF卡
        │                                                  │ USB/串口
        └──────────── 下边缘: 按键/LED/复位 ────────────────┘
```

要点：
- **电源输入 + DC-DC 集中在一侧**（本例左侧），噪声源统一隔离；
- **HDMI 放在离 FPGA 对应 BANK 最近的那条边**（这就是第2讲整理 BANK 的用处）；
- **TF 卡**要能插拔，卡槽开口必须超出板边或对齐外壳槽口；
- **按键/LED**放人手可及的边缘，且远离高速区。

**例2：模块抓取实操。** 在原理图 P4（DDR3 页）框选全部器件 → 使用"布局传递/交叉选择"功能 → PCB 中这些器件被高亮并可整体拖动到 DDR3 预定区域。然后把该组临时"锁定"，防止后续误拖。

### ⚠️ 常见误区

- **先摆主芯片再摆接口**：结构一确认，接口位置固定，主芯片就得挪，前功尽弃。
- **接口不锁定**：布线时误拖 0.2mm，装不进外壳。
- **ESD 器件放远了**：等于没放。
- **HDMI 放在 FPGA 的"背面 BANK"**：差分线要绕过整颗 BGA，长度和风险都翻倍。

### 📌 要点速记

1. 布局顺序：结构件 → 接口 → 主芯片 → 外围 → 小器件。
2. 接口位置由结构决定，放好后**立即锁定**。
3. 接口的保护/滤波器件必须紧贴接口焊盘。
4. 高速接口要放在对应 FPGA BANK 的同侧，缩短走线。
5. 用"模块抓取/布局传递"按原理图页面成组搬运，效率最高。

### 🔗 承上启下

接口钉死了，板子的四条边有了"角色"。下一讲开始做**模块化预布局**，把每个功能块划分到自己的地盘。

## 第8讲：第八讲：模块化布局-预布局

### 📖 这一集讲什么

预布局（Pre-layout / Floorplan）就是**先不摆小器件，只用"方块"划分功能区**。相当于装修前先分卧室、厨房、卫生间。做完预布局，你应该能一眼说出："这块板左边是电源，中间是 FPGA，右上是 DDR3，右边是 HDMI……"

预布局要同时满足四类约束：

```
① 电气约束: 高速线要短 (DDR3 尽量贴 FPGA)
② 电源约束: DC-DC 靠近大电流负载, 但远离敏感电路
③ 热约束  : 发热器件分散, 不要堆一起
④ 结构约束: 接口位置、限高区、螺柱位置
```

### 🔬 深入原理

**模块化布局的核心思想是"最小化关键路径长度"**。可以用一个简单的评价指标：把所有高速网络的飞线长度加起来（EDA 一般有"飞线总长"统计），预布局的目标就是让这个数尽量小，同时不违反其他约束。

**分区（Partition）与隔离**：一块板在物理上应划分为几个"域"：

| 域 | 内容 | 隔离要求 |
|---|---|---|
| 高速数字域 | FPGA、DDR3 | 参考面完整，内部走线最短 |
| 高速差分域 | HDMI TMDS | 远离 DC-DC 与晶振 |
| 低速数字域 | MCU、按键、LED | 无特殊要求 |
| 电源域 | DC-DC、电感、大电容 | 与前三者物理隔开 |
| 模拟/时钟域 | 晶振、PLL 供电 | 独立铺地，远离开关节点 |

**DDR3 与 FPGA 的距离**：点对点（一颗 DDR3）连接时，走线长度建议控制在 **2000~3000 mil（约 50~76mm）以内**。太长会让等长绕线难做、信号完整性变差。因此 DDR3 芯片应放在 FPGA 对应 BANK 的正对面，间距 15~25mm 是常见的舒适值（要给扇孔和等长绕线留空间）。

### 🛠 设计实例/操作

**例1：预布局的"泡泡图"画法。** 先在纸上（或 PCB 上用画线工具）画出各功能块的矩形，标注面积估算：

```
+----------------------------------------------------------+
|  电源区        |            FPGA 核心区        |  HDMI    |
|  (DC-DC x3)    |         [BGA 17x17mm]         |  区      |
|  电感/大电容    |                                |  TVS/连接器
|----------------|-------------------------------|----------|
|  MCU 区        |   DDR3 区 [x16, 一颗]          |  TF 卡区 |
|  晶振/下载口    |   + 去耦 + VREF               |          |
+----------------------------------------------------------+
|                    排针 / 扩展 IO 区                       |
+----------------------------------------------------------+
```

**例2：面积估算方法。** 每个模块的面积 ≈ 主芯片面积 × 2.5~3（要给去耦电容、扇孔过孔、走线通道留位置）。BGA 区域尤其要注意：BGA 下方基本被扇孔过孔占满，去耦电容只能放**背面**。

### ⚠️ 常见误区

- **预布局不留余量**：模块贴太紧，后面加一颗电容都放不下。
- **只看飞线不看噪声**：为了走线短把 DC-DC 塞到 HDMI 旁边。
- **忘了背面**：BGA 背面要放去耦电容，如果背面也堆满器件，就没地方了。
- **不考虑等长绕线空间**：DDR3 等长需要蛇形走线，必须预留至少 5~10mm 的"绕线走廊"。

### 📌 要点速记

1. 预布局 = 用方块划分功能域，不摆小器件。
2. 四类约束同时满足：电气、电源、热、结构。
3. DDR3 走线建议 < 3000mil，芯片间距 15~25mm。
4. 模块面积 ≈ 主芯片面积 × 2.5~3，务必留余量。
5. 必须预留**等长绕线走廊**和**背面去耦位置**。

### 🔗 承上启下

大格局定了。接下来的第 8 讲（一）~（五），逐个模块细化布局，从 HDMI 开始。

## 第9讲：第八讲（一）：HDMI模块化布局

### 📖 这一集讲什么

HDMI 是这块板上速率最高的接口之一。HDMI 1.4 每条 TMDS 通道可达 3.4Gbps，HDMI 2.0 可达 6Gbps。这一讲讲 HDMI 模块的器件应该怎么摆。

HDMI 模块典型器件清单：

| 器件 | 作用 | 布局要求 |
|---|---|---|
| HDMI 连接器 | 对外接口 | 板边，结构定位 |
| TVS/ESD 阵列 | 防静电 | **紧贴连接器**，stub 最短 |
| AC 耦合电容（部分方案） | 隔直 | 对称、靠近源端 |
| DDC 上拉电阻（SDA/SCL） | I²C 通信 | 靠近连接器 |
| HPD 分压/缓冲 | 热插拔检测 | 靠近连接器 |
| +5V 限流/保险 | 给外设供电 | 靠近连接器 |
| CEC 上拉 | 控制通道 | 靠近连接器 |

### 🔬 深入原理

**TMDS 差分对的核心要求：**

1. **阻抗 100Ω 差分**（单端 50Ω）；
2. **对内等长**：$\Delta L \le 5\ \mathrm{mil}\ (0.127\mathrm{mm})$，越严越好；
3. **对间等长**：4 对（3 数据 + 1 时钟）之间建议 $\Delta L \le 50\ \mathrm{mil}$，严格设计可做到 20mil；
4. **参考面连续**：全程不跨分割，换层必须伴随地过孔；
5. **远离干扰**：与其他信号间距 ≥ 3W（W 为线宽），与电源/时钟 ≥ 4W。

**为什么 ESD 器件必须紧贴连接器？** ESD 脉冲上升沿极快（IEC 61000-4-2 规定 $t_r \approx 0.7\sim1\ \mathrm{ns}$），走线的寄生电感 $L$ 会产生电压 $V=L\,di/dt$。1nH 电感在 30A/ns 的 di/dt 下就产生 30V 压降。因此 TVS 到连接器的走线越短越好，TVS 的接地脚要**直接打过孔到 GND 平面**，而不是绕一段再接地。

**差分对间距**：$S$ 与 $H$ 的比值决定耦合强度。工程上 HDMI 常用**弱耦合**设计（$S \ge 2W$），这样对内间距变化对阻抗影响小，走线更容错。

### 🛠 设计实例/操作

**例1：HDMI 布局的 ASCII 布置**

```
   板边
   ┌──────────────┐
   │  HDMI 连接器  │
   └──┬─┬─┬─┬─┬───┘
      │ │ │ │ │      <- TMDS 4 对，笔直向内
   ┌──┴─┴─┴─┴─┴──┐
   │  TVS 阵列    │   <- 紧贴，≤3mm
   └──┬─┬─┬─┬─┬──┘
      │ │ │ │ │
      ↓ ↓ ↓ ↓ ↓  直奔 FPGA 对应 BANK
   [DDC 上拉][HPD][CEC]  <- 低速信号，放两侧，不挡差分通道
```

关键：**中间留出一条"差分高速通道"，任何低速器件都不许挡在这条通道上。**

**例2：给 TMDS 预留通道宽度。** 4 对差分，假设线宽 5mil/间距 7mil（对内），对与对之间留 3W = 15mil：
单对宽度 = 5+7+5 = 17mil，4 对 + 3 个间隔 = 17×4 + 15×3 = 113mil ≈ 2.9mm。布局时至少给这条通道留 4~5mm 净空。

### ⚠️ 常见误区

- **TVS 放在走线中段**：形成长 stub，高频反射 + ESD 保护失效。
- **差分对之间塞低速线**：串扰直接把眼图打糊。
- **HDMI +5V 走细线且不加磁珠**：外设一插，噪声灌回板内。
- **DDC 的 SDA/SCL 上拉放 FPGA 端**：应放连接器端，符合规范。

### 📌 要点速记

1. HDMI TMDS = 100Ω 差分，对内 ≤5mil，对间建议 ≤50mil。
2. ESD/TVS 必须紧贴连接器，接地脚就近打孔到 GND。
3. 布局要预留一条无阻挡的"差分通道"（约 4~5mm 净空）。
4. 低速信号（DDC/CEC/HPD）放两侧，不许穿越差分区。
5. TVS 选低寄生电容（≤1pF 级）型号，否则劣化 Gbps 信号。

### 🔗 承上启下

HDMI 区域定了。下一讲处理相对简单但细节不少的 **MCU 模块**。

## 第10讲：第八讲（二）：MCU模块布局

### 📖 这一集讲什么

开发板上的 MCU 通常承担"协处理"角色：上电配置 FPGA、USB 转串口、按键扫描、电源使能控制等。速率不高，但**布局细节决定它稳不稳**。

MCU 模块的布局要素按优先级排：

```
① 去耦电容   -> 每个 VDD 引脚配 0.1µF，紧贴引脚（<2mm）
② 晶振电路   -> 晶振 + 两个负载电容，紧贴 MCU，包地
③ 复位电路   -> RC 靠近 NRST 引脚
④ 下载/调试口 -> SWD/JTAG，走线短，放板边方便插
⑤ 其他外设   -> LED/按键等，自由度大
```

### 🔬 深入原理

**晶振为什么是"重灾区"？** 晶振是板上少有的**持续振荡的模拟节点**，两条特点：
1. 它**怕干扰**：外部噪声耦合进来会导致频偏甚至停振；
2. 它**是干扰源**：其谐波会一路辐射到几百 MHz。

正确处理：
- 晶振与两个负载电容组成的回路面积**最小化**；
- 晶振正下方（相邻层）保持**完整地平面**，不许走任何线；
- 晶振外围铺地并用**地过孔围一圈**（"包地/护城河"），过孔间距 ≤ λ/20；
- 负载电容的地就近打孔到 GND。

负载电容取值：

$$C_L = \frac{C_1 C_2}{C_1 + C_2} + C_{stray}$$

其中 $C_{stray}$ 为 PCB 与引脚杂散电容，通常取 3~5pF。若晶体要求 $C_L=12\ \mathrm{pF}$，$C_{stray}=4\ \mathrm{pF}$，则 $C_1=C_2=2(12-4)=16\ \mathrm{pF}$，实际选 15pF 或 18pF。**这说明布局时晶振走线越长，杂散电容越大，频率越偏。**

**去耦电容为什么要"紧贴"？** 去耦回路的电感决定了它的有效频率上限。回路电感近似与走线长度成正比（经验值：过孔约 0.3~0.5nH，1mm 细走线约 0.5~1nH）。电容放远 5mm，就等于串了 2~5nH，其有效去耦频率大幅下降。

### 🛠 设计实例/操作

**例1：MCU 去耦布局标准图**

```
        ┌───────────────┐
   C1───┤ VDD        VDD├───C2      C1..C4 = 100nF, 均 <2mm
        │               │           且电容地脚各自打孔到 GND
   [Y1] ┤ OSC_IN        │
   ‖‖   │               │
   [C5] ┤ OSC_OUT       │           Y1 紧贴, 回路面积最小
   [C6] │               │
        │          NRST ├──[R]──VDD
        └───────────────┘   └──[C]──GND   (RC 复位)
```

**例2：下载口布局。** SWD 只需 `SWDIO/SWCLK/GND/VDD/NRST` 五根线，放板边 4~5Pin 排针即可；走线长度尽量 <10cm，SWCLK 上可预留 22Ω 串阻位置抑制过冲。USB 转串口的 D+/D- 是 90Ω 差分，虽然是全速 12Mbps，也建议成对走线、等长、不跨分割。

### ⚠️ 常见误区

- **晶振下面走线**：这是最常见也最致命的错误，会造成时钟抖动。
- **负载电容取值照抄别人的板**：不同晶体 $C_L$ 不同，必须按公式算。
- **去耦电容"象征性"放几颗**：应做到"每个电源引脚一颗"。
- **复位 RC 离引脚远**：容易被干扰误复位。
- **MCU 与 DC-DC 电感靠太近**：电感漏磁耦合到晶振。

### 📌 要点速记

1. MCU 布局优先级：去耦 → 晶振 → 复位 → 调试口 → 外设。
2. 晶振回路面积最小、下方地平面完整、外围包地过孔。
3. 负载电容 $C_1=C_2=2(C_L-C_{stray})$，$C_{stray}$ 取 3~5pF。
4. 每个 VDD 引脚配 0.1µF，距离 <2mm，地脚单独打孔。
5. USB D+/D- 按 90Ω 差分处理，即使是全速也要成对等长。

### 🔗 承上启下

MCU 是"配角"。下一讲进入全板核心——**FPGA 模块布局**，难度陡增。

## 第11讲：第八讲（三）：FPGA模块化布局

### 📖 这一集讲什么

FPGA 是这块板的中心，它的布局其实包含三层内容：

1. **FPGA 本体的朝向**：BANK 与外设的对应关系决定芯片旋转角度；
2. **去耦电容网络**：几十颗电容怎么摆；
3. **配置电路**：FLASH、JTAG、模式引脚的位置。

一句话原则：**先按 BANK 朝向定 FPGA 旋转角度，再排去耦，最后放配置电路。**

### 🔬 深入原理

**BANK 朝向决定一切。** 假设 FPGA 的 BANK 分布如下（示意）：

```
            BANK 0 (顶边)
      ┌──────────────────────┐
BANK7 │                      │ BANK 1
(左)  │      FPGA  BGA       │  (右)
BANK6 │                      │ BANK 2
      └──────────────────────┘
            BANK 3/4 (底边)
```

如果 DDR3 分配在 BANK 1/2（右侧），HDMI 在 BANK 0（顶边），那么 DDR3 就该放在芯片右侧、HDMI 放在顶部。若结构上 HDMI 必须在右边，就把 FPGA **旋转 90°**，而不是让走线绕半圈。**旋转芯片是零成本的，绕线是有代价的。**

**FPGA 去耦网络的分层思想（PDN 三段式）：**

| 频段 | 电容 | 位置 |
|---|---|---|
| DC~100kHz | 稳压器本身 | DC-DC 输出 |
| 100kHz~1MHz | 100µF/47µF 钽电容/固态电容 | 电源入口附近 |
| 1MHz~50MHz | 10µF/4.7µF 0603/0805 MLCC | BGA 外围一圈 |
| 50MHz~500MHz | 100nF 0402 MLCC | **BGA 背面正对电源球** |
| >500MHz | 平面电容（L4-L5 间距薄） | 靠叠层保证 |

目标是让 PDN 阻抗在关注频段内低于目标阻抗：

$$Z_{target}=\frac{V_{dd}\times \text{ripple}\%}{I_{max}}$$

例：$V_{dd}=1.0\mathrm{V}$，允许纹波 5%，$I_{max}=2\mathrm{A}$，则 $Z_{target}=\dfrac{1.0\times0.05}{2}=25\ \mathrm{m}\Omega$。

### 🛠 设计实例/操作

**例1：BGA 背面去耦摆放。**

```
   正面(TOP): BGA 焊球阵列
              ● ● ● ● ● ●
              ● ⊕ ⊕ ● ● ●    ⊕ = VCCINT 球
              ● ⊕ ⊕ ● ● ●
   ─────────────────────────  板
   背面(BOT):    [C 0402]      <- 正对 ⊕ 位置
                 两端各 1~2 个过孔直插 L4(PWR)/L2(GND)
```

要点：电容焊盘到过孔的走线要**极短**（理想 0，即 via-in-pad 或紧贴），因为这段走线的电感直接串进去耦回路。

**例2：配置电路布局。** 配置 FLASH（如 SPI NOR）应靠近 FPGA 的配置引脚 BANK，走线短、加 22~33Ω 串阻；JTAG 排针放板边，TCK 上串阻，TDI/TDO/TMS 加上拉；模式选择引脚（MODE/M[2:0]）的上下拉电阻要**靠近引脚**且**丝印标清**，方便调试时改模式。

### ⚠️ 常见误区

- **不看 BANK 就摆芯片**：结果 DDR3 的 16 根数据线要绕过整颗 BGA。
- **去耦电容全放正面外围**：BGA 中心的电源球得不到高频去耦。
- **电容与过孔之间拉一段细线**：电感翻倍，等于白放。
- **忘记 VCCAUX / VCCBRAM 等辅助电源**：这些也需要独立去耦。
- **配置 FLASH 放太远**：配置速率虽不高，但长走线易受干扰导致配置失败。

### 📌 要点速记

1. 先定 BANK 朝向再定芯片角度，旋转芯片比绕线便宜。
2. PDN 分频段去耦：大电容管低频、小电容管高频、平面管超高频。
3. 目标阻抗 $Z_{target}=V_{dd}\cdot\text{ripple}\%/I_{max}$，据此定电容数量。
4. 高频 0402 电容放 BGA **背面正对电源球**，走线趋近于零。
5. 配置电路（FLASH/JTAG/模式脚）靠近对应引脚，串阻+上下拉齐全。

### 🔗 承上启下

FPGA 定位完成。下一讲摆放与它配对、要求最苛刻的 **DDR3 模块**。

## 第12讲：第八讲（四）：DDR模块布局

### 📖 这一集讲什么

DDR3 布局是整块板的技术制高点。这一讲要解决：**DDR3 芯片放哪、怎么摆、去耦怎么排、VREF 怎么处理、给等长留多少空间。**

DDR3 的关键参数（以 DDR3-800/1066 为例）：

| 项目 | 值 |
|---|---|
| 数据速率 | 800~1600 Mbps/pin |
| 单端阻抗 | 40~60Ω（常取 50Ω） |
| 差分阻抗（DQS/CK） | 100Ω |
| 供电 | VDD/VDDQ = 1.5V（DDR3L 为 1.35V） |
| 参考电压 | VREFCA / VREFDQ = 0.75V |
| 上升沿 | ~200~400ps |

### 🔬 深入原理

**拓扑选择。** FPGA + **一颗** x16 DDR3 属于**点对点（Point-to-Point）**，最简单：
- 数据线（DQ/DQS/DQM）天然点对点，无需外部端接（依靠片上 ODT + 驱动强度）；
- 地址/命令/控制线同样点对点，通常也可省略 VTT 端接（多颗时才需要 fly-by + VTT）。

```
 单颗 x16 (本项目典型):
   FPGA ──── DQ[15:0]/DQS/DQM ────► DDR3
   FPGA ──── A/BA/CMD/CTRL   ────► DDR3
   FPGA ──── CK_P/CK_N       ────► DDR3      (无需 VTT)

 多颗 fly-by (对比):
   FPGA ──┬──┬──┬──► ... ──► VTT 端接电阻排
          U1 U2 U3
```

**摆放方向**：DDR3 的引脚在封装上也是分区的——一侧集中 DQ0-7，另一侧 DQ8-15，中间是地址/命令。摆放时要让 **DDR3 的 DQ 区正对 FPGA 的对应 BANK**，做到"引脚对引脚"，飞线不交叉。如果飞线看起来像"麻花"，说明方向摆反了，旋转 180° 试试。

**间距**：FPGA 与 DDR3 边缘间距建议 **15~25mm**。太近扇孔和等长没空间，太远走线超长。

### 🛠 设计实例/操作

**例1：DDR3 去耦与 VREF 布置**

```
   ┌─────────────────────────────────┐
   │        DDR3  (x16, BGA96)        │
   │   VDD/VDDQ 球在四周与中间         │
   └─────────────────────────────────┘
   背面: 每 1~2 个 VDDQ 球配 100nF, 正对放置
   正面: 边缘放 2~4 颗 10µF + 若干 100nF

   VREF 生成:
   1.5V ──[R1 1% 1k]──┬── VREFCA/VREFDQ (走线 ≥10mil)
                      │
                  [C 100nF] (紧贴分压点)
                      │
   GND  ──[R2 1% 1k]──┘
   每个 VREF 引脚就近再配 100nF 到 GND
```

**例2：预留等长走廊。** DDR3 数据线需要组内等长（±25mil），实际绕线会占用面积。经验做法：在 FPGA 与 DDR3 之间预留一条 **8~15mm 宽的空白带**（不放器件），专门用于蛇形绕线。这块空地在布局阶段就要留出来，后期腾不出来。

### ⚠️ 常见误区

- **DDR3 摆反方向**：飞线交叉成麻花，布线时被迫大量换层。
- **不留等长空间**：等长做不出来，只能在 BGA 缝隙里"绣花"。
- **VREF 用普通细线且走很远**：VREF 是判决门限，受扰会直接误码；应短、粗（≥10mil）、就近去耦、远离 DQ。
- **DDR3 去耦全放正面**：BGA 下方电源球够不着，高频去耦失效。
- **DDR3 下方参考层被分割**：数据线回流断裂，这是致命错误。

### 📌 要点速记

1. 单颗 x16 属点对点拓扑，一般无需 VTT 端接；多颗才用 fly-by。
2. DDR3 摆放看"飞线是否交叉"，交叉就旋转，做到引脚对引脚。
3. FPGA-DDR3 边缘间距 15~25mm，中间留 8~15mm 等长走廊。
4. VREF：1% 电阻分压、走线 ≥10mil、每脚就近 100nF、远离 DQ。
5. VDDQ 去耦 100nF 放背面正对电源球，边缘补 10µF。

### 🔗 承上启下

数字部分布局收官。下一讲处理噪声最大、也最考验功力的 **DC-DC 电源模块布局**。

## 第13讲：第八讲（五）：DCDC电源模块布局讲解

### 📖 这一集讲什么

DC-DC（开关电源）布局是"物理课"：它关心的不是连通性，而是**电流环路面积**和**dv/dt 节点面积**。这一讲讲清楚一个 Buck 电路怎么摆才安静、才不发烫。

一个同步 Buck 的关键器件：`VIN 输入电容 Cin`、`芯片（含上下管）`、`电感 L`、`输出电容 Cout`、`反馈电阻 R1/R2`、`自举电容 Cboot`、`补偿网络`。

### 🔬 深入原理

**核心概念：热回路（Hot Loop）。** Buck 中电流路径分两个相位：

```
上管导通 (相位1):  Vin → Cin → 上管 → L → Cout → GND → Cin
下管导通 (相位2):  L → Cout → GND → 下管 → L

两相位电流之"差"= 高频交流环流, 只流经:
      Cin → 上管 → 下管 → GND → Cin      <== 这就是热回路
```

**只有热回路是高 di/dt 的**，它的面积决定了辐射和 SW 振铃。所以第一优先级永远是：**Cin 紧贴芯片 VIN 和 GND 引脚，环路面积最小（目标 <5mm²）。**

环路电感产生的尖峰电压：

$$V_{spike}=L_{loop}\cdot\frac{di}{dt}$$

若 $L_{loop}=5\ \mathrm{nH}$，$di/dt=2\ \mathrm{A/ns}$，则 $V_{spike}=10\ \mathrm{V}$——足以让 5V 输入的芯片看到 15V 尖峰而损坏。

**SW 节点：铜皮面积要"够用即可，越小越好"。** SW 是 dv/dt 最高的节点（几 V/ns），面积大就是天线。但又要能过电流，所以取折中：宽度按电流够用（如 2A 取 40~60mil 或一小块铜），长度尽量短，**不要为了散热把 SW 铺一大片**。

**反馈（FB）走线**：FB 是高阻抗节点，最怕干扰。规则：
- FB 走细线（6~10mil），从 **Cout 正极就近取样**（真正的负载点），不要从电感出口取；
- FB 走线远离 SW 和电感，必要时在下方铺地隔离；
- 分压电阻靠近芯片 FB 引脚。

### 🛠 设计实例/操作

**例1：Buck 标准布局（ASCII）**

```
        VIN 进来
          │
      ┌───┴───┐ Cin(0402/0603 x2, 紧贴!)
      │  ▓▓▓  │
   ┌──┴───────┴──┐
   │   DCDC IC   │── SW ──[ 电感 L ]──┬── VOUT
   │  VIN    SW  │   短且窄            │
   │  GND    FB  │◄──细线取样───────┤
   └──┬──────────┘                    │
      │                          ┌────┴────┐
     GND 大面积铺铜 + 多过孔      │  Cout   │
                                 └────┬────┘
                                     GND
```

顺序口诀：**Cin 最先摆 → 芯片 → 电感 → Cout → FB 分压 → 其他。**

**例2：热设计与隔离。**
- 芯片散热焊盘下方打 **4~9 个过孔（0.3mm）**，把热导到内层地平面；
- 三路 DC-DC 之间保持 5mm 以上间距，电感之间尽量**错开轴向**，减少磁耦合；
- 电源区与 HDMI/DDR3 区之间，用**一整片地铜 + 缝合过孔**隔开；
- 输入端加 π 型滤波（磁珠 + 电容）抑制传导 EMI。

### ⚠️ 常见误区

- **Cin 放在芯片另一侧或背面绕一圈**：热回路面积暴增，SW 振铃严重。
- **SW 铺成一大片"散热铜"**：变成辐射天线，EMC 测试直接超标。
- **FB 从电感前面取样**：调压不准，负载调整率差。
- **FB 走线贴着 SW 平行走**：容抗耦合导致输出抖动、啸叫。
- **电感紧贴晶振或 HDMI**：漏磁干扰敏感电路。
- **地用细线连**：DC-DC 的 GND 必须是**大面积铜 + 多过孔**。

### 📌 要点速记

1. 摆放顺序：Cin → IC → L → Cout → FB；**Cin 优先级最高**。
2. 热回路（Cin-上管-下管-GND）面积目标 <5mm²。
3. SW 节点"够用即最小"，绝不为散热铺大片。
4. FB 细线、从 Cout 取样、远离 SW 与电感。
5. 芯片散热焊盘打 4~9 个过孔导热；电源区与敏感区物理隔离。

五个模块布局完毕。下一讲从"平面视角"跳到"立体视角"，用 **3D 检查**验证布局的可制造性与可装配性。

## 第14讲：第九讲：布局查看调整排针3D模型

### 📖 这一集讲什么

平面图看着没问题的布局，切到 3D 常常"惨不忍睹"：排针撞到外壳、电解电容超高、螺丝柱压到器件、TF 卡挡住 HDMI……这一讲讲**3D 校验**。

排针（2.54mm 排针）在开发板上是主角之一，它有几个特点：
- 是**插件（THT）**器件，占用所有层（通孔穿透 6 层）；
- 有**高度**（塑胶座 2.5mm + 针长 6/11mm）；
- 有**方向**（直插 / 弯针 90°）；
- 需要**手插空间**，周边不能太挤。

### 🔬 深入原理

**通孔器件对多层板的"破坏性"**：一个 2.54mm 排针的通孔，孔径通常 1.0mm，焊盘 1.6~1.8mm。它会在 **L2/L3/L4/L5 每一层都挖一个洞**（反焊盘 anti-pad 更大，约 2.0mm）。一排 40Pin 排针就是一道**长约 100mm 的"平面栅栏"**，会严重破坏参考平面完整性。

所以布局时排针的位置要考虑：
- 尽量沿板边成排布置，让"栅栏"落在板边缘而不是穿过高速区；
- 高速信号绝不能横穿排针阵列的下方（回流路径被切断）；
- 若必须穿过，改走**没有被穿孔破坏的那一层**，并在旁边补地过孔。

**3D 检查要看什么：**

| 检查项 | 判据 |
|---|---|
| 器件高度 | 是否超过外壳限高区 |
| 器件干涉 | 相邻器件本体是否重叠 |
| 排针可插性 | 周边 2mm 内无高器件 |
| 螺柱/铜柱 | 定位孔周围是否有器件被压 |
| 接口对齐 | HDMI/TF/USB 的开口是否与外壳一致 |
| 背面器件 | 背面高度是否超过底壳间隙 |

### 🛠 设计实例/操作

**例1：为排针补 3D 模型。** 若库里的排针没有 3D 模型，3D 视图看不到高度，很容易漏检。做法是给封装挂上 STEP 模型（或用 EDA 内置的简易 3D 体，设置高度）。2.54mm 单排针常见参数：塑胶体 2.54mm 宽 × 2.5mm 高，针总长 11mm（上 6mm / 下 3mm）。

**例2：排针的丝印与防呆。**
```
 ┌─────────────────────────────┐
 │ ▣ ○ ○ ○ ○ ○ ○ ○ ○ ○  J1     │  ▣ = 1脚方形焊盘 (防呆)
 └─────────────────────────────┘
   ↑ 1 脚丝印三角/数字标识
   ↑ 每 5 脚加一个刻度点，方便数脚
```
- 1 脚必须做成**方形焊盘**并有丝印标识；
- 排针旁标注信号名（如 `IO0 IO1 ... 3V3 GND`），这是开发板的核心易用性；
- 丝印不能压在焊盘上（DRC 会报"丝印开窗"）。

### ⚠️ 常见误区

- **只看 2D 就下单**：结果器件装不进外壳。
- **排针下方走高速线**：反焊盘切断参考平面，信号完整性崩坏。
- **排针孔径按针径画**：2.54mm 排针针为 0.64mm 方针，孔径应取 **0.9~1.0mm**，太小插不进。
- **忘记背面高度**：背面贴了 10µF 钽电容（1.9mm 高），底壳只有 1.5mm 间隙。
- **丝印覆盖焊盘**：影响焊接与外观。

### 📌 要点速记

1. 布局完成必须过一遍 3D，检查高度、干涉、可插拔、外壳对齐。
2. 通孔排针会在所有内层挖反焊盘，形成"平面栅栏"，高速线绕开。
3. 2.54mm 排针孔径取 0.9~1.0mm，1 脚用方形焊盘 + 丝印防呆。
4. 排针旁必须有清晰的信号名丝印，这是开发板的可用性关键。
5. 3D 检查要连**背面器件高度**一起看。

### 🔗 承上启下

布局阶段到此完成。从下一讲开始进入**叠层与阻抗**——这是 6 层高速板真正的分水岭。

## 第15讲：第十讲：PCB 的层数分析以及叠层设置

### 📖 这一集讲什么

这一讲回答两个问题：**为什么是 6 层？6 层怎么排？**

层数不是拍脑袋定的，而是三个因素倒推的结果：

```
① BGA 出线需求 -> 需要几层信号层
② 参考平面需求 -> 需要几个完整 GND / PWR 平面
③ 成本         -> 层数每增 2 层, 成本上升明显
```

**BGA 出线层数估算**：对于 pitch $p$、$N\times N$ 阵列的 BGA，外圈可以从表层直接引出 2~3 圈，剩下的必须靠过孔到内层。经验公式：所需信号层数 ≈ ⌈(总信号球数) / (每层可出线数)⌉。0.8mm pitch 的 BGA，内层每个"过孔通道"能穿 1 根线，实际项目中 FPGA + DDR3 通常需要 **3~4 个可用信号层**。

### 🔬 深入原理

**6 层板的典型叠层方案对比：**

| 方案 | L1 | L2 | L3 | L4 | L5 | L6 | 评价 |
|---|---|---|---|---|---|---|---|
| **A（推荐）** | S | GND | S | PWR | GND | S | 3 信号层，L3 有 GND 参考，L6 有 GND 参考；**平衡最好** |
| B | S | GND | S | S | GND | S | 4 信号层，无完整电源平面，电源靠铺铜；走线多时用 |
| C | S | GND | PWR | GND | GND | S | 只有 2 信号层，SI 最好但走线能力弱 |
| D（不推荐） | S | S | GND | PWR | S | S | L1/L2 相邻信号层串扰大，参考不完整 |

**本项目推荐方案 A：**

```
 ┌──────────────────────────────────────────────┐
 │ L1  TOP     信号 (1oz)   ← 表层器件/短线/HDMI  │
 │        ── PP ~0.1mm ──                        │
 │ L2  GND     完整地平面 (0.5oz)  ★关键参考面    │
 │        ── Core 0.2mm ──                       │
 │ L3  IN3     信号 (0.5oz)  ← DDR3 主力布线层    │
 │        ── PP  ~0.7mm ──   (厚介质, 隔离)       │
 │ L4  PWR     电源平面 (0.5oz)                   │
 │        ── Core 0.2mm ──                       │
 │ L5  GND     完整地平面 (0.5oz)  ★关键参考面    │
 │        ── PP ~0.1mm ──                        │
 │ L6  BOTTOM  信号 (1oz)   ← 背面器件/去耦/短线  │
 └──────────────────────────────────────────────┘
                 总厚 1.6mm
```
> 注：具体介质厚度以板厂（如嘉立创）公布的**标准叠层表**为准，阻抗计算必须用实际叠层数据。

**为什么这样排？**
1. **L1/L6 紧邻 GND（L2/L5）**：表层信号有最近的完整参考面，回流路径最短；
2. **L3 夹在 GND(L2) 和 PWR(L4) 之间**：形成带状线，屏蔽好、辐射低，适合走 DDR3；
3. **L4/L5 相邻且介质薄（0.2mm core）**：形成**平面电容**，改善超高频 PDN；
4. **对称性**：铜分布上下对称，防止压合后板子翘曲（warpage）。

平面电容值：

$$C = \varepsilon_0\varepsilon_r\frac{A}{d}$$

若 $A=50\times50\ \mathrm{mm^2}=2.5\times10^{-3}\ \mathrm{m^2}$，$d=0.2\ \mathrm{mm}$，$\varepsilon_r=4.3$：

$$C=8.854\times10^{-12}\times4.3\times\frac{2.5\times10^{-3}}{2\times10^{-4}}\approx 476\ \mathrm{pF}$$

数百 pF 看似不大，但它**几乎没有 ESL**，在 GHz 频段是唯一有效的去耦。这就是"薄介质电源-地对"的价值。

### 🛠 设计实例/操作

**例1：在 EDA 中设置叠层。** 打开"层管理器/叠层管理器"，设置为 6 层，逐层指定类型（Signal / Plane）、铜厚（外层 1oz、内层 0.5oz）、介质厚度与 $\varepsilon_r$（FR4 约 4.2~4.4，高频段会略降）。设置完成后保存，阻抗计算器才能读到正确参数。

**例2：L4 电源层的分割规划。** L4 不是"一整片 3.3V"，而是要按需分割：

```
 L4 电源层分割示意:
 ┌───────────────────────────────────────┐
 │  3V3 区 (最大)                         │
 │            ┌──────────────┐            │
 │            │ 1V5 (DDR3区) │            │
 │            └──────────────┘            │
 │  ┌────────┐        ┌──────────────┐    │
 │  │ 1V0核心 │        │ 2V5/1V8 辅助 │    │
 │  └────────┘        └──────────────┘    │
 └───────────────────────────────────────┘
 规则: 分割缝隙 ≥20mil; 任何高速信号不得跨越缝隙上方
```

### ⚠️ 常见误区

- **把 L3 也做成电源层**：信号层不够，DDR3 走不完。
- **L2 地平面被大量走线切碎**：这是 6 层板最常见的自毁行为，L2 必须**保持完整**，尽量不走线。
- **叠层不对称**：上下铜量差异大，压合后板翘，SMT 贴片失败。
- **不按板厂实际叠层算阻抗**：自己假设 0.2mm 介质，板厂实际 0.1mm，阻抗差 20% 以上。
- **忘记设置内层铜厚为 0.5oz**：阻抗计算偏差。

### 📌 要点速记

1. 6 层推荐叠层：**S / GND / S / PWR / GND / S**，3 信号层 + 2 完整地平面。
2. L2、L5 是关键参考面，必须完整，不许随意走线切割。
3. L4/L5 薄介质构成平面电容，$C=\varepsilon_0\varepsilon_r A/d$，负责 GHz 去耦。
4. 叠层要上下对称，防止翘板。
5. 阻抗计算必须使用**板厂公布的实际叠层参数**。

### 🔗 承上启下

叠层定了，介质厚度、铜厚、$\varepsilon_r$ 都有了。下一讲讲清楚**阻抗到底是什么**，为下一步计算做准备。

## 第16讲：第十一讲：了解阻抗

### 📖 这一集讲什么

这一讲讲**特性阻抗（Characteristic Impedance）**。很多人以为阻抗是"电阻"，其实完全不是。

**通俗理解**：想象你在一条很长的走廊里推一个球。走廊的"宽窄"决定了你推球时手上感受到的"费劲程度"。这个"费劲程度"就是特性阻抗——它是**信号在传播过程中，电压与电流的比值**，与走线长度**无关**，只与横截面几何和材料有关。

$$Z_0=\frac{V}{I}=\sqrt{\frac{L}{C}}$$

其中 $L$、$C$ 是单位长度的电感和电容。

### 🔬 深入原理

**1）阻抗由什么决定？** 四个因素：

| 因素 | 符号 | 变大时 $Z_0$ |
|---|---|---|
| 线宽 | $W$ | ↓ 减小（C 变大） |
| 介质厚度（到参考面） | $H$ | ↑ 增大 |
| 铜厚 | $T$ | ↓ 略减小 |
| 介电常数 | $\varepsilon_r$ | ↓ 减小 |

一句话记忆：**线越宽、离地越近、材料介电常数越大 → 阻抗越低。**

**2）为什么要"控阻抗"？** 因为阻抗不连续会产生**反射**。反射系数：

$$\Gamma=\frac{Z_L-Z_0}{Z_L+Z_0}$$

例：$Z_0=50\Omega$ 的线接到 $Z_L=75\Omega$ 的段，$\Gamma=(75-50)/(75+50)=0.2$，即 20% 的能量被反射回去，叠加在原信号上形成过冲/振铃，严重时导致误判。

**3）常见阻抗模型：**

```
(a) 表层微带线 Microstrip          (b) 内层带状线 Stripline
     ────W────                          ═══════ GND (L2)
   ▬▬▬▬▬▬▬▬  信号(L1)                      ─W─
   ─────────────── ε_r, H              ▬▬▬▬▬▬  信号(L3)
   ═══════════════ GND(L2)             ─────────── ε_r
                                       ═══════ PWR/GND (L4)

(c) 差分微带 (对内间距 S)           (d) 共面波导 CPWG (两侧有地)
   ▬▬  S  ▬▬                        ▓▓  g ▬W▬ g  ▓▓
   ══════════ GND                    ═══════════════ GND
```

**4）近似公式（IPC-2141，工程估算用）：**

微带线：
$$Z_0=\frac{87}{\sqrt{\varepsilon_r+1.41}}\ \ln\!\left(\frac{5.98H}{0.8W+T}\right)$$

带状线：
$$Z_0=\frac{60}{\sqrt{\varepsilon_r}}\ \ln\!\left(\frac{4H}{0.67\pi\,(0.8W+T)}\right)$$

差分（近似修正）：
$$Z_{diff}\approx 2Z_0\left(1-0.48\,e^{-0.96\,S/H}\right)\quad(\text{微带})$$
$$Z_{diff}\approx 2Z_0\left(1-0.347\,e^{-2.9\,S/H}\right)\quad(\text{带状})$$

**5）传播延时：**
$$t_{pd,\ \text{微带}}=85\sqrt{0.475\varepsilon_r+0.67}\ \ \mathrm{ps/inch}$$
$$t_{pd,\ \text{带状}}=85\sqrt{\varepsilon_r}\ \ \mathrm{ps/inch}$$

取 $\varepsilon_r=4.3$：微带 ≈ 140 ps/inch ≈ **5.5 ps/mm**；带状 ≈ 176 ps/inch ≈ **7.0 ps/mm**。

**这个差异极其重要**：同样 100mm 长度，走内层比走外层多约 150ps 延时。**所以等长绕线不能跨层混走**——同一组等长信号应尽量在同一类层上走完。

### 🛠 设计实例/操作

**例1：手算一次微带线。** 设 $H=0.1\ \mathrm{mm}=3.94\ \mathrm{mil}$，$T=1.4\ \mathrm{mil}$（1oz 完成铜），$\varepsilon_r=4.2$，求 50Ω 线宽：

$$\frac{87}{\sqrt{4.2+1.41}}=\frac{87}{2.368}=36.7$$
$$\ln\!\left(\frac{5.98\times3.94}{0.8W+1.4}\right)=\frac{50}{36.7}=1.362$$
$$\frac{23.6}{0.8W+1.4}=e^{1.362}=3.90 \Rightarrow 0.8W+1.4=6.05 \Rightarrow W\approx 5.8\ \mathrm{mil}$$

考虑阻焊层的影响（会使阻抗降低约 1~3Ω），实际取 **5.5~6 mil** 左右。**注意：这只是估算，最终以板厂阻抗计算器为准。**

**例2：判断哪些线需要控阻抗。**

| 信号 | 是否控阻抗 | 目标 |
|---|---|---|
| HDMI TMDS | 是 | 100Ω 差分 |
| DDR3 DQ/A/CMD | 是 | 50Ω 单端 |
| DDR3 DQS/CK | 是 | 100Ω 差分 |
| USB D+/D- | 是 | 90Ω 差分 |
| 以太网 MDI | 是 | 100Ω 差分 |
| I²C / 按键 / LED | 否 | 常规线宽即可 |
| 电源 | 否 | 按载流 |

### ⚠️ 常见误区

- **以为阻抗和走线长度有关**：无关，只与横截面几何和材料有关。
- **换层不换线宽**：外层 50Ω 需要 ~6mil，内层 50Ω 只需 ~4.5mil，换层必须改宽度。
- **用别人板子的线宽**：叠层不同，线宽完全不同。
- **忽略参考面**：阻抗是"信号线 + 参考面"共同定义的；参考面断了，阻抗就无从谈起。
- **差分对间距随便改**：$S$ 变化直接改变 $Z_{diff}$。

### 📌 要点速记

1. $Z_0=\sqrt{L/C}$，与长度无关，只取决于 $W$、$H$、$T$、$\varepsilon_r$。
2. 线宽↑阻抗↓；介质厚度↑阻抗↑。
3. 反射系数 $\Gamma=(Z_L-Z_0)/(Z_L+Z_0)$，阻抗不连续就有反射。
4. 微带 ≈5.5ps/mm，带状 ≈7.0ps/mm，**等长不能跨层类型混走**。
5. 换层必须换线宽，否则阻抗跳变。

### 🔗 承上启下

原理懂了。下一讲实操：**用工具算出本项目的具体线宽，并把常用规则加进 EDA**。

## 第17讲：第十二讲：计算阻抗以及常用规则添加

### 📖 这一集讲什么

这一讲干两件事：

1. **用阻抗计算器算出本项目每一层的 50Ω / 100Ω 线宽**；
2. **把这些结果连同线宽、间距、过孔规则，配置进 EDA 的规则管理器**。

阻抗计算工具有三类：板厂自带计算器（嘉立创 EDA 内置/官网叠层页面，**最推荐**，因为它用的就是它自己的实际叠层）、Polar SI9000（行业标准）、Saturn PCB Toolkit（免费）。

### 🔬 深入原理

**计算阻抗需要输入的参数清单：**

```
层类型      : 微带(外层) / 带状(内层, 对称或非对称)
介质厚度 H1 : 信号层到上参考面
介质厚度 H2 : 信号层到下参考面 (带状线需要)
介电常数 εr : FR4 ≈ 4.2~4.4 (随频率下降, 高速可取 4.1~4.2)
损耗角 tanδ : 普通 FR4 ≈ 0.02
铜厚 T      : 外层 1oz(含电镀约 1.4~1.7mil), 内层 0.5oz(0.65mil)
阻焊层      : 厚度约 0.4~0.8mil, εr ≈ 3.5~4
```

### ⚠️ 常见误区

- **算完阻抗不锁进规则**：布线时手滑改宽度，阻抗全废。
- **只算外层不算内层**：DDR3 主力在 L3，内层线宽不同。
- **忽略阻焊影响**：外层微带加阻焊后阻抗约降 1~3Ω，计算器要勾选。
- **间距设得过小**：4mil 以下会加价，且良率下降；能用 5mil 就别用 3.5mil。
- **铺铜离信号线太近**：会改变实际阻抗（尤其外层），铺铜间距建议 8~10mil。

### 📌 要点速记

1. 用板厂计算器 + 板厂实际叠层算阻抗，别用假设值。
2. 内层 50Ω 线宽比外层窄（约 4~5mil vs 5.5~7mil）。
3. 规则要覆盖：线宽、间距、过孔、阻焊、铺铜、丝印、孔到孔、板边。
4. 先建网络类（用通配符），再把规则挂到类上。
5. 常规过孔 0.2/0.4mm，电源过孔 0.3/0.5mm。

## 第18讲：第十三讲：电源网络类的添加以及规则设置

### 📖 这一集讲什么

电源网络不控阻抗，它控的是**载流、压降、温升**。这一讲把所有电源网络归类，并给每一类设置合适的线宽和过孔规则。

**电源网络清单（本项目示例）：**

| 网络 | 电压 | 估算电流 | 建议最小线宽（外层1oz） | 备注 |
|---|---|---|---|---|
| `VIN_5V` | 5V | 3A | 铺铜 / ≥60 mil | 输入总电流 |
| `3V3` | 3.3V | 1.5A | ≥30 mil / 铺铜 | 大面积 |
| `1V5` | 1.5V | 1.2A | 铺铜块（L4 分割区） | DDR3 |
| `1V0` (VCCINT) | 1.0V | 2A | 铺铜块 | 压降最敏感 |
| `2V5/1V8` | - | 0.3A | ≥15 mil | 辅助 |
| `0V75` (VREF) | 0.75V | mA 级 | ≥10 mil | 精度优先 |
| `GND` | - | - | 平面 | L2/L5 |

### 🔬 深入原理

**压降（IR Drop）计算。** 铜的方块电阻：

$$R_{\square}=\frac{\rho}{t}$$

铜 $\rho=1.72\times10^{-8}\ \Omega\!\cdot\!\mathrm{m}$，1oz 铜 $t=35\ \mu\mathrm{m}$：

$$R_{\square}=\frac{1.72\times10^{-8}}{35\times10^{-6}}\approx 0.49\ \mathrm{m}\Omega/\square$$

一条长 $L$、宽 $W$ 的走线电阻 $R=R_{\square}\cdot(L/W)$。

**实例**：1V0 电源，走线长 30mm、宽 1mm（1oz），方块数 = 30/1 = 30，$R=30\times0.49=14.7\ \mathrm{m}\Omega$。通 2A 时压降：

$$\Delta V = 2\times14.7\ \mathrm{m}\Omega = 29.4\ \mathrm{mV}$$

对 1.0V 核心电压是 2.9%，接近典型 ±3% 容限。**这说明低压大电流电源必须用铺铜/平面，不能用走线。**

**过孔载流。** 单个 0.3mm 孔（镀铜 20µm）的等效导电截面约 $\pi\times0.3\times0.02 \approx 0.0188\ \mathrm{mm^2}$，工程速记 **约 1A/孔（温升 10℃）**。所以：
- 2A 的 1V0 换层：≥4 个 0.3mm 过孔；
- 3A 的 5V 输入换层：≥6 个。

### 🛠 设计实例/操作

**例1：建立电源网络类与规则**

```
Class: PWR_HIGH_CURRENT  -> VIN_5V, 3V3, 1V0, 1V5
   线宽规则: min 20 / pref 40 / max 200 mil
   过孔规则: 0.3mm/0.5mm
   间距规则: 与其他网络 ≥8 mil (高压/大电流留余量)

Class: PWR_LOW_CURRENT   -> 2V5, 1V8, VCCAUX
   线宽规则: min 10 / pref 15 / max 40 mil

Class: PWR_SENSITIVE     -> 0V75(VREF), VCCPLL
   线宽规则: min 10 / pref 12 mil
   额外: 手动保证远离 SW / 高速线, 两侧包地
```

**例2：电源"星型 vs 平面"策略。**

```
低电流(<300mA)  -> 走线即可, 星型分配
中电流(0.3~1A)  -> 表层铺铜块 + 过孔到 L4
大电流(>1A)     -> L4 平面分区 + 密集过孔阵列
                   ┌────────────┐
                   │  1V0 平面区 │  ← L4
                   └─────┬──────┘
                    ●●●●●●●●  ← 过孔阵列到 BGA 电源球
```

### ⚠️ 常见误区

- **电源用默认信号线宽（5mil）连**：发热、压降大，FPGA 配置失败或不稳定。
- **过孔只打 1 个**：过孔成为瓶颈，局部过热甚至烧断。
- **VREF 当普通电源处理**：VREF 要求的是**精度和干净**，不是电流。
- **电源分割缝隙太窄**：L4 上不同电压区之间缝隙应 ≥20mil，避免爬电/耦合。
- **忘记给 GND 单独设规则**：GND 应设为平面 + 允许大量过孔连接。

### 📌 要点速记

1. 电源规则的核心是载流与压降，不是阻抗。
2. 1oz 铜方块电阻 ≈ 0.49 mΩ/□，用它算 IR Drop。
3. 0.3mm 过孔 ≈ 1A，按电流配过孔数量并留 2 倍裕量。
4. 大电流电源用**平面/铺铜块**，不用走线。
5. VREF 等敏感小电源单独归类，线宽 ≥10mil 且远离噪声源。

单端与电源规则齐了。下一讲补上最后一块规则拼图——**差分对规则**。

## 第19讲：第十四讲：差分规则的添加

### 📖 这一集讲什么

差分对（Differential Pair）是高速设计的主力形式。这一讲讲**怎么在 EDA 里建立差分对、设置差分规则，以及差分布线的物理要求**。

本项目的差分对清单：

| 差分对 | 数量 | 阻抗 | 对内容差 | 备注 |
|---|---|---|---|---|
| HDMI TMDS Data0/1/2 | 3 | 100Ω | ≤5 mil | 最高速 |
| HDMI TMDS Clock | 1 | 100Ω | ≤5 mil | 与数据对间 ≤50mil |
| DDR3 DQS0/DQS1 | 2 | 100Ω | ≤5 mil | 与本 lane DQ 等长 |
| DDR3 CK | 1 | 100Ω | ≤5 mil | 全板最长基准 |
| USB D+/D- | 1 | 90Ω | ≤5 mil | 全速/高速 |

### 🔬 深入原理

**差分信号为什么抗干扰？** 两根线载相反极性信号，接收端取差值 $V_{diff}=V_P-V_N$。外界干扰同时耦合到两根线上（共模），相减后被抵消。这个抵消能力叫**共模抑制比（CMRR）**，前提是两根线**完全对称**：等长、等宽、同层、同环境。

**对内不等长的后果：偏斜（Skew）转共模。** 若两线长度差 $\Delta L$，产生时间偏斜：

$$\Delta t = \Delta L \times t_{pd}$$

内层 $t_{pd}=7\ \mathrm{ps/mm}$，$\Delta L=5\ \mathrm{mil}=0.127\ \mathrm{mm}$：

$$\Delta t = 0.127\times 7 = 0.89\ \mathrm{ps}$$

对 3.4Gbps（UI ≈ 294ps）而言只占 0.3%，可接受。但如果 $\Delta L=50\ \mathrm{mil}$，$\Delta t\approx 8.9\ \mathrm{ps}$，占 3%，眼图明显劣化。**这就是"对内 5mil"这个数字的来历。**

**紧耦合 vs 松耦合：**

| | 紧耦合 $S<2W$ | 松耦合 $S\ge 2W$ |
|---|---|---|
| 抗串扰 | 更好（场约束在对内） | 稍弱 |
| 阻抗敏感度 | 对 $S$ 变化敏感 | 对 $S$ 变化不敏感 |
| 占用空间 | 小 | 大 |
| 适用 | 空间紧张、内层 | HDMI 等要求容错 |

HDMI 常用**松耦合**（$S\approx 2W$），因为过 BGA/连接器时间距难免变化，松耦合更容错。

**差分对间的隔离**：不同差分对之间的间距应 ≥ **5W**（或至少 3 倍对内间距），防止对间串扰。

### 🛠 设计实例/操作

**例1：在 EDA 中创建差分对。**
```
方式一（推荐）: 原理图中网络命名为 XXX_P / XXX_N (或 +/-)
                EDA "从网络自动创建差分对" 一键生成
方式二: 差分对管理器中手动配对
生成后设置差分规则:
   ├ 线宽 W        : 按第17讲阻抗计算结果 (外层5mil/内层4mil)
   ├ 对内间距 S    : 按计算结果 (外层7mil/内层6mil)
   ├ 目标阻抗      : 100Ω (USB为90Ω)
   ├ 对内长度容差  : 5 mil
   └ 与其他网络间距: ≥ 3W~5W
```

**例2：差分布线的六条物理铁律**

```
1. 同层走完      : 不要一根在L1一根在L3
2. 换层成对换    : 两个过孔对称放置, 旁边加 2 个 GND 过孔
3. 对称绕线      : 补偿长度差要"就近补偿", 在偏差产生处立即补
4. 不跨分割      : 参考面必须连续
5. 转角用 45°或圆弧: 不用 90°
6. 对内不加器件差异: 要串阻/电容必须两根都加, 且对称摆放
```

**就近补偿 ASCII 示意：**
```
   差错发生处立即补偿(好)            拖到最后才补(差)
   ═══╮  ╭════════════          ═══╮  ╭══════════════
   ═╮ ╰──╯ ╭══════════          ═╮ ╰──╯              ╭═╮╭═╮╭═
     ╰─────╯                      ╰──────────────────╯ ╰╯ ╰╯
   共模转换小                      中间段一直存在共模
```

### ⚠️ 常见误区

- **对内补偿放在末端**：中间一大段处于偏斜状态，共模噪声已经产生。
- **两个过孔不对称**：换层处引入偏斜和阻抗突变。
- **只给一根线串电阻**：完全破坏对称性。
- **差分对之间贴太近**：对间串扰，HDMI 花屏。
- **90° 直角走线**：转角处阻抗下降（拐角电容），高速下产生反射。
- **对内间距时紧时松**：阻抗波动，用松耦合可缓解但仍要尽量均匀。

### 📌 要点速记

1. 差分靠**对称性**抗干扰，等长、等宽、同层、同环境缺一不可。
2. 对内容差 ≤5mil（≈0.9ps），对间容差 HDMI 建议 ≤50mil。
3. 对间隔离 ≥5W；HDMI 推荐松耦合（$S\approx2W$）以提高容错。
4. 换层必须成对且对称，并在旁加 GND 回流过孔。
5. 长度补偿要**就近**，不要拖到末端统一补。

## 第20讲：第十五讲：BGA扇孔以及BGA滤波电容摆放

### 📖 这一集讲什么

**扇孔（Fanout）= 把 BGA 焊球通过短走线 + 过孔引到内层，形成"狗骨（Dog-bone）"结构**，为后续布线做准备。这是 BGA 板最枯燥也最关键的体力活。

```
   Dog-bone 结构俯视:
     ○───▬▬▬───◎
    焊球  短线   过孔
   (0.4mm) (~0.25mm) (0.2/0.4mm)
```

### 🔬 深入原理

**1）过孔尺寸与通道计算。** 0.8mm pitch BGA，相邻焊球中心距 0.8mm = 31.5mil。若过孔焊盘 0.4mm（15.75mil），相邻两过孔之间的净空：

$$31.5 - 15.75 = 15.75\ \mathrm{mil}$$

再减去两侧的线到盘间距（各 4mil）：

$$15.75 - 8 = 7.75\ \mathrm{mil}$$

也就是说**这个通道能穿 1 根 ≤7mil 的线**（实际取 4~5mil 更保险）。对角方向净空更大（$0.8\sqrt2=1.13\ \mathrm{mm}$），可以穿 1~2 根。

**结论：0.8mm pitch，每个内层信号层，BGA 每"圈"能出 1 根线。** 这直接决定了需要几个信号层。

**2）扇孔方向策略：**

```
        ↖ ↑ ↑ ↑ ↗           外圈 1~2 圈: 表层直接引出(不打孔)
      ← ○ ○ ○ ○ ○ →         第 3 圈起  : 向外斜 45° 打孔
      ← ○ ⊕ ⊕ ⊕ ○ →         中心区    : 电源/地球, 就近打孔到平面
      ← ○ ⊕ ⊕ ⊕ ○ →
      ← ○ ○ ○ ○ ○ →
        ↙ ↓ ↓ ↓ ↘
```

- **信号球**：向 BGA 外侧扇出，保持一致方向，形成整齐的"通道"；
- **GND 球**：**就近打孔，走线越短越好**（回流路径电感最小）；
- **电源球**：就近打孔到 L4，多个球可共用相邻过孔区域，但要保证足够过孔数量。

**3）为什么 GND 过孔要"就近且多"？** 因为每个信号换层时，其回流电流需要通过附近的 GND 过孔从一个参考面跳到另一个参考面。回流过孔缺失会造成回路面积暴增：

$$L_{loop} \propto \text{回路面积}$$

工程规则：**每 1~3 个信号过孔，旁边配 1 个 GND 过孔**，间距 <1mm 最佳。

### 🛠 设计实例/操作

**例1：扇孔的标准操作流程**
```
① 设置过孔默认尺寸 0.2/0.4mm，栅格设为 0.1mm 或更细
② 从 BGA 最外圈开始，先做电源/地球（数量最多、最简单）
③ 再做信号球，按 45° 斜向外扇出，短线 + 过孔
④ 每完成一圈，检查 DRC（孔到孔间距 ≥0.2mm）
⑤ 使用"阵列复制"或"扇出向导"批量处理重复图形
```

**例2：BGA 去耦电容摆放（本讲另一半重点）**

```
  正面 TOP:            背面 BOTTOM:
  ○ ○ ○ ○ ○           
  ○ ⊕ G ⊕ ○     -->    ┌──┐   0402 电容, 正对 ⊕/G 之间
  ○ G ⊕ G ○            │C │   两端焊盘紧贴过孔(<0.3mm)
  ○ ○ ○ ○ ○           └──┘

  好的连接:  Cpad──via   (走线≈0, 电感最小)
  差的连接:  Cpad──▬▬▬▬──via  (多 1nH, 高频失效)
```

去耦电容回路电感估算：

$$L_{total}=L_{via1}+L_{trace}+L_{ESL}+L_{via2}$$

典型值：过孔 0.3~0.5nH/个（1.6mm 板厚全通孔约 1~1.2nH），0402 电容 ESL 约 0.5~0.8nH，1mm 细走线约 0.5nH。目标是把 $L_{total}$ 控制在 **1.5nH 以内**。

有效去耦上限频率：
$$f_{max}\approx\frac{1}{2\pi\sqrt{L_{total}C}}$$
$C=100\ \mathrm{nF}$，$L_{total}=1.5\ \mathrm{nH}$ 时，$f_{max}\approx 13\ \mathrm{MHz}$（自谐振点），再往上靠平面电容。

### ⚠️ 常见误区

- **扇孔方向乱**：有的向外有的向内，通道全被堵死，后面无法布线。
- **过孔打在焊盘正中（非 via-in-pad 工艺）**：焊接时锡从孔漏走，虚焊。除非明确使用**塞孔/树脂塞孔+电镀填平**工艺。
- **GND 球扇孔拉长线共用一个孔**：回流电感大，串扰噪声上升。
- **去耦电容和过孔之间拉长走线**：等于没放电容。
- **忘记 DRC 孔到孔间距**：0.8mm pitch 下 0.4mm 焊盘间只剩 0.4mm，孔壁间距要 ≥0.2mm。

### 📌 要点速记

1. 0.8mm pitch + 0.2/0.4mm 过孔 → 每圈每层可穿 1 根 4~5mil 线。
2. 外圈表层直接出，内圈 45° 斜向外扇出，电源/地就近打孔。
3. 每 1~3 个信号过孔配 1 个 GND 回流过孔。
4. 去耦电容放**背面正对电源球**，焊盘到过孔走线趋近 0。
5. 目标去耦回路电感 <1.5nH。

### 🔗 承上启下

扇孔方法论讲完，接下来的第 16~20 讲逐个模块实操。先从最难的 **DDR3 扇孔** 开始。

## 第21讲：第十六讲：DDR3模块扇孔

### 📖 这一集讲什么

DDR3 模块扇孔的特殊之处在于：**它不仅要"出得来"，还要"出得整齐"**——因为后面要做严格等长，扇孔的对称性直接决定等长的难度。

DDR3（x16，通常 BGA96，0.8mm pitch）的引脚分区：

```
   ┌───────────────────────────────┐
   │ DQ0-7 区 │ Addr/CMD 区 │DQ8-15区│
   │  DQS0    │   CK/CKE    │  DQS1  │
   │  DQM0    │  CS/RAS/CAS │  DQM1  │
   │          │   VREF      │        │
   └───────────────────────────────┘
     ← 电源球 VDD/VDDQ 分布在整个区域 →
```

### 🔬 深入原理

**扇孔对等长的影响。** 假设 DQ0 扇孔用了 0.3mm 引线 + 过孔，DQ1 用了 0.8mm 引线，两者从起点就差了 0.5mm ≈ 20mil。一个 byte lane 有 8 根 DQ + DQS + DQM，如果扇孔长度参差不齐，等长时要额外补偿几十 mil，绕线量翻倍。

**所以铁律是：同一组信号的扇孔要"形状一致"。** 做法：
- 用相同的引出角度（45°）；
- 用相同的引线长度；
- 过孔落在同一栅格上；
- 尽量用**复制粘贴**而不是逐个手画。

**换层策略。** DDR3 数据线主要走 **L3（带状线，参考 L2/L4）**，因为：
- L3 上下都有参考面，屏蔽好；
- 表层要留给去耦电容和短线；
- L6 背面也有器件，且靠近外壳。

因此扇孔目标层就是 L3。从 BGA 球（L1）打孔到 L3，过孔的**残桩（stub）** 是 L3→L6 那一段（约 1.0mm）。1.6mm 板厚、DDR3-800 速率下，这段 stub 的影响可接受（stub 谐振频率远高于关注频段）：

$$f_{res}\approx\frac{c}{4\,L_{stub}\sqrt{\varepsilon_r}}=\frac{3\times10^{11}\ \mathrm{mm/s}}{4\times1.0\times\sqrt{4.3}}\approx 36\ \mathrm{GHz}$$

远高于 DDR3 的关注频段（<2GHz），所以**本项目无需背钻**。

### 🛠 设计实例/操作

**例1：DDR3 扇孔布置图**

```
   DDR3 BGA 底视 (示意, ● 信号球, ⊕ 电源, G 地)
   
   外侧(朝向FPGA)
   ↑ ↑ ↑ ↑ ↑ ↑ ↑ ↑    <- DQ 球全部朝 FPGA 方向 45° 扇出
   ● ● ● ● ● ● ● ●
   G ⊕ G ⊕ G ⊕ G ⊕    <- 电源地就近打孔(几乎垂直向下)
   ● ● ● ● ● ● ● ●
   ↓ ↓ ↓ ↓ ↓ ↓ ↓ ↓    <- 背侧球向背侧扇出, 再绕过来
   
   关键: 朝 FPGA 一侧的球优先, 尽量不绕
```

**例2：VREF 与去耦的扇孔。**
- VREF 球单独打孔，走线宽度 ≥10mil，**不与 DQ 过孔混在一起**；
- 每个 VDDQ 球就近打孔到 L4 的 1V5 分区；
- 背面 100nF 电容正对 VDDQ 球，两端各 1 个过孔（1 个到 L4，1 个到 L2/L5 地）。

**例3：给等长预留"梳子"通道。**
```
  DDR3 扇孔完成后, 从过孔出来的线应该像梳齿一样整齐:
  
   │ │ │ │ │ │ │ │      <- 8 根 DQ, 间距均匀(≥3W)
   │ │ │ │ │ │ │ │
   └─┴─┴─┴─┴─┴─┴─┘  → 向 FPGA 方向
   
  这样后面做蛇形等长时，每根线两侧都有空间
```

### ⚠️ 常见误区

- **扇孔长度参差不齐**：等长阶段付出双倍代价。
- **DQ 与 Addr 的过孔混排**：两组信号交织，后面布线互相挡路。
- **电源过孔占用了信号通道**：应先规划信号通道，电源孔放在通道之间。
- **VREF 混在 DQ 中间**：容易被 DQ 串扰。
- **扇孔后不检查 DRC**：孔间距违规到最后才发现，返工量大。

### 📌 要点速记

1. DDR3 扇孔追求"整齐一致"，为后续等长省力。
2. 数据线主力走 L3（带状线），扇孔目标层就是 L3。
3. 1.6mm 板厚下 stub 谐振约 36GHz，DDR3 无需背钻。
4. 电源/地球就近垂直打孔，信号球统一 45° 朝 FPGA 方向扇出。
5. VREF 独立走线（≥10mil），远离 DQ 过孔群。

### 🔗 承上启下

DDR3 扇孔完成。下一讲处理速率更高但数量少得多的 **HDMI 模块扇孔**。

## 第22讲：第十七讲：HDMI 模块扇孔

### 📖 这一集讲什么

HDMI 侧的"扇孔"其实包含两端：**FPGA 侧 BGA 的 TMDS 引脚扇出** + **HDMI 连接器/TVS 侧的引脚引出**。这一讲讲怎么让 4 对差分从 BGA 出来后一路顺畅到连接器。

核心目标一句话：**让 TMDS 差分对尽可能"少换层、少打孔、走同一层"。**

### 🔬 深入原理

**为什么 HDMI 要少打孔？** 因为每个过孔都是阻抗不连续点。过孔的等效模型是一个 π 型网络（电容-电感-电容），典型全通孔的寄生参数：$L\approx0.5\sim1\ \mathrm{nH}$，$C\approx0.3\sim0.5\ \mathrm{pF}$。其等效阻抗：

$$Z_{via}=\sqrt{\frac{L}{C}}\approx\sqrt{\frac{0.8\times10^{-9}}{0.4\times10^{-12}}}\approx 45\ \Omega$$

单个过孔影响不大，但 HDMI 一对线上下两端各一个过孔就是 4 个不连续点。**能不打就不打。**

**最优方案：TMDS 走表层（L1），全程不换层。**
- 优点：0 过孔，阻抗最连续；
- 条件：FPGA 到 HDMI 连接器之间的表层通道必须畅通（这就是第 9 讲布局时预留"差分通道"的原因）。

**如果必须换层**，则：
1. 两根线的过孔**对称放置**；
2. 每对差分旁边加 **2 个 GND 过孔**（回流路径）；
3. 换层后线宽/间距要按新层的阻抗值调整（外层 5/7mil → 内层 4/6mil）。

**BGA 侧扇出的技巧：** FPGA 的 TMDS 引脚一般在同一 BANK、物理相邻。若这对球在 BGA 外圈，可以**直接从表层引出，不打孔**；若在内圈，则打孔到 L3 走一段再回到 L1，或者干脆整段走 L3。

### 🛠 设计实例/操作

**例1：HDMI 全链路层规划（推荐）**

```
 FPGA BGA(外圈球) ──L1表层──► TVS ──L1表层──► HDMI 连接器
        ↑
   若球在内圈:
 FPGA BGA(内圈球) ─via─► L3 ──带状线──► via ─► L1 ─► TVS ─► 连接器
                    ↑                    ↑
              旁配2个GND过孔        旁配2个GND过孔
```

**例2：TVS 处的阻抗处理。** TVS 阵列（如 SOT-23-6 或 QFN 封装）的焊盘往往比 5mil 走线宽得多，会造成局部阻抗下降。处理方法：
- 在 TVS 焊盘正下方的参考层（L2）**局部挖空（anti-pad）**，减小对地电容，把阻抗拉回来；
- 或者选用小封装、低电容的 TVS；
- 差分对进出 TVS 要保持**对称**，两根线在 TVS 两侧的路径长度一致。

**例3：连接器侧的处理。** HDMI 连接器的引脚间距小（0.5mm 左右），焊盘密集：
- 连接器下方的 L2 保持完整地平面（不要挖空整片，只在必要处局部处理）；
- 连接器的**屏蔽壳（Shell）引脚**要多点接地，用 4 个以上过孔连到 GND 平面；
- HDMI 的 GND 引脚（TMDS 每对之间有一个 GND 屏蔽脚）要**逐个打孔到 GND 平面**，这是 HDMI 抗串扰的关键设计。

### ⚠️ 常见误区

- **TMDS 从 L1 换到 L3 再换回 L1**：4 个过孔，阻抗不连续点太多。
- **换层时不加 GND 回流过孔**：回流被迫绕远路，共模辐射剧增。
- **TVS 焊盘处不做阻抗补偿**：局部阻抗掉到 70~80Ω（差分），产生反射。
- **HDMI 连接器屏蔽壳只接一个点**：屏蔽失效，EMC 不过。
- **忽略 HDMI 的 GND 屏蔽脚**：TMDS 对间串扰增大。

### 📌 要点速记

1. HDMI TMDS 首选**全程走表层不换层**，过孔数量越少越好。
2. 单个过孔等效阻抗约 45Ω，是明显的不连续点。
3. 必须换层时：成对对称 + 旁边 2 个 GND 回流过孔 + 换线宽。
4. TVS/连接器焊盘处可通过参考层局部挖空补偿阻抗。
5. HDMI 屏蔽壳与 GND 屏蔽脚要多点、就近打孔接地。

### 🔗 承上启下

高速差分部分处理完。下一讲处理相对轻松的 **MCU 模块扇孔**。

## 第23讲：第十八讲：MCU 模块扇孔

### 📖 这一集讲什么

MCU 通常是 LQFP 或 QFN 封装，引脚在四周（不是 BGA），所以严格讲不需要"扇孔"，而是**引脚引出与换层规划**。这一讲讲三件事：QFP/QFN 的引出方式、散热焊盘处理、以及低速信号的换层原则。

### 🔬 深入原理

**QFP/QFN 引出方式：**

```
   LQFP48 (0.5mm pitch) 引出:
   
      │ │ │ │ │ │        <- 引脚直接向外引出 (表层)
   ───┴─┴─┴─┴─┴─┴───
   │  ┌───────────┐  │
   ───┤    MCU    ├───
   │  │  ▓▓▓▓▓▓   │  │   <- QFN 散热焊盘
   ───┤  (EPAD)   ├───
   │  └───────────┘  │
   ───┬─┬─┬─┬─┬─┬───
      │ │ │ │ │ │
      
   引出后, 需要换层的信号在离芯片 1~2mm 处打孔
```

**为什么不在焊盘旁边立刻打孔？** 0.5mm pitch 的 QFP，引脚间净空只有约 0.25mm，放不下 0.4mm 的过孔焊盘。所以要先向外引出 1~2mm，等间距拉开后再打孔。

**QFN 散热焊盘（EPAD）处理：**
- EPAD 通常是**电气上的 GND**，必须打孔连到 GND 平面；
- 过孔数量：按面积算，一般 3×3 或 4×4 阵列，孔径 0.3mm，间距 1.0~1.2mm；
- 阻焊开窗：EPAD 要做**分格开窗**（网格状阻焊），防止回流焊时锡量过多导致器件"浮起"（tombstone/floating）；
- 钢网开孔率取 50~80%。

热阻估算：QFN 的 $\theta_{JA}$ 在有散热过孔阵列时可从 50℃/W 降到 30℃/W 以下。功耗 0.3W 的 MCU，温升从 15℃ 降到 9℃。

### 🛠 设计实例/操作

**例1：MCU 信号换层原则。**

| 信号 | 建议层 | 原因 |
|---|---|---|
| 晶振 OSC_IN/OUT | **L1 表层，不换层** | 短、下方 L2 完整地 |
| SWD 调试 | L1 或 L6 | 低速，随意 |
| USB D+/D- | L1 表层成对 | 90Ω 差分，少换层 |
| 一般 GPIO | L1/L6，必要时 L3 | 自由 |
| 与 FPGA 通信线 | L1 或 L3 | 若较长，走 L3 更干净 |

**例2：MCU 电源与地的扇出。**
```
   每个 VDD 引脚:
   VDD pin ──短线(<1mm)── [100nF] ──via── GND(L2)
                │
              via ── 3V3 (L4)
   
   注意: 电容在"引脚与电源过孔之间"，而不是过孔之后
   即 电流路径: L4电源 → via → 电容 → 引脚
```
这样电容才在供电路径上起到就近储能的作用。

**例3：EPAD 过孔阵列。**
```
   ┌─────────────┐
   │ ● ● ●       │   ● = 0.3mm 过孔, 间距 1.0mm
   │ ● ● ●       │   全部连到 GND 平面(L2/L5)
   │ ● ● ●       │   阻焊做网格开窗
   └─────────────┘
```

### ⚠️ 常见误区

- **在 0.5mm pitch 引脚间硬塞过孔**：DRC 报错或制造良率极低。
- **QFN 的 EPAD 不打过孔**：芯片过热、且 GND 参考不良。
- **EPAD 整片开窗不分格**：回流焊器件浮起、偏位。
- **晶振信号换层到内层**：走线变长、增加杂散电容，得不偿失。
- **去耦电容放在电源过孔"之后"**：变成滤波在源端，效果打折。

### 📌 要点速记

1. QFP/QFN 引脚先向外引出 1~2mm 再打孔，避免间距违规。
2. QFN 的 EPAD 必须打过孔阵列（0.3mm，间距 1.0mm 左右）接 GND。
3. EPAD 阻焊做网格分格开窗，防止器件浮起。
4. 晶振信号坚持走表层，不换层、不打孔。
5. 去耦电容应位于"电源过孔 → 电容 → 引脚"的路径上。

### 🔗 承上启下

MCU 处理完毕。下一讲回到 FPGA，处理**外设 BANK 的扇孔**。

## 第24讲：第十九讲：FPGA 外设模块扇孔

### 📖 这一集讲什么

FPGA 除了 DDR3 和 HDMI，还有大量"外设 IO"：排针扩展口、LED、按键、TF 卡、串口、以及各类 BANK 的通用 IO。这一讲讲这些**非高速但数量庞大**的信号怎么扇出。

策略与高速信号完全不同：**高速信号追求质量，外设信号追求"通道利用率"。**

### 🔬 深入原理

**通道规划思想。** BGA 出线的本质是"通道资源分配问题"。假设 FPGA 是 17×17 的 BGA（0.8mm pitch，289 球），扣掉电源地约剩 180 个信号球。已知：

```
DDR3 占用     : ~60 根 (DQ16 + DQS4 + DQM2 + A15 + BA3 + CMD6 + CK2 + 其他)
HDMI 占用     : 8 根 (4 对差分)
配置/JTAG     : ~10 根
剩余外设 IO   : ~100 根
```

100 根外设 IO 要分配到 3 个信号层（L1/L3/L6）+ 4 个方向。分配原则：

| 层 | 优先分配给 |
|---|---|
| L1 (TOP) | 短距离、就近的外设；BGA 外圈直接引出 |
| L3 | DDR3 优先，剩余通道给较长的外设线 |
| L6 (BOTTOM) | 背面器件相关、排针连接、跨板长线 |

**"外圈免打孔"原则。** BGA 最外 1~2 圈的球可以直接在表层向外引出，不需要过孔。289 球的 BGA，最外一圈有 $17\times4-4=64$ 个球，第二圈 $15\times4-4=56$ 个。合理利用这 120 个位置可以省掉大量过孔——所以**引脚分配（Pin Assignment）阶段就应该把常用外设放到外圈**。

这引出一个重要理念：**PCB 工程师应该参与 FPGA 的引脚分配**。FPGA 的 IO 是可编程的，把某个 LED 从内圈球换到外圈球，只需改一行约束文件，却能省掉一个过孔和一段绕线。

### 🛠 设计实例/操作

**例1：扇孔的"方向分区"**

```
         排针区(上)
    ↑ ↑ ↑ ↑ ↑ ↑ ↑ ↑
  ← ┌─────────────┐ →
  ← │             │ →  HDMI(右)
电源← │  FPGA BGA   │ →
  ← │             │ →
  ← └─────────────┘ →  DDR3(右下)
    ↓ ↓ ↓ ↓ ↓ ↓ ↓ ↓
       LED/按键(下)

  每个方向的球, 全部朝该方向扇出, 绝不"逆向"
```

**例2：TF 卡信号扇出。** TF/SD 卡（4bit SDIO 模式）有 `CLK / CMD / DAT0-3`，速率 25~50MHz（SDR25/SDR50 可到 100MHz+）。要求：
- 6 根线**同组等长**（容差 ±100mil 即可，比 DDR3 宽松得多）；
- CLK 单独走，两侧留间距 ≥3W，防止对 DAT 串扰；
- 卡座的 CD（检测）脚加上拉；
- 每根线可预留 22~33Ω 串阻位置（抑制过冲）。

**例3：批量扇孔技巧。** 选中一整排球 → 使用 EDA 的"扇出/Fanout"功能，一次性生成短线+过孔；或做好一个"样板"后用**阵列复制**。手工一个个画 100 个扇孔，既慢又不整齐。

### ⚠️ 常见误区

- **不分方向乱扇**：某个球明明在右侧却往左扇，堵死左侧通道。
- **不参与引脚分配**：接受 FPGA 工程师给的"随机"引脚，导致布线难度倍增。
- **外设线抢占了 DDR3 的 L3 通道**：DDR3 走不完只能上 L1/L6，SI 变差。
- **TF 卡 CLK 与 DAT 挤在一起**：读卡不稳定。
- **过孔全部堆在 BGA 边缘一圈**：形成"过孔墙"，切断 L2 地平面。

### 📌 要点速记

1. 外设扇孔目标是通道利用率，按"方向分区"扇出，绝不逆向。
2. BGA 外 1~2 圈可表层直出，善用可省大量过孔。
3. **PCB 工程师应参与 FPGA 引脚分配**，改约束比绕线便宜太多。
4. L3 优先留给 DDR3，外设走 L1/L6。
5. TF 卡 6 根线同组等长（±100mil），CLK 单独隔离。

### 🔗 承上启下

信号扇孔全部完成。下一讲处理最后一块——**电源模块扇孔**，逻辑与信号完全不同。

## 第25讲：第二十讲：电源模块扇孔

### 📖 这一集讲什么

电源"扇孔"的目标不是"引出一根线"，而是**建立低阻抗、大电流的立体通路**。这一讲讲电源过孔怎么打、平面怎么连、以及地过孔的布置。

### 🔬 深入原理

**电源过孔的三个作用：**
1. **载流**：把电流从 L4 平面送到 L1/L6 的器件；
2. **降低 PDN 阻抗**：过孔电感串在供电路径上，越多越并联，电感越小；
3. **散热**：把 DC-DC 芯片的热导到内层铜。

**并联电感。** $N$ 个过孔并联，总电感约（忽略互感）：

$$L_{total}\approx\frac{L_{single}}{N}$$

单个 0.3mm 通孔电感约 **0.8~1.0 nH**（1.6mm 板厚）。要把电源换层电感降到 0.2nH，需要 **4~5 个过孔**。实际因为互感，效果会略差于理想并联，所以工程上"宁多勿少"。

**地过孔更重要。** 一个常被忽略的事实：**电源电流的回路是地**。给电源打了 6 个过孔，地只打 2 个，回路电感仍由地决定。原则：**地过孔数量 ≥ 电源过孔数量**。

**热过孔。** DC-DC 芯片散热焊盘下的过孔阵列：
- 孔径 0.3mm，间距 1.0~1.2mm；
- 数量 9~16 个；
- 连到 L2/L5 大面积地铜（内层铜是主要散热路径）；
- 若板厂支持，可做**树脂塞孔**避免焊料流失。

### 🛠 设计实例/操作

**例1：DC-DC 输出到负载的电源通路**

```
  L1(TOP):  [DCDC] ── SW ──[L]──┬── 铺铜块 VOUT
                                 │
                            ●●●●●●●●   <- 过孔阵列 (0.3mm x 6~8)
                                 ↓
  L4(PWR):        ┌──────────────────────┐
                  │   1V0 平面分区        │
                  └──────────┬───────────┘
                             ↓
                        ●●●●●●●●●●        <- 到 BGA 电源球区
  L1(TOP):            FPGA VCCINT 球
```

**例2：地平面的"缝合"。** L2 和 L5 是两个独立的地平面，必须用大量过孔连成"一个地"：
- DC-DC 区域：地铜下密集打孔（间距 2~3mm）；
- BGA 区域：每个 GND 球一个孔；
- 板边：缝合过孔（第 50 讲内容）；
- 目的：让 L2 和 L5 电位一致，任何信号换层时回流都能"就近跳层"。

**例3：电源过孔数量速查表**

| 电流 | 最少过孔（0.3mm） | 推荐数量 |
|---|---|---|
| 0.5A | 1 | 2 |
| 1A | 1 | 2~3 |
| 2A | 2 | 4~6 |
| 3A | 3 | 6~8 |
| 5A | 5 | 10~12 |

### ⚠️ 常见误区

- **电源只打 1 个过孔**：既是载流瓶颈也是电感瓶颈。
- **地过孔比电源过孔少**：回路电感没降下来，PDN 改善有限。
- **热过孔不塞孔且开窗过大**：回流焊时锡从孔漏到背面，焊点空洞。
- **SW 节点打过孔换层**：SW 是高 dv/dt 节点，换层会把噪声带到其他层，尽量让 SW 只在表层。
- **电源平面分割区太小**：局部电流密度过大，压降超标。

### 📌 要点速记

1. 电源过孔追求"多而近"：载流 + 降电感 + 散热三重作用。
2. 单个 0.3mm 过孔 ≈ 1A、≈ 0.8~1.0nH，$L_{total}\approx L/N$。
3. **地过孔数量 ≥ 电源过孔数量**，回路电感由地决定。
4. DC-DC 散热焊盘打 9~16 个热过孔，连内层地铜。
5. SW 节点尽量不换层，避免把开关噪声带入内层。

### 🔗 承上启下

扇孔全线完工，板子已经"通了气"。从下一讲开始进入布线主战场，先讲 **DDR3 布线规范**。

## 第26讲：第二十一讲：DDR3 布线规范讲解

### 📖 这一集讲什么

这一讲把 DDR3 布线的"军规"一次性讲全，后面几讲都是执行这套规范。

**DDR3 布线规范总表（点对点单颗 x16，DDR3-800/1066）：**

| 项目 | 要求 | 说明 |
|---|---|---|
| 单端阻抗 | 50Ω ±10% | 40~60Ω 可接受 |
| 差分阻抗（DQS/CK） | 100Ω ±10% | 对内 ≤5mil |
| 走线层 | 优先 L3（带状线） | 参考面 L2/L4 |
| 最大长度 | ≤3000 mil（76mm） | 越短越好 |
| 组内等长（DQ vs DQS） | ±25 mil | 同 byte lane |
| 组内等长（Addr/CMD vs CK） | ±50~100 mil | 视速率 |
| 线间距 | ≥3W（同组）/ ≥4W（异组） | 防串扰 |
| DQS/CK 与其他线间距 | ≥4W | 时钟最敏感 |
| 参考平面 | 全程连续，不跨分割 | **最重要** |
| 换层 | 尽量不换；必换则加 GND 回流孔 | |
| 蛇形线 | 幅度 ≥3W，间距 ≥4W | 防自耦合 |
| VREF | 线宽 ≥10mil，每脚 100nF | 远离 DQ ≥25mil |

### 🔬 深入原理

**1）为什么 byte lane 内要等长，lane 之间不用？** 因为 DDR3 采用 **源同步（Source Synchronous）** 时序：数据 DQ 与选通信号 DQS 一起发送，接收端用 DQS 的边沿去采样 DQ。

```
   发送端           接收端
   DQ0-7  ────────► 用 DQS0 采样
   DQS0   ────────►
   
   只要 DQ 与 DQS 一起到达, 传输时间长短无所谓
   => 只需 lane 内等长, lane 间可以差很多
```

时序裕量（以写时序为例）：

$$t_{margin}=\frac{UI}{2}-t_{skew}-t_{jitter}-t_{setup/hold}$$

DDR3-800 的 $UI = 1/(800\times10^6)=1250\ \mathrm{ps}$，半个 UI = 625ps。25mil 的长度差对应偏斜：

$$25\ \mathrm{mil}=0.635\ \mathrm{mm},\quad t_{skew}=0.635\times7=4.4\ \mathrm{ps}$$

只占 0.7%，非常安全。这就是 ±25mil 这个数字的由来。

**2）为什么 Addr/CMD 与 CK 等长？** 地址/命令是**公共时钟同步**：DDR3 用 CK 的上升沿锁存地址命令。所以要保证 Addr 与 CK 同时到达。容差可放宽到 ±50~100mil，因为地址命令通常以更低的速率（半速率）传输。

**3）串扰（Crosstalk）与 3W 规则。** 相邻走线间的耦合系数随间距增大而快速下降。经验：
- 间距 = 1W：串扰约 20%
- 间距 = 2W：串扰约 8%
- 间距 = 3W：串扰约 3~4%
- 间距 = 4W：串扰 <2%

对 DDR3 这样的并行总线，**同时翻转的线很多（SSN 同步开关噪声）**，所以间距不能省。

### 🛠 设计实例/操作

**例1：DDR3 参考平面检查方法。** 布完线后，用"单层显示"逐层检查：

```
  检查 L3 上的 DQ 线时:
  ① 显示 L2 + L3  -> L3 的线下方 L2 必须是完整铜
  ② 显示 L3 + L4  -> L3 的线上方 L4 必须是完整铜(1V5区或3V3区均可)
  ③ 如果 L4 上有分割缝, 而 DQ 线正好横跨 -> 必须改线或改分割
```

**为什么 L4 是电源平面也能当参考面？** 因为对高频信号而言，电源平面与地平面之间有大量去耦电容（以及平面电容），交流上是"短路"的，所以电源平面同样可以提供回流路径。但前提是：**该处必须有足够的去耦电容**，且信号不能从"1V5 区"跨到"3V3 区"。

**例2：蛇形走线（等长绕线）的几何要求**

```
   正确:                      错误:
    ╭──╮  ╭──╮               ╭╮╭╮╭╮╭╮
   ─╯  ╰──╯  ╰─              ╯╰╯╰╯╰╯╰
   幅度 A ≥ 3W               幅度太小
   间距 S ≥ 4W               间距太密 -> 自耦合, 实际延时小于计算值
   拐角 45° 或圆弧            90° 直角
```

自耦合的后果：蛇形线的两段互相耦合，信号会"抄近路"，实际延时小于按长度计算的值，等长失效。

### ⚠️ 常见误区

- **以为所有 DDR3 线都要等长**：只需 lane 内、以及 Addr 与 CK 之间。
- **跨分割走线**：这是 DDR3 最致命的错误，回流断裂导致大量噪声。
- **蛇形线绕得太密**：自耦合导致等长失效。
- **DQS 与 DQ 混在一起没有间距**：DQS 被串扰，采样点抖动。
- **忽略过孔延时**：每个过孔约 3~10ps 延时，严格等长时要计入。

### 📌 要点速记

1. DDR3 = 源同步，只需 **lane 内等长**（±25mil）+ **Addr/CMD 对 CK 等长**（±50~100mil）。
2. 单端 50Ω，差分 100Ω，走 L3 带状线，长度 ≤3000mil。
3. 同组间距 ≥3W，异组/时钟 ≥4W。
4. **参考平面连续是第一铁律**，不跨分割。
5. 蛇形线幅度 ≥3W、间距 ≥4W，避免自耦合。

### 🔗 承上启下

规范讲完。下一讲把 DDR3 的几十根信号**分类建组**，为分批布线做准备。

## 第27讲：第二十二讲：DDR3 信号线分类

### 📖 这一集讲什么

DDR3 有 60 多根信号，直接乱布必然失控。这一讲教你**分类**——把它们分成 4 大类、若干小组，在 EDA 里建立对应的网络类与 xSignal（点到点长度组），后面按组布线、按组等长。

**DDR3 信号完整分类（x16）：**

```
【第一类】数据组 (Data Group) —— 按 byte lane 分 2 组
  Byte Lane 0: DQ0~DQ7 (8) + DQS0_P/N (2) + DQM0/LDM (1)  = 11 根
  Byte Lane 1: DQ8~DQ15(8) + DQS1_P/N (2) + DQM1/UDM (1)  = 11 根
  特点: 双向, 源同步, 速率最高, 组内严格等长(±25mil)

【第二类】地址组 (Address Group)
  A0~A14 (15) + BA0~BA2 (3)                                = 18 根
  特点: 单向(FPGA->DDR3), 公共时钟同步, 与 CK 等长(±50~100mil)

【第三类】命令控制组 (Command/Control Group)
  RAS# CAS# WE# CS# CKE ODT RESET#                         = 7 根
  特点: 与地址组同一时序域, 一起等长

【第四类】时钟组 (Clock Group)
  CK_P / CK_N                                              = 2 根
  特点: 差分, 100Ω, 是第二三类的时序基准, 通常走最长

【辅助】电源与参考
  VDD/VDDQ(1.5V), VSS, VREFCA, VREFDQ(0.75V), ZQ校准电阻
```

### 🔬 深入原理

**为什么这样分？** 因为**时序域不同**：

| 组 | 时序基准 | 等长对象 |
|---|---|---|
| Byte Lane 0 | DQS0 | 组内 11 根互相等长 |
| Byte Lane 1 | DQS1 | 组内 11 根互相等长 |
| Addr + CMD/CTRL | CK | 25 根 + CK 互相等长 |

**Lane 0 与 Lane 1 之间不需要等长**，这给布局布线带来极大自由度——两个 lane 可以分别从 FPGA 的不同区域出来，走不同的路径。

**ZQ 校准电阻**：DDR3 需要一个 240Ω ±1% 的精密电阻接在 ZQ 引脚到 GND，用于片上驱动强度与 ODT 校准。它必须**靠近 DDR3 的 ZQ 引脚（<10mm）**，走线短，且这条线不要和高速线并行。

**RESET#**：DDR3 的复位是低速信号，但要求上电时保持低电平足够长时间，走线随意但要加上拉/下拉（按控制器要求）。

### 🛠 设计实例/操作

**例1：在 EDA 中建立类与等长组**

```
Net Class:
  ├ DDR3_DQ_L0    : DDR3_DQ0..7, DDR3_DQS0_P, DDR3_DQS0_N, DDR3_DQM0
  ├ DDR3_DQ_L1    : DDR3_DQ8..15, DDR3_DQS1_P, DDR3_DQS1_N, DDR3_DQM1
  ├ DDR3_ADDR     : DDR3_A0..14, DDR3_BA0..2
  ├ DDR3_CMD      : DDR3_RAS_N, CAS_N, WE_N, CS_N, CKE, ODT
  └ DDR3_CLK      : DDR3_CK_P, DDR3_CK_N

Differential Pair:
  ├ DDR3_DQS0 (P/N)
  ├ DDR3_DQS1 (P/N)
  └ DDR3_CK   (P/N)

等长组 (Length Matching Group):
  ├ Group_L0  = DDR3_DQ_L0            容差 ±25 mil, 基准 DQS0
  ├ Group_L1  = DDR3_DQ_L1            容差 ±25 mil, 基准 DQS1
  └ Group_AC  = DDR3_ADDR + DDR3_CMD + DDR3_CLK   容差 ±50 mil, 基准 CK
```

**例2：给每组指定"走线走廊"。**

```
   FPGA                         DDR3
   ┌────┐                      ┌────┐
   │ L0 ├══════走廊A(上)═══════┤ L0 │
   │区  │                      │区  │
   │ AC ├══════走廊B(中)═══════┤ AC │
   │区  │                      │区  │
   │ L1 ├══════走廊C(下)═══════┤ L1 │
   └────┘                      └────┘
   
   三条走廊互不交叉, 每条走廊内部再细分
```

这样规划后，布线就变成"填空题"而不是"创作题"。

### ⚠️ 常见误区

- **把 DQM 漏掉**：DQM（数据掩码）属于数据组，必须与本 lane 的 DQ/DQS 一起等长。
- **把 DQS 当普通信号**：DQS 是差分且是本 lane 的时序基准，优先布。
- **RESET# 混进 Addr 等长组**：RESET# 是异步信号，不需要等长。
- **ZQ 电阻放远了**：校准不准，驱动强度/ODT 偏差。
- **两个 lane 强行等长**：白白浪费大量绕线空间。

### 📌 要点速记

1. DDR3 分 4 类：数据（按 lane）、地址、命令控制、时钟。
2. 等长组只有 3 个：Lane0、Lane1、（Addr+CMD+CK）。
3. DQM 属于数据组，必须一起等长；RESET# 是异步的，不等长。
4. ZQ 校准电阻 240Ω±1%，紧靠 DDR3 的 ZQ 脚。
5. 布线前先划"走廊"，让布线变成填空题。

### 🔗 承上启下

分类完成，走廊划好。下一讲开始真正落笔——**DDR3 数据线布线（一）**。

## 第28讲：第二十三讲：DDR3 布线-数据线（一）布线

### 📖 这一集讲什么

这一讲开始布 **Byte Lane 0（DQ0-7 + DQS0 + DQM0）**。布线的正确顺序不是"从 DQ0 开始"，而是：

```
① 先布 DQS0_P/N (差分, 是本组基准, 走最佳路径)
② 再布 DQM0
③ 最后布 DQ0~DQ7 (顺着 DQS 的路径平行走)
```

**为什么 DQS 先布？** 因为它是等长基准，路径最优；其他线只要"跟着它走"，长度自然接近，等长时补偿量最小。

### 🔬 深入原理

**"跟随布线（Follow Routing）"思想。** 一组信号如果路径形状一致，长度差就小。理想状态：

```
   ══════════════════════   DQS0_P
   ══════════════════════   DQS0_N
   ──────────────────────   DQ0
   ──────────────────────   DQ1
   ──────────────────────   DQ2
   ...  全部平行、同层、同弯道
```

这样 8 根 DQ 与 DQS 的长度差可能只有几十 mil，等长时只需微调。

**DQ 的"引脚交换（Pin Swap）"优化。** DDR3 的一个巨大便利：**同一 byte lane 内的 DQ 位可以任意交换顺序！** 因为 DDR3 控制器在初始化时会做读写训练（Write Leveling / Read Training），只要 DQ0-7 都在同一 lane 内，具体哪根线接哪个球无所谓（注意：这需要控制器/IP 支持，且不能跨 lane 交换）。

利用这一点：**如果飞线交叉，直接在原理图/约束里交换 DQ 顺序**，让所有线都平行不交叉。这能省掉大量换层和绕线。

> 注意：DQM 和 DQS 不能参与交换，只有 DQ0-7 内部可换；跨 byte lane 也不能换。

**换层的代价与处理。** 如果 DQ 必须从 L3 换到 L6：
1. 长度上要计入过孔延时（约 3~10ps，取决于板厚和过孔结构）；
2. L3 的参考面是 L2/L4，L6 的参考面是 L5，回流要跳层 → 必须在过孔旁 1mm 内加 GND 过孔；
3. 线宽要改（L3 4mil → L6 6mil）。

**建议：整个 byte lane 尽量全部走 L3，不换层。**

### 🛠 设计实例/操作

**例1：Lane 0 布线步骤实操**

```
Step1: 显示 L3 层 + L2/L4 参考层，隐藏无关网络
Step2: 布 DQS0_P/N 差分对
       - 用差分布线工具, 线宽4mil/间距6mil
       - 从 FPGA 扇孔过孔出发, 45°折线走到 DDR3
       - 全程不跨分割, 转角 45°
Step3: 布 DQM0, 紧邻 DQS 平行走
Step4: 布 DQ0~DQ7
       - 逐根跟随 DQS 路径, 间距 ≥3W (4mil线 -> 间距≥12mil)
       - 发现交叉 -> 记录下来, 准备做 pin swap
Step5: 检查: 单层查看, 确认下方参考面完整
Step6: 记录当前各线长度 (为等长做准备)
```

**例2：处理飞线交叉**

```
   交叉前 (DQ2 和 DQ5 交叉):
   FPGA          DDR3
   DQ2 ─────╲ ╱───── DQ2球
   DQ5 ─────╱ ╲───── DQ5球
   
   Pin Swap 后 (在 FPGA 约束文件中把 DQ2/DQ5 对调):
   DQ5 ──────────── DQ5球
   DQ2 ──────────── DQ2球
   
   代价: 改一行 XDC/UCF 约束
   收益: 省掉 2 个过孔 + 一段绕线
```

### ⚠️ 常见误区

- **先布 DQ 最后布 DQS**：DQS 被挤到最差路径，等长时全组都要迁就它。
- **不知道 DQ 可以交换**：硬绕线，浪费空间和层资源。
- **跨 byte lane 交换 DQ**：会破坏 DQS 与 DQ 的对应关系，功能异常。
- **8 根 DQ 分散在 3 个层**：长度差异巨大，等长几乎无法完成。
- **间距只留 2W**：串扰导致眼图闭合。

### 📌 要点速记

1. 布线顺序：DQS → DQM → DQ0-7，让基准信号走最优路径。
2. 采用"跟随布线"，全组平行同层，把长度差降到最小。
3. **同一 lane 内 DQ 可自由交换**（需控制器支持），用它消除交叉。
4. DQM/DQS 不可交换，跨 lane 不可交换。
5. 整组尽量走同一层（L3），不换层。

### 🔗 承上启下

Lane 0 完成。下一讲布 **Lane 1**，并处理两个 lane 之间的空间冲突。

## 第29讲：第二十四讲：DDR3 布线-数据线（二）布线

### 📖 这一集讲什么

这一讲布 **Byte Lane 1（DQ8-15 + DQS1 + DQM1）**，并解决实际工程中最常见的两个问题：**两个 lane 抢通道** 和 **地址组穿过数据组**。

方法与 Lane 0 相同（DQS1 先行、跟随布线、pin swap 消交叉），但难点在于此时板上已经有一半的线，空间被压缩。

### 🔬 深入原理

**通道冲突的三种解法：**

| 解法 | 做法 | 代价 |
|---|---|---|
| ① 换层 | Lane1 走 L6 或部分走 L1 | 换层过孔 + 参考面变化 |
| ② 绕行 | 从另一侧绕过去 | 长度增加，等长压力大 |
| ③ 重排 | 调整扇孔方向/pin swap | 需要回头改，但最优 |

**优先级：③ > ① > ②**。能通过重排解决的，绝不换层；能换层解决的，绝不绕行。

**关于 Lane 1 走不同层的可行性。** 由于 lane 之间不需要等长，**Lane 1 完全可以走 L6 而 Lane 0 走 L3**——只要 lane 内部保持同层即可。这是 DDR3 源同步架构给的重要自由度。

但要注意：
- L6 是 BOTTOM 层，参考面只有 L5（单参考），是**微带线**，$t_{pd}\approx5.5\ \mathrm{ps/mm}$，线宽约 6mil；
- L3 是带状线，$t_{pd}\approx7.0\ \mathrm{ps/mm}$，线宽约 4mil；
- **同一 lane 内绝不能一部分走 L3 一部分走 L6**，否则 $t_{pd}$ 不同，按长度等长是错的。

**如果同一 lane 内实在必须换层怎么办？** 那就要按**时间等长**而不是长度等长：把不同层的段分别乘以各自的 $t_{pd}$ 求和。高端 EDA 支持"延时等长"模式；如果只支持长度等长，就要手工换算：

$$L_{equiv,L3} = L_{L6}\times\frac{t_{pd,L6}}{t_{pd,L3}} = L_{L6}\times\frac{5.5}{7.0}=0.786\,L_{L6}$$

即 L6 上的 10mm 相当于 L3 上的 7.86mm。

### 🛠 设计实例/操作

**例1：两个 lane 的层分配方案**

```
方案甲 (推荐, 空间够时):
   Lane0 -> L3, 走廊A
   Lane1 -> L3, 走廊C     (都在 L3, 上下分开)
   Addr  -> L3 或 L1, 走廊B

方案乙 (空间紧张):
   Lane0 -> L3
   Lane1 -> L6            (整组换层, lane 内仍同层)
   Addr  -> L3
   注意: L6 线宽改为 6mil, 等长基准独立
```

**例2：地址组穿越问题。**

```
   问题: Addr 组要从 FPGA 中部出来, 但被 Lane0/Lane1 夹在中间
   
   ┌──────┐              ┌──────┐
   │ FPGA │══Lane0(L3)══►│ DDR3 │
   │      │──Addr(?)────►│      │
   │      │══Lane1(L3)══►│      │
   └──────┘              └──────┘
   
   解法1: Addr 走 L1 表层 (数量多但速率低, 表层空间够)
   解法2: Addr 走 L3 中间走廊, Lane0/1 分别上下让开
   解法3: 部分 Addr 走 L6
   
   注意: Addr 组内部必须同层(与 CK 同层), 否则 tpd 不同
```

**例3：串扰控制的具体数值。** L3 内层，线宽 4mil：
- 同组内 DQ 之间：间距 ≥12mil（3W）；
- DQS 与相邻 DQ：间距 ≥16mil（4W）；
- Lane0 与 Lane1 之间：间距 ≥20mil（5W）；
- 数据组与地址组之间：间距 ≥20mil（5W，因为时序域不同，是"异步"干扰）。

### ⚠️ 常见误区

- **同一 lane 内跨层混走还按长度等长**：$t_{pd}$ 不同，等长结果是错的。
- **为了省事把 Lane1 绕一大圈**：长度超 3000mil，SI 恶化。
- **Addr 组内部跨层**：与 CK 的时序关系被破坏。
- **两个 lane 贴太近**：lane 间串扰虽不影响时序，但会抬高噪声底。
- **忘记 DQM1**：布完 8 根 DQ 就以为完事了。

### 📌 要点速记

1. Lane 之间无需等长 → **Lane1 可以整组走不同层**。
2. **同一 lane 内必须同层**，否则 $t_{pd}$ 不同，长度等长失效。
3. 换算关系：L6 微带 5.5ps/mm，L3 带状 7.0ps/mm，比值 0.786。
4. 冲突解决优先级：重排/pin swap > 换层 > 绕行。
5. 间距：组内 3W、DQS 4W、组间 5W。

## 第30讲：第二十五讲：DDR3 地址线布线

### 📖 这一集讲什么

地址组（A0-A14 + BA0-2 + RAS#/CAS#/WE#/CS#/CKE/ODT + CK_P/N）共约 27 根，是 DDR3 中**数量最多**的一组。好消息是它的时序要求比数据线宽松；坏消息是数量多、占空间大。

**布线顺序：**
```
① 先布 CK_P/CK_N (差分, 时序基准, 走最优、最长的路径)
② 再布 CS# / CKE / ODT (关键控制信号)
③ 最后布 A0-A14 / BA0-2 / RAS/CAS/WE
```

### 🔬 深入原理

**为什么 CK 要走"最长"？** 这是 DDR3 地址组等长的一个重要技巧。地址组要求 Addr/CMD 与 CK 等长，而 CK 是差分对、占空间大、最难绕。如果 CK 走最短，那么其他 25 根线都要绕回来配合它——绕线量巨大。

反过来，**让 CK 走一条自然的、稍长的路径，其余线只需小幅补偿**即可。所以布局布线时有意让 CK 路径略长（或至少不刻意求短）。

> 严格来说不同控制器有不同要求（有的要求 Addr 比 CK 短一个固定量），实际设计应以 FPGA 厂商的 DDR3 布线指南为准。对入门项目，采用"Addr/CMD 与 CK 等长，容差 ±50mil"是安全的做法。

**为什么地址组容差可以放宽？** 地址命令在 DDR3 中通常以 **1T 或 2T 时序**、且是**单倍速率（SDR）** 传输——即每个时钟周期只锁存一次（不像 DQ 是双沿 DDR）。

DDR3-800 的时钟频率是 400MHz，周期 2500ps。地址建立/保持窗口远大于数据的 625ps。所以 ±50mil（≈8.9ps）甚至 ±100mil（≈17.8ps）都是安全的。

**CKE 和 RESET# 的特殊性：**
- `CKE`（时钟使能）：属于同步信号，需与地址组等长；
- `RESET#`：异步信号，不需等长，随便走；
- `ODT`：同步信号，需等长。

### 🛠 设计实例/操作

**例1：地址组的"扁平化"布线**

```
   FPGA 侧扇孔                        DDR3 侧
   
   ●●●●●●●●●●●●●    (27 个过孔)
   │││││││││││││
   ├┼┼┼┼┼┼┼┼┼┼┼┤   全部平行, 间距 12mil (3W)
   ││││││││││││╰──► 组成一条 "宽带" 走线束
   │││││││││││╰───►
   ...
   
   宽度估算: 27 根 × (4mil线 + 12mil间距) ≈ 432 mil ≈ 11 mm
   -> 布局时必须给地址组留 11mm 以上的走廊!
```

**例2：CK 差分对的特殊处理**

```
   CK_P/CK_N 走在地址组的"中间"位置最好:
   
   A0-A7   ══════════════
   BA0-2   ══════════════
   CK_P    ─────────────  <- 中间, 两侧间距 ≥4W (16mil)
   CK_N    ─────────────
   CMD     ══════════════
   A8-A14  ══════════════
   
   原因: CK 在中间, 与各线的路径最接近, 等长最容易
        且两侧留 4W 间距, 保护时钟不被串扰
```

**例3：布线后的长度记录。** 布完后打开"网络长度"面板，记录：

| 网络 | 长度(mil) | 与 CK 差值 |
|---|---|---|
| CK_P | 1850 | 0（基准）|
| CK_N | 1852 | +2 ✓ |
| A0 | 1790 | -60 ✗ 需补 |
| A1 | 1835 | -15 ✓ |
| ... | | |

差值超过 ±50mil 的记下来，等长阶段（第 42 讲）统一处理。

### ⚠️ 常见误区

- **CK 走最短路径**：导致其余 25 根线全部要绕，绕线量爆炸。
- **RESET# 被拉进等长组**：浪费空间，毫无意义。
- **地址组走廊预留不足**：27 根线需要约 11mm 宽，布局时没留就只能换层。
- **CK 贴着地址线走**：时钟被串扰，抖动增大。
- **地址组跨层混走**：$t_{pd}$ 不同，与 CK 的等长失效。
- **忘记 CKE/ODT**：这两个是同步信号，必须一起等长。

### 📌 要点速记

1. 地址组 ≈27 根，走廊宽度需约 11mm，布局阶段就要预留。
2. 布线顺序：CK → CS/CKE/ODT → A/BA/CMD。
3. **让 CK 走自然（略长）路径**，其余线小幅补偿，绕线量最小。
4. CK 放在地址束中间，两侧留 4W 间距保护。
5. RESET# 异步不等长；CKE、ODT 同步必须等长。

### 🔗 承上启下

## 第31讲：FPGA-BANK2 信号布线

📖 这一集讲什么
逻辑派开发板的 FPGA 把引脚划分到多个 BANK，每个 BANK 有独立的 VCCO（I/O 供电电压）和参考电压，因此布线前必须确认 BANK2 上都是什么信号。BANK2 通常挂接一些低速外设、配置相关信号、或 GPIO 扩展。本集的目标是把 BANK2 所有飞线（ratnet）用最短、最干净的路径连通，并遵守"3W 间距""参考平面连续""差分走线"三条铁律。对初学者来说，布线不是"连上线就行"，而是"连得上、跑得稳、好修"。

🔬 深入原理
- BGA 区域走线靠扇孔（fanout）已把每个焊盘引导到表层/内层走线空间，本集在已有过孔基础上拉线。
- 关键公式：线宽由阻抗公式决定，微带线特征阻抗近似
  $Z_0 \approx \frac{87}{\sqrt{\varepsilon_r+1.41}}\ln\frac{5.98h}{0.8w+t}$
  其中 $h$ 为到参考平面距离、$w$ 为线宽、$t$ 为铜厚、$\varepsilon_r$ 为介质介电常数。一旦叠层定好，单端 50Ω 线宽即固定。
- 为什么重要：BANK2 若有高速 LVCMOS 并行总线，线长差异会产生建立/保持时间偏移；即使看起来"慢"，也要尽量等长、避免直角（改用 45° 或圆弧）。

🛠 设计实例/操作
1. 在 Altium 中按 `N → Show Connections → From Selected` 只显示 BANK2 飞线，避免误连其它网络。
2. 例：BANK2 上 8 位 GPIO 接 LED/按键，走线时统一从 BGA 过孔引出后平行蛇形等长到连接器，组内长度差控制 ≤50mil；敏感信号（如 CLOCK 输出）单独包地处理。

⚠️ 常见误区
- 把 BANK2 的 VCCO 与相邻 BANK 的 VCCO 当同一网络连到一起，实际不同 BANK 电压可能不同，会烧毁 IO。
- 在参考平面（GND/L2）上随意打过孔穿层，切断回流路径。

📌 要点速记
- BANK 布线前先核对每个 BANK 的 VCCO 电压。
- 先扇孔后连线，按网络颜色分批走。
- 并行总线组内等长、远离时钟。
- 不允许跨分割平面走线。
- 走完一组清一组飞线，防止遗漏。

🔗 承上启下
承接第 30 讲 BANK1 布线，本集处理 BANK2；下一讲继续 BANK3，逐步把 FPGA 全部 IO 连通，为后续等长与 DRC 打基础。

## 第32讲：FPGA-BANK3 信号线布线

📖 这一集讲什么
BANK3 在逻辑派上常承载与 MCU 交互的并行/串行总线、SPI、或自定义高速接口。和 BANK2 一样，先确认电平标准（LVCMOS33、LVCMOS18 等）与方向。布线核心仍是"短、直、等长、有完整参考面"。若 BANK3 含差分对（如 LVDS），必须成对走线并保持 100Ω 差分阻抗与对内等长。

🔬 深入原理
- 差分阻抗：两条耦合线特性阻抗满足 $Z_{diff}\approx 2Z_0(1-k)$，其中 $k$ 为耦合系数。BANK3 的 LVDS 对需按叠层计算线宽/间距（常见 5/5mil 或 4/8mil 组合）。
- 对内长度偏差（intra-pair skew）会引起共模噪声与眼图闭合，要求通常 ≤5mil。
- 为什么重要：MCU↔FPGA 的并行总线若某位比其它位长很多，采样时会错位；差分对不等长则丧失抗共模干扰能力。

🛠 设计实例/操作
1. 例：BANK3 出 4 对 LVDS 到外部高速 ADC，每对设置 Differential Pair 规则，走线时开启"Length Tuning"实时显示长度，确保对内 ≤5mil、对间可不严格但建议 ≤50mil。
2. 例：SPI 总线（SCLK/MOSI/MISO/CS）从 BGA 扇孔后就近布到 SPI Flash，SCLK 作为参考，MOSI/MISO 与 SCLK 等长 ±50mil。

⚠️ 常见误区
- 差分对中途换层却不补地过孔，导致回流不连续、阻抗突变。
- 把差分对的"正""负"分别走在两个不同参考平面区域，破坏耦合。

📌 要点速记
- 先认电平标准再走线。
- 差分对必须成对、等阻抗、对内等长。
- 换层必打回流地过孔。
- 并行总线相对时钟等长。
- 用交互式等长工具实时核对。

🔗 承上启下
BANK2/BANK3 布线完成后，FPGA 各 BANK 连线基本就绪，第 33 讲统一清理 FPGA 与 MCU 之间残留的"杂线"。

## 第33讲：FPGA 以及 MCU 杂线处理

📖 这一集讲什么
"杂线"指前面各讲布线后还剩下的零碎飞线——可能是电源、地、配置、复位、未归类的单端信号。初学者容易忽略它们，结果 DRC 报成百上千个 unrouted。本集教你用"分类收口"的思路：先电源、后地、再信号；能就近打孔连平面的绝不绕远；实在绕不过的才走信号线。

🔬 深入原理
- 电源/地属于"平面网络"，最优方案是打过孔直接落到大面积铜皮，而非用细线长距离连。
- 复位（RST）、配置（PROG、INIT、DONE）等信号属于"安静信号"，应远离 DDR/HDMI 等噪声源，并加适当上拉（按手册）。
- 为什么重要：杂线残留 = 开路 = 板子不工作；复位走线受干扰会导致 FPGA 反复重启。

🛠 设计实例/操作
1. 用 `Reports → Measure` 或飞线高亮，逐个网络定位；对 GND 网络直接在大铜皮上补过孔阵列。
2. 例：MCU 的 NRST 还差一段没连，把它从 MCU 引脚经 10k 上拉到 3.3V 后，短走线到复位按键，并用地线包夹降低 ESD 风险。

⚠️ 常见误区
- 把杂线一律当成"不重要信号"随便绕，结果复位/配置被高速线串扰。
- 用细信号线代替电源过孔，造成电源瓶颈。

📌 要点速记
- 杂线要分类：电源/地优先打孔入平面。
- 安静信号（复位/配置）远噪声、加上拉。
- 每清一条在原理图/网络表里核对，防错连。
- 优先补过孔而非长走线。
- 清完用飞线显示确认 0 残留（电源地除外）。

🔗 承上启下
杂线清零后进入电源系统连通阶段——第 34、35 讲专门处理电源连通性。

## 第34讲：电源连通性处理（一）

📖 这一集讲什么
"连通性"不等于"连上线"，而是要保证每个电源网络从源头（DCDC/LDO）到所有负载引脚，电气上真正导通、且载流能力足够。本集（上）主要处理主电源通道：12V/5V 输入、3.3V、1.8V、1.0V（FPGA 核心）等。先建立"电源树"概念——谁产生、供给谁。

🔬 深入原理
- 载流能力：外层 1oz 铜、1mm 线宽约可载 1A；内层因散热差需更宽。`电流→铜宽`经验：温升 10℃ 时 $W(mil)\approx I(A)\times 20$（粗略）。
- 压降：$V_{drop}=I\times R_{trace}$，$R=\rho L/(W\times T)$。长距离细电源走线会掉压，必须用铺铜（polygon）或加宽。
- 为什么重要：FPGA 核心 1.0V 瞬时电流大，若通道电阻大，核压跌落触发欠压保护。

🛠 设计实例/操作
1. 例：DCDC 输出 3.3V，先铺一块 3.3V 铜皮覆盖 FPGA/MCU 的 3.3V BANK，再用过孔"树状"分到各引脚；用 `Highlight` 验证每个 3.3V 引脚都被铜皮覆盖。
2. 例：1.0V 核心电源用 L3/L4 两层同时铺铜并打多过孔并联，降低平面电阻与电感。

⚠️ 常见误区
- 以为"一个过孔就够了"——单过孔载流有限（约 1A@10mil 孔），大电流需多个并联。
- 电源铺铜被信号过孔"打穿"成孤岛，实际没连通。

📌 要点速记
- 先画电源树：源→负载一目了然。
- 大电流用铺铜+多过孔，勿用细线。
- 核压（1.0V）走线最短最宽。
- 铺铜后务必高亮验证全连通。
- 电源过孔要足够多，降低 R/L。

🔗 承上启下
本讲搭好主电源骨架，第 35 讲细化各电压域、去耦电容回路与多电源 BANK 的连通收尾。

## 第35讲：电源连通性处理（二）

📖 这一集讲什么
上一讲处理了主通道，本集（下）补齐细节：每个去耦电容的接地回路、多电压域 BANK 的区分、模拟电源与数字电源的分离、以及"星形"或"磁珠隔离"的取舍。很多板子"能上电但不稳定"，根因就在这一讲。

🔬 深入原理
- 去耦电容回路面积越小越好：$L_{loop}$ 决定谐振频率与抑制效果，电容地端应就近打孔到完整 GND 平面，而非绕到远处。
- 模拟/数字分离：AGND 与 DGND 通常在一点（星点）连接，或用磁珠/0Ω 隔离，避免数字噪声灌入模拟。
- 为什么重要：回路电感大→高频去耦失效→电源纹波大→误触发。

🛠 设计实例/操作
1. 例：每个 DDR3 VDDQ 去耦电容，其 GND 焊盘紧邻打 2 个地孔到 L2 GND，电源端直接连 VDDQ 铜皮，回路面积最小。
2. 例：FPGA 的 VCCAUX（模拟辅助）与数字 1.8V 之间用 0Ω 电阻单点连接，AGND 通过单点过孔汇到主地。

⚠️ 常见误区
- 去耦电容放在芯片背面却用很长线接地，等于没去耦。
- 把磁珠当"万能隔离"，结果大电流时磁珠饱和、压降剧增。

📌 要点速记
- 去耦电容回路越短越好，地就近打孔。
- 模拟/数字地单点连接。
- 磁珠只用于小信号隔离，大电流忌用。
- 每个电压域独立铺铜、互不短路。
- 连通后按网络逐条高亮复核。

🔗 承上启下
电源连通完成，进入"布线优化"三连讲（36–38），把前面粗布的通路收拾干净。

## 第36讲：布线优化（一）

📖 这一集讲什么
粗布线（连线）只解决"通"，优化解决"好"。第一讲优化聚焦"拓扑与间距"：把走线理顺、减少不必要的过孔、拉开 3W 间距、修掉直角。目标是在不破坏连通性的前提下降低串扰与反射。想象把一团乱麻捋直——既美观又可靠。

🔬 深入原理
- 3W 规则：线间距 ≥ 3 倍线宽（中心到中心）可使耦合串扰降至约 70% 以下；关键信号用 5W 或加地屏蔽线。
- 直角/锐角的危害：高频下直角等效为小电容突变，引起阻抗不连续与 EMI 尖峰；改用 45° 或圆弧。
- 过孔寄生：$C_{via}\approx \frac{1.41\varepsilon_r T D_1^2}{D_2-D_1}$，过孔越多寄生电容/电感越大，高速线尽量少换层。
- 为什么重要：串扰会让相邻信号误翻转，尤其 DDR/时钟周围。

🛠 设计实例/操作
1. 例：DDR3 地址线原本与时钟平行贴太近，用 `Interactive Routing` 拉开到 3W，并在中间插入地屏蔽走线（Guard Trace）打孔接地。
2. 例：把多个不必要的"来回换层"过孔改回同层直走，从 6 个过孔减到 2 个。

⚠️ 常见误区
- 只追求好看"走直角对齐"，忽略阻抗突变。
- 认为"间距够就行"，忘了平行长距离串扰会累积。

📌 要点速记
- 3W（关键 5W）间距防串扰。
- 直角改 45°/圆弧。
- 高速线减少换层与过孔。
- 关键信号加地屏蔽走线。
- 优化不改连通，只改善质量。

🔗 承上启下
间距拓扑理顺后，第 37 讲深入"参考面与回流"优化。

## 第37讲：布线优化（二）

📖 这一集讲什么
这一讲优化"回流路径与层分配"。信号电流的返回路径永远贴着参考平面（GND/电源）走，哪里被切断，信号就在哪里"绕远+辐射"。我们要检查每条关键信号是否全程有完整参考面，必要时补地过孔、调整层、或在跨分割处加回流过孔。

🔬 深入原理
- 返回电流在参考面上集中于信号正下方（趋肤+最小电感路径），频率越高越贴信号线。
- 跨分割（信号从 GND 参考区走到无参考/不同参考区）会迫使回流绕行，环路面积骤增，EMI 与振铃恶化。
- 为什么重要：回流不连续是高速板最常见的隐性故障源，示波器看到振铃、眼图差，往往就是它。

🛠 设计实例/操作
1. 例：某 HDMI 差分对从 L1 换到 L3 穿越电源平面缝隙，于是在换层点两侧各补一个 GND 过孔，给回流提供"楼梯"。
2. 例：把原本走在 L4（参考 L5 电源平面）的敏感时钟改到 L1（参考 L2 完整 GND），消除跨分割。

⚠️ 常见误区
- 只关心信号线本身，从不看它"下面"的参考面。
- 在缝隙处补一个过孔就以为万事大吉，实际要成对（去/回）补。

📌 要点速记
- 信号线正下方须有完整参考平面。
- 换层处补回流地过孔（成对）。
- 严禁跨分割走高速线。
- 优先把关键信号放在紧邻 GND 层。
- 回流连续 = 信号干净 + EMI 低。

🔗 承上启下
回流理顺后，第 38 讲做"等长整形与收尾优化"。

## 第38讲：布线优化（三）

📖 这一集讲什么
最后一讲优化聚焦"等长整形（Tuning）与整体收尾"：用蛇形线（Serpentine）把组内长度凑齐，同时控制蛇形线本身的耦合（间距、幅度），并清理 stub（残桩）、调整过孔扇出角度。优化到此，板子已基本具备信号完整性基础。

🔬 深入原理
- 蛇形等长规则：相邻平行段间距 ≥ 3W，单段幅度不过小，避免蛇形自身串扰（蛇形线两臂互为耦合源）。
- 残桩（stub）：未端接的多余线头会产生反射，长度应 < $\lambda/10$（对最高频率）。
- 时间换算长度：$\Delta L = \Delta t \times v$，$v=c/\sqrt{\varepsilon_{reff}}$（有效介电常数下相速），FR4 中约 6 in/ns。
- 为什么重要：不规范的蛇形会"为了等长反而引入串扰"。

🛠 设计实例/操作
1. 例：DDR3 数据组内某 DQ 短了 80mil，用 `Interactive Length Tuning` 加一段间距 3W 的蛇形补齐；实时显示达标后停止。
2. 例：清掉 BGA 扇孔后残留的 30mil 短桩，直接删除或连到邻近同网络过孔。

⚠️ 常见误区
- 蛇形绕得太密（间距 <2W），自己串扰自己。
- 为了好看把蛇形堆在连接器口，影响阻抗与装配。

📌 要点速记
- 蛇形线间距 ≥3W，幅度适中。
- 清残桩，避免反射。
- 等长用工具实时校，不靠目测。
- 蛇形避开连接器与过孔密集区。
- 优化三讲结束，布线质量定型。

🔗 承上启下
布线优化完成，第 39 讲再做一轮"电源联通优化"，确保供电无短板。

## 第39讲：电源联通优化

📖 这一集讲什么
前面电源连通性（34、35 讲）偏"建通道"，本集做"查漏补缺+降阻降感"：检查铺铜是否够宽、过孔是否够多、热点（瓶颈）在哪、去耦回路是否最短。目标是让 PDN（供电网络）的直流电阻与交流阻抗都足够低。

🔬 深入原理
- PDN 目标阻抗：$Z_{target}=\frac{V_{ripple}}{I_{transient}}$，例如 1.0V 允许纹波 50mV、瞬变 2A，则目标阻抗 ≤25mΩ。需靠"大平面（低 ESL）+ 多去耦电容（低 ESR）"实现。
- 平面电阻：$R=\rho\frac{L}{W\cdot T}$，铺铜越宽越短电阻越小；瓶颈处（颈缩）电阻陡增。
- 为什么重要：PDN 阻抗高→核压随负载跳动→时序裕量被吃掉。

🛠 设计实例/操作
1. 例：用 `Tools → PDN Analyzer`（或目测铜皮宽度）发现 1.0V 通道在某处被信号走线"颈缩"到 8mil，把信号改道恢复铜皮宽度至 40mil 以上。
2. 例：在 DCDC 输出到 FPGA 核心之间，将 L3/L4 两层铜皮用 8 个过孔并联，降低平面电感。

⚠️ 常见误区
- 只看"连没连"，不看铜皮宽度是否够载流。
- 去耦电容焊盘到平面中间隔细长颈缩铜，实际高频阻抗仍高。

📌 要点速记
- 电源铜皮忌颈缩，保持宽度。
- 多层铺铜 + 多过孔并联降阻感。
- 按目标阻抗法评估 PDN。
- 去耦回路最短化。
- 电源优化与信号优化同等重要。

🔗 承上启下
供电扎实后，进入全板"时序等长"重头戏——第 40 讲起系统做 DDR3 数据线等长。

## 第40讲：DDR3 数据线时序等长（一）

📖 这一集讲什么
DDR3 是这套 6 层板的高速核心，数据线（DQ）与选通（DQS）必须严格等长，否则读数据时采样窗口错位、出现 bit error。本集（上）讲"数据组（Data Group）"的分组逻辑：每 8 位 DQ + 1 对 DQS + 1 位 DM 组成一个 Byte Lane，组内等长，组间可不严格。

🔬 深入原理
- DDR 用源同步时钟：DQS 随数据一起发送，接收端用 DQS 边沿采样 DQ。因此同 Byte Lane 内 DQ/DM 与 DQS 的飞行时间（flight time）必须一致。
- 容忍偏差：DDR3-800（时钟 400MHz）数据组通常要求 $\Delta L \le 20\sim25\,\text{mil}$；按器件手册为准。
- 换算：$\Delta t = \Delta L / v$，$v\approx 6\,\text{in/ns}$（FR4），25mil ≈ 4.2ps。
- 为什么重要：等长偏差超容限→眼图闭合→内存读写错。

🛠 设计实例/操作
1. 例：Byte Lane0 含 DQ[0..7]、DM0、DQS0±。先量得 DQS0 走线长 1250mil，将 DQ0..7 各自加蛇形调到 1240~1260mil 内。
2. 操作：在 Altium 用 `Length Tuning` 配合 xSignals（把"芯片→过孔→DDR 引脚"整条路径定义为一条 xSignal）做精准等长，而非只看直线段。

⚠️ 常见误区
- 只等长"表层直线"，忘了过孔延迟（不同层过孔数不同，时延不等）。
- 把不同 Byte Lane 的 DQ 互相等长，浪费精力且无意义。

📌 要点速记
- 数据按 Byte Lane 分组，组内等长、组间独立。
- DDR3-800 数据组偏差通常 ≤20~25mil。
- 用 xSignals 把过孔延迟算进总长。
- DQ/DM 相对 DQS 等长。
- 等长前先定 DQS 为参考长度。

🔗 承上启下
本讲建立数据组等长方法，第 41 讲实操完成所有 Byte Lane 数据线等长。

## 第41讲：DDR3 数据线时序等长（二）

📖 这一集讲什么
承接上一讲，本集把逻辑派上所有 Byte Lane（通常 2 组：Lane0、Lane1，对应 DDR3 的×16 位宽）的 DQ/DM/DQS 全部等长收尾，并校核"组内最大最小长度差"满足规则。同时处理 DQS 差分对的内等长（≤5mil）。

🔬 深入原理
- 组内等长目标：设参考长度 $L_{ref}$（取 DQS 实际长），要求 $\max|L_i-L_j|\le \Delta_{tol}$。
- 差分 DQS 对内：$\Delta_{intra}\le 5\,\text{mil}$，否则共模噪声增大、采样沿抖动。
- 为什么重要：多组 Lane 若各自超差，整机在高温/低压下内存报错，极难排查。

🛠 设计实例/操作
1. 例：Lane1 的 DQ15 短了 60mil，用蛇形补到与 DQS1 差 ≤20mil；Lane0 与 Lane1 之间不做等长（源同步各自独立）。
2. 例：DQS1± 对内差 12mil，重新走其中一端缩短，调到 ≤5mil。

⚠️ 常见误区
- 蛇形只加在 DQ 短的那根，却把 DQS 也一起拉长，破坏"以 DQS 为参考"。
- 忽略 DM（数据掩码）等长，它同样需在组内。

📌 要点速记
- 每个 Byte Lane 独立等长到各自 DQS。
- DQS 差分对内 ≤5mil。
- DM 别漏掉，随组等长。
- 用规则（Matched Length）自动报超差。
- 等长后导出长度报告留档。

🔗 承上启下
数据组等长完成，第 42 讲转向"地址/命令/时钟"组的等长（这是另一套规则）。

## 第42讲：DDR3 地址线时序等长

📖 这一集讲什么
地址/命令/控制信号（ADDR、BA、CAS、RAS、WE、CKE、ODT、CS 等）与时钟 CK 组成"地址组（Address/Command Group）"。它们由控制器发出、被所有颗粒共享，因此要相对时钟 CK 等长（而非相对 DQS）。本集讲清这组等长规矩。

🔬 深入原理
- 地址组相对时钟 CK：$\Delta L \le 50\,\text{mil}$（DDR3-800，常见值；高速可收紧到 25mil），因为地址在 CK 边沿被所有颗粒同时采样。
- 时钟 CK 本身是差分对，对内 ≤5mil，且 CK 长度通常作为地址组的"基准"。
- 为什么重要：地址组错位→命令/地址被错拍锁存→初始化失败或随机崩溃。

🛠 设计实例/操作
1. 例：以 CK 长度 1300mil 为基准，ADDR[0..14]、BA[0..2]、控制信号全部用蛇形调到 1250~1350mil 区间（±50mil）。
2. 例：CK± 对内差 8mil，先修 CK 对内到 ≤5mil，再依 CK 总长调地址组。

⚠️ 常见误区
- 把地址组和 DQS 组混在一起等长——两者参考时钟不同（CK vs DQS），不可比。
- 忘记 CS/ODT/CKE 也是地址组成员，必须一起等长。

📌 要点速记
- 地址组相对 CK 等长，非 DQS。
- DDR3-800 容差常见 ±50mil。
- CK 差分对内 ≤5mil，作基准。
- CS/ODT/CKE 一并计入。
- 地址组与数据组规则严格区分。

🔗 承上启下
DDR3 全组等长收工，第 43 讲处理 HDMI 差分信号等长。

## 第43讲：HDMI 信号线时序等长

📖 这一集讲什么
HDMI 由 4 对 TMDS 差分信号（3 路数据 + 1 路时钟）组成，速率高（每对可达数 Gbps）。要求：每对内部等长（intra-pair ≤5~10mil），4 对之间相对时钟对（TMDS CLK）等长（inter-pair 通常 ≤? 行业常用 ≤50mil 量级，按标准/速率定）。本集讲 HDMI 等长实务。

🔬 深入原理
- TMDS 是电流模式差分，接收端靠 CDR 从数据里恢复时钟，但接收端仍参考 TMDS CLK 做通道对齐，故各数据对与时钟对需时长匹配。
- 对内等长保证差分共模小、眼图对称；对间等长保证多通道同步。
- 为什么重要：等长差过大会导致颜色错位、画面撕裂或 EDID 握手失败。

🛠 设计实例/操作
1. 例：4 对差分均走 100Ω 受控阻抗，先各自对内调到 ≤5mil；再以 TMDS_CLK 长度为基准，把 TMDS_D0/1/2 各对总长与其差控制在 ≤50mil。
2. 例：在连接器附近用短蛇形微调，避免蛇形进入 BGA 密集区。

⚠️ 常见误区
- 只做对内等长，忘了对间（相对时钟）等长。
- HDMI 差分对与时钟对间距太近又不等长，互串扰。

📌 要点速记
- HDMI 4 对差分均 100Ω 阻抗。
- 对内等长 ≤5mil。
- 各数据对相对 TMDS_CLK 等长（≤50mil 量级，依规格）。
- 蛇形留在板中空闲区，不挤连接器口。
- 全程紧邻 GND 参考面。

🔗 承上启下
HDMI 等长完，第 44–48 讲依次完成 FPGA 各 BANK 信号等长。

## 第44讲：FPGA-BANK0 信号时序等长

📖 这一集讲什么
BANK0 在逻辑派上常承载高速并行或 LVDS 接口（如连接 ADC、显示屏、或板间高速总线）。本集针对 BANK0 中"需要等长"的信号组做等长——通常是差分对组内、或某个源同步并行总线（数据相对随路时钟）。不是所有 BANK 信号都要等长，先判断信号类型。

🔬 深入原理
- 判断依据：源同步总线（数据与 strobe/clock 同源）→数据相对随路时钟等长；时钟分发类→各接收端相对主时钟等长。
- 等长容差由数据速率决定：速率越高容差越小，经验 $tol \approx 0.1\times UI$（单位间隔）对应长度再换算。
- 为什么重要：BANK0 多为对外高速接口，等长差超标直接表现为通信误码率飙升。

🛠 设计实例/操作
1. 例：BANK0 出 1 对 LVDS 时钟 + 8 位 LVDS 数据（源同步），以时钟对长度为基准，8 位数据各自加蛇形到 ±25mil。
2. 例：普通 GPIO（LED、按键）不做等长，可直接略过以省时间。

⚠️ 常见误区
- 不分信号类型一律等长，徒增串扰与绕线难度。
- 把 LVDS 对间（两对之间）误当成要对内那样严格。

📌 要点速记
- 先判信号类型再决定是否等长。
- 源同步总线：数据相对随路时钟等长。
- 普通 GPIO 无需等长。
- 容差随速率收紧。
- BANK0 完成即标记，避免重复。

🔗 承上启下
BANK0 等长完，继续 BANK7（第 45 讲）。

## 第45讲：FPGA-BANK7 信号时序等长

📖 这一集讲什么
BANK7 在逻辑派上往往挂着 DDR 相关或高速配置/通信接口。若 BANK7 也连有源同步并行信号，等长方法同前：以随路时钟/选通为基准做组内等长。本集强调"跨 BANK 信号等长不要混基准"——每个接口用自己的时钟作参考。

🔬 深入原理
- 跨 BANK 的同源总线（如一组总线分布在 BANK0 与 BANK7）仍属同一源同步组，应相对同一随路时钟等长，不因 BANK 边界而分开处理。
- 过孔延迟一致性：同一组内信号尽量走相同层数、相同过孔数，减少系统偏差。
- 为什么重要：分组基准搞错，等长等于白做。

🛠 设计实例/操作
1. 例：某高速 ADC 接口数据线横跨 BANK0/BANK7，统一以 ADC 输出的 DCO（数据时钟）为基准，所有 DQ 调到 ±20mil，不按 BANK 切开。
2. 例：BANK7 上的 SPI（相对 SCK）做 ±50mil 粗等长即可。

⚠️ 常见误区
- 同一总线因跨 BANK 被切成两组、各用各的时钟基准。
- 不同过孔数导致等长"表面达标、实际时延差"。

📌 要点速记
- 同一总线跨 BANK 仍用同一基准时钟。
- 组内过孔数尽量一致。
- BANK7 普通信号按类型决定等长。
- 精细信号 ±20mil，普通 ±50mil。
- 等长以"时延"为准，含过孔。

🔗 承上启下
BANK7 完，第 46 讲做 BANK1 等长。

## 第46讲：FPGA-BANK1 信号时序等长

📖 这一集讲什么
BANK1 在前面第 30 讲已完成布线，本集补充等长。若 BANK1 含与 MCU 的并行总线、或差分调试接口，按对应规则等长。重点提醒：MCU↔FPGA 并行总线中，"时钟/选通"由哪一侧发出，哪一侧就是基准。

🔬 深入原理
- 主从判定：谁发随路时钟，谁就是等长基准端；所有数据相对该时钟等长。
- 若存在双向总线（如异步 FIFO），以双方约定的采样边沿参考信号为基准。
- 为什么重要：MCU 与 FPGA 间总线不等长，高速下会出现偶发数据错位，表现为"偶尔死机"。

🛠 设计实例/操作
1. 例：MCU 以 SCLK 向 FPGA 发 16 位数据，把 16 位数据相对 SCLK 等长到 ±50mil。
2. 例：BANK1 上一对调试用 LVDS，对内 ≤5mil，对间无需严格。

⚠️ 常见误区
- 把双向异步总线硬套源同步等长规则。
- 基准选错（以数据线为基准去调时钟）。

📌 要点速记
- 先定基准时钟（发出方）。
- 源同步总线数据相对基准等长。
- 异步总线不盲目等长。
- 差分对对内 ≤5mil。
- BANK1 完成，进度过半。

🔗 承上启下
BANK1 等长完，第 47、48 讲收尾 BANK3、BANK2 等长。

## 第47讲：FPGA-BANK3 信号线时序等长

📖 这一集讲什么
BANK3 布线在第 32 讲完成，本集对其中的等长需求做收尾。BANK3 若有 LVDS 差分对（如连接外部高速器件），重点是"对内等长 + 必要时对间相对随路时钟等长"；若只是普通 IO，则无需等长，跳过即可，避免无用蛇形引入串扰。

🔬 深入原理
- 差分对内时延差直接降低共模抑制：对内偏差 $\delta$ 引起的峰值共模电压约 $V_{cm}\approx V_{diff}\cdot \frac{\delta}{UI}$。
- 对间等长只在该接口为源同步多通道时才需要（如第 43 讲 HDMI）。
- 为什么重要：对不需要等长的信号强行等长，反而增加耦合与 EMI。

🛠 设计实例/操作
1. 例：BANK3 中 2 对 LVDS 到外部传感器，各自对内调到 ≤5mil；若传感器要求数据相对通道时钟等长，再补对间 ±25mil。
2. 例：确认 BANK3 的 LED/GPIO 段不做任何蛇形。

⚠️ 常见误区
- 盲目给所有差分对加对间等长。
- 对内没调好就先调对间，本末倒置。

📌 要点速记
- BANK3 差分对内优先 ≤5mil。
- 对间等长按需（源同步多通道才做）。
- 普通 IO 不蛇形。
- 先内后对，顺序别反。
- 无用等长 = 额外风险。

🔗 承上启下
BANK3 等长完，第 48 讲做 BANK2 等长，FPGA 全 BANK 等长收尾。

## 第48讲：FPGA-BANK2 信号线时序等长

📖 这一集讲什么
BANK2 布线在第 31 讲完成，本集收尾其等长工作。逻辑派 BANK2 多为通用 IO/外设，等长需求少；如有差分或源同步接口，方法同前。至此 FPGA 所有 BANK（0/1/2/3/7）的布线与等长全部完成。

🔬 深入原理
- 收尾核对：用"Matched Length"规则列出所有等长组，确认无红色超差项。
- 过孔延迟一致性再次复核：同一组内过孔数一致。
- 为什么重要：这是等长阶段最后一道闸，漏一组等于埋一个隐患。

🛠 设计实例/操作
1. 例：检查 BANK2 是否有遗留差分对，对内补到 ≤5mil；无则跳过。
2. 例：打开 `PCB 面板 → Matched Length`，勾选所有组，导出超差清单，对照修改。

⚠️ 常见误区
- 以为"最后一组不重要"草草收场。
- 忘了把本讲修改过的线重新跑等长规则。

📌 要点速记
- BANK2 多为普通 IO，按需等长。
- 用 Matched Length 面板全量核查。
- 过孔一致性再确认。
- FPGA 各 BANK 等长至此全完。
- 导出长度报告留档。

🔗 承上启下

## 第49讲：TF 卡信号线时序等长

📖 这一集讲什么
TF（microSD）卡接口走 SDIO 总线：CLK、CMD、DAT[0..3]。速率相对 DDR/HDMI 较低（默认 25MHz，高速模式 50MHz，UHS 可达 100MHz+）。等长要求宽松，但做好能提升稳定性与兼容性。本集讲 TF 卡等长实务。

🔬 深入原理
- SDIO 为源同步：DAT 相对 CLK 采样。低速模式（≤50MHz）长度差几十 mil 无碍；UHS-I（100MHz+）建议 DAT 相对 CLK ≤? 经验 ±50~100mil 已很宽松，关键仍是阻抗与参考面。
- 阻抗：CLK 单端 50Ω，所有线紧邻 GND。
- 为什么重要：TF 卡常见故障是"偶尔读不出"，多半是电源/上拉/等长综合问题，而非单纯等长。

🛠 设计实例/操作
1. 例：把 DAT0..3 与 CMD 相对 CLK 粗等长到 ±50mil（用短蛇形即可），CLK 尽量短而直。
2. 例：确认 TF 卡座每个电源/地引脚都有独立过孔到平面，CLK 两侧加地屏蔽。

⚠️ 常见误区
- 在低速 TF 卡上过度等长，浪费布线空间。
- 忽略 CLK 上拉（按卡规范）与电源去耦，只盯等长。

📌 要点速记
- TF 卡等长宽松，±50mil 足够。
- CLK 单端 50Ω，短而直。
- 电源/地上拉/去耦比等长更关键。
- 高速 UHS 模式再收紧容差。
- 全板等长阶段至此全部完成。

🔗 承上启下
所有信号等长结束，第 50 讲打"板边缝合地过孔"，从屏蔽角度收尾。

## 第50讲：板边缝合地过孔的添加

📖 这一集讲什么
"缝合地过孔（Stitching Vias）"是在板边、连接器周围、高速信号两侧规则地打一排 GND 过孔，把顶层与底层 GND、以及内层 GND 平面"缝"成一体，形成屏蔽腔与连续回流。本集讲何时打、怎么打、打多密。

🔬 深入原理
-  shielding 间距经验：过孔间距 $s \le \lambda/20$（最高关注频率 $\lambda$），例如 1GHz（$\lambda_{FR4}\approx 20\,\text{cm}$）则 $s\le 1\,\text{cm}$；常用 1/8~1/10 英寸网格也够用。
- 板边过孔还能抑制边缘辐射（边缘场泄漏）并提升 EMC。
- 为什么重要：地平面若只靠零星过孔连接，高频回流会"抄近路"绕行，产生辐射与串扰。

🛠 设计实例/操作
1. 例：沿板四边每 100mil 打一个 GND 过孔，形成"地墙"；HDMI/TF 连接器座四周加密到 50mil。
2. 例：在 DDR3 区域两侧、FPGA 与DDR 之间的"净空带"打地过孔阵列，降低组间串扰。

⚠️ 常见误区
- 只在顶层打地过孔，没连到内层 GND 平面（孔要贯穿所有 GND 层）。
- 过孔打在信号线禁布区外却忘了连接 GND 网络。

📌 要点速记
- 板边/连接器/高速带打地缝合过孔。
- 间距按 $\lambda/20$，常用 50~100mil。
- 过孔须贯穿所有 GND 层才有效。
- 地墙提升 EMC、降串扰。
- 打了要连 GND，非空孔。

🔗 承上启下
屏蔽地墙完成，第 51 讲进入正式的 DRC 全板检查。

## 第51讲：PCB DRC 检查

📖 这一集讲什么
DRC（Design Rule Check，设计规则检查）是交给工厂前的"体检"。它按你设定的规则（线宽、间距、孔径、环宽、短路、未连等）扫描全板，列出所有违规。本集讲必查项与排错顺序，避免被几千条报错淹没。

🔬 深入原理
- 常见规则类别：
  - Clearance（间距）：线与线、线与焊盘最小间隙（常 4~6mil）。
  - Width（线宽）：最小/最大线宽（电源更宽）。
  - Hole Size / Annular Ring（孔径/环宽）：过孔与焊盘环宽防破孔。
  - Un-Routed / Short（未连/短路）。
  - Silk Over Pad（丝印压焊盘）、Component Clearance（元件间距）。
- 为什么重要：DRC 不过 = 工厂做不出或做出废品。

🛠 设计实例/操作
1. 例：先跑"Un-Routed"看有无漏连；再跑 Clearance 处理间距；最后 Silk/Placement 收尾。
2. 例：对批量相同违规（如某封装所有丝印压焊盘），用 `Tools → Find Similar` 批量改封装库，而非逐个修。

⚠️ 常见误区
- 一看到上千报错就放弃，其实大多是可批量处理的同类问题。
- 把规则调得极宽松"骗过"DRC，等于没检查。

📌 要点速记
- 按"未连→间距→孔径→丝印→间距"顺序查。
- 同类违规批量改库，不乱点。
- 规则要合理，不可为过而松。
- 0 报错（或仅确认无误的警示）才交付。
- DRC 是出厂前最后硬闸。

🔗 承上启下
DRC 通过后，第 52 讲做最后一轮"PCB 优化"收拾视觉与工艺细节。

## 第52讲：PCB 优化

📖 这一集讲什么
这里的"优化"指交付前的工艺与观感打磨：泪滴（Teardrop）加固、丝印避让、孤铜（Dead Copper）清理、铺铜修整、测试点规整。它不改变电气性能，但影响良率、可制造性与调试便利性。

🔬 深入原理
- 泪滴：在走线与焊盘/过孔连接处加渐变过渡，抗蚀刻/热应力断线，提升机械强度。
- 孤铜：无连接的悬浮铜皮会成天线、受热翘曲，应删除或打孔接到网络。
- 为什么重要：工厂蚀刻时细颈易断；孤铜引起 EMC 与焊接问题。

🛠 设计实例/操作
1. 例：`Tools → Teardrops` 全板加泪滴，再 DRC 确认泪滴未引入间距违规。
2. 例：用 `Polygon → Pour Manager → Repour` 重铺铜；删除孤立小铜皮；把测试点统一放到板边便于探针。

⚠️ 常见误区
- 加泪滴后不再跑 DRC，结果泪滴造成新间距违规。
- 留大量孤铜"觉得铺满好看"，反而引入天线。

📌 要点速记
- 全板加泪滴提升可靠性。
- 清孤铜、重铺铜。
- 测试点规整到板边。
- 优化后必须再 DRC。
- 工艺细节决定良率。

🔗 承上启下
工艺优化完，第 53 讲调整丝印与 LOGO，准备出图。

## 第53讲：PCB 丝印调整以及 LOGO 文本添加

📖 这一集讲什么
丝印（Silkscreen）是板子上的白字——元件位号、方向标识、接口说明；LOGO 是品牌/项目标识。清晰丝印让焊接与调试事半功倍。本集讲丝印摆放规范与 LOGO 添加方法。

🔬 深入原理
- 丝印规范：位号放在元件外侧、不与焊盘重叠（DRC 的 Silk Over Pad 会报错）；方向点（1 脚标识）清晰；连接器旁标注引脚定义。
- 文字最小线宽/高度受工厂工艺限制（嘉立创丝印线宽 ≥? 常用 ≥4~5mil，字高 ≥0.8mm 才清晰）。
- 为什么重要：丝印混乱 = 焊接返工、调试抓瞎。

🛠 设计实例/操作
1. 例：把被元件压住的位号挪到旁边；给 J1（HDMI）、J2（TF）、P1（电源）加中文/英文标注。
2. 例：`Place → String` 放项目名；导入 LOGO（用 Logo 脚本把图片转成丝印线条）放到板角空白处。

⚠️ 常见误区
- 丝印压在焊盘/测试点上，焊接后看不见且易桥接。
- LOGO 放在铺铜区却没设成禁止铺铜，被铜皮吃掉。

📌 要点速记
- 位号不压焊盘，方向标识清晰。
- 连接器标注引脚定义。
- 丝印线宽/字高符合工厂下限。
- LOGO 放空白区并禁止铺铜覆盖。
- 丝印是"可制造性"的门面。

🔗 承上启下
丝印 LOGO 定稿，第 54 讲导出全套生产资料文件。

## 第54讲：生产资料文件输出

📖 这一集讲什么
设计完成，要交给 PCB 工厂与贴片厂的就是"生产资料"。核心是一组 Gerber（光绘）文件 + 钻孔文件 + 叠层说明，外加 BOM（物料表）与坐标文件（贴片用）。本集逐项讲导出什么、怎么设。

🔬 深入原理
- Gerber（RS-274X）分层：GTL（顶层走线）、GTS（顶层阻焊）、GTO（顶层丝印）、GTP（顶层锡膏/钢网）、GND/PWR 内层、GBL（底层）等；每层一个文件。
- 钻孔：Excellon 格式，含通孔/盲埋孔尺寸。
- 坐标文件（Pick & Place / Centroid）：元件中心坐标 + 旋转角度，供贴片机用。
- 为什么重要：文件缺层/错位 = 工厂做错板、贴错件。

🛠 设计实例/操作
1. 例（Altium）：`File → Fabrication Outputs → Gerber Files`，选需要层，格式 2:4，生成；再 `NC Drill Files` 导出钻孔；`Assembly Outputs → Generates pick and place` 出坐标。
2. 例：导出 `ODB++` 也可（单文件含全部信息）。BOM 从 `Reports → Bill of Materials` 导出 CSV/Excel。

⚠️ 常见误区
- 忘导出阻焊/钢网层，工厂无法做绿油与锡膏。
- 坐标文件旋转角度与封装库不一致，贴片机吸反元件。
- Gerber 精度 2:3 不够，细间距用 2:4。

📌 要点速记
- Gerber 每层一个文件（含走线/阻焊/丝印/钢网）。
- 必导 NC Drill 钻孔文件。
- 导出 BOM 与坐标（Centroid）供贴片。
- 精度用 2:4，阻抗板附叠层说明。
- 导出后自检层数与工厂要求一致。

🔗 承上启下
资料齐了，第 55 讲讲怎么下单（以嘉立创为例）与获取/核对资料。

## 第55讲：PCB下单介绍&资料获取

📖 这一集讲什么
最后一步是把生产资料交给工厂打样。以国内常用的嘉立创（JLCPCB）为例，讲上传 Gerber、选层数与工艺、阻抗控制、确认 eda 文件，以及下单后如何获取生产进度与 Gerber 预览。同时也说明从哪儿拿到"资料"——本项目的封装库、原理图、BOM 等工程文件。

🔬 深入原理
- 6 层板下单要点：在订单页选"6 层"、板厚（常 1.6mm）、最小线宽/间距（本项目用 4/4 或 5/5mil）、孔径；若需阻抗控制，勾选"阻抗"并填写目标（单端 50Ω、差分 100Ω），工厂会按叠层反推线宽。
- 资料获取：工程文件（.SchDoc/.PcbDoc）、Gerber 压缩包、BOM、坐标文件都应归档到项目目录，便于复投与维护。
- 为什么重要：工艺选错（如没勾阻抗）板子能做出来但高速性能不保；资料散落则无法复现。

🛠 设计实例/操作
1. 例：把第 54 讲导出的 Gerber 打包上传嘉立创，选 6 层、1.6mm、沉金（ENIG，适合 BGA 细间距）、阻抗控制填 50/100Ω；确认预览层对齐后提交。
2. 例：在订单附件附 `叠层说明.txt`（芯厚/介质/铜厚），方便工厂核对；保存 BOM 用于后续 SMT 贴片下单。

⚠️ 常见误区
- 高速板忘勾"阻抗控制"，工厂按普通板做，叠层线宽不匹配目标阻抗。
- 只传 Gerber 不传 BOM/坐标，贴片还要再问。
- 表面处理选错（HASL 对细间距 BGA 不友好，宜 ENIG）。

📌 要点速记
- 6 层板选对层数/板厚/最小工艺。

## 第56讲：PCB DRC 检查

### 📖 这一集讲什么

DRC（Design Rule Check，设计规则检查）是把"你脑子里的规则"和"板子上的实际图形"做一次全自动比对。前面我们花了几十讲设置线宽、间距、阻抗、差分、等长、过孔尺寸，这些规则一直在后台默默盯着；但布线过程中我们经常临时改推挤、临时拉小间距、临时挪器件，规则违例就会悄悄堆积。DRC 就是布线收尾后的"总考试"。

操作上非常简单：在 PCB 编辑器里执行一次全局 DRC（Altium 里是 Tools → Design Rule Check，勾选"Online + Batch"里的 Batch 项；立创 EDA 专业版是"设计 → 检查 DRC"），软件跑完会生成一份报告，列出每一条违例的规则名、涉及网络、坐标。然后逐条双击定位、逐条修掉、再跑一次，直到报告干净（或者只剩下你确认可以忽略的项）。

初学者最容易犯的错是"看到一堆红叉就懵了"。正确心态是：DRC 报告不是判决书，是待办清单。先按类别分组——间距类、连接类（未布线/开路）、阻抗与线宽类、等长类、丝印与阻焊类、制造工艺类——一类一类清，效率比一条一条点高得多。

### 🔬 深入原理

DRC 的本质是几何求交 + 网络连通性判定。软件把每个铜图元膨胀（offset）出一个"禁入环"，环半径等于规则要求的最小间距，再检查不同网络的膨胀区是否相交：

```
违例条件：dist(objA, objB) < Clearance(netA, netB, layer)
且  net(objA) ≠ net(objB)
```

必须重点关注的几类检查项，含义和后果如下：

| 检查类别 | 典型规则项 | 违例后果 |
|---|---|---|
| 电气间距 | Clearance（线-线/线-焊盘/铜皮-过孔） | 短路、爬电击穿、蚀刻桥连 |
| 连接性 | Un-Routed Net / Un-Connected Pin | 断网，板子直接不工作 |
| 短路 | Short Circuit | 两网络实连，最致命 |
| 线宽 | Width（Min/Preferred/Max） | 阻抗跑偏、载流不足 |
| 过孔 | Hole Size / Annular Ring | 厂家做不出或钻偏破环 |
| 阻焊/丝印 | Silk to Solder Mask、Silk to Silk | 丝印压焊盘、印不上 |
| 平面 | Power Plane Connect、Plane Clearance | 反焊盘过大割裂参考平面 |
| 制造 | Minimum Annular Ring、Board Outline Clearance | 超出嘉立创工艺能力 |

对 6 层高速板，有两条"DRC 报不出来但必须人工查"的隐性风险，这一集必须一起过一遍：

1. **参考平面完整性**。DRC 不会告诉你"这根 DDR3 数据线跨了分割"。回流路径断裂会让回流被迫绕行，环路面积 $A$ 增大，辐射与串扰同步恶化：$L_{loop} \propto A$，而串扰噪声 $V_n \propto M \frac{di}{dt}$。必须人工用"平面层单层显示 + 高亮网络"逐层扫一遍。
2. **换层过孔的回流伴地**。信号从 L1 换到 L4，参考平面从 GND(L2) 变成 GND(L5)，需要附近有缝合地过孔提供回流通道，否则等效串联电感抬高，边沿完整性变差。

阻焊桥（Solder Mask Sliver）也值得单独设一条规则：细间距 BGA 之间若阻焊桥宽度小于工艺能力（常见下限 0.1 mm），厂家会直接开天窗，回流焊时极易连锡。

### 🛠 设计实例/操作

**实例一：DDR3 区域间距违例批量清理**

跑完 DRC，报告里出现 47 条 `Clearance Constraint (Gap < 4mil)`，集中在 DDR3 BGA 扇出区。定位后发现是扇出过孔到相邻数据线的间距被推挤压到 3.4 mil。处理步骤：

1. 先判断规则本身是否合理。DDR3 区域我们设的是 4 mil 间距，嘉立创标准工艺（≥5 mil 线宽/间距为标准价，4 mil 需升级工艺）能做，规则不动。
2. 用"高亮违例"模式打开，把该区域布线整体向外让 1～2 mil，优先移动过孔而不是移动线——过孔一动，扇出结构整体呼吸开。
3. 若局部实在挤不开，允许该段走线收窄到 3.5 mil，但**收窄长度必须小于 $\lambda/20$ 对应的电长度**，避免形成明显的阻抗不连续段。DDR3-1600 上升沿约 0.2 ns，对应临界长度约 25 mm，局部 2～3 mm 收窄可接受。
4. 重跑 DRC 确认归零。

**实例二：Un-Routed Net 的定位与判定**

报告里出现 3 条 `Un-Routed Net`，分别是 `NC1`、`TEST_PAD2`、`GND`。逐条分析：

- `NC1`：原理图上确实是空引脚，可在规则里设 Ignore，或在原理图放置 No-ERC 标记后重新更新 PCB。
- `TEST_PAD2`：测试点漏连，必须补线，属真实错误。
- `GND`：不是真的没连，而是铺铜后有一小块孤铜（Dead Copper）被围死。解决办法是加缝合地过孔把孤铜接回主地平面，或删除该孤铜。**孤铜绝对不能留**——它是天线，会在高频下产生谐振辐射。

### ⚠️ 常见误区

- **只跑 Online DRC 不跑 Batch DRC**。Online 只检查你当下操作的对象，历史遗留违例根本不报。收尾必须跑一次全局 Batch。
- **规则没使能就跑 DRC**。Altium 的 DRC 对话框里每条规则有独立的 Online/Batch 勾选框，很多人规则写得漂亮但 Batch 没勾，报告一片空白，误以为板子完美。
- **把违例"忽略"当成"修复"**。Ignore 只应用于确认无害的项（如 NC 引脚、Mark 点间距），电气类违例一条都不能忽略。
- **忘记检查板框内外**。器件、丝印、铜皮跑到板框外或压在板边，V-Cut/铣槽时会被切掉。板边到铜的距离建议 ≥0.3 mm。
- **认为 DRC 干净 = 板子没问题**。DRC 查的是几何规则，查不了跨分割、查不了回流、查不了拓扑合理性。这三样必须靠人眼和经验。

### 📌 要点速记

1. DRC 是几何求交 + 连通性判定，收尾必须跑**全局 Batch DRC**，且确认每条规则的 Batch 勾选已使能。
2. 违例按类别批量清理：间距类 → 连接类 → 线宽/过孔类 → 阻焊丝印类，效率远高于逐条点。
3. `Un-Routed Net` 要区分真断线、NC 引脚和铺铜孤铜三种情况，**孤铜必须消灭**。
4. DRC 报不出跨分割、回流断裂、换层缺伴地过孔，这三项必须人工逐层目视复查。
5. 局部为规避违例而收窄线宽，长度须远小于上升沿对应的临界长度，否则会引入可观的阻抗不连续。

### 🔗 承上启下

上一讲我们沿板边加完了缝合地过孔，铜面工作基本完成；这一讲用 DRC 做一次全面体检，把布线阶段积累的所有几何违例清零。DRC 干净只是"及格线"，还谈不上"好"。下一讲（第57讲）进入 PCB 优化，处理那些 DRC 查不出来但直接影响良率和性能的问题——线角、铜皮、过孔分布、器件受力等等。

## 第57讲：PCB 优化

### 📖 这一集讲什么

DRC 通过之后，板子"能用"了，但离"好用、好造、好维修"还有距离。这一集做的是 PCB 优化——在不改变电气连接的前提下，把布线做得更整齐、更抗干扰、更容易生产。

可以理解成写完代码后的重构：功能没变，可读性、健壮性、性能都上一个台阶。优化的对象主要是四类：走线形态（拐角、长度、抖动）、铜皮质量（孤铜、尖角、狭缝、开窗）、过孔分布（缝合密度、去耦回路）、以及可制造性（热焊盘、阻焊、拼板兼容性）。

优化的顺序建议自顶向下：先整体看板（缩到全板视图，找视觉上"乱"的区域），再分层看（每层单独显示，看铜的连续性），最后分模块看（DDR3、HDMI、电源逐块细抠）。

### 🔬 深入原理

优化不是审美问题，每一项背后都有物理依据。

**1. 走线拐角。** 直角走线在拐角处线宽等效变宽（对角线长度是边长的 $\sqrt{2}$ 倍），局部阻抗下降，产生反射。虽然现代研究表明在几 GHz 以下直角的影响远小于早期认知，但直角尖端在蚀刻时容易残留、在高电压下容易尖端放电，所以工程上一律用 45° 斜角或圆弧走线。

**2. 铜皮质量。** 铜皮上的狭缝会强迫回流绕行。回流路径长度增加 $\Delta l$，等效增加的回路电感约为：

$$L \approx 0.2 \cdot l \cdot \left[\ln\left(\frac{2l}{w+h}\right) + 0.5 + 0.2235\frac{w+h}{l}\right] \quad (\text{nH，} l,w,h \text{单位 mm})$$

也就是说狭缝越长，附加电感越大，地弹（Ground Bounce）越严重：$V_{gb} = L\frac{di}{dt}$。DDR3 数据线同时翻转时 $di/dt$ 极大，几 nH 的额外电感就足以吃掉相当一部分噪声裕量。

**3. 过孔与去耦回路。** 去耦电容的有效性由整个回路的等效串联电感决定：

$$L_{total} = L_{ESL} + L_{via} + L_{trace}$$

其中过孔电感的工程估算：

$$L_{via} \approx 5.08 \cdot h \left[\ln\left(\frac{4h}{d}\right) + 1\right] \quad (\text{nH，} h,d \text{单位 inch})$$

对 1.6 mm 厚 6 层板，一个 0.3 mm 孔径的全通孔约 1.2～1.5 nH。所以去耦电容"贴得近"只解决了 $L_{trace}$，**过孔必须打在焊盘边上并且尽量成对（一进一出）**，双过孔并联可把 $L_{via}$ 减半。

**4. 铜的热均衡。** 大面积铜与细线混排会造成回流焊时热容差异，产生立碑（Tombstoning）。所以连接大铜皮的元件焊盘必须使用热焊盘（Thermal Relief）而非直连。

### 🛠 设计实例/操作

**实例一：6 层板叠层下的电源铜皮优化**

典型 6 层叠层（本课程使用的结构）：

| 层 | 用途 | 优化关注点 |
|---|---|---|
| L1 | 顶层信号 + 器件 | 拐角、丝印避让、去耦过孔 |
| L2 | GND 完整平面 | 严禁走线破坏，只允许极少数短跳线 |
| L3 | 内层信号（DDR3 地址等） | 参考 L2/L4，避免跨分割 |
| L4 | PWR 分割平面 | 分割缝要与上下层信号错开 |
| L5 | GND 完整平面 | 与 L2 一起做双面参考 |
| L6 | 底层信号 | 缝合地过孔、测试点 |

L4 是电源分割层，多路电压（如 3V3、1V8、1V5、VTT）共用一层，优化时重点做三件事：

1. **分割缝对齐检查**。把 L3、L4、L5 同时点亮，确认 L3 上没有任何信号横跨 L4 的分割缝。若有，要么把该信号挪到不跨缝的路径，要么把缝挪开。
2. **铜岛宽度校核**。DDR3 的 VTT 电流可能达到几百 mA，铜岛最窄处要满足载流。1 oz 铜内层，10 ℃ 温升下的经验值约 **1 mm 线宽承载 1 A**（内层散热差，取外层的一半）。VTT 铜岛最窄处不应小于 1 mm。
3. **消除尖刺与细颈**。铺铜后常出现细如发丝的铜颈，蚀刻时可能断裂造成开路。设置最小铜宽（Minimum Solder Mask Sliver / Copper Sliver）并手动画禁铺区消除。

**实例二：DDR3 区域的走线抖动整理**

DDR3 数据线在等长绕线后往往留下大量"锯齿抖动"。优化动作：

- 蛇形线（Accordion）的**振幅间距 $S$ 应 ≥ 3 倍线宽 $W$**（$S \ge 3W$，越大越好，理想 $S \ge 4H$，$H$ 为介质厚度），否则蛇形段自耦合会让等效延时小于几何长度，等长白等。
- 蛇形线尽量放在靠近驱动端或靠近负载端的一侧，不要在中间反复折返。
- 每根数据线的过孔数量保持一致。**过孔延时约 5～10 ps/个**，一根线多一个过孔就相当于多了约 1 mm 的走线长度（内层信号约 180 ps/inch ≈ 7 ps/mm），必须在等长中折算或统一过孔数。
- 清理"回头线"（走过去又拐回来），这类线在高速下形成短截线（Stub），产生谐振。

### ⚠️ 常见误区

- **认为优化只是"变好看"**。铜皮细颈、孤铜、蛇形间距不足都是实打实的电气/良率问题。
- **等长做完就不敢动线**。优化时动了线一定要重新查等长，很多人改完形态忘了复查，等长直接跑飞。
- **无脑加过孔**。缝合地过孔不是越多越好，过密会把内层平面打成"筛子"，反而破坏平面连续性。经验：缝合过孔间距取 $\lambda/20$ 对应值，对 1 GHz 谐波约 15 mm 间距足够，板边和换层密集区可加密到 5 mm。
- **忽略丝印与阻焊的优化**。这属于下一讲，但优化阶段就要预留空间，别等丝印时发现无处可放。
- **优化后不重跑 DRC**。任何铜面改动都必须以一次全新的 Batch DRC 收尾。

### 📌 要点速记

1. 优化目标是三个"好"：好用（电气）、好造（良率）、好修（可维护），三者都有物理依据。
2. 拐角一律 45°/圆弧；铜皮消除孤铜、尖刺、细颈；连大铜皮的焊盘用热焊盘。
3. 去耦电容过孔要"贴焊盘 + 成对打"，双孔并联把 $L_{via}$ 减半，这是 PDN 优化性价比最高的动作。
4. 蛇形线间距 $S \ge 3W$（最好 $\ge 4H$），过孔数量按线统一，动线后必须复查等长。
5. 逐层单独显示检查参考平面连续性，是 6 层高速板优化中不可省略的一步。

### 🔗 承上启下

上一讲 DRC 让板子"合规"，这一讲优化让板子"优秀"。铜面到此定稿，接下来就是给板子"写字"和"打包"。下一讲（第58讲）处理丝印调整与 LOGO/文本添加，让板子在装配和维修环节可读、可查、可追溯。

## 第58讲：PCB 丝印调整以及 LOGO 文本添加

### 📖 这一集讲什么

丝印（Silkscreen）是印在阻焊层之上的白色（或黄/黑）油墨字符层，包括位号（R1、C12、U3）、极性标识、管脚 1 标记、接口说明、板名版本、生产批次、LOGO 与合规标志。它不导电、不参与电气功能，但决定了这块板子在**贴片、焊接、调试、返修、出货**五个环节的效率。

很多初学者布完线就直接出 Gerber，结果丝印全挤在一起、位号压在焊盘上、极性标记被器件盖住。到了工厂，SMT 工程师看不懂哪个是 1 脚，只能反复问你；到了调试台，你自己都找不到 R37 在哪。所以丝印调整是一项必做的、需要一两个小时耐心的收尾工作。

具体操作就是：打开丝印层，关掉不必要的层（只留 Top Layer + Top Overlay + Multi-Layer），然后用软件的"位号自动排布"（Altium 里是 Component Text Position / 立创 EDA 的"丝印整理"）先做一遍粗排，再手工逐个微调那些自动排不好的位置。

### 🔬 深入原理

丝印看似简单，但有明确的工艺约束，超出约束工厂就印不出来或印歪。

| 参数 | 嘉立创常规工艺推荐值 | 说明 |
|---|---|---|
| 字符线宽（笔宽） | ≥ 0.15 mm（6 mil） | 小于此值印刷模糊或断线 |
| 字符高度 | ≥ 0.8 mm（32 mil），推荐 1.0 mm | 高宽比建议 5:1 |
| 丝印到焊盘间距 | ≥ 0.15 mm | 压焊盘会被工厂自动"去除" |
| 丝印到板边 | ≥ 0.2 mm | 防止 V-Cut 切掉 |
| 丝印线宽/高度比 | 约 1:5 ～ 1:6 | 保证可辨识 |

**为什么丝印不能压焊盘？** 丝印油墨是绝缘的。若印到焊盘上，回流焊时锡膏无法在该区域润湿，形成虚焊或少锡。因此绝大多数板厂的 CAM 工程会自动做"丝印避让阻焊开窗"处理——把压在开窗上的丝印部分**直接删掉**。结果就是你的 `R12` 变成了 `R1?` 或者干脆消失。所以宁可自己提前挪好，也不要交给 CAM 去砍。

**LOGO 的本质。** 丝印 LOGO 是一张单色位图转成的矢量填充区域（Region / Fill），放在 Top Overlay 层。转换时要注意：位图必须是**纯黑白二值图**，灰度和抗锯齿边缘转出来会变成一堆碎小多边形，让 Gerber 文件巨大且印刷发毛。转换后检查最小笔画宽度是否仍 ≥ 0.15 mm。

**合规与追溯标识。** 量产板通常需要加：板名与版本号（如 `LOGIC-PI-6L V1.0`）、日期码或批次位、RoHS/CE/FCC 标志（若适用）、以及生产厂商代码。版本号建议同时做一个"丝印版本 + 铜层版本"，铜层版本刻在内层或底层铜上，即使丝印磨掉也能追溯。

### 🛠 设计实例/操作

**实例一：BGA 区域与密集模块的丝印策略**

FPGA/DDR3 的 BGA 下方和周边极其拥挤，丝印根本放不下。工程做法是：

1. **BGA 本体只保留一个 1 脚标识**（一个实心三角或圆点，放在 BGA 丝印框外的 A1 角），本体位号 `U2` 放在器件旁边空白处，字高 1.2 mm，加粗。
2. **BGA 周边的去耦电容位号全部隐藏**。这些电容型号一致、方向无关，SMT 靠坐标文件贴片，不靠丝印。隐藏后视觉立刻清爽。
3. 隐藏的位号信息通过 **Assembly 层（装配图层）** 输出。装配图不印在板上，但会随生产资料交给工厂，SMT 核对时使用。这是"板面干净 + 信息完整"的标准解法。

**实例二：极性器件的丝印规范**

| 器件类型 | 必须的丝印标识 |
|---|---|
| 电解电容/钽电容 | 正极加 `+`，或负极侧加填充半圆 |
| 二极管/LED | 阴极加竖线（丝印框一侧封口） |
| IC/连接器 | 1 脚圆点或斜切角 + 丝印框缺口 |
| 排针/排母 | 1 脚方形焊盘 + 丝印 `1` 字符 |
| 晶振 | 1 脚点（四脚晶振必须标） |

关键点：**极性标记必须画在器件本体轮廓之外**，因为器件贴上去后会盖住轮廓内部。一个常见的惨案是把 `+` 号画在电解电容的圆形轮廓里，装完机根本看不见，返修时只能查图纸。

**实例三：接口丝印的可用性设计**

排针、拨码开关、跳线帽这类需要用户操作的接口，丝印要写"人话"：

- 排针旁标注每个脚的功能缩写：`3V3 / TX / RX / GND`，而不是 `P1.1 / P1.2`。
- 拨码开关标注 `ON` 方向和每位含义。
- 电源输入口标注电压范围和极性：`DC 5V 2A`。
- 板边留一块空白区做"版本 + 二维码"，二维码可放产品文档链接。

丝印字符方向也有讲究：整板字符应统一为**从左到右读（0°）或从下往上读（90°）**两种方向，避免出现 180°/270° 的倒字。这样测试人员转动板子一次就能读完所有字符。

### ⚠️ 常见误区

- **位号压焊盘/压过孔**。会被 CAM 砍掉，且可能造成焊接不良。收尾必须开一条 `Silk to Solder Mask ≥ 0.15 mm` 的 DRC 规则专门查这个。
- **字体太小追求"密"**。0.6 mm 高的字肉眼看不清、印不清，等于没印。宁可隐藏，不要印糊。
- **LOGO 用灰度图直接转**。产生上万个碎多边形，Gerber 暴涨、印刷发毛，必须先二值化。
- **忘记底层丝印镜像**。Bottom Overlay 的文字在软件里看是反的才对，如果正着看说明镜像设错了，印出来是反字。
- **只做丝印不做装配图**。隐藏位号后如果没有 Assembly 层输出，SMT 无法核对，返修更是灾难。
- **丝印跑到板边或拼板工艺边上**。V-Cut 分板后字被切一半。

### 📌 要点速记

1. 丝印是**装配、调试、返修、追溯**的信息载体，工艺底线是线宽 ≥ 0.15 mm、字高 ≥ 0.8 mm、离焊盘 ≥ 0.15 mm。
2. 丝印压焊盘会被板厂 CAM 直接删除，必须自己提前避让，并用 DRC 规则兜底。
3. 密集区（BGA、DDR3）采取"隐藏位号 + 输出装配图"策略，板面干净且信息不丢。
4. 极性标记（`+`、阴极线、1 脚点）必须画在器件轮廓**外部**，装配后仍可见。
5. LOGO 必须由纯黑白二值图转换，转换后检查最小笔画宽度；底层丝印务必确认镜像正确。

## 第59讲：生产资料文件输出

### 📖 这一集讲什么

板厂不认识你的 `.PcbDoc` / `.epro` 工程文件，它们只认识一套标准化的制造数据。生产资料输出，就是把设计文件"翻译"成工厂能直接投产的格式包，通常叫 **Gerber 包**或**生产文件包**。

一套完整的 6 层板生产资料至少包含五类文件：

| 类别 | 文件内容 | 交给谁 |
|---|---|---|
| Gerber 层文件 | 6 层铜、2 层阻焊、2 层丝印、板框 | PCB 板厂 |
| 钻孔文件 | Excellon 钻带（通孔/盲埋孔）+ 钻孔报告 | PCB 板厂 |
| 叠层与工艺说明 | 层序、板厚、铜厚、阻抗要求、表面处理 | PCB 板厂 |
| 坐标文件 | Pick & Place（位号、X/Y、旋转角、层面） | SMT 贴片厂 |
| BOM + 钢网数据 | 物料清单 + Paste 层（钢网开孔） | 采购 + 钢网厂 |

输出操作在软件里就是几次导出：Gerber（RS-274X 格式）、NC Drill（Excellon 2）、Pick and Place（CSV）、BOM（Excel）。但**输出之后必须用 Gerber 查看器（CAM350、GerbView、或嘉立创的在线 Gerber 预览）重新打开检查一遍**——这一步是行业铁律，能拦下绝大多数低级致命错误。

### 🔬 深入原理

**1. Gerber 格式。** RS-274X（扩展 Gerber）把每一层描述成"用某个光圈（Aperture）沿某条路径曝光"。现代也可用 **Gerber X2** 或 **ODB++**，它们携带层属性、网络信息，减少人工沟通歧义。嘉立创等国内厂商对 RS-274X 支持最成熟，初学者用它最稳妥。

导出参数的标准设置：

```
格式:        RS-274X
单位:        mm（或 inch，全套统一）
精度:        4:4 (mm) 或 2:5 (inch)
零处理:      Suppress leading zeros（省略前导零）
坐标:        Absolute（绝对坐标）
孔径:        Embedded apertures（内嵌孔径，勿用外部 D 码表）
```

精度不足会造成坐标量化误差。4:4 精度在 mm 制下分辨率为 0.0001 mm = 0.1 µm，完全够用；若误选 2:3，分辨率只有 1 µm 的十倍，细间距 BGA 会明显走形。

**2. 6 层板必须额外说明的工艺参数。** 6 层板不像双面板"一张 Gerber 走天下"，必须随包附一份**工艺说明文档（README / 制造说明）**，写清：

- **叠层结构**：层序（L1 顶层 → L6 底层）、每层铜厚（外层 1 oz、内层 0.5 oz 是常见配置）、介质厚度、总板厚（如 1.6 mm ±10%）。
- **阻抗要求**：单端 50 Ω ±10%、差分 90 Ω（USB/HDMI 常用 100 Ω 差分，DDR3 差分时钟 100 Ω）±10%，并注明对应层与线宽/间距。**阻抗板必须勾选"阻抗控制"选项并额外付费**，否则厂家按普通板做，介质厚度随意调整，你算了半天的阻抗全部作废。
- **表面处理**：HASL（有铅/无铅喷锡）、ENIG（沉金）。**BGA 板强烈建议 ENIG**，因为喷锡表面不平整，细间距 BGA 焊球难以共面焊接。
- **阻焊颜色、丝印颜色、最小线宽/间距、最小孔径**。
- **过孔工艺**：过孔盖油（Tented）/塞孔（Plugged）/开窗。BGA 区域的过孔若在焊盘上（Via-in-Pad），必须做**树脂塞孔 + 电镀填平**，否则焊锡会顺过孔漏走造成空焊。

**3. 钻孔文件。** 6 层板若含盲埋孔，钻孔文件要按孔对分别输出，例如 `L1-L2`、`L1-L6`（通孔）、`L2-L5`。文件里必须明确金属化（PTH）与非金属化（NPTH）孔的区分——安装孔通常是 NPTH，若误标为 PTH，孔壁会镀铜并可能与内层短接。

**4. 钢网（Stencil）数据。** 钢网由 Paste 层（锡膏层）生成，激光切割在不锈钢片上。关键参数：

- **钢网厚度**：常规 0.12 mm；含 0.4 mm 间距 BGA 或 0201 器件时用 0.1 mm。
- **开孔缩放**：细间距器件的 Paste 开孔通常按焊盘缩小 5%～10%（面积比），防止连锡。
- **面积比（Area Ratio）** 判据，决定锡膏能否顺利脱模：

$$AR = \frac{A_{opening}}{A_{wall}} = \frac{L \times W}{2(L+W) \times T}$$

其中 $T$ 为钢网厚度。工程要求 $AR \ge 0.66$，低于此值锡膏留在钢网上，形成少锡/空焊。举例：0.25 mm × 0.25 mm 方孔、钢网 0.12 mm，$AR = \frac{0.0625}{2 \times 0.5 \times 0.12} = 0.52$，不合格，必须减薄钢网到 0.1 mm 才勉强达到 0.625，或改用阶梯钢网。

**5. 拼板（Panelization）。** 小板需要拼板以提高 SMT 效率。两种连接方式：

| 方式 | 适用 | 要点 |
|---|---|---|
| V-Cut（V 割） | 直边、矩形板 | 板边留 0.5 mm 禁布区，残留厚度约 1/3 板厚 |
| 邮票孔（Stamp Hole） | 异形板、带凸出 | 每段 5～6 个 φ0.5 mm 孔，间距 1 mm |

拼板还要加**工艺边**（宽 5 mm，供 SMT 传送轨道夹持）和 **Mark 点**（光学定位点，φ1 mm 裸铜 + φ2 mm 阻焊开窗，对角至少 3 个，全局 Mark 放工艺边，细间距 BGA 旁加局部 Mark）。

**实例二：导出后的 Gerber 复检清单（必做）**

用 Gerber 查看器加载全部层，逐项确认：

1. **层序对不对**：把 L1～L6 依次单独显示，确认 L2/L5 是完整地平面、L4 是电源分割层，没有把内层顺序搞反。**内层反了是 6 层板最致命的错误之一**，且板子做出来才发现。
2. **有没有缺层**：6 层板必须有 6 个铜层文件，少一个厂家可能按 4 层做。
3. **钻孔与焊盘是否对齐**：把 Drill 层叠在铜层上，看孔是否都落在焊盘中心。整体偏移说明原点设置不一致。
4. **板框闭合**：GKO 层必须是一条闭合曲线，有断口厂家无法识别外形。
5. **阻焊开窗**：确认所有焊盘都有开窗、所有过孔按预期盖油或开窗。
6. **负片层不要搞反**：若内层用负片（Negative）输出，务必在说明里注明，否则地和非地会完全反转。现代流程建议**统一用正片输出**，避免歧义。

### ⚠️ 常见误区

- **不做 Gerber 复检直接下单**。这是最贵的错误，几百块和几周时间打水漂。
- **阻抗板忘了勾"阻抗控制"**。板厂按常规叠层生产，介质厚度与你设计的不同，阻抗全跑偏，高速信号眼图崩溃。
- **单位/精度混用**。Gerber 用 mm、钻孔用 inch，或精度不一致，导致钻孔整体偏移。
- **NPTH 标成 PTH**。安装孔镀铜后可能与内层铜连通，装上金属螺柱直接短路。
- **Paste 层直接照搬焊盘尺寸**。细间距器件必然连锡，必须做缩放并校核面积比 $AR \ge 0.66$。
- **拼板没加工艺边和 Mark 点**。SMT 无法上机或无法定位，只能返工重排。
- **BOM 只写"电容 0603"**。必须写清容值、耐压、材质（X7R/X5R/C0G）、精度、封装、可选替代料，否则采购买错。DDR3 的去耦电容用 Y5V 材质会因直流偏压效应损失 70% 以上容量。

### 📌 要点速记

1. 生产资料 = Gerber + 钻孔 + 工艺说明 + 坐标/BOM/装配图 + 钢网数据，五类缺一不可。
2. 导出参数统一：RS-274X、mm、4:4 精度、绝对坐标、内嵌孔径。
3. 6 层板必须随包提供**叠层结构与阻抗要求说明**，并在下单时勾选阻抗控制，否则前面所有阻抗计算作废。
4. 钢网开孔面积比 $AR = \frac{LW}{2(L+W)T} \ge 0.66$，不达标需减薄钢网或用阶梯钢网。
5. 导出后必须用第三方 Gerber 查看器复检层序、缺层、钻孔对齐、板框闭合、阻焊开窗六项。

## 第60讲：PCB下单介绍&资料获取

### 📖 这一集讲什么

这是整套课程的收官。前面 59 讲我们从原理图分析一路做到生产资料输出，现在要把这个 Gerber 包真正变成一块摸得着的板子。这一集讲两件事：**怎么在嘉立创（或同类平台）下单**，以及**课程配套资料怎么获取、怎么继续学习**。

下单流程本身不难：注册账号 → 上传 Gerber 压缩包 → 平台自动解析并生成预览 → 逐项确认工艺参数 → 提交订单 → 支付 → 生产 → 发货。难点全在"逐项确认工艺参数"这一步。6 层板的下单选项比双面板多得多，而且**很多参数一旦下单就无法更改**，选错就是几百块和一周时间。

所以这一集的核心是一张下单核对表，下单前照着逐项打勾。

### 🔬 深入原理

**1. 为什么 6 层板贵这么多。** 双面板是"一次压合"，6 层板需要：内层图形制作 → 内层 AOI 检测 → 棕化 → 与半固化片（PP）多次叠合压合 → 钻孔 → 沉铜电镀 → 外层图形 → 外层蚀刻。工序几乎翻倍，且**压合对位精度**成为良率瓶颈，所以价格从几十元跳到数百元甚至上千元（视面积与工艺）。

**2. 叠层选择的电气含义。** 平台通常提供几种预设叠层供选择，例如 1.6 mm 板厚下的常见结构：

| 结构 | 铜厚配置 | 特点 |
|---|---|---|
| JLC06161H-1080 | 外层 1 oz / 内层 0.5 oz | 通用，介质分布均匀，适合阻抗控制 |
| JLC0616H-7628 | 外层 1 oz / 内层 1 oz | 载流强，但内层厚铜阻抗需重算 |

**关键点：选定的叠层必须与你在第10讲设置、第12讲用于阻抗计算的叠层一致。** 如果计算时按介质厚度 0.1 mm、$\varepsilon_r = 4.3$ 算出 50 Ω 对应 5.5 mil 线宽，而下单选了一个介质厚度 0.2 mm 的叠层，实际阻抗会显著偏高。微带线阻抗的近似关系：

$$Z_0 \approx \frac{87}{\sqrt{\varepsilon_r + 1.41}} \ln\left(\frac{5.98H}{0.8W + T}\right)$$

可见 $Z_0$ 随介质厚度 $H$ 单调上升。$H$ 翻倍，$Z_0$ 大约上升十几到二十欧姆，直接超出 ±10% 容差。

**3. 阻抗控制服务。** 勾选阻抗控制后，板厂会：按你指定的阻抗值反算实际叠层与补偿线宽（蚀刻会让线宽比设计值窄约 0.5～1 mil，厂家会做**蚀刻补偿**），生产后用 TDR（时域反射仪）在**测试条（Coupon）**上实测并出具阻抗测试报告。这份报告是高速板验收的凭证，务必索取。

**4. 表面处理的取舍。**

| 工艺 | 平整度 | 保存期 | 成本 | 适用 |
|---|---|---|---|---|
| 有铅喷锡 HASL | 差 | 长 | 最低 | 通孔件、粗间距 |
| 无铅喷锡 | 差 | 长 | 低 | RoHS 要求 |
| 沉金 ENIG | 优 | 12 个月 | 高 | **BGA、细间距、高频** |
| OSP | 优 | 3 个月 | 低 | 一次性焊接 |

本课程板含 FPGA 与 DDR3 的 BGA 封装，**必须选沉金 ENIG**。此外沉金表面的镍层电阻率较高，超高频（>10 GHz）微带线会有额外损耗，但对 DDR3-1600 / HDMI 1.4 这个频段完全可以接受。

### 🛠 设计实例/操作

**实例一：6 层板下单核对表**

| 序号 | 选项 | 本板取值 | 错选后果 |
|---|---|---|---|
| 1 | 板子层数 | **6 层** | 选 4 层内层直接丢失 |
| 2 | 板子尺寸 | 按板框实测填写 | 影响报价与拼板 |
| 3 | 板厚 | 1.6 mm | 影响过孔深径比与阻抗 |
| 4 | 叠层结构 | 与设计一致的指定叠层 | 阻抗全部跑偏 |
| 5 | 阻抗控制 | **勾选**，填 50 Ω 单端 / 100 Ω 差分 | 不勾选＝按普通板做 |
| 6 | 外层铜厚 | 1 oz | 载流与线宽匹配 |
| 7 | 内层铜厚 | 0.5 oz（或 1 oz） | 影响内层阻抗与载流 |
| 8 | 最小线宽/间距 | 按实际（如 4/4 mil） | 低于工艺能力会被退单 |
| 9 | 最小孔径 | 0.2 mm / 0.3 mm | 深径比超限做不出 |
| 10 | 过孔工艺 | 盖油（BGA 焊盘内过孔需塞孔树脂填平） | 漏锡、空焊 |
| 11 | 表面处理 | **沉金 ENIG** | 喷锡不平，BGA 焊接不良 |
| 12 | 阻焊/丝印颜色 | 绿油白字（最成熟、最便宜） | 特殊色加价加工期 |
| 13 | 出货方式 | 单片 / 拼板（含工艺边） | 影响 SMT |
| 14 | 测试方式 | 飞针测试（务必选） | 不测＝开短路风险自担 |
| 15 | 阻抗报告 | 索取 | 无验收依据 |

**实例二：深径比与最小孔径的校核**

板厚 1.6 mm，若选最小孔径 0.2 mm，深径比为：

$$\text{AR}_{drill} = \frac{H}{d} = \frac{1.6}{0.2} = 8:1$$

常规工艺能力约 **8:1～10:1**，8:1 刚好在边缘，价格会上浮且良率略降。若把最小孔径放宽到 0.3 mm，深径比降到 5.3:1，属于舒适区，成本更低。所以**在扇孔阶段（第15～20讲）就应该有意识地把过孔统一为 0.3/0.5 mm（孔径/焊盘）**，除非 BGA 间距实在放不下。

**实例三：打样后的验收动作**

板子到手后，别急着焊：

1. 目视外观：铜面无划伤、阻焊无脱落、丝印清晰、板边无毛刺。
2. 核对层序：对着光看，或用万用表量几个已知的内层网络。
3. 看阻抗报告：单端是否落在 45～55 Ω、差分是否落在 90～110 Ω。
4. 量关键网络通断：电源与地之间**不能短路**（用万用表二极管档量 VCC-GND，应显示电容充电特征而非 0 Ω）。
5. 先只焊电源部分，上电测各路电压正常后，再焊 FPGA/DDR3 等贵重器件。这个"分步上电"习惯能救回很多板子。

**关于资料获取。** 课程配套资料一般包括：原理图与 PCB 源工程、封装库、Gerber 参考包、规则模板文件（Rule 文件可直接导入复用）、器件数据手册合集。建议自己建立一个持续维护的**个人库**：统一封装命名规范、统一规则模板、统一叠层模板。做过三块板之后，你的模板就能让新项目的前期设置从两天压缩到两小时，这是最实在的效率提升。

### ⚠️ 常见误区

- **下单时叠层与设计叠层不一致**。这是 6 层板新手最高频的翻车点，前面所有阻抗工作瞬间归零。
- **忘勾阻抗控制却期待阻抗准确**。板厂默认按标准叠层做，不会替你操心。
- **BGA 板选喷锡**。焊盘共面性不足，BGA 虚焊率极高，且返修困难。
- **省掉飞针/电测**。6 层板内层看不见，开短路只能靠电测发现，省这点钱风险极大。
- **孔径贪小**。深径比逼近工艺极限会涨价、降良率，扇孔阶段就该规划好。
- **一次打样就下大批量**。首板必须打样验证，验证通过再量产，这是纪律。
- **不索取阻抗测试报告**。高速板出问题时，这份报告是判断"是板厂问题还是设计问题"的第一手证据。

### 📌 要点速记

1. 下单最关键的三项是：**层数、叠层结构、阻抗控制**，任一项错则前面所有高速设计工作作废。
2. 含 BGA 的板必须选**沉金 ENIG**，喷锡的表面平整度无法满足细间距焊接。
3. 钻孔深径比建议控制在 8:1 以内，扇孔阶段就应把过孔规格统一规划好。
4. 必选飞针/电测，必索取阻抗测试报告，这两项是 6 层板的验收底线。
5. 板到手后先目视 + 量电源地阻抗 + 分步上电，最后才焊 FPGA/DDR3 等贵重器件。
6. 沉淀个人封装库、规则模板与叠层模板，是把这套流程转化为长期生产力的关键。

### 🔗 承上启下

从第1讲的课程介绍与原理图分析，到第60讲的下单收货，这块 6 层 FPGA + DDR3 + HDMI 板走完了完整生命周期：读懂原理图 → 布局 → 叠层与阻抗 → 扇孔 → 布线 → 等长 → 优化 → DRC → 丝印 → 出料 → 下单。本讲之后没有"下一集"，但真正的下一步是你自己动手复刻一遍，再独立设计第二块板——设计能力只在反复实践中长出来。

## 核心收获清单

- **看懂原理图是 PCB 设计的第一生产力**：先厘清电源树、时钟树、信号分组与接口归属，再动手布局，能避免后期大规模返工。
- **布局决定 70% 的设计成败**：接口器件先定位、模块化预布局、去耦电容贴近电源引脚，布局做好后布线会自然顺畅。
- **6 层叠层的核心是"两个完整地平面 + 信号紧邻参考"**：L1/L6 信号、L2/L5 地、L3 信号、L4 电源，保证每层信号都有连续、紧邻的回流参考。
- **阻抗控制是一整条链路**：叠层选定 → 阻抗计算 → 规则设置 → 布线遵守 → 下单勾选阻抗控制 → 索取 TDR 报告，任一环断裂则前功尽弃。
- **规则先行、布线在后**：线宽、间距、差分、过孔、等长规则在布线前配置完毕，让软件在过程中持续护航，而不是事后救火。
- **BGA 扇孔是高速板的基本功**：过孔规格统一、扇出方向一致、去耦电容"贴焊盘 + 成对过孔"，扇孔质量直接决定后续布线能否走得通。
- **DDR3 布线要先分类再动手**：数据线按字节组（Byte Lane）分组，DQS 与本组 DQ 严格配对，地址/控制线按 Fly-by 拓扑处理，分类清楚等长才有意义。
- **等长的本质是时序而非几何**：要把过孔延时、蛇形线自耦合、内外层传播速度差一并折算，单纯凑毫米数会得到错误结果。
- **参考平面连续性优先于走线美观**：跨分割带来的回流绕行会同时恶化串扰、EMI 与时序，这是 DRC 检查不出的隐性杀手。
- **电源完整性靠"平面 + 多级去耦 + 低电感回路"三件套**：大容量电容管低频、小容量电容管高频，$L_{via}$ 与 $L_{trace}$ 决定高频段是否真的有效。
- **差分对的关键是对内等长与紧耦合**：对内长度差要在极小范围内，对间距保持恒定，包地过孔仅在必要时使用且必须缝合。
- **缝合地过孔与板边处理是 EMI 的最后一道闸**：板边缝合、换层伴地、孤铜消灭，三项做好可显著降低辐射发射。
- **DRC 只是及格线**：它验证几何合规，验证不了回流、拓扑与时序合理性，人工分层复查不可省略。
- **丝印是产品可维护性的一部分**：位号避让焊盘、极性标记在器件轮廓外、密集区隐藏位号并输出装配图，是专业与业余的分水岭。
- **生产资料要自检**：导出后用第三方 Gerber 查看器复核层序、缺层、钻孔对齐、板框闭合、阻焊开窗，这一步能拦下绝大多数致命错误。
- **可制造性思维贯穿全程**：孔径与深径比、钢网面积比 $AR \ge 0.66$、拼板工艺边与 Mark 点、表面处理选型，要在设计阶段就考虑，而不是下单时才发现做不出来。
- **建立个人模板库是长期复利**：封装规范、规则模板、叠层模板、下单核对表沉淀下来后，新项目的前期设置时间可以压缩一个数量级。

> **配套学习建议**：这套 60 集课程覆盖的是"从零到出板"的完整实操链路，但高速 PCB 的理论纵深还需要专项补强。建议按三条主线继续系统学习：**（1）叠层与阻抗**——深入传输线特征阻抗的推导、介质材料 $\varepsilon_r$ 与 $\tan\delta$ 随频率的变化、铜箔粗糙度对损耗的影响、过孔阻抗与背钻，理解"为什么这样叠层"而不只是"照着叠"；**（2）信号完整性**——反射与端接、串扰机理与隔离、回流路径与跨分割、S 参数与眼图、抖动与时序裕量分析，配合仿真工具（如 HyperLynx、SIwave、ADS、开源的 openEMS）做实验对照；**（3）电源完整性**——PDN 目标阻抗设计、电容自谐振与反谐振、平面电容、磁珠的正确使用场景、目标阻抗与瞬态电流的关系。B 站与各大平台上有多套高质量的中英文专项课程，可按上述关键词自行检索筛选（建议优先选择带公式推导与实测/仿真对照的系列）。理论与本套实操课程交替推进，效果最佳：**先跟着做一遍出板，再补理论，然后独立设计第二块板并用仿真验证**。
