## 二、核心框架：信号完整性的物理地基

### 2.1 什么时候必须按传输线处理

判据：**互连长度 L 与信号上升时间 t_r 的传播距离相当**。

```
L_crit ≈ t_r / 6 × v        （v 为介质中传播速度；经验：L > t_r 对应走线长度的 1/6 即需端接）
```

- FR4 中 v ≈ 150–175 mm/ns；t_r = 1 ns → L_crit ≈ 25–30 mm；
- 推论：边沿越快，"短走线"的门槛越短——100 ps 边沿的芯片，2.5 mm 以上的走线就要考虑传输线效应；
- 传输线不匹配的三个后果：反射（过冲/振铃/台阶）、码间干扰、EMI（振铃的高频能量辐射）。

### 2.2 特性阻抗 Z₀：不是电阻，是"每一步的电压电流比"

信号沿传输线传播时，每前进一段就给该段电容充电、在电感中建立电流——Z₀ 是这一动态过程的比值：

```
Z₀ = √(L/C)        L、C 为单位长度电感/电容
Z₀ = √( (R+jωL)/(G+jωC) )    完整形式（低损近似 Z₀≈√(L/C)）
```

- 直觉：Z₀ 描述"信号感觉到的前方阻抗"，与走线长度无关、与频率有关（有损时）；
- 由几何决定：线宽 w ↑ → Z₀ ↓；介质高度 h ↑ → Z₀ ↑；εr ↑ → Z₀ ↓；铜厚 t ↑ → Z₀ 微降。

### 2.3 反射系数：一切的起点

```
Γ = (Z_load − Z₀) / (Z_load + Z₀)
```

| 情形 | Γ | 表现 |
|---|---|---|
| Z_load = Z₀（匹配） | 0 | 无反射，能量全吸收 |
| Z_load = ∞（开路） | +1 | 全正反射 → 过冲加倍 |
| Z_load = 0（短路） | −1 | 全负反射 → 负台阶 |
| Z_load = 2Z₀ | +1/3 | 正反射 1/3 幅度 |

**振铃的成因**：源端与负载端来回反射叠加。抑制思路：让 Γ 源端 ≈ 0（串阻端接）或 Γ 负载端 ≈ 0（并联端接），或者让往返延迟 < 边沿时间（短走线免端接区）。

### 2.4 数字信号的频域：带宽、拐点、频谱

- 数字信号的能量带宽由**边沿**决定，不是由数据率决定（P25 专门辨析）；
- 常用近似：BW ≈ 0.35/t_r（10–90% 定义）；P27"拐点频率"一讲给出更精细的频谱包络分段（0 dB/dec → −20 dB/dec → −40 dB/dec）；
- 工程含义：选电缆/连接器/滤波器/示波器带宽时，按 t_r 算带宽，而不是按数据率。

### 2.5 参考与回流：全集的暗线

- 高频回流走最小回路电感路径（走线正下方，J(d) ∝ 1/(1+(d/h)²)）；
- 参考平面切换、参考平面缺失、参考平面分割——是反射、串扰、EMI 三类问题的共同根源；
- 这一暗线贯穿 A、B、H 三个主题域，也是 P45（手册误区）的判断底尺。

### 2.6 常用速度与延迟速查

| 介质 | 速度 | 延迟 |
|---|---|---|
| 空气 | 300 mm/ns | — |
| FR4 微带 | ≈175 mm/ns | 5.7 ps/mm |
| FR4 带状线 | ≈150 mm/ns | 6.7 ps/mm |
| 通孔 | 混合介质 | 6–10 ps/mm |

## 三、主题域 A：回流路径与混合信号 PCB 设计（P1–P4、P49）

> 课程开篇三部曲。Zach 把"回流"放在全集第一课，因为后面所有阻抗、串扰、EMI 内容都是它的推论。

### 3.1 P1 回流路径 第一部分：电流永远走闭环

- **基尔霍夫必须成立**：任何电流都有返回路径，问题只是"回流走哪里"；
- 低频（< ~100 kHz，回路尺寸 << λ）：回流走**电阻最小**路径——直线距离；
- 高频：回流走**电感最小**（环路面积最小）路径——紧贴信号线正下方；
- 设计错误的最常见形态：设计者给信号画了路径，却没给回流"画"路径——换层不补孔、跨分割、参考平面中断；
- **诊断动作**：对每一条关键走线问一句"它的回流在哪里？"答不出就是隐患。

### 3.2 P2 接地定义 第二部分："地"不是垃圾桶

- "GND"是**一个网络的名称，不是物理概念**；真正起作用的是参考平面与回流；
- 混合信号系统里的"数字地/模拟地"之争的本质：**数字回流不要流经模拟区域的共阻抗**；
- 单点接地的适用边界：低频成立；高频下星形接点引线电感制造公共阻抗耦合；
- 正确做法：**分区布局 + 完整统一地平面**——让数字回流天然局限在数字区下方，模拟回流局限在模拟区下方，平面连续但电流自动"分道"；
- 板级"分割地"只有在回流确实不会跨（如光耦/隔离电源完全分割的场合）才用，否则分割缝就是天线。

### 3.3 P3 布局 第三部分：混合信号的布局次序

1. **先画功能分区**：数字区（MCU/存储/总线）、模拟区（ADC 前端/传感器）、电源区（DC-DC/LDO）、接口区；
2. **接口与晶振先定位**：连接器靠板边、晶振靠近其负载 MCU、模拟区远离一切开关源；
3. **回流审查**：ADC 的模拟参考/采样回路的回流区域内禁止数字信号穿越；模拟区下方平面保持完整；
4. **电源树落地**：每路电源的去耦与汇流路径明确，避免电源平面跨越功能区把噪声"送货上门"；
5. ADC 布局细节：基准去耦、差分输入对称、驱动器靠近、采样时钟干净（时钟抖动直接转成 SNR 损失）。

### 3.4 P49 回流路径基础（速览版）

P1 内容的浓缩重制：低频回流走电阻最小路径、高频走环路最小路径；跨槽/换层是两大回流杀手； remedy 是"连续参考 + 就近缝合 + 换层补孔"。

### 3.5 交叉印证：P32 数模串扰

- 数字噪声进入模拟域的三条通道：共阻抗（地/电源）、容性/感性耦合、电源调制；
- "重视数模串扰"的理由：模拟信号的信噪比一旦损失不可恢复（数字可以重传，模拟不行）；
- 对策优先级：布局分区（物理距离）> 回流隔离 > 电源滤波 > 后级数字滤波。

## 四、主题域 B：传输线与阻抗控制（P5、P6、P8、P11、P12、P17、P37–P40）

> 全集的理论核心。共 10 讲从特性阻抗一路讲到阻抗计算器的误差来源。

### 4.1 P5 传输线特性阻抗

- 定义（见 2.2）；从极限 ω→∞ 推出 Z₀=√(L/C) 的思路——**高频下 R、G 项退居次要**，几何（L、C）主导；
- 单位长度 L、C 与几何的关系直觉：线越宽 C 越大 → Z₀ 越低；线离参考越远 C 越小、L 越大 → Z₀ 越高；
- 常见目标：单端 50 Ω（行业惯例，源于测试系统与功耗折中）、差分 100 Ω/90 Ω（按接口规范：LVDS 100、USB 90、PCIe 85–100）。

### 4.2 P6 输入阻抗深度解析

- 输入阻抗 Z_in 与特性阻抗 Z₀ 是两个概念：

```
Z_in = Z₀ · (Z_L + jZ₀·tan(βl)) / (Z₀ + jZ_L·tan(βl))
```

- **关键结论**：只有 l >> λ（长线）或端接匹配时，Z_in ≈ Z₀；短线在半波长整数倍附近 Z_in 可以剧烈变化；
- 工程意义：**阻抗测量与仿真的频点选择**必须考虑线长；"这根 20 mm 的线看起来不是 50 Ω"往往是正常的；
- 引出端接（P11）与四分之一波长变换（P19/P21）。

### 4.3 P7 高速 PCB 的替代四层板方案

- 经典四层 `SIG-GND-PWR-SIG` 的问题：底层信号参考 PWR，回流经电容换轨（详见 EMI 篇第6讲分析）；
- 替代方案讨论：`GND-SIG-SIG-GND`（双地外层）或改进介质配置（PWR-GND 紧耦合）；
- 决策要素：走线容量、参考质量、平面电容、成本——没有免费午餐，关键是**知道自己牺牲了什么**。

### 4.4 P8 差分阻抗深度解析

- 差分阻抗 ≠ 2× 单端阻抗：**紧耦合使 Z₀ 奇模降低**：

```
Z_diff = 2 · Z_odd        （奇模阻抗）
Z_odd < Z_single（有耦合时）  →  Z_diff < 2 × Z_single
```

- 对内间距越小，耦合越紧，Z_diff 相对 2×Z₀ 下降越多（间距 = 2–4 倍线宽时下降 5–15%）；
- 两种设计流派：**紧耦合**（抗噪好、布线省空间、对共模噪声抑制强）vs **松耦合**（阻抗对间距不敏感、层压公差容忍度高）；
- P37（差分走线需要参考地吗）的伏笔在此：差分对不需要"每根线各自的地"，但**仍然需要连续参考平面**来控制阻抗与回流。

### 4.5 P11 输入阻抗与端接

- 从 Z_in 公式导出端接策略：
  - **并联端接**（Z_L = Z₀）：Γ_load = 0，代价是静态电流与幅度减半——适合有充足驱动且总线型拓扑；
  - **串联端接**（源端 Rs + Z_driver = Z₀）：Γ_source = 0，一次反射到达负载后无回弹——适合点对点 CMOS 驱动，功耗低；
  - **戴维南端接**：双电阻上拉/下拉，兼顾偏置；
  - **AC 端接**（串电容）：无静态功耗但引入低频反射尾巴；
- 端接值不是"背表"：按驱动器输出阻抗 + 走线 Z₀ 计算，再实测微调（P20 的 Altium SI 工具就用于此）。

### 4.6 P12 阻抗计算器工作原理

- 计算器内核是**二维场求解器**（准静态近似）：把截面切成网格，解拉普拉斯方程得 L、C 矩阵，Z₀=√(L/C)；
- 准静态近似的适用边界：截面尺寸 << 波长（大多数 PCB 走线 OK，毫米波失效）；
- 输入参数的意义讲透：PP 的 εr 随树脂含量变化、铜厚有"加工后有效铜厚"（电镀加厚）、阻焊层对表层微带有 1–3 Ω 降阻——**这些就是 P17 误差来源的伏笔**。

### 4.7 P17 为什么阻抗计算器算不准

误差来源清单（按影响排序）：

1. **εr 不确定**：datasheet 给的是 1 MHz 下的 Dk，GHz 下更低（且随树脂含量/玻璃布 style 漂移）——±0.2 的 Dk 误差 → ±2–3 Ω 阻抗误差；
2. **有效铜厚**：外层电镀后远大于标称 1 oz；
3. **蚀刻梯形**：线截面是梯形不是矩形（底宽>顶宽）；
4. **阻焊覆盖**：表层微带被绿油覆盖后阻抗下降；
5. **粗糙度**：铜箔轮廓增加有效损耗与等效电感（影响高频阻抗）；
6. **参考平面位置**：实际压合厚度公差 ±10%。

对策：按"光板 + 阻焊"两态分别建模、要求板厂首件 TDR 报告回读、设计留 ±10% 裕量。

### 4.8 P38 参考平面可以靠得多近？

- 参考平面贴近信号层的好处：阻抗可控、回流紧、串扰小、平面电容大；
- 限制因素：①阻抗目标下的线宽（太近 → 线太细 → 电流密度/可制造性）；②平面间电容与耐压；③同层相邻走线耦合增大；
- 实用区间：带状线 h ≈ 0.1–0.15 mm 单端 50 Ω 可用；PWR-GND 平面对 0.075–0.11 mm（3–4 mil）是常见甜点。

### 4.9 P39 偏移参考平面为什么让设计失效

- 场景：阻抗计算器按"参考平面无限大、正对走线"计算，实际布局中参考平面在走线下方**横向偏移**（平面边缘、分割边、过孔反焊盘阵列）；
- 后果：边缘耦合缺失 → C 下降 → Z₀ 实际高于计算值；更糟的是回流被迫绕行 → 局部环路 → 串扰/EMI；
- 对策：平面边缘与走线保持**≥3 倍介质高度**的水平距离；检查反焊盘阵列（P43/P44）的"伪开槽"效应。

### 4.10 P40/P41 在阻抗计算器中补偿传输线损耗 / 介质损耗

- 计算器默认无损（R=G=0）；高频下导体损耗（集肤，∝√f）与介质损耗（∝f，由 tanδ 决定）使有效阻抗与衰减随频率变化；
- 介质损耗：α_d ≈ π·f·√εr·tanδ / c——**tanδ 是关键材料参数**：FR4 普通 tanδ≈0.02（10 GHz 衰减大），低损耗材料 tanδ<0.005（P41）；
- 长线（>20 cm）+ 多 Gbps 时必须用有损模型/通道仿真，不能只看无损阻抗。

## 五、主题域 C：数字信号带宽与频域分析（P9、P23、P25、P27、P42）

### 5.1 P9 数字信号带宽深度解析

- "带宽"的三种定义辨析：**3 dB 带宽**（系统）、**频谱能量带宽**（信号）、**示波器测量带宽**（仪器）——混用是初学常见错误；
- 信号的能量带宽由边沿决定：BW ≈ 0.35/t_r（10–90%）；P9 从梯形波频谱包络推导并给出工程近似；
- 例：t_r = 500 ps → BW ≈ 700 MHz——一根"1 Mbps 的 I2C"若边沿 500 ps，也需要按 700 MHz 通道对待（这就是慢总线上快边沿照样出 SI 问题的原因）；
- 通道设计要求：通道 3 dB 带宽 > 0.5–1 × 信号 BW，否则边沿被吃（上升时间退化：t_r,out = √(t_r,in² + t_r,channel²)）。

### 5.2 P23 NRZ 与 PAM-4：带宽需求对比

| 调制 | 符号 | 电平 | 相同数据率下的符号率 | 带宽需求 |
|---|---|---|---|---|
| NRZ | 1 bit/符号 | 2 | f_bit | 基准 |
| PAM-4 | 2 bit/符号 | 4 | f_bit/2 | **一半** |

- PAM-4 用多电平换带宽：56/112 G SerDes 的标准选择（PCIe 6.0、224G lane 用 PAM-4/PAM-6）；
- 代价：眼图垂直张开度只剩 NRZ 的 1/3 → 对噪声/串扰/非线性极敏感，需要均衡（CTLE/DFE/FEC）；
- 设计启示：多电平时代，**通道的线性度与损耗均衡**比单纯追求更低损耗更重要。

### 5.3 P25 别再迷信 25% 上升时间准则

- 流行说法："示波器带宽 ≥ 信号的 0.35/t_r 不够，要留 5 倍/25% 边沿保真"云云；
- 讲师的观点：这些"倍数准则"都是**测量误差预算的粗略表达**，不问"你要测什么、允许多大误差"就没意义；
- 正确框架：测量系统的上升时间合成 t_r,meas = √(t_r,scope² + t_r,probe² + t_r,signal²)——**由你允许的误差反推所需带宽**，而不是套倍数；
- 本质：又一个"条件丢失的指南"（与 P45 同一方法论）。

### 5.4 P27 拐点频率深度解析

- 频谱包络两拐点：f₁ = 1/(πτ)（脉宽决定）、f₂ = f_knee = 0.35/t_r（边沿决定）；
- f₂ 之后 −40 dB/dec 衰减——**但 EMI/SI 问题常发生在 f₂ 附近**（能量仍可观 + 结构谐振）；
- 应用：EMC 预判关注到 f_knee（EMI 篇缝合间距的 λ/20 就是取 f_knee 量级）；通道仿真建模到 f_knee 的 2–3 倍。

### 5.5 P42 色散分析可视化

- **色散 = 相速随频率变化**：不同频率分量传播速度不同 → 波形展宽/失真；
- PCB 上的色散来源：介质 Dk 随频率下降（玻纤/树脂色散）、导体损耗的 √f 特性、过孔的模态混合；
- 可视化方法：对通道跑 S 参数 → 群时延 vs 频率曲线，平坦度即色散程度；
- 影响：几 GHz 以上长通道的确定性抖动（DJ）的重要来源；低损耗材料 + 均衡器缓解。

## 六、主题域 D：S 参数与 VNA 测量（P13–P16、P20、P35）

### 6.1 P13 S 参数 第一部分：概念与定义

- S 参数把网络描述成"波的散射"：端口入射波 a、出射波 b，S_ij = b_i/a_j；
- **二端口核心量**：

| 参数 | 含义 | SI/EMC 用途 |
|---|---|---|
| S11 | 输入反射 | 阻抗匹配质量（|S11|<-10 dB 视为"匹配可接受"） |
| S21 | 正向传输（插损） | 通道损耗、滤波器通带 |
| S12 | 反向隔离 | 串扰/反向泄漏 |
| S22 | 输出反射 | 负载侧匹配 |

- 差分系统的**模态 S 参数**：Sdd（差模→差模）、Scc（共模→共模）、Scd/Sdc（模态转换）——与 EMI 篇 CMC 选型同一套语言；
- S 参数是频率域数据：幅值（dB）+ 相位（度），可无损换算为 TDR/时域响应（IFFT）。

### 6.2 P14 S 参数 第二部分：使用要点

- **因果性/无源性/稳定性**：从厂商拿到的 S 参数模型常违反这三性——直接用于仿真会出现能量凭空产生（无源性破坏），需工具修复；
- 带宽与动态范围：S 参数只在其测量频段内有效，外推危险；
- 参考面：S 参数在哪个参考面定义（含/不含焊盘、探针区）决定它能不能直接用；
- 级联：Touchstone 文件按端口顺序级联，顺序错了结果全错。

### 6.3 P15/P35 LibreVNA 实测：S 参数与走线阻抗

- LibreVNA（开源矢量网络分析仪，~500 元级硬件）是本课的"穷人的实验室"：
  - 校准是灵魂：SOLR/TRL 校准把误差从测量中剥离——**不做校准的 VNA 读数只是玩具**；
  - 测 S 参数：校准 → 接 DUT → 读 S11/S21，注意夹具去嵌入；
  - 测走线阻抗（P35）：TDR 模式（对 S11 做反 FFT 得阻抗 vs 距离）——直接看到连接器/过孔/线宽变化的阻抗剖面；
- 工程价值：把"阻抗计算器 vs 实际板子"的误差（P17）变成可测量的闭环。

### 6.4 P20 Altium SI 工具测阻抗

- Altium Designer 内置信号完整性分析器：布线后直接跑反射/振铃分析，驱动/接收模型用 IBIS；
- 用法：布线 → Tools→Signal Integrity → 分配 IBIS → 屯端接方案扫描（串阻值扫描）→ 看波形选端接；
- 局限：准静态截面阻抗 + 行为级模型，不替代全波仿真——但够解决 80% 的板级反射/端接问题。

## 七、主题域 E：串扰与保护走线（P16、P30、P31）

### 7.1 P16 串扰的类型

- **容性耦合**（电场）：aggressor 的 dv/dt 经互容 C_m 注入 victim；等效为在 victim 上并联受控电流源；
- **感性耦合**（磁场）：aggressor 的 di/dt 经互感 L_m 在 victim 回路感应电压；**回流重叠区越大互感越大**——感性串扰与"回流共享"直接挂钩；
- **近端串扰 NEXT** 与 **远端串扰 FEXT**：
  - 微带：容性/感性分量速度不同 → FEXT 显著累积；
  - 带状线：两分量速度相同 → FEXT 相互抵消（均匀介质下 FEXT→0），NEXT 仍随长度增长；
  - **推论：重要总线放内层带状线**（与叠层章一致）；
- 量级直觉：3W 间距、介质 0.1 mm 时相邻耦合系数约 3–5%；**介质高度减半 = 串扰近减半**（比拉间距更有效）。

### 7.2 P30/P31 保护走线两讲：有没有用，条件说了算

P30（实验结论）：

- **两端接地的 guard trace**：在中等边沿速率下对串扰改善有限（1–3 dB），某些频点甚至更差（谐振）；
- **多点接地（密集缝合）的 guard trace**：可再降 3–6 dB，代价是布线空间与过孔数量。

P31（进阶机理）：

- guard 走线起作用的本质是**把 aggressor 的边缘场"截流"并就近导入地**——所以它的效果取决于接地电感与缝合密度；
- 若 guard 走线与 victim 之间距离太近，guard 自身的回流也会耦合进 victim——**间距设计是双刃剑**；
- 实战建议（性价比排序）：

```
拉开间距 > 降介质高度（换层）> 带状线 > 密缝合 guard trace > 两端接地 guard trace（禁用）
```

### 7.3 数模串扰专题（P32 详述见 3.5）

- 数字开关噪声对模拟的三大通道：共阻抗、场耦合、电源调制；
- "数模分割地"是流传最广的错误方案——正确的是**分区 + 统一连续地**（3.2）。

## 八、主题域 F：匹配与端接（P19、P21、P22、P33）

### 8.1 P19 四分之一波长阻抗匹配（基础）

- λ/4 传输线的**阻抗变换**性质：

```
Z_in = Z₀² / Z_L        （线长 = λ/4 时）
```

- 应用：把 Z_L 变换到源阻抗——选 Z₀ = √(Z_S·Z_L) 的 λ/4 段即可完成匹配；
- 经典场景：天线匹配（50 Ω 馈线 ↔ 非纯阻天线）、射频前端偏置线（λ/4 高阻线 = RF 扼流）；
- 局限：**窄带**——只在设计频点附近有效（分数带宽约与变换比成反比）。

### 8.2 P21 四分之一波长匹配进阶

- 多节 λ/4 变换器（Chebyshev/Binomial 阶梯）展宽带宽——每加一节，带宽↑、长度↑；
- 复阻抗负载：先用短传输线/枝节把电抗抵掉（归一化到实数），再做 λ/4 电阻变换——Smith 圆图上的"沿等电阻圆/等驻波圆走"；
- PCB 实操：λ/4 的物理长度按有效介电常数算（微带 ε_eff 需查表/仿真），FR4 @ 2.4 GHz λ/4 ≈ 18 mm（微带）；
- 与 SI 的关系：数字板上少用 λ/4 匹配（宽带问题），但**时钟走线 accidentally 恰为 λ/4 时会谐振**——布线长度规划要避开。

### 8.3 P22 共轭匹配与无反射匹配

- **共轭匹配（最大功率传输）**：Z_S = Z_L*——负载从源取最大功率；用于射频/功率链路；
- **无反射匹配（Z_S = Z_L）**：纯实数相等——用于数字信号完整性与测量系统；
- 两者不同！共轭匹配下反射系数不为零（虚部对消）；数字设计者要的是无反射；
- 常见混淆场景：射频工程师和数字工程师对"匹配"的争论，往往是这两个定义之争。

### 8.4 P33 端接的适用场景详解

| 场景 | 推荐端接 | 理由 |
|---|---|---|
| 点对点、驱动强（CMOS） | 源端串阻 22–33 Ω | 低功耗、一次反射 absorbed |
| 多负载总线（星形/菊花链） | 负载端并联/戴维南 | 消除分支反射 |
| 差分高速（LVDS 等） | 负载端 100 Ω 差分（片内） | 规范要求 |
| 短线（L < t_r·v/6） | 不端接 | 反射被边沿"掩埋" |
| 漏极开路/总线共享（I2C 等） | 上拉 + 速率限制 | 慢边沿即对策 |
| 大容性负载（时钟树末端） | 串阻 + 短桩控制 | 阻尼振铃 |

- 决策流程：算 L_crit（2.1）→ 短线免端接 → 长线按拓扑选端接 → 仿真/实测微调（P20 工具）；
- 端接的代价意识：并联端接的静态功耗、串阻的边沿放缓与幅度损失——**端接是交易，不是免费**。

## 九、主题域 G：损耗、集肤效应与色散（P18、P28、P48）

### 9.1 P18 集肤效应：电流与电磁场

- 高频下电流集中在导体表层（集肤深度 δ）：

```
δ = √( 2ρ / (ωμ) )        铜 @ 1 GHz ≈ 2.1 μm；@ 100 MHz ≈ 6.6 μm
```

- 后果一：**导体电阻 ∝ √f**——1 oz 铜（35 μm）在 1 GHz 只有表面 ~2 μm 有效导电，交流电阻是直流的十几倍；
- 后果二：粗糙铜箔（RTF 之外的标准箔齿高 ~5 μm > δ）让实际损耗比平滑模型高 20–50%——高速板材选低粗糙度箔（RTF/HVLP）；
- 后果三：回流电流也集肤——参考平面上回流集中在走线正下方的薄层，平面"看起来很大"但高频回流通道其实很窄（与 4.2 回流分布公式互证）。

### 9.2 P28 PCB 走线电感：何时加宽走线

- 走线自感（近似，L 单位 nH）：L ≈ 5.08·l·[ln(2l/(w+h)) + 0.5 + (w+h)/(3l)]（l/w/h 同单位）——**长度线性、宽度对数**；
- 关键结论：**加宽走线对电感的改善是对数的**（宽度翻倍 → 电感降 ~15–20%），而缩短长度是线性的；
- 什么时候加宽：载流（IR drop 与温升）、可控阻抗（配合 h）、**ESD/浪涌泄放路径（低电感是硬需求，用宽+短+多孔）**；
- 什么时候不值得：单纯为"降电感"把走线加到 3 倍宽——不如改短路径或多打并联过孔；
- 过孔电感 ≈ 0.5–1 nH/个（1.6 mm 板）：换层是电感"加法"，敏感节点就近打孔。

### 9.3 P48 过孔色散：传输延时为何随频率变化

- 过孔的等效电路（L-C 混合结构）对不同频率呈现不同相速——**孔内延迟不是常数**，高频分量延迟更短/更长（视结构），导致边沿高频相位失配；
- 表现：长过孔链（背板、厚板）的通道在 TDR/眼图上出现"台阶"与确定性抖动；
- 缓解：短过孔（薄板/盲埋）、背钻去残桩（残桩谐振与色散叠加）、过孔旁回流地孔降低回路面积；
- 与 EMI 篇第3讲互证：过孔延迟录入 DDR 规则时用的是"宽带近似值"，GHz 级设计要用带 S 参数的孔模型。

## 十、主题域 H：电源分配与去耦（P4、P10、P34、P50）

### 10.1 P4 稳压器输出端要不要加磁珠？

- 流行做法：LDO/DCDC 输出串一颗磁珠再接负载——讲师给出的判断框架：
  - 磁珠（ferrite bead）= 频率相关的电阻+电感：低频近似短路、高频呈阻性（吸收）；
  - **适合的场景**：隔离两个子系统的高频噪声（数字电源 → 模拟供电、PLL/ADC 基准供电），且后级有大电容共同构成低通；
  - **不适合的场景**：①大电流主电源轨（DCR 与饱和电流、压降）；②后级负载有大的动态电流阶跃——磁珠电感与负载电容构成欠阻尼 LC，**阶跃响应振铃可能比不加更糟**；
- 设计方法：磁珠与后级电容的谐振 f₀ = 1/(2π√(L_bead·C_load))，要用"带阻尼"的方案（磁珠的 R@f₀ 或并联阻尼电阻）把 Q 压下来；
- 结论一句话：**磁珠是"噪声隔离器"不是"稳压增强器"**——先看负载的动态电流特性，再决定加不加。

### 10.2 P10 电源平面作为回流路径

- 信号层参考电源平面时（如 4 层板底层），回流在电源平面流动——电源平面承担"地"的角色；
- 三个条件决定质量：①PWR 平面与 GND 平面之间的高频低阻通道（紧耦合平面电容 + 去耦电容群）；②PWR 平面完整不分割；③换轨点（信号换层处）就近有 PWR-GND 电容/缝合孔；
- 平面电容的作用机理（详见 EMI 篇 8.4）：C=εA/d、零安装电感——是 PWR 平面作为回流路径的"底气"；
- 实用结论：**能参考 GND 就参考 GND；必须参考 PWR 时，保证 PWR 完整 + 换轨电容就位**。

### 10.3 P34 电源层分割区域上方走线有何影响

- 信号跨 PWR 平面分割（如 3.3 V / 1.2 V 域交界）：回流无法跨越 → 绕行或经耦合电容过桥 → 环路暴增；
- 三重后果：阻抗局部突变（反射）、对邻线串扰增大（回流拓宽）、分割缝天线辐射（EMI）；
- 对策排序：**改道（信号不跨）> 走线换层到有连续参考的层 > 分割缝搭接电容（100 nF，最后手段，有效但窄带）**；
- 设计流程落地：画电源域时就规划"信号不跨缝"的通道——布完线再发现就晚了。

### 10.4 P50 去耦电容的布局位置真的很重要吗

- 讲师的实证结论（与前文 P17/P45 同一方法论精神）：**"位置重要"的流行说法需要条件化**：
  - 决定高频性能的是**回路电感**（电容安装电感+过孔+扩展电感），距离本身只是其中一项；
  - 有完整平面 + 平面电容的板：3 mm 与 10 mm 的差别往往测不出来；
  - 无平面/双层板：走线电感占大头，距离权重回升；
- 真正要抠的细节（按收益排序）：①过孔短而粗（盘内孔最优）；②电容贴电源平面侧；③同值多颗分散（分摊扩展电感）；④大小电容不要"级联串糖葫芦"（中点电感抵消平面电容收益）；
- 结论：**优化"回路"而不是优化"距离"**——与 EMI 篇第4讲案例完全同源。

## 十一、主题域 I：过孔与反焊盘（P43、P44）

### 11.1 P43 如何绘制反焊盘（anti-pad）

- **反焊盘 = 平面层上围绕过孔的"挖空区"**：防止孔壁与平面短路，同时决定孔与平面之间的耦合；
- 反焊盘尺寸的影响：
  - 过大 → 孔-平面耦合电容减小 → 孔的阻抗升高 → 通道出现局部高阻（反射）；
  - 过小 → 耦合过强、工艺风险（介质击穿、短路）、且过密孔阵的反焊盘连成"伪开槽"（回流断裂，P39）；
- 手工绘制场景：特殊孔（背钻孔、大电流孔、射频孔）需要非默认反焊盘。

### 11.2 P44 何时用设计规则、何时用绘图工具

| 方式 | 适用 | 风险 |
|---|---|---|
| 设计规则（默认反焊盘） | 95% 的常规过孔——一致性、可批量调整 | 对特殊孔无差别控制 |
| 绘图工具（手画铜/挖空） | 射频过孔反焊盘优化、背钻孔、大电流孔 | 布局改动后容易"忘删/忘改"，需在 DRC 之外人工复查 |

- 实操建议：默认交给规则；特殊孔单独建 class/规则；手绘区域做醒目标注（板框层注释），改版时逐个核对；
- 反焊盘与过孔色散（P48）、偏移参考（P39）是同一件事的三个侧面：**孔-平面几何决定孔的电气行为**。

## 十三、主题域 K：实操、工具与 AI 辅助（P24、P26、P36、P51–P53）

### 13.1 P24 系统级仿真认证（是德科技 Tim Wang Lee）

- 芯片级 IBIS/AMI 模型 → 通道 S 参数 → 系统级眼图/误码率（BER）仿真的完整链路；
- 认证思维：按规范（如 PCIe/USB 的合规测试项）反推设计指标——插损、回损、模态转换、眼高眼宽模板；
- 工具链：ADS/SignalIntegrity Builder 类工具把 IBIS-AMI + Touchstone 串成 StatEye 仿真；
- 对板级工程师的启示：**通道是"芯片+封装+PCB+连接器+线缆"的串联合成**，PCB 只是其中一环，但也是你最可控的一环。

### 13.2 P26 偏置器电路设计与仿真

- Bias-Tee（偏置器）：电感馈直流 + 电容隔直——把直流偏置与射频信号叠加到同一根同轴/走线；
- 两个元件的频域要求：馈电电感在最低工作频率呈高阻（L >> Z₀/ω），隔直电容在最低频率呈低阻（C << 1/(ωZ₀)）；
- 算例：100 MHz 最低工作频率 → L > 500 nH 量级、C > 30 pF 量级（留 10 倍裕量再取整）；
- 仿真要点：元件自谐振频率决定可用上限——实际馈电电感在 SRPF 之后失效，要用带寄生参数的模型。

### 13.3 P36 Bogatin 访谈精讲

- 核心观点集（与全集主线互证）：
  - "有三种工程师：用公式的、用仿真的、用测量的——好的工程师让三者互相校验"；
  - 示波器测量的本质是"带宽 × 校准"，便宜仪器 + 正确方法 > 贵仪器 + 乱用；
  - 教学法：先给物理图像（场、回流），再给公式——顺序反了就会变成背公式；
- 本课结构正是按这个教学法组织的（回流先于阻抗、测量贯穿全程）。

### 13.4 P51–P53 AI PCB 布局三讲

- **P51 AI vs 人工（客观剖析）**：AI 自动布局在规则遵守（间距/阻抗/散热）上可以做到不犯错，但在**回流意识、功能分区策略、EMC 经验直觉**上与资深工程师仍有代差——它优化的是"可量化的约束"，而好的布局一半是"不可量化的经验"；
- **P52 糟糕 AI 布局实例（USB 连接器与二极管阵列）**：AI 把 ESD 阵列放得离连接器过远、TVS 接地回路绕远——**布局电感（第1讲灵魂）这类"乘法关系"的失效模式 AI 目前不敏感**；人工审查的重点恰恰是这类位置关系；
- **P53 黑盒难题**：AI 工具给出结果但给不出"为什么"——无法审计的布局不可用于高可靠产品；未来方向是"AI 出初稿 + 工程师按机制清单审查"的人机协作流；
- 与 P45 方法论呼应：**对 AI 输出与对数据手册指南，用同一套检验流程**——问机制、找假设、复核、验证。

## 十五、全课程设计 Checklist 汇总

### 回流与混合信号（P1–P4、P32、P49）
- [ ] 每条关键走线能回答"回流在哪里"；
- [ ] 换层过孔旁有回流地孔（参考平面切换处必查）；
- [ ] 混合信号：分区布局 + 统一连续地平面，不分割地；
- [ ] ADC/模拟区回流区域无数字信号穿越；
- [ ] 晶振环路面积最小。

### 阻抗与传输线（P5–P12、P17、P37–P40）
- [ ] 按 t_r 判断哪些线是传输线（L > t_r·v/6 量级即按长线处理）；
- [ ] 阻抗目标写进制板说明（±10%，coupon 回签）；
- [ ] 计算器误差三来源复核：Dk 频变、有效铜厚、阻焊；
- [ ] 差分对：紧/松耦合流派二选一并统一全板；
- [ ] 平面边缘与走线保持 ≥3 倍介质高度；
- [ ] 高速差分参考平面连续，无伴随地线迷信。

### 带宽与时频域（P9、P23、P25、P27、P42）
- [ ] 按边沿（非数据率）定通道带宽：BW ≈ 0.35/t_r；
- [ ] 慢总线快边沿同样按带宽预算处理（串阻放缓边沿）；
- [ ] 多电平接口（PAM-4）按规范模板走，留均衡余量；
- [ ] 示波器/探头带宽按测量误差预算反推。

### 串扰与端接（P16、P19–P22、P30–P31、P33）
- [ ] 关键总线放内层带状线（FEXT 抵消）；
- [ ] 介质高度优先于间距的串扰权衡；
- [ ] guard trace 只在密缝合时使用；
- [ ] 端接按拓扑选型（点对点串阻 / 总线并联 / 差分片内）；
- [ ] 短线免端接判据核过（L < t_r·v/6）。

### 损耗与高频效应（P18、P28、P40–P42、P48）
- [ ] >5 Gbps 或 >20 cm 通道用有损模型仿真；
- [ ] 高速板材关注 tanδ 与铜箔粗糙度（RTF/HVLP）；
- [ ] 走线加宽要明白是"对数收益"；降电感优先缩长度/多过孔；
- [ ] 长通孔评估残桩与背钻；
- [ ] 时钟走线长度避开 λ/4 谐振。

### 电源与去耦（P4、P10、P34、P50）
- [ ] 磁珠只用于噪声隔离，核过 LC 谐振阻尼；
- [ ] 信号不跨电源分割；无法避免时换层或搭桥电容；
- [ ] 参考 PWR 平面的信号：PWR 完整 + 换轨电容就位；
- [ ] 去耦优化"回路电感"：短孔、贴平面、多颗分散。

### 过孔与反焊盘（P43、P44）
- [ ] 反焊盘默认走规则，特殊孔单独建规则；
- [ ] 孔阵反焊盘不连成"伪开槽"；
- [ ] 射频/背钻手绘区做改版复查标注。

### AI 辅助（P51–P53）
- [ ] AI 布局结果按"回流/防护链位置/参考连续"三清单人工审查；
- [ ] 不可解释的自动布局不用于高可靠产品。

19. S 参数使用的三个"性"要求？
20. AI 布局工具当前的两大短板？

### 参考答案要点

1. L 与 t_r 的传播距离相当（L > t_r·v/6 量级）；t_r=1 ns → FR4 约 25–30 mm；
2. Z₀ 是几何属性，Z_in 随线长/端接/频率变化；短线在非匹配时正常；
3. 奇模激励下两线互容互感增强等效 C、降低等效 L → Z_odd < Z_single；
4. Rs = Z₀ − Z_driver 输出阻抗；点对点 CMOS 驱动；
5. Dk 频变/漂移、有效铜厚、蚀刻梯形、阻焊、粗糙度、压合公差；
6. 边缘耦合缺失→C↓→Z₀↑；回流绕行→环路→串扰/EMI；
7. 带状线均匀介质容性/感性 FEXT 相消；微带介质不均匀 → FEXT 累积；
8. 密集多点接地（λ/20）；两端接地是悬空谐振振子；
9. 眼图垂直张开度剩 1/3 → 对噪声/串扰/非线性敏感，需均衡+FEC；
10. 按允许测量误差由 t_r 合成公式反推；25% 倍数是丢了条件的粗略表达；
11. ≈2.1 μm；交流电阻 ∝√f，回流在平面薄层内，粗糙度放大损耗；
12. 对数；缩长度与多过孔并联更有效；
13. 谐振+延迟+辐射；盲埋孔>背钻>缩短残桩>接受；
14. 大动态电流负载时 L_bead·C_load 欠阻尼 LC 阶跃振铃；
15. 反射（阻抗突变）、串扰（回流拓宽）、EMI（缝隙天线）；改道>换层>搭桥电容；
16. 对象应是回路电感（安装电感+过孔+扩展电感），距离只是子项；
17. Z_in=Z₀²/Z_L；只在设计频点附近有效（窄带）；
18. Z_S=Z_L*（最大功率）vs Z_S=Z_L（零反射）；数字要无反射；
19. 因果性、无源性、稳定性；
20. 对"布局电感/回流意识"类乘法失效不敏感；结果黑盒不可审计。

## 二十、逐讲知识点卡片（P0–P55 全覆盖）

> 每讲一张卡：核心结论 + 可执行要点。与前面主题章节互补——主题章节讲"为什么"，这里保证"每一讲都有落点"，也方便按分P回看视频。

### P0 课程预告（6 s）
符号性分P。预告课程主线：回流 → 阻抗 → 反射/串扰 → 测量闭环。

### P1 回流路径 混合信号 PCB 设计 第一部分（606 s）
- 电流必须成环：设计者给信号画了路，常常忘了给回流画路；
- 低频回流走电阻最小路径（直线），高频回流走环路面积最小路径（正下方）；
- 执行习惯：每条关键走线问"回流在哪里"。

### P2 接地定义 第二部分（553 s）
- "GND"是网络名不是物理概念，起作用的是参考平面与回流；
- 混合信号的正确答案是"分区布局 + 统一连续地"，不是分割地；
- 分割地只适用于回流确实不会跨越的完全隔离场合。

### P3 布局 第三部分（947 s）
- 布局次序：功能分区 → 接口/晶振定位 → 回流审查 → 电源树落地；
- ADC：基准去耦、差分输入对称、采样时钟干净（时钟抖动直接吃 SNR）；
- 数字回流不许穿越模拟区下方。

### P4 稳压器输出端要不要加磁珠（950 s）
- 磁珠=频率相关 R+L，是"噪声隔离器"不是"稳压增强器"；
- 适合：数字电源→模拟/PLL 供电的高频隔离；
- 不适合：大动态电流负载——L_bead·C_load 欠阻尼振铃会更糟；要按 f₀=1/(2π√(LC)) 核阻尼。

### P5 传输线特性阻抗（941 s）
- ω→∞ 极限推出 Z₀=√(L/C)：高频下几何主导；
- 线宽↑→Z₀↓；离参考远→Z₀↑；εr↑→Z₀↓；
- 50 Ω 是行业惯例（测试系统+功耗折中），不是物理必然。

### P6 输入阻抗深度解析（980 s）
- Z_in=Z₀(Z_L+jZ₀tanβl)/(Z₀+jZ_L·tanβl)；
- 长线/匹配时 Z_in≈Z₀；短线随频率剧烈变化（半波长整数倍附近）；
- 测量与仿真频点选择必须考虑线长。

### P7 高速 PCB 的替代四层板方案（1053 s）
- 经典 `SIG-GND-PWR-SIG` 的病根：底层参考 PWR，回流经电容换轨；
- 替代：`GND-SIG-SIG-GND` 或压薄 PWR-GND 介质；
- 决策=走线容量 vs 参考质量 vs 平面电容 vs 成本，先想清楚牺牲什么。

### P8 差分阻抗深度解析（810 s）
- Z_diff=2×Z_odd，紧耦合使 Z_odd<Z_single → Z_diff<2×单端；
- 对内间距 2–4 倍线宽时比 2×单端低 5–15%；
- 紧耦合（抗噪/省空间）vs 松耦合（公差容忍）全板统一。

### P9 数字信号带宽深度解析（1194 s）
- 带宽由边沿决定：BW≈0.35/t_r；1 Mbps 的 I2C 配 500 ps 边沿也是 700 MHz 问题；
- 通道 3 dB 带宽不足 → t_r,out=√(t_r,in²+t_r,ch²) 边沿退化；
- 选连接器/电缆/示波器都按这个公式。

### P10 电源平面作为回流路径（722 s）
- 参考 PWR 平面的回流质量=平面电容+去耦群+平面完整性；
- 换轨点就近放 PWR-GND 电容；
- 能参考 GND 就参考 GND。

### P11 输入阻抗与端接（1114 s）
- 端接本质：让 Γ 源端或负载端归零；
- 并联（功耗大）、串联（点对点首选）、戴维南（带偏置）、AC 端接（无静态功耗有尾巴）；
- 端接值按 Z₀−Z_driver 计算再实测微调。

### P12 阻抗计算器工作原理（1070 s）
- 内核是二维准静态场求解器：解截面拉普拉斯方程得 L、C；
- 适用边界：截面 << 波长（毫米波失效）；
- Dk、铜厚、阻焊都是输入——输入错结果必错（引出 P17）。

### P13 S 参数 第一部分（1074 s）
- S11 反射、S21 插损、S12 隔离、S22 输出反射；
- |S11|<−10 dB 是"匹配可接受"的常用门槛；
- 差分模态 Sdd/Scc/Scd/Sdc 与 CMC 选型同一语言。

### P14 S 参数 第二部分（651 s）
- 使用三性：因果性、无源性、稳定性——厂商模型常违反，需修复再用；
- 只在测量频段内有效，外推危险；
- 级联注意端口顺序与参考面定义。

### P15 LibreVNA 测 S 参数（1272 s）
- 校准是灵魂（SOLR/TRL），不校准的 VNA 是玩具；
- 夹具去嵌入决定低频段可信度；
- 开源 VNA 把"阻抗实测闭环"降到数百元成本。

### P16 串扰类型（1090 s）
- 容性（dv/dt·C_m）与感性（di/dt·L_m）两种机制；
- 带状线 FEXT 相消、微带 FEXT 累积——重要总线放内层；
- 介质高度减半 ≈ 串扰近减半，比拉间距有效。

### P17 阻抗计算器为什么不准（1028 s）
- 六类误差：Dk 频变/漂移、有效铜厚、蚀刻梯形、阻焊、粗糙度、压合公差；
- Dk ±0.2 → 阻抗 ±2–3 Ω；
- 对策：分态建模 + 板厂 TDR 回签 + 设计留裕量。

### P18 集肤效应（695 s）
- δ=√(2ρ/ωμ)：铜 @1 GHz ≈2.1 μm；
- 交流电阻 ∝√f；标准铜箔齿高 > δ → 损耗放大 20–50%（高速板用 RTF/HVLP）；
- 平面回流也是集肤的——"大平面"高频有效通道其实很窄。

### P19 四分之一波长阻抗匹配（790 s）
- Z_in=Z₀²/Z_L：λ/4 线是阻抗变换器；
- 选 Z₀=√(Z_S·Z_L)；
- 窄带局限；RF 扼流偏置线是同原理逆用。

### P20 Altium SI 工具测阻抗（851 s）
- IBIS 模型 + 布线后反射/振铃分析；
- 端接扫描：串阻值扫一遍看波形选值；
- 准静态+行为级，解决 80% 板级问题，不替代全波仿真。

### P21 四分之一波长匹配进阶（1251 s）
- 多节阶梯展宽带宽；复阻抗先枝节抵电抗再做实数变换；
- Smith 圆图操作：等电阻圆/等驻波圆；
- 数字板时钟线长度避开 λ/4 谐振。

### P22 共轭匹配与无反射匹配（777 s）
- 共轭 Z_S=Z_L*（最大功率）≠ 无反射 Z_S=Z_L（SI 要的）；
- 共轭匹配下反射不为零——射频/数字"匹配"之争常常是定义之争；
- 测量系统按无反射（50 Ω）设计。

### P23 NRZ 与 PAM-4（872 s）
- PAM-4 同数据率符号率减半 → 带宽减半；
- 代价：眼高剩 1/3 → 要 CTLE/DFE/FEC；
- 56G+ SerDes、PCIe 6.0 的选择。

### P24 系统级仿真认证（2494 s，是德科技）
- 链路=芯片+封装+PCB+连接器+线缆的串联 S 参数；
- IBIS-AMI + StatEye 统计眼图/BER；
- 按规范测试项反推设计指标（插损/回损/模态转换/眼模板）。

### P25 别再迷信 25% 上升时间准则（851 s）
- "倍数准则"是丢了条件的误差预算表达；
- 正确：t_r,meas=√(t_r,scope²+t_r,probe²+t_r,signal²)，由允许误差反推带宽；
- 与 P45 同一方法论。

### P26 偏置器电路设计与仿真（1240 s）
- Bias-Tee：馈电电感低频高阻（L>>Z₀/ω），隔直电容低频低阻；
- 100 MHz 最低频 → L>500 nH、C>30 pF 量级（10 倍裕量）；
- 元件 SRF 决定上限，用带寄生模型仿真。

### P27 拐点频率深度解析（1398 s）
- 频谱两拐点：f₁=1/(πτ)（脉宽）、f₂=0.35/t_r（边沿）；
- f₂ 后 −40 dB/dec，但问题常在 f₂ 附近（能量+谐振）；
- 仿真建模到 2–3×f_knee。

### P28 走线电感：何时加宽走线（1229 s）
- L≈5.08l·[ln(2l/(w+h))+…]：长度线性、宽度对数；
- 加宽走线翻倍只降 ~15–20% 电感——缩短/多孔并联更有效；
- 加宽的正当理由：载流、阻抗配合、ESD 泄放路径。

### P29 IO 模型中的传输线传递函数（1569 s）
- IO 缓冲器不是理想阶跃源：有输出级、封装、On-die 端接的传递函数；
- IBIS/AMI 模型把这些打包——仿真精度上限由模型质量决定；
- 高速接口用 AMI（含均衡算法），普通 IO 用 IBIS。

### P30 保护走线真能降低串扰吗（840 s）
- 实测：两端接地 guard 改善仅 1–3 dB，某些频点更差；
- 密集多点缝合才有效（再降 3–6 dB）；
- 性价比低于拉间距/降介质高度。

### P31 保护走线与串扰进阶（823 s）
- 机理：guard 把边缘场截流就近入地——效果取决于接地电感与缝合密度；
- guard 与 victim 太近反而引入 guard 自身回流的耦合；
- 双刃剑：间距设计要平衡。

### P32 数模串扰（755 s）
- 三通道：共阻抗、场耦合、电源调制；
- 模拟信噪比损失不可恢复——优先级高于数字 SI 问题；
- 对策：分区布局 > 回流隔离 > 电源滤波。

### P33 端接适用场景（791 s）
- 决策流程：算 L_crit → 短线免端接 → 按拓扑选端接 → 仿真微调；
- 总线型用并联/戴维南，点对点用串阻，差分用片内 100 Ω；
- 端接是交易：功耗、幅度、边沿。

### P34 电源分割区上方走线（812 s）
- 跨缝：阻抗突变反射+串扰增大+缝隙天线；
- 对策：改道 > 换层 > 搭桥电容（窄带最后手段）；
- 电源域规划阶段就留"不跨缝通道"。

### P35 LibreVNA 测走线阻抗（1008 s）
- TDR 模式=对 S11 反 FFT → 阻抗 vs 距离剖面；
- 直接看到连接器/过孔/线宽变化的局部阻抗；
- 把 P17 的计算误差变成可测量。

### P36 Bogatin 访谈（1876 s）
- 公式、仿真、测量三者互相校验才是完整方法；
- 便宜仪器+正确方法 > 贵仪器+乱用；
- 教学顺序：物理图像先行，公式殿后。

### P37 差分走线真的需要参考地吗（943 s）
- 差分对不依赖"伴随地线"工作（对内互为参考）；
- 但仍需连续参考平面：控阻抗+回流+场束缚；
- "差分不需要地"被断章取义是常见事故源。

### P38 参考平面可以靠得多近（859 s）
- 越近越好有边界：线宽变细、同层耦合增大、平面电容与耐压；
- 实用区间：带状线 h≈0.10–0.15 mm；PWR-GND 3–4 mil 甜点；
- 用场求解器在"线宽可制造性"与"耦合"之间找平衡。

### P39 偏移参考平面导致失效（859 s）
- 计算器假设参考正对走线；平面边缘/分割边/反焊盘阵列造成横向偏移；
- 后果：C↓→Z₀↑+回流绕行；
- 规则：平面边缘离走线 ≥3 倍介质高度。

### P40 阻抗计算器中补偿传输线损耗（1022 s）
- 无损模型到 GHz 失真：导体损耗 √f + 介质损耗 f；
- 高频有效阻抗与衰减随频率变化——长通道必须用有损模型；
- 补偿思路：把 R、G 按频率拟合进模型。

### P41 介质损耗解析（56 s）
- α_d ∝ f·√εr·tanδ——tanδ 是关键；
- FR4 tanδ≈0.02（10 GHz 吃不消），低损材料 <0.005；
- 材料选型=速率×长度×成本三角。

### P42 色散分析可视化（72 s）
- 相速随频率变化 → 波形展宽；
- 群时延-频率曲线平坦度=色散程度；
- 来源：Dk 频变、导体损耗、过孔模态混合。

### P43 绘制反焊盘（828 s）
- 反焊盘决定孔-平面耦合：过大→孔阻抗高；过小→工艺风险+伪开槽；
- 特殊孔（背钻/大电流/射频）手工绘制；
- 与 P39/P44 同一几何主题。

### P44 反焊盘：规则 vs 绘图工具（71 s）
- 95% 交给设计规则（一致可批量）；
- 特殊孔单独建规则或手绘，改版需人工复查标注；
- 手绘区在丝印/注释层做醒目标记。

### P45 芯片手册 PCB 指导为什么往往不正确（1197 s）
- 同 EMI 篇第4讲：五根源+五步检验法；
- 对每条指南问机制、找假设、算一遍、查出处、实测；
- 详见 EMI 篇总结第六章。

### P46 DDR 过孔延时录入（741 s）
- 同 EMI 篇第3讲：等长≠等时、12 ps/孔、xSignals+Matched Length；
- 详见 EMI 篇总结第五章。

### P47 共面地正确设计（1169 s）
- 同 EMI 篇第2讲：缝合 λ/20、悬浮铜三宗罪、差分对内不放地铜；
- 详见 EMI 篇总结第四章。

### P48 过孔色散（1075 s）
- 孔的 L-C 结构使相速随频率变化——孔延迟不是常数；
- 表现：长孔链的台阶失真与确定性抖动；
- 缓解：短孔/背钻/回流地孔。

### P49 混合信号回流路径基础（120 s）
- P1 的 2 分钟速览版；
- 一句话：高频回流走环路最小路径，跨槽与换层是两大杀手。

### P50 去耦电容布局位置重要吗（1133 s）
- 有平面时 3 mm vs 10 mm 常测不出差别——回路电感才是对象；
- 收益排序：短过孔>贴平面侧>多颗分散>距离；
- 双层板例外（无平面，距离权重回升）。

### P51 AI 布局 vs 人工（1278 s）
- AI 能守住可量化约束（间距/阻抗）；
- 代差在回流意识、分区策略、EMC 直觉；
- 现实定位：AI 初稿 + 工程师机制审查。

### P52 糟糕 AI 布局：USB 连接器与二极管阵列（77 s）
- 实例：ESD 阵列远离连接器、TVS 接地回路绕远；
- 布局电感是"乘法关系"失效——AI 对此类不敏感；
- 人工审查重点=位置关系类规则。

### P53 AI 布局工具的黑盒难题（50 s）
- 给结果不给理由=不可审计；
- 高可靠产品要求可解释性；
- 人机分工：AI 提效率，人负责机制与责任。

### P0/P55 片头片尾
无技术内容。

## 二十一、SI 问题诊断案例库（六个典型场景）

> 与 EMI 篇案例库互补：EMI 案例看"辐射/抗扰"，这里看"波形/误码/时序"。每个案例按现象→诊断→根因→对策展开。

### 案例 1：SPI Flash 偶发读错，示波器看波形"没问题"

- **现象**：50 MHz QSPI 偶发 CRC 错误，探头点上波形看似干净；
- **诊断**：换短接地弹簧再测——发现时钟上升沿顶部有 ~200 mV 台阶；探头长地线把振铃滤掉了（地线电感与探头电容构成低通）；
- **根因**：时钟线换层处无回流地孔，回流绕行 → 局部阻抗突升 → 反射台阶；偶发错误来自台阶吃掉建立时间裕量 + 温度漂移；
- **对策**：换层孔旁补两个回流地孔；串阻 22 Ω 放缓边沿；
- **印证**：P1（回流）、P6（局部阻抗）、P33（端接）。

### 案例 2：千兆以太网链路降速协商到 100M

- **现象**：网口偶尔协商失败或降速，PHY 与变压器按参考设计画的；
- **诊断**：VNA 测差分对：100 MHz 处 Sdd21 出现 −8 dB 陷波；TDR 剖面显示 PHY 侧过孔处阻抗冲到 ~130 Ω；
- **根因**：过孔反焊盘过大 + 孔残桩 3 mm（1.6 mm 板全通孔但信号只到内层）→ 残桩谐振落在基频附近；
- **对策**：反焊盘收小、改盲孔、或背钻；走线换到带状线层；
- **印证**：P43（反焊盘）、P35（TDR 实测）、P48（过孔）。

### 案例 3：DDR3 写均衡通不过，几何等长"完美"

- **现象**：地址/数据等长报告 ±5 ps 级完美，write leveling 训练失败；
- **诊断**：检查发现 DQS 与 DQ 的过孔数量差 3 个（12 ps×3=36 ps 差异）；封装长度未录入；
- **根因**：等长≠等时（详见 EMI 篇第3讲）；
- **对策**：xSignals + 过孔延迟按层对录入 + 封装长度补上；
- **印证**：P46（交叉引用 EMI 篇第五章）。

### 案例 4：模拟前端底噪比设计值高 20 dB

- **现象**：ADC 采集底噪超标，模拟区与数字区已"分割地"；
- **诊断**：近场探头发现数字回流绕经分割缝末端的"桥"（为了连通两地强行搭的窄桥）——分割没隔离回流，反而把数字回流压缩到窄桥上集中噪声；模拟前端电源来自"加磁珠"的数字电源，磁珠后电容小，LC 振铃在 30 MHz；
- **根因**：P2（分割地错误）+ P4（磁珠欠阻尼）双重叠加；
- **对策**：改统一连续地 + 分区布局；磁珠后加大电容并核阻尼；ADC 基准独立 LDO；
- **印证**：P2、P4、P32。

### 案例 5：PCIE Gen3 通道插损超标 3 dB @ 8 GHz

- **现象**：PCIe 通道长度 ~18 cm，链路训练降速；
- **诊断**：通道 S 参数分解损耗构成：介质损耗占大头（FR4 tanδ 0.02）；一对过孔残桩谐振 12 GHz 未处理；两处 90° 换层孔无回流孔；
- **根因**：材料等级与通道长度不匹配（P41）+ 过孔高频缺陷（P48/P43）；
- **对策**：换低损板材（tanδ<0.008）或缩短通道/中继；背钻；优化反焊盘；
- **印证**：P40/P41/P48、P24（按规范模板核算）。

### 案例 6：加宽走线后 EMI 反而变差

- **现象**：为"降电感"把时钟线从 0.15 mm 加宽到 0.5 mm，近场辐射反而抬升；
- **诊断**：加宽后走线与两侧地铜间距 <2 倍介质高度——共面耦合改变阻抗且回流重新分配，部分回流被挤到远处绕行；
- **根因**：P28 的"宽度对数收益"被误用 + P39 偏移参考效应；
- **对策**：恢复合理线宽（按阻抗目标）；降电感改用缩路径+换层就近回流孔；
- **印证**：P28、P39。

### 案例库小结：SI 诊断路径模板

```
波形/误码问题
  ├ 探头先自查（接地弹簧、带宽、位置）——先排除测量假象
  ├ 静态看阻抗剖面（TDR/TDR 模式）→ 找突变点（过孔/反焊盘/参考偏移）
  ├ 频域看 Sdd21 陷波 → 对应谐振（残桩/λ/4/反焊盘阵列）
  ├ 时序问题 → 检查"等长还是等时"（过孔/封装延迟）
  └ 模拟域问题 → 先查回流与电源，再查场耦合
```

## 二十二、高频问答 10 问

**Q1：50 Ω 是计算出来的还是规定的？**
历史惯例+工程折中：气体击穿/功率与损耗的平衡点附近，且早期测试设备定为 50 Ω，沿用至今。PCB 上 LVDS 100、USB 90 等是接口规范规定，不必纠结"为什么不是 50"。

**Q2：我走线 3 cm、边沿 2 ns，需要端接吗？**
L_crit ≈ t_r·v/6 ≈ 2 ns × 175 mm/ns / 6 ≈ 58 mm——3 cm 是短线，可不端接；但注意换层孔与参考连续性。

**Q3：差分线的间距怎么定？**
先选流派：紧耦合（间距 2–3 倍线宽，抗噪省空间）或松耦合（间距 ≥4 倍线宽，公差容忍）。然后按目标差分阻抗用场求解器反推，全板统一。

**Q4：为什么我的串阻端接波形还是有振铃？**
串阻只消源端反射。振铃还可能来自：串阻位置不对（要在驱动器最近处）、线中间有阻抗突变（过孔/换层）、探头假象（长地线）。逐项排查。

**Q5：IBIS 模型哪里找？不准怎么办？**
厂商官网/芯片支持包。不准时：换更高版本、用 IBIS-AMI（高速接口）、或用实测（P15/P35/P20）反推行为。

**Q6：内层带状线不好散热，怎么办？**
带状线的热瓶颈在大电流线——大电流走外层（微带+铜厚），高速小信号走内层；两者按"谁需要什么"分层，不必一刀切。

**Q7：保护走线到底还做不做？**
默认不做；高阻模拟节点等特殊场景做，且必须密集缝合（P30/P31）。

**Q8：磁珠选型看哪三个参数？**
@噪声频点的阻抗（阻性成分）、直流偏置下的衰减曲线（偏置饱和）、DCR 与额定电流；再加 LC 谐振阻尼核算（P4）。

**Q9：过孔残桩多长才需要处理？**
看信号带宽与残桩谐振：t_stub 对应频率落在信号 5–7 次谐波内就要处理；经验 1.6 mm 板全通孔无碍，厚板浅层信号必处理（EMI 篇 5.3 算例表）。

**Q10：学习 SI 最小动手装备是什么？**
示波器（≥200 MHz）+ 短接地弹簧 + 一块有已知缺陷的练习板 + LibreVNA（可选）——P15/P35 的路线：校准→测量→与计算器对比→解释偏差。

## 二十四、核心算例集（12 个完整计算，带步骤）

> 前文给了公式，这里把最常用的 12 个算例按"已知→公式→代入→结论→设计动作"完整走一遍，可直接当模板用。

### 算例 1：判断走线是否需要端接

- 已知：FPGA IO 边沿 t_r = 300 ps，走线长 60 mm，FR4 带状线；
- 公式：L_crit ≈ t_r·v/6；v ≈ 150 mm/ns；
- 代入：L_crit = 0.3 ns × 150 mm/ns / 6 = **7.5 mm**；
- 结论：60 mm >> 7.5 mm，**必须按传输线处理并端接**；
- 动作：源端串阻（约 Z₀ − 驱动内阻）+ 全程控阻抗 50 Ω。

### 算例 2：由目标阻抗反推线宽（量级估计）

- 已知：微带，介质 h = 0.1 mm，εr = 4.2，目标 50 Ω；
- 直觉公式：w ≈ 2h（50 Ω 微带经验）；
- 结论：w ≈ 0.2 mm；
- 动作：把 w=0.2 mm、h=0.1 mm、εr=4.2、铜厚 35 μm 输入场求解器复核，与板厂书面回签；实际以 Si9000 结果为准（本步只建立量感）。

### 算例 3：反射台阶幅度

- 已知：Z₀ = 50 Ω 走线中途经过一段 65 Ω 区域（参考偏移）；
- 公式：Γ = (65−50)/(65+50) = 0.13；
- 结论：约 **13% 的入射幅度正反射**——3.3 V 逻辑上是 ~430 mV 台阶，足以侵占噪声裕量；
- 动作：消除参考偏移（P39）。

### 算例 4：边沿经过通道后的退化

- 已知：驱动 t_r = 200 ps，通道 BW = 1.5 GHz；
- 公式：t_r,out = √(t_r,in² + t_r,ch²)，t_r,ch ≈ 0.35/BW = 233 ps；
- 代入：√(200² + 233²) ≈ **307 ps**；
- 结论：边沿退化 53%——如果时序预算按 200 ps 算就错了；
- 动作：通道带宽上提（缩短/换低损材料）或时序按 307 ps 重新预算。

### 算例 5：相邻走线耦合系数量级

- 已知：带状线、间距 s = 0.2 mm、介质 h = 0.1 mm、平行长度 50 mm；
- 经验：耦合系数 k ≈ (1/(1+(s/h)²)) 的量级；s/h = 2 → k ≈ 0.2 的场重叠 → 串扰系数约 2–5%；
- 结论：50 mm 平行走线上 1 V 阶跃 → 邻线 ~20–50 mV 串扰；
- 动作：关键线间距翻倍或降介质高度；串扰预算内则接受。

### 算例 6：NEXT/FEXT 的方向性判断

- 已知：受害线在 aggressor 打印端测（NEXT）与远端测（FEXT），拓扑为微带长线；
- 结论：微带 FEXT 随长度累积（容性感性速度差不抵消）；带状线 FEXT→0、NEXT 随长度增长；
- 动作：把敏感线放带状线层，长平行走线的远端就安全一半。

### 算例 7：源端串阻取值

- 已知：Z₀ = 50 Ω，驱动器输出阻抗 ≈ 20 Ω；
- 公式：Rs = Z₀ − R_driver；
- 结论：Rs ≈ **30 Ω**（取标准值 33 Ω 或 27 Ω 实测微调）；
- 动作：串阻靠近驱动器引脚放置；用 P20 工具扫 22/27/33/39 Ω 对比波形。

### 算例 8：并联端接功耗

- 已知：50 Ω 并联端接到 GND，驱动高电平 3.3 V，8 根数据线持续翻转占空 50%；
- 功耗：每根 P = (3.3/2)²/50 ≈ 109 mW 平均，8 根 ≈ **0.87 W**；
- 结论：总线型慢速系统不可接受 → 改源端串阻或戴维南（上拉到中间电平减半摆幅电流）；
- 动作：端接方式选择必须过功耗核算。

### 算例 9：集肤效应下的交流电阻

- 已知：0.2 mm 宽走线，f = 1 GHz，δ = 2.1 μm；
- 近似：电流集中在周长 × δ 的截面：A_ac ≈ 2×(0.2+0.035) mm × 2.1 μm ≈ 9.9×10⁻¹⁰ m²；
- R_ac = ρ/A_ac ≈ 1.7×10⁻⁸ / 9.9×10⁻¹⁰ ≈ **17 Ω/m**——直流电阻（0.44 Ω/m）的近 40 倍；
- 动作：长线损耗预算按交流电阻算；高速线选低粗糙度铜箔。

### 算例 10：介质损耗比较

- 已知：10 cm 通道 @ 5 GHz；FR4 tanδ=0.02 vs 低损板 tanδ=0.008；
- α_d ≈ π·f·√εr·tanδ/c；FR4：≈27.9×10⁹×0.02×2.05×π/3×10⁸ → 约 1.2 dB/10 cm？逐步：π×5×10⁹×2.05×0.02/3×10⁸ ≈ **0.215 dB/cm → 2.15 dB/10 cm**；低损板 → 0.86 dB/10 cm；
- 结论：仅介质损耗一项差 **1.3 dB**，加上导体损耗与粗糙度差距更大；
- 动作：>5 Gbps 长通道换低损板，或缩长度/加均衡。

### 算例 11：磁珠-电容谐振阻尼核算

- 已知：磁珠 1 μH（@低频），后级 10 μF；
- f₀ = 1/(2π√(1 μH×10 μF)) ≈ **1.6 MHz**；Q 取决于磁珠 @1.6 MHz 的阻性分量；
- 结论：若磁珠 @1.6 MHz 呈纯感性（R 小），负载阶跃时振铃严重；
- 动作：选 @1.6 MHz 已呈阻性的磁珠（600 Ω@100 MHz 型号通常在低频感性太强——要看阻抗-频率曲线的 R/X 分解），或并联阻尼电阻。

### 算例 12：时钟线避开 λ/4 谐振

- 已知：25 MHz 时钟关注 5 次谐波 125 MHz，FR4 微带 v≈175 mm/ns → λ ≈ 1.4 m，λ/4 ≈ 350 mm；
- 结论：板内走线远短于 λ/4，谐振风险低；但**线缆级连接（外接时钟线 30 cm）时 125 MHz 的 λ/4≈30 cm 恰好命中**——外接线缆上的时钟谐波是重灾区；
- 动作：线缆口滤波/共模抑制（与 EMI 篇第1讲接口防护衔接）。

## 二十五、端接方案详解补充（电路与选择流程）

### 25.1 四种端接的电路速记

```
① 串联(源端):     驱动 ──[Rs]════════════════ 受容(高阻输入)
                  Rs ≈ Z₀ − R_driver；功耗低；点对点首选

② 并联(负载端):   ════════┬──────── 受容
                        [R=Z₀]
                          │
                         GND      幅度减半+静态功耗；总线型

③ 戴维南:         Vcc ──[R1]──┬──════════ 受容
                              │
                       GND ──[R2]
                  R1∥R2=Z₀；分压定偏置；总线+带偏置需求

④ AC 端接:        ════════┬──[C]──[R=Z₀]──GND
                  无静态功耗；C 引入低频反射尾巴；时钟类适用
```

### 25.2 选择流程（决策树）

```
线长 < L_crit？ ──是──→ 不端接，做好回流即可
    │否
点对点？ ──是──→ 源端串阻（驱动器最近）
    │否（多负载）
负载可吸收静态功耗？ ──是──→ 并联/戴维南（负载端居中布置）
    │否
时钟/周期信号？ ──是──→ AC 端接
    │否
改拓扑（缩短分支/菊花链）+ 片内端接（OSERDES/LVDS 自带）
```

### 25.3 端接的常见翻车点

- 串阻放错了位置（放到负载端 = 无效）；
- 并联端接阻值用了"标称 50 Ω"但通道实际 45 Ω（TDR 回签后再定）；
- 戴维南分压把静态工作点拉到驱动器线性区边缘；
- 差分线只端接了单端（必须按差分阻抗端接或用片内端接）。

## 二十六、串扰定量估算补充

### 26.1 耦合参数的定义

- 单位长度互容 C_m、互感 L_m 由截面几何决定（场求解器输出）；
- 近端串扰系数（NEXT）：

```
K_N ≈ (1/4)·( C_m/C + L_m/L )      带状线/微带通用近似
```

- 远端串扰系数（FEXT）：

```
K_F ≈ (1/2)·( C_m/C − L_m/L )·l·(v/长度项)     均匀介质中 C_m/C = L_m/L → K_F→0
```

- **读法**：带状线中容性与感性 FEXT 相消（K_F→0）；微带中介质不对称使两者不平衡 → FEXT 显著；
- NEXT 与耦合长度成正比、与边沿成反比（边沿越快串扰脉冲越窄但峰值不变——峰值由 K_N 决定）。

### 26.2 串扰预算流程

1. 列出 aggressor 的 dv/dt、di/dt（由 t_r 与摆幅算）；
2. 场求解器/经验表得 K_N、K_F；
3. victim 上的串扰峰值 ≈ K_N × 摆幅；
4. 与 victim 噪声裕量比较（如 CMOS 裕量 ~0.3×VDD）；
5. 超标则按"拉间距/降 h/换带状线/加缝合"顺序迭代。

### 26.3 3W 与间距的真实含义

- 3W 让 s/h ≈ 2–3（典型 h 下）→ K_N ~2–4%；
- 但同样的 K_N，把 h 减半也能拿到——**3W 不是目标，K_N 才是**；
- 高密度板的正确动作：先定串扰预算，再反推允许的 s/h 组合。

## 二十七、S 参数使用实务补充

### 27.1 从拿到 Touchstone 到可信结论的流程

1. **看元数据**：端口定义、参考阻抗、参考面、频段与点数；
2. **检查因果性/无源性**（工具自带检查项）：无源性被破坏的模型在仿真中会"自激"；
3. **看 S11/S21 全貌**：陷波位置对应谐振（残桩/腔体），缓坡对应损耗；
4. **模态变换**（差分通道）：把 4 端口单端 S 参数按混合模态变换成 Sdd/Scc/Scd/Sdc——Scd/Sdc（模态转换）大 = 差分对称性差 = 共模泄漏；
5. **时域反演**：对 S11 反 FFT 得 TDR 阻抗剖面，对 S21 反 FFT 得冲激响应——与实测示波器结果互验。

### 27.2 VNA 测量的常见坑

- 校准件与夹具不匹配（N/SMA/板内 coupon）→ 低频段全错；
- 动态范围不够 → 深陷波（−40 dB 以下）测不准，误判谐振深度；
- 未做去嵌入 → 夹具损耗计入 DUT；
- 测试电缆弯折后未复校 → 相位漂移，TDR 剖面错位。

### 27.3 与 EDA 仿真数据的互验

- EDA 抽取的通道 S 参数 vs VNA 实测：先比相位（延迟差 = 叠层速度假设差），再比幅值（损耗差 = Dk/tanδ/粗糙度假设差）；
- 偏差定位到参数后回写材料库——**这就是 P36 说的"三者互验"的具体操作**。

## 二十八、叠层与阻抗协同设计流程（打通 SI 与 EMI 两课）

> SI 课管"阻抗与串扰"，EMI 课管"参考与辐射"，两者在同一张叠层表上交汇。这里给出把两课结论合并执行的完整流程。

1. **需求清单**：接口类型与速率（定阻抗目标）、时钟清单（定 f_knee）、电源域（定平面）、EMC 目标等级；
2. **层数初定**：布线容量 + 每个高速域一条带状线层 + PWR-GND 对；
3. **叠层草案**（以 6 层为例）：
   - EMI 结论：每信号层有相邻完整 GND；关键线内层；PWR-GND 薄介质；
   - SI 结论：带状线对称参考；参考偏移管控；差分紧/松耦合统一；
4. **阻抗定稿**：场求解器反推线宽/间距/介质 → 写入叠层表；
5. **规则落地**：Altium 规则集（线宽/间距/差分/长度/过孔策略）+ 团队 checklist；
6. **布线中三查**：换层回流孔、跨分割、保护走线（禁两端接地）；
7. **验证**：通道 S 参数/眼图仿真 → 板厂 TDR 回签 → 样机近场扫描；
8. **闭环**：偏差回写材料库与规则库（P36 三者互验）。

## 二十九、重点课题深挖（五讲合并精读）

### 29.1 深挖一：传输线的物理图像——"波"与"场"（整合 P5/P6/P18）

**为什么会有特性阻抗**：信号传播的本质是电磁场沿介质的传播。信号前沿经过的每一段，导体上的电荷分布建立电场（→电容 C），磁场环绕导体（→电感 L）。前沿处持续"开户"新的 C 和 L，驱动源看到的瞬时阻抗就是 dV/dI = √(L/C)。三个推论：

1. **Z₀ 与长度无关**——每一步都一样；
2. **Z₀ 只由横截面几何与材料决定**——这就是"画叠层定阻抗"的物理基础；
3. **改变几何 = 改变 Z₀**——线宽、介质高、参考偏移、阻焊都是"几何"的一部分（P17 的误差清单其实就是"没算进去的几何"）。

**反射的场图像**：阻抗突变处，场不能连续——一部分能量被反射回源，就像绳子上的波打到粗细变化的结点。"阻抗匹配"就是让结点两侧的"绳子粗细"一致。

**损耗的场图像**（整合 P18/P40/P41）：

- 导体损耗：场把电流挤进表层（集肤），有效截面缩小；
- 介质损耗：场在介质中反复极化，分子"摩擦"发热，∝f·tanδ；
- 辐射损耗：场束缚不牢（参考远、结构谐振）时能量漏到空间——这也是 EMI 的来源；
- 三者都随频率上升 → 通道像低通滤波器 → 边沿退化（算例 4）→ 码间干扰。

### 29.2 深挖二：回流路径的四种典型错误与修复（整合 P1–P3/P49/P39/P34）

| 错误 | 场景 | 后果 | 修复 |
|---|---|---|---|
| ① 换层不补回流孔 | 高速线从 L1 换到 L3 | 回流从 L2 "换轨"时绕远，局部环路 → 尖峰串扰与 EMI | 换层孔旁 1–2 个 GND 过孔（若参考层对是 PWR-GND 则换成对缝合孔） |
| ② 跨电源分割 | 信号横穿 3.3 V/1.8 V 域缝 | 回流断路 → 绕行或耦合过缝 | 改道/换层；规划电源域时留通道 |
| ③ 参考平面边缘走线 | 平面缩进、板边走线 | 边缘耦合缺失 → Z₀ 升 + 辐射增强 | 离平面边缘 ≥3h；板边走线内移 |
| ④ 分割地"隔离" | 数模分割地 + 信号跨缝 | 回流集中在窄桥 → 公共阻抗耦合暴涨 | 统一连续地 + 分区布局 |

**审查方法**（把"回流在哪里"变成可执行动作）：

1. 高亮关键网络 → 显示其所有换层孔；
2. 对每个换层孔：确认参考层、确认就近有回流孔；
3. 显示平面层 → 沿走线走廊检查连续性（反焊盘阵列、分割、边缘）；
4. 对外接口线：回流能一路低阻抗走到连接器地。

### 29.3 深挖三：混合信号 ADC 系统布局全流程（整合 P2/P3/P32/P4/P10）

以"MCU + 外置 16 位 ADC + 传感器前端"为例：

**第一步：分区与方向**

- 板面划三区：数字区（MCU/存储/USB）、混合区（ADC+基准+驱动）、电源区（DC-DC 在最远端，LDO 靠 ADC）；
- 传感器/接口在板边，模拟信号从板边单向流入混合区——**避免模拟线横穿数字区**。

**第二步：地与回流**

- 统一连续 GND 平面（不分割）；
- ADC 的"模拟回流区"（AGND 引脚 + 基准去耦地 + 输入驱动器地）在平面上是一个局部安静区——靠布局让数字回流不经过这里，而不是靠割铜；
- ADC 下方平面完整；基准电容、去耦电容的地全部就近入这个安静区。

**第三步：电源**

- ADC 模拟电源：LDO 就近 + 磁珠隔离数字残余噪声（按 P4 核阻尼：磁珠-电容谐振点避开信号半功率点，或选阻性磁珠）；
- 基准（REF）：独立去耦（10 μF + 100 nF 紧贴），基准走线短粗且回流区安静；
- 数字电源与模拟电源各自平面域，分割缝上无信号跨越。

**第四步：信号**

- 差分输入对称等长、参考层连续（P37/P39）；
- 采样时钟：从干净时钟域来，串阻放缓边沿，远离开关电感；
- SPI/数字总线远离模拟输入走线（间距 ≥3h 或不同层）。

**第五步：复查清单**

- [ ] 数字回流路径不穿模拟区（3.2 的审查法）；
- [ ] 磁珠后 LC 阻尼核过（P4）；
- [ ] 基准/模拟电源去耦的安装电感最低（短孔）；
- [ ] 时钟抖动预算核过（抖动 → SNR 损失：SNR = −20log(2π·f_in·t_jitter)）。

### 29.4 深挖四：高速差分对设计全流程（USB 3.0 实例，整合 P8/P37/P38/P39/P43）

**参数目标**：90 Ω 差分、5 Gbps、通道长 8 cm、两个过孔。

1. **叠层选位**：L1 微带起端 → 换层到 L3 带状线（对称参考）→ L1 出连接器；L3 上下 GND；
2. **线宽/间距**：场求解器按"紧耦合"流派：间距 = 2.5×线宽，反推 w 与 gap 满足 90 Ω ±10%；
3. **过孔处理**：
   - 孔径尽量小（0.2–0.25 mm）；
   - 反焊盘收小到耦合适中（P43）；
   - 残桩：1.6 mm 板信号到 L3 → 残桩 ~0.8 mm（谐振 >40 GHz，可接受）；若信号只到 L2 则必须背钻；
   - 每个信号过孔旁一对回流 GND 孔（间距 ≤0.5 mm）；
4. **换层与参考**：换层处回流从 L2 → L5？若是 PWR-GND 对，加缝合电容；本例 L2/L4 都 GND 则直接地孔；
5. **对称性**：两根线过孔数量、位置镜像；长度差 <5 mil（0.127 mm）；等长补偿放在最不敏感段；
6. **防护**：低容 TVS（Cj<0.5 pF）靠近连接器，镜像对称（与 EMI 篇第1讲接口防护链衔接）；
7. **验证**：通道仿真眼图（含 S 参数）→ 板厂阻抗回签 → 实测眼图模板（合规测试）。

**差分设计的三条铁律**（P37/P8 提炼）：

1. 对称性 > 一切（对称性破坏 = 模态转换 = 共模泄漏 = EMI）；
2. 参考平面连续是前提，"差分不需要地"不适用于参考层；
3. 紧耦合流派下间距公差也是阻抗公差——布线时管住间距漂移。

### 29.5 深挖五：时钟分配与抖动入门（整合 P9/P23/P27/P36）

- **时钟是板上最危险的信号**：周期性 → 谐波能量集中（P27），且扇出多、线长长；
- 两大危害方向：自身被干扰（抖动→采样错误）与干扰别人（谐波辐射）；
- **抖动的 SI 视角**：电源噪声 → 缓冲器延迟调制 → 随机抖动（RJ）；串扰/反射 → 确定性抖动（DJ）；
- SNR 限制公式：SNR_jitter = −20·log10(2π·f_in·t_jitter)——40 MHz 输入、1 ps 抖动 → 约 78 dB；输入频率每翻倍 SNR 掉 6 dB——**高速采样系统的时钟品质比 ADC 位数更先成为瓶颈**；
- 布线策略：
  - 时钟走内层带状线（FEXT 抵消 + 场束缚）；
  - 时钟线避开 λ/4 谐振长度（算例 12）；
  - 扇出用低抖动缓冲器，各分支等长；
  - 时钟电源脚独立去耦 + 磁珠隔离（核阻尼）；
- 修改手段优先级：**降谐波能量（边沿/展频）> 布线隔离 > 屏蔽**。

## 三十一、整板 SI 走查实例（从原理图到布线的完整叙事）

> 把全集方法装进一次真实走查：一块"MCU + QSPI Flash + 千兆 PHY + USB 2.0 + DC-DC + LDO"的四层板。走查按信号分组推进，每一步给出"查什么、怎么判、不过怎么办"。

### 31.1 走查准备

- 输入清单：所有网络的 t_r（查芯片手册 IO 规格）、数据率、拓扑；
- 分组：**A 组传输线**（t_r·v/6 < 线长的网络：QSPI@50 MHz、RMII 50 MHz 时钟、USB、PHY 差分对）；**B 组慢信号**（I2C、UART、GPIO、使能）；
- 叠层确认：4 层 `SIG-GND-PWR-SIG`，PWR-GND 介质 0.11 mm——底层走线参考 PWR（已知短板，走查时重点盯）。

### 31.2 A 组走查（传输线网络）

**PHY 差分对（100 Ω）**：

- 阻抗：场求解器按当前叠层反推 w/gap，写入规则；板厂回签 TDR；
- 拓扑：点对点，PHY 内置端接——不外加电阻；
- 参考与回流：走 L1 微带全程，无换层 → 回流无忧；平面边缘距离 ≥3h 复核；
- 对称性：长度差 <5 mil、过孔镜像、TVS 阵列镜像对称；
- 判定：过。

**RMII 50 MHz 时钟（t_r = 1 ns）**：

- L_crit ≈ 29 mm，实际 45 mm → 传输线处理；
- 端接：源端串阻 33 Ω（扫值确认）；
- 长度：45 mm，避开了 50 MHz×7 次谐波 λ/4 陷阱（≈1 m 量级，远未到）；
- 参考连续性：走 L1，参考 L2 GND 完整；换层一次，孔旁补地孔；
- 判定：过。

**QSPI @50 MHz（t_r = 2.5 ns）**：

- L_crit ≈ 73 mm，最长线 60 mm——边界情况；
- 决策：不端接但收紧边沿（串阻 22 Ω 放缓到 4 ns，L_crit 升到 117 mm，彻底脱离传输线区）——**用放缓边沿换免端接**，这是慢总线的最优解；
- Flash 的 IO 电容负载大（10 pF×2 器件），串阻同时抑制容性负载振铃；
- 判定：过（带条件：串阻必须贴 MCU 引脚）。

**USB 2.0 差分（90 Ω）**：

- 低容 TVS（Cj≤1 pF）+ D+/D− 等长 ±1 mm + 镜像；
- TVS 接地过孔双孔入 L2 GND；
- 判定：过。

### 31.3 B 组走查（慢信号）

- I2C：上拉 4.7 kΩ、走线 <20 cm、总线电容 <400 pF 核算；
- 使能/复位：远离开关电感与晶振；下拉电阻确定默认态；
- 判定：过。

### 31.4 电源与地走查

- DC-DC（1.5 MHz，t_r≈15 ns）热环路面积最小：输入电容-芯片-电感紧凑布局；SW 节点铜皮适中（兼顾 EMI 与散热）；
- 输出磁珠（给模拟 LDO 前级）：核 P4 阻尼——磁珠 @100 kHz 呈感性、后级 22 μF，f₀≈3.4 kHz 远离开关频段，且负载电流小（<50 mA）→ 可接受；
- PWR 平面分割：3.3 V 与 1.2 V 分割缝——检查无信号跨越（RMII 时钟原本要跨，已改为绕行）；
- 去耦：每电源脚 100 nF 短孔入平面；DC-DC 输入 10 μF+0.1 μF 组合贴热环路；
- L2 GND 平面完整性：反焊盘阵列检查无"伪开槽"；缝合孔沿板边 ≤λ/20（按 f_knee=175 MHz → λ/20≈48 mm，轻松满足）。

### 31.5 走查结论与遗留项

- 全部 A 组网络通过，两个带条件项（QSPI 串阻位置、时钟串阻值待扫值）；
- 遗留风险：底层参考 PWR 的走线（复位线）在 PWR 分割缝附近——已改道；
- 后续动作：布线后跑 Altium SI 反射分析复核串阻值；样板后示波器+接地弹簧实测 A 组波形。

### 31.6 这次走查用到的分P索引

P1/P49（回流审查）、P5/P6（传输线判据）、P11/P33（端接选择）、P16（串扰间距）、P20（串阻扫值）、P4（磁珠阻尼）、P34（跨分割）、P39（边缘参考）、P43（反焊盘）、P12/P17（阻抗回签）、P25（测量准备：接地弹簧）。

## 三十二、常见错误清单 30 条（按"症状 → 错误 → 纠正"）

### 波形类

1. **过冲振铃** → 未端接/串阻缺失或值错 → 按 L_crit 判据+串阻扫值；
2. **台阶** → 换层无回流孔/参考偏移 → 补地孔/修参考；
3. **边沿变缓超预期** → 通道带宽不足或串阻过大 → 算 t_r 合成公式；
4. **单调性破坏（回勾）** → 容性负载+感性走线 → 缩短、串阻、减过孔；
5. **差分偏斜** → 过孔数不等/等长只在几何层面 → 录入过孔延迟、镜像布线。

### 布局类

6. TVS 远离连接器 → 防护失效（EMI 篇第1讲）；
7. 晶振环路内走其他信号 → 调制与辐射；
8. 数字回流穿模拟区 → 数模串扰（P32）；
9. 去耦电容级联串糖葫芦 → 中点电感抵消平面电容（P50）；
10. 连接器地未与板地多孔连接 → 共模出口高阻（EMI 篇）。

### 叠层类

11. 信号层无相邻参考 → 重画叠层；
12. GND 平面被分割 → 恢复完整；
13. PWR-GND 介质过厚 → 平面电容损失；
14. 底层全靠 PWR 参考 → 关键线移到 GND 参考层；
15. 层序不对称 → 翘曲。

### 阻抗类

16. 信任计算器默认 Dk → 按频率与树脂含量修正（P17）；
17. 忽略阻焊降阻 → 表层微带按盖油建模；
18. 差分间距漂移 → 紧耦合下间距也是阻抗（P8）；
19. 未做 TDR 回签 → 首件即验证；
20. 参考偏移无审查（P39）。

### 串扰类

21. 只拉间距不管介质高度（P16）；
22. 两端接地 guard trace（P30）；
23. 长平行走线无长度预算 → NEXT 累积；
24. 敏感线放微带层受 FEXT（P16）。

### 电源类

25. 磁珠当稳压用（P4）；
26. 信号跨电源缝（P34）；
27. 去耦只堆数量不看安装电感（P50）；
28. DC-DC 热环路面积大 → 开关噪声全板扩散。

### 方法论类

29. 盲信手册指南与"倍数准则"（P25/P45）；
30. 仿真模型不查三性就跑（P14）。

## 三十四、概念对比表集（易混概念一页清）

| 对比 | 区别要点 |
|---|---|
| Z₀ vs Z_in | 几何属性 vs 端口属性（随长度/频率/端接变化） |
| 共轭匹配 vs 无反射匹配 | Z_L*（最大功率）vs Z_L（零反射）；数字要后者 |
| NEXT vs FEXT | 近端持续 vs 远端脉冲；带状线 FEXT→0 |
| 串联 vs 并联端接 | 源端消反射低功耗 vs 负载端零反射耗功耗 |
| 微带 vs 带状线 | 快/易修/有 FEXT vs 慢/屏蔽好/FEXT 抵消 |
| 集肤效应 vs 邻近效应 | 自身场挤压 vs 相邻导体场挤压；都 ∝√f 加剧损耗 |
| Dk vs Df | 介电常数（阻抗/速度）vs 损耗因子（衰减） |
| NRZ vs PAM-4 | 2 电平全带宽 vs 4 电平半带宽但眼高 1/3 |
| RJ vs DJ | 随机抖动（高斯、电源噪声）vs 确定性抖动（串扰/反射/周期） |
| IBIS vs IBIS-AMI | 行为级查表 vs 带均衡算法（SerDes 必需） |
| TDR vs VNA | 时域阻抗剖面 vs 频域散射参数；TDR=VNA 反 FFT |
| 反焊盘 vs 隔离盘 | 平面挖空（孔-平面耦合）vs 焊盘隔离（孔-走线连接） |
| 分割地 vs 分区布局 | 错误的隔离手段 vs 正确的回流管理 |
| 等长 vs 等时 | 几何长度 vs 飞行时间（过孔/封装延迟） |

## 三十五、叠层阻抗设计完整算例（六层板从参数到叠层表）

> 把 P5/P12/P17/P38/P41 的知识合并成一次完整的六层板阻抗设计演练，输出一张可发给板厂的叠层表。

### 35.1 设计输入

- 高速接口：USB 3.0 差分 90 Ω（一对）、RMII 50 Ω 单端；
- 时钟/总线：DDR3L-1600 数据组（+PCB 走线 ≤8 cm）；
- 电源：5 V 输入 → 3.3 V/1.2 V 两域；
- EMC 目标：Class B。

### 35.2 叠层方案确定

采用 EMI 篇方案 B（双地夹带状线）：

```
L1 SIG (微带)     —— USB、低速信号
L2 GND
L3 SIG (对称带状线) —— DDR、RMII 时钟（最优层）
L4 GND
L5 PWR (3.3V/1.2V 分域)
L6 SIG (微带)     —— 电阻、低速
```

- P46 交叉：DDR 走 L3，等长按"等时"录入过孔延迟；
- P38 核对：L3 上下介质对称（各 0.12 mm），线宽可制造；
- P10 核对：不走 L6 高速线（参考 PWR，需换轨）。

### 35.3 阻抗计算（场求解器输入/输出）

| 目标 | 层 | 参考几何 | 求解结果（示例） |
|---|---|---|---|
| 单端 50 Ω | L3 带状线 | 上下各 0.12 mm，εr 4.2，铜 1 oz | w = 0.11 mm |
| 差分 90 Ω | L1 微带 | h = 0.107 mm（含阻焊建模） | w = 0.22 mm，gap = 0.13 mm |
| 单端 50 Ω | L1 微带 | 同上 | w = 0.21 mm |

误差修正（P17 六项）逐项过：

1. Dk：按 1 GHz 实测值 4.05（而非手册 4.2@1 MHz）重算；
2. 有效铜厚：外层电镀后按 45 μm；
3. 蚀刻梯形：按底/顶宽差 20 μm 建模；
4. 阻焊：L1 按盖油（25 μm，εr 3.3）建模——阻抗降约 2 Ω，已在 w/gap 中补偿；
5. 粗糙度：影响损耗不显著影响阻抗，标注 RTF 铜箔；
6. 压合公差：±10% 写入公差栏。

### 35.4 输出：制板说明叠层表（可直接抄的模板）

```

  Core        εr=4.2          0.30 mm

  PP 7628×1   εr(1GHz)=4.05   0.12 mm

  Core        εr=4.2          0.30 mm
```

### 35.5 布线期的约束落地

- Altium 规则集：线宽/间距按 35.3 结果、差分对规则、长度规则（DDR 组按等时+过孔延迟）、过孔策略（信号孔 0.25 mm、电源孔 0.3/0.5 mm）；

## 三十八、结语：这门课真正要带走的东西

如果 55 讲只能压缩成五句话，是这五句：

1. **回流先于信号**：画信号之前先想回流在哪里——回流决定阻抗、串扰、EMI 的一切表现（P1–P4）；
2. **几何决定阻抗**：Z₀=√(L/C)，算的是截面；算不准是因为有六类"没算进去的几何与材料"（P5/P12/P17）；
3. **边沿决定带宽**：1 Mbps 的线配 500 ps 边沿就是 700 MHz 问题；放缓边沿是最便宜的 SI/EMI 对策（P9/P25/P27）；
4. **端接是交易**：串阻、并联、戴维南、AC，每种都在拿功耗/幅度/边沿换反射；先判短线免端接，再按拓扑选型（P11/P19/P33）；
5. **三者互验才算懂**：公式、仿真、测量互相校验，偏差回写规则库——工程师的成长速度取决于这个闭环转多快（P15/P20/P24/P36）。

再往上一层，是这门课反复示范的**方法论姿态**：对任何规则（25% 准则、3W、手册指南、乃至 AI 布局结果）都问四个问题——机制是什么、条件是什么、我能算一遍吗、我测过吗。答案齐了，规则才是你的；缺一个，就还是别人的。
