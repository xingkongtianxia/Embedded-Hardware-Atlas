# 电源篇

## 一、电源概念

## 1、电源发展历史

电源的发展经历了从直流电源、交流供电、线性稳压电源到开关电源、数 字化智能电源的演变，整体趋势是效率更高、体积更小、精度更高、功能更智 能。 

## 1.1 电池电源（18—19世纪）：

伏打电堆的灵感来源于 1786年伽伐尼发现的“动物电”现象：将剥皮的青 蛙腿与不同金属接触时会产生痉挛和电火花。伏打经过实验发现，这种电并非 来自生物体，而是由不同金属接触产生的“接触电”。1799年，伏打用锌片和 铜片交替叠放，中间夹浸盐水的布或纸板，成功制成了能产生持续电流的装 置，1800 年伏打电堆诞生，人类首次获得持续电流。1859年铅酸蓄电池的发 明，让电能第一次具备了可充电、可存储的特性，为后来的车载和后备电源奠 定了基础。 

## 1.2 交流供电时代（19世纪末）：

核心是“电流之战”。特斯拉与西屋电气推广的交流电（AC），配合变压器 实现高压远距离输电，彻底解决了直流电传输损耗大的问题，构建了现代电网 的雏形，此时的“电源”主要指发电机和变压器。 

## 1.3 线性稳压电源（20世纪初期—中期）：

代表器件是真空管整流器，后发展为晶体管和经典的 78xx系列三端稳压 器。其最大特点是“干净”（纹波极小、无高频噪声），至今仍在音频设备、精 密仪器和低功耗待机电路中不可替代。但其致命伤是调整管工作在放大区，压 差大时效率极低通常＜40%。 

## 1.4 开关电源时代（20世纪 60—80年代）：

核心是“高频化”。PWM控制芯片和功率 MOSFET的普及，让开关频率从几 十Hz提升到几十/几百kHz。高频变压器取代了笨重的工频变压器，实现了电 源的小型化、轻量化。这一时期，开关电源在计算机、电视等消费电子中全面 取代线性电源。 

## 1.5 高性能电源时代（20世纪90 年代至 21世纪初）：

核心是“高功率密度与高效率”。同步整流技术（用 MOSFET替代肖特基二 极管）大幅降低了导通损耗；软开关技术（ZVS/ZCS）降低了开关损耗。同时， 电源管理芯片高度集成，外围电路极简，使得电源模块可以做到指甲盖大小。 

## 1.6 智能化与绿色电源时代（21世纪至今）：

核心是“宽禁带半导体与数字控制”。GaN（氮化镓）和SiC（碳化硅）让 开关频率突破MHz，手机快充头可以做到口红大小；数字电源（DSP/MCU 控制） 

实现了动态自适应调节、故障预测和远程遥测；绿色节能（如 80 PLUS 钛金标 准、待机零功耗）成为硬性指标。此外，光伏逆变器、电动汽车 OBC（车载充 电机）和数据中心 48V供电架构，成为这一阶段最大的应用驱动力。 

## 2、电源分类

电源的分类从电压转换类型和转换原理两个最核心的维度对电源进行了系 统梳理。 

![](images/b46bb2b0e191348bc792fdfaf6ce95843a1c8759814885d0ca0db69e5f119b3d.jpg)



电源的分类


2.1 按照电压转换类型分类：根据电能形式的转换方向，电源可分为四大基本 类型： 

AC/DC（交流转直流）：即整流器，将市电（交流）转换为设备所需的直 流电，常见如 LED照明（灯）、充电器、电源适配器。 

DC/AC（直流转交流）：即逆变器，常见于逆变器、电机控制、光伏发电 并网、车载逆变器。 

DC/DC（直流转直流）：改变直流电压的大小，广泛存在于各类电子电路 板中，常见如芯片、传感器、电池管理。 

<sub>•</sub> AC/AC（交流转交流）：改变交流电的电压或频率，常见如变频器、变压 器。 

2.2 按照转换原理分类：主要分为线性电源与开关电源两大阵营。 

2.2.1 线性电源（Linear Power Supply） 

调整管工作在线性放大区，特点是纹波小、噪声低，但效率相对较低。 

<sub>•</sub> 按照实现形式分类： 

<sub>o</sub> 简易稳压电路： 

▪ 稳压管二极管并联型稳压电路（利用稳压管反向击穿特 性）。 

▪ 单晶体管串联型稳压电路。 

<sub>o</sub> 标准线性电源：分为固定输出和可调输出。 

低压差线性电源（LDO）：属于特殊的线性电源，压差极低，分为 可调和固定两种，常用于对噪声敏感的模拟电路或后级稳压。 

## 2.2.2 开关电源（Switching Power Supply）

调整管工作在饱和与截止（开关）状态，特点是效率高、 体积小、功率密度 大。开关电源的分类维度极其丰富： 

<sub>•</sub> 按照是否有隔离： 

<sub>o</sub> 隔离型（输入与输出之间有变压器物理隔离）。 

<sub>o</sub> 非隔离型。 

<sub>•</sub> 按照输入输出关系： 

<sub>o</sub> 升压（输出 > 输入）。 

<sub>o</sub> 降压（输出 < 输入）。 

<sub>o</sub> 升降压（输出可变，可大于或小于输入）。 

<sub>•</sub> 按照向负载输出能量的时间： 

<sub>o</sub> 正激（开关管导通时向负载传递能量）。 

反激（开关管关断时向负载传递能量）。 

## <sub>•</sub> 按照拓扑结构（极重要）：

<sub>o</sub> 基础拓扑（非隔离）：Buck（降压）、Boost（升压）、Buck-Boost （升降压）。 

其他拓扑（非隔离）：Cuk、Zeta、SEPIC、四开关 Buck-Boost。 

隔离拓扑：隔离型反激、隔离型正激、Full-Bridge（全桥）、 Half-Bridge（半桥）、Push-Pull（推挽）、Two-Transistor Forward（双晶体管正激）。 

<sub>•</sub> 按照调制方式： 

<sub>o</sub> PWM（脉宽调制）：固定频率，改变占空比（最常用）。 

<sub>o</sub> PFM（脉冲频率调制）：固定脉宽，改变频率（常用于轻载提效）。 

PSM（脉冲跨周期调制）：通过跳过周期来控制能量（常用于极轻 载）。 

## 2.3 线性电源与开关电源本质区别

<sub>•</sub> 工作状态： 

<sub>o</sub> 线性电源：调整管工作在放大区（一直导通，相当于一个可变电 阻）。 

<sub>o</sub> 开关电源：调整管工作在饱和区与截止区（像开关一样高频快速切 换）。 

<sub>•</sub> 转换方式： 

<sub>o</sub> 线性电源：“串联耗能”。多余的电压和能量全部转化为热量散发 掉。 

<sub>o</sub> 开关电源：“高频储能-释放”。利用电感/变压器和电容，将能量暂 存后再传递给负载。 

<sub>•</sub> 结果表现： 

<sub>o</sub> 线性电源：效率低、发热大、体积大；但纹波极小、噪声低。 

<sub>o</sub> 开关电源：效率高、发热小、体积小；但纹波和 EMI 噪声较大。 

## 3、开关电源隔离与非隔离区分及调制方式

3.1 开关电源隔离与非隔离区分 

<sub>•</sub> 隔离型（Isolated）：输入与输出之间没有直接的电气连接，通过高频变 压器进行磁耦合传递能量。 

<sub>•</sub> 非隔离型（Non-isolated）：输入与输出之间有直接的电气连接（共 地），通过电感直接传递能量。

## 3.2 开关电源调制方式

开关电源通过控制功率开关管的导通与关断，调节输出电压或电流。常见 调制方式有 PWM、PFM、PSM 三种。 

![](images/6678336e086ece02f53f866930a70592f951ba306d20006188305979238e3f42.jpg)


## <sub>•</sub> PWM（脉冲宽度调制）

<sub>o</sub> 原理：频率固定，改变占空比。开关管的工作周期（频率）保持不 变，通过调节每次导通的“时间长短”（脉宽）来控制输出电压。 

<sub>o</sub> 优点：开关频率恒定，输出纹波小，后级滤波电感/电容设计简单， EMI（电磁干扰）频谱固定，易于处理。 

<sub>o</sub> 缺点：轻载（小电流）时，因为频率不变，开关损耗占比变大，效率 相对较低。 

应用：最主流的方式，适用于重载或对纹波要求高的场景（如电脑电 源、工业设备）。 

## <sub>•</sub> PFM（脉冲频率调制）

原理：脉宽固定（或关断时间固定），改变频率。开关管每次导通的 时间固定，通过改变开与关的“节奏快慢”（频率）来调节输出。 

<sub>o</sub> 优点：轻载效率极高。负载变小需要能量少时，开关频率自动降低， 开关损耗大幅减少。 

缺点：频率不固定，导致输出纹波较大，滤波电感容易产生音频噪 声，EMI 频谱分散，滤波设计较难。 

应用：待机电源、电池供电设备（如可穿戴设备），主打低功耗。 

## <sub>•</sub> PSM（脉冲跳跃调制）

原理：频率和脉宽均固定，直接“跳周期”。当需要降低能量输出 时，控制芯片直接跳过（屏蔽）一整个或几个开关周期，完全不发脉 冲。 

<sub>o</sub> 优点：极轻载或待机状态下效率极高，控制逻辑简单。 

<sub>o</sub> 缺点：纹波非常大，输出电压波动明显。 

应用：多用于微功耗待机模式（如智能电表、休眠状态下的电源）。 

注：PWM 适合稳定、精确的常规调节；PFM 适合需要改变开关频率的控制 场景；PSM 常用于降低轻载功耗。实际控制器也可能组合使用多种调制方式。 

## 4、开关电源的 CCM、DCM、BCM 模式

CCM、DCM、BCM 是开关电源中根据电感电流在一个开关周期内是否降为零 划分的三种工作模式，常用于 Buck、Boost、反激等变换器的分析。 

4.1 CCM（连续导通模式）： 

<sub>•</sub> 核心特征：在整个开关周期内，电感电流始终大于零，从未降到零。 

<sub>•</sub> 波形特征：电感电流波形呈“梯形波”（或带直流偏置的三角波）。电流 在开关管导通时线性上升，关断时线性下降，但在下一个周期开始前， 电流仍未降到零。 

![](images/64860f7e5172688e25e5d98037784d68c4fc78639694940f34b79fcc02dd2400.jpg)


## <sub>•</sub> 特点：

<sub>o</sub> 电流连续、电流纹波较小，输出滤波容易。 

<sub>o</sub> 峰值电流小，变压器/电感利用率高。 

在重载下，二极管存在反向恢复损耗（关断瞬间有反向电流）。 

<sub>•</sub> 应用：大功率、重载场景（如电脑电源、工业电源）。 

## 4.2 DCM（断续导通模式）：

核心特征：在一个开关周期内，电感电流会降到零并保持一段时间（死 区），直到下一个周期开关管再次导通。 

波形特征：电感电流波形呈“带平底的三角波”。电流上升到峰值后下 降， 触底到 0并保持为 0 一段时间，然后再上升。 

![](images/53b5b3eed7b6c8c9ba12c3850444163aa182e05f922a3415439849dd52c8440f.jpg)


<sub>•</sub> 特点： 

<sub>o</sub> 轻载效率高，二极管无反向恢复损耗（因为电流已提前降到 0）。 

<sub>o</sub> 峰值电流大，输出纹波大，EMI（电磁干扰）较大。 

<sub>•</sub> 应用：小功率、轻载/待机场景（如手机充电器、反激式辅助电源）。 

4.3 BCM（临界导通模式）： 

<sub>•</sub> 核心特征：CCM 和 DCM 的临界状态。电感电流在每个周期结束时刚好降 到零，然后立即开始下一个周期（没有死区，也没有连续电流）。 

<sub>•</sub> 波形特征：电感电流波形呈“纯三角波”。波谷刚好触及零点，没有平 底（零电流区），也没有台阶。 

![](images/799fb028f324978e19c990e251b2b11fe740a249c8fbfb234570a2af9d1681a6.jpg)


<sub>•</sub> 特点： 

<sub>o</sub> 电流每周期归零，无反向恢复损耗（实现零电流开通 ZCS），效率 高。 

<sub>o</sub> 开关频率是变频的（随负载变化），控制相对复杂。 

<sub>•</sub> 应用：PFC（功率因数校正）电路、反激变换器、高效率适配器。

## 4.4 实际芯片工作状态：

现代开关电源芯片（如 LMR16030）通常具备模式自动切换功能： 

<sub>•</sub> 重载时：自动进入 CCM 模式，保证输出稳定、纹波小。 

轻载时：自动切入 DCM 或PFM（跳频）模式，降低开关频率，减少开关 损耗，提高轻载效率，进入节能模式（常被称为 Eco-mode 或 Powersave mode）。 

## 5、同步与非同步电源

同步与非同步电源通常是指“同步整流电源”和“非同步整流电源”，常 见于Buck 降压、Boost 升压等开关变换器中。两者的核心区别是：续流时使用 MOSFET，还是使用二极管。 

核心本质区别： 

<sub>•</sub> 非同步（Asynchronous）：使用二极管作为续流/整流器件。 

<sub>•</sub> 同步（Synchronous）：使用MOSFET（开关管）替代二极管进行续流/整 

流（即“同步整流”）。

## 6、有效电流概念与计算

## 6.1 有效电流的概念

有效电流（RMS）：指交流电流通过电阻时，在相同时间内产生与某一数值 的直流电流相同的热效应，该直流电流的数值就是交流电流的有效值。有效电 流反映电流的发热能力。在开关电源设计中，常用于计算 MOSFET、电感、变压 器绕组、整流二极管的导通损耗和温升。 

## 6.2 有效电流的计算公式

## 6.2.1 通用公式

对于周期为T的周期电流i(t)： 

$$
\mathrm {I_ {RMS}} = \sqrt {\frac {1}{\mathrm{T}} \int_ {0} ^ {\mathrm{T}} \mathrm{i} ^ {2} (\mathrm{t}) \mathrm{dt}}
$$

计算步骤：电流平方 →一个周期内取平均 →开平方。 

## 6.2.2 常见波形的电流有效值计算

➢ 直流电流：恒定不变的电流。久 

$$
\mathrm{I} _ {\mathrm{RMS}} = \mathrm{I}
$$

➢ 正弦交流电流： $\mathrm { I } _ { \mathrm { m } }$ 为峰值，约为峰值的 0.707 倍。 

$$
\mathrm {I_ {RMS}} = \frac {\mathrm {I_ {m}}}{\sqrt {2}}
$$

矩形脉冲电流：电流导通时为 $\mathrm { { I I } } _ { \mathbf { o n } }$ ，其余时间为零；D为占空比。 

$$
\mathrm {I_ {RMS} = I_ {on} \sqrt {D}}
$$

## ➢ 三角波电流（开关电源常见）

对称三角波电流：其中 $\mathrm { I } _ { \mathrm { m } }$ 为三角波的峰值，正负对称三角波的平均值 为零，但有效值不为零。 

$$
\mathrm {I_ {RMS}} = \frac {\mathrm {I_ {m}}}{\sqrt {3}}
$$

$$
\mathrm {I_ {RMS}} = \sqrt {\mathrm {I_ {avg} ^ {2}} + \frac {\Delta \mathrm{I} ^ {2}}{1 2}}
$$

这个公式适用于平均值上叠加对称三角波纹的电流。

$$

$$

因此，电感电流有效值约为 5.03A。

$$

$$
\mathrm {I_ {\mathrm{RMS}} = I_ {\mathrm{pk}} \sqrt {\frac {t_ {\mathrm{r}} / 3+ t_ {\mathrm{p}} + t_ {\mathrm{f}} / 3}{T}}}
$$

$$

## 1、电源电路中的电阻作用（基础元器件~电阻篇）

电阻主要用于限流、分压、采样、反馈、偏置、泄放及阻尼，是电源电路中 实现电压、电流控制和保护的重要元件。

<sub>•</sub> 作用：通过两个（或更多）电阻串联分压，将输出端的高压按比例缩 小，反馈给控制芯片的 FB（反馈）引脚，与内部基准电压进行比较。久 

<sub>•</sub> 应用：电源输出电压设定。例如公式 $\mathrm { \Delta V _ { o u t } = V _ { r e f } \times \left( 1 + R _ { f } / R _ { g } \right) }$ ， $\mathrm { V _ { r e f } }$ 参数 参考手册。通常需要使用高精度（如 0.1%）、低温漂的电阻，以保证输 出电压的准确度。

## 1.2 电流采样与限流保护（检流电阻）

<sub>•</sub> 作用：串联在电流主回路中，将流过的电流转化为微弱的电压信号 （V = I×R）。控制芯片通过检测该电压来判断电流大小。 

<sub>•</sub> 应用：过流保护（OCP）、恒流输出（CC）、峰值电流模式控制。通常需要 使用阻值极小（毫欧级），低温度系数的合金电阻，以减少自身发热和功 率损耗。

## 1.3 环路补偿（RC 补偿网络）

<sub>•</sub> 作用：与电容一起组成 RC 网络，用于调整误差放大器的频率响应，保证 开关电源闭环系统的稳定性，防止输出电压振荡。 

<sub>•</sub> 应用：控制芯片的 COMP 引脚外接的 Type II 或 Type III 补偿网络。

## 1.4 限制电流与阻尼保护

<sub>•</sub> 驱动电阻：串联在控制芯片与 MOS 管栅极之间。限制栅极充电电流，减 缓 MOS 管的开通/关断速度，从而抑制 SW节点的振铃，优化 EMI。 

<sub>•</sub> 缓冲吸收：由电阻和电容串联组成，并联在开关管或二极管两端。吸收 关断瞬间的电压尖峰，保护器件。 

电阻和电容串联：电阻控制电流，电容储存电荷；两者串联配合，可控制充 放电速度、频率响应和瞬态波形,实现限流、滤波、延时、尖峰吸收及波形整形 功能。 

<sub>•</sub> 软启动电阻：限制开机瞬间给输入电容充电的浪涌电流。

1.5 上拉/下拉与逻辑设定 

<sub>•</sub> 作用：确保芯片引脚处于确定的高或低电平状态。 

<sub>•</sub> 应用：使能引脚（EN）的上拉/下拉、PGOOD（电源良好）信号的上拉、 频率设定引脚（RT）的外接电阻。 

![](images/7f0dbeabccb3a2d4153450dbd98c723c3410dc4c65f15eaf49f10c7b5fc3b101.jpg)


1.6 假负载（泄放电阻） 

作用：并联在输出端。一方面为轻载/空载时提供最小维持电流，防止输 出电压漂高；另一方面在断电后快速泄放输出滤波电容上的电荷。 

<sub>•</sub> 缺点：会带来静态功耗，现代电源常采用“有源假负载”或 X电容放电 芯片替代。 

## 2、电源电路中的电容作用（基础元器件~电容篇）

电容具有隔直通交、储能、滤波、旁路、耦合及抑制干扰等作用，它在电 源中主要扮演滤波、储能、去耦和稳定控制的角色。 

## 2.1 输入/输出储能滤波（平滑电压与吸收纹波）

<sub>•</sub> 输入滤波：在整流桥后或 DC-DC输入端，使用大容量电解电容平滑脉动 直流电，并吸收开关瞬间产生的浪涌电流。 

<sub>•</sub> 输出滤波：在输出端，常采用大容量电解电容 + 小容量陶瓷电容的组 合。电解电容负责滤除低频纹波，陶瓷电容负责滤除高频开关尖峰噪 声，使输出电压更纯净。 

<sub>•</sub> 应用：通常使用 220μF / 47μF 的电解电容/陶瓷电容。 

## 2.2 去耦与旁路（去除高频噪声）

<sub>•</sub> 旁路（Bypass）：为高频噪声提供一条低阻抗的“捷径”流向地，防止噪 声窜入后级电路。 

<sub>•</sub> 去耦（Decoupling）：放置在控制芯片（如 MCU、PWM控制器）的电源引 脚附近，作为局部的“微型蓄水池”，补偿芯片高速开关时瞬间所需的 电流，防止电源电压跌落。 

<sub>•</sub> 应用：通常使用旁路 0.1μF+去耦 10μF的陶瓷电容紧贴芯片引脚放 置。 

## 2.3 环路补偿（稳定系统）

作用：开关电源是一个闭环负反馈系统，存在相位延迟。如果不加补 偿，极易发生自激振荡。通过在误差放大器（COMP引脚）外接 RC补偿 网络，调整系统的零极点分布，确保电源在各种负载下都能稳定工作。 

<sub>•</sub> 应用：Type II 或 Type III 补偿网络中的小容量电容（pF~nF 级）。

## LLC 谐振变换器的工作原理：

<sub>•</sub> 谐振电感 $\mathrm { L } _ { \mathrm { r } } .$ 谐振电容 $\mathrm { { C _ { r } } }$ 与励磁电感 $a _ { \mathrm { { m } } } \mathrm { { . } }$ 共同参与谐振过程。

硬开关：电压与电流重叠明显，开通时电压尚未降至低值，电流已经上 升，产生较大的瞬态功耗。

零电压开通（ZVS）：开通前 MOSFET漏源电压 $\mathrm { V _ { D S } }$ 先下降至接近 0；开通过程 中栅极驱动使MOSFET导通，此时 $\mathrm { V _ { D S } } \approx 0$ ，漏极电流 $\mathrm { I _ { D } }$ 开始上升；关断过程中 不一定是零电压关断，具体取决于拓扑。 

特点：降低开通损耗，常见于 LLC谐振变换器、移相全桥等。 

零电流开通（ZCS）：开关动作前谐振网络使 MOSFET电流逐渐下降。关断瞬 间 $\mathrm { I _ { D } } \approx 0$ 时关断MOSFET。减小关断瞬间的电流变化及相关开关损耗。 

特点：常见于部分谐振变换器；实际效果取决于电路拓扑及寄生参数。

## 4、电源电路中的 MOS 管作用（基础元器件~MOS 管篇）

## 4.1 开关管为啥选 MOSFET 而非 BJT

在开关电源中，开关管几乎全面采用 MOSFET（场效应管）而不是 BJT（三 极管/双极型晶体管）。其核心原因在于：MOSFET 更适合现代电源“高频、高 效、大电流”的需求。 

① 驱动功耗低：MOSFET为电压驱动，稳态栅极电流极小；BJT 为电流驱 动，需要持续提供基极电流，产生不必要的消耗 $\mathrm { \cdot I _ { b } \times V _ { b e } }$ 

② 开关速度快：MOSFET属于多数载流子器件，存储效应小，适合高频开 关；BJT存在电荷存储，关断通常较慢。 

③ 导通损耗低：MOSFET导通损耗近似为 $\mathsf { P } = \mathsf { I } _ { \mathrm { D } } ^ { 2 } \mathsf { R } _ { \mathrm { D } \mathsf { S } ( \mathrm { o n } ) }$ ，低压大电流场景优 势明显；BJT 导通时存在饱和压降。 

④ 并联更容易与热稳定性强：MOSFET 导通电阻通常具有正温度系数，有利 于静态均流；BJT更容易出现电流集中，需要额外均流措施。 

⑤ 同步整流：用MOSFET替代整流二极管，通过控制栅极实现同步导通， 降低整流损耗。MOSFET导通电阻低，尤其适合低压、大电流电源，可显 著提高转换效率。需要注意合理控制驱动时序，避免上下管同时导通造 成直通短路；MOSFET也并非只能单向导电，其沟道在导通时可允许双向 电流。而BJT 无法像开关一样方便地做反向或同步整流。 

总结：虽然BJT 成本更低、驱动电压死区小，但由于其驱动耗电、开关 慢、压降大、难并联的硬伤，在高频开关电源领域已经被 MOSFET 全面取代。 MOSFET具有驱动简单、开关速度快、低压大电流效率高、并联方便等优点，因 此广泛用于现代开关电源。 

注意：MOSFET 并非所有场景都优于 BJT。高压大功率场合还常使用 IGBT；苏 具体选型需综合考虑耐压、电流、开关频率、导通损耗和驱动成本。

② 同步整流（替代二极管降损） 

<sub>•</sub> 作用：在低压大电流输出的电路（如 CPU供电、手机快充）中，用低内 阻的 MOS管代替传统的肖特基二极管进行整流/续流。

③ 线性调整（LDO 稳压） 

<sub>•</sub> 作用：在低压差线性稳压器（LDO）中，MOS管工作在线性放大区，等效 于一个可变电阻。通过改变自身阻抗来分压，维持输出电压恒定。

<sub>•</sub> 负载开关：控制各模块的上下电时序，或在待机时彻底切断某部分电路 供电（降低静态功耗）。

<sub>•</sub> 过流/短路保护：检测到异常大电流时，控制芯片迅速关断 MOS管以切断 回路。

总结：MOS 管是电源电路中的核心功率控制器件，主要负责控制电流通断、调 节能量传递、降低损耗和提高转换效率。 

## 5、电源电路中的变压器作用

在电源电路中，变压器（特别是高频变压器）是隔离型开关电源的“心久 脏”。它不仅是能量的搬运工，更是安全与电压转换的枢纽。 

① 电气隔离（核心） 

<sub>•</sub> 作用：通过磁耦合传递能量，使变压器的初级（原边，接市电/高压）与 次级（副边，接负载/低压）在电气上完全断开，没有直接的导线连接。苏 

<sub>•</sub> 意义：有效防止触电事故，实现“热地”与“冷地”的分离，保障人身 和设备安全。

## ② 电压变换（升压/降压）

作用：通过调整初级与次级线圈的匝数比 $( \mathsf { N } _ { \mathsf { p } } \colon \mathsf { N } _ { s } )$ ，实现电压的升高或 降低。 

<sub>•</sub> 应用：例如市电 220V 降压至 12V、5V 供设备使用；或在反激/正激拓 扑中，通过变压器将能量按比例传递到输出端。 

![](images/dd951a70e016c946026243ec7aa8a2680ae2276506ea25615b9ee5e602e79ab7.jpg)


理想变压器满足： 

$$
\frac {V _ {1}}{V _ {2}} = \frac {N _ {1}}{N _ {2}}
$$

• 降压： $N _ { 2 } < N _ { 1 }$ ，输出电压低于输入电压。 

• 升压： $N _ { 2 } > N _ { 1 }$ ，输出电压高于输入电压。 

•电流变化：理想情况下，次级电流与匝数比成反比，即 $\begin{array} { r } { \frac { I _ { 1 } } { I _ { 2 } } = \frac { N _ { 2 } } { N _ { 1 } } . } \end{array}$ 

## ③ 能量传递与储能（拓扑核心）

<sub>•</sub> 反激式（Flyback）：变压器兼具电感的作用。开关管导通时，初级线圈 储能；开关管关断时，能量传递给次级。此时变压器本质上是一个多绕 组耦合电感。 

<sub>•</sub> 正激/推挽/桥式：变压器纯粹作为能量传递媒介，开关管导通时能量直 接传递到负载，不依赖变压器储能。

<sub>•</sub> 多路输出：一个变压器可以增加多个次级绕组，轻松实现多路不同电 压、互相隔离的输出（如同时输出 5V、12V、24V）。 

<sub>•</sub> 辅助绕组（VCC）：通常增加一个辅助绕组为控制芯片提供稳定的供电电 压，取代了启动电阻的持续功耗。

⑤ 谐振与抗干扰（EMI） 

<sub>•</sub> 谐振元件：在 LLC等先进拓扑中，变压器的励磁电感 $\mathrm { L } _ { \mathrm { m } }$ 与漏感 $\mathrm { \Delta L _ { k } }$ 直接参 与谐振，帮助开关管实现 ZVS（零电压开通），降低开关损耗。

## 三、线性稳压器拓扑结构（LDO）

## 1、线性稳压器原理及设计

工作原理：线性稳压器通过负反馈闭环控制，让内部的“调整管”（功率 晶体管/MOSFET）工作在线性放大区，像一个可变电阻一样消耗掉多余的电压， 从而实现对输出电压的精确调节，从而保持输出电压稳定。 

内部四大核心模块： 

<sub>•</sub> 基准电压源 $( \mathrm { { V _ { r e f } } ) }$ ：提供高精度、低噪声的参考电压。 

<sub>•</sub> 误差放大器（EA）：将反馈电压与 $\mathrm { V _ { r e f } }$ 比较，放大误差信号。 

<sub>•</sub> 调整管（BJT/MOSFET）：受误差放大器控制，调节自身的等效阻抗。 

<sub>•</sub> 反馈分压网络 $( \mathtt { R } _ { 1 } , \mathtt { R } _ { 2 } )$ ）：采样输出电压。 

<sub>•</sub> 工作流程：当输出电压 $\mathrm { V _ { o u t } }$ 下降时，分压后的反馈电压降低，误差放大 器驱动调整管导通程度增加（阻值变小），使 $\mathrm { V _ { o u t } }$ 回升，最终达到动态平 衡，实现电压温度输出。 

<sub>•</sub> 核心公式： $\begin{array} { r } { \mathrm { V _ { o u t } } = \mathrm { V _ { r e f } } \times \left( 1 + \frac { \mathrm { R _ { 1 } } } { \mathrm { R _ { 2 } } } \right) } \end{array}$

 输入电压 $( \mathbf { V _ { I N } } )$ ：芯片能承受的最高和最低输入电压。最高耐压需留有余 量（防瞬态过冲），最低电压必须大于“输出电压+压差”。 

 输出电压 $( \mathbf { v _ { 0 U T } } )$ )：分为固定输出版本（如 3.3V、5V）和可调版本（通过 外部电阻分压设定）。 

 最大输出电流 $\mathbf { \big ( I _ { O U T ( M A X ) } \big ) }$ ：稳压器能持续提供的最大电流。具体需结合热 功耗计算，不能只看标称值。 

 压差电压 $( \mathbf { v _ { D 0 } } )$ ：LDO的核心。维持输出电压稳定所需的最小输入输出压 差。压差越小，电池利用率越高，越适合低压场景。 

 静态电流 $\left( \mathbf { I } _ { 0 } \right)$ ：无负载时芯片自身消耗的电流。对于电池供电设备（如 物联网、可穿戴设备）， $\mathbf { I _ { 0 } }$ 越低越好（通常要求 nA或μA级）。 

电源抑制比(PSRR)：衡量LDO滤除输入端纹波（如开关电源的纹波）的 能力。通常以 dB表示，越高越好（在特定频率下，如 1kHz 或1MHz）。 

输出噪声 $( \mathbf { v _ { N } } )$ ：LDO自身产生的噪声（通常用 $\mu \mathrm { V } _ { \mathrm { R M S } }$ 表示）。对高精度 ADC、传感器供电时，需选择低噪声 LDO（有时需外接NR降噪电容）。噪 声会影响模拟电路、射频电路的供电质量。 

 调整率：包括线性调整率（输入变化）和负载调整率（负载变化）。 

线性调整率：输入电压变化时，输出电压保持稳定的能力。 

<sub>o</sub> 负载调整率：负载电流变化时，输出电压保持稳定的能力。 

<sub>o</sub> 瞬态响应：当负载电流发生突变（如 MCU瞬间唤醒）时，输出电压的 跌落或过冲幅度及恢复时间。

## 四、开关电源拓扑结构

## 1、Buck 电路原理及设计

## 1.1 核心工作原理

Buck 电路的本质是通过电感的储能与释能，配合开关管的高速斩波，实现 能量传递。 

<sub>•</sub> 开关导通（ON）：主开关管导通，输入电源通过开关管加到电感两端，电 感电流线性上升（储能），同时向负载供电并对输出电容充电。此时续流 管（二极管或同步MOS）承受反向电压而截止。 

<sub>•</sub> 开关关断（OFF）：主开关管关断，电感为了维持电流不突变，产生感应 电动势，使续流管（二极管或同步 MOS）导通。电感释放能量，继续向 负载供电。 

<sub>•</sub> 核心公式（理想 CCM 模式）： $\mathrm { V _ { o u t } = D \times V _ { i n } }$ （D为占空比，且D < 1，因 此只能降压）。

## 1.2 拓扑结构分类

根据续流器件的不同，Buck电路分为两种拓扑： 

① 非同步 Buck 

<sub>•</sub> 结构：主开关（MOSFET）+ 续流二极管 + 电感 + 电容。 

工作流程：Q1导通Vin向电感 L和负载供电，电感储能。Q1 关断电感通 过续流二极管 D1继续向负载供电。 

特点：结构简单、成本低，但二极管存在正向压降 $( \mathrm { V _ { F } { = } 0 } . 3 { \sim } 0 . 7 \mathrm { V } )$ ），产 生额外损耗，低压大电流时效率相对较低。 

<sub>•</sub> 适用：高压、小电流或对成本极度敏感的场景。低压输出时效率极低。 

② 同步 Buck（现代主流） 

<sub>•</sub> 结构：上管（主 MOS）+下管（同步整流 MOS 替代二极管）+电感+电容。 

<sub>•</sub> 工作流程： $\mathrm { Q p }$ 导通高侧MOSFET 导通，Vin向电感和负载供电。 $\mathrm { Q p }$ 关 断、Qn导通电感电流通过低侧 MOSFET 续流。 

<sub>•</sub> 特点：低侧 MOSFET导通电阻较小，通常比二极管压降造成的损耗低（压 降 $\mathrm { I } \times \mathrm { R } _ { \mathrm { D S ( o n ) } }$ 远小于 $\mathrm { \Delta V _ { F } }$ ）。 

<sub>•</sub> 适用：低压大电流场景（如 CPU供电、手机快充）。效率极高，但需要控 制死区时间防止上下管直通炸机。

## 2、Boost 电路原理及设计

## 2.1 核心工作原理

Boost 电路通过电感的“充放电”与二极管的单向导电性，将能量“泵”到 更高电压的输出端。 

<sub>•</sub> 开关导通（ON）：主开关管导通，输入电源直接加在电感两端。电感电流 线性上升（储能）。此时，二极管截止，输出电容单独为负载供电。 

开关关断（OFF）：主开关管关断。由于电感电流不能突变，电感产生感 应电动势（左负右正），与输入电源串联叠加，通过导通的二极管向负载 供电，并给输出电容充电。 

核心公式（理想 CCM 模式）： $\begin{array} { r } { \mathrm { V _ { o u t } } = \frac { \mathrm { V _ { i n } } } { 1 - \mathrm { D } } } \end{array}$ （D为占空比，因此 $\mathrm { U _ { o u t } } > \mathrm { V _ { i n } } )$ 

![](images/e2685da2efd93dfb6aaf186ce3d8c076c01bd1dc93c4407e8e03f6eaa01b5583.jpg)


## 2.2 拓扑结构差异

与Buck 电路类似，Boost也分同步与非同步： 

<sub>•</sub> 非同步 Boost：使用肖特基二极管作为整流管。结构简单，但二极管压 降带来损耗，适用于中小功率。 

<sub>•</sub> 同步Boost：用MOSFET 代替二极管（下管）。导通内阻极低，效率高， 且支持双向电流（可用于电池充放电电路）。但需要严格的死区控制防直 通。 

![](images/ec5e4f1d1ad43f2d7e81eb8fa69b67bbeb4847f652f1035dc36d8ae52dc405d4.jpg)


## 2.3 设计核心

Boost 电路设计看似简单，但由于其输入输出电流的物理特性，实际设计中 比Buck 更容易“踩坑”。 

① 电感（L） 

<sub>•</sub> 计算公式： $\begin{array} { r } { \mathrm { L } = \frac { \mathrm { V _ { i n } \times D } } { \Delta \mathrm { I _ { L } } \times \mathrm { f _ { s w } } } } \end{array}$ （注意分子和 Buck不同，这里用的是 $\mathrm { V _ { i n } } )$ ）。 

峰值电流极大：Boost的输入平均电流等于输出电流除以(1-D)。例如5V 升 12V，输出 1A，输入平均电流高达 2.4A。加上纹波，峰值电流很容易 超过 3A。务必选择饱和电流 $\mathrm { I } _ { s \mathrm { a t } }$ 足够大、直流电阻 DCR 小的电感，否则 极易饱和烧毁开关管。 

② 输出电容 $( \mathbf { C _ { o u t } } )$ 

坑点：Boost 的输出电容只在开关关断时才有电流充入，属于脉冲电流 充放电。其承受的 RMS纹波电流远大于 Buck电路。必须选用低 ESR、高 纹波电流承受能力的电容（常并联多个 MLCC），否则电容会严重发热鼓 包。 

## ③ 开关管（MOSFET）与二极管

<sub>•</sub> 耐压要求：开关管和二极管关断时承受的电压是 $\mathrm { V _ { o u t } }$ ，而不是 $\mathrm { V _ { i n } }$ 。因此 耐压必须大于 $ { \mathrm { \Delta V _ { o u t } } }$ （通常留1.5倍裕量）。 

<sub>•</sub> 电流要求：开关管的峰值电流必须大于电感峰值电流。 

④ 环路补偿（RHPZ 问题） 

<sub>•</sub> 为什么会产生 RHPZ：MOSFET 占空比增大时，输出电压短时间内反而下 降，随后才逐渐上升。这种“先反向、后正向”的响应就是 RHPZ的直观 表现。常见于 Boost 升压电路、CCM 反激电路、SEPIC 电路和部分 Buck-Boost 电路。 

<sub>•</sub> 右半平面零点（RHPZ）：理想Boost 电路在CCM下，右半平面零点的频率 近似为： $\begin{array} { r } { \mathrm { f } _ { \mathrm { z , R H P } } = \frac { \mathrm { R } ( 1 - \mathrm { D } ) ^ { 2 } } { 2 \pi \mathrm { L } } } \end{array}$ 

RHPZ 对环路的影响：RHPZ不只是普通的增益零点，它会在提高增益的同 时引入额外相位滞后，带宽受限，动态响应变慢。占空比D越大（升压 比越大），RHPZ 频率越低，越容易引起振荡。因此不能像左半平面零点 那样简单地用来补偿相位。 

<sub>•</sub> 解决方法：降低环路带宽；优化电感参数；限制最大占空比；优化补偿 网络；采用峰值电流模式控制。 

## ⑤ 直通与启动（缺点）

<sub>•</sub> 直通：由于 Boost拓扑的输入和输出之间只隔了一个二极管/MOS管，如 果输出短路，输入会直接灌入输出。或者在启动瞬间，存在输入到输出 的直通电流，常需要外加限流或软启动电路。 

<sub>•</sub> 开机浪涌：启动时输出电容电压为 0，输入电压会通过电感和二极管直 接给大电容充电，瞬间电流极大，容易拉低输入电源。 

## ⑥ PCB Layout 布局

“输出高频环路”面积：二极管（或上管）、输出电容和芯片 GND之间会 形成巨大的脉冲电流环路。这三点必须紧贴放置，环路面积越小越好， 否则会产生剧烈的高频尖峰和 EMI。 

SW节点走线“短而窄”，远离敏感信号：电感、开关管、二极管交汇处 具有极高的dV/dt，是最大的干扰源。走线要短且不能大面积铺铜（防止 成为辐射天线）。必须远离反馈走线（FB）和使能端，反馈电阻必须直接 从输出电容末端取电。 

<sub>•</sub> 输入电容紧贴，主功率路径加宽：输入电容必须紧靠电感的输入端和芯 片 VIN引脚，提供极低阻抗的高频回路。同时，电感、开关管、二极管 所在的主功率路径需宽走线或铺铜，芯片底部的散热焊盘必须多打过孔

3、Buck--Boost 电路原理及设计（输入与输出反极性） 

3.1 核心工作原理 

经典 Buck-Boost 电路的本质是将电感放在中间，利用开关管控制电感的储 能与释能。它的输出电压与输入电压极性相反。 

<sub>•</sub> 开关导通（ON）：主开关管导通，输入电源加在电感两端，电感电流上升 （储能）。此时，二极管（或同步下管）承受反向偏置而截止，输出电容 单独向负载供电。 

<sub>•</sub> 开关关断（OFF）：主开关管关断。电感电流不能突变，产生感应电动 势，使二极管导通。电感通过二极管向负载供电并给输出电容充电。注 意极性：负载的“地”其实是接在电感的负端，因此输出是负压。 

<sub>•</sub> 核心公式（理想 CCM）： $\begin{array} { r } { \mathrm { V _ { o u t } } = - \mathrm { V _ { i n } } \times \frac { \mathrm { ~ D ~ } } { 1 - \mathrm { D } } } \end{array}$ 

<sub>o</sub> 当 $\mathrm { D } < 0 .$ 5时， $\mid \mathrm { V _ { o u t } \mid { < } \mid \mathrm { V _ { i n } \mid } }$ （降压）。 

<sub>o</sub> 当 $\mathrm { D } > 0 . 5 \sharp \mathrm { j }$ ， $\mid \mathrm { V _ { o u t } \mid > \mid V _ { i n } \mid }$ （升压）。 

![](images/0d7a4021932e7fd5360c4d43406e0ba7083b18c07e1415fbd6448610c75422ca.jpg)


## 3.2 两大主流拓扑结构

① 经典反转 Buck-Boost 

<sub>•</sub> 电路拓扑：主要元件包括开关管 Q、电感 $\mathrm { L } ,$ 二极管 D、输入电容 $\mathrm { C _ { \mathrm { i n } } }$ 和输出电容久 $\mathrm { C _ { o u t } }$ 。其输出电压与输入电压极性相反。 

工作原理：开关管导通（ON）电感储能，输入电源给电感充电，电感电 流上升。二极管截止，输出电容独立向负载供电。开关管关断（OFF）电 感释能，电感电流不能突变，电感两端电压反向。二极管导通，电感向 输出电容和负载传递能量。输出端形成负电压。 

<sub>•</sub> 输出公式：在连续导通模式（理想 CCM）下， $\begin{array} { r } { \mathbf { V _ { 0 } } = - \frac { \mathbf { D } } { 1 - \mathbf { D } } \mathbf { V _ { i n } } } \end{array}$ 

<sub>•</sub> 痛点：输入和输出不共地（输出端的地是浮动的或接负电压），且输入和 输出的电流都是脉冲式的，EMI较大。 

![](images/485d1dbd737f0b6af9204dfb1acebb5f817879b646dcee68afa74fe99aa03f5c.jpg)


② 四开关 Buck-Boost（现代主流） 

<sub>•</sub> 电路拓扑：四开关Buck-Boost 由两个半桥和中间电感构成 ${ \sf Q } _ { 1 } , \ { \sf Q } _ { 2 }$ ：输 入侧半桥。 $\mathrm { Q } _ { 3 } , \mathrm { Q } _ { 4 }$ ：输出侧半桥。L：连接两个半桥开关节点的储能电 感。 $\mathrm { C } _ { \mathrm { i n } } \setminus \mathrm { C } _ { \mathrm { o u t } }$ ：稳定输入、输出电压。它的输出与输入同极性，通常可 与输入共地，适合正电压升降压应用。 

<sub>•</sub> 工作模式： 

<sub>o</sub> Buck 降压模式：当 $\mathrm { V _ { i n } } > \mathrm { V _ { 0 } }$ 且输入电压有足够余量时，输入侧半桥进 行PWM斩波，输出侧通常由高侧管保持导通、低侧管关断。理想情况 下 $\mathrm { V } _ { \mathrm { o } } \approx \mathrm { D V } _ { \mathrm { i n } }$ （输入高、输出低时，后级全导通，前级做 Buck斩 波） 

![](images/e3db1148bb00c5d45f16f1563f8dd42b9121ec2f72d339b38dfe2e081039dbca.jpg)


<sub>o</sub> Boost 升压模式：当 $\mathrm { V _ { i n } } < \mathrm { V _ { 0 } }$ 且需要升压时，输入侧通常保持高侧管 导通，输出侧半桥进行 PWM控制。理想情况下 $\begin{array} { r } { \mathtt { V } _ { 0 } \approx \frac { \mathtt { V } _ { \mathrm { i n } } } { 1 - \mathrm { D } } } \end{array}$ （输入低、 输出高时，前级全导通，后级做 Boost斩波） 

Buck-Boost 模式：当输入与输出电压接近，或输入电压跨越目标输 出电压时，控制器可以让两侧半桥都参与调制，使升降压平滑衔接。 实际控制策略因芯片而异，并非所有控制器都会让四个 MOSFET始终 同时高频开关。

<sub>•</sub> 应用：手机快充（PD充电宝）、车载 USB供电、工业宽压电源。

## 3.3 设计核心要点

Buck-Boost 电路在设计中相比单纯的 Buck 或 Boost 更容易踩坑： 

## ① 开关管与电容电压选取

<sub>•</sub> 耐压要求：开关管关断时承受的电压是 $\mathrm { V _ { i n } + \lvert \Delta V _ { o u t } \rvert } .$ 0 

<sub>•</sub> 避坑：如果是 12V输入升压到 24V（负压），开关管承受的应力是 36V。 选管子时耐压必须大于这个总和（通常选 40V或60V），绝不能只看输入 或输出电压。 

## ② 输入输出电容纹波电流极大

<sub>•</sub> 痛点：经典 Buck-Boost的输入和输出电流都是断续的脉冲电流。这意味 着无论是输入电容还是输出电容，都要承受极大的 RMS纹波电流。 

<sub>•</sub> 避坑：必须并联多个低 ESR 的陶瓷电容（MLCC），或者配合固态电容，否 则电容严重发热、寿命锐减。四开关拓扑在这方面表现稍好（有连续导 通的阶段）。 

## ③ 四开关的“模式切换”与环路稳定性

<sub>•</sub> 控制复杂性：四开关在从Buck模式切换到 Boost模式时，如果逻辑设计 不好，容易出现输出电压跌落或过冲。 

<sub>•</sub> 直通危险：必须确保同一个半桥的上下管之间有足够的死区时间，否则 瞬间直通会导致炸机。 

## ④ 右半平面零点（RHPZ）

当工作于 Boost 模式（经典Buck-Boost 模式）时，依然存在之前提到的 RHPZ 问题。环路补偿的带宽必须避开这个零点，导致动态响应变慢。 

## 4、其他非隔离拓扑结构

## 4.1 Cuk 电路原理及设计（TI(德州仪器)生产 LM2611AMFX/NOPB）

Cuk（丘克）电路是一种非常经典的非隔离反转拓扑（输出负电压），以发 明者 Slobodan Cuk 的名字命名。相比传统的 Buck-Boost 电路，Cuk 电路最 大的优势在于：它的输入电流和输出电流都是连续的，因此纹波极小、电磁干 扰（EMI）非常低。 

## 4.1.1 工作原理

Cuk 电路的核心是通过电容（耦合电容 $\mathsf C _ { 1 } )$ ）作为能量传递的桥梁，结合两 个电感实现能量的平滑转移。 

<sub>•</sub> 核心元件： $\mathrm { L } _ { 1 }$ 输入储能电感，平滑输入电流； $\mathrm { Q } _ { 1 }$ 主开关管，控制能量传 递; $\mathsf C _ { 1 }$ 能量传递电容，负责储存和转移能量； $\mathsf { D } _ { 1 }$ 续流二极管，提供关断 期间的电流通路； $\mathrm { L } _ { 2 }$ 输出滤波电感，平滑输出电流； $\mathsf { C } _ { 2 }$ 输出滤波电容， 降低输出电压纹波。 

<sub>•</sub> 开关导通（ON）：输入电源 $\mathrm { V _ { G } }$ 向 $\mathrm { L } _ { 1 }$ 供电， $\mathrm { L } _ { 1 }$ 电流上升并储能。 $\mathsf C _ { 1 }$ 通过 $\mathrm { Q } _ { 1 }$ 向 $\mathrm { L } _ { 2 }$ 传递能量。 $\mathrm { L } _ { 2 }$ 维持输出电流，向负载供电。二极管 $\mathrm { D } _ { 1 }$ 截止。 

<sub>•</sub> 开关关断（OFF）： $\mathrm { L } _ { 1 }$ 中的电流通过 $\mathrm { D } _ { 1 }$ 向 ${ \sf C } _ { 1 }$ 传递能量，使 $\mathrm { C } _ { 1 }$ 充电。 $\mathrm { L } _ { 2 }$ 利用 自身储存的能量继续向负载供电。输入电源 $\mathtt { V _ { G } }$ 与 $\mathrm { L } _ { 1 }$ 共同参与能量传递。 

<sub>•</sub> 核心公式（理想 CCM）： $\begin{array} { r } { \mathrm { V _ { o u t } } = - \mathrm { V _ { i n } } \times \frac { \mathrm { ~ D ~ } } { 1 - \mathrm { D } } } \end{array}$ （与 Buck-Boost 公式相同，D 为占空比）。

Cuk 电路结构相对复杂，在实际设计中主要关注以下几点：

<sub>•</sub> 通常 $\mathrm { L } _ { 1 }$ 和 $\mathrm { L } _ { 2 }$ 可以耦合在同一个磁芯上（称为耦合电感 Cuk），这不仅能进

<sub>•</sub> 电压：当开关管关断时，它们承受的最大反向电压均为 $ { \mathrm { V } _ { \mathrm { i n } } } +  { \vert \mathrm { \nabla }  { V _ { \mathrm { o u t } } } \vert }$ 。选 型时必须留足裕量。

<sub>•</sub> 高频环路：虽然输入输出电流连续，但开关管、二极管和 ${ \mathrm { C } } _ { 1 }$ 构成的回路 依然是高频脉冲电流环路，必须尽可能小。

• 开关导通（ON）：输入电源给 $\mathrm { \Delta L _ { 1 a } }$ 充电（储能）；同时，耦合电容 $\mathrm { C _ { P } }$ 通过开 关管给 $\mathrm { L } _ { 1 \mathrm { b } }$ 充电。此时二极管截止，输出电容向负载供电。 

<sub>•</sub> 开关关断（OFF）：开关管断开， $\mathrm { L } _ { 1 \mathrm { a } }$ 的电流通过二极管给 $\mathrm { C _ { P } }$ 充电；同时， $\mathrm { L } _ { 1 \mathrm { b } }$ 的电流通过二极管流向负载并给输出电容充电。 

<sub>•</sub> 电压关系：理想 CCM 模式占空比公式： $\begin{array} { r } { \mathsf { V } _ { \mathrm { o u t } } = \frac { \mathrm { D } } { 1 - \mathrm { D } } \mathsf { V } _ { \mathrm { i n } } } \end{array}$ 

<sub>•</sub> 电流特性：输入电流连续（通过 $\mathrm { L } _ { 1 \mathrm { a } }$ 平滑），输出电流断续（二极管只在 一部分时间导通，输出电容承受大脉冲电流）。 

4.3.2 设计核心 

① 耦合电容 $( \mathbf { C _ { 1 } } )$ 

<sub>•</sub> 电压： ${ \mathrm { C } } _ { 1 }$ 在稳态时两端电压等于输入电压 $\mathrm { V _ { i n } }$ 

纹波电流极大：导通时流过 $\mathrm { L } _ { 1 \mathrm { b } }$ 的电流，关断时流过 $\mathrm { L } _ { 1 \mathrm { a } }$ 的电流。必须使 用低ESR 的陶瓷电容（MLCC），且容量要足够，否则电容发热严重。 

<sub>•</sub> 容值计算： ${ \mathrm { C } } _ { 1 }$ 的容值决定了输入电感 $\mathrm { L } _ { 1 \mathrm { a } }$ 和输出电感 $\mathrm { L } _ { 1 \mathrm { b } }$ 之间的能量传 递。容值不能太小，否则会产生较大的低频纹波。 

② 电感 $\bf ( L _ { 1 a }$ 与 $\bf { L } _ { 1 b } )$ 

$\mathrm { L } _ { 1 \mathrm { a } }$ 和 $\mathrm { { I L } } _ { 1 \mathrm { { b } } }$ 的感量公式类似（基于各自的电压和纹波），但二者的平均电流 不同： $\begin{array} { r } { \mathrm { I } _ { \mathrm { L 1 a \_ a v g } } = \mathrm { I } _ { \mathrm { i n } } , \quad \mathrm { I } _ { \mathrm { L 2 b \_ a v g } } = \mathrm { I } _ { \mathrm { o u t } ^ { \circ } } } \end{array}$ 

<sub>•</sub> 耦合电感：在 SEPIC设计中，经常将 $\mathbf { \cdot L _ { 1 a } }$ 和 $\bf { { I L } } _ { 1 \mathrm { { b } } }$ 绕在同一个磁芯上（耦合 电感）。这不仅能节省体积和成本，还能显著降低输入和输出的电流纹 波。 

③ 输出电容 $( \bf { C _ { o u t } } )$ 

<sub>•</sub> 由于输出端（二极管后）是脉冲电流，输出电容必须承受极高的 RMS 纹 波电流。必须并联多个低 ESR的MLCC 或固态电容，否则极易鼓包爆炸。 

④ 耐压与控制环路 

<sub>•</sub> 耐压：开关管和二极管关断时承受的电压均为 $ { \mathrm { V } _ { \mathrm { i n } } } +  { \mathrm { V } _ { \mathrm { o u t } } }$ 

<sub>•</sub> 右半平面零点（RHPZ）：与 Boost 类似，SEPIC 在 CCM 模式下存在 RHPZ，导致环路带宽受限。补偿网络需要设计得比较保守。

5.1 开关电源中变压器关键参数 

开关电源变压器主要用于电压变换、电气隔离和能量传递。常见的拓扑反 激式、正激式、推挽式、半桥式、全桥式这五种电路。 

① 电感特性参数（决定能量转换能力） 

<sub>•</sub> 初级励磁电感 $\mathrm { ( L _ { m } ) }$ ）：决定变压器的储能能力和励磁电流大小。在反激 中，它决定了工作模式（CCM/DCM）；在 LLC中，它直接参与谐振。工作 时初级绕组通电产生磁场，励磁电感储存磁场能量： $\begin{array} { r } { \mathrm { E } = \frac { 1 } { 2 } \mathrm { L } _ { \mathrm { m } } \mathrm { I } _ { \mathrm { p k } } ^ { 2 } } \end{array}$ 

$\mathrm { L } _ { \mathrm { m } }$ 越大，相同电压和导通时间下，励磁电流上升越慢。 

o $\mathrm { L } _ { \mathrm { m } }$ 越小，励磁电流上升越快，峰值电流更大。 

<sub>o</sub> 反激电路中，励磁电感是主要储能元件。 

![](images/5127984f3b8da78764ec370b2b9c63f5dd4c2e25f0d7fc9daffb386ffb8233e3.jpg)


<sub>•</sub> 漏感 $( \mathrm { L _ { k } } )$ ）：初、次级耦合不紧密产生的寄生电感。它是万恶之源，关断 时会产生极高的电压尖峰（必须用 RCD吸收），但也可在LLC 中巧妙作为 谐振电感使用。 

影响：由于变压器初级和次级绕组不能做到完全耦合，一部分磁 通没有同时链过两个绕组，形成漏感。 

o 产生电压尖峰：MOSFET关断瞬间，漏感电流不能突变 $\mathrm { { V } = \mathrm { { L } _ { l k } \frac { d i } { d t } \mathrm { { \bar { \Omega } } } } } $ 

漏感能量： $\begin{array} { r } { \mathrm { E } _ { \mathrm { l k } } = \frac { 1 } { 2 } \mathrm { L } _ { \mathrm { l k } } \mathrm { I } _ { \mathrm { p k } } ^ { 2 } } \end{array}$ 。这些能量会产生 MOSFET漏极电压尖 峰，严重时可能导致 MOSFET 击穿。 

![](images/a7cbd363f8afda7c7965ebf656f959e22733e50aedddbd8a1e119109676c35aa.jpg)


<sub>•</sub> 匝比 $( \mathsf { N } _ { \mathsf { p } } \colon \mathsf { N } _ { s } )$ ）：初级与次级绕组的匝数比。直接决定了输出电压的范围 和原副边的电流比例。理想变压器： $\begin{array} { r } { \frac { \mathrm { V _ { p } } } { \mathrm { V _ { s } } } = \frac { \mathrm { N _ { p } } } { \mathrm { N _ { s } } } ; \quad \frac { \mathrm { I _ { p } } } { \mathrm { I _ { s } } } = \frac { \mathrm { N _ { s } } } { \mathrm { N _ { p } } } } \end{array}$ 

② 磁芯与物理参数（决定抗饱和能力） 

<sub>•</sub> 有效截面积 $( \mathsf { A } _ { \mathrm { e } } )$ ）：磁芯中心柱的等效导磁截面积，决定磁芯能够承载多 少磁通。 $\mathsf { A } _ { \mathsf { e } }$ 越大，变压器能承受的功率越大，越不容易饱和。 

<sub>o</sub> 公式： $\begin{array} { r } { \mathsf { A } _ { \mathrm { e } } = \frac { \Phi } { \mathsf { B } } } \end{array}$ ；B磁通密度；Φ磁通量； $\mathsf { A } _ { \mathsf { e } }$ 有效截面积。 

![](images/d99695b7800e433ec28b4cb5af02f381bb8c050911ddc85c046bbdc8ca19caec.jpg)


![](images/3f1c22c6129992e0022504cf94f7ae3bda57e78df85b80c04aa9dbeb702f428f.jpg)


<sub>•</sub> 饱和磁通密度 $( \mathtt { B } _ { \mathtt { s a t } } )$ ）：磁芯材料的物理极限。磁芯磁通密度不断增加 时，磁芯逐渐进入磁饱和区域。进入饱和后，磁导率和电感量会明显下 降，导致励磁电流快速增大，可能造成 MOSFET过流损坏。一旦工作时的 磁通密度��超过饱和磁通密度 $\mathtt { B } _ { \mathrm { s a t } }$ ，电感量会急剧下降，导致电流瞬间 飙升炸管。 

<sub>o</sub> 公式： $\begin{array} { r } { \Delta \mathsf { B } = \frac { \boldsymbol { \nabla } \cdot \boldsymbol { \mathrm { D } } } { \mathrm { N } _ { \mathrm { p } } \cdot \boldsymbol { \mathrm { A } } _ { \mathrm { e } } \cdot \boldsymbol { \mathrm { f } _ { s } } } \mathsf { ; } } \end{array}$ V初级绕组电压；D开关导通占空比； $\Nu _ { \mathrm { p } }$ 初级 匝数； $\mathsf { A } _ { \mathsf { e } }$ 磁芯有效截面积； $\mathrm { f } _ { s }$ 开关频率。 

<sub>•</sub> 气隙 $\left( \mathbf { { \sigma } } _ { \mathbf { { l } _ { g } } } \right)$ ）：在磁芯磁路中人为设置的一段非磁性间隙。由于空气磁导率 远低于铁氧体磁芯，气隙会增加磁路磁阻，降低磁路等效磁导率。 

作用：增大磁路磁阻，降低磁芯有效磁导率。在相同匝数下，降 低励磁电感。提高电感储能能力，减少磁芯饱和风险。使反激变 压器能够储存更多能量。 

反激变压器储能公式： $\begin{array} { r } { \mathrm { E } = \frac { 1 } { 2 } \mathrm { L } _ { \mathrm { m } } \mathrm { I } _ { \mathrm { p k } } ^ { 2 } } \end{array}$ 

③ 电气参数（决定器件选型） 

<sub>•</sub> 饱和电流 $( \mathrm { I } _ { \mathrm { { s a t } } } )$ ）：电感量下降到标称值一定比例（如 10%或 20%）时的电 流。设计时必须保证峰值电流小于此值。 

<sub>•</sub> 有效值电流 $\left( \mathrm { I } _ { \mathrm { r m s } } \right)$ ）：用于计算绕组的铜损（发热）。选线径时，通常按 $3 \sim 5 \mathrm { A } / \mathrm { m m } ^ { 2 }$ 的电流密度计算，并考虑高频下的集肤效应（通常采用多 股细线并绕）。 

<sub>•</sub> 工作频率 $( \mathrm { f } _ { \mathrm { s w } } )$ ）：变压器的工作频率。频率越高，允许使用的磁芯越 小，但铁损（涡流和磁滞损耗）会随之增加。 

④ 绝缘与结构参数（决定安规与 EMI） 

<sub>•</sub> 耐压：初级与次级之间必须满足的隔离电压（如 3000V AC/1 分钟），防 止漏电击穿。 

<sub>•</sub> 爬电距离：原副边引脚之间、绕组之间的物理安全距离，以满足安规要 求。 

<sub>•</sub> 绕制工艺：如“三明治绕法”（原边-副边-原边），能大幅减小漏感并改 善 EMI。

5.2 反激式开关电源电路原理及设计


## 5.2.1 核心工作原理

反激电路通过高频变压器实现能量的传递与电气隔离。变压器在这里不仅起 变压作用，还充当储能电感（耦合电感）。 

开关导通（ON）：初级绕组接通输入电压，初级电流线性上升，磁芯储 能。此时次级绕组感应电压使整流二极管反偏截止，负载完全由输出电 容供电。 

<sub>•</sub> 开关关断（OFF）：初级电流被切断，磁芯磁场剧烈变化，次级绕组感应 电压反向，整流二极管导通。变压器将储存的能量释放给次级负载，并 给输出电容充电。 

核心公式：CCM 模式下： $\begin{array} { r } { \mathrm { V } _ { \mathrm { o u t } } = \mathrm { V } _ { \mathrm { i n } } \times \frac { \mathrm { N } _ { s } } { \mathrm { N } _ { \mathrm { p } } } \times \frac { \mathrm { ~ D ~ } } { 1 - \mathrm { D } } } \end{array}$ ； $\Nu _ { \mathrm { p } }$ 初级 $/ \Nu _ { s }$ 次级为匝数 比。

## 5.2.2 设计核心

① 变压器设计（气隙与磁通） 

<sub>•</sub> 必须开气隙 $( \mathrm { l } _ { \mathbf { g } } )$ ）：反激变压器磁芯必须磨气隙。气隙能大幅降低有效磁 导率，防止磁芯在储能过程中饱和，并能储存更多能量。 

<sub>•</sub> 磁通密度（ΔB）：利用公式 $\begin{array} { r } { \Delta \mathrm { B } = \frac { \mathrm { V } \cdot \mathrm { D } } { \mathrm { N } _ { \mathrm { p } } \cdot \mathrm { A } _ { \mathrm { e } } \cdot \mathrm { f } _ { s } } } \end{array}$ 计算。设计时必须确保ΔB不超过 磁芯的饱和磁通密度，否则电感量骤降会导致电流爆炸。 

<sub>•</sub> 匝比 $( \mathsf { N } _ { \mathsf { p } } \colon \mathsf { N } _ { s } )$ ）：决定了反射电压和占空比范围，需权衡原边 MOS管的耐 压和副边二极管的耐压。 

② 漏感 $\mathrm { L } _ { \mathrm { k } }$ 与 RCD 吸收电路 

<sub>•</sub> 由于变压器无法做到完全耦合，必然存在漏感 $( \mathrm { L _ { k } } )$ ）。开关关断瞬间，漏 感电流不能突变 $\mathrm { ( V = L _ { k } \frac { d i } { d t } ) }$ ），会产生极高的电压尖峰。 

<sub>•</sub> 解决方案：在原边并联 RCD 吸收电路（钳位电路），消耗掉漏感能量，保 护 MOS管不被击穿。

谐振电压尖峰 $\mathbf { V _ { r } }$ ：漏感产生的谐振电压尖峰。当 MOSFET关断瞬间，变压 器漏感 $( \mathrm { L } _ { \mathrm { k } } )$ 中的电流突然被切断，巨大的di/dt会在MOSFET 漏极产生 极高的电压尖峰。公式： $\begin{array} { r } { \mathrm { V _ { r } = \sqrt { \frac { \mathrm { L _ { l k } } } { \mathrm { C _ { d s } } } } I _ { p } } } \end{array}$ 

<sub>•</sub> 副边整流二极管的电流 $\pmb { \Delta } \mathbf { I _ { \mathrm { D } } }$ ：只在开关管关断期间才有电流流过，呈现 一个下降的斜坡。公式： $\begin{array} { r } { \Delta \mathbf { I _ { D } } = \frac { \mathbf { V _ { 0 } } \left( 1 - \mathbf { D } \right) \mathbf { T } } { \mathrm { L _ { m } } } } \end{array}$ ；其中T为开关周期，D为占空 比。 

<sub>•</sub> 副边二极管的峰值电流 $\mathbf { I _ { D - p } }$ ：由于副边只在开关管关断期间供电，为了 维持平均输出电流 $\mathrm { I } _ { 0 }$ ，其峰值必须更高。公式： $\begin{array} { r } { \mathbf { I _ { D - p } } = \frac { \mathbf { I _ { 0 } } } { 1 - \mathbf { D } } + \frac { \Delta \mathbf { I _ { D } } } { 2 } } \end{array}$ ；前半 部分为平均电流（或直流分量），后半部分为纹波的一半。 

<sub>•</sub> 原边峰值电流 $\mathbf { I _ { p } }$ ：原边和副边电流根据匝数比n呈反比关系。公式： $\mathbf { I _ { p } } =$ $\frac { \mathrm { I _ { D - p } } } { \mathrm { n } }$ ；这个 $\mathrm { { I _ { p } } }$ 用来代入求解 $\mathrm { V _ { r } }$ 的关键参数。 

<sub>•</sub> 励磁电流 $\mathrm { I } _ { \mathrm { m } }$ ：呈三角波，在开关管导通时线性上升（储能），关断时线 性下降（释能）。 

<sub>•</sub> 变压器原边绕组的电压 $\mathbf { V _ { L } }$ ：导通时为 $\mathrm { V _ { i n } }$ ，关断时被副边钳位为 $- \mathrm { n V } _ { \mathrm { 0 } }$ 

$\mathrm { V } _ { \mathrm { g } s }$ ：MOSFET 的栅极驱动电压。高电平表示开关管导通，低电平表示关 断。 

$\mathrm { V _ { d } } _ { s }$ ：MOSFET 漏源极两端的电压波形。导通时，电压接近0。关断瞬间， 电压急剧上升，先出现一个巨大的高频振荡尖峰（这就是 $\mathrm { \Delta V _ { r } }$ ），然后稳 定在 $\mathrm { { V } _ { \mathrm { { i n } } } + n V _ { o } }$ （输入电压+副边反射电压）。

## ③ 工作模式（DCM vs CCM）

<sub>•</sub> DCM（断续模式）：DCM一个周期分为三个阶段。 

MOSFET 导通（储能）：初级励磁电流从零开始线性上升，变压器储 存能量。 

<sub>o</sub> MOSFET 关断（释能）：次级整流二极管导通，变压器向输出端释放 能量，励磁电流下降。 

退磁完成（空闲）：次级电流降至零，二极管截止，等待下一个开 关周期。 

<sub>o</sub> 公式： $\begin{array} { r } { \mathrm { V } 0 = \frac { \mathrm { V i n } * \mathrm { D } } { \mathrm { n } * ( 1 - \mathrm { D } ) } , \mathrm { I } _ { \mathrm { p } } = \frac { \mathrm { V } _ { \mathrm { i n } } \mathrm { D T } } { \mathrm { L } _ { \mathrm { m } } } \Rightarrow \mathrm { V } _ { \mathrm { 0 } } = \sqrt { \frac { \mathrm { R T } } { 2 \mathrm { L } _ { \mathrm { m } } } } \mathrm { V } _ { \mathrm { i n } } \mathrm { D } } \end{array}$ 

<sub>o</sub> 应用：中小功率首选。无二极管反向恢复问题，环路稳定（无右 半平面零点 RHPZ），但峰值电流大，变压器利用率低。

<sub>•</sub> CCM（连续模式）：CCM一个周期分为两个阶段： 

<sub>o</sub> MOSFET 导通（储能）：初级励磁电流在上一个周期的剩余电流基础 上继续上升。 

<sub>o</sub> MOSFET 关断（释能）：次级整流二极管导通，变压器释放能量，但 在下一个周期开始前，励磁电流尚未降至零。 

<sub>o</sub> 公式： $\begin{array} { r } { \mathrm { V } 0 = \frac { \mathrm { V i n } * \mathrm { D } } { \mathrm { n } * \mathrm { ( 1 - D ) } } ; \mathrm { V d } s = \frac { \mathrm { V i n } } { \mathrm { ( 1 - D ) } } } \end{array}$ （n 匝数比） 

<sub>o</sub> 应用：大功率场景。电流平滑，但存在 RHPZ问题，导致环路带宽 受限，需设计复杂的补偿网络。

## ④ 次级整流与输出电容

次级二极管仅在关断期间导通，输出电流是脉冲式的。因此输出电容必 须承受极大的 RMS纹波电流，建议使用低 ESR的电解电容并联 MLCC。 

追求高效率时，次级必须使用同步整流（SR）技术，用MOSFET 替代肖特 基二极管。现代高效率反激（如GaN 氮化镓快充），大幅降低次级损耗。

<sub>•</sub> 利用单变压器多个副边绕组，实现低成本的多路隔离电压输出。

## 5.3 正激电路原理及设计

## 5.3.1 核心工作原理

正激电路是一种常见的隔离型 DC-DC变换器，通过高频变压器直接传递能 量，在MOSFET导通期间向次级负载供电。广泛应用于工业电源、通信电源及中 等功率开关电源。 

开关导通（ON）：变压器原边通电，能量瞬间耦合到副边。副边整流二极 管导通，电流通过输出电感L流向负载，同时电感储能。 

<sub>•</sub> 开关关断（OFF）：开关管关断，变压器停止传递能量。此时副边续流二 极管导通，输出电感L释放能量，维持负载电流。 

<sub>•</sub> 输出电压:在连续导通模式（CCM） $\begin{array} { r } { \mathsf { V } _ { 0 } = \mathsf { D } \frac { \mathsf { N } _ { s } } { \mathsf { N } _ { \mathsf { p } } } \mathsf { V } _ { \mathrm { i n } } } \end{array}$ ；电感L 的纹波电 流: $\begin{array} { r } { \mathrm { { I } _ { r i p p l e } = \frac { D \cdot \left( 1 - D \right) } { N \cdot \mathrm { L } \cdot \mathrm { f } _ { s } } \cdot \mathrm { V } _ { \mathrm { i n } } } } \end{array}$ 

<sub>•</sub> 核心要点：正激电路必须有磁复位网络。因为正激变压器是单向励磁 的，每个周期结束前必须将磁芯中的能量清零（复位），否则磁芯会迅速 饱和炸机。

## ② 双管正激电路

电路结构：原边用两个MOSFET 串联上下各一个，可以看作是由两个开 关管构成的半桥，且没有第三复位绕组。 

<sub>•</sub> 工作过程 

开关导通（ON）： $\mathrm { Q } _ { 1 }$ 和 $\boldsymbol { \mathrm { I Q } } _ { 2 }$ 同时导通，输入电压 $\mathrm { { V _ { i n } } }$ 直接加在变压器原 边绕组上。此时，二极管 $\mathsf { D } _ { 1 }$ 和 $\mathsf { D } _ { 2 }$ 承受反向偏置，处于截止状态。能 量通过变压器传递给副边负载。 

开关关断（OFF）： $\mathrm { Q } _ { 1 }$ 和 $\boldsymbol { \mathrm { Q } } _ { 2 }$ 同时关断。变压器原边电流不能突变， 原边绕组极性反转（变成“下正上负”）。此时，变压器原边的异 名端电压升高，导通二极管 $\mathsf { D } _ { 2 }$ ；同名端电压降低，导通二极管 $\mathsf { D } _ { 1 }$ <sub>o</sub> 复位过程：励磁电流和漏感能量，通过 $\mathrm { D } _ { 2 }$ 回馈到输入电源的正极， 再通过 $\mathrm { \Delta D } _ { 1 }$ 回到电源负极。能量直接倒灌回输入端（电容），没有任 何电阻消耗它，这就是“天然无损复位”。 

<sub>•</sub> 优势：开关管关断时，漏感能量通过两个二极管回馈到输入电源，天然 实现无损磁复位；且开关管耐压只需承受 $\mathrm { V _ { i n } }$ （单管正激承受 $2 \mathrm { { V _ { i n } } . }$ ）。安全 性高、可靠性极强。

## ④ 谐振复位正激变换器

谐振复位正激是一种介于传统单管正激和有源钳位正激之间的“折中且巧 妙”的拓扑。它不需要额外的复位绕组，也不需要 RCD吸收电路，更不需要辅 助开关管，而是纯粹利用变压器自身的励磁电感 $\mathrm { L } _ { \mathrm { m } }$ 与开关管的寄生电容 $\mathrm { C } _ { 0 s s }$ 发 生谐振来实现磁芯复位。

## 5.3.3设计核心要点

## ① 占空比限制与磁复位

<sub>•</sub> 必须严格遵守伏秒平衡。单管正激的占空比D绝不能超过50%，必须留出 足够的死区时间让磁芯复位。如果复位不彻底，磁芯会累积磁通，最终 饱和。 

## ② 输出电感 $( \mathbf { L _ { 0 } } )$ 设计

正激的副边相当于一个 Buck电路，必须计算并选用合适的输出电感。它 的设计与 Buck 电感一模一样（基于副边电压和占空比计算感量），且必 须承受全部的输出电流。 

## ③ 副边整流网络设计

• 副边需要两个二极管或同步整流 MOS：整流管（导通时传递能量）和续 流管（关断时维持电感电流）。 

<sub>•</sub> 这两个管子承受的电压应力都是 $\begin{array} { r } { \nabla _ { \mathrm { i n } } \times \frac { \mathrm { N } _ { s } } { \mathrm { N _ { p } } } \cdot } \end{array}$ 

## ④ 环路补偿

<sub>•</sub> 正激本质是 Buck的隔离版。在CCM 模式下，它没有反激和 Boost 那种致 命的右半平面零点 RHPZ 问题。因此，正激的环路补偿相对简单，带宽可 以做得比较高，动态响应极快。 

## ⑤ 变压器设计

<sub>•</sub> 与反激不同，正激变压器不需要开气隙（因为不靠它储能）。变压器的任 务是高效传递能量，因此初级匝数通常较多，以避免磁通密度ΔB过大导 致饱和。 

## 5.4 桥式电路原理及设计

桥式变换器是一种常见的隔离型 DC-DC 开关电源拓扑，通过多个 MOSFET交 替导通，在变压器原边产生正、负交替电压，实现能量传输和电压变换。 

## 5.4.1 半桥拓扑（Half-Bridge）

<sub>•</sub> 电路结构：由两个主开关管（上下管）和两个分压电容（两个串联的输 入电容）组成。变压器原边接在两个开关管的中间节点和电容的中间节 点之间。 

<sub>•</sub> 工作过程： 

<sub>o</sub> 正半周期（Q1导通）：上管Q1 开通、下管Q2关断。输入电压加在 变压器原边（幅值约为 $+ \mathrm { V _ { i n } } / 2 )$ ，副边正向整流导通，能量传递给 负载。 

<sub>o</sub> 死区时间（全关断）：Q1关断，Q2尚未导通。上下管均关断，防止 桥臂直通短路；此期间变压器漏感与开关管寄生电容发生谐振换 流。 

<sub>o</sub> 负半周期（Q2导通）：下管Q2 开通、上管Q1关断。原边承受反向 电压（幅值约为 $- V _ { \mathrm { i n } } / 2 )$ ，变压器磁通反转，副边另一整流回路导 通，继续向负载传递能量。 

再次死区（周期结束）：Q2关断，再次进入死区状态。等待下一个 o 周期Q1 再次导通，至此完成一个完整的开关周期（实现变压器双向 对称励磁）。 

特点：抗偏磁能力强（通过电容自动隔直）、单管耐压 $\mathrm { V _ { i n } }$ 、结构简单、 成本适中。但输出功率一般（通常几百瓦到 1kW）。 

常见变种：LLC 谐振半桥（在极高频、高效率场景下最主流）。 

总结：半桥通过两个 MOSFET 交替导通，使变压器原边获得约± $\mathtt { V _ { i n } } / 2$ 的 交变电压，实现隔离变换；两个分压电容有助于抑制直流偏磁。LLC谐 振半桥则进一步利用谐振实现软开关，适合高频、高效率电源设计。

## 5.4.2 全桥拓扑（Full-Bridge）

<sub>•</sub> 电路结构：由四个主动开关管（S1、S2、S3、S4）、高频变压器（T）、两 个理想整流二极管（D1、D2）、储能电感（L）和滤波电容（C）构成。 

<sub>•</sub> 工作过程： 

<sub>o</sub> S1、S4 导通（正半周期）：电流从输入电压流经 S1、变压器原边线 圈与S4 形成回路，原边电压为 Vi。副边线圈1感应出电压 Vi/n， D1导通，向负载传递能量并为电感储能。 

<sub>o</sub> 全关断（死区时间）：原边电压为 0，变压器停止传输能量。副边 储能电感产生反电势使 D1与D2 同时导通续流，释放此前储存的能 量。 

S2、S3 导通（负半周期）：电流流经 S3、变压器原边线圈与 S2形 成回路，原边电压反向，幅值仍为 Vi。副边线圈2感应出电压 Vi/n，D2导通，再次向负载传递能量。 

<sub>o</sub> 再次全关断：原边线圈通过S1 与S3（或相应开关）短路，原边电 压为 0。副边 D1、D2 再次共同续流，完成一个完整开关周期。 

<sub>•</sub> 特点：输出功率极大（可达数千瓦）、变压器利用率最高。单管耐压 $\mathrm { V _ { i n } } ,$ 但在同等功率下，原边电流仅为半桥的一半。

① 反激变换器(Flyback) 

<sub>•</sub> 核心数据： 

<sub>o</sub> 原边开关管电压应力： $\begin{array} { r } { \mathrm { { V } _ { D S } = \mathrm { { V } _ { i n } + \frac { N _ { p } } { N _ { s } } \mathrm { { V } _ { 0 } + V _ { \mathcal { F } \backslash \mathcal { V } _ { \overline { { \mathcal { F } } } } } } } } } \end{array}$ 

<sub>o</sub> 变压器复位方式：副边二极管导通，磁化电感释放储能，实现磁 芯复位。 

<sub>o</sub> 输出电压公式（理想 CCM）： $\begin{array} { r } { \mathrm { V } _ { 0 } = \frac { \mathrm { N } _ { \mathrm { s } } } { \mathrm { N } _ { \mathrm { p } } } \mathrm { V } _ { \mathrm { i n } } \frac { \mathrm { D } } { 1 - \mathrm { D } } } \end{array}$ （占空比 $0 < \mathsf { D } < 1 )$ ）。 

<sub>o</sub> 输出纹波频率： $\mathrm { f } _ { s }$ （与开关频率相同）。 

<sub>o</sub> 能量传递方式：开关导通时储能，关断时释放能量。 

<sub>o</sub> 适用范围：小功率（通常几瓦至 150W）。 

## <sub>•</sub> 优点：

<sub>o</sub> 电路结构简单、成本低：只需要一个主开关管、一个变压器（耦 合电感）、一个副边整流二极管和输出电容，外围器件少，控制简 单。 

<sub>o</sub> 输入输出电气隔离：通过变压器实现原副边隔离，满足安全隔离 要求，适合市电输入电源。 

<sub>o</sub> 多路输出方便：变压器增加副边绕组即可实现多组不同电压输 出，适合辅助电源、待机电源等应用。 

宽输入范围适应性好：通过调节占空比和变压器匝比，可以适应 较宽的输入电压范围。 

载开关损耗。 

## <sub>•</sub> 缺点：

开关管电压应力较高：开关管关断时，需要承受输入电压与反射 电压之和，同时存在变压器漏感产生的电压尖峰，通常需要 RCD、TVS或有源钳位电路吸收尖峰。 

峰值电流较大：能量以磁化电感的形式储存后再释放，原副边电 流均呈脉冲特性，峰值及 RMS 电流较大，增加MOSFET、二极管和 变压器的导通损耗。 

<sub>o</sub> 输出纹波较大：副边仅在主开关关断期间向负载传递能量，输出 电容需要承担较大的脉冲电流，滤波设计要求较高。 

变压器设计要求高：磁芯需要储存能量，通常需要开气隙以提高 储能能力，同时需要考虑磁芯饱和、漏感、绕组损耗及温升。 

CCM 控制难度较高：连续导通模式（CCM）下存在右半平面零点 （RHPZ），限制控制环路带宽，增加补偿设计难度。 

## <sub>•</sub> 适用场景：

<sub>o</sub> 小功率辅助电源：如开关电源待机电源、工业控制辅助电源、家 电控制电源。 

<sub>o</sub> 消费电子电源：如手机充电器、小功率适配器、机顶盒电源。 

<sub>o</sub> 工业隔离电源：如PLC、电表、传感器及仪器仪表的隔离供电。 

多路输出电源：如需要同时提供 5V、12V、15V等多组辅助电压的 电源系统。 

## ② 谐振复位正激(Resonant Reset Forward)

<sub>•</sub> 核心数据： 

<sub>o</sub> 原边开关管电压应力： $\mathtt { V } _ { \mathrm { D S } } = \mathtt { V } _ { \mathrm { i n } } + \mathtt { V } _ { \mathrm { c r \_ p e a k } }$ （峰值极高，通常为 $\mathrm { V _ { i n } }$ 的 $1 . 5 { \sim } 2$ 倍以上）。 

<sub>o</sub> 变压器复位方式：关断期间，励磁电感 $\mathrm { L } _ { \mathrm { m } }$ 与开关管寄生电容 $\mathrm { C } _ { \boldsymbol { 0 } s s }$ 发生 LC谐振，实现无损磁芯复位 

<sub>o</sub> 输出电压公式（理想 CCM）： $\begin{array} { r } { \mathrm { V } _ { \mathbf { 0 } } \approx \frac { \mathrm { N } _ { s } } { \mathrm { N } _ { \mathbf { p } } } \mathrm { V } _ { \mathrm { i n } } \mathrm { D } \ \left( \mathbf { 0 } < \mathrm { D } < 1 \right) } \end{array}$ 

<sub>o</sub> 最大占空比：D可大于0.5（依靠谐振产生的高复位电压加快复位 速度，突破伏秒平衡限制）。 

<sub>o</sub> 输出纹波频率：通常为 $\mathrm { f } _ { s }$ （与开关频率相同）。 

<sub>o</sub> 输出特性：带有输出滤波电感 $\mathrm { L } _ { \mathfrak { o } }$ ，输出电流连续，纹波较小。 

能量传递方式：开关导通时直接向副边传递能量，关断时原边 LC 谐振复位。 

o 适用范围：中小功率（通常几十瓦至数百瓦）、高频化、低电压输 入（如 48V、24V）的场景。 

## 优点：

电路结构极简、成本极低：不需要第三复位绕组、不需要 RCD吸 收电路、不需要辅助开关管。仅利用变压器自身的励磁电感和开 关管寄生电容（或外接一个小电容）即可复位。 

<sub>o</sub> 无损复位，效率较高：漏感和励磁能量在 LC之间来回振荡并回馈 到电网或用于软开关，没有电阻消耗能量。 

占空比范围宽：最大占空比可以大于 0.5，极大地提高了变压器 的利用率，减小了变压器体积。 

<sub>o</sub> 可实现软开关（ZVS）：在重载条件下，利用谐振能量可以抽干开 关管的寄生电容，在电压谷底开通，实现零电压开通（ZVS），降 低开关损耗和 EMI。 

<sub>o</sub> 副边滤波容易：因为带有输出储能电感，输出电流连续，输出电 容不需要承受极大的脉冲电流。 

## <sub>•</sub> 缺点：

<sub>o</sub> 开关管电压应力极高（最大痛点）：为了保证宽输入范围和轻载下 能可靠复位，谐振峰值电压被设计得很高，开关管往往需要选用 800V 甚至 1000V 的高压 MOSFET，导致导通内阻 $\mathsf { R } _ { \mathrm { D S ( o n ) } }$ 变大，导通 损耗增加。 

<sub>o</sub> ZVS 范围受限：ZVS极其依赖励磁电流。在轻载时，由于励磁能量 不足，容易退化为硬开关，导致轻载效率下降且发热加剧。 

<sub>o</sub> 死区时间极其敏感：必须精确控制死区时间，使其等于或略大于 谐振周期的一半，否则会错过谷底开通，导致 ZVS 失败。 

<sub>o</sub> 变压器设计限制：为了获得足够的复位电压，变压器的励磁电感 $\mathrm { ( L _ { m } ) }$ 不能太大，且需要精确匹配开关管电容。 

## <sub>•</sub> 适用场景：

<sub>o</sub> 超薄/小功率适配器：如使用 GaN（氮化镓）器件的高频小功率快 充（对体积要求极高，且可容忍较高的管子耐压）。 

<sub>o</sub> 低电压输入电源：如24V或 48V通信/工业母线系统（由于输入电 压低，管子耐压压力相对较小）。 

<sub>o</sub> 对成本极致敏感的隔离电源：希望省去辅助管驱动电路和复杂变 压器绕组的小功率工业电源。 

LED 驱动电源：适合需要高频化以减小磁性元件体积的恒流/恒压 电源。 

## ③ 有源钳位正激(Active Clamp Forward)

<sub>o</sub> 变压器复位方式：通过辅助开关管与钳位电容构成谐振回路，实 现磁芯复位及漏感能量回收。

## <sub>•</sub> 优点：

<sub>o</sub> 磁芯复位效果好：通过钳位电容与辅助开关控制原边复位电压， 避免磁芯磁通累积，充分利用磁芯磁通摆幅。 

<sub>o</sub> 漏感能量回收：传统RCD吸收电路通过电阻消耗漏感能量，而有 源钳位可以将部分漏感能量回收到钳位电容及电源回路中，降低 损耗。

<sub>o</sub> 变压器利用率较高：相比传统单管正激，能够实现较大的有效占 空比，改善磁芯利用率，适合高频、高功率密度设计。 

## <sub>•</sub> 缺点：

<sub>o</sub> 控制与驱动复杂：需要主开关管和辅助开关管配合工作，通常采 用互补驱动及死区控制，对驱动时序要求较高。 

<sub>o</sub> 谐振参数设计复杂：励磁电感 $\mathrm { L } _ { \mathrm { m } }$ 、漏感 $\mathrm { L _ { l k } }$ 、钳位电容 $\mathrm { C _ { c l a m p } }$ 和 MOSFET 输出电容 $\mathrm { \bf C } _ { \mathrm { \bf 0 } s s }$ 相互影响，需要综合优化。 

轻载 ZVS 条件较差：轻载时励磁电流和负载电流减小，可能无法 提供足够的换流能量，导致 ZVS丢失，开关损耗增加。 

o 辅助开关增加成本：相比传统单管正激，增加辅助 MOSFET、驱动 电路及钳位电容，提高 BOM成本和设计复杂度。 

o 存在环流损耗：谐振过程中原边可能产生额外环流，增加 MOSFET、变压器绕组及钳位电容的 RMS电流，影响轻载效率。 

## 适用场景：

<sub>o</sub> 高频工业电源：如工业控制电源、通信电源及高功率密度 DC-DC 模块。 

服务器及数据中心电源：适合对效率、体积和功率密度有较高要 求的隔离电源。 

新能源辅助电源：如光伏逆变器辅助电源、电动汽车低压辅助电 源。 

<sub>o</sub> 高效率隔离电源：需要降低开关损耗、改善 EMI，并且适合采用 软开关技术的中小功率电源。 

④ 半桥(Half-Bridge) 

<sub>•</sub> 核心数据： 

<sub>o</sub> 原边开关管电压应力： $\mathrm { V _ { i n } }$ （两个 MOSFET均承受输入母线电压， 忽略尖峰）。 

<sub>o</sub> 变压器原边电压： $\pm \mathtt { V } _ { \mathrm { i n } } / 2$ （正负交替励磁）。 

<sub>o</sub> 变压器复位方式：正负半周交替工作，自动复位。 

<sub>o</sub> 输出电压公式（理想 PWM）： $\begin{array} { r } { \mathsf { V } _ { 0 } = \frac { \mathrm { N } _ { \mathrm { s } } } { \mathrm { N } _ { \mathrm { p } } } \frac { \mathsf { V } _ { \mathrm { i n } } } { 2 } \mathrm { D } } \end{array}$ （D为两个有效功率脉冲 占整个周期的总占空比；具体定义需结合控制方式）。 

<sub>o</sub> 输出纹波频率：通常为 $\Pi 2 \mathrm { f } _ { s }$ （全波整流、正负半周交替传能时）。 

<sub>o</sub> 适用范围：中功率（通常约 200W～1kW，也可根据设计扩展）。 <sub>•</sub> 优点： 

<sub>o</sub> 开关管数量较少：只需要两个主开关管，相比全桥减少两个 MOSFET，驱动电路相对简单，成本较低。 

<sub>o</sub> 开关管电压应力较低：两个开关管分别承受输入母线电压 $\mathrm { V _ { i n } }$ ，适 合高压直流母线应用。 

<sub>o</sub> 变压器双向励磁：原边施加正负交替电压，磁通能够自动复位， 避免单端正激拓扑需要额外复位绕组的问题。 

<sub>o</sub> 结构成熟可靠：拓扑结构简单，控制方式成熟，容易实现 PWM调 节， 工程应用广泛。 

适合中等功率设计：相比单管正激，变压器原边电压利用率更 高；相比全桥，器件数量和驱动成本更低。 

## <sub>•</sub> 缺点：

原边电压利用率较低：变压器原边只能获得± $\mathrm { \Delta } V _ { \mathrm { i n } } / 2$ ，相同输入电 压和匝比下，输出能力低于全桥。 

输入分压电容存在平衡问题：通常需要两个串联电容构成中点电 压，若电容参数、漏电流或工作状态不一致，可能产生电压不平 衡。 

<sub>o</sub> 原边电流较大：在相同输入电压、输出功率及效率条件下，半桥 原边电压只有全桥的一半，因此原边电流通常更大，增加绕组和 开关管导通损耗。 

存在变压器偏磁风险：如果正负半周伏秒不平衡，可能产生直流 磁通偏移，严重时导致磁芯饱和。

## ⑤ 全桥(Full-Bridge)

<sub>•</sub> 核心数据： 

<sub>o</sub> 原边开关管电压应力： $\mathrm { V _ { i n } }$ （最低的电压应力）。 

<sub>o</sub> 变压器复位方式：正负半周工作，自动复位。 

<sub>o</sub> 输出电压公式： $\begin{array} { r } { \mathrm { V } _ { \mathrm { o } } = \frac { \mathrm { V _ { i n } \cdot D } } { \mathrm { n } } } \end{array}$ （单边占空比 $0 < \mathrm { D } < 0 . 5 )$ 

<sub>o</sub> 输出纹波频率：2f（滤波容易）。 

<sub>o</sub> 适用范围：大功率 $( > 5 0 0 \mathrm { W } ^ { \sim }$ 数千瓦）、高压输入、高功率密度。 

## <sub>•</sub> 优点：

原边电流应力最小：在同等输出功率下，全桥原边电流仅为半桥 的一半（原边电压为 $V _ { \mathrm { i n } } )$ ），大幅降低了原边导通损耗和变压器绕 线难度，非常适合大功率输出。 

o 开关管电压应力低：四个管子最高仅承受输入母线电压 $\mathrm { V _ { i n } }$ （无 漏感尖峰前提下），在高压输入（如 400V母线）场景下优势极 大。 

磁芯利用率极高：变压器双向对称励磁，无直流偏磁风险（配合 隔直电容或控制算法）。 

<sub>o</sub> 动态响应快：输出纹波频率是开关频率的两倍（2f），输出 LC 滤 波器体积小，环路带宽高。 

## <sub>•</sub> 缺点：

<sub>o</sub> 器件多、成本高：需要4个主开关管（加上驱动、隔离电源）， BOM 成本远高于单管正激或半桥。 

<sub>o</sub> 驱动与防直通极其复杂：同一桥臂的上下管极易发生直通短路 （通常需要死区控制），且上管/下管通常都需要复杂的隔离驱动 （如光耦或磁隔离变压器）。 

<sub>o</sub> 偏磁风险：虽然能自动复位，但如果对角开关管的导通压降或驱 动时序不一致，容易产生“直流偏磁”导致变压器饱和，需加隔 直电容或采用电流模式控制。 

## <sub>•</sub> 适用场景：

<sub>o</sub> 大功率工业电源：如通信电源（>1kW）、电焊机、大功率逆变器。 

<sub>o</sub> 高效率新能源场景：结合软开关技术（移相全桥 PSFB 或全桥 LLC），广泛用于电动汽车车载充电机（OBC）和充电桩模块。

## 5.5 DC/DC 的 EMI 优化（不区分隔离或非隔离）

DC/DC 的EMI优化主要是通过抑制干扰源、切断耦合路径、降低敏感度，减 少开关电源产生的传导干扰和辐射干扰。 

## ① 主要优化措施

## <sub>•</sub> 输入滤波：

o 差模滤波：输入端并联X电容，配合差模电感，抑制正负输入线 之间的高频干扰。 

共模滤波：采用共模电感，配合 Y电容，抑制共模噪声。 

<sub>o</sub> 输入电容尽量靠近功率开关回路，减小高频电流环路面积。 

## <sub>•</sub> 开关节点优化：

<sub>o</sub> 减小 SW节点铜箔面积，降低高频电场辐射。 

<sub>o</sub> 优化 MOSFET开关速度，适当增加栅极电阻，减小电压、电流变化 率（dv/dt、di/dt）。 

<sub>o</sub> 合理设置死区时间，避免上下管直通及异常振铃。 

## <sub>•</sub> 吸收与钳位电路：

<sub>o</sub> 在MOSFET、二极管或变压器两端增加 RC、RCD、TVS 吸收电路。 

<sub>o</sub> 抑制寄生电感与寄生电容产生的电压尖峰和高频振铃。 

<sub>o</sub> 吸收参数应根据实际振铃频率和波形调整。 

## <sub>•</sub> PCB 布局优化：

<sub>o</sub> 缩小高频大电流环路面积，尤其是输入电容—MOSFET—续流回 路。 

<sub>o</sub> 功率地与信号地合理分区，采用单点连接或受控回流路径。 

<sub>o</sub> 驱动信号远离 SW节点和功率电感，避免干扰反馈及控制电路。 

<sub>o</sub> 缩短关键功率走线，减少寄生电感。 

## <sub>•</sub> 输出滤波优化：

<sub>o</sub> 合理选择 LC滤波器，降低输出电压纹波及高频噪声。 

<sub>o</sub> 选择低 ESR电容，必要时增加磁珠或 π型滤波网络。 

<sub>o</sub> 注意滤波器与控制环路之间的稳定性影响。

## 5.6 DC/DC 电源关键参数选型

DC/DC 电源（尤其是开关电源芯片）的选型是一个权衡成本、体积、效率和 可靠性的过程。以下是关键参数选型的简要总结： 

## ① 拓扑

<sub>•</sub> 拓扑结构：根据需求选 Buck（降压）、Boost（升压）或 Buck-Boost （升降压）。 

整流方式：首选同步整流（内置下管 MOS），尤其在低压大电流输出时， 效率远高于非同步（二极管续流）。 

## ② 电压与电流

<sub>•</sub> 输入电压：必须涵盖系统母线电压，且需留出 20%~30%的瞬态裕量（防 过冲击穿）。 

<sub>•</sub> 输出电压：分清是固定输出还是可调输出（需外接分压电阻）。 

<sub>•</sub> 输出电流：看芯片的最大持续电流（如 2A），实际设计需降额使用 （70%~80%）以防过热。 

## ③ 效率与功耗

<sub>•</sub> 静态电流（Iq）：电池供电或待机设备，Iq 越低越好（μA 级）。 

<sub>•</sub> 开关频率：频率高（如 580kHz+）可缩小电感和电容体积；频率低则开 关损耗小、EMI好处理。 

<sub>•</sub> 工作模式：是否支持轻载高效模式（如PFM/跳周期），这对降低待机功 耗至关重要。 

## ④ 保护与控制功能

<sub>•</sub> 核心保护：过流/短路保护（OCP/SCP）（最好带打嗝模式Hiccup，短路 不发热）、过温保护（OTP）、输入欠压锁定（UVLO）。 

<sub>•</sub> 软启动（SS）：防止开机瞬间产生巨大浪涌电流拉垮前级电源。

 第 1步（输入）：选取输入电压 $\mathrm { V } _ { \mathrm { I N } }$ 、输出电压 $\mathsf { V } _ { 0 \mathrm { U T } }$ 、输出电流 $\mathrm { I _ { 0 U T } }$ 和开 关频率 f，用于计算下方方程。 

 第 2 步（最大占空比）： $\begin{array} { r } { \mathrm { D C } _ { \mathrm { M A X } } = \frac { \mathrm { V } _ { 0 \mathrm { U T } } } { \mathrm { V } _ { \mathrm { I N ( M I N ) } } + \mathrm { V } _ { 0 \mathrm { U T } } } } \end{array}$ 

 第 3步（限流电压）：查看“典型性能特性”中的最大电流限制与占空 比曲线图，以找到在 $\mathsf { D C } _ { \mathrm { M A X } }$ 时的 $\tt V _ { C S P N }$ 

第 4 步（采样电阻）： $\begin{array} { r } { \mathsf { R } _ { \mathtt { S E N S E } } \le 0 . 6 3 \cdot \frac { \mathtt { V } _ { \mathtt { C S P N } } ( 1 - \mathrm { D C } _ { \mathtt { M A X } } ) } { \mathtt { I } _ { \mathtt { O U T } } } = \mathsf { R } _ { \mathtt { S E N S E 1 } } = } \end{array}$ 

第 5 步（电感）： $\begin{array} { r } { \mathrm { L } _ { \mathrm { T Y P } } = \frac { \mathrm { R } _ { \mathrm { S E N S E } } \cdot \mathrm { V } _ { \mathrm { 0 U T } } } { 1 2 . 5 \mathrm { m } \cdot \mathrm { f } } \cdot \frac { \mathrm { V } _ { \mathrm { I N ( M I N ) } } } { \mathrm { V } _ { \mathrm { I N ( M I N ) } } + \mathrm { V } _ { \mathrm { 0 U T } } } ; } \end{array}$ 

$$

<sub>•</sub> 外围构成：输入电容、高频隔离变压器（带中心抽头，双向对称励磁）、 两个主开关管（交替导通，源极共地）、副边全波整流二极管（或同步 MOS）、输出储能电感、输出滤波电容。 

选型核心：电源类型（隔离型）、是否同步、工作电压（开关管电压应力 较高，关断时需承受两倍输入电压 $2 V _ { i n }$ ）、输出电压及电流（适合低压 输入、中大功率应用）、开关频率（副边输出纹波频率为 2�）、静态电 流、工作温度、封装及电源转换效率 η这些参数。（补充关注：存在变 压器直流偏磁风险，两管导通时间或管压降不一致极易导致磁芯单向饱 和炸机，需严格匹配或采用电流模式控制；但两管源极共地，驱动相对 简单，无需高边浮驱）。
