# 第一部分：射频电路 PCB 设计实战（PCB吉迷哥，5 集）

## 1.1 射频电路基础知识（RF01）

### 1.1.1 什么是射频

射频（RF，Radio Frequency）狭义上指 300 kHz ~ 300 GHz 的电磁振荡频率范围，广义上凡是"信号的波长与电路尺寸可比拟、必须考虑波动特性"的高频电路都按射频方法处理。

| 频段名称 | 频率范围 | 波长（自由空间） | 典型应用 |
|---|---|---|---|
| HF 高频 | 3 ~ 30 MHz | 100 ~ 10 m | 短波电台、RFID |
| VHF 甚高频 | 30 ~ 300 MHz | 10 ~ 1 m | FM 广播、对讲机 |
| UHF 特高频 | 300 MHz ~ 3 GHz | 1 m ~ 10 cm | 手机、WiFi 2.4G、蓝牙、GPS |
| SHF 超高频 | 3 ~ 30 GHz | 10 ~ 1 cm | 5G 毫米波前段、雷达、卫星 |
| EHF 极高频 | 30 ~ 300 GHz | 1 cm ~ 1 mm | 毫米波雷达（60/77 GHz）、6G 研究 |

PCB 设计中"射频板"常见的实际工作频段：433 MHz、868/915 MHz（ISM）、1.575 GHz（GPS L1）、2.4 GHz（蓝牙/WiFi/ZigBee）、3.5 GHz（5G sub-6）、5.8 GHz、24 GHz 与 77 GHz（车载雷达）等。

### 1.1.2 集总参数与分布参数——射频电路的第一性原理

低频/数字电路中，导线只是"理想连接线"，电阻、电容、电感是**集中在器件里**的，这叫集总参数（lumped）电路。当频率升高到波长与走线尺寸可比拟时，导线本身每一段都分布着电阻、电感、电容、电导，信号以电磁波形式沿线传播，这叫**分布参数（distributed）电路**。

判断一条走线要不要按"传输线"处理，工程上用两个准则：

| 准则 | 公式 | 判据 | 说明 |
|---|---|---|---|
| 波长准则 | `λ = c / (f · √εreff)` | 走线长度 > λ/10 | 走线电长度超过 1/10 波长，必须按传输线分析 |
| 上升沿准则 | `l_max = Tr / (6 · tpd)` | 看信号 Tr | Tr 为上升时间，tpd 为单位长度传播延时 |

**数值算例**：FR-4 板上 εreff ≈ 4.3（微带有效值，约取 εr 一半到全值之间），2.4 GHz 信号：
- 波长 λ = 300 / 2.4 / √4.3 mm ≈ 125 / 2.07 ≈ **60 mm**（板上波长，比自由空间 125 mm 短）
- λ/10 ≈ **6 mm**——也就是说 2.4 GHz 射频板上，超过 6 mm 的走线就是"长线"，必须做阻抗控制；而数字电路里 10 cm 都不算长。这就是射频板和数字板布线逻辑的本质区别。

**趋肤效应（Skin Effect）**：频率越高，电流越集中在导体表面流动。趋肤深度：

```
δ = √( 2ρ / (ω·μ) ) = √( ρ / (π·f·μ) )
```

铜（ρ = 1.72×10⁻⁸ Ω·m，μ ≈ μ0）的趋肤深度速查：

| 频率 | 趋肤深度 δ（铜） | 说明 |
|---|---|---|
| 1 MHz | 66 μm | 仍大于普通铜厚（35 μm），整层铜都载流 |
| 10 MHz | 21 μm | 开始集中到表面 |
| 100 MHz | 6.6 μm | 表面电镀质量开始重要 |
| 1 GHz | 2.1 μm | 走线表面粗糙度直接成为损耗主力 |
| 10 GHz | 0.66 μm | 必须用压延铜（低粗糙度铜箔） |

这带来三个 PCB 结论：
1. **射频电流走"最小回路面积"路径**，即紧贴走线正下方的参考地平面表面流动（微带线返回电流约 80% 集中在走线投影宽度内），所以参考平面的完整性是射频布线的生命线；
2. **表面处理影响插损**：ENIG 化学镍金的镍有磁性且电导率低，高频损耗大于沉银/OSP；毫米波频段要评估镀层选型；
3. **铜箔粗糙度 Rz ≈ 1~8 μm 与趋肤深度同量级**，5 GHz 以上尽量选 RTF（反转处理铜箔）或 HVLP 铜箔的板材。

### 1.1.3 射频 PCB 与数字 PCB 的设计思维差异

| 维度 | 数字 PCB | 射频 PCB |
|---|---|---|
| 信号本质 | 电平（0/1），时域 | 波（幅度/相位），频域 |
| 关心指标 | 建立时间、串扰、EMI | 插损、回损、隔离度、噪声系数 |
| 走线 | 逻辑连接线 | 具有特征阻抗的元器件（微带线、带状线） |
| 布线优先级 | 等长 > 间距 | 阻抗连续 > 拐角平滑 > 长度 |
| 过孔 | 拉信号用 | 寄生电感电容明显，能少则少 |
| 地平面 | 参考 + 屏蔽 | 电流回路的**组成部分**，参与阻抗计算 |
| 弯角 | 45° 或双 135° | 圆弧优先，且半径 ≥ 3 倍线宽 |
| 器件封装 | 功能优先 | **封装即电路**：0402 与 0201 的寄生参数直接进匹配网络 |
| 仿真工具 | SI 仿真（时域） | S 参数、史密斯圆图（频域） |

### 1.1.4 射频核心指标词汇表

| 指标 | 符号/公式 | 物理含义 | 工程经验值 |
|---|---|---|---|
| 特性阻抗 | `Z0 = √((R+jωL)/(G+jωC))`，无损时 `Z0 = √(L/C)` | 传输线上行波电压/电流之比 | 射频系统统一 50 Ω（历史沿袭，兼顾损耗与功率容量的折中） |
| 反射系数 | `Γ = (ZL - Z0)/(ZL + Z0)` | 负载失配引起的反射比例 | \|Γ\|<0.1 为良配 |
| 电压驻波比 | `VSWR = (1+\|Γ\|)/(1-\|Γ\|)` | 驻波最大/最小电压比 | <1.5 合格，<1.2 优良 |
| 回波损耗 | `S11 = -20·log10(\|Γ\|)` dB | 反射能量的负 dB 数 | ≥ 15 dB 良好，≥ 20 dB 优良 |
| 插入损耗 | IL，= -20·log10\|S21\| dB | 信号通过后的衰减 | 越小越好，无源链路预算 |
| 隔离度 | Iso dB | 两个通道/腔体间泄漏的抑制比 | 收发隔离、腔间隔离常要求 >60 dB |
| 噪声系数 | `NF = SNRin / SNRout` | 信号信噪比恶化倍数（dB） | LNA 决定整链路 NF，前级低噪高增益最重要 |
| 三阶交调 | `OIP3 = Pout + IMR/2` | 两个信号产生的 2f1-f2 交调产物 | 表征线性度 |
| 1 dB 压缩点 | P1dB | 增益比线性下降 1 dB 的输出功率 | 功放的功率基准 |

**50 Ω 的来历**：早期同轴电缆在 77 Ω 损耗最小、在 30 Ω 功率容量最大，50 Ω 是两者的几何平均，于是成为射频仪器、电缆、连接器的统一标准。射频板必须迁就这个"生态约定"，源、负载、传输线三者都 50 Ω 才能实现最大功率传输（共轭匹配时功率最大，纯阻性 50 Ω 系统中共轭匹配就是 50 Ω 对 50 Ω）。

### 1.1.5 S 参数——射频工程师的"万用表"

低频用 Z/Y/H 参数（开路短路测量困难），射频统一用 S 参数（散射参数）：端口接标准 50 Ω，测入射波/反射波关系。

| 参数 | 含义 | 理想值 |
|---|---|---|
| S11 | 端口 1 的反射（输入匹配） | 0（即回损无穷大） |
| S21 | 1→2 的正向传输（增益/插损） | 放大器 >0 dB，无源 <0 dB |
| S12 | 2→1 的反向传输（反向隔离） | 越小越好 |
| S22 | 端口 2 的反射（输出匹配） | 0 |

读 S 参数的三个习惯：
1. 频率扫描下先看 **S11 谷**在哪，谷对应谐振/匹配点；
2. 无源网络看 S21 有没有"周期性波纹"，有波纹说明存在失配多次反射；
3. 群时延 `group delay = -dφ/dω` 突变处往往是谐振点。

### 1.1.6 阻抗匹配的物理意义

失配的三大恶果：
- **功率反射**：负载不是 50 Ω，功率送不过去，`反射功率 = 入射功率 × |Γ|²`；
- **增益波动与平坦度恶化**：多次反射叠加造成频响纹波；
- **损坏风险**：功放输出失配时反射功率烧末级管子，驻波保护电路就是基于这个。

共轭匹配定理：源阻抗 `Rs - jXs` 与负载 `Rl + jXl` 共轭时负载获最大功率。匹配网络的本质就是**用无耗电抗元件（L、C、传输线段）把阻抗在史密斯圆图上"转"到目标点**，同时不引入额外损耗。

## 1.2 射频电路布局原则（RF02）

### 1.2.1 布局总原则：按信号流"一字排开"

射频布局第一原则：**沿信号链路方向按功能顺序直线排布，让信号像流水一样从天线流到数字接口，不走回头路**。

| 原则 | 说明 | 违反后果 |
|---|---|---|
| 一字形/流水线布局 | 天线→双工器→LNA→混频→中频→基带 依次排开 | 信号绕圈导致输入输出耦合，自激振荡 |
| 高低频分区 | 射频区、电源区、数字区分开，间距 ≥ 5 mm 或用地带隔离 | 数字噪声串进射频前端，底噪抬升 |
| 输入输出远离 | 同一模块的输入与输出端口间距尽量大 | 寄生反馈 → 自激 |
| 屏蔽罩预留 | 每个射频功能级预留屏蔽罩墙位置和焊盘 | 后期无法补救隔离度 |
| 屏蔽墙即分界 | 布局时就把屏蔽罩墙体当"高速公路隔离带"规划进去 | 腔体谐振与串扰失控 |

**为什么"一字排开"如此重要——自激机理**：放大器增益 30 dB 意味着输出功率是输入的 1000 倍，输出只要通过空间耦合、地回路、电源线把千分之一的能量送回输入端（-30 dB 隔离），环路增益 ≥ 1 即满足起振条件。射频布局的本质就是**用物理距离和屏蔽把反向隔离做到远大于正向增益**。

### 1.2.2 器件级布局规则

| 器件 | 布局规则 | 原因 |
|---|---|---|
| LNA | 尽量靠近天线/双工器输出，走线最短 | 前级插损直接 1:1 恶化系统噪声系数（NF 级联公式中第一级最关键） |
| 滤波器 | 靠近 LNA 或混频器，输入输出走线对称 | 滤波器前后失配会改变通带形状 |
| 晶振/TCXO | 远离射频大功率路径与天线，下方完整地平面，包地处理 | 晶振谐波（奇次倍频泄漏）是杂散源 |
| PLL/VCO | 独立屏蔽腔，环路滤波器器件紧凑围绕芯片 | 环路滤波器走线拾取噪声 → 相位噪声恶化 |
| 电感（RF 扼流/匹配） | 轴向互相垂直、间距 ≥ 3 倍线宽或换向排布 | 电感间互感耦合 |
| 去耦电容 | 每电源引脚一个最近的（容值阶梯 100pF/10nF/1μF/10μF），过孔就近下地 | 电源在高频不是理想源，是噪声总线 |
| 功放 PA | 靠近板边/屏蔽罩、大面积散热过孔到散热层 | 热与 EMI 双重问题 |
| Balun（巴伦） | 紧贴芯片差分端口，走线对称 | 差分对称性决定平衡度 |

### 1.2.3 电源与地的处理

1. **电源走"星型"或"一点分叉"**：各级射频供电从电源入口单独拉线，不要让后级电流流经前级供电路径（避免共阻抗耦合反馈）。
2. **PA 供电与 LNA 供电物理隔离**：大电流纹波不能进小信号级。
3. **地即射频电路的一部分**：射频区不"分割地平面"，所有地过孔就近打到完整参考层；多点接地（每 1/20 波长至少一个地过孔）。
4. **参考层完整**：射频走线换层时，必须在换层过孔旁打伴随地过孔（stitching via），让返回电流有低感回路。
5. **禁止射频走线跨分割**：跨分割 = 回路面积暴增 = 感性失配 + 辐射 + 串扰三重打击。

### 1.2.4 布局顺序 checklist

```
□ 1. 确定天线位置（板边、净空区）→ 双工器/滤波器 → 射频链路主干
□ 2. 沿主干一字排开放大、混频各级
□ 3. 规划屏蔽罩墙体（腔体划分），每腔一个功能级
□ 4. 时钟/PLL/VCO 独立小腔
□ 5. 电源入口、DC-DC、数字接口放射频区对角/另一端
□ 6. 预留测试点（射频测试焊盘 on 50Ω 线）
□ 7. 评审：信号流无交叉、无回头、输入输出隔离、屏蔽墙闭合
```

## 1.3 射频电路布局要求（RF03，具体量化规范）

### 1.3.1 间距与尺寸量化要求

| 项目 | 量化要求 | 备注 |
|---|---|---|
| 射频走线与地过孔间距 | 3W 原则（≥2~3 倍线宽），屏蔽要求高用 5W | 串扰随间距指数衰减 |
| 地过孔间距（屏蔽墙） | ≤ λ/20，高频（>2 GHz）建议 ≤ λ/40 | 2.4 GHz 时 λ/20≈3 mm，即每 3 mm 一个地孔 |
| 腔体尺寸（屏蔽罩内） | 最长边 < λg/2，避免腔体谐振落在工作带内 | λg 为介质中波长 |
| 电感间距 | ≥ 3× 电感本体宽度，或互相垂直 | 抑制互感 |
| 敏感级与噪声源间距 | ≥ 5 mm 且有隔离地 | 晶振 vs 天线、PA vs LNA |
| 射频走线最短化 | 每多 1 mm 都是插损（FR-4 微带约 0.1~0.2 dB/cm @ 2.4G） | 布局定插损预算 |
| 板边铜皮距离 | ≥ 20H（H 为层间距）时相邻层无耦合 | 板边辐射控制 |

### 1.3.2 走线要求

| 项目 | 要求 | 原因 |
|---|---|---|
| 拐角 | 圆弧优先，半径 ≥ 3W；或 45° 切角（切角 50% 外侧补偿） | 直角拐角等效宽度突变 → 容性不连续 → 反射 |
| 线宽变化（匹配网络进出） | 用渐变（taper）过渡，禁止突变台阶 | 阻抗突变点每个产生反射 |
| 射频走线禁止 | 分支、桩线（stub）、测试焊盘直挂 | 开路桩线 = 谐振器/陷波器 |
| 过孔 | 射频主路径尽量不打过孔；必须换层时用背钻或盲埋孔 | 过孔残桩在 GHz 频段呈容性/谐振 |
| 焊盘 | 射频器件焊盘两侧加"减压盘"或改小焊盘 | 焊盘电容使局部阻抗下坠（典型 0402 焊盘区阻抗掉到 ~40 Ω） |
| 耦合间距 | 微带线间距 ≥ 3H（H=介质厚）防耦合 | 保证隔离度 |
| 端接 | 0402 电阻接地端直接打孔，孔中心距焊盘中心 <0.5 mm | 孔电感 (~0.5 nH) 串进端接破坏高频性能 |

**算例：过孔寄生参数**。一个 0.3 mm 孔径、1.6 mm 板厚过孔的电感量级：

```
L_via ≈ 5.08 × h × [ ln(4h/d) + 1 ] × 10⁻⁹  (h 英寸)
     ≈ 5.08 × 0.063 × ( ln(4×0.063/0.012) + 1 ) nH ≈ 1.2 nH
```

1.2 nH 在 2.4 GHz 的感抗 `XL = 2π×2.4G×1.2n ≈ 18 Ω`——一个过孔就给端接电阻串了 18 Ω，10 GHz 时高达 75 Ω，端接完全失效。这就是射频地过孔要"多而密"（并联降感）的原因。

### 1.3.3 屏蔽墙与腔体划分细则

1. **一腔一级**：一个屏蔽腔内放一个功能级（如"LNA 腔""VCO 腔""IF 腔"），腔与腔之间墙体上不放射频信号穿行（必须穿时用屏蔽腔贯穿式连接器或墙下过孔带）。
2. **墙体 = 过孔带 + 屏蔽罩立筋**：PCB 上预留双排交错地过孔（间距 λ/40）+ 表面焊接屏蔽罩立墙焊盘。
3. **腔体谐振规避**：矩形腔谐振频率 `f(mnp) = (c/2√εr)·√((m/a)² + (n/b)² + (p/d)²)`，最低模 TE101。**算例**：30×20 mm 腔体、FR-4（εr=4.3）、屏蔽罩高 4 mm：f101 ≈ (300/2/2.07)×√((1/30)²+(1/20)²) GHz ≈ 5.6 GHz——2.4G 板安全，5.8G 板这个腔体尺寸正好激励谐振，需分腔缩小。
4. **屏蔽罩下方走线**：尽量不放；必须放时保证屏蔽罩内净高和走线 50 Ω 兼容（罩体离线 ≥5 倍线高时影响 <2%）。
5. **腔内禁止无关信号穿过**：一个数字 I2C 从 VCO 腔穿过会毁掉相位噪声。

### 1.3.4 天线区要求

- 天线及净空区（keep-out）禁铺铜、禁走线、禁器件，净空 ≥ 波长的 1/10 且参考评估板指南；
- 天线馈点走 50 Ω 微带/共面波导，馈点附近地过孔密集；
- 天线远离 LCD 排线、电池、金属结构件（外壳金属件会让实测谐振频偏 10% 以上）。

## 1.4 射频电路屏蔽罩设计（RF04）

### 1.4.1 为什么需要屏蔽罩

自由空间隔离度随距离增加非常缓慢（远场衰减 ~1/r），而射频板内部各级靠距离隔离远不够，必须用金属腔体"物理截断"耦合路径：

| 耦合路径 | 无屏蔽时量级 | 屏蔽后 |
|---|---|---|
| 空间辐射耦合（电场/磁场） | -20 ~ -40 dB（几 mm 距离） | 附加 40~80 dB 隔离 |
| 地平面共阻抗耦合 | -30 dB 量级 | 配合良好接地孔仍需布线控制 |
| 近场互感（电感间） | 强 | 屏蔽罩吸收 + 垂直布局 |

**隔离度预算算例**：GPS LNA 前端增益 40 dB，要求稳定不自激需反馈 < -60 dB。板面布局给 -35 dB，屏蔽罩给 -40 dB，合计 -75 dB，留 15 dB 余量 → 设计通过。没有屏蔽罩则余量 -5 dB，量产一致性一波动就自激。这就是"高频高增益链路必加屏蔽"的定量理由。

### 1.4.2 屏蔽罩的结构组成

| 元件 | 作用 | 设计要点 |
|---|---|---|
| 屏蔽罩框架（立墙） | 围出腔体 | 洋白铜/锡磷青铜，厚 0.2~0.3 mm，高 3~7 mm |
| PCB 焊接边框 | 立墙焊到板上 | 宽 1.0~1.5 mm 表贴焊盘带，窗花（减小焊盘）不推荐开成梳齿 |
| 屏蔽盖 | 封顶 | 可拆卸盖（调试期）或一体框架；量产板常用两件式 |
| 过孔带 | 墙下 PCB 内部延续 | 与墙焊盘重合，孔距 λ/40，双排交错 |
| 隔离墙（中隔） | 把大罩分成多腔 | 防止腔体过大谐振、级间串扰 |

### 1.4.3 屏蔽罩设计规则（量化）

1. **墙焊盘过孔带**：地过孔中心距 ≤ λg/40，2.4 GHz FR-4 上约 1.5 mm；孔带越密低频磁场隔离越好（高频主要靠金属墙本体）。
2. **罩内净高**：≥ 器件最高点 + 0.5 mm；同时注意罩高与腔体尺寸共同决定谐振频率，罩内最高点与顶盖距离对第 2 章腔体谐振公式中的 d 项影响显著。
3. **分腔**：单腔最长边建议 < λg/2 @最高工作频率；PA 腔与 LNA 腔必须独立。
4. **接地连续**：屏蔽墙焊盘正下方内层地与表层地通过过孔阵列连成一体；墙下禁止走非地信号。
5. **开孔/开窗**：散热孔单孔直径 ≤ λ/20（防泄漏，2.4G 即 ≤6 mm，但实际孔阵一般 ≤2 mm）；禁止长条孔。
6. **盖子与墙搭接**：搭接边 ≥ 1 mm，弹性接触齿保证连续导电；拼接缝长于 λ/20 时隔离度下降明显。
7. **装配兼容**：罩内器件与墙距离 ≥ 0.5 mm 防短路；罩外周围 1 mm 内禁布件（回流焊阴影）。
8. **热设计**：PA 腔顶盖可加导热垫与外壳接触散热。

### 1.4.4 屏蔽罩的谐振与去谐振

屏蔽腔是一个矩形谐振腔，工作频段必须避开腔体谐振频率，否则屏蔽罩变成"谐振器"，隔离度在谐振点反而恶化 20 dB 以上。对策：
- 拆小腔体（最常用）；
- 腔内加吸收材料（载波板频率高时用）；
- 腔体尺寸故意做成非整数比（长宽比避开 2:1、1:1，多模简并）；
- 评估时用谐振公式对最高谐波频率（如 2.4G 的三次谐波 7.2G）都验算一遍。

### 1.4.5 替代/补充手段

| 手段 | 适用场景 | 局限 |
|---|---|---|
| 屏蔽罩 | 量产射频板标准做法 | 成本、高度 |
| 屏蔽框+导电泡棉 | 低频（<1 GHz）消费类 | 隔离上限 ~40 dB |
| 吸波材料贴片 | 腔体谐振吸收、毫米波 | 温度/老化、成本 |
| 腔体化 Layout（无罩强隔离） | 高密度板、模块化 SiP | 依赖级间距足够 |

## 1.5 射频电路阻抗设计（RF05）

### 1.5.1 三种常用射频传输线结构

| 结构 | 剖面 | 典型阻抗范围 | 特点 |
|---|---|---|---|
| 微带线（Microstrip） | 表层走线 + 下方完整参考地 | 20~120 Ω | 最常用，场一半在空气，εreff < εr，易受环境影响 |
| 带状线（Stripline） | 内层走线，上下双参考地 | 30~100 Ω | 自屏蔽、EMI 好，但加工控参更严、无表面检测 |
| 接地共面波导（CPWG / GCPW） | 表层走线 + 两侧共面地 + 下参考地 | 25~120 Ω | 对屏蔽/串扰最好，对铜厚和阻焊不敏感度介于两者间，地孔密 |

选型经验：普通射频链路表层微带；高隔离、多路并行走线用 CPWG；敏感内层时钟/中频用带状线；毫米波窄线宽时用 CPWG 改善加工鲁棒性。

### 1.5.2 微带线阻抗计算

微带线无严格闭式解，工程用近似公式（IPC-2141 系）：

```
W/H ≤ 1 时：
  Z0 = (60/√εreff) · ln( 8H/W + W/(4H) )
W/H > 1 时：
  Z0 = (120π/√εreff) / [ W/H + 1.393 + 0.667·ln(W/H + 1.444) ]

有效介电常数：
  εreff = (εr+1)/2 + (εr-1)/2 · 1/√(1+12H/W)
```

各参数的灵敏度（**做阻抗控制时脑中必须有这张表**）：

| 参数变化 | 阻抗变化方向 | 量级 |
|---|---|---|
| 线宽 W ↑ | Z0 ↓ | FR-4 上 W 从 0.3→0.4 mm（H=0.2 mm）Z0 约降 8~10 Ω |
| 介质厚 H ↑ | Z0 ↑ | H 每翻倍 Z0 升 20~25 Ω 量级 |
| 介质常数 εr ↑ | Z0 ↓ | εr 4.2→4.6，同样尺寸 Z0 降约 3% |
| 铜厚 T ↑ | Z0 ↓ | 35 μm→70 μm 约降 2~3 Ω |
| 阻焊覆盖 | Z0 ↓ | 阻焊 εr≈3.8 覆盖后约降 1~3 Ω（高频板仿真必须含阻焊） |

**算例：2.4 GHz 常见单端 50 Ω 微带尺寸**。FR-4：εr=4.3，次表层参考，介质厚 H=0.2 mm，铜厚 35 μm，无阻焊 → 解得 W ≈ 0.38 mm。加阻焊后要加宽补偿约 10~20 μm 量级，实际交给 Polar Si9000 / ADS LineCalc / 立创阻抗计算器做，板材模型必须与板厂叠层参数一致。

### 1.5.3 阻抗连续性设计

"单根线 50 Ω"只是及格线，整条链路处处连续才是目标。常见的不连续点与对策：

| 不连续点 | 寄生 | 对策 |
|---|---|---|
| 器件焊盘 | 焊盘宽 → 并联电容 → 局部阻抗下坠 | 减小焊盘、两侧掏空参考层（见第三部分第 17 讲）、用 0201 |
| 拐角 | 直角等效附加电容 | 圆弧 R≥3W / 45° 外侧切角 |
| 过孔 | 孔壁电感 + 残桩电容 | 主路径不打孔；必要换层用背钻、大孔盘下的反焊盘优化 |
| 线宽渐变处 | 台阶反射 | 线性/指数 taper 过渡（见第三部分第 19 讲） |
| 连接器/SMA 焊盘 | 焊盘往往偏宽 | 焊盘下方参考层挖空局部补偿（见第三部分第 18 讲） |
| 屏蔽罩边缘 | 罩体对线附加电容 | 罩内走线靠墙保持 ≥3W 距离 |

**每 0.1 的反射系数意味着什么**：|Γ|=0.1 → 回损 20 dB、VSWR 1.2，这通常是一个"看不见但存在"的失配；10 个 |Γ|=0.1 的不连续点相位最坏叠加时可能到 |Γ|≈0.6。所以阻抗设计要**控制不连续点数量**而不只是每段的标称值。

### 1.5.4 差分射频走线（100 Ω 差分 / 50 Ω 单端）

- 差分对内偏差：线宽线距公差导致差分阻抗 ±10% 以内；
- 耦合方式：松耦合（S≥2W）便于分别控 50 Ω、抗干扰略弱；紧耦合（S≈W）抗干扰强但单端阻抗低；
- 巴伦（Balun）到芯片段保持对称：等长、等参考层、过孔成对出现。

### 1.5.5 阻抗设计与生产

1. **阻抗不是画出来的，是板厂做出来的**：设计端给目标值 + 叠层，板厂按实测板材批号微调线宽（加减成法蚀刻补偿）；量产前必须做阻抗条（test coupon）验证。
2. **阻抗公差**：常规 ±10%，射频高要求 ±8% 或更优（影响成本与良率）。
3. **玻纤效应（Fiber Weave Effect）**：10 GHz 以上/差分长走线，玻纤束与树脂 εr 差异使线左右交替经过不同介质 → 相位抖动（差分 skew）。对策：走线与玻纤成 5°~15° 角（斜走）、选开纤布（1080、Ne-glass）、1078 混压。
4. **板材选择速查**：

| 板材 | εr | Df @10GHz | 适用 |
|---|---|---|---|
| FR-4 普通 | 4.2~4.7 | 0.02 | ≤ 3 GHz 低成本 |
| 低损耗改性 FR-4（如 IT-180A） | 4.0~4.4 | ~0.013 | ≤ 6 GHz |
| Rogers RO4350B | 3.48 | 0.0037 | ≤ 20 GHz，与 FR-4 混压工艺兼容 |
| Rogers RO3003 | 3.00 | 0.0010 | 毫米波雷达 77 GHz |
| PTFE 系（RT/duroid 5880） | 2.20 | 0.0009 | 20 GHz+、天线 |

## 1.6 史密斯圆图与匹配网络实操（RF01/RF05 延伸）

### 1.6.1 史密斯圆图的结构

史密斯圆图是把复阻抗平面经 `Γ = (Z-Z0)/(Z+Z0)` 双线性变换到 Γ 平面的工具，一图集齐阻抗、导纳、反射、驻波：

| 元素 | 位置 | 读数 |
|---|---|---|
| 圆心 | 50 Ω 纯阻（归一化 1） | 完全匹配 Γ=0 |
| 横轴 | 纯阻线 | 右端 ∞（开路），左端 0（短路） |
| 上半圆 | 感性（+jX） | 频率升高时阻抗顺时针转 |
| 下半圆 | 容性（-jX） | |
| 等 VSWR 圆 | 以圆心为心的同心圆 | 越靠边失配越重 |
| 归一化阻抗/导纳双标 | 标准圆图同时刻两组数 | 导纳图 = 阻抗图绕圆心旋转 180° |

**沿传输线移动 = 在圆图上顺时针绕等 VSWR 圆转**，每 λ/2 转一圈；**并电容 = 导纳图上加 jb 下行；串电感 = 阻抗图上加 jx 上行**。

### 1.6.2 L 形匹配网络设计流程（板级最常用）

把负载 `ZL = 25 + j15 Ω` 匹配到 50 Ω（2.4 GHz）：

1. 归一化：`zL = 0.5 + j0.3`，打点；
2. 目标：转到圆心。串 L 后加并 C（8 种 L 形拓扑之一）：
   - 先并电容：在导纳图上从 `yL = 1/(0.5+j0.3)` 加容性电纳，直到落在 g=1 圆上（得 `y = 1 + jb'`）；
   - 再串电感：串 jx 抵消剩余 -jb'；
3. 元件值：`C = b'·Y0/(2πf)`，`L = x'·Z0/(2πf)`。数值结果约 C≈1.1 pF、L≈2.2 nH 量级（具体随圆图精度）；
4. **0402 化**：1.1 pF 用 1 pF+焊盘寄生凑；2.2 nH 查厂商曲线确认 SRF > 4×工作频率。

### 1.6.3 拓扑选择八原则

| 情况 | 选拓扑 |
|---|---|
| 负载在 g=1 圆内侧（R 偏大） | 先并后串 |
| 负载 R 偏小 | 先串后并 |
| 有直流需要直通（如偏置口） | 串电容拓扑（隔直） |
| 需要给器件馈电 | 串电感做 RFC 顺路偏置 |
| 谐波抑制要求 | π/T 形（多元件，Q 可控、高频滚降好） |
| 带宽要求宽 | 多级 L 级联或渐变线 |
| 阻抗比悬殊 | T 形 + 仿真优化 |
| 频率 >3 GHz | 用短截线/渐变替代集总 |

### 1.6.4 匹配的 Q 与带宽极限

单级 L 匹配的 Q 由阻抗比锁定：`Q = √(Rbig/Rsmall - 1)`，带宽 `BW ≈ f0/Q`。R 从 5 到 50 Ω：Q=3，f0=2.4G 时带宽只有 ~800 MHz——想更宽必须多级匹配（每级分担阻抗变换），这是"宽带功放匹配难"的数学根源。**圆图上"等 Q 弧"离圆心越远损耗带宽越大**，匹配路径应尽量贴着低 Q 区走。

# 第二部分：微波收发机系统板级设计（凡亿教育，5 集）

## 2.1 详解微波收发机系统（第 1 集）

### 2.1.1 收发机在无线系统中的位置

一个完整的无线通信链路：

```
[语音/数据] → 信源编码 → 信道编码 → 调制 → 上变频 → PA → 天线 ~~空间信道~~ 天线 → LNA → 下变频 → 解调 → 信道译码 → [语音/数据]
                              └──────── 射频前端（本课程主角）────────┘
```

收发机（Transceiver）= 发射机（TX）+ 接收机（RX）+ 频率综合（PLL/本振）三大部分的合称。板级设计者的任务：把芯片厂商给出的参考电路 + 架构需求，转化成一块真实 PCB 上可量产的电路。

### 2.1.2 收发机的核心系统指标

| 指标 | 公式/定义 | 典型值（以 2.4 GHz WiFi/蓝牙为例） | 板级影响 |
|---|---|---|---|
| 灵敏度 | `Ps = -174dBm/Hz + 10·logBW + NF + SNRmin` | -90 ~ -100 dBm | 前级插损与噪声系数直接扣减灵敏度 |
| 动态范围 | 从灵敏度到 1dB 压缩点的跨度 | 60~100 dB | 决定 AGC 增益范围与级数 |
| 邻道抑制 | 干扰下保持解调的能力 | 30~60 dB | 决定滤波器止带指标与 LNA 线性度 |
| EVM | 误差矢量幅度 | -30 ~ -20 dB（256QAM 要求更高） | 本振相位噪声、IQ 失衡、PA 回退 |
| 相位噪声 | dBc/Hz @ 偏移频率 | -120 dBc/Hz @1MHz | VCO 布局、环路滤波器抗干扰 |
| 杂散辐射 | 带外辐射限制 | -30 dBm（法规） | 屏蔽、滤波、本振泄漏路径 |

**灵敏度算例**：蓝牙 BLE，BW=1 MHz，要求解调 SNR=17 dB，接收链路 NF=8 dB：

```
Ps = -174 + 10·log(10⁶) + 17 + 8 = -174 + 60 + 25 = -89 dBm
```

若天线到 LNA 之间的前端走线+双工器插损 2 dB，则整机灵敏度恶化 2 dB——**前级 1 dB 插损 = 1 dB 灵敏度损失**（NF 级联中第一级损耗直接加进去），这是射频布局"LNA 永远紧贴天线口"的定量依据。

### 2.1.3 系统指标的链路预算（Link Budget）

发射端预算：`EIRP = PPA - ILduplexer + Gant`。接收端预算：`Prx = EIRP - FSPL + Grx`，其中自由空间路径损耗：

```
FSPL(dB) = 20·log10(d) + 20·log10(f_MHz) + 32.44   (d 单位 km，f 单位 MHz)
```

**算例**：2.4 GHz、50 m：FSPL = 20·log(0.05)+20·log(2400)+32.44 = -26+67.6+32.44 ≈ **74 dB**。发射 EIRP=4 dBm（BLE），则接收口功率 = 4 - 74 = **-70 dBm**，对照灵敏度 -89 dBm，余量 19 dB（留穿透、衰落、人体遮挡）。余量 <10 dB 的产品在实测中"隔一堵墙就没信号"。

## 2.2 射频收发机架构（第 2 集）

### 2.2.1 四种主流架构对比

| 架构 | 变频方式 | 优点 | 缺点/难点 | 典型应用 |
|---|---|---|---|---|
| 超外差（Superheterodyne） | RF→IF→BB 两级或三级 | 选择性最好、增益好分配（分频段） | 镜像频率需滤除、元件多、体积大 | 雷达、对讲机、早期手机 |
| 零中频（Zero-IF / 直接变频） | RF→BB 一次到零 | 无镜像问题、滤波器可片内集成、BOM 少 | 直流偏置、1/f 闪烁噪声、本振泄漏自混频、I/Q 失衡 | 手机、WiFi、蓝牙 SoC |
| 低中频（Low-IF） | RF→几百 kHz 低 IF | 避开直流问题、镜抑靠数字 | 数字端复杂、ADC 要求高 | 蓝牙、ZigBee |
| 数字中频（采样中频） | RF→IF 后直接 ADC | 模拟链路极短、灵活 | ADC 动态范围要求极高 | 基站、软件无线电 SDR |

### 2.2.2 超外差与镜像频率

本振 `fLO` 与射频 `fRF` 混频出 `|fRF ± fLO|`，取下变频项 fIF。位于 `fimage = fRF ± 2·fIF` 的干扰同样混出 fIF，如不滤除与信号无法区分。

**算例**：fRF=2.4 GHz，fIF=140 MHz，fLO=2.26 GHz（低本振），则镜像 = 2.4 - 2×0.14 = **2.12 GHz**。镜像抑制滤波器必须放混频器之前，用双工器/带通滤波器在 2.12 GHz 处提供足够抑制（如 60 dB）。镜像抑制比 IRR（相位法，90° 移相）：

```
IRR = (1+ε)² / (1-ε)²    ε 为幅度/相位误差
```

幅度误差 0.5 dB、相位误差 5° 时 IRR ≈ 25 dB——纯靠相位法不够，还需要前端滤波器。

### 2.2.3 零中频的板级难题

| 难题 | 机理 | 板级对策 |
|---|---|---|
| 直流偏置 | 本振泄漏到混频输入自混频产生直流量，淹没基带 | 基带交流耦合/校准；PCB 上抑制 LO 到 RF 口的耦合路径（屏蔽、垂直布局） |
| 1/f 噪声 | 基带电路在 kHz~MHz 噪声大 | 大信号用零中频+直序扩频躲开直流；低速率链路改低中频 |
| 本振再辐射 | VCO 经 LNA 反向辐射出天线（本振位于带内） | VCO 与 LNA 屏蔽分腔、LO 走线远离天线馈点 |
| I/Q 失衡 | 走线/巴伦不对称、器件容差 → 边带泄漏 | 布线严格等长对称、选高平衡度巴伦 |

### 2.2.4 收发切换：TDD 与 FDD

| 双工方式 | 原理 | 板级表现 |
|---|---|---|
| TDD（时分双工） | 收发分时隙共用一个频段 | 收发开关（RF switch）或 PA/LNA 交替使能，重点在开关插损与隔离 |
| FDD（频分双工） | 收发同时用两个频段 | 双工器（duplexer，两个带通滤波器对），重点在 TX→RX 隔离度与体积 |

全双工 FDD 中双工器隔离度需大于 `PTX - LNA线性度上限` 约 90~110 dB 量级，是整链路最贵的无源器件之一；TDD 板则要小心开关的谐波与建立时间（从 TX 切 RX 的 settling 期间大信号残留会阻塞 LNA——PA 关断时序与 LNA 使能时序软件上要错开）。

### 2.2.5 架构在 PCB 上的分区映射

架构图上的每个功能块 = PCB 上的一个腔体/区：天线区 → 前端滤波区 → LNA 区 → 混频区 → IF/BB 区 → 数字区；PLL 独立区；电源独立区。第二部分 2.6 节把这条映射做成可执行的板级流程。

## 2.3 射频器件原理与设计思想（第 3 集：滤波器、放大器、混频器、PLL）

### 2.3.1 滤波器

**四类频响**：

| 类型 | 通带 | 关键参数 | 设计思想 |
|---|---|---|---|
| 巴特沃斯 | 最平坦，无纹波 | 阶数↑→滚降↑ | 对通带平坦度敏感时选 |
| 切比雪夫 | 通带等纹波，滚降更陡 | 纹波 dB + 阶数 | 对止带抑制/过渡带敏感时选，牺牲平坦度 |
| 贝塞尔 | 群时延最平坦 | 线性相位 | 对波形保真/脉冲敏感（雷达基带）时选 |
| 椭圆（Cauer） | 通带止带都等纹波，滚降最陡 | 极点零点 | 过渡带最苛刻时选，代价是止带回升 |

**频率选择性（Q 与阶数）**：过渡带带宽由阶数和纹波决定，`n ≥ log( ... )` 查切比雪夫表格求阶数；板级上集总 LC 滤波器做到 ~300 MHz~3 GHz，更高用声表（SAW，插损 1.5~3 dB）、体声波（BAW，2~6 GHz）、介质/腔体（基站级，Q 上千）。

**集总参数滤波器板级要点**：
1. LC 排布按梯形网络顺序一线排开，与"布局一字排开"原则一致；
2. 电感方向交错/垂直摆放（互感会让仿真响应变形）；
3. 节点间地过孔密集（每个电容接地点独立过孔，避免共地电感抬高通带）；
4. 屏蔽罩内 Q 值受罩壁影响，距墙 ≥5H。

### 2.3.2 放大器

| 类型 | 核心指标 | 设计思想 | 板级要点 |
|---|---|---|---|
| LNA 低噪放 | NF(0.5~2 dB)、增益(15~25 dB)、OIP3 | 最小 NF 与输入匹配的折中（噪声匹配≠功率匹配，用源简并电感等方法同时逼近） | 输入匹配网络紧贴芯片，走线 < λ/20 |
| VGA/IF 放大 | 增益可控范围 | AGC 环节 | 控制线滤波，远离射频线 |
| 驱动放大 | 线性度 | 陪 PA 末级 | 热设计 |
| PA 功率放大 | P1dB、效率（PAE）、OIP3 | 负载线匹配到 50 Ω（用 L 匹配/T 匹配多节） | 输出匹配网络承受大电流：加宽铜、多过孔、基偏置走星型 |

**P1dB 与 IP3 关系**：`OIP3 ≈ P1dB + 10 dB`（经验值）。两个 -10 dBm 干扰进 LNA，输出交调产物 = 2×Pout - OIP3；对 OIP3=+5 dBm、Pout=-10+15=+5 dBm 干扰 → 交调 = 5-5-5×2？——按定义 `IM3 = 2·Pout - OIP3` = 2×(-15+15) - 5 = -5 dBc…（用 Pout 每载波计算）。板级记住：**LNA 前的插损帮助线性度（干扰先衰减）、恶化灵敏度 1:1**，所以线性度受限的系统前级可放适度衰减的滤波器。

**稳定性 K 因子**：`K > 1 且 |Δ| < 1` 无条件稳定。板级表现：稳定性差的放大器对屏蔽罩高度、焊盘电容极敏感，量产前必须带结构仿真/实测。

### 2.3.3 混频器

原理：本振 LO 与射频 RF 在非线性器件（二极管/晶体管）相乘，产生 `fIF = |fRF - fLO|`。

| 类型 | 增益 | 线性度 | 本振功率 | 应用 |
|---|---|---|---|
| 无源二极管（环形） | -6~-7 dB | 极好 | 高（+7~+10 dBm） | 雷达、高线性 |
| 无源 FET/CMOS | -6~0 dB | 好 | 中 | 集成收发机 |
| 吉尔伯特有源 | +增益 | 中 | 低 | SoC、手机 |
| 亚采样 | 含混叠 | 中 | 脉冲 | 低功耗窄带 |

板级要点：
1. LO、RF、IF 三口互相隔离，LO 口泄漏是最大杂散源（LO 泄漏到天线辐射超标是 EMC 失败经典项）——三口走线垂直方向排布、分腔；
2. 无源混频器 LO 驱动要足：LO 功率不足 → 线性度骤降，LO 走线按 50 Ω 传功率而不是"逻辑信号"心态；
3. IF 口低通滤波器吸收镜频与和频产物。

### 2.3.4 PLL 频率综合器

```
参考晶振(如 40 MHz) → 鉴相器PFD → 电荷泵CP → 环路滤波器LPF → VCO → ÷N 反馈 → 回到PFD
输出 fout = N · fref （整数N）   或  (N + F/2^M) · fref （小数N）
```

| 组件 | 作用 | 设计要点 |
|---|---|---|
| PFD+CP | 检出相位差并泵电流 | CP 输出走线短、防漏 |
| 环路滤波器 | 把电流积分成 VCO 控制电压、稳定环路 | 无源 2 阶/3 阶 RC；元件围绕芯片紧凑摆，走线拾噪直接变相位噪声 |
| VCO | 压控振荡器产生本振 | 板级分腔屏蔽；谐振电感不受应力 |
| ÷N 分频器 | 反馈分频比 | 走线短，时钟信号包地 |

关键指标：
- **带内相位噪声** = 鉴相噪声底 + 20·logN（源于倍频），带外跟随 VCO 自身相噪；
- **锁定时间** ≈ 5/环路带宽（速度与杂散抑制的折中）；
- **参考杂散**：整数 N 会在输出出现 fref 频偏杂散，小数 N 有分数杂散（用 Σ-Δ 调制打散）。

**环路线性度/杂散的板级防串扰**：VCO 电源单独 LDO（psrr 优于共享电源 20 dB+），磁珠+电容二级去耦；分频器输出与晶振走线远离（参考时钟谐波串进 CP 就是 100 kHz 级边带杂散）。

## 2.4 板级收发机的系统设计、器件仿真、原理图和微波 PCB 设计（第 4 集）

把 2.1~2.3 的知识落到一块板上的完整流程：

```
① 系统需求 → ② 架构选型 → ③ 链路预算(增益/噪声/线性度分配到级) → ④ 器件选型+评估
→ ⑤ 仿真验证(原理图级 S 参数/谐波) → ⑥ 原理图(含匹配网络/电源/时序)
→ ⑦ 叠层设计 → ⑧ 布局(分区一字排开+屏蔽墙) → ⑨ 布线(50Ω+渐变+CPWG)
→ ⑩ 仿真(S参数、阻抗、屏蔽腔谐振) → ⑪ 打样+阻抗条 → ⑫ 调试(匹配网络微调)
```

各步要点：

1. **增益/噪声分配算例**（2.4 G 接收链）：前端滤波 IL=2 dB → LNA(G=18, NF=1.2) → 混频(IL=6) → IF 放大(G=30) 。Friis 级联：

```
F_total = F1 + (F2-1)/G1 + (F3-1)/(G1·G2) + ...
       = 1.58 + (4-1)/63 + ...  ≈ 1.63 → NF ≈ 2.1 dB
```

前 2 dB 滤波插损直接进第一项：整链 NF ≈ 2.1（含 2 dB 损耗时 LNA 的 1.2 dB 贡献几乎被淹没）→ **想省灵敏度就先砍前端插损**。

2. **器件仿真**：厂商给 S 参数（放大器）、SPICE（无源），在 ADS/GeneSYS 做原理图级链路仿真，谐波平衡看 IP3，S 参数看匹配；TX 用负载牵引数据（load-pull）设计 PA 匹配。
3. **原理图阶段就要画屏蔽框**：把每腔的边界在原理图页面上用线框注明，PCB 阶段直接照搬。
4. **叠层**：四层射频板经典叠层 `SIG / GND / PWR / SIG`，关键：射频层紧邻完整地平面（间距小 → 线细、抗干扰好）；电源层与地层之间介质薄 → 平面电容去耦。
5. **布线**：第一部分与第三部分的所有规则在此全部适用。

## 2.5 项目案例分享（第 5 集）

课程以一个 2.4 GHz 收发模块从原理图到打样的全过程复盘常见翻车点：

| 翻车点 | 现象 | 根因 |
|---|---|---|
| LNA 输入匹配离芯片 3 cm | 灵敏度比仿真低 4 dB | 匹配网络按"远端"算，走线电感没算进网络 |
| PA 输出匹配电感用 0402 | 线性度差、发热大 | 大电流下 0402 电感 Q 低、额定电流不足 |
| 屏蔽罩内一条 UART 从 LNA 腔穿到数字区 | 底噪抬升 6 dB | 腔体"公共走廊"破坏隔离 |
| 晶振放天线正下方 2 mm | 空口杂散超标 | 晶振谐波直耦天线 |
| 双排屏蔽墙过孔打了单排 | 高频隔离比实测差 15 dB | 孔距 3 mm 对 2.4G 太稀 |
| PA 供电从 LNA 供电线顺路分叉 | 发射时 LNA 增益跳变 | 共阻抗耦合 → 改星型供电解决 |
| 阻抗线穿过 0402 焊盘没有补偿 | 回损 12 dB | 焊盘电容失配 → 焊盘下参考层挖空后 20 dB |

案例总教训：**射频板的问题 80% 在布局阶段就埋下，布线和调试只能救 20%**；仿真要含"真实寄生"（走线、焊盘、过孔、罩体），不含寄生的仿真只是自我安慰。

## 2.6 板级调试与测试流程（第 4~5 集实操延伸）

### 2.6.1 收发机板调试顺序

```
① 目视/短路检查（X-Ray 查连锡、显微镜查射频焊盘）
② 电源时序与静态电流 → 每路 LDO 电压、纹波（示波器 20M 带宽限制测）
③ 时钟与数字接口 → 晶振起振、SPI 读写、PLL 锁定指示
④ 射频小信号指标（VNA）→ 回损/插损/增益/匹配
⑤ 频谱类（频谱仪/信号分析仪）→ 杂散、本振泄漏、谐波
⑥ 线性度（信号源+频谱仪）→ P1dB、IP3
⑦ 整机联调（误码率/EVM/灵敏度）→ 无线吞吐或 BER 仪
```

**为什么按这个顺序**：前一步的通过是后一步读数可信的前提。常见错误是板子供电都没量就上 VNA 测匹配，测到的是"未上电芯片的接口阻抗"，白忙一场——**芯片 RF 口在上下电时阻抗不同，测匹配必须带电或明确标注测试状态**。

### 2.6.2 增益分配与 AGC 的板级考虑

系统动态范围靠 AGC 压缩。板级设计要给 AGC 留控制带宽和布局位置：
1. AGC 检波点（耦合器/检波器）在主链路旁支，耦合度按检测动态范围选（-20 dB 常用）；
2. 控制电压线是"低速模拟"：RC 滤波 + 包地，从检波到 VGA 布线独立走，禁止与大信号 PA 输出平行走线（控制线拾取 PA 泄漏会形成二次反馈环）；
3. 级联增益平坦度：单级增益 ±1 dB，三级级联最坏 ±3 dB，预算表里要按最坏情况分配。

### 2.6.3 双工器/开关的隔离度预算算例（FDD 系统必算）

发射 +30 dBm 同时接收灵敏度 -100 dBm 量级系统：TX 到 RX 泄漏必须 < LNA 输入的阻塞电平。双工器 TX-RX 隔离 55 dB 时，泄漏进 RX 口的功率 = 30-55 = -25 dBm——LNA 需在 -25 dBm 阻塞下保持线性（其 IIP3 要 ≥ 阻塞+交调余量，约 -15 dBm 以上）。若双工器隔离只有 45 dB，泄漏 -15 dBm 直接把 LNA 推进压缩区——**双工器每差 10 dB 隔离，对 LNA 线性度要求就抬 10 dB**。这是射频前端"BOM 上最贵器件值这个钱"的定量解释。

### 2.6.4 常见调试现象速查表

| 现象 | 优先怀疑 |
|---|---|
| 增益低 3~6 dB | 匹配网络没调好/寄生低估；焊盘补偿未做 |
| 频谱有 fref 整数倍边带 | PLL 参考串扰：晶振走线与 CP 线耦合 |
| 底噪比仿真高 5 dB+ | 数字噪声进射频地/电源；屏蔽罩未盖或墙孔稀 |
| 输出杂散随触摸变化 | 屏蔽腔谐振/盖未盖好；腔体尺寸接近 λ/2 |
| 大功率时频率跳变 | PA 拉偏 VCO（注入牵引）：VCO 与 PA 屏蔽分腔不够 |
| EVM 差但 BER 正常 | 相位噪声临界：查 VCO 电源纹波、环路带宽设置 |
| 温度高后频偏 | 晶振温度曲线 vs VCO 温补数据表不匹配 |

# 第三部分：射频设计核心技术与实操（Altium Academy，27 讲）

## 3.1 第 1 讲：射频与微波印制电路板设计总览

本讲建立整个系列的框架：射频 PCB 上，**每一段走线、每一个焊盘、每一个过孔都是电路元件**。频率越高，"几何=电路"越成立。

| 概念 | 数字板思维 | 射频板思维 |
|---|---|---|
| 30 mm 走线 | 一根导线 | 2.4 GHz 下半个波长——相位变换器、辐射器 |
| 焊盘 | 机械接口 | 0.1~0.3 pF 电容 |
| 过孔 | 层间通道 | 0.3~1 nH 电感 + 残桩谐振 |
| 铜平面 | 等势体 | 有电流分布、有谐振模式的导体 |

射频设计的三个层次：
1. **拓扑层**：匹配网络、功分器、滤波器怎么联（电路理论）；
2. **物理层**：传输线结构、尺寸、叠层（场理论近似）；
3. **工艺层**：蚀刻公差、铜厚、阻焊、表面处理（决定量产一致性）。

## 3.2 第 2 讲：传输线与阻抗（系列核心）

### 3.2.1 从 LC 链理解特性阻抗

把传输线切成无穷小段，每段有串联电感 L'（H/m）与并联电容 C'（F/m）：

```
Z0 = √(L'/C')        v = 1/√(L'C') = c/√εreff
```

直觉：线宽加大 → 单位长度电容 C' 变大（与地更近"面积"更大）→ Z0 下降；介质变厚 → C' 变小 → Z0 上升。**所有阻抗公式都是这个直觉的定量版**。

### 3.2.2 三种结构与阻抗公式

**微带线**（第一部分 1.5.2 已给公式），有效介电常数的物理含义：场一半在空气一半在介质，等效介于 1 与 εr 之间。

**带状线**（对称）：

```
Z0 = 60/√εr · ln( 4·b / (0.67π·(0.8W + T)) )    （W/b < 0.35 近似）
```

带状线全场在介质内，εreff = εr，色散比微带小。

**接地共面波导 GCPW**：中心导体 + 两侧地 + 下地。三重阻抗控制自由度（W、缝隙 G、介质 H），当缝隙 G < H 时场集中在缝隙，对下层地不敏感 → **低介电常数薄板/两层板做射频的关键结构**（第 20 讲 nRF52 详述）。

### 3.2.3 色散与损耗

| 损耗机制 | 表达 | 对策 |
|---|---|---|
| 导体损耗 | αc ∝ √f / W · Z0 相关 | 加宽线、厚铜、低粗糙度铜箔 |
| 介质损耗 | `αd = 27.3·(εr/εreff)·f·tanδ / (λg·2)` ≈ 每 λg 长度 27.3·tanδ dB | 选低 Df（tanδ）板材，毫米波唯一有效手段 |
| 辐射损耗 | 弯角、不连续处 | 圆弧、渐变 |
| 泄漏/模式转换 | 平行板模式 | 缝隙地孔密集缝合 |

**算例**：FR-4（tanδ≈0.02）@5.8 GHz 的微带线单位插损约 0.15~0.25 dB/cm；Rogers 4350B（tanδ=0.0037）约 0.03~0.05 dB/cm——**同一段 5 cm 走线，FR-4 损 1 dB，Rogers 损 0.2 dB**。2.4 GHz 以下 FR-4 尚可，5 GHz 以上必须认真评估板材。

## 3.3 第 3 讲：短截线（Stub）

### 3.3.1 短截线的阻抗变换本质

一段终端开路或短路的传输线，从输入端看进去呈现纯电抗：

```
开路短截线：Zin = -j·Z0·cot(βl)     输入导纳 Yin = j·Y0·tan(βl)
短路短截线：Zin =  j·Z0·tan(βl)
```

| 电长度 l | 开路线等效 | 短路线等效 |
|---|---|---|
| < λ/8 | 电容 | 电感 |
| λ/8 | 纯容性导纳 Y0 | 纯感性阻抗 Z0 |
| λ/4 | 短路（串联谐振） | 开路（并联谐振） |
| λ/2 | 回到开路 | 回到短路 |

**结论**：λ/4 变换 + 周期性，是射频"分布式元件"的全部基础——电感、电容、谐振器、滤波器、偏置三通都由这两行公式推演出来。

### 3.3.2 短截线的三大用途

1. **匹配网络元件**：单短截线/双短截线匹配，用短截线代替集总 LC（频率高、Q 要求高时）；
2. **偏置馈电（RFC）**：λ/4 高阻短截线对主路呈开路，直流从根部注入不干扰射频（第 15 讲 bias tee 详解）；
3. **陷波/抑制**：λ/4 开路短截线在中心频率把该频率短路到地，做成带阻（如 5.8 GHz 板上用 λ/4@5.8G 开路 stub 抑制 5.8G 泄漏）。

**工程警钟：stub 一定是故意的**。射频线上任何"多余的小段"（测试点引出的 stub、走线末端多余一小节、过孔残桩）都是一个谐振器/滤波器——**在 2~10 GHz 频段，2 mm 的残桩就能造成 >1 dB 的插损凹陷**。这就是射频布线"消灭一切无意 stub"的原因；过孔残桩用背钻消除。

## 3.4 第 4 讲：功分器

### 3.4.1 T 型结功分器（最简单）

三端口网络固有无耗不可逆（无法三口全匹配且无耗）：

- 简单 T 结：无耗、不隔离，输出反射会互相串扰；
- 电阻式功分器：两输出各串半波电阻 R/2（如 50/50 系统用两个 50 Ω/2=25 Ω 或 16.67Ω 三角形），有 3 dB（ Wilkinson 无耗时）以上损耗但有隔离、超宽带——用在测试馈电、时钟分配。

### 3.4.2 Wilkinson 功分器（工程标配）

结构：输入 50 Ω 分成两支各 70.7 Ω（=50·√2）的 λ/4 支线，输出端之间跨接 100 Ω 隔离电阻。

| 特性 | 数值/说明 |
|---|---|
| 单路理论损耗 | 3 dB（功率守恒对半分） |
| 隔离度 | >20 dB（取决于结构精度） |
| 带宽 | 一节约 20%~30%，多节扩展 |
| 三口 | 全部匹配到 50 Ω |

**为什么是 70.7 与 100**：λ/4 变换器把两路 50 Ω 并联的 25 Ω 变到 50 Ω 需要 `Z = √(25×50) = 35.4`？——注意 Wilkinson 分析：从输入看两支 70.7 Ω λ/4 线并联，等效 `Zin = (70.7²/50)/2 = 50 Ω` ✓；隔离电阻在奇模等效电路中两个 25 Ω 串联 = 50 Ω 匹配 ✓。

**板级设计步骤**（2.4 GHz 一分二实例）：
1. λ/4 @2.4 GHz 板上（εreff≈3.3 用 Rogers）: `λg/4 = 30/(2.4·√3.3)/4 mm ≈ 17.3 mm`；
2. 画 70.7 Ω 支线宽（查表/仿真，典型比 50 Ω 窄 ~30%）；
3. 输入输出 50 Ω 微带；
4. 两支线间跨 100 Ω 片式电阻（0402），电阻两焊盘直接跨在支线末端，焊盘下参考层挖空减容；
5. 圆弧转弯、分支点用渐变。

## 3.5 第 5 讲：耦合器

### 3.5.1 定向耦合器原理

四端口器件：输入 P1、直通 P2、耦合 P3、隔离 P4。耦合度、方向性：

```
耦合度 C(dB) = 10·log(P1/P3)        常用 10/20/30 dB
方向性 D(dB) = 10·log(P3/P4)        越大越好
隔离度 = C + D
```

用途：功率检波（发射功率监测）、反射测量（驻波监测）、取样、合成。

### 3.5.2 板上实现结构

| 结构 | 耦合方式 | 特点 |
|---|---|---|
| 边缘耦合线（微带平行耦合） | 两条平行微带线耦合 λ/4 | 弱耦合（>10 dB）易做，强耦合（3 dB）需要极窄缝、难加工 |
| 分支线耦合器（branch-line） | λ/4 分支 35.3/50 Ω | 90° 移相输出，做成正交混合结，面积大 |
| Lange 耦合器 | 交指多指耦合 | 3 dB 强耦合可做、带宽宽，指宽缝细、加工精度要求高 |
| 环形耦合器（rat-race） | 1.5λ 环 | 和/差口，0°/180° 输出 |

**90° 混合结的两大应用**：镜像抑制混频器（与移相器组合成 Hartley 结构）、平衡放大器（反射被耦合器吸收——改善匹配与稳定）。

**耦合度与缝宽的经验量级**（微带边缘耦合，1.6 mm Rogers 4350）：20 dB 耦合缝约 0.8~1.2 mm；10 dB 约 0.2~0.3 mm；3 dB 缝 <0.1 mm 且必须交指化。**强耦合优先选多层（宽边耦合，用相邻层叠在一起）或 Lange**。

## 3.6 第 6 讲：滤波器（白板射频）

### 3.6.1 从传输线看滤波器

阶梯阻抗低通（高低阻抗线交替）→ 开路短截线低通 → 边缘耦合带通 → 交指/梳状线带通 → 发夹（hairpin，耦合线折成 U 形省面积）。

| 板上结构 | 等效 | 适用 |
|---|---|---|
| 高低阻抗阶梯 | 串联电感 + 并联电容 | 低通、LPF 3 GHz 以下 |
| 开路 stub 阵列 | 并联电容 | 带阻/低通 |
| 边缘耦合线（λ/4 对） | 谐振腔耦合 | 带通，2~10 GHz |
| 发夹滤波器 | 耦合线折叠 | 带通，面积敏感 |
| 交指/梳状线 | λ/4 谐振器并排 | 窄带带通、体积紧 |
| SIW（基片集成波导） | 金属波导 | 10 GHz+ 高 Q 带通 |

### 3.6.2 发夹滤波器设计流程（板级实操）

1. 确定指标：中心 f0、带宽 BW、纹波、止带；
2. 查切比雪夫表格得原型 g 值（阶数 n）；
3. 换算耦合系数 `M(i,i+1) = BW/(f0·√(g_i·g_i+1))` 与输入输出 Q；
4. 初值仿真（ADS/HFSS/开源 Qucs）：线宽 = 50 Ω 宽度起步，缝隙由耦合系数扫描定；
5. 版图 EM 仿真微调（缝隙 ±0.05 mm 量级敏感）；
6. 留出后调余量：首版在末端加一小段可切 stub 或可贴补电容的焊盘。

**板级要点**：耦合缝隙内禁止阻焊堆积不均；谐振器周围地孔带围一圈防泄漏；输入输出抽头位置决定外 Q。

## 3.7 第 7 讲：射频 PCB 设计入门要点串讲

入门者最容易忽略的五件事：
1. **参考平面是电路**，不是"铺铜装饰"——射频电流真实地在其表面流动；
2. **50 Ω 不是一个数，是一个工艺区间**——设计要给蚀刻公差（±15% 线宽）留裕量；
3. **焊盘比走线宽**——电容效应，每个焊盘是小的阻抗台阶；
4. **过孔=电感**——高频接地孔并联使用；
5. **屏蔽罩不是可选项**——>1 GHz 高增益链路默认必加。

## 3.8 第 8 讲：1 波长（半波长）阻抗匹配

半波长传输线的阻抗重复性：`Zin = ZL`（βl = π 时 tan 为 0）。应用：
1. **重复器**：λ/2 线把负载阻抗原样搬运——相位需要 180° 而不变换阻抗时使用（如阵列天线馈电相位差 180° 分支）；
2. **半波长振子/缝隙**：天线结构中的半波长谐振器；
3. **检波/频率测量**：半波长延迟线做鉴频鉴相。

工程要点：色散使"电气半波长"随频率偏移，宽带应用要用多节渐变代替单节 λ/2。

## 3.9 第 9 讲：四分之一波长阻抗匹配（补充）

### 3.9.1 λ/4 阻抗变换器

```
Zin = Z0² / ZL        （Z0 为 λ/4 线的特性阻抗）
要 Zin = Zs：  Z0 = √(Zs·ZL)
```

**算例**：把 35 Ω 天线匹配到 50 Ω：Z0=√(50×35)=41.8 Ω，长度 λ/4@工作频率。

局限：窄带（相对带宽 10~20% 内回损 >15 dB），且**只能匹配纯阻负载**——复数负载需先移除电抗（串联 λ/4 或短截线调谐）再变换。

### 3.9.2 单短截线匹配（解析流程，板级最常用）

负载 `ZL = R + jX` 匹配到 50 Ω：
1. 归一化 zL，在史密斯圆图上找 `g = 1` 圆的交点（移动距离 d）；
2. 在该点加开路短截线，长度 l 使其电纳抵消剩余电纳；
3. 公式版：设主线上距负载 d 处输入导纳 `Y = Y0 + jB`（选 B 为负的解），短截线提供 `-jB`。

**板级实现**：调试点用"可裁剪 stub"（初始留长，调试剪短）或并排贴电容焊盘，避免一版失败全重投。

## 3.10 第 10 讲：在 Altium Designer 中实现任意角度与弧形布线

AD 的射频布线操作要点：
1. **弧形走线**：交互式布线中按 Shift+空格 切换走线模式（直线→45°→圆弧），或用"Arc"命令画独立圆弧段（圆心半径可输入精确值）；
2. **任意角度**：设置中打开"任意角度"走线模式，配合"prefer arc"；
3. **参数化**：圆弧半径建议 ≥3W 且能整板复用统一半径（美观+参数一致便于仿真抽取）；
4. **弧形的主要场景**：直角/45° 拐点在 >10 GHz 成为明显反射源，毫米波板全部圆弧化；耦合器圆环（rat-race）、贴片天线圆角、威尔金森圆弧分支；
5. 注意 AD 的"填充区/敷铜圆弧化"（solid region 支持圆弧边界），屏蔽腔圆角用敷铜画。

## 3.11 第 11 讲：贴片天线设计

矩形贴片（microstrip patch）——最常用的低成本板载天线：

```
宽度（辐射边）：W = c/(2f) · √( 2/(εr+1) )
有效长度：Leff = c/(2f·√εreff)
等效延长 ΔL = 0.412·H·(εreff+0.3)(W/H+0.264) / [(εreff-0.258)(W/H+0.8)]
物理长 L = Leff - 2ΔL
```

**算例**（2.4 GHz，FR-4 εr=4.3，H=1.6 mm）：
- W = 122/2/√(2/5.3) ≈ 96/1.31？——分步算：c/(2f)=62.5 mm，√(2/5.3)=0.614 → **W ≈ 38.4 mm**；
- εreff（W/H≈24）≈ 4.08 → Leff = 62.5/2.02 ≈ **30.9 mm**；
- ΔL ≈ 0.42 mm → **L ≈ 30 mm**。

馈电方式对比：

| 馈电 | 带宽 | 实现 | 备注 |
|---|---|---|---|
| 微带边馈 | 窄（1~2%） | 一条 50 Ω 线直接接贴片边 | 最简单，阻抗由插入深度调 |
| 微带侧馈+λ/4 匹配 | 窄 | 四分之一波长变换 | 边馈的正规化 |
| 探针/过孔背馈 | 2~5% | 过孔从背面馈 | 地完整，常见于模块 |
| 缝隙耦合馈 | 5~10% | 地层开缝、馈线在另一层 | 层间隔离好 |

板级要点：贴片下方与周围 1/4 波长内地完整；同层大面铺铜离贴片 ≥3H（别用包地思想贴太近——地太近会吸收场，增益下降）；FR-4 贴片因 εr 公差与温度漂移谐振频率可漂 ±2%，2.4G ISM 全带宽宽容设计；净空区内电池/排线是失谐源。

## 3.12 第 12 讲：敷铜连接——直接式

射频器件接地焊盘与敷铜的连接方式：

| 方式 | 做法 | 电感 | 适用 |
|---|---|---|---|
| 直接式（full connect） | 焊盘四边全连铜皮 | 最低 | 射频接地端**默认全连接** |
| 热焊盘（thermal relief） | 十字缩窄连接 | 高 2~5 倍 | 大铜皮上的**普通直流/低频焊盘**（可焊性） |

**规则**：射频接地焊盘、屏蔽墙焊盘、去耦电容接地端一律直接式 + 就近地过孔；只有"大铜面上低频器件"为可焊性用热焊盘。回流焊散热过快导致冷焊，是直接式的工艺代价，用回流曲线补偿。

## 3.13 第 13 讲：分布参数电路

把"分布式元件 vs 集总元件"再深化：**频率高了，连一个 0402 电容本身也是一段传输线**。

- 集总 L 的自谐振（SRF）：`fSRF = 1/(2π√(LC_parasitic))`，0402 10 nH 电感 SRF 约 1~2 GHz——超过 SRF 它是电容不是电感！
- 0402 100 pF 电容 SRF 约 1.5 GHz；1 pF 可用到 10 GHz+（封装越小寄生越小：0201 > 0402 > 0603）；
- **用传输线段替代集总元件的临界**：λ/10 以上用分布；f < 1 GHz 且经验不足时集总+小封装更省心。

选型速查（Murata/村田等厂商 S 参数曲线是唯一可信来源，数据手册的 L/C 名义值在 GHz 不可直接用）。

## 3.14 第 14 讲 & 第 16 讲：板边镀铜（Edge Plating）

**是什么**：PCB 板边缘（侧面）金属化镀铜，通常与各层地连通。

**作用**：
1. **EMI 屏蔽**：整板"铜笼"的一部分（配合屏蔽罩形成法拉第笼），把内层地平面在板边用铜墙连通，防止内层信号从板侧泄漏；
2. **改善地平面回流路径**：多层板各层地在板边低感连通，降低层间地阻抗；
3. **边缘辐射抑制**：开槽/板边泄漏的辐射源被导体壁衰减；
4. **结构/工艺**：边缘导电接触、防潮（部分场景）。

**设计规范（第 16 讲量化）**：
1. 板边镀铜需在板边预留 ≥0.5~1.0 mm 无铜区后设置"castellations/edge plating"工艺层，Altium 中用 board outline 内偏移的机械层或"Edge Connector"焊盘指定；
2. 板边镀铜与内层地必须用过孔缝合：孔距 ≤2 mm 沿边一排，否则板边铜墙是"浮墙"高频无效；
3. 拼板工艺注意 V-cut 与板边镀铜冲突（V-cut 不能切穿镀铜边），铣边 + 破孔（mouse bite）替代；
4. 至少三处与主地平面的连接桥，防止孤立导体（工艺上"孤铜"会被去除）；
5. 板边镀铜区域禁布件、禁走线，间距 ≥0.3 mm。

## 3.15 第 15 讲：偏置三通（Bias Tee）的设计与仿真

### 3.15.1 作用与结构

给放大器/有源器件经同一根 50 Ω 射频主线"顺路"注入直流偏置，同时直流与射频互不干扰：

```
        RF-in ────┬──────── RF-out
                  │（隔直电容 C，主路直通）
                  ├── λ/4 高阻线（或电感 L）── Vdc 偏置口
                  └──（根部旁路电容）
```

| 元件 | 取值 | 作用 |
|---|---|---|
| 主路隔直电容 C | 容抗在工作频率 <<50 Ω，如 2.4G 用 10~100 pF | 阻直流、通射频，把偏置支路的直流挡在主路 |
| λ/4 高阻线 | 特性阻抗 80~100 Ω、长 λ/4，终端接旁路电容（等效短路）→ 输入端呈开路 | 射频"看不见"偏置支路 |
| 替代方案集总电感 | `XL >> 50 Ω`（如 10·Z0），S 要低于自谐振 | λ/4 太长（低频板放不下）时用 |
| 偏置口旁路电容 | 100 pF + 10 nF 组合 | 给高阻线终端提供射频短路 + 电源去耦 |

### 3.15.2 设计算例（2.4 GHz，FR-4）

λ/4 线长 ≈ 17~18 mm（εreff≈3.0 时），特性阻抗取 90 Ω → 线宽约 0.15 mm。末端接 100 pF（在 2.4 G 阻抗 ~0.7 Ω，良好短路）→ 从主路看支路在 2.4 GHz 呈开路，插入损耗仿真 <0.1 dB。带宽：单节 λ/4 偏置三通带宽约 ±15%~20%；宽带（倍频程以上）用两节阻抗阶梯（90 Ω → 45 Ω λ/4 两段）或直接宽带铁氧体/锥形电感。

### 3.15.3 板级要点

1. 高阻线在偏置口附近弯折时保持 ≥3W 转弯半径，末端电容接地过孔密集；
2. 偏置电压走线（低频）穿屏蔽墙时加馈通电容或磁珠+电容 π 滤波，防电源噪声沿偏置线进射频；
3. PA 偏置三通电流大：λ/4 线宽 <25 μm 会烧——大电流场景用高 Q 绕线电感或加宽的 λ/4 线（折中阻抗）；
4. 仿真验证三件事：主路 S21（通带插损）、偏置口到主路隔离、主路到偏置口隔离（射频泄漏进电源）。

## 3.16 第 17 讲：是否移除阻抗匹配网络下方的接地层？

**问题**：0402 匹配元件焊盘宽于 50 Ω 线宽，焊盘下方参考层的耦合电容使局部阻抗跌到 40 Ω 量级，回损恶化。**做法**：在匹配元件焊盘正下方的参考层挖空（cutout）一块铜，恢复阻抗。

| 方案 | 效果 | 风险 |
|---|---|---|
| 不处理 | 焊盘处 Z≈40 Ω，回损 ~12 dB | 无 |
| 焊盘下参考层挖空（纵向挖长 ≈焊盘长，横向≈焊盘宽±50%） | 局部回升到 ~48-52 Ω | 挖太多 → 阻抗过冲 + 返回电流绕行 → 感性 |
| 焊盘下第二层地补一块 | 控制耦合 | 加工公差敏感，需仿真 |

**原则**：挖空尺寸由 EM 仿真（HFSS/CST 或 ADS Momentum）确定，不是拍脑袋；挖空区下面如果有第二层地，参考层切换路径上的返回电流要给过孔桥；**答案是"通常要挖，但按仿真挖"**。同理适用于任何宽焊盘（滤波器焊盘、连接器中心脚）。

## 3.17 第 18 讲：是否应移除 SMA 连接器下方的接地层？

SMA 中心针焊盘直径约 1.5~2 mm，远宽于 50 Ω 线（0.4 mm 量级），且 SMA 过孔壁与地层耦合强烈。

标准做法（四步）：
1. 中心针过孔的**反焊盘（anti-pad）加大**：把过孔周围地层开窗半径从默认 0.3 mm 加到 0.5~0.7 mm，降低并联电容；
2. 过孔残桩：SMA 在表层时过孔穿透整个板厚形成残桩 → **背钻**或用表贴 SMA；
3. 焊盘下参考层适度挖空（同第 17 讲逻辑）；
4. SMA 外壳接地脚与地层之间密过孔（外壳是共面地延续），外壳脚焊盘直接连地铜。

**结论**：不是"移除接地层"，而是**优化反焊盘 + 消除残桩**。1.5~3 GHz 影响尚可容忍（回损 15 dB），6 GHz 以上不做优化时 SMA 处回损可劣于 10 dB。

## 3.18 第 19 讲：射频走线渐变段（Taper）设计

阻抗不同的两段线之间（如 50 Ω 主线 → 大焊盘 → 芯片引脚，或 50 Ω → 90 Ω 偏置支路）直接拼接会产生反射，渐变段让阻抗平滑过渡：

| 渐变类型 | 公式/特点 | 长度与带宽 |
|---|---|---|
| 线性 taper | 宽度线性变化 | 最短，带宽中 |
| 指数 taper | W(z)=W1·(W2/W1)^(z/L) | 平滑，常用 |
| Klopfenstein | 等波纹最优 | **给定回损下最短**——工程首选 |
| 阶梯多节（λ/4 二项式/切比雪夫多节） | 离散多节 | 加工简单，宽带经典 |

**回损预算式**：渐变段等效"分布式小反射"，总反射近似为渐变两端阻抗跳变 `Γ = (Z2-Z1)/(Z2+Z1)` 的函数，长度超过 λ/4 后反射随长度迅速下降（多次反射互相抵消）。设计准则：**taper 长度 ≥ λ/4（最低工作频率处），反射可压到 -30 dB 以下**。

实操：免费计算器（如 EEWeb/Altium 课堂提供的阻抗渐变计算器）输入两端阻抗 + 目标回损 → 得出长度与轮廓；AD 中用"自定义焊盘/region"或逐段线宽实现。常见应用：SMA 焊盘进出、功放 die 到 50 Ω、巴伦差分端。

## 3.19 第 20 讲：nRF52 模块的 PCB 层数精简（两层板做 2.4 GHz）

北欧 nRF52 系列参考设计可做四层，也可两层板落地（成本敏感产品）。两层板做射频的关键技巧：

1. **顶层射频 + 底层完整地**：顶层走 50 Ω 微带，底层整版 GND，禁止底层走任何非射频回流路径；
2. **匹配网络用 0402→0201**：两层板介质 1.6 mm 太厚导致 50 Ω 线宽 ~3 mm——不可行！改用 **CPWG（共面波导）**：线宽 0.4 mm + 两侧缝隙 0.2 mm 的共面结构在 1.6 mm 板上也能做到 50 Ω（靠两侧地"拉低"阻抗），这是薄板线宽难题的解法（与第 26 讲呼应）；
3. **净空**：nRF52 芯片下方（直流/数字）与天线区严格净空；
4. **去耦电容**：芯片 VDD 引脚每脚一个 100 nF，且过孔就近到底层地；
5. **晶振**：XTAL 引脚走线 <2 mm，负载电容地过孔独立；
6. 层数取舍总结：

| 对比项 | 4 层板 | 2 层板 |
|---|---|---|
| 阻抗控制 | 容易（薄介质） | 必须 CPWG |
| 地完整性 | 内层地纯净 | 底层地被数字回流污染 → 割补丁布线纪律 |
| EMI | 好 | 靠器件与净空弥补 |
| 成本 | 高 | 低（量产价差可达 30%+） |

结论：**两层板可行但纪律更严**——射频区下方底层 100% 净地，数字区放远，共面地孔密。

## 3.20 第 21 讲：阻焊层（Solder Mask）是否产生显著的信号损耗？

阻焊是 εr≈3.3~4.0、Df≈0.02~0.03 的介质覆盖层，微带线上方覆盖阻焊后：

| 影响 | 量级 |
|---|---|
| 特性阻抗 | 下降 1~3 Ω（部分场从空气 εr=1 变为阻焊 εr≈3.8） |
| 有效介电常数 | 上升 → λg 缩短 |
| 损耗 | Df 高的阻焊带来附加介质损耗：2.4 GHz 约可忽略；**10 GHz 以上 0.05~0.1 dB/cm 量级，开始显著**；24/77 GHz 必须把阻焊从射频走线上开窗（Solder Mask Opening） |
| 一致性 | 阻焊厚度公差 ±10 μm → 高频阻抗漂移 |

**规则**：
- ≤6 GHz：覆盖阻焊没关系，但仿真与阻抗计算要含阻焊；
- 6~15 GHz：射频线阻焊开窗（开窗比线宽每边大 50~100 μm），避免助焊剂残留影响；
- >15 GHz：开窗 + 评估阻焊对邻近耦合结构（耦合器缝隙）的影响，缝隙内阻焊流动不均对耦合度扰动明显。

## 3.21 第 22 讲：5~6 GHz 雷达设计中的 PCB 难点

以 5.8 GHz（多普勒/生物雷达）与向 77 GHz 过渡的雷达板为例，难点清单：

| 难点 | 机理 | 对策 |
|---|---|---|
| 走线损耗陡增 | 介质损耗 ∝ f·tanδ，粗糙度损耗 ∝ √f | 低 Df 板材（Rogers 3003/4350B）+ RTF/HVLP 铜箔 |
| 阻抗公差收窄 | 线宽公差相对影响变大 | 阻抗条全检、CPWG 减小对蚀刻敏感度 |
| 过孔残桩谐振 | 2 mm 残桩在 ~10 GHz 发生谐振，5~6 GHz 段附近已有容性失配 | 背钻、HDI 盲孔、避免换层 |
| 屏蔽腔谐振密集 | 腔体尺寸缩小到 λ/2 量级 | 更小的腔、吸收材料、每腔一级 |
| 高速串行走线（DDR/chip 链路）与射频共存 | 串扰与谐波 | 分区 + 屏蔽墙 + 串扰包地 |
| 发射-接收隔离 | 连续波雷达 TX 耦合进 RX 造成直漏 | 板上隔离 > 系统需求（屏蔽墙十字结构、TX/RX 走线对角布置） |
| 天线阵列一致性 | 馈电网络公差 → 波束指向偏 | 等长馈电、对称 Wilkinson 树 |

## 3.22 第 23 讲：射频走线上的瞬态抑制二极管（TVS）要点

ESD/浪涌防护二极管是射频口的"安全气囊"，但它是寄生电容大户：

| 参数 | 影响 |
|---|---|
| 结电容 CT | 0.2~3 pF。1 pF 在 2.4 GHz 容抗 ≈ 66 Ω——直接并联在 50 Ω 线上=严重失配 |
| 动态电阻 RD | 钳位能力 |
| 寄生电感 | 封装/走线电感使高频保护失效 |

**选型与布局规则**：
1. **必须选低电容射频专用 TVS**（如 CT≤0.3 pF 的 ESD 阵列，厂商标 "low capacitance for RF"）；
2. **放在匹配网络之后、靠近连接器**：让匹配网络"吸收"TVS 电容的影响一起设计，仿真时把 TVS 的 S 参数（厂商提供）串进链路模型；
3. 布局顺序：连接器 → TVS（最短路径、外壳地就近泄放）→ 匹配/滤波 → 芯片；
4. TVS 接地过孔：至少 4 个并联过孔（泄放电流 + 降低电感）；
5. **永远不要把通用大电容 TVS（CT>3 pF）放在 >900 MHz 射频口上**——灵敏度、插损、驻波全毁；
6. 用仿真确认：含 TVS 后回损 >15 dB、插损增量 <0.3 dB。

## 3.23 第 24 讲：标准叠层设计 + 受控阻抗深度解析

### 3.23.1 四种经典射频叠层

| 层数 | 叠层（自上而下） | 说明 |
|---|---|---|
| 2 层 | SIG+GND | CPWG 做 50 Ω；低成本低速产品 |
| 4 层 | SIG / GND / PWR / SIG | 射频标配：L1 射频微带紧贴 L2 完整地；L4 数字低速 |
| 4 层 | SIG / GND / GND / SIG | 双地叠层：EMI 最好，电源走线化 |
| 6 层 | SIG / GND / SIG / SIG / GND / SIG 或带内嵌带状线 | 高密度射频+高速数字混合 |

**核心原则**：
1. 每个信号层紧邻完整参考层；
2. 射频层与参考层介质**薄**（0.1~0.25 mm）：线细、抗干扰、过孔短；
3. 电源与地平面相邻且介质薄 → 平面电容 + 去耦；
4. 对称叠层防翘曲（胀缩系数平衡）。

### 3.23.2 受控阻抗（Controlled Impedance）生产链

设计 → 板厂按板材实测 εr 与蚀刻补偿调线宽 → 附阻抗测试条（coupon）→ 时域反射 TDR/分段谐振法测试 → 报告。工程师要给板厂的完整信息：每层阻抗目标值、参考层、介质厚度、板材牌号、铜厚、阻焊开窗区域。**"阻抗板"要在制版说明中显式声明，否则默认普通工艺不控公差**。

### 3.23.3 层间介质厚度与线宽的算例

| 介质厚 H | FR-4 50Ω 微带线宽（T=35μm） | 评价 |
|---|---|---|
| 0.1 mm | ≈0.18 mm | 线细抗干扰强，蚀刻公差影响小（相对），高频优选 |
| 0.2 mm | ≈0.38 mm | 常规 |
| 0.5 mm | ≈0.95 mm | 线太宽，占空间且拐角寄生大 |
| 1.6 mm | ≈3 mm | 不可用 → 必须 CPWG |

## 3.24 第 25 讲：PCB 叠层设计逆向思路

"逆向"= 从约束反推叠层：
1. 列出全部约束：阻抗种类（50/90/100Ω差分）、最高频率、层数成本上限、屏蔽/EMC 等级、过孔类型（通孔/盲埋/背钻）、板厚、散热；
2. 先定**射频层与参考层的介质厚度**（由目标线宽反推：要 0.3 mm 线宽 → 查表得 H≈0.15 mm）；
3. 再分配其余层间距（电源-地近、数字参考近）；
4. 校核总厚与对称性；
5. 输出叠层表（层名、材料、厚度、铜厚）给板厂确认 εr 公差与残铜率。

与正向（先定叠层再算线宽）相比，逆向在**空间紧张的高密度板**上先满足"物理可布性"，再满足电气。

## 3.25 第 26 讲：共面接地敷铜技术减小传输线线宽

（与 3.19 第 20 讲同一原理的正向专题）微带线在厚介质上 50 Ω 线太宽时，**在走线两侧加共面地（间隙 G）**，部分电力线端接在侧壁，等效电容上升 → 同样介质下线宽大幅变窄。

| 结构 | 1.6 mm FR-4 上的 50 Ω 尺寸 |
|---|---|
| 微带（只有下层地） | W≈3.0 mm |
| GCPW，G=0.2 mm | W≈0.4 mm + 两侧 0.2 mm 缝 |

配套规则：
1. 两侧共面地必须用**地过孔缝合到下层地**（孔距 <λ/20，且 ≤2~3 mm），否则共面地"悬浮"失谐；
2. 共面地铜皮宽度 ≥3~5 倍缝宽即可，过宽无增益；
3. 缝宽公差（±20 μm）对阻抗敏感：G 越小越敏感，量产慎用 <0.15 mm 缝；
4. 对焊盘/器件处，缝要能"绕过"焊盘保持连续。

## 3.26 第 27 讲：NFC 读卡器设计项目（原理图到 PCB）

NFC（13.56 MHz）是"射频但不高速"的特例：波长 22 m，板上走线全部 <λ/100，传输线效应可忽略，**但天线与匹配是分布参数问题**：

### 3.26.1 NFC 匹配网络拓扑

```
NFC 芯片 TX/RX 差分口 → EMI 滤波（LPF，13.56M 通带、止带 100M+）
→ 匹配网络（串并电容组合，把天线阻抗变换到芯片目标差分负载，如 20~40 Ω 纯阻）
→ NFC 环形天线（PCB 走线圈电感 L_ant ≈ 0.5~3 μH）
```

| 步骤 | 计算/操作 |
|---|---|
| 1. 测/算天线阻抗 | LCR 表或阻抗分析仪测 L_ant 与串联电阻 R_ant（铜损+磁损） |
| 2. 目标 | 芯片要求负载（如 Ztx = R_target + j0），品质因数 Q 限 ~20~35（带宽 13.56M±7kHz 振荡容差，Q 太高通信超时） |
| 3. 串联/并联电容把电感谐振到 13.56 MHz | f0 = 1/(2π√(LC))：L=1 μH → C ≈ 138 pF |
| 4. 阻抗变换到芯片目标 | L 形/π 形网络，R = Q²·R_ant 分步匹配 |
| 5. 放pcb上并联电容用多只并联 | 精调（如 100p+22p+10p 组合贴装） |
| 6. EMV/门限调试 | 实测 Q、带宽，改电容微调 |

### 3.26.2 PCB 要点

1. 天线圈：线宽 ≥0.3 mm、间距 0.3~0.5 mm、4~10 匝，走线绕外框一圈的环形（面积大增益大）；
2. 天线下方与匹配网络区域禁高速数字线穿过；
3. 谐振电容靠近天线端口；匹配元件 0402、精度 5% 以内（NPO 温漂小）；
4. 天线区净空 ≥5 mm 无金属（电池、液晶、金属屏蔽壳会吸能量），金属电池盖必须开窗或用铁氧体隔离片；
5. EMC 滤波器（NFC 芯片参考设计自带）抑制 13.56M 谐波与 27/40/54 MHz 辐射；
6. 调试工具：网络分析仪看谐振点与带宽，或用非接触 Q 表；产线校准用"贴不同容值"补电容焊盘。

## 3.27 VNA 实测与去嵌入实操（27 讲综合实践）

### 3.27.1 矢量网络分析仪（VNA）使用要点

VNA 是射频板调试第一仪器，核心操作：

| 步骤 | 操作 | 目的/易错点 |
|---|---|---|
| 1. 校准 | SOLT（Short-Open-Load-Thru）或 SOC 校准件 | 把测量参考面移到电缆头；校准件与仪器品牌配套，混用误差 0.1 dB 级 |
| 2. 功率设置 | 小信号（-10~-20 dBm）测无源/线性 | 功率过大压缩被测件，测得"假插损" |
| 3. 测回损 S11 | 频段两端各扫 20% 余量 | 看带外谐振、看匹配谷位置 |
| 4. 测插损 S21 | 读取中频点与带内波动 | 带内波纹大 = 存在多重失配反射 |
| 5. 群时延 | 检查平坦段 | 突变点=谐振点 |
| 6. 时域（TDR 模式） | 低通冲击激励 | 定位不连续点的物理位置 |

### 3.27.2 PCB 测试夹具损耗的去嵌入

测量包含：电缆+连接器+SMA+板上走线+被测网络。要得到"纯被测网络"指标需去嵌入（de-embedding）：
1. 做一块校准板：与被测板同叠层、同 SMA、同 50 Ω 线，做成 Thru（直通）标准；
2. 测校准板 S 参数，作为"夹具效应"存入 VNA 的去嵌入文件（或后期软件处理）；
3. 被测板测量后减去夹具段 → 真实器件响应。
没有去嵌入时，一个 SMA+3 cm FR-4 线在 6 GHz 的"背景损耗"可达 0.8 dB——低插损器件的测量误差可能 100%来自夹具。

### 3.27.3 无屏蔽腔的隔离度快速自测法

用两根探头（或拆掉屏蔽罩的状态）+ 频谱仪跟踪源：信号从一个腔注入，相邻腔测泄漏，直接读级间隔离。预算：相邻腔隔离 > 60 dB 且不随频率出现尖峰（尖峰=腔体谐振路径），罩上与不罩对比可以验证过孔带密度是否达标——比全波仿真更快的工程判断手段。

### 3.27.4 天线的快速验证

网络分析仪 S11 单口测天线：谐振点是否落在目标频段（调匹配/剪枝）、谐振深度（>15 dB 表示辐射电阻占主导、匹配良好）；带宽读 -10 dB 频宽。注意：S11 好不代表效率高（有耗匹配也能骗过 S11），效率增益须在暗室或对比法测——板载天线优先用"史密斯圆图看谐振环扫频轨迹"判断而不是只看单点。

## 附录 C：工程 FAQ（高频实际问题 Q&A）

**Q1：2.4 GHz 板用 FR-4 还是 Rogers？**
看走线总长与成本。射频主链路短（<3 cm）且非阻抗敏感的 IoT 板，FR-4 可用；链路长、有滤波器/耦合器等"功能结构"、或有 5 GHz 以上谐波要求时，用 Rogers 混压（射频层 Rogers + 芯层 FR-4），成本只增 10~20%。

**Q2：为什么仿真好好的，实测回损只有 12 dB？**
按概率排查：① 焊盘未补偿（最常见）；② 阻焊没进模型；③ 连接器/SMA 反焊盘没优化；④ 板厂 εr 与模型差 5%；⑤ stub 残留。用 TDR 找到反射点位置再对号入座。

**Q3：50 Ω 线上并一个测试点为什么不行？**
测试点焊盘+分支线是一个开路短截线，等效并联电容+λ/4 内谐振。改用：嵌位式 RF 测试座（焊接在主线上）、或"可裁剪 stub"调试法。

**Q4：射频过孔换层到底能不能用？**
短支路（匹配元件接地）随便用；主路尽量不换层，必须换时：两过孔旁伴随地过孔、残桩背钻、EM 仿真验证插损与回损。>8 GHz 主路换层每个过孔约 0.1~0.3 dB 损耗。

**Q5：屏蔽罩多高合适？**
3~5 mm 常规。罩高影响腔体谐振频率（越高谐振越低），先算谐振再定高度；罩内最高器件 +0.5 mm 净空；PA 腔可加高做导热。

**Q6：PA 输出匹配发热怎么处理？**
三件事：匹配电感选大电流绕线型或微带 λ/4 结构（铜走线承受电流远超 0402）；地层打散热过孔阵列（孔阵热阻每孔 ~50~100°C/W 并联）；顶盖导热垫贴外壳。

**Q7：直流偏置串进射频口的电源噪声怎么除？**
偏置三通根部 π 滤波（磁珠+双电容）+ 独立 LDO；验证方法：偏置口注入已知纹波，测输出口 AM 噪声抑制比。PLL/VCO 电源用 PSRR >50 dB 的 LDO，磁珠选 600~2 kΩ @100 MHz 型号并注意其 SRF。

**Q8：两层板做 2.4 G 的底线是什么？**
底线是"底层在射频区 100% 完整净地"：任何数字回流都不许从射频走线底下走。做不到就上四层板，两层板省的钱不够回一次板的成本。

**Q9：差分射频线（如芯片 IQ 或平衡混频口）按 50Ω 单端还是 100Ω 差分布？**
芯片差分口按 datasheet 的差分阻抗（常见 100 Ω 或 50 Ω 差分）布；巴伦到单端芯片段按单端 50 Ω。松耦合（间距 ≥2W）布 100 Ω 差分最简单：每根单端约 60~65 Ω。

**Q10：13.56 MHz NFC 为什么既要当射频设计又要当"低频"设计？**
传输线效应可忽略（走线 << λ）→ 走线不用 50 Ω；但天线是辐射体、匹配是谐振电路、金属环境是耦合扰动 → 天线区按射频的净空/隔离纪律处理。一句话：NFC 的难点不在布线阻抗，在天线与匹配。

**Q11：同一块板上 2.4 G 射频和 DDR3 怎么共处？**
分区+屏蔽墙+时序错开。物理上：射频区与 DDR 各占板两端，中间电源区缓冲；屏障上信号不许穿过；频谱上：DDR 时钟选频使谐波避开射频带（或扩频时钟 SSC）；预算上：射频口杂散限值倒推屏蔽指标。

**Q12：阻抗控制 ±10% 和 ±8% 怎么选？**
常规消费类 ±10% 足够；指标敏感（回损>20dB、滤波器、阵列馈电）才上 ±8%（板厂加价、良率降）。更值得花的是**让仿真含全部寄生**，比压公差收益大。

## 结语：三套课程的知识合流

- 第一部分给了"纪律"：布局一字排开、屏蔽罩、阻抗连续；
- 第二部分给了"系统"：架构、链路预算、器件原理，知道每个铜皮为什么存在；
- 第三部分给了"技术武器库"：短截线、功分器、耦合器、渐变、CPWG、叠层逆向……

一块合格的射频板 = 系统指标分解（第二部分）× 分布参数思维（第三部分）× 布局布线纪律（第一部分）。任何一块板出问题，都可以回到这三条主线定位是哪一环的知识缺口。
