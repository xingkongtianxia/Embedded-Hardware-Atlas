## 第一章 绪论：电源基础与拓扑总览（P1–P20）

### 1.1 电源和负载（P1）

**电源的本质**：电源是一个"功率变换与调节"装置，它把一种形式的电能（市电交流、电池直流、不定电压母线）转换成负载需要的、稳定的另一种电能形式。评价电源好坏，不是看它"输出多少电压"，而是看它在各种扰动下能否**持续、稳定、干净地**向负载供电。

**负载的特性决定电源的要求**：

- **恒压负载（电阻型）**：电流随电压按欧姆定律变化，如加热器、白炽灯。电源只需维持输出电压恒定。
- **恒流负载**：如 LED、电机绕组、电解加工。LED 的正向压降随温度和电流剧烈变化，必须用恒流源驱动，否则电流失控烧毁。
- **恒功率负载**：如 DC-DC 后级、服务器主板。输入电压越低电流越大，呈现"负阻抗特性"，对前级电源的环路稳定性是严峻考验。
- **脉冲负载**：如射频功放、CPU。负载电流在纳秒~微秒级大幅跳动，要求电源既有快速的环路响应，又有足够的输出电容储能。

**电源的核心指标一览**：输出电压精度（±1%~±5%）、负载调整率、线性调整率、输出纹波与噪声、瞬态响应（过冲/跌落与恢复时间）、转换效率、功率密度、温升与可靠性。

**关键观念**：负载电流路径上的每一个电阻、电感都在"吃掉"电压裕量；电源设计的起点是准确刻画负载——最大/最小/典型电流、动态谱、允许的电压窗口。

### 1.2 功率变换器（P2）

**为什么需要功率变换器**：市电 220V/50Hz 是交流，电池是 3.7V/12V 直流，而芯片要 1V、电机要 310V、LED 要恒流——电压形式、大小、稳定度都不匹配，必须变换。

**四大基本变换类型（DC-DC 变换的四种基本拓扑族）**：

| 类型 | 功能 | 典型拓扑 |
|---|---|---|
| Buck（降压） | 输出低于输入 | Buck、半桥、全桥、正激、反激 |
| Boost（升压） | 输出高于输入 | Boost、反激 |
| Buck-Boost（反相/升降压） | 输出可高于或低于输入，极性可反 | Buck-Boost、Flyback、Cuk、SEPIC、Zeta |
| 直流变压器（比例变换） | 按匝比变换 | 变压器耦合拓扑 |

**AC-DC 变换链路**：EMI 滤波 → 整流桥 → PFC（升压到 ~400V 母线）→ DC-DC 变换器 → 输出滤波 → 反馈控制。市电输入的开关电源本质上是"AC→PFC 母线→DC-DC"两级（或反激单级）结构。

**功率变换器按开关方式分类**：

- **硬开关 PWM**：结构简单，开关损耗大，EMC 差，是最基础的实现。
- **软开关（准谐振/LLC/相移全桥）**：让开关器件在电压为零（ZVS）或电流为零（ZCS）时刻切换，大幅降低开关损耗，是高频化、高功率密度化的关键。
- **线性调节**：调整管工作在放大区，无开关噪声但效率极低（详见第三章）。

**占空比——功率变换的"旋钮"**：开关管周期 T 内导通时间为 D·T，通过调节占空比 D 即可调节能量传递的多少。所有 PWM 拓扑的稳态增益都是 D 的函数（Buck：Vo=Vin·D；Boost：Vo=Vin/(1−D)；Buck-Boost：Vo=Vin·D/(1−D)）。

### 1.3 对电源的要求（P3）

**稳态指标**：

- **电压精度**：常温 ±1%~2%，全温全寿命 ±5% 是常见规范；精度预算要分配给基准误差、采样分压误差、放大器失调、温度漂移。
- **负载调整率**：负载从 10%→100% 变化时输出电压变化量，反映直流增益环路刚度。
- **线性调整率**：输入电压变化时输出的稳定性，取决于前馈抑制与环路增益。
- **纹波（Ripple）**：开关频率及其谐波上的周期性波动，mV 级指标；由输出电容 ESR、ESL 和充放电 ΔQ 共同决定。
- **噪声（Noise）**：开关瞬间 di/dt、dv/dt 耦合到输出的高频毛刺，带宽可达几十 MHz，测量要用 20MHz 带宽限制和短接地弹簧。

**动态指标**：

- **负载瞬态响应**：突加/突卸负载时输出电压的跌落/过冲幅度与恢复时间。决定因素：环路带宽（GBW）、输出电容容量与 ESR、相位裕度。
- **启动特性**：软启动（Soft-Start）控制占空比从 0 缓升，防止变压器饱和与输出过冲；要有浪涌电流抑制（NTC/继电器/有源钳位）。
- **保护功能**：过压保护 OVP（防止反馈断线时输出失控）、过流保护 OCP（打嗝/恒流/逐周期限流）、过温保护 OTP、短路保护 SCP、欠压锁定 UVLO。

**效率与热**：效率 η = Po/Pin = Po/(Po+Ploss)。损耗包括导通损耗、开关损耗、磁芯损耗、驱动损耗等。1% 效率提升在大功率下意味着显著的散热成本下降——热设计贯穿整个电源设计。

### 1.4 电源功率调节（P4）

功率调节的本质：**控制单位周期内从输入搬到输出的能量包大小**。实现手段有三类：

1. **PWM（脉宽调制）**：固定频率，改变脉宽。谐波频谱固定便于滤波，是最主流方式。缺点是轻载时开关损耗占比升高。
2. **PFM（频率调制）**：固定脉宽（或固定导通时间），改变频率。轻载效率高（跳周期、突发模式），但频谱散、EMC 难处理。
3. **PSM（相移调制）**：固定脉宽与频率，改变全桥两臂之间的相移来调节等效占空比，用于相移全桥 ZVS 拓扑。

**控制量的选择**：

- **电压模式控制**：误差放大器输出直接与锯齿波比较生成 PWM。结构简单、抗噪好，但对输入扰动的抑制依赖环路增益（音频抑制比需要高增益弥补）。
- **电流模式控制（峰值电流模）**：时钟触发开通、电流采样达到误差放大器阈值关断。内环自然限制电流，逐周期保护简单，输入前馈天然良好（斜率补偿防止次谐波振荡 D>0.5）。
- **迟滞/滞环控制**：输出纹波窗口比较器直接控制，无补偿、响应极快，但频率随条件变化。

**轻载节能策略**：跳周期（Skip Mode）、突发模式（Burst）、深度突发、降频、断续导通（DCM）运行——本质是降低轻载时的开关频率或开关次数。

### 1.5–1.6 电源拓扑总览（P5–P6）

**基本非隔离拓扑的推导逻辑**：一只开关管、一只二极管、一只电感，通过改变三者的连接顺序即可得到 Buck、Boost、Buck-Boost 三大基本拓扑：

- **Buck**：开关串在输入与电感之间，二极管续流到地。Vo = Vin·D（0<D<1 只降压）。输入电流断续（需要输入电容），输出电流连续（纹波小）。
- **Boost**：电感在输入侧，开关管接地，二极管连到输出。Vo = Vin/(1−D)。输入电流连续（EMC 友好，PFC 首选），输出电流断续（输出纹波大）。
- **Buck-Boost**：极性反转，Vo = −Vin·D/(1−D)，输入输出电流都断续，纹波最大，但可升可降。

**CCM/DCM/BCM 三种导通模式**：

- CCM（连续导通）：电感电流纹波不降到零，增益只与 D 有关，与负载无关。
- DCM（断续导通）：轻载或小电感时电流每周期归零，增益变为与负载相关（Buck-Boost DCM：Vo/Vin ∝ 1/√(负载)），环路模型变化需重新补偿。
- BCM（临界导通）：谷底开通，用于准谐振反激，降低开通损耗。

**拓扑选择的决策树**：是否需要隔离？→ 功率等级（<100W 反激；100~500W 正激/半桥；>500W 半桥/全桥/LLC）→ 输入输出电压范围 → 是否需要多路输出 → 效率与密度要求（要不要软开关/LLC）。

### 1.7–1.8 隔离型拓扑（P7–P8）

**为什么隔离**：安规要求（IEC 60950/62368 规定一次侧与二次侧的绝缘距离与耐压）、电位隔离（避免共地干扰）、匹配悬空输出（负电压、多路输出）。隔离由变压器与光耦（或隔离运放、数字隔离器）实现。

**隔离拓扑族谱**：

- **反激（Flyback）**：单管，变压器实质是耦合电感，开关关断时副边释放能量。元件最少、成本最低，<150W 绝对主力。漏感引起的电压尖峰需 RCD 钳位吸收。
- **正激（Forward）**：单管，变压器真实变压，需第三绕组或 RCD/有源钳位复位磁芯。比反激电流纹波小，适合 100~300W。
- **推挽（Push-Pull）**：两管+中心抽头原边，磁通双向，适合低压输入（电池、车载 12V/24V/48V）中功率场合。
- **半桥（Half-Bridge）**：两管串联分压，变压器接中点，原边承受 Vin/2，适合 300~800W；配合电容分压天然抗偏磁。
- **全桥（Full-Bridge）**：四管，原边承受全压 Vin，功率密度最高，>1kW 首选；可做相移 ZVS 软开关。
- **LLC 谐振**：全桥/半桥+谐振腔（Lr、Cr、Lm），靠调频调增益，原边 ZVS、副边同步整流 ZCS，开关损耗极小，效率可达 94%+，是大功率高密度电源主流。

**隔离拓扑的共同问题——磁通复位与伏秒平衡**：每个开关周期变压器承受的正伏秒必须等于负伏秒，否则磁通逐周期累积直至饱和、电流失控。反激靠反射电压自动平衡；正激需要专门的复位回路；桥式拓扑靠对称驱动 + 隔直电容。

### 1.9 大功率拓扑（P9）

大功率（kW 级以上）的特殊考虑：

- **电流分担**：交错并联（Interleaving）多相 Buck，每相错开 360°/n 相位，纹波相互抵消、输入输出电容减小、每相电感体积减小。
- **全桥+移相 ZVS**：利用变压器漏感与寄生电容实现四管零电压开通，效率与 EMC 显著改善；滞后臂轻载可能丢 ZVS，需辅助电感或饱和电感。
- **LLC/CLLC**：谐振软开关+同步整流，是大功率 DCX（直流变压器）化方案。
- **三相 PFC / 维也纳整流**：kW 级 AC 输入的前级，把功率因数提到 0.99 以上。
- 大功率下的器件：IGBT（低压侧大电流、低速）、SiC MOSFET（高压高速）、Si 并联、铜排母线、叠层母线降低寄生电感。

### 1.10 变压器磁通复位（P10）

**磁芯的 B-H 回线与饱和**：B=μH，磁芯磁通密度有饱和限值（铁氧体 ~0.3–0.4T）。若每周期净伏秒不为零，B 逐周期爬升（staircase），磁导率骤降、励磁电流暴涨，开关管瞬间过流损坏。

**伏秒平衡法则**：Σ(V·t)on = Σ(V·t)off。反激：Vin·D·T = Vor·(1−D)·T（Vor 为反射电压），由此确定匝比与反射电压的折中（通常 Vor ≈ 80–120V 于 220Vac 反激）。正激：需要复位绕组提供负伏秒 Np/Nr 关系决定复位时间 < (1−D)T。桥式：双极性对称驱动自动平衡，仍常串隔直电容（DC block）防偏磁。

**防饱和的工程手段**：RCD 钳位、有源钳位、同步整流驱动对称、励磁电流检测、软启动限占空比爬升、选择 Bsat 余量大的磁芯（带气隙）。

### 1.11 多路输出拓扑（P11）

多路输出的实现方式与代价：

- **多绕组变压器**：反激天然适合多路输出（每副边绕组按匝比分压），但只有主路（闭环那一路）严格稳压，辅路精度差（漏感压降+负载交叉调整率差）。
- **后级稳压（Post Regulator）**：辅路加 LDO 或磁放大器（MagAmp）/同步后稳，精度好但成本/效率代价。
- **加权反馈**：主辅路分压加权共同反馈，折中精度。
- **交叉调整率改善**：绕组耦合（三明治绕法减小漏感）、输出同步整流时序配合、辅路最小假负载（预载）。

### 1.12 功率因数校正（P12，详见第十六章）

功率因数 PF = 有功功率/视在功率 = cosφ·(基波因数)。整流桥+电容直接整流时，电流是窄脉冲，PF 仅 0.5–0.6，谐波污染电网。PFC 强制输入电流跟随正弦电压，PF>0.95。主流为 Boost 型有源 PFC（CRM/CCM），输出约 380–400V 母线给后级 DC-DC。

### 1.13 软开关技术（P13）

硬开关的问题：开通/关断时电压电流交叠，单次开关能量 E = ½·V·I·(tr+tf)，对应损耗 P = ½·V·I·(tr+tf)·fs；dv/dt、di/dt 引起 EMI；体二极管反向恢复雪上加霜。

**软开关手段**：

- **ZVS（零电压开通）**：让开关两端电压先降为零再开通。实现：谐振（LLC）、准谐振（QR 反激谷底开通）、移相全桥（漏感+结电容谐振）。
- **ZCS（零电流关断）**：让电流先降为零再关断，消除关断拖尾（IGBT 受益大）。LLC 副边整流天然 ZCS。
- **无源吸收 vs 有源钳位**：RCD 吸收把尖峰能量烧掉；有源钳位把漏感能量回收并实现主管 ZVS（反激有源钳位 ACF 是当前高密度方案热点）。

### 1.14 开关电源损耗（P14）

损耗分解（以 Buck/反激为例）：

- **导通损耗**：P = I²rms·Rds(on)（MOSFET）/ I·Vf（二极管）。与 RMS 电流平方成正比，低压大电流时是主导，用同步整流取代二极管。
- **开关损耗**：开通/关断交叠损耗 E = ½Vin·Io·(tr+tf)·fs，与频率成正比——高频化必须软开关或更快的器件（SiC/GaN）。
- **驱动损耗**：P = Qg·Vdrive·fs，高压高频下不可忽略。
- **磁芯损耗**：磁滞+涡流，按 Steinmetz 公式 P ∝ fs^α·ΔB^β（α≈1.3–1.7，β≈2–2.7），与纹波电流强相关。
- **铜损**：I²R + 趋肤/邻近效应交流电阻 Rac。
- **输出电容 ESR 损耗**、**控制器/静态损耗**、**体二极管反向恢复损耗**。

效率优化的优先级排序：先抓最大项（通常导通损耗与磁损），同步整流、优化 ΔB 与匝数、升级器件、软开关、优化死区。

### 1.15 整流电路（P15）

- **半波整流**：一只二极管，利用半周期，纹波大、变压器利用率低，仅小功率。
- **全桥整流**：四只二极管，全程利用，变压器无直流偏磁，最常用；代价两个二极管压降。
- **全波（中心抽头）整流**：两只二极管，压降小一个，适合低压大电流输出；变压器绕组利用率减半。
- **同步整流**：用低 Rds(on) MOSFET 取代整流二极管（0.3V vs 0.7V+），低压大电流输出效率提升显著；关键在于时序——过早开通直通短路，过晚则体二极管导通增加损耗，驱动信号可取自变压器绕组（自驱动）或专用控制器（外驱动）。
- 倍压整流、桥式+倍压混合（110/220V 自适应老方案）。

### 1.16–1.17 控制策略（P16–P17，详见第十九章）

控制的目标：在扰动（输入跳变、负载跳变、温漂）下维持输出恒定，同时保证稳定裕度。电压模式 vs 电流模式、PI 补偿器、Type-II/Type-III 频域补偿、峰值电流模的斜率补偿是本章主线（详见第十九章展开）。

### 1.18–1.20 输出功率、增益与误差补偿（P18–P20）

- **输出功率与器件应力**：确定拓扑后，先算每个器件的电压/电流应力（如反激 MOS 耐压 = Vin,max + Vor + 尖峰裕量；反激输出二极管耐压 = Vo + Vin/n，n = Np/Ns），应力决定器件选型，器件损耗决定散热。
- **增益与占空比范围**：考虑最小输入电压下最大占空比（避免 D 接近 1 造成匝比失控与效率崩塌）、最大输入电压下最小占空比（受控制器最小导通时间限制）。
- **误差来源与补偿**：反馈分压精度、基准容差（±0.5%~±2%）、光耦 CTR 老化漂移（隔离反馈的最大敌人）、补偿网络元件容差。设计时把精度预算表格化，逐项分配，留出老化余量。

## 第二章 电源中的组件与元器件（P21–P27、P117–P121）

### 2.1 电阻在电源中的应用

- **采样电阻（Shunt）**：电流检测用，毫欧级，功率与温漂是关键，常用 2512 封装散热好、四端开尔文接法消除引线误差。
- **分压电阻（反馈网络）**：精度直接影响输出精度，用 ±1% 甚至 ±0.1% 薄膜电阻；上/下分压电阻的取值平衡精度与静态功耗。
- **假负载（Preload）**：多路输出辅路挂最小负载防输出电压漂高。
- **缓冲电阻（Snubber R）**：与 C 串联组成 RC/RCD 吸收，电阻功率按吸收能量估算 P ≈ ½·C·V²·fs。
- **限流/启动电阻**：芯片启动供电的泄放电阻，注意脉冲功率额定与耐压。
- **热敏电阻 NTC**：上电浪涌抑制，选型看冷阻、最大稳态电流与残余功耗；并联继电器可旁路以降低损耗。

### 2.2 电容家族与选型

- **铝电解电容**：容量大、耐压高、便宜，但 ESR 大、寿命受温度与纹波电流制约（温度每升 10°C 寿命减半，Arrhenius 规律），是开关电源寿命短板；低温电解液凝固导致容量骤降。
- **固态电容（聚合物）**：ESR 小、寿命长、无干涸问题，容量密度低于电解，广泛用于输出滤波。
- **陶瓷电容 MLCC**：ESR/ESL 极小、高频特性最佳，用于 IC 去耦与高频吸收；注意直流偏压下容量下降（X7R 可降 50%+）、陶瓷电容的压电啸叫、柔性端子防板弯开裂。
- **薄膜电容**：耐压高、自愈性好、ESR 低，常用于 PFC 输出母线、X/Y 安规电容、缓冲电容。
- **钽电容**：容量密度大、ESR 中等，但失效模式是短路起火，需降额 50% 使用，电源中慎用。
- **X/Y 安规电容**：跨接在电网线之间（X 为跨线差模，Y 为线对地共模），失效不得短路/不得触电，等级 X1/X2、Y1/Y2 按耐脉冲与绝缘要求选。

**输出电容的纹波电流承受**：电容温升由 RMS 纹波电流决定，电解电容有明确的额定纹波电流谱；Buck 输出电容电流为三角波交流分量，反激输出电容承受近似方波的副边电流——选型必须核对纹波电流规格。

### 2.3 二极管与整流器件

- **硅整流二极管**：Vf≈0.7–1V，反向恢复 trr 大，用于工频整流（桥堆）。
- **快恢复二极管 FRD**：trr < 150ns，用于输出整流（反激/正激副边）。
- **超快恢复/碳化硅二极管**：trr≈20–50ns 或几乎无反向恢复，用于 PFC 升压二极管（反向恢复损耗是 CCM PFC 最大损耗项），效率提升立竿见影。
- **肖特基二极管**：Vf≈0.3–0.5V、无反向恢复，低压输出整流首选；漏电流大、耐压低（<200V，SiC 肖特基除外）、体二极管热失控风险。
- **TVS 瞬态抑制二极管**：吸收浪涌尖峰，响应 ps 级，按钳位电压与峰值功率选型，用于输入浪涌与 MOS 漏极尖峰保护。

### 2.4 MOSFET 与开关器件

- **关键参数**：Rds(on)（导通损耗）、Qg/Qgd（驱动损耗与米勒平台）、Coss（开关损耗与 ZVS 谐振）、体二极管 trr、Vds 耐压降额（80% 规则）、热阻 Rth(j-c)。
- **Rds(on) × Qg 品质因数（FOM）**：衡量器件综合水平的核心指标，同代工艺下二者乘积近似恒定，选择即折中。
- **超结 MOSFET**：高压（500–900V）低 Rds(on)，但 Coss 非线性大、体二极管 trr 差，适合硬开关桥式要谨慎（直通风险）。
- **GaN HEMT**：无反向恢复、开关速度极快，可 MHz 级工作；驱动要求苛刻（dv/dt 高），栅压裕量小。
- **SiC MOSFET**：高压 1200V 级、高温工作、开关损耗小，取代 IGBT 趋势明显。
- **驱动设计要点**：栅极电阻调开关速度与 EMI 平衡；米勒钳位防 dv/dt 误开通（桥式上下管）；负压关断增强抗扰；驱动回路面积最小化。

### 2.5 控制器 IC 与辅助电路

- **PWM 控制器分类**：电压模式、峰值/平均电流模式（UC384x 系列是峰值电流模经典）、恒流恒压 CC/CV 反激控制器（如各厂 primary-side regulation PSR 芯片）、QR 准谐振控制器、数字电源 DSP/MCU。
- **启动电路**：高压启动电流源（集成）vs 启动电阻（外置，损耗大）；启动后由辅助绕组供电，芯片静态电流决定待机损耗。
- **辅助绕组三重用途**：芯片供电 VCC、输出电压检测（PSR）、过压保护信号。
- **自举供电（Bootstrap）**：桥式高侧驱动用电容+二极管自举，注意最小占空比时电容补充电时间。

### 2.6 光耦与隔离反馈

- **CTR（电流传输比）**：光耦的核心参数，随温度下降、随时间老化（CTR 逐年衰减是隔离电源反馈失效主因），设计时保证寿命末期 CTRmin 仍满足环路增益需求。
- **线性度**：普通光耦 CTR 非线性，配合 TL431 构成"精密基准+误差放大+光耦传输"标准隔离反馈结构；光耦工作在小信号线性区（偏置 1–5mA）。
- **速度**：普通光耦上升下降时间 μs 级，限制环路带宽在 20kHz 以内；高速光耦可到几百 kHz。
- **安规间距**：光耦内部一次/二次侧爬电距离与电气间隙按工作电压与污染等级确定，是隔离屏障的一部分。

### 2.7 基准与误差放大器 TL431

- TL431 = 2.5V 基准 + 运放 + 输出管的"可编程齐纳"，是隔离电源反馈的工业标准。
- 典型接法：输出经分压接入 REF 端，阴极经偏置电阻接输出（或辅助电源），阴极-阳极串入光耦 LED。
- **补偿网络放在 TL431 周围**（Type-I/II），因为共阴/共阳接法与光耦分流逻辑决定极性；注意阴极最小偏置电流 1mA 保证调节能力。
- 环路中光耦 CTR 与偏置电阻共同决定中频段增益，设计时统一折算。

## 第三章 线性调压器（P28–P38）

### 3.1 线性调压器原理（P28–P31）

线性稳压器是"可控电阻分压"：调整管（BJT/MOSFET）工作在线性放大区，等效为一个受误差放大器控制的动态电阻，通过分压把多余的电压"烧掉"。

**核心结构**：基准源（Bandgap ~1.2V）+ 误差放大器 + 调整管 + 反馈分压。误差放大器把 Vout 采样值与基准之差放大，控制调整管导通深度。

**效率的宿命**：η = Vout/Vin。压差越大效率越低，损耗 P = (Vin−Vout)·Io 全部变成调整管的热。例：12V→3.3V@1A 效率仅 27.5%，损耗 8.7W。

**LDO（低压差线性稳压器）**：调整管用 PMOS 或 NMOS 结构，压差可低至 0.1–0.5V（PMOS 输入输出电容耦合决定瞬态特性；NMOS 需要 >Vin 的驱动电荷泵但负载调整率更好）。

**关键指标**：

- **Dropout（压差）**：保持稳压的最小 Vin−Vout。
- **PSRR（电源抑制比）**：随频率上升而下降，好的 LDO 在 100kHz 仍有 40dB+；开关电源后级的"清洁工"。
- **瞬态响应**：负载跳变时输出跳变量由环路带宽与输出电容决定，LDO 无开关纹波但响应慢于 DC-DC。
- **稳定性**：LDO 是带输出电容的闭环系统，对输出电容 ESR 有稳定窗口要求（零点补偿），换电容型号需验证。

### 3.2 线性调压器在电源系统中的角色（P32–P38）

虽然效率低，线性调压在系统中不可替代：

1. **开关电源后级净化**：DC-DC 先降到 Vout+0.5V，LDO 再稳压，兼顾效率与超低纹波（模拟供电、ADC 基准供电、时钟供电的标配方案）。
2. **待机/轻载供电**：极轻载时 LDO 效率尚可且无开关噪声，适合待机电路。
3. **辅助电源/偏置**：从 PFC 母线或输出取电产生芯片 VCC（配合小降压或直接线性，注意压差损耗）。
4. **恒流源应用**：LED 驱动、基准电流产生——线性恒流的噪声与精度远优于开关恒流。
5. **高压线性启动电路**：从高压母线经调整管给 VCC 电容预充电，启动完成后切换到辅助绕组供电，省去启动电阻损耗。

**散热计算示例**：调整管结温 Tj = Ta + P·(Rθjc+Rθca)。8.7W 损耗若 Rθ 总和 15°C/W 则温升 130°C——不可行；改用 DC-DC 后损耗降到 0.5W 级。这解释了"先开关、后线性"的级联哲学。

**线性调压的局限**：只能降压；无隔离；大压差大电流不现实；但精度、噪声、瞬态（小范围）、成本、简单性是开关电源无法替代的。

## 第四章 开关变换器基础（P39–P45）

### 4.1 电感的基本规律（P39）

开关电源的一切波形都源于两条定律：

- **电感伏秒平衡**：稳态时电感一个周期的平均电压为零（否则电流无限增长）。Buck 的 Vo=Vin·D 直接由此导出：Ton 时 VL=Vin−Vo，Toff 时 VL=−Vo，(Vin−Vo)·DT = Vo·(1−D)T ⇒ Vo=Vin·D。
- **电容电荷平衡**：稳态时电容平均电流为零，输出电容的 ΔQ 充放电决定纹波电压 ΔV = ΔQ/C + ΔI·ESR。

### 4.2 Buck 的波形解剖（P40–P42）

CCM 下 Buck 一个周期内：

- **开关导通**：Vin 加到电感，电流斜率 +（Vin−Vo)/L；二极管反偏承受 Vin。
- **开关关断**：电感续流经二极管，斜率 −Vo/L；开关承受 Vin。
- **电感纹波电流**：ΔI = (Vin−Vo)·D·T/L = Vo·(1−D)·T/L，纹波系数取 20–40% 的满载电流是设计惯例（权衡铜损/磁芯损耗与暂态能力）。
- **输入电容的挑战**：Buck 输入电流是方波脉冲，输入电容承担全部交流分量，RMS 电流 Icin = Io·√(D(1−D))，D=0.5 时最大 0.5·Io——输入电容纹波电流额定值常被忽视而失效。
- **输出纹波**：ΔVout = ΔI·(ESR + 1/(8·fs·C))，陶瓷电容 ESR 项主导时纹波近似三角波。

**同步整流 Buck**：下管取代续流二极管，消除二极管压降损耗，且允许电流反向（CCM 深入到轻载），轻载无 DCM 模式切换点；但要注意死区控制防直通，轻载效率反而可能因栅驱损耗不如二极管方案——因此有二极管仿真（Diode Emulation）模式。

### 4.3 Boost 电路解剖（P43–P45）

> 注：课程 P39–P45 章节名均为"4.x 变换器"，内部按 Buck/Boost/升降压顺序展开；本节 P 号为按教学顺序的推断标注，以实际课程为准。

- 开关导通：电感储能，斜率 +Vin/L；二极管截止，输出由电容供电。
- 开关关断：电感电流经二极管泵入输出，斜率 −(Vo−Vin)/L。
- **增益 Vo=Vin/(1−D)** 的代价：D 越大效率越低（电流 RMS 按 1/(1−D) 放大），实际 D>0.85 基本不可用；升压比大时用两级或变压器拓扑。
- **输出电流断续**：二极管电流是三角脉冲串，输出电容承受大纹波电流 Icap,rms = Io·√(D/(1−D))，Boost 输出电容是大应力件。
- **浪涌问题**：上电时输入经电感-二极管直通到输出，输出预充到 Vin；软启动必须限制电感电流。
- **右半平面零点（RHPZ）**：Boost/Buck-Boost 的小信号传函含右半平面零点 fz = Rs·(1−D)²/(2πL)（Rs 为负载等效电阻折算），相位滞后使环路带宽被压到 fz 的 1/3 以下——这是 Boost 类拓扑环路设计的核心约束。

### 4.4 非理想因素（P45）

- **寄生电阻**：电感 DCR 造成负载相关压降与铜损；MOS 导通电阻使增益偏离理想值；二极管压降在低压输出时占比巨大（3.3V 输出中 0.5V 占 15%）。
- **开关时序损失**：死区时间、驱动延迟、最小导通时间限制了最大/最小占空比范围，高升压/降压比时成为瓶颈。
- **开关损耗随频率线性上升**，磁损随频率指数上升——每个拓扑都有一个效率最优频率窗口。

## 第五章 降压（Buck）变换器详解（P46–P53）

### 5.1 设计流程八步法（P46–P47）

以 Vin=12V、Vout=3.3V、Io=5A、fs=500kHz 为例：

1. **占空比**：D ≈ Vout/Vin = 0.275（理想）。
2. **电感量**：按纹波系数 r=0.3，L = Vout(1−D)/(fs·ΔI) = 3.3·0.725/(500k·1.5) ≈ 3.2µH；取 3.3µH 标准值，饱和电流 > 峰值电流 Ipk = Io+ΔI/2 = 5.75A 的 1.2 倍余量。
3. **输出电容**：纹波要求 50mV：ESR 项 + 容量项；MLCC 100µF×2 或固态电容；校核 RMS 纹波电流。
4. **输入电容**：按 Icin,rms = Io√(D(1−D)) = 2.2A 选型；电解+陶瓷并联兼顾容量与高频。
5. **开关管**：上管 Qg/Rds(on) 折中；下管同步整流低 Rds(on) 优先；耐压 30V 级（12V 系统留 2.5 倍余量）。
6. **环路补偿**：Buck 无 RHPZ，带宽可做到 fs/10~fs/6；Type-II 补偿配合电流模，Type-III 配合电压模。
7. **软启动与时序**：SS 电容设定爬升时间；多轨系统配置上电时序（PGOOD+EN 级联）。
8. **保护**：OCP 逐周期限流点 > 1.3×Ipk；OVP 防反馈开路。

### 5.2 电流纹波与电流应力的精确计算（P48）

- 电感电流 RMS：ILrms = √(Io² + ΔI²/12)，铜损按此计算。
- 上管导通损耗：Pup = Iup,rms²·Rds(on) = Io²·D·Rds(on)（忽略纹波修正）。
- 下管导通损耗：Plo = Io²·(1−D)·Rds(on,sr)。
- 死区体二极管损耗与反向恢复：非同步 Buck 的续流二极管损耗 P = Vf·Io·(1−D)（续流占空比 1−D），与同步整流方案的损耗对比决定是否值得同步化。

### 5.3 轻载模式与效率曲线（P49）

- **CCM→DCM 边界**：Io < ΔI/2 时进入断续模式，增益开始随负载变化（电压模环路需重新稳定），纹波反而可能增大。
- **跳脉冲/省电模式**：轻载关闭部分开关周期，效率曲线在 10% 负载处抬升 10–30%；代价是纹波增大与频谱不确定。
- **强制 CCM**：抗噪与恒频 EMC 需求时禁用省电模式，但轻载效率低。
- **效率峰值点**：通常在 50–80% 负载，导通损耗（∝Io²）与固定损耗（驱动+铁损+静态）平衡处。

### 5.4 多相交错并联 Buck（P50–P51）

- n 相交错，等效纹波频率 n·fs，纹波抵消条件与占空比有关（D=0.5 时两相完全抵消）。
- 输入/输出电容 RMS 应力按相数下降；瞬态响应每相同时参与，动态性能倍增。
- **均流问题**：各相电流分配不均导致热失衡——主动均流（各相独立环路）、Droop 调节、电流共享总线；相位检测与顺序换相（Phase Shedding）可在轻载关掉部分相保效率。

### 5.5 高压/大功率 Buck 变体（P52–P53）

- **双管 Buck（2-Switch Buck）**：两只开关+两只二极管/或同步管，开关承受 Vin/2，无体二极管直通与自举问题，适合高压输入（如 400V→12V 中间母线）。
- **多电平 Buck**：飞跨电容分压，开关应力减半，等效开关频率倍增，电感体积缩小，用于高密度大电流 VRM。
- **VRM/VR13 多相磁集成**：CPU 供电几十相 + 磁集成电感阵列，负载瞬态 ns 级，是 Buck 技术的极限应用场景。

## 第六章 升压（Boost）与升降压电路（P54–P55）

> 注：课程 P54–P55 原章节名为"6.x 升降压电路"，内容衔接第四章的 Boost 讲解并引入升降压概念；本章按知识点归纳整理，同时补充 Boost 的工程细节。

### 6.1 Boost 的能量搬运两步曲（P54）

- **第一步（开关导通）**：输入电压直接加在电感两端，电流线性上升，电感储能；负载由输出电容独立供电——此时输出与输入"脱开"，这就是 Boost 输出电流断续、纹波大的根源。
- **第二步（开关关断）**：电感电流不能突变，感生电压使二极管导通，电感电压 = Vo−Vin，电流下降，储能与输入能量一起泵入输出。

### 6.2 关键设计点（P55）

- **电感选型**：Ton 伏秒最大点发生在最大 D 与最低输入频处；ΔI = Vin·D·T/L，纹波系数 30–40%。
- **开关管应力**：Vds = Vo + 尖峰（布线电感引起），电流峰值 = 输入平均电流 + ΔI/2 = Io/(1−D)+ΔI/2——大升压比时输入电流是输出电流的数倍。
- **二极管（或同步管）**：承受 Vo 反压，平均电流 = Io，但峰值电流大、导通角小，损耗集中在窄脉冲——升压比大时同步整流收益显著。
- **输出电容 RMS 电流**：Icap,rms = Io·√(D/(1−D))，大 D 时远超输出电流，必须选低 ESR 大纹波电流额定器件（固态/MLCC 阵列）。
- **应用场景**：PFC（第十六章主角）、电池升压、LED 恒流驱动（电流型天然适配）、太阳能 MPPT 前级、OLED 供电。

## 第七章 升降压变换器（Buck-Boost/SEPIC/Cuk/Zeta）（P56–P58、P139–P142）

### 7.1 反相 Buck-Boost（P56、P139）

- 结构：开关接 Vin，电感一端接地、一端经二极管接输出——注意输出极性与输入相反。
- **增益 |Vo| = Vin·D/(1−D)**：D<0.5 降压、D>0.5 升压，一个拓扑覆盖全范围。
- **代价**：输入、输出电流都断续，两侧电容都承受大纹波电流；开关管电压应力 = Vin+|Vo|；能量经"电感储能→释放"两段搬运，效率低于同等级 Buck。
- 环路含 RHPZ（与 Boost 同理），带宽受限。

### 7.2 四管无桥升降压（P140）

- H 桥结构 Buck-Boost：四只开关全控，能量可双向流动（充放电应用），CCM 下输入输出电流均可连续（同步整流）。
- 电池充放电、双向 DC-DC、UPS 母线变换的标准方案。

### 7.3 SEPIC（单端初级电感变换器）（P57、P141）

- 结构：两只电感（或耦合电感）+ 串联电容 + 隔离二极管。增益 Vo = Vin·D/(1−D)（同 Buck-Boost 但**极性不反**）。
- **优点**：输入电流连续（耦合电感后接近纯直流，EMC 友好）；输出与输入同极性；电容隔直，可做 LED 恒流（输出短路时电容阻断直流通路）。
- **缺点**：元件多；中间电容承受大纹波电流；两只电感体积/成本高；RHPZ 同样存在。
- 耦合电感设计：耦合后等效电感感量翻倍、漏感可兼作纹波抑制，但要控制漏感尖峰（加 RC 或钳位）。

### 7.4 Cuk 与 Zeta（P58、P142）

- **Cuk**：输入输出电流都连续（电感分别在两侧），纹波最小、EMC 最好；但极性反转、中间电容应力大、对电容 ESR 敏感；耦合电感可进一步消纹波。
- **Zeta**：SEPIC 的"对偶"，输出电流连续、输入断续，极性不反，适合输出纹波要求极严的场合。
- **选型逻辑**：输入侧纹波敏感选 SEPIC/Cuk（输入连续），输出侧纹波敏感选 Zeta；同极性需求排除反相 Buck-Boost；成本敏感时反相 Buck-Boost 元件最少。

## 第八章 反激（Flyback）变换器（P59–P62、P152–P160）

### 8.1 反激的本质（P59、P152）

反激变压器**不是传统变压器，而是一对耦合电感**：开关导通时原边储能（副边因同名端关系二极管反偏不导通）；开关关断时能量经副边释放给负载。"Flyback"之名即来自副边电流"回扫"。

**与正激的本质区别**：正激开关导通时同时向副边传能（真实变压），反激导通时只储能、关断时才放能——因此反激变压器磁芯利用率低（单向磁化，ΔB 仅工作在第一象限），体积相对同功率正激更大；但省去输出电感，多路输出天然容易。

### 8.2 反射电压与匝比设计（P60、P153）

- **反射电压 Vor = n·Vo**（n = Np/Ns）：开关关断时副边电压反射回原边，开关管承受 Vin,max + Vor + Vspike。
- **经典折中**：Vor 取 80–120V（220Vac 输入、700V 管）：Vor 高→占空比大、副边二极管应力小（Vrrm = Vo + Vin/n，n = Np/Ns），但原边应力大；Vor 低→反之。600V 管系统 Vor 一般 ≤100V。
- **DCM 设计**：每个周期储能 E = ½·Lp·Ipk²，功率 Po = η·½·Lp·Ip²·fs ⇒ Lp = 2·Po/(η·Ip²·fs)。DCM 副边二极管零电流关断，无反向恢复问题。
- **CCM 设计**：ΔB 按纹波电流比例取（如 0.25），Lp 更大、峰值电流小、导通损耗低，但副边二极管有反向恢复、需要斜坡补偿（峰值电流模 D>0.5 稳定性）。
- **BCM/QR 设计**：谷底开通（漏感-结电容谐振电压谷），开通损耗最低，高压输入时 EMI 频谱变动（变频），需频率抖动/展频处理。

### 8.3 钳位吸收电路（P61、P154）

漏感是反激的心腹之患：关断瞬间漏感能量无处释放，与结电容谐振产生电压尖峰，不加处理会击穿开关管。

- **RCD 钳位**：电容吸收漏感能量，电阻耗散。钳位电压 VC 通常设为 1.5–2.5 倍 Vor：太低则钳位消耗原边主能量（效率大降），太高则尖峰残留。电阻功率 P ≈ ½·Llk·Ip²·fs。这是反激效率的最大"出血点"，漏感控制（三明治绕法）优先于吸收优化。
- **有源钳位（ACF）**：辅助管+钳位电容在关断后谐振，漏感能量**回收**并实现主管 ZVS——当前 USB-PD 高密度快充的主流方案，效率比 RCD 方案高 3–5%。
- **齐纳钳位**：简单粗暴，仅小功率/低成本场合。

### 8.4 副边与输出（P62、P155）

- **输出电容**：副边电流是三角/梯形脉冲，RMS 应力大；ESR 决定纹波主体——ΔV ≈ Ipk,sec·ESR（关断瞬间电流最大），低 ESR 固态电容或并联 MLCC。
- **同步整流（SR）**：副边 MOS 取代二极管，低压大电流（5V/20A）效率提升 8–12%；自驱动（绕组驱动）注意死区与轻载误开通，控制器驱动最可靠；DCM 下 SR 提前关断防倒灌。
- **假负载**：轻载时反激能量传输在 DCM 下使输出电压漂高（尤其辅路），需最小预载或跳周期控制。
- **多路输出交叉调整**（详见 1.11）：耦合不好→辅路电压随主路负载漂移 20%+；三明治绕法+加权反馈是基本对策。

### 8.5 PSR 原边反馈与恒流恒压（P156–P160）

- **PSR（Primary-Side Regulation）**：省去光耦+TL431，用辅助绕组在副边续流期间采样反射电压（消磁时间内的采样点），直接在原边完成 CV 调节；恒流通过原边峰值电流 × 消磁时间比例控制。优点：省 BOM、超小体积（充电器）；缺点：输出精度受漏感影响（±3%~±5%）、动态响应慢。
- **恒流环（CC）实现**：峰值电流模本身就是逐周期限流，把误差放大器钳位到恒定值即成恒流源——LED 驱动反激即此原理。
- **线缆压降补偿**：充电器在输出端并联补偿电阻抬升空载电压抵消线阻压降。
- **保护设计**：逐周期 OCP + 打嗝模式短路保护 + 辅绕组 OVP + OTP（NTC 或芯片结温）。

## 第九章 正激变换器（Forward）（P63–P66、P161–P166）

### 9.1 正激的工作原理（P63、P161）

正激是"真变压器"：开关导通时原边电压感应到副边，能量**同时**传递到输出（经 LC 滤波），与 Buck 类似，只是插入了变压器与隔离。

- 副边侧波形 = 降压后的方波，LC 滤波器承担储能与滤波——**输出纹波小**是正激相对反激的核心优势。
- 增益 Vo = Vin·D·(Ns/Np)，D 通常限制在 0.45 以内（留复位时间）。
- 磁芯单向磁化（同反激），必须复位。

### 9.2 磁复位方案对比（P64、P162）——正激设计的核心

- **第三绕组复位**：增加复位绕组（同绕向反接），关断时励磁能量回馈电源。优点：无损耗、可靠；缺点：D<0.5 限制、变压器多一个绕组。最经典方案。
- **RCD 复位**：RCD 吸收励磁能量，D 可 >0.5，但损耗大、且复位电压随负载变化，少用于主复位。
- **有源钳位正激**：辅助 MOS+电容复位磁芯并把励磁能量回馈，同时实现主管 ZVS、D 可 >0.5——高效方案，与有源钳位反激共享技术生态。
- **谐振复位/双管正激**：双管正激（两管串接+两只钳位二极管）把开关应力降为 Vin，无复位绕组（钳位二极管自动复位），适合高压大功率（如 400V 输入 300–800W），是通信电源经典结构。

### 9.3 输出滤波与同步整流（P65、P163–P164）

- **输出电感**：与 Buck 输出电感同设计逻辑，纹波系数 20–30%；电感电流连续，正激输出电容应力远小于反激。
- **续流二极管/同步管**：副边三个器件（整流、续流、钳位）损耗在低压输出占比高，5V/12V 大电流输出必须同步整流；正激 SR 时序比反激复杂（整流管与续流管交替）。
- **磁通平衡**：电流模控制天然抗偏磁；电压模正激需注意励磁电流累积。

### 9.4 正激 vs 反激选型（P66、P165–P166）

| 维度 | 反激 | 正激 |
|---|---|---|
| 功率范围 | <150W（快充可到 300W） | 100–500W |
| 元件数 | 最少（无输出电感） | 多（输出电感+复位） |
| 输出纹波 | 大（电容滤波） | 小（LC 滤波） |
| 多路输出 | 天然容易 | 需多绕组+各路电感 |
| 变压器体积 | 大（储能） | 小（真变压） |
| 效率 | 中 | 较高 |
| 典型应用 | 充电器、辅源、小功率 | 通信电源、适配器、工业电源 |

## 第十章 半桥变换器（P67–P70）

### 10.1 半桥结构（P67）

两只开关串联跨接母线，变压器原边接两管中点，副边通常全波/全桥整流+LC 滤波。

- 原边电压幅值 = Vin/2（被分压电容钳位），开关应力 = Vin——**耐压减半是半桥的核心优点**。
- 原边电流是双向交流，磁芯双向磁化，**ΔB 利用率翻倍**，变压器比同功率正激小一半。
- 分压电容中点漂移天然抗偏磁；串联隔直电容进一步保险。

### 10.2 驱动与控制（P68）

- 上下管互补驱动 + 死区（防直通）；高侧驱动用自举或隔离变压器/隔离驱动器。
- PWM 调制：两管同时开关（对称半桥，D<0.5），Vo = (Vin/2)·D·(Ns/Np)（副原匝比）。
- 副边：全波整流（中心抽头）适合低压大电流，全桥整流适合高压输出；LC 滤波同正激。

### 10.3 半桥谐振的过渡——LLC 的引入（P69–P70）

- 硬开关半桥的开关损耗与副边整流反向恢复限制频率提升。
- 半桥 LLC：在原边串入谐振电感 Lr 与谐振电容 Cr，变压器励磁电感 Lm 参与谐振：
  - fs = fr（谐振点）：纯阻性，ZVS+副边 ZCS，增益=1；
  - fs < fr：增益 >1（Boost 区），ZVS 保持；
  - fs > fr：增益 <1，ZCS 丢失。
- **调频调增益**（PFM）替代 PWM，增益范围由 Q（负载）与 k=Lm/Lr 决定；轻载增益失控是 LLC 设计难点（Burst 模式解决）。
- LLC 是 300W–3kW 高效率电源（服务器、适配器、储能）的事实标准。

## 第十一章 全桥变换器（P71–P74）

### 11.1 全桥结构（P71）

四管 H 桥，变压器接桥中点，原边电压幅值 = Vin（全部母线电压），同功率下原边电流比半桥小一半——**大功率首选**（>1kW）。

- 副边全桥/全波整流+LC；输出电感电流大，续流回路设计重要。
- 磁芯双向磁化，ΔB 全利用。
- 四管驱动的隔离/自举方案成本高，控制复杂度最高。

### 11.2 相移全桥 ZVS（P72–P73）——大功率软开关经典

- **移相调制**：四管恒定 50% 占空比，超前臂与滞后臂之间相移角 φ 控制有效占空比。
- **ZVS 原理**：换相时利用变压器漏感（或外加谐振电感）的能量把开关节点电压抽空，实现零电压开通：
  - 超前臂：负载电流换向，能量充足，宽负载范围 ZVS；
  - 滞后臂：仅靠励磁+漏感能量，**轻载丢 ZVS**——加辅助谐振网络/饱和电感/加大励磁电流对策。
- **占空比丢失**：谐振电感使换相期间原边电流爬坡，副边整流短路期（有效占空比丢失），需匝比补偿设计。
- **副边整流问题**：输出电感续流期间整流管同时导通（环流），同步整流需智能时序；反向恢复应力大。
- 应用：通信电源模块、充电桩模块、电焊机——kW 级效率 94%+。

### 11.3 全桥的其他调制方式（P74）

- **双极性/单极性调制**：单极性调制纹波频率倍增、纹波幅值减半，输出滤波更小。
- **全桥 LLC**：kW 级以上软开关+同步整流的最高效率路线；CLLC 支持双向（V2G、储能）。

## 第十二章 电源设计方法（P75–P84、P173–P180）

### 12.1 电源设计总体流程（P75–P76）

一个完整开关电源项目的设计顺序：

1. **规格定义**：输入范围（AC 85–265V / DC 范围）、输出电压电流组、效率目标、纹波噪声指标、瞬态指标、保护需求、安规认证（CCC/UL/CE）、EMC 标准（CISPR 32/25）、尺寸与成本约束。
2. **架构选择**：单级（反激，<150W）or 两级（PFC+LLC/正激，>150W）；隔离 or 非隔离；多路输出方案。
3. **关键参数计算**：母线电压、反射电压/匝比、占空比范围、电流应力、磁芯初选。
4. **器件选型**：开关管、整流管、磁件、电容、控制器、反馈器件——每项核算应力降额（电压 80%、电流 80%、结温 110°C 以下）。
5. **环路设计**：建模（小信号传函）→ 补偿网络 → 验证稳定裕度（第十九章）。
6. **原理图评审**：保护链路完整性、软启动、时序、去耦、反馈走线。
7. **Layout**（第十四章）→ **打样 → 测量**（第十五章）→ **整改（EMC，第二十章）→ 温升与老化测试 → 量产文件。

### 12.2 规格书到设计参数的转换（P77–P78）

- **输入范围与母线电容**：AC 输入下，母线电容按保持时间（Hold-up 10–20ms）与纹波要求折算：C = 2·Po·t/(η·(Vmax²−Vmin²))。母线谷值电压决定后级最大占空比。
- **效率预算表**：把 1−η 按环节分配（整流 2%、PFC 4%、变压器/磁件 3%、开关管 3%、输出整流 4%、辅助 1%…），逐项对标实现，这是"预算式设计"思想。
- **降额设计**：电容额定纹波电流降 20%、二极管结温降额、MOS Vds 降 20%、光耦 CTR 按寿命末期核算——可靠性出自降额。

### 12.3 器件应力核算清单（P79–P80）

对每个功率器件建立"应力表"：

- 反激开关管：Vds,max = Vin,max + Vor + Vspike（钳位后），Id,rms、Id,pk、结温。
- 输出二极管：反激 Vrrm = Vo + Vin/n（n = Np/Ns）；正激 Vrrm = Vo + Vin·(Ns/Np)（关断时原边电压反射到副边）。Iavg、If,rms 逐项核算。
- 输入整流桥：浪涌电流（冷启动峰值）、平均电流与导通损耗、散热器。
- 母线电容：纹波电流 RMS（低频 100Hz 分量 + 高频开关分量，两者折算相加）、电压降额 80%。

### 12.4 磁件初步设计（P81–P82，详见第十七章）

- 初选磁芯：按面积乘积法 Ap = (Lp·Ipk·ΔB/(Bmax·J·Ku))^… 或按厂家 AP 表估算。
- 匝数确定：Np = Lp·Ipk/(Bmax·Ae)；气隙 lg = µ0·Np²·Ae/Lp − l_core/µr。
- 校核窗口面积、绕组层数、趋肤深度（Δ=66/√f mm，铜线直径 ≤2Δ 或用利兹线）。

### 12.5 PCB 与结构协同（P83–P84）

- 功率密度与散热：自然对流 vs 风冷 vs 灌封；外壳开孔与烟囱效应。
- 安规距离落地：一次/二次爬电 ≥6.4mm（加强绝缘、污染等级 2）、Y 电容位置、变压器三重绝缘线。
- 接地体系：一次地、二次地、Y 电容连接点、母线电容中点接地（EMC 关键）。

## 第十三章 电源设计仿真（P85–P92、P181–P185）

### 13.1 仿真工具与层次（P85–P86）

- **器件级 SPICE（LTspice/SIMPLIS/PSIM/Saber）**：开关波形、应力、损耗精确，速度慢。
- **平均模型（CCM/DCM averaged model）**：把开关周期平均掉，环路频域分析（伯德图）用，配合 PSpice/TI-Tina 的平均模型库。
- **SIMPLIS**：分段线性快速开关仿真，开关电源环路与瞬态仿真的工业利器，速度比 SPICE 快百倍。
- **Mathcad/Excel 设计计算** + **厂家设计工具**（TI PowerStage Designer、MPS设计师、ON Semi 设计表）：初值快算。

### 13.2 开关波形仿真要点（P87–P88）

- 设置正确的器件模型：MOS 用带 Coss/trr 的实际模型，磁件用含漏感/励磁电感的耦合电感模型。
- 步长与收敛：开关沿 1ns 级步长；用 .options 收敛参数；理想化变压器先行、实际模型复验。
- **必须仿真的场景**：启动（软启动波形、浪涌电流）、稳态（各点电压电流应力与设计值对照）、负载阶跃（10%↔100% 瞬态跌落/过冲）、输入跌落（AC drop test）、短路（打嗝恢复）、开环故障（OVP 动作）。

### 13.3 环路频域仿真（P90–P92）

- 平均模型下做 AC 扫描，获取增益/相位曲线，验证穿越频率 fc、相位裕度 PM>45°（目标 60°）、增益裕度 GM>10dB。
- 验证音频敏感度（AS）与输出阻抗（闭环）——直接对应输入纹波抑制与负载瞬态。
- 电流模需加斜坡补偿后的等效模型；PSR/QR 变频系统用变周期平均模型近似。

### 13.4 仿真与实测的对照方法（P181–P185）

- 仿真先行的正确用法：**趋势与比例**（哪个参数影响哪个指标）而非绝对精度；实测差异来自寄生（布局电感/电容）、器件容差与模型误差。
- 建立"设计→仿真→实测"三点对照表，逐项闭环修正，沉淀为个人/团队的设计规则库——这是训练营强调的工程方法论。

## 第十四章 开关电源 PCB 布局（P93–P96）

> 本章是训练营中时长最长的实操章节（四讲合计超过 2 小时），核心思想：**布局先于一切**——纸面设计再好，布局失败则全部归零。

### 14.1 电流回路思维（P93）

布局的第一性原理：**所有电流都是回路**。交流回路（di/dt 大的环路）面积必须最小。

- **Buck 三大关键环路**：
  1. 输入环路（输入电容→上管→下管→地→输入电容）：di/dt 最大的"热回路"，输入电容必须距开关管最近；
  2. 输出环路（电感→输出电容→地）；
  3. 驱动环路（驱动器→栅极→源极→驱动地）。
- **反激关键环路**：原边环路（母线电容→变压器原边→开关管→采样电阻→地）、副边环路（副边绕组→整流管→输出电容→地）、钳位环路（RCD）——每个环路都是辐射天线。
- **降低环路面积的手段**：叠层平面（功率地平面正对功率走线）、电容跨接在环路两端、母线电容紧贴开关器件、铜排/平行窄缝设计。

### 14.2 接地系统设计（P93–P94）

- **单点接地 vs 平面接地**：小功率单点串联回地；中大功率必须完整地平面 + 分区。原则：**功率地、驱动地、信号地、模拟地分区，最后在单点（通常母线电容负端或芯片 GND）汇接**。
- **电流采样线**：开尔文（Kelvin）四线接法，采样电阻的检测走线直接从电阻本体焊盘引出，避免功率电流流经检测路径产生误差。
- **反馈走线**：分压中点走线远离开关节点/电感，远离变压器漏磁；光耦下方铺净地。
- **芯片 AGND/GND 处理**：芯片 GND 引脚单点连功率地，模拟部分局部净地岛。

### 14.3 关键节点与寄生控制（P94–P95）

- **开关节点（SW/漏极）**：铜面积在"散热"与"辐射天线"之间权衡——够散热即可，避免大面积开关节点铜皮；电感紧邻开关节点，缩短高 dv/dt 走线。
- **寄生电感的代价**：1nH @ 10A/10ns → 1V 尖峰；漏极走线每 mm 都在制造尖峰与 EMI。对策：粗短直、多层并联过孔（过孔阵列）、母线电容紧贴。
- **寄生电容的代价**：变压器绕组层间电容、MOS 输出电容的充放电回路流经地平面→共模干扰路径（EMC 章节深化）。
- **Y 电容位置**：跨接一次地与二次地，位置决定共模电流回流路径——放在变压器与母线电容中点之间，让共模电流就地闭合，不流过输出线缆。

### 14.4 热设计布局（P95）

- 发热件（开关管、整流管、采样电阻、变压器）分散布置，避免热点叠加；热源远离电解电容（寿命杀手）。
- 大铜皮散热：器件铜垫延伸铺铜 + 热过孔阵列（0.3mm 孔、阻焊塞孔）连接到底层大平面——与 MPS 电机驱动指南同源。
- 风冷设计：进风口→热源排布→出风口按"低温→高温"顺序（先低压后高压/先小信号后功率），避免前级加热后级。
- 温度实测点预留：NTC 位置贴近热点（变压器绕组/散热器），布局预留测温孔。

### 14.5 安规与工艺布局（P96）

- 爬电距离/电气间隙：一次侧对二次侧 ≥6.4mm（加强绝缘），一次侧高压对地按工作电压查表；板边开槽（slot）增加爬电。
- 变压器引脚、光耦、Y 电容是"跨隔离带"元件，隔离带下不走任何信号线。
- 大电流过孔计算：1oz 铜一个 0.3mm 过孔约 1–2A，并联阵列设计；母线用铜排或厚铜。
- 器件间距与返修空间：SMT 钢网、波峰焊阴影、手工焊工具空间——DFM 检查。

## 第十五章 开关电源测量（P97–P105）

### 15.1 测量仪器与探头基础（P97）

- **示波器带宽选择**：≥3–5 倍被测信号最高频率；测量开关沿（10–50ns）需要 100MHz+；测 SW 节点振铃要看 200MHz+。
- **探头**：10:1 无源探头（高压信号，注意补偿校准）、高压差分探头（浮地/桥式测量，带宽与共模抑制比是关键指标）、电流探头（霍尔+Rogowski，低频精度 vs 高频带宽）、隔离示波器通道（注意浮地测量安全）。
- **探头接地弹簧**：长地线=环形天线，开关测量必须用短接地弹簧，否则测到的"振铃"一半是探头自己拾取的。
- **万用表/功率分析仪**：效率测量必须用功率分析仪（四端、宽带宽、0.1% 级精度），万用表测 AC 功率误差巨大（波形因数/ crest factor 影响）。
- **LCR 表、耐压仪（Hipot）、绝缘电阻表**：磁件验证与安规测试。

### 15.2 关键波形测量方法（P98–P99）

- **SW 节点**：看占空比、电压应力（尖峰幅度 vs 器件耐压裕量）、死区、振铃频率（诊断漏感/寄生）。
- **栅极波形**：平台（米勒）高度与宽度、驱动幅度、关断负压、直通风险（桥式上下管波形叠加对比）。
- **电感/变压器电流**：电流探头看纹波、峰值、CCM/DCM 边界、励磁电流饱和迹象（斜率变陡）。
- **输出纹波测量规范**：20MHz 带宽限制 + 探头接地弹簧 + 摘掉长地线；纹波（开关频率成分）与噪声（高频毛刺）分开评估；AC 耦合。
- **动态响应测量**：电子负载编程跳变（如 0.1A↔5A @ 0.1A/µs），捕捉过冲/跌落幅度与恢复时间；对照环路带宽预期（tr≈0.35/fc）。
- **启动/保护波形**：软启动曲线、浪涌电流包络、短路打嗝周期、OVP/OCP 动作点与恢复。

### 15.3 效率与热测量（P100–P101）

- **效率测量**：功率分析仪输入/输出四线接法；报告要注明测量点（输入插座/PCB 端子）与环境；分段负载（10%–100%）绘效率曲线。
- **温度测量**：热电偶（T型/K型）贴关键器件（绕组、二极管、电解电容壳温）；热像仪扫板找热点；记录环境温度与气流条件；对照器件规格降额线。
- **纹波电流分解**：电解电容支路串电流探头，看低频（100Hz）与高频开关分量，对照额定值。

### 15.4 环路特性实测（P102–P103）

- **增益相位分析仪（Bode 100、频响分析仪）**：注入电阻（5–20Ω）串入反馈分压下端，注入电平保持 <输出纹波的 1/5（线性区），扫频 10Hz–1MHz。
- 读出穿越频率、相位裕度、增益裕度；**实测伯德图是环路设计的最终验收**，与仿真对照修正补偿网络。
- PSR/无直接反馈采样点的电源（无注入点）用输出阻抗法或阶跃响应反推。

### 15.5 EMI 预测试与整改测量（P104–P105，详见第二十章）

- 近场探头（磁场 H/电场 E）定位辐射源；LISN+接收机做传导预测试。
- 整改迭代顺序：定位源→判断差模/共模→加/改滤波或吸收→复测。建立"测量→定位→整改→验证"闭环。

## 第十六章 功率因数校正 PFC（P12、P143–P151）

### 16.1 为什么要 PFC（P12、P143）

- 直接整流+电容滤波的输入电流是窄脉冲（导通角仅 2–3ms），PF≈0.5–0.65：视在功率大、线路损耗大、谐波污染电网（三次谐波使中性线过载）。
- 强制标准：IEC 61000-3-2（谐波电流限值），>75W 的电源必须处理谐波——PFC 是合规刚需。
- PF = cosφ₁·(I₁/Irms)：位移因数×畸变因数。PFC 的任务是让输入电流波形贴合正弦电压。

### 16.2 Boost PFC 拓扑与工作模式（P144–P145）

- **Boost PFC 是绝对主流**：电感串在输入侧（电流连续好整形）、输出母线 ~400V、开关应力=母线电压。
- **CRM/BCM（临界模式）**：谷底开通，频率随负载/电压变化，电感小、二极管无反向恢复，适合 <300W；缺点频谱变化 EMI 难。
- **CCM（连续模式）**：恒频、纹波小、适合 >300W；升压二极管反向恢复是大问题——SiC 二极管几乎是标配。
- **无桥 PFC**：省去整流桥损耗（~2% 效率收益）：图腾柱（Totem-Pole）无桥 PFC 配 GaN/SiC 是当前高效率方案（98%+），双 Boost 无桥为过渡方案。

### 16.3 控制实现（P146–P147）

- **双环结构**：内环电流环（整形电流，带宽 5–10kHz）+ 外环电压环（稳母线，带宽 10–20Hz——刻意压低，避免二次谐波失真注入电流基准）。
- **平均电流模**：电流环带宽足够时 THD<5%；乘法器把电压环输出与整流正弦采样相乘生成电流基准。
- **单周期控制（OCC）/ 谷底包络 / 临界模式无需乘法器**：简化控制的低成本方案。
- **母线二次谐波问题**：P 输出含 100Hz 脉动，电压环带宽低抑制之；快速负载响应需前馈或储能解耦方案。

### 16.4 器件与磁件设计（P148–P150）

- **PFC 电感**：CCM 下 ΔB 由纹波电流决定（铁粉芯/铁硅铝环形磁芯常用，饱和特性软、容错好）；CRM 下高频大 ΔB 用铁氧体。
- **开关管与二极管**：CCM 用低 Qg 管+SiC 二极管；CRM 用低 Rds(on)+快恢复即可。
- **母线电容**：承担 100Hz 纹波电流（大）+ 开关频率纹波；容量由 hold-up time 与电压纹波折算；450V 额定/400V 工作的降额。

### 16.5 PFC 的保护与异常（P151）

- 母线过压（负载突卸）、过流、输入欠压（Brown-out）、过温；轻载母线控制（跳周期防止母线漂高）。
- 浪涌与雷击防护链（MOV+GDT+串联电感）在 PFC 前级。
- 起动时序：母线预充（NTC/旁路继电器）→ PFC 启动 → 后级 DC-DC 启动，避免 PFC 带载启动过流。

## 第十七章 电源中的磁性元件设计（P122–P131）

> 磁件是开关电源里最"玄学"的部件——既是储能核心，又是损耗与噪声大户，也是定制成本最高的器件。本章十讲从物理到工程完整展开。

### 17.1 磁学基础（P122）

- **基本关系**：B = µ·H（µ=µ0·µr）；安培定律 N·I = H·le；法拉第定律 V = N·dΦ/dt = N·Ae·dB/dt。
- **电感的本质**：N 匝绕在磁路上的储能元件，L = N²·AL（AL 为磁芯电感系数）；储能 E = ½·L·I² = ½·B·H·V_core。
- **饱和**：B 超过 Bsat 后 µ 骤降→电感量消失→电流失控。铁氧体 Bsat≈0.3–0.4T（100°C 时降至 ~0.3T，**热态饱和**必须按高温核算！），铁粉芯 1.0–1.5T，铁硅铝 1.0T，非晶/纳米晶 1.2T+。
- **气隙的作用**：把 B-H 回线"放扁"——降低有效磁导率、提高抗饱和能力、储能主要存于气隙（气隙储能占比 >90%）；代价是边缘磁通（fringing）造成附近绕组涡流损耗。
- **B-H 回线与损耗**：回线包围面积=每周期磁滞损耗；µr 随频率/温度/偏置变化。

### 17.2 磁芯材料与形状（P123）

- **铁氧体（MnZn）**：高频损耗最小（25–500kHz 最优），Bsat 低，是开关变压器主力；PC40/PC95/3C95/3C97 等牌号按频率与温升选。
- **铁粉芯**：分布式气隙、软饱和、便宜，PFC 电感与差模电感常用；损耗较大。
- **铁硅铝（Sendust/FeSiAl）**：损耗介于铁粉芯与铁氧体之间，PFC/储能电感主力。
- **高频高 Bsat**：非晶、纳米晶（Bsat 1.2T、高频损耗低）——大电流共模电感与中频变压器。
- **形状选择**：E/E（通用便宜）、ETD（绕组空间均匀）、PQ/PM（大功率屏蔽好）、罐形（屏蔽极好绕线难）、环形（无漏磁绕线难）、平面 E（低高度、寄生参数一致、适合平面变压器）。

### 17.3 变压器设计流程（P124–P125）

以反激为例（其他隔离拓扑同理）：

1. **确定 ΔB 或电流纹波比**：反激按 Lp 与 Ipk；正激/桥式按伏秒与工作频率（ΔB 取 0.1–0.2T 铁氧体 @100kHz，频率升高 ΔB 按损耗曲线下降）。
2. **初选磁芯**：面积乘积法 Ap = (Lp·Ipk·ΔI/(ΔB·J·Ku))^(4/3) 或按"功率-频率-磁芯"经验表；比 AP 法更实用的是厂家"伏秒-温升"曲线。
3. **原边匝数**：Np = Lp·Ipk/(Bmax·Ae)（储能式）或 Np = Vin·D·T/(ΔB·Ae)（伏秒式）。
4. **气隙**：lg ≈ µ0·Np²·Ae/Lp（中心柱气隙）；考虑边缘磁通修正系数。
5. **副边匝数**：按匝比 n=Ns/Np（反射电压折中确定）取整——匝比取整后**回头修正 Vor、Vds 应力与 D 范围**（迭代环节）。
6. **绕组结构**：电流密度 J 取 4–6A/mm²（自然冷）或 8–10A/mm²（风冷）；趋肤深度 Δ=7.65/√f(cm)（铜 @100°C），线径 ≤2Δ 或利兹线；层数与绕法决定漏感与层间电容。
7. **校核**：窗口充满率（<70%）、温升（磁损+铜损的热阻法或厂家曲线）、D 铜损交流因子 Fr（Dowell 曲线）。

### 17.4 漏感与绕组技巧（P126–P127）

- **漏感来源**：原副边绕组没有共享的磁通；分层交错绕（三明治：原边一半→副边→原边一半）可把漏感降到非交错的 1/4–1/10。
- **漏感的代价**：关断电压尖峰（需钳位/吸收）、占空比丢失（桥式）、ZVS 能量（相移全桥反而是资源）。
- **层间电容**：多层层绕电容大→开关节点 dv/dt 电流注入（共模 EMI 源）；对策：Z 形绕法、屏蔽绕组（铜箔屏蔽层接地）。
- **邻近效应**：多层绕组交流电阻暴涨（层数指数增长），用利兹线、扁铜线、减少层数、交错绕法对抗；Dowell 公式估算 Fr。
- **边缘磁通损耗**：大气隙时气隙附近的绕组涡流损耗集中——气隙分散（多点小气隙）或气隙远离绕组。

### 17.5 共模电感（P128）

- 共模电感：两绕组同相绕在同一磁芯，差模电流磁通抵消（不饱和），共模电流磁通叠加→高阻抗阻断。
- 材料用高 µr（纳米晶/高磁导率铁氧体），差模电感量（漏感）是免费附赠的差模滤波。
- 设计矛盾：匝数多→共模阻抗大但漏感大/绕组电容大（谐振点下移）；多级共模滤波器级联解决宽带插入损耗。

### 17.6 磁件损耗与温升（P129–P131）

- **磁芯损耗**：Steinmetz：Pv = k·fs^α·ΔB^β（mW/cm³），厂家给曲线族——设计流程是"选定温升目标→从曲线反推允许 ΔB→再定匝数"（损耗限制设计法，比饱和限制更常成为约束）。
- **铜损**：直流 I²R + 交流（趋肤+邻近）Fr·Iac²·Rdc；反激/正激副边梯形电流谐波丰富，Fr 要按谐波展开逐项计算（谐波叠加法）。
- **温升估算**：ΔT = P_total/(热阻)，环形磁芯热阻经验式或厂家"损耗-表面积-温升"曲线；40K 温升是常规定义。
- **测试验证**：LCR 表测感量（含偏流源测增量磁导）、短路法测漏感、伏秒积测试（V·t 饱和裕量）、温升实测（绕组电阻法：铜阻温升系数 0.393%/°C 换算）。

## 第十八章 功率半导体器件（P133–P138）

### 18.1 MOSFET 结构与参数（P133–P134）

- **垂直 MOS 结构**：源-漏间导通靠沟道+外延层电阻；耐压越高外延层越厚越阻——Rds(on) 随耐压 ~2.5 次方增长，这就是"高压 MOS 贵且差"的物理根源。
- **超结（SuperJunction）**：P/N 柱交替补偿电荷，打破上述定律，600–900V 的 Rds(on) 降一个量级；代价：Coss 大且强非线性、体二极管 trr 慢（硬开关桥式慎用）、dv/dt 敏感。
- **栅极电荷 Qg/Qgd**：Qgd（米勒电荷）决定开通平台时长与 dv/dt 抗扰；驱动损耗 P=Qg·Vgs·fs。
- **Coss 与 ZVS**：Coss 储能 ½·Coss·V² 在硬开关时损耗、在 ZVS 时参与谐振；非线性 Coss 使谐振设计复杂。
- **体二极管**：反向恢复电荷 Qrr 是桥式直通/损耗/EMI 的元凶；同步整流的死区设计要考虑其导通窗口。
- **封装与热**：TO-220/TO-247 引脚电感大，DFN/TO-Leadless/顶散热（Top-Cool）封装把 Rθjc 从 1°C/W 降到 0.2–0.5°C/W；开尔文源极封装消除源极电感，开关速度大幅提升。

### 18.2 IGBT 与 SiC/GaN（P135–P136）

- **IGBT**：电导调制使其高压大电流导通压降低（Vce,sat 1.5–3V），但拖尾电流限制频率 <50kHz（一般 8–30kHz）；适合大功率低速（电机驱动、感应加热、光伏集电）。
- **SiC MOSFET**：10 倍场强→薄外延→高压低损耗+高温（200°C 结温潜力）；无体二极管拖尾问题（body diode 恢复快）；驱动需负压关断+更低 Rg；用于 PFC、光伏逆变器、充电桩、车载 OBC。
- **GaN HEMT**：横向器件，无体二极管（反向导通压降为正——"同步自续流"）、Qg 极小、开关沿 <2ns；驱动敏感（dv/dt >100V/ns 的回路设计、栅压窗口 ±6V 级）；用于高频 LLC、图腾柱无桥 PFC、USB-PD 高密度。
- **选型决策**：频率 >300kHz 或高密度→GaN；>650V 大功率→SiC；成本敏感中低频→Si 超结/普通 MOS；工频大电流→IGBT 仍有性价比。

### 18.3 驱动电路设计（P137）

- **驱动强度**：Rg 控制开关速度——开通快（损耗小 EMI 大）、关断快（尖峰大）；分离 Rgon/Rgoff 独立调节；米勒平台时间估算 tr = Qgd/Ig。
- **高侧驱动**：自举（简单，受占空比/频率限制）、隔离电源+数字隔离器（高性能）、驱动变压器（传统，占空比范围受限）。
- **抗 dv/dt 误开通**：米勒电流 × 下管共源阻抗产生正向压降——负压关断、米勒钳位、开尔文源极、低 Cgd 器件选型四管齐下。
- **驱动损耗链**：驱动 IC 损耗 + 自举二极管损耗 + 栅电阻损耗，高频高压下需专门核算。

### 18.4 器件失效模式（P138）

- **过压击穿**（雪崩）：漏极尖峰超 Vds 额定——吸收电路/降额/慢关断对策。
- **过流/短路**：MOS 短路耐受 ~10µs，必须逐周期保护+软关断（大 Rg 关断削尖峰）。
- **过热**：热失控（Rds(on) 正温度系数——并联均流安全；二极管 Vf 负温度系数——并联不均流！）。
- **dv/dt 误开通导致的桥臂直通**：硬开关桥式的隐形杀手。
- **门极氧化层失效**：栅压超限（±20V 一般），ESD 与浪涌防护。

## 第十九章 非隔离电源的控制与实现（P167–P172）

### 19.1 控制系统基础（P167）

- **负反馈三要素**：采样（分压）、基准（误差比较）、执行（PWM/开关）。控制目标是：稳（稳定裕度）、准（精度）、快（响应）。
- **小信号建模思想**：把开关周期平均化，得到线性化传函——Buck 功率级是低通双极点（LC 谐振峰），Boost/Buck-Boost 含 RHPZ 单极点系统多一个零点。
- **衡量稳定的判据**：开环伯德图上 PM>45°（实用 60°）、GM>10dB、穿越斜率 −20dB/dec（避免 −40 穿越）。

### 19.2 电压模式控制（P168）

- 结构：误差放大器输出 Ve 与固定锯齿波比较，产生占空比。
- **优点**：单环简单、抗噪强（锯齿波幅度大）、多路输出均流实现直观。
- **缺点**：输入扰动要等输出变化后才被纠正（音频抑制差）、对 LC 谐振峰需要 Type-III 补偿（复杂）、无天然限流。
- 补偿设计：Type-III（两个零点抵消 LC 双极点、一个极点抵消 ESR 零点、高频极点衰减开关噪声）。

### 19.3 峰值电流模式控制（P169–P170）

- 结构：外环电压误差放大器设定电流阈值，内环逐周期比较电感电流（采样电阻/电流镜/RCM 采样）。
- **优点**：电感电流被"即时受控"——等效功率级降为一阶（单极点），Type-II 补偿即可；天然逐周期限流；输入前馈（输入变化立即反映到电流斜率）；多相均流容易。
- **次谐波振荡**：D>0.5 时电流扰动逐周期放大——**斜率补偿**（叠加下斜坡到电流信号或减小上斜坡）是必修对策。
- **采样问题**：峰值控制实际采的是峰值而非平均值，轻载 DCM 时平均增益变化；平均电流模（运放积分电流环）解决精度问题但带宽低。
- 实用变体：恒定导通时间（COT）、谷值电流模、迟滞电流模。

### 19.4 补偿器设计流程（P171）

1. 画功率级传函（解析或仿真提取）；
2. 选穿越频率 fc：Buck 可 fs/10~fs/6；Boost/Buck-Boost 受 RHPZ/3 限制；隔离电源受光耦带宽与右半平面零点共同限制（常 1–5kHz）；
3. 布置补偿零极点：零点在 1/2 fc 附近抬相位，极点在 fs/2 附近压噪声；Type-II/III 网络计算 R、C 值；
4. 验证：PM、GM、低频增益（稳压精度）、中频增益（抗扰）；
5. 实测伯德图复核（第十五章方法）。

### 19.5 数字控制与特殊控制（P172）

- 数字电源（DSP/MCU/专用数字控制器）：PID/状态机实现、系数在线可调、非线性控制（变带宽）、故障记录与遥测——中高端电源趋势。
- COT/恒定导通时间：无误差放大器补偿设计、瞬态极快，中频段增益平坦度差，适合大动态 CPU 供电。
- PSR 反激的"原边控制"（第八章）：控制在一次侧完成，是隔离控制的特殊实现。

## 第二十章 电磁兼容 EMC（P106–P115、P186–P197）

> EMC 是开关电源的"第二场考试"——功能做出来只是及格线，EMC 达标才能上市。本章 24 讲是课程最大篇幅。

### 20.1 EMC 基础框架（P106、P186）

- **EMC 三要素**：干扰源（开关 dv/dt、di/dt）、耦合路径（传导/辐射）、敏感设备。整改就是切断任意一环。
- **传导干扰频段 150kHz–30MHz**（沿电源线传播），辐射 30MHz–1GHz（空间场），标准 CISPR 32（信息技术）、CISPR 25（车载）、IEC 61000（抗扰度）。
- **噪声的两种模式**：
  - 差模（DM）：火线↔零线回路电流，源是开关环路电流；
  - 共模（CM）：线对地电流，源是开关节点 dv/dt 通过寄生电容（变压器层间、散热器）对地的位移电流。
- **诊断方法**：用电流探头分别测火/零线相位相关性——两线同向=共模，反向=差模；或用 LISN 的 CM/DM 分离器。

### 20.2 传导 EMI 的机理（P107、P187）

- 开关节点 dv/dt 经变压器层间电容 Cps 流向副边→经 Y 电容回流一次侧→进入 LISN：这是**共模主导路径**。
- 开关电流脉冲（原边梯形波）在输入环路中流动：**差模主导路径**，频谱集中在开关频率及其谐波，低频段（150k–2MHz）差模占优。
- 二极管反向恢复产生高频振铃（1–30MHz 尖峰带），是传导中高频段的常见超标源。
- 频谱包络规律：梯形波 −40dB/dec 包络，沿越快高频越差；减缓开关沿=最根本的高频降噪（但要平衡效率）。

### 20.3 EMI 滤波器设计（P108、P188）

- **滤波器结构**：共模电感（X 电容跨线差模 + Y 电容对地共模 + 共模电感阻断共模）；两级级联扩展高频插入损耗。
- **X 电容**：跨火零线，滤差模，容值 0.1–2.2µF 常见；**Y 电容**：一次二次地之间/线对地，滤共模，受漏电流安规限制（≤0.25–0.75mA 医疗/IT 不同），一般 1–4.7nF。
- **插入损耗设计法**：测"裸电源"噪声谱→按超标裕量+6dB 设计滤波器转折频率→计算 LC 值→校核阻尼（滤波器输入阻抗/输出阻抗匹配防谐振放大，源-滤波器交互稳定性！）。
- **滤波器磁芯饱和**：共模电感的差模漏感成分要承受全部差模电流，大电流时共模磁芯差模饱和→插入损耗崩塌；核对差模电流下的阻抗跌落。

### 20.4 辐射 EMI 与近场定位（P109、P189–P190）

- 辐射源：**小环天线（di/dt 回路）** 与 **单极子天线（dv/dt 导体）**。30–100MHz 超标常来自电缆（共模电流驱动电缆天线）；100–300MHz 常来自开关节点/散热器。
- **近场探头定位**：磁场环探头找电流环（贴近走线找最大点）、电场杆找高 dv/dt 节点；先定位频率（用频谱仪/接收机标记峰值），再空间扫描定位源。
- **共模电流测量**：电流探头卡整束线缆测共模电流，与辐射限值有经验对应关系（μA 级共模电流可导致 dB 级辐射超标）——"控共模电流即控辐射"。

### 20.5 整改技术工具箱（P110–P111、P191–P194）

按优先级排列（源头→路径→末端）：

1. **减缓开关沿**：Rg 增大、减缓驱动、GaN 的可编程沿；沿每慢一倍，高频包络降 6–12dB。
2. **吸收/缓冲**：RC 吸收二极管振铃（按振铃周期定 C：C≈1/(2π·fr·Z)，R 按阻尼）、RCD 钳位漏感尖峰、缓冲变压器谐振。
3. **降低 dv/dt 节点面积**：开关节点铜皮最小化、散热器接地/加屏蔽板、变压器绕组加屏蔽层。
4. **环路面积最小化**（第十四章布局原则——80% 的 EMI 问题其实是布局问题）。
5. **Y 电容调整**：加大/移动 Y 电容位置改变共模回流路径；双 Y 电容（一次侧+二次侧各一个）分流。
6. **加粗滤波器/加级**：一级不够上两级；注意谐振阻尼与低频稳定性。
7. **屏蔽**：外壳金属化、导电泡棉、电缆屏蔽与磁环（卡式磁环治电缆辐射立竿见影）。
8. **频率抖动/展频（SSM）**：把窄带尖峰摊成宽带噪声，峰值降 3–8dB——治标但有效，注意下游滤波与环路带宽适配。

### 20.6 抗扰度与雷击浪涌（P112、P195–P197）

- **浪涌（IEC 61000-4-5）**：差模 1–2kV、共模 2–4kV（1.2/50µs 波形）；防护链：MOV（压敏电压按最大稳态 AC 选）+ GDT（气体放电管泄大电流）+ 串联阻抗（X 电容/共模电感等效阻抗）协调；MOV 与 GDT 之间的退耦电感/电阻是让 GDT 先动作的关键。
- **EFT（电快速瞬变 4-5/50ns 群脉冲）**：靠滤波器高频插入损耗+PCB 抗扰布局（关键信号滤波）。
- **ESD（接触 8kV/空气 15kV）**：外壳绝缘距离、放电走廊、TVS 阵列与地回路设计。
- **电压暂降/中断（Voltage Dips & Interruptions，IEC 61000-4-11）与谐波抗扰**：母线电容 hold-up 设计对应（第十二章）。
- **设计前的 EMC 预案**：滤波器占板、Y 电容位、屏蔽与接地结构在架构阶段就规划——"EMC 是设计出来的，不是整改出来的"。

## 第二十一章 典型设计实例精算

> 本章用两个完整算例把前面所有章节的知识点串联起来，示范"从规格到参数"的完整推演过程，可作为设计报告模板。

### 21.1 实例一：65W USB-PD 快充（反激 + PSR）完整设计推演

**规格定义**：输入 AC 90–264V（全球宽电压）；输出 5V/3A、9V/3A、15V/3A、20V/3.25A（65W 最大）；效率目标 ≥92%（230Vac 满载）；空载功耗 <75mW；符合 IEC 62368 安规与 CISPR 32 Class B。

**第一步：架构与母线**

- 单级反激（<150W 无需独立 PFC 级，需满足谐波限值——65W 处于 IEC 61000-3-2 Class D 边界，用好的 EMI 滤波与高 PF 控制器即可）。
- 整流后母线：90Vac 时母线谷值 ≈ 90×1.414−纹波跌落 ≈ 100V；264Vac 时峰值 ≈ 373V。
- 母线电容：若按 hold-up 10ms 公式 C = 2·Po·t/(η·(Vmax²−Vmin²)) 计算仅约 11µF，但该式适用于"母线跌落期间仍需维持输出"的两级结构；反激直接挂母线时，容量主要由低频纹波与 PF 决定，典型取 2–3µF/W（宽输入），选 120–150µF/450V（并联两个 68µF 分摊纹波电流并降低高度）。

**第二步：反射电压与匝比**

- 选用 700V 内置 MOS 的 PSR 控制器（或 650V 外置超结管）。
- 钳位电压预算：Vds,max = 373 + Vor + Vspike ≤ 650×0.9 = 585V ⇒ Vor + Vspike ≤ 212V；取 Vor = 100V、尖峰余量 100V（RCD 钳位在 1.8×Vor = 180V 动作）。
- 匝比 n = Np/Ns = Vor/(Vo+Vf) = 100/(20+0.6) ≈ 4.85 → 取 Ns=6 匝则 Np=29 匝（取整后 n=4.83，Vor≈99.5V，复核通过）。
- 副边整流管应力：Vrrm = Vo + Vin,max/n = 20 + 373/4.83 ≈ 97V → 选 150V 肖特基（或 100V 同步管，降额 65%）。

**第三步：原边电感与电流（按 20V/3.25A 输出点）**

- 取 DCM 与 CCM 边界附近设计：Pin = 65/0.92 ≈ 70.7W；开关频率 100kHz（DCM 高压角）。
- 取 Ipk = 2.2A（PSR 限流点设定），DCM 储能式：Lp = 2·Pin/(Ipk²·fs) = 2×70.7/(4.84×100k) ≈ 292µH → 取 300µH。
- 校核占空比：DCM 下 D = Ipk·Lp·fs/Vin,min = 2.2×300µ×100k/100 ≈ 0.66——偏高，说明 90Vac 低角进入 CCM，需复核磁损与斜率补偿（PSR 常固定 Toff 策略自然适应）。
- 原边 RMS：Ipk/√3 ≈ 1.27A（三角波），采样电阻（若有）= 限流阈值/Ipk。

**第四步：变压器绕组**

- 磁芯：65W/100kHz 反激常用 EFD29 或 EDR2809（扁平高密度）。
- Np = Lp·Ipk/(Bmax·Ae)：取 Bmax = 0.28T（100kHz 温升限制内），Ae=76mm²：Np = 300µ×2.2/(0.28×76µ) ≈ 31 匝 → 与匝比迭代微调 Np=30、Ns=6。
- 气隙：lg = µ0·Np²·Ae/Lp = 4πe-7×900×76µ/300µ ≈ 0.29mm（中柱研磨）。
- 绕法：三明治（原边一半 15T → 副边 6T 屏蔽 → 原边 15T → 辅助 8T），漏感目标 <2% Lp（<6µH）；副边用 3×0.4mm 利兹或铜箔。
- 损耗预估：ΔB = Lp·ΔI/(Np·Ae) = 300µ×2.2/(30×76µ) ≈ 0.29T p-p——超过 100kHz 铁氧体的损耗舒适区，暴露出 DCM 大纹波下"损耗限制"与"饱和限制"的矛盾：改用 PC95 低损材料并把 fs 提到 130kHz 或增大磁芯，工程上取 120kHz 重算收敛（磁芯损耗常是最终约束）。

**第五步：输出与反馈**

- 输出电容：20V 路副边峰值电流 ≈ n×Ipk = 10.6A，纹波主要受 ESR：ΔV=10.6×ESR ≤ 150mV ⇒ ESR ≤ 14mΩ → 两颗 470µF/25V 固态电容并联（ESR 8mΩ each）+ MLCC 10µF×4。
- PSR 恒压精度：辅助绕组采样+线补电阻；恒流精度 ±5%。
- 待机：<75mW 要求跳周期深度待机（控制器 BURST <1kHz）+ 启动电阻改高压启动电流源。

**第六步：EMC 预案（设计阶段就布好）**

- 输入滤波：共模电感 10mH + X2 0.68µF + Y1 2.2nF×2（一次-二次跨接）。
- RCD 钳位 RC 参数按振铃频率整定；输出线加磁环（治 100–300MHz 辐射）。
- 布局：热回路最小化、Y 电容紧邻变压器与母线电容中点、PSR 采样走线远离漏极。

### 21.2 实例二：48V→12V/10A 通信电源砖（同步 Buck）关键计算

- D = 12/48 = 0.25；fs = 400kHz；纹波 30%：ΔI = 3A ⇒ L = Vo(1−D)/(fs·ΔI) = 12×0.75/(400k×3) = 7.5µH → 取 6.8µH 标准值复核 ΔI=3.3A。
- 电感峰值 11.65A、RMS ≈ 10.05A：选饱和 16A/温升电流 12A 的一体成型电感（DCR<8mΩ）。
- 上管导通损耗：P = Io²·D·Rds(on)。若选 4mΩ 管：10²×0.25×0.004 = 0.1W？——核算过程：Io²·D = 100×0.25 = 25A²（等效电流 5A），25×0.004Ω = 0.1W，单管损耗其实可控；但加上开关损耗、下管与电感损耗后总热预算仍偏紧，工程上 10A 输出更倾向 Rds(on)≤1.5mΩ 或两相并联——此算例演示了用"应力表"逐项核损、暴露设计余量不足的过程。
- 输入电容 RMS = 10×√(0.25×0.75)=4.33A：需 4–6 颗 10µF/100V MLCC + 1 颗 47µF 电解。
- 环路：Buck 无 RHPZ，fc 取 40kHz（fs/10），电流模 Type-II：零点 8kHz、极点 200kHz；PM 目标 60°。

## 第二十二章 工程避坑清单（实战经验汇编）

> 以下条目均对应前述章节的高频翻车点，供设计评审（Design Review）逐条核对。

### 22.1 拓扑与参数类

- 反射电压 Vor 一味取高：开关管应力超标但被尖峰吸收"掩盖"，实测高温满载时管子接近雪崩——务必按 Vin,max+Vor+Vspike 三项和核算。
- Boost/Buck-Boost 忽略 RHPZ：环路带宽设到 fz 的一半以上，负载跳变时振荡加剧——带宽永远让位于 RHPZ。
- DCM/CCM 边界模式切换：轻载增益跳变导致输出抖动，电压模系统尤其明显——确认控制策略在两种模式下都稳定。
- 高升压比单级 Boost：D>0.85 后效率与纹波崩塌——改两级或抽取式拓扑。
- 忽略最小导通时间：高输入电压下占空比压不下去，输出失控或必须降频——核对控制器 tON(min) 与最大 Vin 的组合。

### 22.2 磁件类

- 按常温 Bsat 设计：铁氧体 100°C 的 Bsat 比常温低 20%——热态才是真约束。
- 只看饱和不看损耗：100kHz 以上ΔB 常由温升（损耗）而非饱和决定——先查损耗曲线再定 ΔB。
- 漏感失控后才补吸收：三明治绕法把漏感压到 2% 以内比优化 RCD 有效十倍。
- 大气隙贴绕组：边缘磁通在邻近绕组里感应涡流，局部过热——气隙分散或远离绕组。
- 忽略副边谐波交流电阻：副边梯形电流谐波丰富，Fr 按基波估算严重低估铜损——谐波展开计算。

### 22.3 器件与驱动类

- 超结管用于硬开关桥式：体二极管 trr 大+直通 dv/dt 误开通——桥式选带快恢复体二极管器件或加负压关断。
- 同步整流轻载倒灌：DCM 下 SR 续流电流反灌输出电容使电压漂高——SR 控制需电流方向检测或提前关断。
- 并联二极管想当然均流：二极管 Vf 负温度系数，并联越热越流——并联用 MOS（同步整流）或选 Vf 匹配+热耦合。
- 忽视驱动损耗：MHz 级 GaN 系统驱动损耗可占总损耗 10%+——按 Qg·V·fs 精算。

### 22.4 环路与控制类

- 补偿网络照抄参考设计：输出电容 ESR/容量不同则功率级极零点全变——补偿必须按自己的功率级重算。
- 光耦 CTR 只按初期计算：五年后 CTR 衰减 30–50%，环路增益下降、稳压精度劣化——按寿命末期 CTRmin 设计。
- 电流模忘加斜率补偿：D>0.5 次谐波振荡，表现为半开关频率的输出振荡——C>0.5 必补。
- 环路只仿真不实测：仿真模型不含光耦极点与采样延迟——伯德图实测是唯一验收标准。

### 22.5 布局与 EMC 类

- 输入电容离开关管远：热回路面积大，尖峰与辐射双输——输入电容永远第一位优先布。
- 单点接地用成了"菊花链串地"：功率电流流经信号地线产生共模压降——分区+单点汇接。
- 反馈走线穿开关节点下方：耦合噪声造成输出毛刺甚至误保护——反馈线绕行+地保护线。
- Y 电容随手放：共模回流路径绕远，滤波器失效——Y 电容放在共模电流路径的"咽喉"。
- 先过不了传导就猛加滤波器：源头（沿速度/振铃）没治，滤波器越加越大、低频稳定性反而恶化——先减缓沿+吸收振铃，再配滤波。
- 忘记滤波器与电源的相互作用：滤波器输出阻抗与电源输入阻抗在转折频率交叠引发振荡——校核阻尼与稳定裕度。

### 22.6 测试与量产类

- 长地线测纹波：探头地线环路拾取的噪声远大于真实纹波——弹簧接地+20MHz 限制。
- 万用表测效率：AC 波形因数误差可达 5%——功率分析仪+四线制。
- 只测常温满载：低温启动、高温满载、输入跌落、老化后才暴露的问题被漏掉——按测试矩阵全覆盖。
- 电解电容壳温不测：寿命预测完全基于壳温，遗漏即埋雷——热电偶定点监控。
- 软件版本不受控地"顺手改参数"：保护点、时序漂移无记录——量产固件配置冻结+变更记录。

| 增益裕度 | Gain Margin, GM | 环路稳定的增益储备，工程目标 ≥10dB |
| 斜率补偿 | Slope Compensation | 峰值电流模 D>0.5 时注入斜坡防止次谐波振荡 |
| 音频抑制比 | Audio Susceptibility | 输出对输入扰动的传递率，电压模的弱项 |
| 功率因数校正 | PFC | 强制输入电流跟随正弦电压的谐波治理技术 |
| 零电压/零电流开关 | ZVS / ZCS | 软开关技术，消除电压电流交叠损耗 |
| 准谐振 | Quasi-Resonant, QR | 谷底开通的反激变体，降低开通损耗 |
| 有源钳位 | Active Clamp, ACF | 回收漏感能量并实现 ZVS 的钳位技术 |
| 相移全桥 | Phase-Shifted Full Bridge | 靠桥臂相移调功率并利用漏感实现 ZVS |
| 同步整流 | Synchronous Rectification, SR | 用 MOSFET 取代整流二极管降低压降损耗 |
| 原边反馈 | PSR | 省去光耦、在原边采样辅助绕组完成调节的技术 |
| 电流传输比 | CTR | 光耦输出/输入电流比，随温度与老化衰减 |
| 交叉调整率 | Cross Regulation | 多路输出中一路负载变化对其他路的影响 |
| 保持时间 | Hold-up Time | 输入断电后输出维持规定值的时间，决定母线电容 |
| 共模/差模噪声 | CM / DM | 线对地/线对线的干扰模式，滤波对策不同 |
| 插入损耗 | Insertion Loss | 滤波器对噪声的衰减量，EMI 滤波器设计核心指标 |
| 猝发模式 | Burst Mode | 轻载时间歇性开关以降低待机损耗 |
| 展频调制 | Spread Spectrum, SSM | 抖动开关频率摊薄 EMI 尖峰的技术 |
| 爬电距离 | Creepage Distance | 沿绝缘表面两导电体间最短距离，安规核心尺寸 |
| 电气间隙 | Clearance Distance | 空气中两导电体间最短距离 |
| 降额设计 | Derating | 按额定值的一定比例使用器件以保障可靠性 |
