## 第1集：2小时，入门高速PCB设计！

这一集通常会从一个最核心的困惑讲起:为什么同样是画板子,有的板子"低速"随便连都行,有的"高速"却要算阻抗、控等长、抠回流?本集的目标是帮零基础同学用 2 小时建立一套完整的高速 PCB 设计全局观——知道哪些概念必须懂、为什么重要、以及实际动手时大概怎么操作。下面按小节展开。

### 📖 什么是高速信号、为什么 PCB 设计要关注它

很多新手把"高速"理解成"信号频率高",这其实是个常见的误解。严格地说,**判断一条走线是否要按"高速/传输线"来对待,看的不是时钟频率,而是信号的上升/下降时间(边沿速率)以及走线长度**。

一个通俗的比喻:你朝峡谷大喊一声(发出信号),如果峡谷很窄很短,回声几乎和你同时到达,你根本分不清原声和回声;但如果峡谷很长,回声会明显延迟并叠加到下一句话上,造成"串音"和失真。PCB 上的走线也是一样:当走线足够长、信号边沿足够陡时,信号在线上"来回反射"的时间已经和信号变化时间可比拟,这条走线就不再是一条简单的"导线",而变成了一根**传输线**。

工程上常用的判断经验(上升沿准则):当走线长度 $L$ 满足

$$
L > \frac{t_r}{k} \cdot v \qquad (k \text{ 常取 } 6 \sim 10)
$$

时,就应视为传输线。其中 $t_r$ 是信号上升时间,$v$ 是信号在介质中的传播速度 ($v = c/\sqrt{\varepsilon_r}$,FR-4 板材 $\varepsilon_r \approx 4.2$,所以 $v \approx 0.5c \approx 15\,\text{cm/ns}$)。

例如一个上升时间 1 ns 的信号,临界长度约为 $15/6 \approx 2.5\,\text{cm}$ 到 $15/10 \approx 1.5\,\text{cm}$。也就是说,哪怕时钟只有几十 MHz,只要边沿很陡,几厘米长的走线就已经是"高速"了。所以**关注 PCB 设计,本质上关注的是信号完整性(SI)、电源完整性(PI)和电磁兼容(EMC)**——板子画错,轻则偶发误码,重则根本跑不起来或被 EMC 测试卡住。

### 🔬 关键概念深入

下面把本集会反复提到的几个概念物理含义讲透。

#### 1. 阻抗与特性阻抗 $Z_0$

任何一条 PCB 走线,在高频下都同时具有电阻 $R$、电感 $L$、电容 $C$、电导 $G$。沿传输线往前看,每前进一段微元,就看到一个由这些参数构成的"串联+并联"网络。当信号以行波形式传播时,线上某点电压与电流的比值趋于一个恒定值,这就是**特性阻抗 $Z_0$**:

$$
Z_0 = \sqrt{\frac{R + j\omega L}{G + j\omega C}}
$$

在常见的"无损近似"($R,G$ 可忽略)下简化为:

$$
Z_0 = \sqrt{\frac{L}{C}}
$$

也就是说,特性阻抗由"单位长度电感"和"单位长度电容"的比值决定。它**只和走线的几何结构以及板材介电常数有关,和走线长度无关**。最常用的两类结构公式(经验公式,工程够用):

- 微带线(表层走线,下方有参考平面):

$$
Z_0 \approx \frac{87}{\sqrt{\varepsilon_r + 1.41}} \ln\!\left(\frac{5.98\,h}{0.8\,w + t}\right)
$$

- 带状线(内层走线,夹在两个参考平面之间):

$$
Z_0 \approx \frac{60}{\sqrt{\varepsilon_r}} \ln\!\left(\frac{4\,h}{0.67\pi\,(w + 0.8\,t)}\right)
$$

其中 $w$ 是线宽、$t$ 是铜厚、$h$ 是到参考平面的介质厚度。可见:**线越宽、离参考面越近,$Z_0$ 越低**;介电常数越高,$Z_0$ 越低。

**为什么重要**:如果驱动端、走线、接收端阻抗不一致,信号到达终点会"撞墙反弹"(反射),叠加出振铃、过冲、台阶,导致采样错误。所以高速设计第一件事就是**定阻抗目标**(常见 50Ω 单端、90Ω/100Ω 差分),再由厂家叠层反推线宽。

#### 2. 反射与阻抗匹配

反射系数描述了多少信号被弹回:

$$
\Gamma = \frac{Z_L - Z_0}{Z_L + Z_0}
$$

当 $Z_L = Z_0$ 时 $\Gamma = 0$,完美吸收、无反射;当末端开路 $Z_L=\infty$ 时 $\Gamma=+1$(全反射,幅度翻倍);短路时 $\Gamma=-1$。**阻抗匹配**就是让源端或末端阻抗等于 $Z_0$,把能量"接住"。常见手段:末端并联电阻到地/电源、串联源端电阻、戴维南匹配等。

#### 3. 等长(时序等长 / 长度匹配)

信号在线上不是瞬时到达,而是以有限速度传播。传播延迟:

$$
t_{pd} = \frac{\sqrt{\varepsilon_r}}{c} \cdot L \approx \frac{L}{15\ \text{cm/ns}} \quad (\text{FR-4})
$$

也就是大约 **每 1 ns 走 15 cm**,折算约 **55~65 ps/cm**(取决于层间 $\varepsilon_r$ 差异,内层比表层稍慢)。对 DDR 这类并行总线,数据线(DQ)和时钟(DQS)必须同时到达,否则采样窗口错位就会出错。于是要做**等长**——把所有相关网络的长度差控制在几 mil 到几十 mil 以内(例如 DDR3 数据组内通常要求误差 < ±25 mil)。注意:**等长不等于等阻抗**,它是时序概念,和前面的 $Z_0$ 是两套约束。

#### 4. 串扰(Crosstalk)

相邻走线之间会通过**互容 $C_m$**(电容耦合,电场)和**互感 $M$**(电感耦合,磁场)互相干扰。攻击线上的跳变会在受害线上感应出噪声。分为:

- **近端串扰 NEXT**:在攻击线发送端同一侧的受害线近端出现;
- **远端串扰 FEXT**:在受害线远端出现,会随线长累积。

**缓解手段**主要是拉开间距和加屏蔽地:经典"**3W 原则**"——走线中心间距 ≥ 3 倍线宽,可把串扰降到约 70 dB 以下量级;更严时用"2S(隔一条地线)再 3W"。同层尽量正交走线,避免长距离平行。

#### 5. 回流路径(Return Path)

这是新手最容易忽略、却最致命的一点。高频下,信号的回流电流**不会绕远路**,而是紧贴信号走线在其参考平面(地或电源层)上"镜像"回流,路径面积最小、电感最低。

```
   信号线(top)   ──────→
   ┌─────────────────────┐
   │   参考平面(地)       │   ← 回流电流紧贴走线正下方流回
   └─────────────────────┘
        ←────── 回流
```

一旦参考平面被分割、换层、开槽,"镜像回流"被迫绕行,回路面积变大 → 环路电感上升 → 阻抗突变、EMI 恶化、信号振铃。**所以换层时必须紧挨着打"伴随地过孔"**,给回流提供就近的通道。这是高速布线的黄金法则之一。

### 🛠 设计实例:用嘉立创 EDA 从建库到生产资料

这一集会以"一个实际工程"为主线串起全流程。下面给出可操作的步骤框架(工具以嘉立创 EDA 专业版为例,其他 EDA 思路一致)。

**① 建库(封装 / 原理图符号)**
- 打开嘉立创 EDA → 新建「元件库」→ 根据器件数据手册绘制封装(焊盘尺寸、间距、丝印)。
- 常见坑:按"推荐 land pattern"而非"芯片尺寸"画焊盘;QFP/BGA 注意 1pin 标记;连接器留足禁布区。

**② 原理图与导入**
- 放置元件、连线、标网络名;用"网络标号"区分电源/地/高速网。
- 设计 → 更新/转换到 PCB,把网表一次性导入。

**③ 叠层与阻抗(关键)**
- 在「层管理」里设定板层(如 4 层:Top-GND-PWR-Bottom 或 6 层)。
- 用「阻抗计算工具」输入板材 $\varepsilon_r$、铜厚、介质厚,反推目标线宽。例如要 50Ω 微带线,工具会告诉你线宽约多少 mil。

**④ 布局(Layout)**
- 先摆放接口、接插件、大器件;再按"模块化"就近摆放(电源模块、MCU、DDR、射频)。
- 原则:高频/高速器件靠近其对应接口;去耦电容紧贴电源引脚;晶振远离干扰源并包地。

**⑤ 布线(Routing)—— 实例:一个 USB 差分对怎么走**
USB 2.0 是 90Ω 差分对,USB 3.0 还含更高速差分对。具体步骤:
1. 在「设计规则」里建差分对(快捷键可框选两根网设为差分),目标阻抗 90Ω,线宽/线距由阻抗工具给出(常见 7/8 mil 线宽、间距约 6~8 mil,随叠层变)。
2. 两根线**等长、等距、同层**走,避免中途换层;若必须换层,在旁边打"地过孔"陪同步进。
3. 走线尽量短、少打过孔、少拐 90°(用 45° 或圆弧),长度差控制在几十 mil 内。
4. 两侧加地保护、远离时钟和电源噪声源,遵守 3W 间距。
5. 终端 90Ω 匹配由芯片内部或端接电阻完成,板上主要保证走线阻抗连续。

```
   GND ─┐   ┌─ USB_D−  ═════╗ (90Ω 差分, 紧耦合等距)
        │   │
   GND ─┤   ├─ USB_D+  ═════╝
        │   │
   GND ─┘   └─ 地过孔(回流/屏蔽)
```

**⑥ 等长与检查**
- 对 DDR 等总线用「等长调节(蛇形线)」把组内长度差压进容差。
- 运行 DRC(设计规则检查),清掉短路、间距不足、未连接。

**⑦ 生产资料输出**
- 「制造」→ 一键生成 Gerber、钻孔、坐标文件、BOM、贴片坐标;
- 直接对接嘉立创下单,填层数、板材、阻焊颜色、是否阻抗控制(务必勾选"阻抗",并附上你的阻抗要求表)。

### ⚠️ 新手常见误区

| 误区         | 真相                     |
| ---------- | ---------------------- |
| "频率低就不是高速" | 看上升时间+走线长度,边沿陡也要控阻抗    |
| "线越粗越好"    | 线宽决定了 $Z_0$,乱加宽会偏离目标阻抗 |
| "只要连通就行"   | 连通 ≠ 信号质量,反射/串扰/回流才是关键 |
| "地随便连"     | 回流路径必须连续,换层要打伴随地孔      |
| "等长就是等阻抗"  | 两回事:等长是时序,阻抗是信号质量      |
| "过孔随便打"    | 过孔有寄生电感/电容,高速线尽量少打、对称打 |
| "丝印/工艺不用管" | 丝印压焊盘、阻焊开窗错会导致焊接不良     |

### 📌 要点速记

1. 高速看**边沿速率 + 走线长度**,不是看时钟频率。
2. 特性阻抗 $Z_0=\sqrt{L/C}$,由线宽、介质厚、介电常数决定,与长度无关。
3. 阻抗不连续 → 反射 → 振铃/误码,目标是全程 $Z_0$ 一致。
4. 差分对要**等宽、等距、等长、同层**,USB 用 90Ω、常见射频用 50Ω。
5. 回流电流紧贴参考平面下方走,换层必打伴随地过孔。
6. 串扰靠"3W 间距 + 包地 + 少平行"抑制。
7. 等长针对时序总线(DDR 等),容差常 < ±25 mil。
8. 生产资料里阻抗控制要单独勾选并附要求表。

## 核心收获清单
- 建立"高速 = 边沿速率 + 走线长度"的正确直觉,而非只盯时钟频率。
- 理解特性阻抗 $Z_0$ 的物理来源 ($Z_0=\sqrt{L/C}$) 及其与线宽/介质厚/介电常数的关系。
