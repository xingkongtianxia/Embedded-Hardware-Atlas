## 第1集：阻抗基本概念

### 📖 这一集讲什么

先抛开公式,用一句大白话理解"阻抗":**阻抗就是信号在PCB走线上传输时,遇到的"阻力"有多大**。

我们平时学电路,最熟悉的是"直流电阻" $R$。一根铜线不管多长,测得电阻是几欧姆或几十毫欧,电流"想走就走"。但一旦信号频率变高(比如几十 MHz、上百 MHz、几 GHz 的时钟或高速数据),情况就完全变了:信号不再像"水流灌满水管"那样整体推进,而是像一道电磁波"贴着"走线往前跑。这时决定信号好不好传的,不再是直流电阻,而是"**特征阻抗(Characteristic Impedance)**" ,符号记为 $Z_0$。

为什么重要?因为**如果信号源、走线、接收端三者的阻抗不一致(不匹配),信号到端点就会"撞墙反弹"**——一部分能量反射回去,造成过冲、振铃、眼图闭合,严重时接收端压根读不出正确数据。这就是高速设计里反复强调"50 欧姆""90 欧姆差分"的根本原因:它是为了让整条路径阻抗连续,信号顺畅抵达。

把电路类比成水管:阻抗就像水管的"粗细+管壁光滑度"组合决定的流量特性,而不是单纯的水管电阻。信号频率越高,这种"特性"越主导,直流电阻反而可以忽略。所以**做高速 PCB 第一步,就是先建立"走线是有阻抗的传输线,不是普通导线"这个观念**。

### 🔬 深入原理

特征阻抗 $Z_0$ 本质上由传输线的**单位长度分布参数**决定:

```text
单位长度电感 L (nH/mm)
单位长度电容 C (pF/mm)

Z0 = sqrt(L / C)
```

注意:特征阻抗与频率几乎无关(在常规高速频段内),它取决于**几何结构**(线宽、介质厚度、铜厚)和**材料**(介电常数 $\varepsilon_r$)。信号沿线的传播速度:

```text
v = c / sqrt(εr_eff)      c ≈ 3×10^8 m/s (光速)
```

常见目标阻抗经验值:

| 场景       | 典型阻抗    | 说明      |
| -------- | ------- | ------- |
| 射频/单端高速  | 50 Ω    | 最常用单端标准 |
| 单端时钟/地址  | 50–60 Ω | 依芯片手册   |
| USB 差分   | 90 Ω    | 差分对间    |
| 以太网差分    | 100 Ω   | 差分对间    |
| DDR 差分时钟 | 100 Ω   | 依规范     |

关键认知:**阻抗是"每一点"的属性**,整条路径都要尽量维持同一数值,才能避免反射。

### 🛠 设计实例

- **例1**:一颗主控输出 50 Ω 单端 DDR 地址线,若 PCB 走线随意画成 70 Ω,末端无端接,信号到达 DDR 颗粒时发生反射,波形出现振铃,眼图高度被压缩,误码率上升。把走线调到 50 Ω 并加串联匹配电阻后,振铃消失。
- **例2**:USB 2.0 要求差分 90 Ω。若板厂按 100 Ω 做,插上主机可能识别困难或不稳定;按 90 Ω 控制则通信顺畅。

### ⚠️ 常见误区

- 误以为"阻抗就是电阻",用万用表量走线电阻来判断阻抗——**错**,万用表量的是直流电阻,阻抗要用阻抗计算工具/ TDR 测量。
- 以为阻抗只跟线宽有关——**错**,介电常数、介质厚度、铜厚同样关键(见第2集)。
- 以为低频电路不用管阻抗——**错**,只要信号上升沿足够陡(边沿速率快),即使频率不高也会表现出传输线效应。

### 📌 要点速记

1. 特征阻抗 $Z_0=\sqrt{L/C}$,由几何与材料决定,与频率基本无关。
2. 阻抗不匹配 → 反射 → 振铃/眼图恶化。
3. 50 Ω 单端、90 Ω / 100 Ω 差分是最常见目标。
4. 走线是"传输线"不是"普通导线",这是高速设计的第一课。
5. 整条路径阻抗要连续,不是只管某一段。

## 第2集：影响阻抗的因素有哪些

### 📖 这一集讲什么

上一集我们知道了阻抗 $Z_0=\sqrt{L/C}$。这一集回答最实际的问题:**画 PCB 时,我动哪个参数,阻抗会变?**

核心就四类"可调旋钮":**①线宽(W)、②介质厚度(H,即走线到参考平面的距离)、③介电常数($\varepsilon_r$,板材决定)、④铜厚(T)**。记忆口诀:"**宽、厚、材、铜**"。

直觉理解:
- **线越宽**,跟参考平面"面对面"面积越大,电容 C 越大、电感 L 越小 → 阻抗**下降**。所以想降阻抗就加宽线。
- **走线离参考平面越远(介质越厚)**,耦合越弱,C 越小、L 越大 → 阻抗**上升**。所以想升阻抗就拉厚介质(或把参考层搬远)。
- **板材介电常数 $\varepsilon_r$ 越大**,电容 C 越大 → 阻抗**下降**。FR-4 约 4.2–4.5,高频板 Rogers 4350B 约 3.48,特殊材料各有不同。
- **铜越厚**,相当于走线"更胖",跟平面耦合略增 → 阻抗**略降**(影响比前三个小)。

还有一个容易被忽略的:**阻焊油墨(绿油)覆盖在走线上,会轻微降低阻抗**(约 1–2 Ω),所以"算阻抗"时要问清楚板厂是否按"带绿油"还是"裸铜"模型算。

把这些因素画成一张影响关系表,设计时就有了"调参地图":

```text
阻抗 Z0  ↑ 增大                ↓ 减小
─────────────────────────────────────────
线宽 W         变窄              变宽
介质厚 H       变厚(离平面远)    变薄(离平面近)
介电常数 εr    变小(如改用低Dk)  变大(如FR-4)
铜厚 T         变薄              变厚
绿油           不盖/薄盖          厚盖
```

### 🔬 深入原理

以最典型的**表层微带线(Microstrip)**为例,工程上常用的近似公式(空气上方、单端):

```text
Z0 ≈ (87 / (√(εr+1.41))) × ln( 5.98×H / (0.8×W + T) )
```

其中 H 为介质厚度,W 为线宽,T 为铜厚,单位统一(mm。可以看到:

- Z0 与 H 近似**正比于 ln(H)** → H 增大,阻抗缓慢上升;
- Z0 与 W 近似**反比于 ln(W)** → W 增大,阻抗下降;
- Z0 与 $\sqrt{\varepsilon_r}$ **成反比** → 板材 Dk 越大阻抗越低。

对**内层带状线(Stripline)**,走线夹在两个参考平面之间,公式为:

```text
Z0 ≈ (60 / √εr) × ln( 4×H / (0.67×π×(0.8×W+T)) )
```

(不同资料常数略有差异,但趋势一致:带状线阻抗对 H 更敏感,且因上下都有平面,同等阻抗下需要的线宽比微带线更窄。)

### 🛠 设计实例

- **例1(想提阻抗)**:某 50 Ω 微带线当前 W=8 mil、H=4 mil(FR-4,εr≈4.2),实测偏 45 Ω。方案:保持 H 不变,把 W 收窄到约 6.5 mil,即可回到 50 Ω 附近;或把 H 加厚到 5 mil 同时略缩 W。
- **例2(板材切换)**:同一线宽线厚,把 FR-4(εr=4.3)换成 Rogers 4350B(εr=3.48),阻抗会明显升高,需要重新算线宽才能维持 50 Ω。这正说明"换板材必须重算阻抗"。

### ⚠️ 常见误区

- 只改线宽调阻抗,忘了介质厚度也是大变量——有时 H 微调几 mil,阻抗就漂好几欧。
- 把板厂"标称 εr"当真实值——FR-4 的 εr 随频率、树脂含量、玻璃布型号波动,批量生产要留余量。
- 忽略绿油和铜箔粗糙度对阻抗的细微影响,导致仿真值和实测差 1–3 Ω。
- 误以为铜厚影响最大——其实在常规 0.5–1 oz 范围内,铜厚对阻抗影响较小,调它不如调 W/H 有效。

### 📌 要点速记

1. 四大因素:线宽 W、介质厚 H、介电常数 εr、铜厚 T(口诀"宽厚材铜")。
2. 加宽线/加厚介质降阻抗;换高 Dk 板材也降阻抗。
3. 绿油会轻微降阻抗(约 1–2 Ω),算阻抗要说明是否带绿油。
4. 板材 Dk 会波动,批量设计要留余量。
5. 调阻抗优先动 W 和 H,铜厚是次要手段。

### 🔗 承上启下

知道了"哪些因素能动",下一集(第3集)进入**多层板叠层**:在 4/6/8 层板里,这些 H、参考平面到底怎么排布,才能既控好阻抗又保证电源完整性与 EMC。

## 第3集：多层板叠层分析

### 📖 这一集讲什么

前面两集讲的是"一条线"的阻抗。真实项目里,板子有好多层,**叠层(Stack-up)就是把这些信号层、电源层、地层像"千层饼"一样叠起来的结构图**。叠层设计直接决定了:哪里能走 50 Ω 线、去耦电容好不好使、EMC 安不安分。

先记住一个黄金法则:**高速信号层必须紧邻一个完整的参考平面(地或电源层)**。参考平面有两件事要做:①给信号提供回流路径(电流总是走最近的平面);②和走线一起构成传输线、决定阻抗。

常见层数选择:
- **4 层板**:Top / GND / PWR / Bottom。最便宜,但只有一个地平面,电源层作参考时信号质量受限。
- **6 层板**:典型 `Top / GND2 / Sig3 / Sig4 / PWR / Bottom`,或 `Top / GND / Sig / PWR / GND / Bottom`。比 4 层多一个完整平面,高速信号有更好回流,是性价比之王。
- **8 层板**:在 6 层基础上再插入信号/平面层,适合更密集、更高速(如 DDR4、PCIe)的设计。

一个 6 层板叠层的 ASCII 示意(厚度从上到下):

```text
┌──────────────┐  Top      (高速信号, 参考 L2 地)
├──────────────┤  介质 H1
├──────────────┤  L2 = GND (完整地平面 ★参考)
├──────────────┤  介质 H2 (较薄, 控阻抗)
├──────────────┤  L3 = Sig (内层带状线, 上下有平面)
├──────────────┤  介质
├──────────────┤  L4 = Sig
├──────────────┤  介质 H3
├──────────────┤  L5 = PWR (电源平面)
├──────────────┤  介质 H4
└──────────────┘  Bottom   (信号, 参考 L5)
```

设计要点:**相邻信号层之间最好夹一个平面**,避免两层信号"互相串扰";电源/地平面成对紧靠,可形成"平板电容"帮助去耦。

### 🔬 深入原理

叠层的核心是**安排好每一层的参考平面距离 H**,因为 H 直接决定阻抗(见第2集)。例如想做 50 Ω 微带线:表层 Top 到 L2 地的 H1 取 4–5 mil;内层带状线则看它到上下平面的距离(常取对称,如各 4–5 mil)。

叠层还要兼顾**电源完整性(PI)**:GND 与 PWR 平面紧邻(间距小,如 3–4 mil)能增加层间平板电容,在高频段提供低阻抗去耦,减小电源噪声。

EMC 角度:**完整的地平面能束缚磁场**,减少对外辐射;地平面开槽(尤其是高速信号跨槽)会迫使回流绕行,既增大环路面积又恶化 EMC。

| 层数 | 优点 | 缺点 | 适用 |
|------|------|------|------|
| 4层 | 成本低 | 仅1个地平面,参考受限 | 中低速、成本敏感 |
| 6层 | 性价比高,双平面 | 层数有限 | 主流高速板 |
| 8层 | 密度/性能强 | 成本高、压合复杂 | DDR4/PCIe 等 |

### 🛠 设计实例

- **例1(6层板阻抗分配)**:Top 微带 50 Ω,H1=4.2 mil(FR-4),算得 W≈6.8 mil;L3/L4 内层带状线 50 Ω,到上下平面各 4.5 mil,算得 W≈4.5 mil。两套线宽不同,布线规则要分网络类设置。
- **例2(避免跨槽)**:某 DDR 数据线在 Top 层走到一半,下面 L2 地被一条分割线切断,回流被迫绕远,EMC 测试辐射超标;把地平面补全后通过。

### ⚠️ 常见误区

- 把电源层当"万能参考层"——只有当信号参考的 PWR 网络与走线同源且低噪声时才合适,否则宜用地。
- 相邻两层都布高速信号又没夹平面 → 层间串扰严重。
- 地平面随意开长槽,高速线跨槽走 → 阻抗突变+EMC 恶化。
- 以为层数越多越好,忽略成本与压合良率。

### 📌 要点速记

1. 高速信号层必须紧邻完整参考平面(地优先)。
2. 6 层板是性价比最高的高速叠层选择。
3. 相邻信号层间最好夹平面,减小串扰。
4. 电源/地平面紧靠 → 增加平板去耦电容。
5. 地平面勿随意开槽,避免信号跨槽。

## 第4集：常见阻抗模型分析

### 📖 这一集讲什么

"模型"就是走线和参考平面构成的几何形状,不同形状算阻抗的公式不同。认识模型,才能在 EDA 工具里选对算法。最常见的几类:

1. **表层微带线(Microstrip)**:走线在板子最外层(Top/Bottom),一面是介质、一面是空气。最常见、最好加工。
2. **嵌入式微带线(Embedded / Coated Microstrip)**:表层走线但被绿油/阻焊完全覆盖,相当于上方也填了介质,阻抗比裸微带略低。
3. **内层带状线(Stripline)**:走线夹在两个平面之间,完全被介质包住。阻抗最稳定、抗干扰最强,但加工要内层。
4. **差分对(Differential Pair)**:两条等长的耦合线一起传信号(如 USB、PCIe、以太网)。看的是**差分阻抗 $Z_{diff}$**,通常 90 Ω 或 100 Ω。
5. **共面波导(Coplanar)**:走线两侧(同层)也布了地铜,形成"三面"屏蔽,常用于射频、高密度板。

用 ASCII 区分结构:

```text
微带线(Microstrip)            带状线(Stripline)
┌── 空气 ──┐                  ┌── 介质(平面) ──┐
│  ══走线══ │  ← 信号           │  ══走线══       │
├══介质═════┤                  ├══介质══════════┤
├══地平面═══┤                  ├══地/电源平面════┤
                              ├══介质══════════┤
                              ├══地平面════════┤

差分对(Differential)          共面波导(Coplanar)
  ══走线A══   ══走线B══          GND║ ══走线══ ║GND
  ←耦合→ 间距S                    (同层两侧有地)
```

### 🔬 深入原理

**单端微带线**近似公式(见第2集)。**单端带状线**:

```text
Z0 ≈ (60/√εr) × ln( 1.9×H / (0.8×W + T) )   (对称带状线,H为到单侧平面距离)
```

**差分阻抗**与单端阻抗关系(边缘耦合微带):

```text
Zdiff ≈ 2 × Z0 × (1 − 0.48 × e^(−0.96×S/H))
```

其中 S 为两线间距,H 为到参考平面距离。可见:**间距 S 越小,耦合越强,差分阻抗越低**。所以控差分阻抗同时受线宽 W 和间距 S 两个旋钮控制。

**共面波导**额外受同层地铜到走线间隙 G 影响,间隙越小屏蔽越好、阻抗越低。射频常用"接地共面波导(GCPW)"以获得可控阻抗+良好屏蔽。

| 模型 | 位置 | 参考 | 特点 | 典型阻抗 |
|------|------|------|------|----------|
| 微带线 | 表层 | 1个平面(下方) | 易加工,受绿油影响 | 50 Ω 单端 |
| 嵌入式微带 | 表层+绿油 | 1个平面 | 比微带略低 | 50 Ω |
| 带状线 | 内层 | 上下2平面 | 最稳,抗扰强 | 50 Ω |
| 差分对 | 表/内 | 平面+互耦 | 抗共模干扰 | 90/100 Ω |
| 共面波导 | 表层 | 平面+同层地 | 屏蔽好,射频常用 | 50 Ω |

### 🛠 设计实例

- **例1(USB 90 Ω 差分)**:表层微带差分对,目标 90 Ω。给定 H=4 mil、W=6 mil,调 S 使差分阻抗落到 90 Ω(典型 S≈7–8 mil)。EDA 里建"差分规则"自动算。
- **例2(射频 50 Ω 共面波导)**:2.4 GHz 蓝牙天线馈线用 GCPW,线宽 10 mil、两侧地间隙 8 mil、H=5 mil,得到稳定 50 Ω 且屏蔽好,减少邻近数字信号串扰。

### ⚠️ 常见误区

- 把差分阻抗当成"单端阻抗×2"——实际因耦合, $Z_{diff}<2Z_0$,间距越小差得越多。
- 内层用微带公式算阻抗——**错**,内层是带状线,公式不同,会算错好几欧。
- 忽略绿油对嵌入式微带的影响,裸算导致实测偏低。
- 共面波导两侧地铜没打足够过孔连到主地,屏蔽失效。

### 📌 要点速记

1. 表层用微带线,内层用带状线,两者公式不同。
2. 差分阻抗由 W 和间距 S 共同决定,耦合越强阻抗越低。
3. 共面波导靠同层地铜屏蔽,射频/高密度常用。
4. 选模型要和叠层(第3集)匹配,层位错了算法就错。
5. 差分≠单端×2,务必用差分公式。

## 第5集：如何计算阻抗

### 📖 这一集讲什么

前面四集铺垫完毕,本集落到"动手算"。实际工程里算阻抗有三种路子,由粗到精:

1. **手工近似公式**:第2、4集给的那些经验式,适合快速估、心算、面试。缺点是忽略绿油、铜箔粗糙度、梯形截面,误差几欧姆。
2. **EDA/专业阻抗计算器**:如 SI9000(Polar)、Altium 阻抗计算、KiCad 内置、板厂在线工具。选对模型(微带/带状/差分/共面),填入 W、H、T、εr、绿油,直接出阻抗或反推线宽。**这是日常主力**。
3. **板厂反推 + 制前工程(PCB CAM)**:你把目标阻抗和叠层要求交给板厂,板厂用各自材料参数(真实 εr、铜粗度、压合厚度)反算最终线宽,并在生产稿里加"阻抗控制"工单,最后用 TDR 抽检实测。

流程建议:**自己先用 SI9000 算出版本 → 把层叠和阻抗要求写进叠层说明 → 发给板厂确认/反推 → 板厂回传最终线宽和公差 → 据此设 EDA 走线规则**。

### 🔬 深入原理

以 SI9000 为例,选 "Edge-Coupled Microstrip"(差分表微带),输入:

```text
H  (介质厚, 到参考平面)      = 4.0  mil
W  (线宽)                    = 6.0  mil
S  (差分间距)                = 7.5  mil
T  (铜厚, 1oz≈1.4mil)        = 1.4  mil
εr (FR-4)                    = 4.2
Coated (绿油)                = yes, 0.5mil
→ 输出 Zdiff ≈ 90 Ω (目标命中)
```

若想反推线宽(给定 Zdiff=90 Ω):固定其余,让软件扫 W 直到 Zdiff≈90,得到 W≈6.2 mil。

注意**铜箔粗糙度**:铜面不是镜面,粗糙会等效增大高频损耗并轻微降有效阻抗,高频(GHz 级)需用"粗糙度修正模型"(如 Hammerstad、Huray),否则算出的阻抗偏乐观。

**公差与实测**:板厂一般保证阻抗 ±10%(常见 ±7%~10%),TDR 实测在板边 coupon 上打点验证。设计时要留:①线宽制造公差(蚀刻侧蚀使成品线比设计细,阻抗偏高);②εr 批次波动。

### 🛠 设计实例

- **例1(6层板 50 Ω 反推)**:目标 50 Ω 单端微带,FR-4,εr=4.2,H=4.2 mil,T=1.4 mil,带绿油。SI9000 算出 W≈6.8 mil。发给板厂,板厂按实际 εr=4.3 回传 W=6.5 mil,EDA 规则设 6.5 mil ±0.5。
- **例2(100 Ω 差分 DDR 时钟)**:内层带状线差分,目标 100 Ω。给定 H=4.5 mil(到上下平面各 4.5)、T=1.4、εr=4.2,反推 W≈4.0 mil、S≈7.0 mil。布线时差分对紧耦合等长。

### ⚠️ 常见误区

- 用教学近似公式直接定量产线宽,不找板厂反推 → 批量阻抗漂移超差。
- 忽略蚀刻侧蚀:设计 7 mil,成品可能 6.3 mil,阻抗偏高,应预留。
- 把"标称 εr"写死,不问板厂实际值 → 算错。
- 不在生产文件里标注阻抗要求和参考层 → 板厂按通用工艺做,失控。
- 以为算完就完事,不做 TDR 抽检 → 无验证闭环。

### 📌 要点速记

1. 三手段:手工公式(估)→ EDA 计算器(主力)→ 板厂反推+TDR(落地)。
2. 务必把叠层 + 目标阻抗 + 参考层写进生产说明。
3. 铜箔粗糙度在 GHz 频段不可忽略,需修正模型。
4. 蚀刻侧蚀使成品线变细、阻抗偏高,要留公差。
5. 板厂保证 ±7%~10%,TDR 抽检形成验证闭环。

## 核心收获清单
- 特征阻抗 $Z_0=\sqrt{L/C}$,由几何与材料决定,与频率基本无关,是高速走线的核心属性。
- 阻抗不匹配会产生信号反射,导致振铃、过冲、眼图恶化,是高速设计首要敌人。
- 影响阻抗的四大因素是线宽、介质厚度、介电常数、铜厚(口诀"宽厚材铜")。
- 叠层设计要遵循"高速信号层紧邻完整参考平面",6 层板是性价比最高的高速叠层。
- 微带线(表层)、带状线(内层)、差分对、共面波导是四类常见阻抗模型,公式各不相同。
- 差分阻抗由线宽和间距共同决定,且 $Z_{diff}<2Z_0$,不可简单翻倍。
- 阻抗计算走"EDA 工具粗算 → 板厂反推 → TDR 实测"的闭环,不能只靠手算。
- 铜箔粗糙度和蚀刻侧蚀在量产中不可忽略,需留制造公差与材料波动余量。
- 绿油和阻焊会轻微降低表层阻抗(约 1–2 Ω),算阻抗须说明是否带绿油。
- 地平面勿随意开槽,避免高速信号跨槽导致回流绕行、EMC 恶化。
- 生产文件必须标注目标阻抗、参考层与叠层结构,否则板厂无法控阻抗。
- 本专题聚焦"为什么阻抗重要、怎么算、怎么叠层",是进入反射/端接/PI 等进阶主题的基础。

> **配套学习建议**:在掌握叠层与阻抗后,建议进一步学习高速信号完整性(反射与端接、串扰、时序等长)、电源完整性(PDN 设计与去耦)、EMC/EMI 设计,以及具体的 6 层板实战布线、DDR/PCIe/USB 等接口设计规范,形成"叠层—阻抗—布线—仿真—量产"的完整能力链。
