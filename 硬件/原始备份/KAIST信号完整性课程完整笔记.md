# 第一部分：导论与互连设计的重要性（第 1–2 讲）

## 1.1 什么是信号完整性

信号完整性（Signal Integrity, SI）研究的是：**信号波形从驱动器发出、经过互连（封装、PCB 走线、连接器、电缆、过孔等）、到达接收器之后，仍然能够被正确识别的程度**。

传统观念里导线只是"电的管道"——电压加上去，另一端就原样出现。这种"透明导线"假设在低速时代基本成立，因为信号波长远大于物理尺寸，互连表现为集总元件。但当信号边沿变得陡峭（上升时间进入 ns 甚至 ps 量级），互连的电气长度与信号的空间尺寸相当甚至更长时，互连本身变成了一个复杂的电磁系统，会产生：

- **反射（Reflection）**：阻抗不连续处信号反弹，造成过冲、下冲、振铃；
- **串扰（Crosstalk, XTalk）**：相邻走线通过电场（容性）与磁场（感性）耦合互相干扰；
- **损耗（Loss）**：导体损耗与介质损耗使高频分量衰减，边沿变缓；
- **码间干扰（ISI）**：前面比特的残余波形污染后面比特的判决点；
- **电源噪声（SSN/同步开关噪声，ΔI 噪声）**：大量驱动器同时翻转时电源网络电压波动；
- **电磁干扰（EMI）**：共模电流通过外部电缆/结构辐射出去。

课程强调的一个核心观念：**SI、PI（电源完整性）、EMI（电磁干扰）不是三个独立问题，而是同一物理系统的三种表现**。回流路径设计不当既产生 SI 问题，也产生 EMI 问题；电源噪声既造成 PI 违例，也转化为抖动（PSIJ）。设计时必须统一考虑。

## 1.2 判定"高速"的工程标准：边沿速率而非时钟频率

一个普遍的误解是"高速设计取决于时钟频率"。实际上决定互连是否表现出传输线行为的是**信号的上升/下降时间（边沿速率）**。

判断准则（工程经验值）：

| 准则 | 判定 |
|---|---|
| 互连长度（电气） < 上升沿空间延伸的 1/6 | 可视为集总电路，忽略传输线效应 |
| 互连长度 > 上升沿空间延伸的 1/6 | 必须按传输线（分布参数电路）分析 |

上升沿的空间延伸计算：

```
Len_Tr = Tr × v
v = c / √εr   （近似为光速的 1/√εr）
```

**例**：Tr = 1 ns，FR-4 微带线 εr_eff ≈ 3.5，则 v ≈ 3×10⁸/√3.5 ≈ 1.6×10⁸ m/s ≈ 16 cm/ns。上升沿空间延伸 16 cm，其 1/6 ≈ 2.7 cm。也就是说，**哪怕时钟只有 1 MHz，只要芯片边沿是 1 ns，超过 2.7 cm 的走线就是"高速走线"**。这也是为什么现代设计里几乎所有的互连都要按高速信号处理——先进工艺的 CMOS 驱动器即使在小数据率场合也能输出 1 ns 以下的边沿。

带宽与上升时间的关系：

```
BW ≈ 0.35 / Tr
```

Tr = 1 ns → BW ≈ 350 MHz；Tr = 100 ps → BW ≈ 3.5 GHz。设计互连时需要关心的频率成分远高于时钟频率。

## 1.3 数据率演进与设计挑战

- 并行总线（共享地址/数据总线）→ 点对点差分串行链路（PCIe、DDR 数据眼、SerDes）演进；
- 数据率从几百 Mb/s 发展到 224 Gb/s+/lane（PAM4 及更高速率）；
- 每一次速率提升都把"裕量"吃掉一部分：眼图高度、抖动裕量、电压裕量、时序裕量。
- 时序预算（timing budget）概念：建立/保持时间要求 + 时钟偏斜 + 抖动 + 走线飞行时间偏差 + 负载效应，所有项目之和必须小于一个时钟周期。速率越高，预算中留给"意外"的份额越小，SI 控制越严格。

1. **拓扑/方案层**：单端还是差分？端接放哪里？菊花链还是星型？

3. **电源/噪声层**：PDN 阻抗、去耦策略、平面谐振控制。

## 1.5 同步开关噪声（SSN）与 ΔI 噪声详解

当芯片内大量输出驱动器（例如 64 位数据总线）在同一个时钟沿同时翻转时，会在极短时间内抽取很大的瞬态电流。这个电流必须流经：片上电源网格 → 封装引脚/焊球的电感 → PCB 去耦网络 → VRM。整个回路存在寄生电感 L_loop，于是产生电压突变：

```
ΔV = L_loop · (dI/dt)
```

这个 ΔV 叠加在电源与地之间，就是**同步开关噪声（SSN）**，也称 ΔI 噪声、地弹（当主要表现在地路径时）。它的特点：

1. **与翻转的驱动器数量成正比**：N 个驱动器同时翻转，电流摆幅近似 N 倍；
2. **与电流变化率成正比**：边沿越快越严重——这就是为什么很多 FPGA/ASIC 允许编程调整输出驱动强度（drive strength）与压摆率（slew rate），在时序裕量允许时主动放慢边沿；
3. **表现为芯片本地参考的跳动**：芯片的"地"相对板级地上下浮动，所有以该地为参考的信号都被调制，等价于同时叠加了噪声与抖动（PSIJ 的物理根源之一）。

工程缓解手段汇总：

| 手段 | 原理 | 效果 |
|---|---|---|
| 增加电源/地引脚数量 | 并联电感减小 | 直接降低 L_loop |
| 封装内去耦电容（封装盘电容） | 高频电流就地供给 | 覆盖数百 MHz–数 GHz |
| 降低 dI/dt | 放缓边沿、分时翻转（staggered switching） | 线性改善 |
| 芯片下正对放去耦电容阵列 | 回路面积最小 | 板级最有效 |
| 薄介质电源地平面对 | 平面电感小 | 板级结构性改善 |

## 1.6 时序预算完整计算实例

以一条源同步总线（类似 DDR 写通道）为例演示预算编制方法。

设定：周期 T = 5 ns（200 MHz）、接收端建立时间 tSU = 1.0 ns、保持时间 tH = 0.8 ns。

| 预算项 | 数值（ns） | 说明 |
|---|---|---|
| 时钟偏斜（skew） | 0.30 | 时钟树+PCB 时钟线偏差 |
| 数据线间偏差（组内 skew） | 0.40 | DQ 之间飞行时间差 |
| 驱动抖动（含 PSIJ） | 0.35 | 芯片数据手册 |
| 接收器抖动 | 0.25 | 采样窗不确定度 |
| 串扰引起的数据相关偏移 | 0.30 | 仿真/经验 |
| ISI 引起的眼图塌陷 | 0.50 | 信道仿真 |
| 预留工程余量 | 0.40 | 20% 左右 |
| **合计** | **2.50** | |

可用于数据的窗口：T − tSU − tH = 5.0 − 1.0 − 0.8 = 3.2 ns；预算占用 2.5 ns 后**剩余有效裕量 0.7 ns**。如果速率翻倍（T = 2.5 ns），可用窗口缩到 0.7 ns，预算直接爆掉——必须把各项压缩（ODT、更强均衡、更好板材、更严等长），这正是高速化过程中 SI 越来越难的本质：**预算条目不会自动消失，只会被逐项压缩**。

## 1.7 SI、PI、EMI 的统一物理图景

课程反复强调三者共享同一物理机理——**电流总是要走回路，而回路怎么走决定了三者的表现**：

| 现象 | 物理根源 | 表现 |
|---|---|---|
| SI 恶化 | 回流路径被扰动 → 阻抗不连续/噪声叠加 | 反射、眼图塌陷 |
| PI 恶化 | 回流路径阻抗（频变）超标 | 电源纹波、droop、PSIJ |
| EMI 超标 | 回流环路面积大 → 磁场辐射；共模电流外流 | 辐射/传导发射超标 |

由此得出高速设计的第一性原则：**每一条信号、每一个电源域，从源头到终点都要能画出一条明确的、几何上紧凑的回流路径。** 所有设计规则（完整参考平面、缝合过孔、去耦靠近、差分对称、地孔跟随）都是这条原则的具体化。

# 第二部分：传输线理论基础（第 3 讲）

## 2.1 从集总到分布

把一根均匀传输线切成极小段 dz，每段用如下单元电路等效（RLCG 模型）：

- R：单位长度串联电阻（导体损耗，Ω/m）
- L：单位长度串联电感（回路电感，H/m）
- C：单位长度并联电容（信号线到参考平面，F/m）
- G：单位长度并联电导（介质损耗，S/m）

当段长 dz→0 时，得到**电报员方程（Telegrapher's Equations）**：

```
∂V/∂z = -(R + jωL)·I
∂I/∂z = -(G + jωC)·V
```

其解为沿 +z 和 −z 方向传播的波的叠加：

```
V(z) = V⁺·e^(-γz) + V⁻·e^(+γz)
```

其中 γ 为传播常数：

```
γ = √[(R + jωL)(G + jωC)] = α + jβ
α：衰减常数（Np/m），β：相位常数（rad/m）
```

## 2.2 特性阻抗

行波电压与电流之比定义为特性阻抗：

```
Z0 = √[(R + jωL)/(G + jωC)]
无损近似（R、G 很小）：Z0 ≈ √(L/C)
```

**物理理解**：Z0 不是导线的直流电阻，而是"波在传播过程中每往前推进一点，所遇到的瞬时阻抗"。它由几何结构与介质决定（L 与 C 的比值），与线长无关。

典型值：同轴电缆 50 Ω/75 Ω；PCB 单端走线通常 50 Ω；USB 差分 90 Ω；以太网差分 100 Ω。

## 2.3 相速、传播延迟与波长

```
vp = 1/√(LC) = c/√εr        （无损）
tpd = √(LC) = √εr / c        （每单位长度延迟）
```

- FR-4 基材（εr ≈ 4.2）内层带状线：vp ≈ c/2.05 ≈ 1.47×10⁸ m/s，tpd ≈ 6.8 ps/mm ≈ 170 ps/inch；
- 微带线因为电场一半在空气中，用**有效介电常数 εr_eff**（介于 1 和基材 εr 之间）；
- 设计中"1 ns 大约走 15~17 cm"是 FR-4 上的常用记忆值。

## 2.4 有损传输线：两类损耗

### 趋肤效应（导体损耗）

频率升高时电流趋向导体表面流动，电流分布集中在厚度为趋肤深度 δ 的表层：

```
δ = √(2 / (ω·μ·σ)) = 1/√(π·f·μ·σ)
铜在 1 GHz 时 δ ≈ 2.1 μm
```

后果：
- 高频电阻 R_ac ∝ √f，衰减 α_c ∝ √f；
- 粗糙铜箔表面（牙状起伏）进一步增加损耗，需用**粗糙度修正因子**（Huray 雪球模型、Hammerstad 模型等）；
- 高频电流在参考平面上也不是均匀流过，而是集中在走线正下方（回流电流分布，见第 21 讲）。

### 介质损耗

介质的极化滞后造成损耗，用损耗角正切 tanδ 描述：

```
α_d = π·f·√εr·tanδ / c   （Np/m）
```

关键规律：**介质损耗与频率成正比（α_d ∝ f），趋肤损耗与 √f 成正比**。因此：
- 低频段导体损耗主导；
- 高频段（多 GHz 以上）普通 FR-4 的介质损耗主导——这是高速板材（低 Df：Megtron、Rogers 等）存在的理由。

| 材料类型 | Dk（εr） | Df（tanδ，@1GHz 量级） | 典型应用 |
|---|---|---|---|
| 普通 FR-4 | ~4.2–4.5 | 0.015–0.025 | ≤几 Gb/s |
| 中速板材（Megtron4 等） | ~3.7 | ~0.005 | 10–28 Gb/s |
| 低损耗 PPO/PPE 类 | ~3.2–3.6 | 0.002–0.004 | 28+ Gb/s |
| PTFE/陶瓷（Rogers） | 2.2–3.5 | 0.001–0.002 | 射频/超高速 |

## 2.5 微带线与带状线

| 特性 | 微带线（外层） | 带状线（内层） |
|---|---|---|
| 参考 | 一个平面（下方） | 上下两个平面 |
| 场分布 | 一半在空气，一半在介质 | 全部在介质中 |
| 有效 εr | εr_eff < εr（1 < εr_eff < εr） | εr |
| 速度 | 较快 | 较慢 |
| 串扰 | 较大 | 较小（两面都有屏蔽） |
| 受加工影响 | 走线表面阻焊/氧化影响阻抗 | 受蚀刻/层偏影响 |

阻抗的近似公式（微带线，IPC 或 Hirschowitz 近似）概念上可归纳为依赖四个几何/材料变量：

```
Z0 主要由 4 个变量决定：
① 线宽 w（越宽 Z0 越低）
② 介质厚度 h（越厚 Z0 越高）
③ 介电常数 εr（越高 Z0 越低）
④ 铜厚 t（越厚 Z0 越低）
```

工程上用场求解器或 Polar/Si9000 类工具计算，不必手算，但**必须理解四个变量的方向性**，才能在板厂反馈"阻抗超差"时正确调整。

## 2.6 RLCG 参数的物理来源与数量级直觉

掌握典型 FR-4 50 Ω 走线的单位长度参数量级，对估算非常有用：

| 参数 | 典型量级（50 Ω FR-4） | 物理来源 |
|---|---|---|
| L（回路电感） | ~350 nH/m（约 8.9 nH/inch） | 信号线自感 + 与回流平面的互感（互感越大回路电感越小——所以平面越近 L 越小） |
| C | ~140 pF/m（约 3.5 pF/inch） | 信号线与参考平面正对面积 |
| R（DC） | 取决于铜厚线宽 | 0.5 oz 铜厚、6 mil 线宽约 0.1 Ω/inch |
| G | 与 tanδ 成正比 | 介质漏电与极化损耗 |

验算：Z0 = √(L/C) = √(350e-9/140e-12) = 50 Ω。tpd = √(LC) = √(350e-9 × 140e-12) ≈ 7 ns/m = 7 ps/mm，与 FR-4 惯用值吻合。

**邻近效应补充**：两根电流方向相反的导线（信号与回流）靠近时，电流会相互靠近集中（与趋肤效应共同作用），使有效电阻进一步上升、回路电感进一步下降。这就是"回流电流集中在走线正下方"在导体内部机理层面的原因。

## 2.7 损耗与眼图闭合的定量联系（算例）

一条 20 inch（约 0.5 m）的 FR-4 背板走线，Df = 0.02，εr = 4.2：

- 介质损耗 α_d（dB/m，工程式）≈ 91.2·f(GHz)·√εr·Df ≈ 91.2·f·2.05·0.02 ≈ 3.74·f(GHz) dB/m；
- 6.25 Gb/s NRZ 的 Nyquist 频率 = 3.125 GHz → 0.5 m 走线介质损耗 ≈ 5.9 dB；加上趋肤与铜箔粗糙度，总插损常达 −10 ~ −12 dB @ Nyquist；
- 经验规律：**信道的 ISI 眼图在总插损超过 −12 ~ −15 dB（@Nyquist）后基本闭合，必须依赖均衡打开**。

这个算例解释了：为什么 6–10 Gb/s 是"传统设计"的上限，超过它就必须上均衡（第 14 讲内容在此埋下伏笔）；也解释了低 Df 板材的意义：Df 从 0.02 降到 0.005，同样的走线损耗降为 1/4，对应可传输距离×4。

## 2.8 传输线类型与工程选择

| 类型 | 截面特征 | 电气特征 | 工程用途 |
|---|---|---|---|
| 带状线（stripline） | 两参考面之间，全介质 | 串扰小、FEXT 理论为零、对环境不敏感 | 高速关键信号首选 |
| 微带线（microstrip） | 表层，一面空气 | 速度快、加工成本低、受阻焊影响 | 布线密度高的表层、BGA 扇出 |
| 嵌入式微带 | 表面覆盖阻焊/介质 | 介于两者之间 | 常见实际形态（阻焊影响阻抗 1–3 Ω） |
| 共面波导（CPW/GCPW） | 信号线两侧紧邻地 | 对地过孔缝合敏感、屏蔽好 | 射频、毫米波 |

选择策略：低速/一般信号表层微带省层；高速差分与时钟走内层带状线；射频走 CPW 并密缝地孔。

# 第三部分：阻抗与回流路径（第 4 讲）

## 3.1 瞬时阻抗与受控阻抗

信号沿传输线行进的每一步，都会在"当前瞬间"对线充电。若整条线均匀，则每一瞬间看到的阻抗恒等于 Z0——这称为**受控阻抗（controlled impedance）设计**。

只要任何一点瞬时阻抗发生变化（线宽变化、换层、过孔、接插件、封装引脚、线距变化……），信号就会发生部分反射并使传播失真。**高速设计的本质，就是管理整条信号路径上所有不连续点的瞬时阻抗。**

## 3.2 回流路径是阻抗的一半

一根走线的特性阻抗、电感、电容，都不是这根"线自己"的属性，而是**这根线与其回流路径共同构成的回路属性**：

- L 是回路电感；C 是走线对回流导体的电容；
- 没有明确回流路径的信号线，其阻抗是未定义且不受控的。

高频回流电流的分布规律（重要，贯穿全课程）：

> **回流电流并不在整个参考平面上均匀流回，而是集中在信号走线正下方附近，随偏离距离快速衰减。**

近似分布（走线距平面高度 h）：

```
J(d) ∝ 1 / [1 + (d/h)²]
```

有效宽度约等于几倍 h（工程记忆：回流电流约 95% 集中在走线下方 ±3h 范围内）。推论：

1. **走线下方的参考平面区域就是信号"占用"的地**，密集布线时每根线各自使用自己正下方的地，互不冲突；
2. 任何在参考平面上开的槽、孔、分割，只要切断或压缩了这条"正下方通道"，都会造成回流绕行 → 局部电感增大 → 阻抗不连续 → 反射与 EMI。

## 3.3 阻抗不连续的典型来源清单

| 不连续源 | 典型影响 | 缓解手段 |
|---|---|---|
| 线宽/线距变化 | 局部 Z0 跳变 | 保持等宽；必须变宽时用渐变/45°过渡 |
| 过孔（stub + barrel 电容） | 容性不连续 | 背钻、盲埋孔、减小焊盘、反焊盘加大 |
| 换参考层 | 回流路径中断 | 靠近放缝合过孔（同层对）或缝合电容（异层对） |
| 连接器/金手指 | 结构突变 + 短桩 | 选低不连续连接器、地孔围绕 |
| 芯片封装引脚/焊球 | 电感突变 | 封装协同设计 |
| 走线拐角 | 拐角处宽度等效增大（45°/圆角影响很小，90° 角在 10G 以上才明显） | 高速用 45° 或圆弧 |
| 残桩（stub）：未使用的分支/背板分支 | 传输线开路 stub 形成 1/4 波长谐振 | 禁止 T 分支；背钻 |

## 3.4 50 Ω 的由来（工程文化知识）

- 空气同轴线在约 77 Ω 时损耗最小，在约 30 Ω 时功率容量最大；
- 50 Ω 是两者的折中，后来成为射频与数字系统的约定俗成标准；
- PCB 上 50 Ω 也刚好落在"线宽适中、介质厚度适中、便于制造"的区域。

# 第四部分：传输与反射（第 5 讲）

## 4.1 反射系数

当行波从阻抗 Z1 区域进入 Z2 区域，在交界处发生反射与透射：

```
反射系数：Γ = (Z2 - Z1) / (Z2 + Z1)
透射系数：T = 2·Z2 / (Z1 + Z2)   （电压透射）
```

边界情形：

| 负载情况 | Γ | 物理现象 |
|---|---|---|
| 开路（Z2 → ∞） | +1 | 全反射同相，负载端电压翻倍 |
| 短路（Z2 = 0） | −1 | 全反射反相，负载端电压为零 |
| 匹配（Z2 = Z1） | 0 | 无反射，能量全部吸收 |
| 容性负载 | 频变 | 低频近似短路 → 负反射（下冲）后充电恢复 |
| 感性负载 | 频变 | 低频近似开路 → 先全反射后放电 |

## 4.2 弹跳图（Bounce Diagram / Lattice Diagram）

分析多次反射的标准工具。设源内阻 RS、线阻抗 Z0、负载 RL：

- 初始发射波幅度：V1 = Vs·Z0/(RS+Z0)；
- 负载反射系数：ΓL = (RL−Z0)/(RL+Z0)；源端反射系数：ΓS = (RS−Z0)/(RS+Z0)；
- 波在两端来回反射，每次往返乘 ΓL·ΓS；
- 最终收敛于直流分压 Vs·RL/(RS+RL)。

**经典案例——欠驱动的振铃**：当 RL 开路（ΓL=+1）、RS < Z0（ΓS<0）时，负载端波形出现典型的阶梯振荡（过冲→下冲→…），即"振铃"。若 RS > Z0 则阶梯单调收敛，无过冲。这就是串联端接（第 6 讲）的原理基础。

## 4.3 反射造成的时序/可靠性危害

- 过冲/下冲：可能超过芯片 ESD 结构导通阈值，长期可靠性受损；
- 振铃拖尾在采样点未稳定 → 建立时间违例；
- 多负载总线各分支反射叠加 → 波形随码型变化（数据相关抖动）。

# 第五部分：终端匹配与多次反射（第 6 讲）

## 5.1 端接的目的

在信号传播的某个位置人为加入电阻网络，使**从信号角度看过去的阻抗等于 Z0**，从而吸收行波、消除（或大幅减少）反射。

## 5.2 四种经典端接方式对比

| 端接方式 | 结构 | 优点 | 缺点 | 适用 |
|---|---|---|---|---|
| 串联端接 | 源端串 R，使 RS+R = Z0 | 功耗小、不增加直流负载、单负载点对点最佳 | 只适合一个负载/近端负载；上升沿减半（分压） | 点对点、总线少量负载在末端 |
| 并联端接 | 负载端并 R=Z0 到地 | 全速、拓扑自由 | 一直有直流电流（功耗大）、拉低高电平 | 差分/特定背板 |
| 戴维南端接 | 负载端 R 上拉+R 下拉，并联等效 = Z0 | 兼容 CMOS/TTL、可调电平 | 静态功耗更大、阻值非标 | 双向总线 |
| AC 端接 | R 串 C 后并在负载端 | 无直流功耗 | 时间常数受码型影响、电容引入不连续 | 低速总线、内存类 |

选择流程（工程 checklist）：

1. 拓扑是不是点对点？是 → 优先串联端接；
2. 有多个负载？先问能否改为菊花链+末端一次端接；星型拓扑最难处理，应尽量避免；
3. 功耗预算紧张 → 避免戴维南；
4. 差分对 → 差分端接电阻跨接在两线之间（有时另加共模端接）。

## 5.3 端接电阻的布局细节

- 串联端接电阻尽量靠近驱动器（让源端反射段最短）；
- 并联/戴维南端接电阻尽量靠近最后一个负载；
- 端接电阻的焊盘、走线本身就是不连续点，高速场合用优化焊盘几何；
- 端接器件下方保持完整参考平面。

## 5.4 多次反射工程案例：为什么 T 分支/菊花链中段端接很危险

- 每个分支都是一段开路 stub，入射波到达分支点被分裂并部分反射；
- stub 长度接近信号上升沿的 1/4 波长时反射叠加最严重；
- 规则：**stub 电气长度 < Tr/6 可忽略；否则禁用**。背板总线改点对点或串行差分是根本解法。

---

## 5.5 端接设计完整算例（串联端接数值计算）

条件：驱动器 RS = 10 Ω，线 Z0 = 50 Ω，Tr = 1 ns，线长 15 cm（FR-4，tpd ≈ 6.7 ps/mm → 单程延迟 1 ns），负载为高阻接收器 + 5 pF 输入电容。

**第 1 步：判断是否需要端接。** 上升沿空间延伸 = 1 ns × 15 cm/ns = 15 cm > 线长，线长约为 Tr 延伸的 1 倍（大于 1/6 判据），需按传输线处理。开路负载 ΓL = +1，RS < Z0（ΓS = (10−50)/(10+50) = −0.67），源端欠驱动 → 必然振铃 → 端接。

**第 2 步：串联端接值。** Rseries = Z0 − RS = 40 Ω（取标称 39 Ω）。此时源端看到 50 Ω，初始发射波幅度 = Vs·50/50 = Vs（全幅发射）。

**第 3 歲：核对波形过程。**

1. t=0：源端发出 Vs 的半幅（对总摆幅而言）行波（因为负载端会反射回来加倍）；
2. t=1 ns：波到达负载，ΓL=+1 全反射，负载端瞬时达到 Vs（开路倍压）；
3. t=2 ns：反射波回到源端，源端阻抗 50 Ω 恰好匹配，无再反射，吸收完毕；
4. 稳态：分压 Vs·∞/(50+50) = Vs（负载高阻，全部电压在负载侧）。

结果：负载端一次到达即稳定（一倍延迟后干净的单调阶跃），这正是串联端接"波只走一个来回"的理想行为。

**第 4 步：容性负载修正。** 5 pF 与 50 Ω 构成时间常数 τ = 250 ps < Tr/5，边沿被轻微放缓（可接受）；若 Cload 大（如 20 pF），末端呈 RC 充电，反射系数在边沿期间近似 −1 → 出现明显下冲，此时需评估戴维南/并联端接。

## 5.6 DDR 系列的 ODT（片上端接）机制

DDR 内存接口是"单端 + 多负载 + 点对点（现代 DDR 已是点对点）"的典型，其反射管理核心是 ODT：

- DRAM 芯片内部集成可编程端接电阻（通过 MRS 寄存器配置，如 34/40/48/60/120 Ω 档位）；
- **写操作时**：DRAM 端 OTD 使能（吸收控制器发来的波）；**读操作时**：控制器端 ODT 使能——即端接始终跟随"谁是接收方"动态切换；
- 控制器侧还有**输出阻抗可调（驱动强度）**，与 ODT 配合把整条链路调到近似匹配；
- VTT 中间电压 + SSTL 端接结构：命令/地址总线经典戴维南端接到 VTT（= VDDQ/2）；
- 设计含义：**DDR 的 SI 仿真必须包含发送/接收两侧的阻抗配置组合**（所有 ODT × 驱动强度档位的矩阵扫描），从中选出时序/眼图最佳的组合——这是与普通点对点串联端接最大的不同。

## 5.7 反射定位与调试：TDR 原理

时域反射计（TDR）向被测互连发送快速阶跃，同时测量入射端口电压：

- 阻抗突变的**位置** = 时间差 × v/2（往返取半）；
- 突变的**性质**从波形形状判读：
  - 向上台阶 → 阻抗升高（变窄、开槽、串接电感）；
  - 向下台阶 → 阻抗降低（变宽、容性过孔、焊盘）；
  - 振荡 → 感性/容性复合；
- 分辨率取决于阶跃边沿（~10 ps 系统 ≈ 1.5 mm FR-4 分辨率）；
- 现代示波器 TDR + S 参数（频域）互为傅里叶变换，结合使用。

调试 checklist：眼图差 → 先看 TDR/RL 频域回损定位不连续 → 检查该位置的结构（过孔/焊盘/线宽）→ 修改后复测。

# 第六部分：单端信号传输（第 7 讲）

## 6.1 单端 vs 差分的本质

- 单端信号：一根信号线 + 共享参考（地/电源）回路，电压相对参考判读；
- 差分信号：两根线传输互补信号（V+ 与 V−），接收器判读**差分电压 Vdiff = V+ − V−**；
- 单端的优势：引脚数少、驱动简单、功耗低；劣势：对参考地噪声、共模干扰敏感；
- 差分的优势：抗共模干扰、偶次谐波抵消、EMI 辐射低、适合高数据率；劣势：引脚翻倍、布线更复杂。

## 6.2 单端信号的工程要点

1. **参考平面必须连续**：单端信号的回流完全依赖参考平面，跨分割是单端信号的头号问题；
2. **地弹（ground bounce）**：多个驱动器同时翻转，回流电流流过芯片地引脚/封装/去耦回路的电感，使芯片本地"地"相对板级地跳动。缓解：更多地引脚、封装内去耦、降低同时翻转输出数（SSO 控制）、输出边沿放缓；
3. **总线负载效应**：每个接收端都是容性负载挂在总线上，使有效特性阻抗降低、延迟增大（近似 Z0' = Z0/√(1+Cd/C)，tspd' = tspd·√(1+Cd/C)）；
4. **端接策略**见第 6 讲；多点总线（如老式地址/数据总线）本质上是反射管理问题，被现代点对点差分串行化替代。

## 6.3 单端信号依然广泛存在的场景

- DDR 存储器接口（数据 DQ 仍是单端，用 VTT 端接、ODT 片上端接技术管理反射；命令/地址走的是"伪差分/单端+ODT"）；
- 时钟信号（常为差分以抗干扰）；
- 低速控制信号、I²C/SPI、GPIO。

# 第七部分：差分线理论（第 8 讲）

## 7.1 奇模与偶模

差分对上的信号可以分解为两种标准模式：

- **奇模（odd mode）**：两线驱动等幅反相（+1/−1），即纯差分信号；
- **偶模（even mode）**：两线驱动等幅同相（+1/+1），即纯共模信号。

| 参数 | 定义 | 关系 |
|---|---|---|
| 奇模阻抗 Zodd | 奇模激励下单根线对地的阻抗 | Zodd < Z0（互容增大/互感减小） |
| 偶模阻抗 Zeven | 偶模激励下单根线对地的阻抗 | Zeven > Z0 |
| 差分阻抗 | Zdiff = 2·Zodd | 100 Ω 差分 ↔ 50 Ω 奇模 |
| 共模阻抗 | Zcomm = Zeven / 2 | |

耦合程度影响：两线靠得越近，Zodd 与 Zeven 差别越大；紧耦合使 Zdiff 下降（要达到 100 Ω 需要更窄的线）。

## 7.2 紧耦合 vs 松耦合的工程取舍

| 维度 | 紧耦合（线距 < 2 倍线宽） | 松耦合（线距 ≥ 3 倍线宽） |
|---|---|---|
| 抗共模/抗串扰 | 好（外部干扰在两线上近似等量，被减法抵消） | 稍差 |
| 布线密度 | 占空间小 | 占空间大 |
| 对走线偏差敏感度 | 换层/局部绕线时模式转换更复杂 | 容忍度更高 |
| 阻抗受邻线影响 | 大 | 小 |
| 阻焊/加工偏差敏感度 | 高 | 低 |

工程主流做法：中等偏松耦合（线距 2–3 倍线宽），把 EMI 控制交给完整的参考平面和对称设计，而不是极端紧耦合。

## 7.3 差分信号的四个关键设计规则

1. **等长**：两线长度差控制目标由时序决定。0.15 mm（6 mil）FR-4 内层差分延迟 ≈ 1 ps。例如要求 intra-pair skew < 5 ps → 长度差 < 0.75 mm。更高速率（PCIe/112G）要求 ps 甚至亚 ps 级；
2. **对称**：两线的过孔数、换层、参考平面、端接位置必须对称，否则差分→共模转换（见第 10 讲）；
3. **参考平面完整**：差分信号的主要回流仍然在参考平面上（尤其松耦合时），"差分对不需要参考平面"是错误说法；
4. **间距**：对外的对间隔离 ≥ 3–4 倍线宽（或按仿真确定），防止对间串扰。

## 7.4 差分对的串扰免疫力从何而来

外部 aggressor 在两根线上感应的噪声近似共模（等量同相），接收器做减法时抵消；两线相反的电流产生的远场辐射也部分抵消——因此 EMI 更低。但注意：**任何不对称（长度、邻线环境、过孔）都会把共模能量转化为差分噪声**，抵消效果随之劣化。

---

## 7.5 模式转换算例与共模控制量化

**Skew 转换算例**：一对差分线，D=1 mm 长度差（FR-4 内层 ≈ 6.7 ps skew）。对 20 GHz 分量（周期 50 ps），skew 占 13% 相位 → Sdc21 量级估算约 −17 dB。若链路要求 Sdc < −25 dB，允许 skew ≈ 0.4 mm 量级。这说明：**对称性要求可以从频域指标反推为长度公差**，比笼统的"尽量等长"可执行得多。

**LVDS 电平验算**：恒流源 I = 3.5 mA 流过接收端 100 Ω 跨阻：Vdiff = 3.5 mA × 100 Ω = 350 mV。两线各自摆幅 ±175 mV（单端 350 mVpp），共模恒定约 1.25 V。这个例子同时解释了 LVDS 为何低功耗（恒 3.5 mA，与速率无关）以及为何抗共模（接收器只看差）。

**差分端接的π型网络计算**：若要同时端接差模 100 Ω 与共模 50 Ω（单线对地偶模 100 Ω，两线并联对地 50 Ω）：差模路径两个 R/2 串联 = R；共模路径两条 (R/2 ∥ …) 对地——设计成 R = 100 Ω、每线到地 100 Ω 的π网络，共模等效 = 50 Ω。工程上按此列方程即可，注意所有电阻的寄生电感在 10G+ 时同样要仿真。

## 7.6 差分对的布线实操规则

1. 蛇形等长在**松绕距**下进行：间距 ≥ 3~4 倍线宽，否则绕线段自耦合（内圈对外圈串扰）反而制造模式转换与 ISI；
2. 蛇形段应放在走线中段而不是端接附近；
3. 过孔数量两线严格一致，过孔位置镜像对称；
4. 不要为凑长度在最后一刻绕大圈——改变参考环境本身就是新的不连续；
5. 等长优先在**松耦合的对内**用小幅度调整；大幅度 skew 宁可换层分段处理；
6. 表层差分进出 BGA 扇出区时用颈缩（neck-down），颈缩段计算入阻抗预算（用 2D 求解器确认局部阻抗偏移量与长度，短于 Tr/6 可接受）。

# 第八部分：差分信号方案（第 9 讲）

## 8.1 差分接口电平与实例

| 接口 | 差分阻抗 | 典型速率 | 备注 |
|---|---|---|---|
| LVDS（TIA/EIA-644） | 100 Ω | ≤ ~1 Gb/s（可更高） | 低摆幅 350 mV、恒流源 3.5 mA |
| CML（电流模式逻辑） | 50 Ω 单端/100 Ω 差分 | 10–56+ Gb/s | SerDes 主流，尾电流+端接 |
| PCIe | 85/100 Ω | 2.5→32 GT/s | 内置均衡（FFE/CTLE/DFE） |
| USB 2.0 / USB3 | 90 Ω | 480 Mb/s / 5–20 Gb/s | |
| 以太网 1000BASE-T 等 | 100 Ω | 变压隔离、PAM 编码 | |
| HDMI/MIPI D-PHY | 100 Ω 差分 | Gb/s 级 | 源同步、多 lane |
| DDR 时钟/命令（部分代差分化） | 100/120 Ω | — | VREF 相关 |

## 8.2 LVDS 要点

- 摆幅典型 350 mV，共模约 1.25 V；
- 驱动器为恒流桥（4 个 MOS 开关切换电流方向），数据率本质不受输出摆幅限制；
- 端接 100 Ω 跨接在接收端两线之间；
- 功耗与数据率基本无关（恒流），比 CML 功耗低，速率上限低于 CML；
- 板级设计仍需要受控 100 Ω 差分阻抗与对称布局。

## 8.3 差分端接方案

- **差分端接**：R = Zdiff 跨接两线（最常用）；
- **π 型端接**：各线到地各一个 R/2 + 差分一个 R，同时端接差模与共模（牺牲功耗）；
- **共模端接**：对共模噪声大的链路增加共模端接/共模扼流圈（CMF）；
- 片上端接（ODT）已在多数高速 SerDes 中内置，板级可不再外加。

## 8.4 源同步接口 vs 嵌入式时钟

- 源同步（DDR DQ/DQS、老式 SPI 类）：随数据同发一个时钟/选通，飞行时间匹配要求"数据组内、组间对齐"——长度匹配的目标不是绝对等长而是相对关系正确；
- 嵌入式时钟（SerDes）：时钟从数据中恢复（CDR），板级不再做全局等长，改为控制 intra-pair skew 与插入损耗不均匀性；重点转向信道损耗、ISI、抖动传递。

# 第九部分：共模产生与电磁干扰（第 10 讲）

## 9.1 共模是什么

- 共模电压：Vcomm = (V+ + V−)/2；
- 差分信号理想时共模恒定（如 LVDS 的 1.25 V）；
- 实际中共模会随时间波动：驱动器占空比失真、上升/下降不对称、走线不对称、参考平面突变都会产生**共模分量**。

## 9.2 模式转换（Skew/对称性引起的 SCD/Sdc）

- 一对不等长的差分线：信号能量的一部分从差模转换为共模（时域上：fast leg 与 slow leg 交点轨迹上下波动形成共模波纹）；
- S 参数表述：SCD21（差模入→共模出）应尽量小（典型要求 < −20 ~ −30 dB）；
- 1 ps 的 skew 在数 GHz 频段可产生 −30 dB 量级的转换——速率越高对称性要求越苛刻。

## 9.3 共模为什么是 EMI 的罪魁祸首

- 差模电流：两线大小相等方向相反，远场辐射几乎抵消；
- 共模电流：两线同方向流动，经由大地/电缆/机壳构成的巨大环路返回，辐射效率高；
- 经验数量级：**几 μA 的共模电流（流经长电缆）造成的辐射即可超标**，而差模需要 mA 级以上；
- 共模辐射场强 ∝ f²·I_cm·环路面积——频率越高越严重。

## 9.4 抑制共模/EMI 的设计手段

1. 差分对严格对称（等长、同过孔数、同层、同环境）；
2. 回流路径连续，禁止跨分割；
3. 板边缘走线内缩 ≥ 20H（相对介质厚度）抑制边缘辐射；
4. 共模扼流圈（CMF）：对共模呈高阻、差模低损；
5. 电缆屏蔽层 360° 搭接机壳（猪尾巴接地是辐射大忌）；
6. 接口处对地放 ESD/滤波电容时注意对差分平衡的影响（两线对称放）；
7. 系统级：金属屏蔽、导电衬垫、螺钉接地间距 < λ/20。

# 第十部分：近端串扰与远端串扰（第 11 讲）

## 10.1 串扰机理：两条耦合通道

攻击线（aggressor）与受害者（victim）之间：

- **容性耦合**：通过线间互电容 Cm，电流 i = Cm·dV/dt，与攻击线电压变化率成正比；
- **感性耦合**：通过互感 Lm，在受害线上感应出电压，与攻击线电流变化率 dI/dt 成正比；
- 两端看到的串扰分别称为**近端串扰（NEXT）**与**远端串扰（FEXT）**。

## 10.2 后向（近端）串扰的特性

- 串扰波向源端反向传播；
- **饱和特性**：耦合长度超过饱和长度（约为上升沿空间延伸的一半）后，NEXT 幅度不再随长度增长，达到饱和值；
- 饱和值由耦合系数决定（约正比于 Cm·Z0 与 Lm/Z0 之和）；
- NEXT 脉冲宽度 ≈ 2×耦合线段延迟（来回程）。

## 10.3 前向（远端）串扰的特性

- 串扰波与攻击信号同向同速传播，沿途不断叠加；
- 容性与感性耦合在前向方向**极性相反**，在**均匀介质（带状线/同轴）中两者抵消，理论上 FEXT ≈ 0**；
- 在**非均匀介质（微带线，场一半在空气）中两者不完全抵消，残留净前向串扰**，且幅度 ∝ 耦合长度 × dV/dt，频率越高越严重；
- 这是高速差分对优先走内层带状线的重要理由之一。

| 特性 | NEXT | FEXT |
|---|---|---|
| 传播方向 | 反向 | 同向 |
| 随耦合长度 | 饱和 | 线性增长 |
| 微带 vs 带状线 | 两者都有 | 带状线≈0，微带明显 |
| 对 Tr 敏感度 | 饱和值随 Tr 变化 | 幅度 ∝ 1/Tr（更陡更糟） |
| 频域表现 | 高频段近似白噪 | 随频率增长（dB 线性下降） |

## 10.4 降低串扰的设计规则

1. **3W 规则**：中心距 ≥ 3 倍线宽时，串扰大约降至 −25 ~ −30 dB（经验值，需仿真确认关键网络）；
2. 关键网络走**带状线**（FEXT 天然小、两面屏蔽）；
3. **保护地线**：两关键线间插入地线，必须密集打**缝合过孔**（间距 < λ/10，通常 1–3 mm）才有效；只画线不打孔的保护线几乎无效甚至更糟（自身成为谐振体）；
4. 层间垂直布线（相邻信号层 X/Y 正交，避免平行长距）；
5. 减小介质厚度 h（回流更集中，耦合减弱）；
6. 端接减少攻击线自身反射（反射波也是二次串扰源）；
7. 高敏感/高速总线整体换层隔离、拉大对间距离。

## 10.5 S 参数视角

- 串扰在频域用 S31（近端）与 S41（远端）观察；
- 插入损耗 S21 与回损 S11 是本征通道指标，SCD/Sdc 是差分平衡指标——四端口/混模 S 参数是现代 SI 分析的标准语言（见第 12–13 讲应用）。

---

## 10.6 串扰工程算例（3W 规则验证与估算）

**估算模型**（饱和后向串扰近似）：NEXT_sat ≈ ½·(K_C + K_L)，其中 K_C、K_L 分别为容性/感性耦合系数（受害线感应量与攻击量之比）。对于典型 FR-4 外层 1 倍线距（1W 边到边），K 约 0.05~0.1（即 −26 ~ −20 dB）；3W 时降到约 0.02~0.03（−34 dB 量级）。

**算例**：3.3 V 攻击线、噪声预算 50 mV（victim 接收阈值裕量的 5%）。

- 允许串扰比 = 50 mV/3.3 V ≈ 1.5%（≈ −36 dB）；
- 1W 间距（−25 dB 假设）→ 串扰约 180 mV，超标 3.6 倍；
- 3W 间距（−34 dB）→ 约 65 mV，仍略超标；
- 结论：要么 4W + 带状线（−45 dB 量级），要么在攻击线串联端接压低 dV/dt，要么改拓扑。

这个算例说明两件事：3W 是**起步规则而非保证**；关键网络（时钟、复位、模拟）必须仿真确认，而不是套规则。

**FEXT 算例（微带）**：FEXT ∝ 耦合长度 × (Tr⁻¹)·(K 差)，同样的 3W 外层平行 10 cm，6 Gb/s（Tr≈66 ps）时 FEXT 可能比 600 Mb/s（Tr≈660 ps）大一个数量级——**陡边沿 + 长平行 + 微带是 FEXT 三重放大器**。

## 10.7 S 参数与混模 S 参数详解

四端口差分通道用标准单端 S 参数（S11/S21/S31/S41…）描述不直观，标准做法是转换到**混模（mixed-mode）S 参数**：

```
Sdd = 差模→差模（差分插损 Sdd21、差分回损 Sdd11）
Scc = 共模→共模
Scd = 共模入→差模出（共模抑制能力）
Sdc = 差模入→共模出（模式转换，对称性指标）
```

| 混模参数 | 好坏方向 | 工程含义 |
|---|---|---|
| Sdd21 | 衰减小 | 信道损耗 |
| Sdd11 | 越负越好 | 差分端口匹配/反射 |
| Sdc21 | 越小越好（−20~−30 dB 目标） | 差分对不对称引起的共模 |
| Scd21 | 越小越好 | 外部共模侵入转化为差分噪声 |
| Sdd21 抖动 | 平滑 | 谐振/反射造成的频响波动 |

测量与仿真都以混模 S 参数交付（Touchstone 格式 .s4p），协议 Compliance 模板也以其为准。

**模式转换的时域直觉**：差分对两线长度不等（skew = t），差分沿传播时两沿错开，错开期间"差分"信号暂时表现为共模脉冲；频域上 Sdc21 随频率近似线性上升，在 f = 1/(2t) 处达到峰值——这就是为什么 ps 级 skew 在数十 GHz 的信道里必须当成头等问题。

## 10.8 对间隔离与总线级串扰

- 多对并行总线（如 8 lane PCIe）：对与对之间的隔离优先级高于对内耦合控制；
- 常用间距策略：对边到对边 ≥ 4~5 倍线宽，或隔一整条走线通道 + 地线；
- 层间串扰：相邻层平行走线（非正交）是最容易被忽略的串扰来源——**叠层设计时就应规定相邻信号层正交布线**；
- 噪声预算化：把串扰作为链路预算的一项（dB），与 IL、ISI、抖动一起在仿真中合并评估。

# 第十一部分：码间干扰与眼图（第 12 讲）

## 11.1 眼图是什么

把高速比特流按 UI（Unit Interval，单位间隔）切片、重叠绘制在同一张图上，就得到眼图。眼睛张开的程度直观反映信道质量：

- **眼高**（垂直张开）：电压裕量（含噪声后仍能判 0/1 的余量）；
- **眼宽**（水平张开）：时序裕量（含抖动后仍能正确采样的窗口）；
- **眼图模板（mask）**：协议规定的禁入区域，测试时波形不得压到模板。

## 11.2 码间干扰（ISI）

信道是带限的（损耗随频率上升），单个比特的脉冲响应会展宽/拖尾，侵入后续比特的判决窗口——前后比特的残余能量污染当前判决，称为 ISI。特征：

- **数据相关**：孤立 1 与连续 111 的波形不同，长串 0 后的第一个 1 幅度偏小（基线漂移）；
- 信道脉冲响应展宽 > 1 UI 时开始严重；
- ISI 属于有界确定性抖动（DJ）中的 DDJ 分量。

## 11.3 眼图恶化的四大来源

1. 信道损耗（趋肤/介质）→ 边沿变缓、眼闭合；
2. 反射（阻抗不连续）→ 产生数据相关的振铃叠加；
3. 串扰 → 邻线能量注入，眼角塌陷；
4. 噪声（电源/共模）→ 垂直方向模糊。

## 11.4 PRBS 与测量

- 用伪随机码（PRBS7/15/23/31）激励，保证各种码型组合都被覆盖；PRBS 阶数越高，最长连 0/连 1 序列越长，对基线漂移/CDR 考验越严酷；
- 误码率测试（BERT）配合浴缸曲线（Bathtub Curve）：横轴采样相位、纵轴累积 BER，曲线张口越大时序裕量越大；
- 均衡后的眼图（如经 CTLE/DFE 的接收端重绘眼图）才是可判决的有效眼图。

# 第十二部分：高速信道与抖动（第 13 讲）

## 12.1 抖动的分解体系

总抖动 TJ = 随机抖动 RJ + 确定性抖动 DJ：

| 类别 | 子项 | 来源 | 有界性 | 分布 |
|---|---|---|---|---|
| RJ | — | 热噪声、散粒噪声、闪烁噪声 | 无界 | 高斯 |
| DJ | DCD（占空比失真） | 上升/下降不对称 | 有界 | 离散双峰 |
| DJ | DDJ（数据相关抖动，含 ISI） | 信道损耗/反射 | 有界，与码型相关 | |
| DJ | PJ（周期性抖动） | 时钟耦合、电源纹波、SMPS 干扰 | 有界 | 正弦/周期 |
| DJ | BUJ（有界不相关抖动） | 串扰 | 有界 | 近高斯 |

近似关系（工程速算）：

```
TJ(BER) ≈ DJ_total + 2·Q(BER)·σ_RJ
其中 Q(1e-12) ≈ 7.03，故常用 TJ(1e-12) ≈ DJ + 14.1·σ_RJ
```

（高斯分量的峰峰值取决于目标 BER，这是"眼图在 1e-12 下仍是开眼"的含义。）

## 12.2 抖动的时域/频域观测

- 时域：示波器抖动分解（统计分析、N-Q 图）；
- 频域：相位噪声谱（相位噪声积分到指定偏移频带得到 RMS 相位抖动：σφ = 积分 L(f)·df 后开方）；
- TJ/眼图与 BER 的关系通过浴缸曲线与双狄拉克（Dual-Dirac）模型联系。

## 12.3 信道建模：S 参数与脉冲响应

- 信道（PCB+连接器+封装+电缆）以 S 参数（touchstone 文件）描述；
- 级联（cascade）各段 S 参数得到端到端信道；
- 通过 IFFT 得到脉冲响应 → 卷积任意码型 → 时域眼图仿真；
- 无源性/因果性检查：S 参数文件必须无源、因果、互易，否则仿真发散/失真。

## 12.6 关键信道指标速查

| 指标 | 含义 | 工程目标 |
|---|---|---|
| 插入损耗 IL（S21） | 信道衰减 | 按协议 mask（如 112G 在 Nyquist 处限值） |
| 回波损耗 RL（S11） | 反射大小 | 越小越好（通常 < −10 ~ −15 dB） |
| IL 插入损耗偏差 ILD | 频响波动（谐振造成） | 指标化控制 |
| NEXT/FEXT | 串扰 | mask 限定 |
| Skew/模式转换 | 差分平衡 | SCD21 < −20 ~ −30 dB |

---

## 12.4 时钟数据恢复（CDR）与抖动跟踪

高速串行链路的时钟嵌在数据里，接收端用 CDR（Clock-Data Recovery）电路从数据沿提取采样时钟。CDR 是一个**锁相的跟踪系统**，它对抖动有选择性的响应：

- **低频抖动**：CDR 跟得上 → 采样点跟着数据一起动，**不被计为有效抖动**（jitter 传递函数近似 0）；
- **高频抖动**（超出 CDR 环路带宽）：时钟跟不上 → 全部体现为采样误差（传递函数趋于 1）；
- 因此同样的 RJ/DJ，在"CDR 环路带宽内"与"带宽外"的 BER 影响完全不同——**抖动测量必须注明参考时钟与环路带宽设置**（如 10 MHz CDR），否则数据不可比；
- **抖动容限（jitter tolerance）**：注入正弦抖动并逐渐加大幅度，BER 保持合格的最大抖动幅度随频率的曲线；低频段容限可以很大（跟踪），高频段容限受限于采样窗（近似 0.5 UI）；
- **抖动传递（jitter transfer）**：中继器/重定时器输出抖动与输入抖动之比，级联系统中要防止抖动峰值放大（锁相环路带宽与峰值设计有协议规定）。

CDR 与均衡的关系：DFE 的判决依赖采样时刻，采样时刻来自 CDR，二者在接收机 DSP 中联合自适应——眼图张开度、误码与二者的收敛互相耦合，这是现代 SerDes "联合优化"设计的核心。

## 12.5 抖动测量实操要点

1. 抖动分解结果依赖所用模型（Dual-Dirac vs. 全直方图拟合），报告必须注明方法与 BER 目标；
2. 示波器自身的时基抖动（底噪）要从测量结果中扣除（去卷积）；
3. 长捕获与稀疏事件：低概率 DJ（如特定码型相关）需要足够长码流（PRBS31 + 误码定位）；
4. 电源相关 PJ：用频谱视图找尖峰频率，对照 SMPS 开关频率/时钟谐波锁定来源；
5. 温度/电压扫描：RJ/DJ 随工艺角与温度漂移，验收须在最恶劣组合下进行。

# 第十三部分：预加重与均衡器（第 14 讲）

## 13.1 为什么需要均衡

信道呈现低通特性（高频衰减大）。解法不是放大所有频率（噪声同样放大），而是**让整体系统（均衡器 + 信道）的组合响应平坦化**：

- 在发送端预失真（FFE/预加重）；
- 在接收端频率整形（CTLE）与码间消除（DFE）。

## 13.2 线性均衡（FFE / 预加重 / 去加重）

- **FFE（前馈均衡）**：横向滤波器（多 tap FIR），发送侧使用即预加重；
- **预加重（pre-emphasis）**：增强跳变沿的高频能量（首过冲）；
- **去加重（de-emphasis）**：压低连续相同比特（低频分量）幅度，相对提升高频；
- 典型设置（dB）表示首比特相对后续比特的增益；
- 代价：发送摆幅受限时，预加重会压缩低频眼高（长串码型幅度下降）→ 需与信道损耗匹配，过度预加重反而劣化。

## 13.3 连续时间线性均衡（CTLE）

- 接收端一个高通/带通有源峰值放大电路，增益随频率上升（在信道衰减大的频段补偿）；
- 同时放大高频噪声，过强则 SNR 恶化 → 存在最优峰值设置；
- 无判决、无反馈，先于 DFE 使用，用于"开眼"给判决电路。

## 13.4 判决反馈均衡（DFE）

- 对**已判决**的历史比特造成的 ISI 在求和节点上直接减去；
- 因为反馈取自判决后信号，**不放大噪声**（关键优势）；
- 局限：判决错误会传播（error propagation）；高速下反馈环路时序紧张（1 UI 环路），tap 数受限（常见 1–10+ tap）；
- 常与 CTLE 串联：CTLE 先开眼 → DFE 消残留 ISI。

## 13.5 各类均衡器对比

| 均衡器 | 位置 | 线性? | 放大噪声? | 补偿能力 | 复杂度 |
|---|---|---|---|---|---|
| FFE/预加重 | TX | 线性 | 本身不放大但预失真 | 良 | 低-中 |
| CTLE | RX | 线性 | 是 | 中 | 低 |
| DFE | RX | 非线性 | 否 | 强 | 中-高 |
| MLSD（最大似然序列检测） | RX | 非线性 | — | 最强 | 高（112G+ DSP 中出现） |

## 13.6 自适应与现代 DSP

- 现代高速 SerDes（56G/112G/224G）中 FFE/CTLE/DFE 均为自适应（LMS/gradient 算法根据眼图质量/误差信号自动收敛）；
- PAM4 时代还需 DSP 完成 FFE tap 权重、时钟恢复、PAM 判决等——"SerDes 即 DSP"。

---

## 13.7 均衡参数整定实例（以预加重 + CTLE 组合为例）

场景：10 Gb/s NRZ，信道在 Nyquist（5 GHz）处 −18 dB 插损。

**第 1 步：预加重档位选择。** 发送预加重典型 0~12 dB（3~4 档）。若选 9 dB：首比特增益比后续比特高 9 dB，等效于把信道一阶低通响应"预失真"回来。注意代价：长串码型（如连 1 后的 0→1）低频幅度被压到约 1/2.8，接收端共模/基线漂移——**预加重并不是越大越好**。

**第 2 步：CTLE 峰值选择。** 剩余插损约 −9 dB @ 5 GHz，选峰值增益约 6~9 dB 的 CTLE 档位（略欠补偿，因为 CTLE 同时放大噪声，过补偿使高频 SNR 崩掉）。仿真对比 3/6/9/12 dB 四档的眼高与眼宽，取折中。

**第 3 步：DFE tap 数。** 1-tap DFE 主要消第一个 post-cursor；信道脉冲响应展宽超过 2 UI 时用 3~5 tap。判定方法：观察均衡后残留 ISI 的多径分布。

**第 4 步：自适应收敛验证。** 用 PRBS23 在低温/高温、快/慢工艺角下仿真，确认自适应算法都能收敛且眼图满足模板。

## 13.8 链路预算方法（Link Budget）

把整条高速链路的损耗与噪声做成一张预算表（所有项都以 dB 或 mV 计），是判断"这链路能不能跑"的系统方法：

| 预算项 | 典型数值（10 Gb/s NRZ 举例） |
|---|---|
| 发送摆幅（差分峰峰） | 800 mVpp（~+2 dBm 折算） |
| 信道插损 @Nyquist | −18 dB |
| 串扰侵入 | −4 dB（等效） |
| 反射/ISI | −3 dB（均衡前） |
| 均衡恢复 | +14 dB（CTLE+FFE+DFE 组合） |
| 接收灵敏度 | 100 mVpp（眼图判决所需） |
| **裕量** | **正几 dB → 通过；负 → 迭代设计** |

该方法的价值：把"调阻抗、换板材、加均衡、改拓扑"的每一步决策都变成预算表上的数字游戏，可追溯、可评审。

# 第十四部分：面向电源完整性的 PDN 阻抗设计（第 15 讲）

## 14.1 PDN 的定义与组成

电源分配网络（Power Distribution Network, PDN）是从稳压器（VRM）到晶体管沟道的完整供电通路：

```
VRM → 板级走线/平面 → 去耦电容阵列 → 封装 → 片上电源网格 → 晶体管
```

PDN 的设计目标：**在从直流到最高有效频率（通常取几倍 1/Tr）的整个频段，把电源-地之间的阻抗压在目标值以下**，保证负载电流波动时电压波动（纹波/噪声）不超标。

## 14.2 目标阻抗法

```
Ztarget = (VDD × 允许纹波%) / ΔI（瞬态电流摆幅）
```

**例**：1.0 V 核电、允许 ±3% 纹波、芯片瞬态电流 10 A：
Ztarget = (1.0 × 0.03)/10 = 3 mΩ。
在所有频点都要 ≤ 3 mΩ——这是 PDN 频域设计的核心指标。

## 14.3 PDN 阻抗谱：谁在哪个频段干活

| 频段 | 起作用的元件 | 典型量级 |
|---|---|---|
| DC – ~kHz | VRM 闭环输出阻抗 | mΩ 级 |
| kHz – MHz | 体电容（大电解/钽/大容量 MLCC） | |
| MHz – 数百 MHz | 板级 MLCC 阵列 + 平面电容 | |
| 数百 MHz – GHz | 封装电容（SMD/IDC/嵌入式） | |
| GHz 以上 | 片上电容（on-die decap） | nH 级电感以下 |

每一级"接力"覆盖上一级失效的频段。**任何频段的空窗（反谐振峰）都是潜在风险点**。

## 14.4 反谐振峰

- 电容网络由"电容+寄生电感"组成，在自谐振频率（SRF）以上呈感性；
- 大电容（低 SRF，感性段）与小电容（高 SRF，容性段）并联时出现**并联谐振（阻抗峰）**——即反谐振峰；
- 反谐振峰若超过 Ztarget 且恰有电流激励（时钟谐波/数据谱），即产生电源噪声甚至共振放大；
- 抑制手段：多种容值搭配铺满频段、控制 ESR（ESR 高些反而能压平峰）、缩短电流路径减小回路电感。

## 14.5 平面阻抗与特征

- 电源-地平面对本身是一段低阻抗传输线，端到端来回反射形成**腔体谐振**（详见第 19–20 讲）；
- 平面对的等效串联电感随平面间距增大而增大（叠层设计要点：电源地平面紧邻、薄介质）；
- 平面电容（同层对面）容量小但频率高，是 GHz 级的重要角色。

---

## 14.6 PDN 时域验证：droop 算例

频域 Ztarget 达标后必须做时域复核，因为芯片的电流需求是时域脉冲。

**算例**：核电 1.0 V，芯片在 1 ns 内电流从 2 A 阶跃到 12 A（ΔI = 10 A），VRM 只能覆盖 kHz~MHz 级。

1. **第一时间段（0~1 ns）**：电流斜坡主要由片上电容供给。设片上总电容 C_diel = 200 nF，则仅靠它时电压跌落 ΔV ≈ ΔI·dt/C = 10 × 1n/200n = 50 mV——刚到 3% 允许值边缘，说明片上去耦预算紧张；
2. **第二时间段（1 ns~10 ns）**：封装与板级电容接力。若封装+安装路径的等效电感 L_eff = 20 pH，电流爬升率 10 A/ns → 感应压降 L·dI/dt = 20p×10G = 200 mV —— 严重超标！对策：增加并联路径（多点供电焊球）、封装电容，把 L_eff 压到 5 pH 以下（50 mV）；
3. **第三时间段（10 ns~µs）**：板级 MLCC 阵列供电，需求容量估算 C = ΔI·dt/ΔV = 10 A × 100 ns / 30 mV ≈ 33 µF → 安排数十颗大容值 MLCC + 体电容；
4. **更长时标**：VRM 闭环接管。

这个分层计算就是"PDN 是一个接力系统"的定量体现：**每一级元件的 C 与 L 决定了它在哪个时间窗内起作用**，任何一级缺失都会在相应时间窗内出现超标 droop。

## 14.7 PDN 设计的频域验收标准

| 检查项 | 标准 |
|---|---|
| 全频段阻抗 | Z(f) ≤ Ztarget，从 DC 扫到 ~1/Tr 对应频率 |
| 反谐振峰 | 峰值不超 Ztarget，且峰所在频率避开主要激励谱线（时钟谐波、数据开关谱峰） |
| 芯片视角 | 在芯片焊球端口看进去的阻抗（含封装与片上），而不只是板端口 |
| 多端口 | 多个电源引脚同时激励（相关/不相关两种激励模式都查） |
| 阻抗相位 | 电阻性为主（感性/容性斜率过陡说明某频段缺元件） |

# 第十五部分：去耦电容设计与谐振（第 16 讲）

## 15.1 实际电容的模型

一个真实的去耦电容 = C + ESR + ESL（安装后还有安装电感）：

```
|Z(f)| 呈 V 形：
f < SRF：容性，|Z| 随 f 下降
f = SRF = 1/(2π√(LC))：最低点 = ESR
f > SRF：感性，|Z| 随 f 上升
```

**决定高频去耦能力的不是容量，而是等效电感**——这是本讲最重要的一句话。

## 15.2 安装电感：布线决定去耦性能

电容要经过"焊盘-过孔-平面"接入 PDN，这段结构的电感（典型 0.5–2 nH）往往远大于电容本身 ESL。降低安装电感的布局手法：

1. 电容尽量靠近芯片电源引脚（"靠近"指的是**电气回路小**，不是物理直线距离）；
2. 过孔紧贴焊盘甚至盘中孔（via-in-pad）；
3. 多对过孔并联、电源/地过孔紧挨（互感抵消）；
4. 电源-地平面介质尽量薄（平面间回路电感小）；
5. 小封装（0402/0201）比大封装（0805+）寄生电感小得多；
6. 电容朝向使电流环路面积最小（电源过孔与地过孔分居焊盘两侧）。

## 15.3 容值组合策略

- 过去流行的"十倍程容值阶梯"（0.1µF/0.01µF/0.001µF…）并非教条，本质是**让并联组合的阻抗曲线在所有频段压住 Ztarget**；
- 现代做法：大量同容值（如 0.1 µF）小封装 MLCC + 少量大容值 + 体电容，用仿真验证阻抗谱；
- MLCC 的**直流偏压效应**：施加电压后实际容量显著下降（如 X5R 0.1 µF/6.3V 在额定电压下可能只剩 50%），选型时必须按偏压曲线降额；
- 温度/老化（Class II 介质容量逐年下降）也要留余量。

## 15.4 去耦电容数量估算流程

1. 确定 Ztarget（电压/电流/纹波规格）；
2. 频段划分：VRM、体电容、MLCC、片上各覆盖哪段；
3. 用每颗电容的 C/ESL/ESR 与安装电感建PDN 模型（SPICE 或专用工具）；
4. 扫频找超标的反谐振峰，调整容值组合/数量/位置；
5. 复核时域：阶跃电流激励下的电压 droop（下垂）/ring 是否达标。

# 第十六部分：片上电源分配网络设计（第 17 讲）

## 16.1 片上 PDN 结构

从封装焊球进入芯片后：C4/凸点 → 片上电源网格（多层金属网格交织）→ 电源条 → 标准单元电源轨 → 晶体管。

## 16.2 片上关键效应

- **IR drop（电压降）**：静态电流流过金属网格电阻造成直流压降；网格越密/金属越厚越低；局部大电流模块（CPU 核、PLL）周围必须加强；
- **Ldi/dt 噪声**：翻转电流陡变在网格电感上感应电压（与封装电感共同作用）；
- **片上去耦电容**：MOS 电容（MOSCAP）、MIM、Deep Trench 等，是唯一能在 GHz 以上频段工作的去耦；容量由版图预算决定，常需专门"去耦单元"填充；
- 时钟网络全芯片同步翻转是最大的周期性电流冲击源。

## 16.3 芯片-封装-板协同

- 片上电网 ↔ 封装 ↔ 板级是一个级联系统，**孤立优化任何一级都会出现别的频段的峰**；
- 封装内去耦（SMD/嵌入式电容）恰好在数百 MHz–数 GHz 段"接力"；
- 电源感知设计：把芯片电流画像（current profile）传给封装/板级仿真，做联合 PDN 分析。

# 第十七部分：电源激励抖动（PSIJ）建模（第 18 讲）

## 17.1 什么是 PSIJ

Power Supply Induced Jitter：**电源噪声通过电路的电源敏感度转化为时序抖动**。是 SI 与 PI 的交叉问题。

两条主要转化路径：

1. **时钟路径**：PLL/振荡器/时钟缓冲器的延迟受电源调制 → 时钟抖动（每 mV 噪声产生多少 ps 抖动，敏感度以 ps/mV 计）；
2. **数据路径**：驱动器输出延迟、判决器阈值随电源移动 → 数据眼图抖动与高度变化。

## 17.2 分析流程（本课程重点）

1. 提取 PDN（板+封装+片上）阻抗（频域）或电流激励得到电源噪声波形（时域）；
2. 建立电源-时延敏感度模型（对时钟树与数据通路的各节点）；
3. 电源噪声 × 敏感度 → 各节点时延扰动；
4. 在时序分析工具中累计传播 → 输出抖动（眼图/浴缸退化）；
5. 迭代 PDN 设计降低敏感频段阻抗。

## 17.3 关键结论

- PSIJ 是**有界确定性抖动**（DJ）的重要成分；
- 不同频段的电源噪声作用不同：低频调（低于环路带宽）表现为周期挪移，高频直接调制边沿；
- 减小 PSIJ 的三板斧：降低 PDN 阻抗（尤其敏感频段）、增加片上去耦、敏感电路（PLL）局部电源过滤（片上 LDO/RC 滤波）；
- DDR/高速 SerDes 的 PSIJ 预算在规范中往往有明确条目。

# 第十八部分：PCB 电源分配网络平面谐振（第 19 讲）

## 18.1 平面对就是矩形腔体

电源-地平面对在低频是电容，在高频是**两端开路的传输线腔体**，在特定频率形成驻波谐振。矩形平面腔的谐振频率：

```
f(m,n) = c / (2√εr) · √[(m/a)² + (n/b)²]
```

a、b 为平面边长（m），m、n 为模式数（不能同时为 0）。

**例**：100 mm × 80 mm FR-4（εr=4.2）平面对，最低模 f(1,0) ≈ (3e8/2/2.05)·(1/0.1) ≈ 0.73 GHz 量级——正好落在常见时钟谐波/数据谱内。

## 18.2 谐振的危害

- 谐振频率上平面阻抗大幅升高（可达几十 Ω）；
- 若与噪声源谱线重合（时钟谐波、数据开关能量、SMPS 开关频率）→ 平面电压大幅驻波波动；
- 平面边缘的电场/磁场辐射 → **平面谐振是 PCB 辐射 EMI 的主要机理之一**；
- 谐振模式下平面不同位置的电压相位相反——同一芯片不同电源引脚看到不同噪声。

## 18.3 观测与抑制

- 观测：仿真（全波求解器 + 平面腔体模型）、近场扫描、测量端口间阻抗 Z21；
- 抑制手段：
  1. **密集缝合过孔阵列**（去耦电容顺带把两面平面缝起来）；
  2. **去耦电容打散分布到平面各处**（特别是边缘、角落、谐振腹点）——电容在谐振腹点处将电压波节住；
  3. **薄介质**平面对（间距 0.1 mm 以下）提高平面电容、压低阻抗；
  4. 嵌入式电容材料（如 C-Ply）直接把谐振推高/压低；
  5. 边缘加地孔墙抑制边缘辐射（20H 法则配合）。

# 第十九部分：PCB 中的功率波与谐振控制（第 20 讲）

## 19.1 功率波视角

高频电源噪声在平面对中以**波**的形式传播（功率波）：

- 芯片开关电流注入平面 → 激励平面波 → 向四周传播 → 遇边缘反射 → 与入射波叠加形成驻波；
- 去耦电容在波动方程中相当于"吸收边界/阻尼项"：分布位置决定其吸收哪些模式；
- 去耦电容放置策略从"靠近负载"（低频直觉）升级为"在谐振腹点+传播路径上布防"（高频波动观点）。

## 19.2 去耦电容位置的波动理论

- 对第(m,n)阶谐振模，电容放在**电压腹点（anti-node）**最有效，放在波节点无效；
- 实操：对主要模式做谐振场分布仿真 → 在腹点处放电容/缝合过孔；
- 边缘一排电容（经典"边缘去耦"策略）本质上阻尼了边缘反射，从而抬高所有模式的 Q 值衰减；
- 电容数量不是越多越好，位置与容值组合决定效果（浪费的电容只增加成本与占地）。

## 19.3 阻抗峰的系统性压制 checklist

1. 平面几何尽量规整，避免细长颈缩（颈缩处电感大、且形成高 Q 谐振腔）；
2. 薄介质电源地平面（≤0.1 mm）；
3. 多容值混合 + 全平面分布（角落/边缘必放）；
4. 缝合过孔阵列（尤其平面边缘，兼顾 EMI）；
5. 全频段仿真验证 Ztarget 达标；
6. 有条件时：嵌入式电容、电源平面分割评估（必要时分割以隔离噪声域——但要保证每个域内部仍谐振可控）。

# 第二十部分：多层板中的地回流电流路径（第 21 讲）

## 20.1 回流电流的物理事实（复习并深化）

- **直流**回流在整层平面均匀散布（走最小电阻路径）；
- **高频**回流集中在走线正下方（走最小阻抗路径——互感耦合使能量最小）；
- 分布宽度 ∝ 介质厚度 h：介质越薄，回流越集中，回路电感越小，串扰/EMI 越好。

## 20.2 换层时的回流路径

信号过孔换层时，回流必须"跟随"换到新的参考平面。回流转换途径：

1. **同参考类型换层（地→地）**：就近的**地缝合过孔**提供通路（过孔电感小，首选）；
2. **地→电源换层**：回流借助**去耦电容**（电容连通电源与地）——数量要够、位置要近，否则回路绕行；
3. 工程规则：信号换层处 1–2 mm 内必须有缝合过孔/去耦电容；高速差分对换层时放一对地孔跟随。

## 20.3 参考平面被破坏的场景

| 场景 | 后果 | 对策 |
|---|---|---|
| 跨分割/开槽 | 回流绕槽两端，回路面积暴增 → 电感↑、辐射↑、串扰到其他线 | 禁止；无法避免时桥接电容 |
| 平面挖空区（keepout/排针区） | 同上 | 走线避开挖空；或换层 |
| 密集过孔区（反焊盘串） | 回流通道被切碎 | 控制反焊盘尺寸、关键线避让 |
| 连接器过渡区 | 参考平面不连续 + 结构突变 | 选带完整地平面的连接器、地孔跟随 |

## 20.4 差分对换层的特殊性

- 松耦合差分对尤其依赖参考平面（回流主要在平面），换层同样需要缝合措施；
- 紧耦合差分对回流部分走对方线，抗平面中断能力稍强，但高速下仍需成对地孔跟随；
- 差分对两线换层点要并排对称（同过孔结构），避免模式转换。

# 第二十一部分：回流路径与隔离设计（第 22 讲）

## 21.1 噪声隔离的三种思路

1. **物理隔离**：噪声源（SMPS、时钟发生器、射频前端）与敏感电路（ADC、PLL、音频）在板面分区布局，信号不穿越他人领地；
2. **回流路径隔离**：让不同电路块的回流电流各走各的路径，不共享阻抗（避免公共阻抗耦合）；
3. **屏蔽/滤波**：屏蔽罩、EMI 滤波器、磁珠 + 电容、共模扼流圈。

## 21.2 地平面要不要分割？（经典争论的工程解答）

- "分割地来隔离噪声"在低速有效（限制直流/低频环流），但在高速下**割断回流路径会迫使电流绕行，反而辐射更大、串扰更糟**；
- 现代主流做法：**统一地平面 + 合理分区布局**（功能区物理分开、接口处单点汇接/滤波）；
- 确实需要分割的场合（如安全隔离、模拟/数字边界明确且信号速率低）：必须保证**任何信号线不跨越分割**，跨越处放桥接电容/磁珠；
- 混合信号 ADC：通常把 ADC 下方的地保持完整，AGND/DGND 在芯片下方单点连接（或直接统一），让芯片内部决定回流，而不是在板上切出一条"裂缝"。

## 21.3 接口防护与滤波设计

- 所有进出板/进屏蔽体的信号：靠近接口放 TVS/ESD 器件 + 共模/差模滤波；
- 电源进板：共模扼流圈 + X/Y 电容（对外传导 EMI）；
- 屏蔽罩上孔缝尺寸 < λ/20（最高关注频率）；
- 电缆：屏蔽层 360° 端接、内部线束加磁环（铁氧体）抑制共模。

## 21.4 布局分区 checklist

1. 先划功能区：数字核、时钟、电源、模拟/射频、接口；
2. 高速信号只在数字区内部走线；
3. 晶振/时钟尽量靠近负载、下方完整地、包地处理；
4. SMPS 开关环路面积最小化（热回路：开关节点、电感、输入电容回路）；
5. 每个功能区本地去耦 + 与邻区的接口滤波；
6. 敏感走线（复位、模拟小信号）远离时钟/开关节点，必要时换层+地隔离。

## 21.5 高速 PCB 叠层设计模板

叠层是 SI 的"宪法"——所有走线规则都建立在叠层之上。经典方案：

**4 层板（低成本，一般速度）**

| 层 | 用途 |
|---|---|
| L1 | 信号（微带） |
| L2 | 完整地平面 GND |
| L3 | 电源平面 |
| L4 | 信号（微带） |

要点：信号只走 L1/L4，各自有紧邻参考面；L2-L3 之间薄介质形成平面电容。

**6 层板的经典缺陷**（课程批判的经典叠层）：L1 信号 / L2 地 / L3 信号 / L4 信号 / L5 电源 / L6 信号——L3 与 L4 两个信号层紧邻且平行，层间串扰严重；且 L3 的参考是 L2 地但回流要在 L4 的电源域之间跳。**若必须 6 层，改为**：信号/地/信号/电源/地/信号（牺牲一个信号层布线密度，换取每个信号层都有紧邻完整参考）。

**8 层板（高速主流）**

| 层 | 用途 |
|---|---|
| L1 | 信号（高速优先） |
| L2 | GND |
| L3 | 信号（带状线，高速） |
| L4 | GND |
| L5 | PWR |
| L6 | 信号（带状线） |
| L7 | GND |
| L8 | 信号 |

要点：GND-PWR（L4-L5）紧邻薄介质 → 平面电容大；每个信号层至少一面是完整平面；对称叠层（防止翘曲）：上下铜层分布对称。

**叠层设计原则汇总**：

1. 每个信号层必须有一紧邻完整参考面（地优先于电源）；
2. 相邻两个信号层布线方向正交（X/Y 交替）；
3. 电源与地平面成对紧邻、介质尽量薄（2~4 mil）；
4. 高速关键信号走内层带状线；
5. 对称（防翘曲）、阻抗计算书与板厂公差联合确认（蚀刻线宽损失、介质厚度公差、阻焊影响）；
6. 材料按数据率选 Df（参照 2.7 节算例）。

## 21.6 过孔设计详解

过孔是 PCB 上最强的阻抗不连续源。结构：焊盘（pad）+ 孔壁（barrel）+ 反焊盘（antipad）+ 残桩（stub）。

| 参数 | 对阻抗的影响 | 优化方向 |
|---|---|---|
| 焊盘直径 | 容性（拉低阻抗） | 小焊盘（HDI）、焊盘开槽 |
| 反焊盘直径 | 容性/感性平衡 | 加大反焊盘抵消部分容性 |
| 残桩长度 | 容性 + 1/4 波长谐振（stub 谐振在 f = v/(4·Lstub) 处表现为插损深坑） | **背钻**、盲埋孔、控制换层使 stub 最短 |
| 孔壁直径 | 电感（拉高阻抗） | 小孔径 |
| 管理信号回流 | 换层处电感 | 缝合地孔成对跟随 |

**数字直觉**：一个典型 8 mil 通孔残桩 60 mil，等效谐振频率约 v/(4L) ≈ 12 GHz 量级——在 25+ Gb/s 信道中是致命的插损尖峰，必须背钻掉。

**背钻（back-drilling）**：板厂用第二把钻头把过孔未使用段钻掉，残桩可控制到 <10 mil，代价是成本与板厚公差。

**HDI 手段**：盲埋孔、盘中孔（via-in-pad + 树脂塞 + 盘上电镀）用于 BGA 扇出，缩短回路。

# 第二十二部分：专题一：5G NR FR2 中 DPDT 的信号完整性设计与分析（第 23 讲）

## 22.1 背景

- 5G NR FR2（毫米波，24–52 GHz）前端需要**DPDT（双刀双掷）开关**在收发通道间切换（如 TDD 切换、天线选择）；
- 毫米波频段 PCB 走线损耗大、寄生参数影响显著，开关的插入损耗/隔离度直接决定链路预算。

## 22.2 设计要点

- 传输线：50 Ω 共面波导（GCPW）或带状线，介质用低 Df 材料；
- 开关芯片：QFN/倒装封装的焊盘-过孔寄生必须纳入仿真（封装-板协同建模）；
- 隔离度：TX 泄漏到 RX 的功率要压到接收器可容忍水平（布局上拉开 TX/RX 走线、中间地墙隔离）；
- TDD 切换瞬态：开关切换瞬间产生的瞬态可能进入接收带 → 时域+频域联合仿真评估。

## 22.3 分析方法

- 全波 3D EM 仿真（HFSS/CST 类）提取无源通道 S 参数；
- 与开关 SPICE/行为模型联合仿真瞬态；
- 关注指标：IL（插入损耗）、RL（回损）、TX-RX 隔离度、端口间串扰、开关瞬态毛刺。

# 第二十三部分：专题二：Chiplet 芯片间 D2D 接口的信号完整性分析（第 24 讲）

## 23.1 Chiplet 与 D2D 背景

- 大芯片（单体 SoC）良率与成本受限 → 拆分为多个小芯粒（chiplet），通过**裸片到裸片（Die-to-Die, D2D）互连**通信；
- 典型封装载体：硅中介层（interposer）、RDL 有机基板、硅桥（EMIB 类）；
- 标准接口：UCIe（Universal Chiplet Interconnect Express）、BoW 等；
- 速率：每对几 GHz 起步（UCIe 标准单 lane 多速率档），单封装内总带宽可达 TB/s 级。

## 23.2 D2D 链路的 SI 特点

- 距离短（mm 级）、损耗低，但**对能耗每比特（pJ/bit）极敏感**（总带宽巨大）；
- 走线在再分布层/中介层上，截面极小（1–10 µm 量级），RC 主导（衰减 ∝ √f 的 RC 段）或低速 LC 段；
- 电源/地与信号共享紧凑布线空间，串扰与同步开关噪声（SSN）密集；
- 端接通常片上完成，阻抗规格（单端/差分）由标准定义。

## 23.3 分析要点

- 提取中介层/RDL 走线的 RLGC/S 参数（2.5D/3D EM 或场求解）；
- 联合 driver-receiver 晶体管级或 IBIS-AMI 行为模型做眼图仿真；
- 关键指标：眼图在目标 BER（1e-12~1e-15）下的裕量、每比特能耗、SSN 引起的 PSIJ；
- 标准合规：UCIe 的电气测试项（眼图模板、抖动分解、回损）。

# 第二十四部分：专题三：片上 AHB 总线的信号完整性分析（第 25 讲）

## 24.1 片上总线互连即传输线问题

- AHB 等片上总线线长可达毫米级，在先进工艺下 RC 延迟主导，部分全局线呈有损传输线行为；
- 片上 SI 关注点与 PCB 不同：
  - IR drop 与信号完整性耦合（电源网络既供电流也影响驱动能力）；
  - 串扰：密集平行走线的耦合电容占比大，引起时延变化（数据相关）与功能噪声；
  - 全局时钟树的偏斜/抖动预算。

## 24.2 分析流程

- 提取版图寄生（RC extraction）→ 静态时序分析（STA）含串扰增量（crosstalk delta delay）；
- 关键网络（时钟、复位、长总线）做 SI 专项仿真（SPICE + 寄生网表）；
- 屏蔽（两侧加地线）、加大线距、插中继器（repeater/buffer）打断 RC 累积是三大经典手段。

# 第二十五部分：专题四：PAM-N 信号估计方法导论（第 26 讲）

## 25.1 从 NRZ/PAM2 到 PAM4/PAM-N

- NRZ（PAM2）：每 UI 传 1 bit；PAM4：4 电平，每 UI 传 2 bit（同波特率带宽翻倍）；
- 112G/224G SerDes 主流采用 PAM4；PAM6/PAM8 在研究中；
- 代价：电平间距缩小（同样摆幅下眼高除以 (N−1)），对噪声/ISI/非线性更敏感，需要 DSP。

## 25.2 PAM4 的眼图与均衡特点

- 三个"眼睛"垂直叠放，眼高天然只有 NRZ 的 1/3；
- 判决门限三个电平 → 噪声容限小、误码机制复杂（符号间错误不对称）；
- 均衡需求：强 FFE/DFE + MLSD（最大似然序列检测）类算法逐渐成为 PAM4 接收机标配。

## 25.3 接收估计方法

- **线性均衡（FFE/CTLE）**：先做信道白化/补偿；
- **判决引导（DD-DFE）**：逐符号判决并消除后标 ISI；
- **序列估计（MLSD/Viterbi）**：把 ISI 当作状态转移，在序列空间找最可能路径——性能最优、复杂度随信道记忆长度指数增长；
- **预编码（Tomlinson-Harashima 类）**：发送端预消除 ISI；
- 时钟恢复在 PAM4 下的新挑战：边沿统计特性改变，需专门的相位检测算法。

# 第二十六部分：专题五：无凸点通道的信号完整性分析与设计（第 27 讲）

## 26.1 无凸点（Bumpless）互连

- 传统封装芯片通过焊料凸点（C4/微凸点）连接；**无凸点技术**（如混合键合/Cu-Cu 直连）去掉凸点，芯片与中介层/晶圆直接键合；
- 互连间距从 40–150 µm 降到 10 µm 以下，密度提高一个数量级以上；
- 应用：HBM 堆叠、3D NAND、CPO（共封装光学）、先进 3D IC。

## 26.2 电气特性

- 无凸点过孔的寄生电感/电容远小于凸点 → 互连带宽大幅提升（>100 GHz 级）；
- 路径极短（µm 级 mm 级）但数量巨大：供电与信号密度极高，IR drop 与散热成为主要矛盾；
- 混合键合界面必须精确建模（薄氧化层电容、Cu 扩散电阻）。

## 26.3 设计分析要点

- 电源：百万级键合点并联供电——IR drop、电迁移（EM）寿命评估必不可少；
- 信号：键合点对（signal-return）的配置决定阻抗与串扰，需 3D EM 提取；
- 热-电协同：功率密度极高，温度影响电阻与可靠性，需电-热联合仿真；
- 展望：无凸点 + CPO（光互连）共同支撑后摩尔时代带宽密度需求。

# 综合篇：整机级 SI 设计流程与工具链

## A. 从需求到验证的完整流程

1. **需求分解**：数据率、协议（含 mask 与合规模板）、 BER 目标、抖动预算、功耗预算 → 形成链路预算表；
2. **架构决策**：单端 vs 差分、并行 vs 串行、拓扑（点对点优先）、端接策略、ODT 配置矩阵；
3. **叠层与阻抗设计**：选定参考平面方案、阻抗计算书、板材选型（Dk/Df/厚度公差）；
4. **预布局**：关键器件位置（收发对齐、长度预算预分配、跨板路径最短化）；
5. **规则制定**：线宽线距表、差分/组内组间等长规则（换算成 ps 并留温度/工艺裕量）、过孔规则、回流路径规则（缝合过孔/禁跨分割）；
6. **布线中仿真**：关键网络抽取 2D/2.5D 模型、S 参数、眼图预仿真；PDN 阻抗谱仿真；平面谐振仿真；
7. **布线后验证**：全链路端到端仿真（含封装、连接器、电缆模型）、串扰矩阵复核、时序复核（SSN/PSIJ 叠加进时序报告）；
8. **样机测量**：TDR/RL 定位、眼图与抖动分解测量、S 参数测量（VNA）、近场扫描（EMI）、BER 浴缸测试；
9. **闭环迭代**：测量与仿真相关性校准 → 模型修正 → 设计规则更新。

## B. 建模与仿真方法分层

| 层级 | 方法 | 适用 | 精度/成本 |
|---|---|---|---|
| 规则估算 | 手算/经验公式 | 预研、评审初筛 | 低/秒级 |
| 2D 场求解 | 横截面 RLGC | 叠层与阻抗 | 高（截面内）/分钟级 |
| 2.5D（边界元/MoM） | 平面+过孔建模 | 叠层走线、PDN 平面 | 高/小时级 |
| 3D 全波（FEM/FDTD） | 结构级 | 过孔区、连接器、封装、天线 | 极高/小时~天级 |
| 瞬态电路（SPICE/HSPICE） | 与晶体管/IBIS 联合 | 端接/驱动优化、SSN | 中高 |
| 统计眼图/AMI | IBIS-AMI 行为模型 | 多 Gb/s 链路系统仿真 | 中/快 |

**模型无源性/因果性检查**：所有 S 参数模型进入系统仿真前必须通过无源（无能量产生）、因果（响应不超前于激励）、互易校验，否则仿真结果不可信——这是工程仿真的基本功。

## C. 测量仪器与被测量的对应

| 仪器 | 被测量 | 关键指标 |
|---|---|---|
| 实时示波器（≥信号 BW 3~5 倍） | 眼图、抖动分解、TDR | 带宽、底噪、抖动本底 |
| VNA | S 参数、PDN 阻抗（含低频 μΩ 级） | 动态范围、校准（SOLT/TRL） |
| BERT | BER、浴缸、抖动容限 | 亚 ps 级时钟 |
| 近场探头/频谱仪 | EMI 定位 | 探头分辨率 |
| 探针台/示波器探头 | 芯片级波形 | 负载效应（皮法级也会畸变） |

测量探头本身是不连续：高频测量用低容探头/焊接式分压，否则"测到的波形"是探头与被测点相互作用的结果而非真实信号。

## D. 常见设计失误 Top10（课程案例提炼）

1. 高速线跨参考平面分割（回流绕行，反射+EMI）；
2. 差分对不等长未按 ps 预算控制，Sdc 超标；
3. T 分支/stub 残留（包括测试点焊盘的 stub）；
4. 去耦电容按"容量信仰"而不是按"回路电感+频段接力"摆放；
5. 忽略 MLCC 偏压/温漂，实际容值腰斩 → 反谐振峰超标；
6. 换层处没有缝合措施（差分对尤其）；
7. 平面谐振未评估，恰好与时钟谐波重合 → 系统性 EMI 峰；
8. 6 层板使用缺陷叠层（双信号层紧邻平行）；
9. 端接电阻位置随意（串联端接放负载端、并联端接放源端都是反的）；
10. 用"过孔穿电源平面"时未评估反焊盘电容与平面挖孔对平面谐振的激励。

# 工程实践问答（FAQ 精选）

**Q1：怎么快速判断某个信号要不要按传输线处理？**

三步：① 查驱动器数据手册的边沿时间 Tr（不是周期！）；② 估算上升沿空间延伸 Len = Tr × 15 cm/ns（FR-4）；③ 走线长度 > Len/6 → 必须受控阻抗 + 端接；< Len/6 → 集总近似，只关注负载电容与直流。注意 FPGA 输出可编程，最坏配置下 Tr 可能只有几百 ps——按最坏情况判定。

**Q2：等长到底要控到多少？**

换算公式：FR-4 内层 0.15 mm ≈ 1 ps。反推：
- DDR3 数据组内（tDQSK 预算 50 ps 量级）→ 组内差 ±10~20 ps → ±1.5~3 mm；
- PCIe Gen3 intra-pair skew 要求 < 2~5 ps → 0.3~0.75 mm；
- 千兆以太网 1000BASE-T 对内 < 25 ps 即可。
先从时序规格拿到 ps 预算，再换算成 mm 规则；"越等长越好"是错误直觉——过度蛇形引入自串扰反而更糟。

**Q3：为什么仿真眼图是开的，实测却闭合？**

常见原因排序：① 仿真没含封装与连接器模型（通常漏掉几 dB）；② S 参数模型非无源/非因果（低估损耗）；③ 没有串扰侵入（仿真是孤立信道）；④ 供电噪声与 PSIJ 未建模；⑤ 实测夹具/探头效应未去嵌；⑥ 温度与工艺角（芯片驱动强度实测更弱）；⑦ 板厂实际阻抗偏差（±10% 时插损与反射都变差）。排查顺序就是这七条。

**Q4：板厂阻抗公差 ±10%，我该怎么留余量？**

设计阻抗不要压着 50.0 Ω：名义值设计在 50 Ω，但要复核 ±10% 时（45~55 Ω）关键指标（反射、插损波动、协议 mask）仍然合格——即做"公差敏感性分析"。对差分对尤其注意：间距公差对 Zdiff 的影响比线宽公差大，间距要留足加工能力。

**Q5：信号参考电源平面行不行？**

行，但有条件：① 电源平面必须在该信号的频段内是"低阻抗的交流地"——即去耦网络把电源与地在信号带宽内短接良好；② 换层跨地↔电源参考时必须有近距离去耦电容提供回流通路；③ 高速关键信号优先参考地平面（无条件成立），参考电源是次选。

**Q6：什么时候必须背钻？**

残桩 stub 的 1/4 波长谐振 f ≈ v/(4·Lstub) 落在信号关心的带宽内（约 0.35/Tr 覆盖到）就必须处理。经验：≥ 25 Gb/s 的信道一律评估背钻；残桩 > 20 mil 且速率 > 10 Gb/s 时背钻收益明显。盲埋孔/HDI 是替代方案。

**Q7：时钟线包地有用吗？**

有用但常被做错。包地要成立：① 包地线两端及中间密集接地过孔（间距 < λ/10，1 GHz 以下至少每 5 mm 一个，10 GHz 每 0.5~1 mm 一个）；② 包地线本身等电位（多点接地）；③ 与时钟线间距按 3W 起步。只画一根不接地的地线没有屏蔽作用，反而增加耦合电容、拉低阻抗、引入额外反射。

**Q8：蛇形等长的代价是什么？**

蛇形段内圈与外圈之间是强耦合区：① 内圈线对自身造成数据相关损耗变化（ISI）；② 耦合使等效阻抗下降（蛇形区局部低阻）；③ 紧急补线的大蛇形会明显劣化眼图。规则：蛇形间距 ≥ 3~4 倍线宽、单段蛇形幅度小而多段均匀分布、优先在等长要求松的走线上绕。

**Q9：为什么我的差分阻抗实测偏低？**

排查顺序：① 阻焊层（表层绿油使等效 εr 升高，可拉低 3~5 Ω）——计算书有没有含阻焊？② 蚀刻线宽梯形修正（板厂按底宽报还是顶宽算）；③ 间距比设计小（阻抗随间距变小而下降）；④ 铜厚偏厚；⑤ 参考平面是否真如设计（内层是否恰好有个挖空）。差分对测量还要注意 TDR 分辨率不足以分开两根线时的去嵌。

**Q10：高速差分对能不能走表层微带？**

能，但三思：① 微带 FEXT 大（非均匀介质，容性感性耦合不抵消）；② 表层受阻焊厚度/环境敏感（阻抗一致性差）；③ 对外辐射略大。决策：短距离（BGA 扇出后换内层）、对间隔离充裕、速率中等——可以表层；长距并行、高速关键线——内层带状线。

**Q11：晶振/时钟器件下方能不能走别的信号线？**

不能。时钟器件下方的地平面被其他信号穿透回流，等于把噪声直接注入时钟——这是把"最干净"的信号与"最脏"的回流放在一起。晶振下方平面挖空是另一种错误（回流绕行+辐射）。正确做法：时钟区下方完整地平面，禁止任何无关信号穿越。

**Q12：PDN 仿真应该用什么电流激励？**

用"最坏同时翻转"的电流画像：① 从芯片功耗模型/仿真拿到开关电流波形（或用 I = C·V·f 估算动态分量 + 静态电流）；② 多个电源域/多个电流端口相关激励与不相关激励两种工况都要做；③ 时域 droop 与频域 Ztarget 双重复核。用标准方波激励（如 1 A/100 MHz）只适合粗筛。

**Q13：测试点对高速信号有影响吗？**

影响很大且经常被低估：一个 0402 测试焊盘 + 短支线的 stub 在 10 Gb/s 以上几乎必然毁掉眼图。高速信号若必须留测试点：① 用芯片内建的测试/环回功能代替物理测试点；② 复合接法（测试点串在线路中而非分支）牺牲可用性换取无 stub；③ 否则不留测试点，用连接器或协议规定的测试夹具。

**Q14：回流路径从地平面换到另一个地平面，需要做什么？**

在信号过孔旁边（1~2 mm 内）放一个地缝合过孔，把回流从一层地引到另一层地。高速差分对放一对地孔。如果多层板中该处地过孔资源紧张（BGA 区），优先把高速线换层点安排在过孔富余区。

**Q15：平面分割（割地）到底还能不能用？**

三句话：低速（边沿 > 5 ns）+ 有明确隔离需求（安全、大功率模拟）→ 可以，但任何信号不跨缝；高速 → 统一地 + 功能分区布局，不要割；如果一定要在统一地上做"软隔离"，用局部去耦加强 + 关键走线绕行，而不是切开平面。

# 附录 B：设计规则速查（工程 checklist）

1. 走线长度 > Tr 空间延伸/6 → 按传输线设计（受控阻抗 + 端接）；
2. 每条高速线全程有完整参考平面，绝不跨分割；
3. 换层处 1–2 mm 内放缝合过孔（同类参考）或去耦电容（跨电源域）；
4. 单端 50 Ω / 差分 100 Ω（按协议）受控；4 变量（w/h/εr/t）理解阻抗方向性；
5. 差分对：等长（按 ps 级预算换算）、对称、对间 ≥3–4W；
6. 串扰：3W 规则起步，关键网络仿真确认；高速优先带状线；
7. stub（T 分支、过孔残桩）必须消除：背钻/盲埋孔；
8. 端接：点对点用串联端接靠源端；多负载用末端并联/戴维南；
9. PDN：Ztarget 法设计，多容值 MLCC + 体电容 + 薄介质平面对，全频段仿真；
10. 去耦看回路电感而非容量：小封装、过孔贴焊盘、薄电源地介质；
11. 平面谐振：电容分布到谐振腹点与边缘，缝合过孔阵列；
12. 时钟/PLL 电源单独滤波，评估 PSIJ；
13. EMI 三板斧：对称（共模小）、回流连续（环路小）、边缘处理（20H/地孔墙）；
14. 高速串行链路按协议 mask 管理 IL/RL/串扰/模式转换，端到端仿真含封装与连接器；
15. 板厂投产前：阻抗计算书 + 叠层公差 + 蚀刻/粗糙度补偿一并确认。
