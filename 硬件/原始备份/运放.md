# 运放篇

## 一、运放结构及原理

运算放大器（简称运放、Op-Amp）是一种具有高增益、高输入阻抗、低输 出阻抗特点的集成模拟电路。它最基本的作用是对两个输入端的电压差进行放 大。

通过上述可知运放的内部通常由四个主要部分组成：


## 差分输入级：

利用差分放大电路（常用差分对管，如 BJT 或JFET），接收同相输入端 和反相输入端的信号，放大两个输入电压之差（V+ − V-），同时抑制两输 入端的共模信号；具有较高的共模抑制能力。同时提供较高的输入阻抗。 中间增益级（中间放大级）： 

对差分输入信号进行进一步放大，提供主要的电压增益。通常采用共射 /共源放大或达林顿结构，是运放获得高开环增益的主要部分（配合有源负 载增益可达数千倍）。通常还会设置频率补偿电容，防止运放自激振荡保证 运放稳定工作。 

 输出级： 

通常采用推挽结构，提供足够的输出电流和较低的输出阻抗，驱动负 载。同时具有输出短路保护和限流电路。 

##  偏置电路

为各级晶体管提供稳定的工作电流。通常采用恒流源、电流镜等电路实 现，把基准电流复制到各级。保证运放在不同温度、电源电压下稳定工作。

⚫ 运放的工作原理可以分成两种模式： 

 开环工作（比较器状态）：当运放不加负反馈时： 

若 $\mathrm { V } + > \mathrm { V } -$ ，输出趋向正饱和电压 $\left( + \mathbf { V } \mathbf { c } \mathbf { c } \right)$ ）； 

若 $\mathrm { V } + < \mathrm { V } -$ ，输出趋向负饱和电压 $\left( - \mathrm { V e e } \right)$ C 

此时运放相当于一个电压比较器。 

 闭环工作（负反馈状态）： 

实际使用运放时，通常会加入负反馈。将输出通过反馈网络引回反相 输入端，形成负反馈：由于开环增益极大，电路会自动调节输出，使 $\mathrm { V } + \approx \mathrm { V } -$ （虚短）。闭环增益由外部反馈电阻决定，而非运放本身。

通过理想运放的特性：开环增益 $\mathtt { A _ { 0 L } }$ 无穷大（虚短）；输入阻抗 $\mathrm { R _ { i } }$ 无穷大 （虚断）。由此推出“虚短和虚断”（用于分析负反馈电路）： 

<sub>•</sub> 虚短： $\mathrm { V } + \approx \mathrm { V } -$ （两输入端电压几乎相等） 

<sub>•</sub> 虚断： $\mathrm { I } _ { + } = \mathrm { I } _ { - } = 0$ （流入两输入端的电流几乎为零） 

3、运放负反馈原理及作用 

负反馈是指将运放输出信号的一部分，通过反馈网络送回到运放的反相输 入端（−），使反馈信号与输入信号相抵消。

⚫ 负反馈最重要的作用 

<sub>•</sub> 稳定闭环增益（只取决于外部元件）： 

运放开环增益 $\mathbf { A _ { 0 L } }$ 非常大，而且会随温度、频率、制造工艺等发生变 化。加入负反馈以后，闭环增益 $\mathbf { A _ { C L } }$ 主要由外部反馈网络决定（一般由外 部反馈电阻决定）。 

<sub>•</sub> 扩展带宽： 

负反馈会降低闭环增益 $\mathbf { A } _ { \mathbf { C L } }$ ，但可以扩大电路的有效工作频率范围。对于 很多运放，可以近似认为： 

$$
\boxed {\mathrm{GBW} = \mathrm{A} _ {\mathrm{CL}} \times \mathrm{BW}}
$$

闭环增益越低，能够获得的 BW带宽越大。 

<sub>•</sub> 减小非线性失真： 

运放内部的晶体管并不是完全线性的。负反馈会不断检测输出误差，并 对误差进行修正。因此：输出波形会更加接近理想波形。 

<sub>•</sub> 提高电路稳定性： 

运放的开环增益 $\mathtt { A } _ { 0 \mathrm { I } }$ 非常高，如果没有反馈，很容易因为输入信号的微 小变化而进入饱和（文章上有举例）。 

负反馈能够限制实际增益，使输出处于可控的线性范围。从而稳定电 路。 

<sub>•</sub> 改变输入/输出阻抗： 

对于典型的电压负反馈电路：输入阻抗通常提高；输出阻抗通常降低； 因此运放更加适合连接前级信号源和后级负载（高阻输入低阻输出）。 

## 二、运放轨到轨和非轨到轨的区别

运放中的“轨（Rail）”指的是电源电压的上下限。例如运放采用单电源供 电： 

$$
\mathrm{V} _ {\mathrm{CC}} = 3 \mathrm{V} 3; \mathrm{V} _ {\mathrm{EE}} = 0 \mathrm{V} (\text {GND}) (\text {上图运放有示例图})
$$

那么 0 V 和 3V3 就是两个电源轨。所谓“轨到轨（Rail-to-Rail）”，就是指 运放的输入或输出电压范围可以非常接近电源轨。 

1、最基本的区别：假设运放由 0～3.3V供电（单电源）。 

⚫ 非轨到轨运放（BJT 输出级--如 LM358） 

输入或输出通常不能靠近电源轨。实际应用电路输出可能只能达到： $0 . 2 \mathrm { V } \mathrm { \sim } 3 . 1 \mathrm { V }$ 0 

 非轨到轨运放（BJT 输出级）内部机制如下图所示。 

![](images/dce6eb4e7e35d794766a151eb4526edc427578c6f6b89b8a243914b2caf76fb5.jpg)


非轨到轨运放输出级常采用推挽结构，下管为 PNP 晶体管，接成射极跟随 器：发射极接输出端，集电极接负电源（地），基极由内部驱动电路控制。射极 跟随器的基本关系是发射极电压始终比基极电压高一个发射结正向压降，即 $V _ { o u t } = V _ { B } + 0 . 6 V$ 。当输入为 0V且外部灌入电流时，负反馈环路会驱动下管导 通以吸收电流。若要将输出拉至 0V，基极电压必须达到-0.6V。但在单电源或 有限负压供电条件下，内部驱动电路无法提供低于负电源轨（通常为 0V）的电 压，基极最低电位被钳位在 0V附近。因此，输出电压最低只能达到约 0.6V。 这0.6V本质上是 PNP 管发射结的固有压降，是输出级结构与驱动摆幅受限共 同造成的结果，导致运放输出无法真正归零。 

## ⚫ 轨到轨运放（CMOS 输出级--如 OPA340）

可以非常接近电源轨。实际应用电路输出可能达到：0.005V∼3.295V。 

 轨到轨运放（CMOS 输出级）内部机制如下图所示。 

![](images/b602e07197f3e99fcc18253eeff5b227d49048e0fd10ee761ddb7e6ce327b63f.jpg)


轨到轨运放输出级通常采用互补 MOS 管，下管为NMOS 晶体管，源极直 接接负电源（地），漏极接输出端，栅极受驱动电路控制。NMOS 管导通时表 现为压控电阻，其漏源电压 $V _ { D S } = I _ { s i n k } \times R _ { D S ( o n ) } ; \quad \mathrm { ( I _ { s i n k } \times R _ { D S ( o n ) } \times R _ { D S ( o n k ) } ) }$ 灌电流； $\operatorname { I } _ { \mathrm { s o u r c e } }$ 拉电 流； ${ \mathrm { R o s } } ( \mathrm { o n } )$ 漏极与源极之间的等效电阻）不存在 PN结的固定压降。当外部灌入 电流时，驱动电路将栅极电压提升至高于源极（如 3.3V），使NMOS 管充分导 通。由于 $R _ { D S ( o n ) }$ 很小，通常仅数十欧姆，在小灌电流下 $V _ { D S }$ 极小，因此输出电 压可非常接近0V，实现轨到轨输出。 

## 2、轨到轨分为“输入”和“输出”

①轨到轨输入 RRI：运放的输入电压可以非常接近正、负电源轨。 

例如 0～5V供电（单电源）时，普通非轨到轨（BJT输出级）输入运放要 求 $\mathrm { V } _ { \mathrm { C M } } = 1 \mathrm { V } \sim 4 \mathrm { V }$ ，当运放输入接近 0V或 5V时，此运放可能无法正常工作。 

而轨到轨（CMOS输出级）输入运放支持： $V _ { C M } \approx 0 V \sim 5 V$ 所以轨到轨输入非常适合：单电源系统；传感器信号；ADC 前端。 

②轨到轨输出 RRO：运放的输出电压可以非常接近正、负电源轨。 

例如单电源时： $\mathrm { V _ { C C } } = 5 \mathrm { V } , \mathrm { V _ { E E } } = 0 \mathrm { V }$ ；普通非轨到轨运放可能只能输出 $0 . 2 \mathrm { V } \sim 4 . 7 \mathrm { V } ;$ ；轨到轨输出运放可能达到 $0 . 0 1 \mathrm { V } \sim 4 . 9 9 \mathrm { V }$ ，这样可以更加充分地利 用整个电源电压范围。 

③轨到轨输入+轨到轨输出 RRIO：运放的输入与输出电压可以非常接近 正、负电源轨。 

注意：设计低压单电源时优先选择轨到轨输入输出（RRIO）器件。

## ⚫ 供电电压：

 单/双电源、总电源范围、是否轨到轨输入/输出；输出摆幅 Vo留余量， 避免削波。 

## ⚫ 增益带宽积（GBW）：

 原理：运放内部存在寄生电容，构成了主极点，使其开环增益随频率增 加以-20dB/十倍频的斜率下降。当开环增益降至 1（0dB）时，对应的频 率就是 GBW。 

 影响：体现了运放的“高频处理能力”。闭环增益越高，可用带宽越窄 （带宽=GBW/闭环增益 $( \mathrm { G B W } = \mathrm { A _ { C L } } \times \mathrm { f _ { C L } } ) )$ ；一般要求闭环带宽≥信号 最高频率的 5–10倍。 

## ⚫ 压摆率（SR）：

 原理：运放内部对补偿电容的充电电流是有限的，导致输出电压的最大 变化速率受限。 

 影响：决定了运放处理“大信号”时的速度。如果信号变化太快，输出波 形会变成三角波（压摆率失真）。所需所需 $\mathrm { S R } \approx 2 \pi \mathrm { f V p k } , 0 . 5 \mathrm { V / \mu s }$ 较慢， 不适合高频大信号。 

## ⚫ 输入失调电压（Vos）：

 原理：由于芯片内部晶体管和电阻在制造时不可能完全对称，导致两个 输入端即使外加电压为 0，内部也存在微小的电位差。 

 影响：直流放大时的绝对误差。3mV 偏大（精密运放通常 ${ < } 1 0 0 \mu \mathrm { V } )$ ）。如 果闭环放大 100倍，输出端会凭空多出 0.3V的直流误差，甚至导致饱 和。 

## ⚫ 输入失调电压温漂（Vos TC）：

 原理：失调电压会随温度变化而漂移，这是由于半导体参数 Vbe具有温 度系数。 

 影响：决定了系统在变温环境下的稳定性。虽然初始 Vos 有 3mV，但只 要温度变化不大，漂移量相对较小。 

## ⚫ 输入偏置电流（Ib）：

 原理：运放输入级晶体管（通常是双极型 BJT）正常工作需要基极电 流。 

 影响：电流流经外部反馈电阻会产生附加的电压误差（Ib×R）。35nA 属 于中等，搭配大电阻（如 1MΩ以上）时误差会显著增大，高阻抗传感 器选型需谨慎。 

## ⚫ 输入失调电流（Ios）：

 原理：两个输入端偏置电流之差的绝对值（|Ib+ -Ib-|）。 

 影响：进一步加剧了由偏置电流引起的直流误差。可以通过在输入端串 联匹配电阻（使两端等效电阻相等）来抵消大部分偏置电流的影响。 

## ⚫ 静态电流（Iq）：

 原理：运放内部偏置电路维持正常工作的基础电流，与负载和输出无 关。 

 影响：决定功耗。300μA很低，非常适合电池供电的便携设备。 

## ⚫ 输入电压噪声密度（eN）：

 原理：由运放内部电阻的热噪声和半导体载流子的散粒噪声引起。密度 值越低，运放自身产生的噪声越小。 

 影响：决定了系统的“信噪比底线”。40nV/√Hz属于中等偏大噪声（精密 运放通常在 1~10nV/√Hz），不适合用作微弱信号（如微伏级）的前置放 大。 

## ⚫ 共模抑制比（CMRR）：

 原理：运放差分输入级的匹配程度。理想情况下，共模信号（两输入端 相同的电压）应被完全抵消。100dB 意味着共模信号被衰减了 10万倍。 

 影响：抗共模干扰能力极强。在存在强共模噪声（如长线传输、电机干 扰）的环境中，依然能准确放大差模小信号。 

## ⚫ 输出电流（Io）：

 原理：输出级晶体管的驱动能力极限。 

 影响：决定了能带多重的负载。20mA 可驱动轻载，但驱动低阻负载 （如 50Ω或 8Ω扬声器）会导致波形削顶或发热。 

## ⚫ 工作温度（T<sub>A</sub>）：

 原理：半导体封装的散热能力和内部电路的温度特性补偿范围。 

 影响：工业级温度范围，可用于大多数恶劣环境，但不满足汽车级（- $4 0 { \sim } 1 2 5 ^ { \circ } \mathrm { C } )$ 或军级要求。 

## ⚫ 电源抑制比（PSRR）：

 原理：衡量运放抑制电源电压变化的能力。 

 影响：决定运放在电源不干净环境下的稳定性。PSRR不足时，开关电 源纹波、工频干扰会混入输出，表现为音频“嗡嗡”声、测量跳动、ADC 采样不稳。PSRR随频率升高而下降，高频抑制更差；正负电源抑制比 可能不同。 

 解决：选高 PSRR运放，兼顾低频和高频；电源加 $0 . 1 \mu \mathrm { F } + 1 0 \mu \mathrm { F }$ 去耦， 靠近引脚；必要时加 LDO或RC/LC 滤波；布局上电源短粗、地平面完 整，避免数字回流经过模拟区。 

## 六、运放失真问题

运算放大器（运放）理想情况下应该线性放大输入信号，但实际运放受到 内部结构、电源电压、频率和负载等因素限制，会导致输出波形不能完全按照 比例复制输入信号，这种现象称为运放失真。 

## 1、运放常见失真类型与原因

## ⚫ 截止（削顶）/饱和（削底）失真(Vo)

 现象：波形顶部或底部被削平。 

 原因：输出接近电源轨、电源电压不足、增益过大、输入幅度过大。 

 解决方法：输出摆幅 Vo是否超出数据手册的最大输出电压摆幅 Vom； 单电源时是否加了偏置；降低输入幅度；降低放大倍数；提高供电电 压；使用轨到轨输出（RR输出）运放。
