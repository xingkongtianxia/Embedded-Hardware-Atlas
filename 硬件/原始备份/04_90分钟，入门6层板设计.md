## 第1集：90分钟，入门6层板设计

这一集通常会讲解：从"什么是6层板"到"为什么你的板子需要多于4层"，再到"叠层、阻抗、布线到底怎么安排"，把一张6层板从概念到生产资料的全流程串起来。下面按小节系统展开。

### 📖 一、6层板是什么、与2层/4层板的区别

**什么是"层"？** PCB 的"层(Layer)"指的是在绝缘基材(通常是 FR-4 环氧玻璃布)两面或内部,通过压合+电镀形成的、彼此绝缘的导电铜箔平面。我们常说的"双层板/四层板/六层板"，指的就是这块板子里一共"埋"了多少个这样的铜箔导电层。

用最通俗的话讲：

- **2层板（双层板）**：只有最上面和最下面各一层铜,中间是绝缘芯材。所有信号和电源都只能在这两面"绕"。
- **4层板**：在 2 层板的基础上,内部又压合进 2 层铜,一般用作 **完整的地平面(GND)** 和 **完整的电源平面(PWR)**。于是表面两层专门走信号。
- **6层板**：在 4 层板基础上再加 2 层,通常是"1个地平面 + 1个电源平面 + 更多信号层",或者"2个地平面 + 1个电源平面 + 3个信号层"。

它们最本质的区别,不是"铜多了两层"这么简单,而是**参考平面的数量与质量**发生了质变。

| 对比项 | 2层板 | 4层板 | 6层板 |
|---|---|---|---|
| 总铜层 | 2 | 4 | 6 |
| 典型叠层 | Sig / Sig | Sig / GND / PWR / Sig | 见下文 |
| 是否有完整地/电源平面 | 无(靠铺铜) | 有 1 地 1 电源 | 有 2~3 个平面 |
| 信号回流路径 | 差,绕远 | 较好 | 优秀 |
| 阻抗控制 | 难 | 较易 | 容易且稳定 |
| 高速信号支持 | ≤ 数十 MHz | 数百 MHz | GHz 级常见 |
| 布线密度 | 低 | 中 | 高 |
| 成本 | 最低 | 中 | 中高 |

这一集应掌握的判断标准:**当你的高速信号走线（如 DDR、USB、HDMI、PCIe、千兆网）多到 4 层板放不下、或信号质量开始出问题、或 EMC 测试过不了时，就该考虑上 6 层板了。**

### 🔬 二、关键概念深入

#### 1) 6层板典型叠层结构

叠层(Stack-up)是 6 层板设计的核心。评价一个叠层好坏的第一原则:**每一个信号层,都应紧邻一个完整、连续的参考平面(地或电源)**,这样信号的回流电流才有最短路径,阻抗才可控。

业界常见的几种 6 层叠层方案：

```
方案 A（重视信号完整性，推荐起步用）
┌─────────┐ L1  Signal (Top，高速信号)
├─────────┤ L2  GND    ← 完整地平面
├─────────┤ L3  Signal (内层关键信号)
├─────────┤ L4  PWR    ← 完整电源平面
├─────────┤ L5  GND    ← 完整地平面
└─────────┘ L6  Signal (Bottom)
→ 三个信号层(1/3/6)各自紧邻一个平面，SI/EMI 都好

方案 B（信号层多，密度优先）
┌─────────┐ L1  Signal
├─────────┤ L2  GND
├─────────┤ L3  Signal
├─────────┤ L4  Signal
├─────────┤ L5  PWR
└─────────┘ L6  Signal
→ 标题里提到的 "Sig-Gnd-Pwr-Sig-Sig-Pwr" 这类思路的变体；
  缺点：L3 与 L4 两层信号紧挨着、中间没有平面，
  易串扰，需错层/正交走线来缓解
```

补充要点：
- 当某电源层被用作信号的参考平面时,**该层必须是一个"干净、连续"的铜面**(不要被随意切断),否则信号回流会绕路,引发 EMI 与振铃。
- 两个地平面(GND+L5)比一个地一个电源更利于 EMC,因为地平面提供屏蔽。

#### 2) 为什么需要 6 层

- **更多信号走线空间**：4 层板表面被地/电源平面"占掉"两层后,信号只剩上下面,复杂板子放不下。
- **更干净的电源/地**:6 层可给关键电源单独分一个平面,降低电源阻抗(PDN)。
- **可控阻抗与高速支持**:紧贴平面后,微带线/带状线阻抗才可稳定计算与布线,这是 USB3、DDR3/4、PCIe 等高速接口的硬性要求。
- **EMC/EMI 改善**:完整地平面提供回流与屏蔽,辐射噪声显著下降。

#### 3) 阻抗控制与介质厚度的关系（重点公式）

信号在 PCB 走线上传输时,看到的"特性阻抗" $Z_0$ 不是由电阻决定的,而是由**走线宽度、铜厚、到参考平面的介质厚度、介质常数 $\varepsilon_r$** 共同决定的。

**表层微带线(Microstrip)近似公式:**

```text
Z0 ≈ (87 / sqrt(εr + 1.41)) * ln( 5.98 * h / (0.8 * w + t) )

其中:
  εr = 介质相对介电常数 (FR-4 约 4.2~4.5)
  h  = 走线到参考平面的介质厚度 (mm 或 mil)
  w  = 走线宽度
  t  = 铜箔厚度
```

**内层带状线(Stripline,夹在两个平面之间)近似公式:**

```text
Z0 ≈ (60 / sqrt(εr)) * ln( 4 * h / (0.67 * π * (0.8 * w + t)) )

其中 h 为上下两个参考平面之间的介质总高度的一半附近取值
```

**差分阻抗(常用,如 USB、HDMI、以太网):**

```text
Z_diff ≈ 2 * Z0 * (1 - 0.48 * exp(-2 * s / h))

其中 s = 两根差分线之间的间距, h = 到参考平面的厚度
```

**关键直觉(这一集应重点理解):**

- $Z_0$ 与介质厚度 $h$ **正相关**:$h$ 越大(走线离平面越远),阻抗越高;要做低阻抗就得减小 $h$ 或加宽 $w$。
- $Z_0$ 与线宽 $w$ **负相关**:线越宽阻抗越低。
- 所以**叠层厚度决定了线宽**:先定叠层(定 $h$ 和 $\varepsilon_r$),再反算需要多宽的线才能达到 50Ω/90Ω/100Ω。
- 介质常数 $\varepsilon_r$ 越大,同样尺寸下阻抗越低;高速板材(如 Rogers)的 $\varepsilon_r$ 与损耗和 FR-4 不同,换料必须重算。

> 小知识:PCB 工厂用"芯板(Core,已固化)"和"半固化片(Prepreg,压合时软化粘合)"来堆叠出各层间的精确介质厚度,叠层文件就是要告诉工厂每一层的材质与厚度。

### 🛠 三、设计实例：一张 6 层板是怎么做出来的

以"**MCU + DDR3 + 一路 USB 的小主控板,从 4 层升级到 6 层**"为例,走完整流程。

**步骤 1 · 建库(原理图符号 + 封装)**
先准备好器件的原理图 Symbol 和 PCB Footprint(封装)。DDR 用 BGA、USB 用连接器、MCU 用 QFP/LQFP。封装的焊盘尺寸、间距必须与器件 datasheet 一致,这是后面能扇出(fan-out)的前提。

**步骤 2 · 布局(Placement)**
- 先放接口(USB、电源座)在板边;
- MCU 居中,DDR 紧挨 MCU(缩短地址/数据线);
- 电源模块(DC-DC/LDO)靠边,远离敏感模拟区;
- 去耦电容紧贴每个芯片的电源引脚。

**步骤 3 · 叠层设置(Layer Stack Manager)**
在 EDA 工具里配置 6 层:Top / GND / Sig / PWR / GND / Bottom,并填入各层介质厚度与 $\varepsilon_r$,让工具能按公式算阻抗。

**步骤 4 · 布线(Routing)**
- 高速差分(USB D+/D−)走表层微带线,90Ω 差分阻抗,紧邻 GND 平面;
- DDR 数据线走内层带状线,50Ω 单端;
- 电源通过过孔连到 PWR 平面,再扇出给芯片。

**步骤 5 · 等长(Length / Timing Matching)**
DDR 的"同一组数据线(DQ0~DQ7 + DQS)"长度要一致,保证同时到达。工具可做蛇形绕线(Trombone/Serpentine)把短的补长。

**步骤 6 · DRC(设计规则检查)**
检查线宽、间距、短路、开路、阻抗规则、差分对、丝印重叠等是否违规。

**步骤 7 · 生产资料输出**
导出 Gerber(各层光绘)、NC Drill(钻孔)、IPC-356 网表、钢网层、BOM、装配图,连同叠层说明一起发给工厂。

**第二个小例子(一句话带过):** 一块"HDMI + 千兆 PHY"板,重点在于 HDMI 的四对差分(100Ω)与 PHY 的 MDI 差分都要有专属、不被打断的参考平面,否则眼图会闭合——这正是 6 层板多出来的地平面派上用场的地方。

### ⚠️ 四、新手常见误区

1. **把电源层当"万能走线层"乱穿信号**：切断了参考平面,回流绕路,EMI 爆表。
2. **相邻两层长距离平行走线**：L3/L4 紧贴时平行走线会严重串扰,应错层或正交。
3. **只算线宽、不管介质厚度**：同一个 50Ω,在 4mil 和 8mil 介质里线宽完全不同,叠层变了阻抗就变了。
4. **等长但不等时**：忽略了过孔本身的延时,差分数对里一根多打两个过孔,时序照样偏。
5. **地平面随意开槽(Split)**：为了隔离数字/模拟地而开长槽,反而让高速回流绕远、辐射变大;正确做法常是"单点桥接"或干脆不分地。
6. **过孔太密打断平面**：BGA 区域大量过孔若排布不当,会在地/电源平面上戳出"瑞士奶酪",破坏平面完整性。
7. **盲目抄 4 层板经验到 6 层**：6 层多了内层,参考平面关系更复杂,照搬 4 层走法会踩坑。

### 📌 五、要点速记

1. "层"是绝缘基材内外的导电铜箔;2/4/6 层的本质区别是**参考平面的数量与质量**。
2. 6 层板的核心价值:更多布线空间 + 干净的电源/地 + 可控阻抗 + 更好的 EMC。
3. 评价叠层的第一原则:**每个信号层都要紧邻一个完整连续的参考平面**。
4. 常用起手叠层:`Sig / GND / Sig / PWR / GND / Sig`,三个信号层各有平面。
5. 阻抗 $Z_0$ 由 **线宽 w、铜厚 t、介质厚度 h、介电常数 $\varepsilon_r$** 决定;$h$ 越大阻抗越高,$w$ 越宽阻抗越低。
6. 先定叠层(定 h、$\varepsilon_r$),再反算线宽——**叠层决定线宽,不是反过来**。
7. 高速信号(USB/HDMI/DDR/PCIe)几乎必须 6 层,因为需要稳定参考平面与可控差分阻抗。
8. 完整流程:建库 → 布局 → 叠层设置 → 布线 → 等长 → DRC → 生产资料。
