# 第 1 部分：AC-DC 开关电源系统架构

## 1.1 从 220V 到 5V 的完整能量链路

一个典型的 220V 输入、5V/2A 输出的反激式开关电源，能量流经下面这条链路：

```
220V AC ─→ 保险丝 ─→ 压敏电阻 ─→ EMI滤波器 ─→ 整流桥 ─→ 大电解电容
        ─→ 反激变压器+MOSFET(高压开关) ─→ 变压器隔离 ─→ 副边肖特基整流
        ─→ 输出LC滤波 ─→ 5V/2A 输出
                    ↑
              TL431+光耦反馈（跨隔离带）
```

各环节的功能与常见取值：

| 环节     | 元件                             | 作用        | 典型取值（5V/2A 反激）          |
| ------ | ------------------------------ | --------- | ----------------------- |
| 输入保护   | 保险丝 F1                         | 短路/过流熔断   | 250V AC，2~3.15A 慢断      |
| 浪涌保护   | 压敏电阻 MOV（如 14D471K）            | 吸收雷击/浪涌   | 470V 压敏电压               |
| EMI 滤波 | 共模电感 + X 电容 + Y 电容             | 抑制传导/辐射干扰 | X:0.1~0.47µF；Y:2.2nF×2  |
| 整流     | 整流桥 DB107/GBU                  | AC→脉动直流   | 600V/1A 以上              |
| 滤波     | 高压电解电容                         | 平滑直流母线    | 400V/10~22µF            |
| 开关     | 功率 MOSFET（如 650V N-MOS）        | 高频斩波      | 20~65kHz（准谐振可到 100kHz+） |
| 隔离传输   | 反激变压器                          | 储能+隔离+变压  | EE16/EE19 磁芯            |
| 副边整流   | 肖特基二极管（如 SR5100/SS54）          | 快速整流      | 100V/5A                 |
| 输出滤波   | 低阻电解 + 磁珠/电感 + 陶瓷电容            | 降纹波       | 470~1000µF + 100nF      |
| 反馈     | TL431 + PC817 光耦               | 隔离采样稳压    | 精度 ±1%~2.5%             |
| 控制     | 副边反馈 PWM IC（如 OB2263/UC3842 类） | 调节占空比     | DIP-8/SOT23-6           |

## 1.2 为什么小功率 AC-DC 首选反激拓扑

| 拓扑          | 功率范围          | 隔离   | 成本 | 典型应用          |
| ----------- | ------------- | ---- | -- | ------------- |
| 反激（Flyback） | <75W（充电器、适配器） | 天然隔离 | 最低 | 手机充电器、5V 小电源  |
| 正激（Forward） | 75~250W       | 隔离   | 中  | 工业电源          |
| 半桥/全桥       | 250W~kW 级     | 隔离   | 高  | 服务器/通信电源      |
| LLC 谐振      | 50~500W，高效率需求 | 隔离   | 中高 | 笔记本适配器、LED 驱动 |

反激的本质：MOSFET 导通时变压器**储能**（原边电流线性上升、副边二极管反偏）；MOSFET 关断时能量**释放**到副边（变压器像一对耦合电感，不是传统变压器）。这就是"反激"名字的来历——副边在开关管关断时才导通，相位相反。

关键波形关系：

```
导通期 Ton:  Lp * dIp/dt = Vin        → Ip 线性上升
关断期 Toff: Ls * dIs/dt = -Vout-Vd   → Is 线性下降
```

占空比与匝比关系（DCM 断续模式，忽略损耗）：

```
Vout = Vin * (Ns/Np) * D/(1-D)
```

算例：Vin = 300V（220V 整流后），Np:Ns = 100:6，D = 0.28 时：  
Vout ≈ 300 × (6/100) × 0.28/0.72 ≈ 7V，再由反馈环路把 D 微调到使 Vout = 5V 稳定。

## 1.3 PCB 设计视角下的四大分区

开关电源 PCB 布局的根本思想：**按电压和功能分区，按功率流向摆件**。

| 分区      | 电压域             | 包含元件                 | 布局要求            |
| ------- | --------------- | -------------------- | --------------- |
| EMI/输入区 | 热地（L/N，220V AC） | 保险丝、MOV、共模电感、X 电容    | 沿输入走线一字排开       |
| 高压 DC 区 | 热地（~300V DC）    | 整流桥、大电解、MOSFET、变压器原边 | 功率环路面积最小        |
| 隔离带     | 强制空区            | Y 电容（唯一允许跨越的功率元件）    | ≥6.4mm 爬电       |
| 低压输出区   | 冷地（5V/2A）       | 副边二极管、输出电容、TL431、光耦  | 输出环路面积最小、反馈远离噪声 |

**热地（一次侧地）与冷地（二次侧地）是两个物理上完全分开的地**，它们之间唯一允许的连接是 Y 电容（为共模电流提供回路）。这是开关电源 PCB 与普通数字板最大的区别：地不是一张统一的铜皮，而是被隔离带一分为二。

## 1.4 安全等级与 CLASS II 设计

| 绝缘等级 | 定义            | 实现方式          | 耐压测试              |
| ---- | ------------- | ------------- | ----------------- |
| 功能绝缘 | 仅电路功能需要       | 走线间距即可        | 无要求               |
| 基本绝缘 | 防电击基本保护       | 爬电/间隙达标       | 1250V AC（220V 系统） |
| 附加绝缘 | 基本绝缘失效后的第二道防线 | 双重物理隔离        | 1250V AC          |
| 加强绝缘 | 基本+附加合一       | 变压器三层胶带、隔离带加宽 | 3000V AC          |

本例 5V/2A 充电器类产品通常是 **CLASS II（两芯插头，无保护地）**，一次侧到二次侧必须满足**加强绝缘**：变压器内部三层绝缘胶带、光耦 PC817 内部也是隔离器件（爬电 ≥6.4mm 或 ≥8mm 取决于标准版本）。

# 第 2 部分：EMI 滤波器设计与布局

## 2.1 开关电源为什么是"干扰源"

MOSFET 每秒开关几万次，di/dt 达 10⁷~10⁸ A/s 量级。干扰从两条路出去：

| 路径                 | 机理                | 抑制手段                 |
| ------------------ | ----------------- | -------------------- |
| 传导干扰（150kHz~30MHz） | 开关电流经输入线回到电网      | EMI 滤波器（X/Y 电容、共模电感） |
| 辐射干扰（30MHz~1GHz）   | 环路天线效应、dV/dt 节点辐射 | 最小化环路面积、缩短开关节点、屏蔽    |

标准依据：CISPR 32 / GB 9254（信息技术设备）、CISPR 35 / GB 17625（谐波）。传导测试在 150kHz~30MHz 频段，恰好覆盖开关频率及其谐波——所以 EMI 滤波器必须从 **150kHz 起就有足够插入损耗**。

## 2.2 EMI 滤波器电路结构

标准两级 π 滤波：

```
L ──F1──┬──CM电感──┬──→ 整流桥
        │          │
  MOV   Cx1   Cx2  Cy(×2，跨接到二次侧地)
        │          │
N ──────┴──────────┴──→ 整流桥
```

| 元件             | 拖制对象               | 典型值                     | 关键布局要求        |
| -------------- | ------------------ | ----------------------- | ------------- |
| X 电容（Cx）       | 差模干扰（L-N 之间）       | 0.1~0.47µF/275V AC      | 紧贴共模电感前后，走线短粗 |
| Y 电容（Cy）       | 共模干扰（L/N→PE 或二次侧地） | 1~2.2nF/400V AC Y1 或 Y2 | 尽量靠近变压器/副边噪声源 |
| 共模电感（CM choke） | 共模干扰               | 10~33mH（高磁导率锰锌铁氧体）      | 输入线绕向一致，前后错开  |

X/Y 电容的安规含义：

- **X 电容**跨接 L-N，失效短路会引起火灾→必须用"失效开路"的薄膜电容（X2 最常用）；
- **Y 电容**跨接一次侧到二次侧（或到 PE），失效短路会让人摸到 220V→必须用通过 4000V 以上脉冲测试的 Y1/Y2 陶瓷电容，且容值受**漏电流限制**（手持设备 <0.25mA，按 `I = 2πf·C·V` 反推）。

算例：220V/50Hz，手持设备要求漏电流 <0.25mA：

```
C_max = I / (2πf·V) = 0.25mA / (2π×50×250) ≈ 3.2nF
```

所以手持类产品 Y 电容总容量控制在 2×2.2nF 以内（两只对称放）。

## 2.3 共模电感的布局细节

1. **进线（AC 输入）→ 保险丝 → MOV → X 电容 → 共模电感 → X 电容 → 整流桥**，按这个顺序一字排开，别绕弯；
2. 共模电感前后走线**不能平行靠近**，否则输入输出耦合，滤波器等于白放——前后走线呈"U 型"错开；
3. 电感本体下方**禁止走任何信号线**（尤其反馈线），磁通耦合会引入噪声；
4. 若空间紧张，X 电容优先靠近整流桥侧（差模噪声主要来自整流桥后的大电容充电脉冲）。

## 2.4 Y 电容放置位置的学问

Y 电容的作用：给共模电流（通过变压器杂散电容 Coupling 到二次侧的位移电流）一条低阻抗回流路径，避免它经过输出线形成辐射。

放置优先级（从好到差）：

1. 变压器原边静点（大电解负极/母线地）→ 副边输出地，**紧贴变压器**；
2. MOSFET 散热铜皮（开关节点对地电容是共模源）→ 副边地；
3. 热地 → 冷地最远距离直连（环路最大，效果最差）。

工程结论：Y 电容焊盘要**直接放在变压器引脚旁边**，引线电感 `L = 1nH/mm` 级别，1cm 引线在 30MHz 时阻抗 `2πfL ≈ 1.9Ω`，会显著削弱 Y 电容的高频旁路效果。

# 第 3 部分：一次侧功率环路布局（最核心）

## 3.1 什么是"功率环路"及其面积要求

反激一次侧的开关环路：

```
高压母线+（C_bulk+）→ 变压器原边 → MOSFET D-S → 采样电阻 Rs → C_bulk−（地）
```

MOSFET 每 20~60kHz 通断一次，这个环路的面积就是**天线面积**。设计铁律：

> **功率环路面积最小化是开关电源 PCB 设计的第一原则。**

| 环路       | 构成                 | 面积目标           |
| -------- | ------------------ | -------------- |
| 一次侧开关环路  | 大电容→原边→MOS→采样电阻→回地 | 越小越好，通常 <3 cm² |
| 二次侧整流环路  | 变压器副边→肖特基→输出电容→回副边 | 同样最小化          |
| RCD 吸收环路 | 钳位电容+二极管+电阻        | 单独小环路，别混入主环路   |

布局实操（AD23 演示思路）：

1. 先摆**大电解电容 → 变压器 → MOSFET**，三者构成的主环路优先级最高；
2. 元件按原理图信号流"一字/口字"排布，让回路自然闭合；
3. 用**铺铜代替走线**承载功率电流（铜皮比细线阻抗低、散热好）；
4. 大电容的 + 和 − 焊盘之间直接铺铜拉近距离，返回路径就在电容脚下闭合。

## 3.2 开关节点（MOSFET 漏极/变压器原边异名端）

开关节点是全板 dV/dT 最大的节点（0~300V 摆动，上升沿几十 ns），它是辐射干扰的主要源头：

| 规则                                 | 原因                  |
| ---------------------------------- | ------------------- |
| 开关节点铜皮面积"够焊就好"，最小化                 | 铜皮=辐射_patch antenna |
| MOSFET 漏极和变压器引脚**直接相对/紧贴**         | 缩短最热点               |
| 开关节点下方（次层）尽量不走敏感线                  | 电场耦合                |
| MOSFET 需要散热铜皮时，铺铜放在**源极（地）** 而不是漏极 | 地铜皮不辐射，漏极铜皮是天线      |

这就是为什么很多参考设计里 MOSFET 下方一大片接地铜皮——它既是散热器又是屏蔽，而漏极引脚只有一小段走线。

## 3.3 采样电阻与 IC 感应线

峰值电流模式控制（如 OB2263、UC3842 系列）通过 Rs 上的电压检测原边电流：

```
Rs = Vcs(th) / Ipk     （Vcs(th) 通常 0.5~1V）
```

算例：5V/2A 反激，最大原边峰值电流约 0.6A，取 Vcs(th)=0.9V → Rs ≈ 1.5Ω（用两只 3Ω 并联降功耗、提精度）。

布局规则：

| 规则                                                        | 违反后果                 |
| --------------------------------------------------------- | -------------------- |
| Rs 到 IC 的 CS 引脚走线**成对（Kelvin）接法**，紧贴 Rs 焊盘取样              | 引线压降混入，电流限不准         |
| RC 前沿消隐滤波（如 1kΩ+470pF）**紧贴 IC 引脚放**                       | 高频振铃直接打进 CS，误触发逐周期限流 |
| CS 走线远离变压器、开关节点                                           | 感应噪声                 |
| Rs 功率核算：P = Ipk²·Rs·D/3 ≈ 0.6²×1.5×0.3/3 ≈ 54mW，1206 封装富余 | 电阻过热漂移               |

## 3.4 启动电阻与 IC 供电（VDD）

高压启动电阻从母线（约 300V）接到 IC 的 VDD：

| 项    | 数值与规则                                  |
| ---- | -------------------------------------- |
| 启动电阻 | 几百 kΩ~2MΩ（如 2×470k），0805/1206 耐压分摊     |
| 启动时间 | C_VDD 0.1~10µF 由启动电流充电到 UVLO-on（如 16V） |
| 运行供电 | 辅助绕组 + 整流二极管 + 47µF/25V 电容             |
| 布局   | 启动电阻靠高压侧，VDD 电容**紧贴 IC**（一端直接接 IC 地）   |

辅助绕组供电环路（辅助绕组→二极管→VDD 电容→回绕组）也是一个开关环路，面积同样要小，二极管选 1N4148/快恢复即可（电流 mA 级）。

# 第 4 部分：反激变压器与 RCD 吸收电路

## 4.1 漏感与电压尖峰

变压器不是理想元件，原边总有一部分磁通不耦合到副边——**漏感 Llk**（通常为原边电感的 1%~3%）。MOSFET 关断瞬间，漏感电流没有通路，电压瞬间泵升：

```
Vspike = Ipk × sqrt(Llk / Coss_parasitic)
```

不加抑制，MOSFET 漏极看到的电压：

```
Vds = Vbulk + (Vout + Vd) × Np/Ns + Vspike
     ≈ 300V + (5 + 0.5) × (100/6) + 尖峰
     ≈ 300 + 92 + 尖峰(50~150V) ≈ 450~550V
```

所以 600V/650V MOSFET 是 220V 输入的标准选择，而 RCD 钳位的目的就是把尖峰压到安全范围（一般钳位在反射电压的 1.5~2 倍）。

## 4.2 RCD 钳位电路设计与布局

```
原边同名端 ──┬──────→ MOSFET 漏极
             │
             ├─→ 二极管(1N4007/快恢复UF4007) → Rc ─┐
             │                                    │
             └────────←── Cc ←───────────────────┘
```

参数设计步骤（工程法）：

| 步骤             | 公式                                     | 本例取值                  |
| -------------- | -------------------------------------- | --------------------- |
| 1. 钳位电压 Vclamp | 取 2~2.5 × Vor（反射电压）                    | Vor≈92V → Vclamp≈200V |
| 2. 钳位电容 Cc     | Cc = Ipk²×Llk/(Vclamp²−Vor²)，Llk≈1%×Lp | 约 2.2~10nF/400V       |
| 3. 钳位电阻 Rc     | Rc = (Vclamp−Vor)²/(0.5×Llk×Ipk²×fsw)  | 约 47k~150kΩ           |
| 4. 功耗校核        | Pc = 0.5×Llk×Ipk²×fsw                  | <0.5W，选 1206          |
| 5. 二极管         | 耐压 >Vclamp+Vbulk，快恢复                   | UF4007(1000V/1A)      |

**布局铁律**：RCD 三元件构成的小环路必须**紧贴变压器原边和 MOSFET 漏极**，环路里流的是最高 di/dt 的尖峰电流。RCD 环路 + 主开关环路是双绞关系：RCD 吸收回路要"骑"在主环路上方闭合，两者共用变压器引脚到 MOS 漏极那段铜皮。

常见错误：把 RCD 放到板子另一头"找空位"——结果尖峰电流绕板半圈，EMI 爆表，钳位效果反而变差。

## 4.3 变压器引脚排布与布局

典型 EE16 反激变压器的引脚分区（俯视，从 PCB 角度理解）：

| 引脚组  | 内容                      | 布局去向        |
| ---- | ----------------------- | ----------- |
| 一侧   | 原边起始端（接母线+）             | 铺铜到 C_bulk+ |
| 同侧相邻 | 原边结束端/同名端（接 MOS 漏极、RCD） | 短粗铜到 MOS    |
| 另一侧  | 副边绕组 + 辅助绕组             | 到肖特基阳极      |
| 跨越   | 无——原副引脚天然分居两侧           | 中间就是隔离带     |

布局时把变压器**旋转到"原边引脚朝高压区、副边引脚朝低压区"**&#x7684;方向，让隔离带自然从变压器底下穿过。变压器底下 PCB 区域禁止任何一次-二次走线穿越（加强绝缘要求，胶带+挡墙胶带+PCB 间距共同保证）。

# 第 5 部分：二次侧整流、输出滤波与纹波控制

## 5.1 副边整流环路

MOSFET 关断瞬间，副边电流从 0 冲到 Ip×Np/Ns（本例约 0.6×100/6 = 10A 峰值！），环路是：

```
变压器副边 → 肖特基阳极→阴极 → 输出电解电容+ → 输出电容− → 回副边
```

这是全板 di/dT 最猛的环路，布局优先级与一次侧主环路同级：

1. **肖特基紧贴变压器副边引脚**；
2. **第一只输出电解电容紧贴肖特基**，构成小闭环；
3. 副边地铺一整片铜，让返回电流从电容脚下直接回来；
4. 若用 SS54（5A/40V）注意耐压：反向电压 = Vout×Np/Ns + Vin_max×Ns/Np ≈ 5×16.7 + 373/16.7 ≈ 83+22 ≈ 105V——所以 5V 输出反激往往要 **SR5100（100V/5A）或 SR560（60V/5A）**，耐压必须按最坏情况核算！这是新手最容易踩的坑。

| 参数      | 计算式                                 | 本例                         |
| ------- | ----------------------------------- | -------------------------- |
| 副边峰值电流  | Is_pk = Ipk×Np/Ns                   | ≈10A                       |
| 二极管平均电流 | Io×(1+D')/1（近似 Io=2A）               | ≈2A 有效值更高，选 5A 管           |
| 反向电压峰值  | Vrrm = Vout×Np/Ns + Vbulk_max×Ns/Np | ≈105V → 选 150V 更稳          |
| 导通损耗    | P = Vf×Io×D''                       | 0.5V×2A×0.7 ≈ 0.7W → 需散热铜皮 |

## 5.2 输出滤波网络

输出电容不是一只电容解决，而是"大容量电解 + 高频陶瓷 + 磁珠"组合，因为电容有 ESR/ESL，单只电容高频阻抗上升：

```
肖特基 → C1(470µF低阻电解) → (+磁珠/1µH电感 L1) → C2(470µF) → 端子
              └ C3(100nF X7R 紧贴)                
```

| 元件    | 作用         | 选型要点                                  |
| ----- | ---------- | ------------------------------------- |
| C1 电解 | 平滑工频级纹波    | 低 ESR（<50mΩ）、耐纹波电流 >2A_rms、6.3~10V 耐压 |
| C3 陶瓷 | 旁路开关频率及谐波  | X7R/X5R，100nF~1µF，紧贴肖特基               |
| 磁珠/L1 | 抑制 MHz 级尖峰 | 磁珠注意直流压降（DCR）与额定电流 >3A                |
| C2 电解 | 端子处储能      | 与 C1 分担，降低输出阻抗                        |

**纹波预算算例**：输出纹波 = 电容充放电纹波 + ESR 纹波

```
ΔV_cap = Io×D'/(C×fsw) = 2×0.72/(470µ×65k) ≈ 47mV
ΔV_esr = ΔIs×ESR = 5A×40mΩ ≈ 200mV
```

可见 ESR 纹波占大头——低 ESR 电容和减小副边环路（降低寄生电感引起的振铃）才是关键，一味加大容量收益有限。

## 5.3 副边地的分割与汇流

副边地（冷地）虽然是一整片，但内部仍有"功率地"和"信号地"之分：

```
功率地：肖特基、C1/C2 的地 —— 大电流
信号地：TL431、分压电阻、光耦的地 —— µA 级
```


规则：TL431 分压电阻的下端**单点接到输出端子地**，而不是中途接在功率地铜皮上——否则功率电流在地铜皮上的 mV 级压降会直接叠加进反馈电压，造成输出纹波加大或环路震荡。光耦（副边侧）地也归信号地。

# 第 6 部分：隔离反馈环路（TL431 + PC817）布局

## 6.1 反馈电路拓扑

跨隔离带的信号只有一路：光耦。典型副边反馈网络：

```
5V输出 ──R_up(10k)──┬── TL431 REF ──┐
                    │               │
              R_dn(10k)+C_comp      TL431 K─A 接 PC817 LED−
                    │               PC817 LED+ 经 R_bias(470Ω) 接 5V
                   信号地           PC817 C-E：原边 IC FB 引脚 ─ IC 地
```

| 元件              | 取值                          | 作用                              |
| --------------- | --------------------------- | ------------------------------- |
| R_up / R_dn     | 10k / 10k（5V 基准 2.5V 时 1:1） | 分压设定输出电压：Vout = 2.5×(1+Rup/Rdn) |
| R_bias          | 220~1kΩ                     | 光耦 LED 静态偏置，保证 TL431 最小阴极电流 1mA |
| C_comp / R_comp | 100nF + 依环路调整               | TL431 跨导补偿，决定穿越频率与相位裕量          |
| 光耦 PC817        | CTR 50~300%                 | 信号隔离传输，原边拉 FB                   |

## 6.2 布局的五条铁律

1. **反馈走线"远、短、静"**：分压电阻尽量靠近输出端子（真正的输出电压点），而不是靠近肖特基（噪声源）；走线短而细，远离开关节点、变压器、共模电感；
2. **单点接地**：分压电阻下端、TL431 地、光耦副边地，一起拉到输出电容负极端子处单点汇接；
3. **补偿元件紧贴 TL431**：C_comp 直接连 REF 与 K 之间，别让补偿网络走长线；
4. **光耦跨隔离带放置**：PC817 本体骑在隔离带上方（器件内部隔离），原边引脚朝 IC、副边引脚朝 TL431，两侧走线绝不交叉；
5. **原边 FB 走线**：光耦集电极到 IC 的 FB 引脚，走线短、并联上拉电阻（内部或外部），旁边 0.1µF 滤波电容紧贴 IC。

## 6.3 环路稳定性与 PCB 的关系

反馈环路带宽典型设置为开关频率的 1/10~~1/20（65kHz 开关 → 穿越频率 3~~6kHz）。PCB 布局不当会把好环路变坏：

| PCB 缺陷         | 环路后果                      |
| -------------- | ------------------------- |
| 分压点引线过长，检到开关噪声 | 输出纹波被放大、可听闻啸叫             |
| 补偿电容远离 TL431   | 引线电感与 TL431 输出电容谐振，相位裕量恶化 |
| 光耦原边走线与开关节点平行  | 噪声耦合进 FB，占空比抖动            |
| TL431 阴极走线绕远   | 高频段光耦驱动不足，穿越频率上不去         |

排故口诀：输出电压不准 → 查分压比与基准；空载正常带载啸叫 → 查补偿与环路；带载纹波大 → 查副边环路面积与电容 ESR。

# 第 7 部分：安规距离详解（爬电与间隙）

## 7.1 两个概念必须分清

| 概念              | 定义                | 决定因素             |
| --------------- | ----------------- | ---------------- |
| 电气间隙（Clearance） | 两导电部件间**空气**中最短距离 | 瞬态过电压（雷击浪涌）、电场击穿 |
| 爬电距离（Creepage）  | 沿**绝缘表面**的最短距离    | 工作电压、污染等级、材料 CTI |

为什么爬电 > 间隙：表面可能积灰、受潮，形成导电通道（漏电起痕），所以沿面距离要求更严。

## 7.2 220V 一次侧到二次侧的取值（参考 IEC 62368-1 / 60950-1）

| 位置               | 电气间隙        | 爬电距离          |
| ---------------- | ----------- | ------------- |
| L-N 之间（熔断前）      | ≥2.0mm      | ≥2.5mm        |
| 一次侧工作电压之间（≤300V） | ≥2.0mm      | ≥2.5mm（污染等级2） |
| 一次侧→二次侧（加强绝缘）    | **≥4.0mm**  | **≥6.4mm**    |
| Y 电容引脚跨接（Y1 可放宽） | 按器件标准       | Y 电容本体承担      |
| 变压器内部原-副边        | 三层绝缘胶带 + 挡墙 | 器件内保证         |

**PCB 落地做法**：

1. 隔离带区域（变压器下方、光耦下方、跨越区域的整条带）**禁止走任何一次/二次走线**，禁止过孔；
2. 一次侧与二次侧铜皮之间开槽（slot）可以把爬电路径拉长——开槽后沿面距离沿槽壁绕行，同样直线距离可获得更大爬电；
3. AD23 里用规则（Design → Rules → Clearance / Creepage 规则组）给 Net Class "PRI" 和 "SEC" 之间设 6.4mm 间距规则，DRC 自动卡；
4. 一次侧高压网络单独 Net Class，如 L、N、HV+、HV−、SW 节点，规则间距 ≥2.5mm；
5. 板边、安装孔周围 1mm 内不留一次侧铜（边缘放电风险），安装孔用≥3mm 孔距的隔隙。

## 7.3 常见安规检查项 checklist

| # | 检查项         | 判据                      |
| - | ----------- | ----------------------- |
| 1 | 一次-二次爬电     | ≥6.4mm（含开槽后等效）          |
| 2 | 隔离带内无走线/过孔  | DRC + 肉眼复查              |
| 3 | 保险丝前 L-N 距离 | ≥2.5mm，熔断器有灭弧间距         |
| 4 | 变压器挡墙       | 挡墙宽度 ≥ 一次-二次爬电/2        |
| 5 | 光耦、Y 电容选型   | 认证器件（VDE/UL 等）          |
| 6 | 高压铜皮圆角      | 避免尖刺放电，铺铜倒圆角            |
| 7 | 丝印耐压标识      | 一次侧标 "⚠ HOT"、危险标识       |
| 8 | 板材 CTI      | FR-4 CTI≥175（污染等级 2 可用） |

# 第 8 部分：载流、热设计与铜箔计算

## 8.1 铜箔载流能力（IPC-2221 经验公式）

```
I = k × (ΔT^0.44) × (A_mils²)^0.725
内层 k=0.024，外层 k=0.048；A 为铜截面积（mil²）
```

1oz 铜箔（35µm 厚）常用线宽速查（外层、10°C 温升）：

| 线宽           | 载流（1oz，ΔT=10°C） | 本例用途           |
| ------------ | --------------- | -------------- |
| 0.3mm（12mil） | ~1.2A           | 信号、辅助绕组        |
| 0.5mm（20mil） | ~1.9A           | 低压侧一般功率        |
| 1.0mm（40mil） | ~3.2A           | 副边整流、5V 输出     |
| 2.0mm（80mil） | ~5.5A           | 输出主路（本例 2A 足够） |
| 铺铜 ≥5mm      | >8A             | 一次侧母线、副边地      |

注意：一次侧虽然电流有效值小（原边 RMS 约 0.3~0.5A），但走线短粗有助于减小环路寄生电感——所以一次侧功率路径同样用铜皮。

## 8.2 发热元件与散热铜皮

本例（5V/2A，总效率约 80%）各元件损耗与热处理：

| 器件     | 估算损耗                  | 散热措施              |
| ------ | --------------------- | ----------------- |
| 整流桥    | 2×1.4V×0.35A ≈ 0.7~1W | 加大焊盘铺铜、必要时选低 VF 桥 |
| MOSFET | 导通+开关损耗 ≈ 0.8~1.2W    | TO-252 封装大面积源极铜皮  |
| 变压器    | 铜损+铁损 ≈ 0.5~1W        | 本体自然散热，留空间        |
| 肖特基    | ≈0.7~1W               | 阴极/阳极焊盘大面积铺铜      |
| RCD 电阻 | ≈0.2~0.5W             | 1206/1210 封装，别贴板边 |
| 输出电解   | ESR 损耗 ≈0.15W         | 选低 ESR、留通风        |

散热铜皮设计要点：

1. 铺铜**放在**低电位侧（地/源极/阳极），高压节点铜皮最小化；
2. 大铜皮上多打**过孔阵列**把热导入对面层（单个过孔热阻约 50~100°C/W，10 个并联降到 10°C/W 级）；
3. 高损耗电阻选 1206 以上封装并留铜皮；RCD 电阻、启动电阻远离电解电容（电解怕热，每升 10°C 寿命减半）；
4. 热敏元件（TL431、电解）远离变压器与整流桥。

# 第 10 部分：工程 FAQ（高频实际问题 Q\&A）

**Q1：为什么要区分热地和冷地？万用表打起来通不通？**  
热地（一次侧地）与电网直接相连，摸到=摸 220V；冷地是隔离后的安全地。两者物理上绝不相连（除 Y 电容），万用表二极管档量应为开路（Y 电容在则量到电容充放电现象）。

**Q2：Y 电容能不加吗？EMC 过不了怎么办？**  
可以先不加，传导测试超标（尤其 1~10MHz 段共模分量高）时加。位置从变压器引脚旁开始试，容量逐步 1nF→2.2nF，注意漏电流预算。

**Q3：输出纹波用示波器量出来 200mV，是设计问题还是量测问题？**  
先用"spring ground"（短接地弹簧）代替长地线，带宽限制 20MHz。很多"纹波"其实是量测环路感应的开关噪声。若确为真纹波，按 ESR 纹波 → 换低 ESR 电容/并联陶瓷；振铃尖峰 → 减小副边环路、加 RC 吸收（肖特基并 1nF+10Ω）。

**Q4：空载电压正常，一带载就掉到 3V，哪里查？**  
顺序：① 变压器饱和/感量不足（带载啸叫）；② CS 限流过早触发（Rs 偏小或噪声误触发）；③ 副边二极管/电解高温内阻增大；④ 反馈环路增益不足（补偿错误）。量 CS 脚波形看是否逐周期限流最直接。

**Q5：MOSFET 漏极波形振铃很大，吸收加了也没用？**  
检查 RCD 环路面积（是否绕远）、钳位电压是否设得太高（Rc 太大）、变压器漏感是否超标（>5% 需重绕）。漏感是根因，PCB 只能抑制表现。

**Q6：保险丝选快断还是慢断？**  
开机瞬间给大电解充电，浪涌电流是稳态的十几倍，选**慢断**（T 型），额定电流按稳态输入电流的 1.5~~2 倍。220V 输入 10W 输出、效率 80% → 输入电流约 57mA 稳态，浪涌可达数安 → 选 T315mA~~T1A 均常见，按 I²t 校核。

**Q7：5V 输出端子用多粗铜？**  
2A 输出，0.5mm 线宽（1oz）理论够，但考虑压降（0.5mm×50mm 长的铜电阻约 24mΩ → 2A 压降 48mV，占 1%）和温升，建议 ≥1mm 或铺铜。压降直接吃掉输出精度。

**Q8：光耦坏了输出会怎样？**  
光耦开路 → 原边 FB 拉不到 → IC 以最大占空比运行 → 输出过压。所以输出侧要有独立的过压保护（如稳压管+可控硅 SCR crowbar，或在副边加 OVP 比较器）。这是安全设计冗余。

# 第 11 部分：变压器磁学深入（设计 PCB 前必须理解的器件）

## 11.1 磁芯材料与几何

反激变压器工作在 65kHz 附近，磁芯材料几乎清一色是锰锌铁氧体（Mn-Zn Ferrite），功率级主流牌号对照：

| 牌号（厂商系列）             | 初始磁导率 µi  | 特点                   | 用途       |
| -------------------- | --------- | -------------------- | -------- |
| PC40（TDK）            | 2300      | 通用功率铁氧体，100kHz 以下损耗低 | 反激/正激通用  |
| PC44 / PC95（TDK）     | 2400/3300 | 中高温损耗更低              | 高效率、高温环境 |
| Mn-Zn 通用（国产磁盛、东磁同等级） | 2000~2300 | 成本低，性能接近 PC40        | 消费类电源    |

几何选择：5~~15W 用 EE16/EE19；20~~30W 用 EF25/EE25；45~65W 充电器用 PQ2620/PQ3220。磁芯越大：① 骨架绕线窗口越大（铜损小）；② 磁芯截面 Ae 越大（匝数可以少、磁损小）；③ 但成本与高度增加。本例 10W 用 EE16 合适。

## 11.2 为什么反激变压器必须开气隙

反激变压器本质是"耦合电感"，需要储存能量。铁氧体饱和磁通密度 Bsat 约 390mT（25°C），但功率设计限制在 **Bmax ≤ 0.3T 甚至 0.25T**（高温下 Bsat 下降到约 310mT，且要留瞬态余量）。不开气隙时 AL 值太高，很小的安匝就饱和。

开气隙后的设计链：

```
Lp = AL_g × Np²          （AL_g：开气隙后的电感系数）
Bmax = Lp×Ipk / (Np×Ae)  （必须 < 0.3T，含 1.2 倍余量）
气隙长度 lg ≈ µ0×Np²×Ae / Lp − 磁路长度贡献
```

算例（EE16，Ae=20.1mm²，Lp=1.2mH，Ipk=0.6A，Np=100）：

```
Bmax = 1.2m×0.6 / (100×20.1mm²) = 0.72/2.01 ≈ 0.358T ← 超限！
```

说明 Np=100 不够，需加到 Np=120：

```
Bmax = 1.2m×0.6/(120×20.1) ≈ 0.298T → 勉强，取 Np=130 → 0.276T，留余量 OK
```

对应气隙：lg ≈ µ0×Np²×Ae/Lp = 4π×10⁻⁷×130²×20.1mm²/1.2m ≈ 1.1mm（中柱气隙，磨芯实现）。

**磁芯损耗估算**：Pv ≈ k×f^α×(ΔB/2)^β，PC40 在 65kHz、ΔB=0.15T 时约 100~~150mW/cm³，EE16 磁芯体积约 0.55cm³ → 磁损约 60~~80mW，加铜损（原边 I_rms²×DCR ≈ 0.25²×3Ω ≈ 0.19W 量级），总变压器损耗 0.3~~0.5W，温升 20~~30°C，正常。

## 11.3 绕组结构与 EMI（三明治绕法）

变压器寄生参数直接决定 EMI 表现：

| 参数          | 影响             | 改善手段            |
| ----------- | -------------- | --------------- |
| 漏感 Llk      | 关断尖峰、RCD 损耗    | 原副边耦合紧、三明治绕法    |
| 原副边耦合电容 Cps | 共模电流通路（EMI 元凶） | 法拉第屏蔽层（绕一层铜箔接地） |
| 副边绕组自谐振     | 高频振铃           | 减少层数、分段绕        |

三明治（交错）绕法：把原边绕组拆成两半，副边夹在中间（P1 → S → P2 → 辅助），漏感可从 5% 降到 1~~2%。法拉第屏蔽：在原副边之间绕一层不闭环铜箔，接一次侧静点（大电解正端），把位移电流"接走"而不流向副边——对 30~~100MHz 辐射改善显著，代价是耦合变差、漏感略增。

PCB 设计要配合：变压器引脚定义确认绕组起末端（同名端），布线时同名端朝 MOS 漏极方向，异名端朝母线，别绕反导致 SW 节点铜皮被迫拉长。

## 11.4 变压器绕制规格表（本例）

| 绕组       | 匝数      | 线径             | 层级       | 起脚→落脚  |
| -------- | ------- | -------------- | -------- | ------ |
| P1（原边内层） | 65      | 0.15mm×2 股     | 最内       | 1→4    |
| S（副边）    | 8       | 0.3mm×3 股（或铜箔） | 中层       | 6→5    |
| P2（原边外层） | 65      | 0.15mm×2 股     | 中外       | 4→1 并联 |
| 辅助 Na    | 13      | 0.15mm×1       | 最外       | 3→2    |
| 屏蔽（可选）   | 铜箔一层不闭环 | —              | S 与 P2 间 | 接 HV+  |

绝缘：原副之间三层 2mil 胶带 + 挡墙 3mm（满足加强绝缘），整体真空浸漆。

# 第 12 部分：MOSFET 开关波形与损耗定量分析

## 12.1 漏极波形的四个阶段（对应示波器实测）

```
Vds
 ^   ┌─┐钳位平台(Vbulk+Vclamp)  ┌──────────────┐ ← 关断保持段(Vbulk+Vor)
 |   │ │    RCD放电路径           │              │
 |   │ │        ┌────────────────┘              │
 |   │ └────────┘  ← 尖峰被钳位                  └──────┐ ← 谐振下降
 |   │                                                  │
 |___┘__________________导通段(≈0V)______________________┤→ t
     Ton                                            Toff  下一周期
```

| 阶段     | 电路行为                  | 损耗机制                                |
| ------ | --------------------- | ----------------------------------- |
| ① 开通   | 栅极充电过 Vth，电流上升+电压下降交叠 | 开通损耗 P=0.5×Vds×Id×(tr+tf_cross)×fsw |
| ② 导通   | Rds(on) 压降            | P=Id_rms²×Rds(on)                   |
| ③ 关断交叠 | 电压先升（米勒平台）电流后降        | 关断损耗，同交叠公式                          |
| ④ 关断保持 | 漏感尖峰→RCD 钳位→平台        | RCD 损耗 0.5×Llk×Ipk²×fsw             |

算例（本例）：Vds=375V，Id=0.6A，tr+交叠 50ns，fsw=65kHz：

```
P_sw ≈ 0.5×375×0.6×50n×65k ≈ 0.37W
P_cond ≈ 0.25²×5Ω(650V管典型) ≈ 0.31W
P_RCD ≈ 0.5×12µH×1%漏感折算×0.6²×65k... 取 Llk=12µH → 0.14W
P_total ≈ 0.8~1W → TO-252 + 铺铜，温升约 40°C，可接受
```

## 12.2 米勒平台与驱动电阻

栅极电荷 Qg 是驱动损耗来源：P_drive = Qg×Vgs×fsw。本例 Qg≈15nC、Vgs=10V：P_drive ≈ 15n×10×65k ≈ 10mW（IC 内部驱动，发热可忽略）。驱动电阻（IC 与栅极之间的 Rg，典型 10~47Ω）的取舍：

| Rg      | 优点      | 代价                |
| ------- | ------- | ----------------- |
| 小（10Ω）  | 开关快、损耗低 | di/dt 大、EMI 恶化、振铃 |
| 大（100Ω） | EMI 温和  | 交叠损耗增大、发热         |

PCB 上：Rg 串联电阻与栅极下拉电阻（关断加速）**紧贴 MOS 栅极**放，驱动回路（IC OUT → Rg → 栅 → 源 → IC GND）面积小。栅极走线绝不与漏极开关节点平行——米勒电容 Cgd 会把 dV/dt 耦合进栅极引起误开通。

## 12.3 MOSFET 选型表（650V 通用管对比）

| 型号系列                  | Rds(on) | Qg      | 封装         | 场景      |
| --------------------- | ------- | ------- | ---------- | ------- |
| 通用 650V（如 STP7NM60 类） | ~1Ω     | 30nC    | TO-220     | 老设计、余量大 |
| 650V SJ（超结，如 5N65 类）  | 0.5~1Ω  | 15~25nC | TO-252     | 主流反激    |
| 高压低 Qg（准谐振配）          | 1~2Ω    | <10nC   | SOT-23/DFN | 小功率高集成  |

超结（SuperJunction）管 Coss 非线性强、Co(er)（有效输出电容）在高压下小——准谐振（QR）模式利用它实现谷底开通，把开通损耗转移到电压谷点，65~~130kHz QR 反激是当前 10~~30W 主流。

# 第 13 部分：传导 EMI 定量分析与滤波器设计进阶

## 13.1 噪声分离：差模 vs 共模

LISN（线路阻抗稳定网络）测试中，用噪声分离器把传导噪声拆成 DM/CM：

| 分量            | 来源                            | 频段特征             | 滤波元件      |
| ------------- | ----------------------------- | ---------------- | --------- |
| 差模 DM（L↔N）    | 电解电容充电脉冲（100/120Hz 及开关频率纹波电流） | 150k~1MHz 为主，低频段 | X 电容、差模电感 |
| 共模 CM（L/N→PE） | 开关节点对地电容、变压器 Cps 的位移电流        | 1~30MHz，高频段      | 共模电感、Y 电容 |

判别技巧（测试曲线形态）：低频（<1MHz）超标 → 加 X 电容/差模磁芯；高频（>5MHz）超标 → 加 Y 电容、查共模电感、查变压器屏蔽层、查接地（屏蔽布/铜箔接地位置）。

## 13.2 滤波器插入损耗估算

共模电感 + Y 电容构成 LC 低通，转折频率：

```
f_c = 1/(2π×sqrt(Lcm × 2Cy))
```

算例：Lcm=20mH，Cy=2×1nF（两侧各 1nF，对共模等效串联看 Lcm 两绕组）：

```
f_c = 1/(2π×sqrt(20m×2×1n)) ≈ 25kHz  ← 150kHz 处衰减约 5.5 阶(≈35dB)
```

若 150kHz 处超标 20dB，理论余量够；实际受寄生（电感匝间电容把高频"短路"、Y 电容引线电感）影响，高频段实测衰减常只有 20~40dB，所以布局（短引线）比元件值更重要。

共模电感匝间电容 Cp 在高频把电感旁路，自谐振点典型 1~5MHz。选电感看两个数：感量（低频损耗）+ SRF 自谐振频率（高频上限）。必要时两级共模电感串联拉开频段。

## 13.3 浪涌与雷击防护（IEC 61000-4-5）

| 等级            | 测试电压（1.2/50µs 组合波） | 防护配置               |
| ------------- | ------------------ | ------------------ |
| Level 2       | 1kV                | MOV 单只（471K）       |
| Level 3（常见要求） | 2kV                | MOV + 输入线绕电感限流     |
| Level 4       | 4kV                | MOV + GDT（气体放电管）级联 |


MOV 选型：压敏电压 = 1.5×最大稳态电压峰值 ≈ 1.5×373 ≈ 560 → 选 471K~561K（标称 470V/560V）。MOV 失效模式是短路，必须位于**保险丝之后**，让保险丝断掉救板。PCB 上 MOV 紧贴保险丝与共模电感，走线短粗承受浪涌（8/20µs 波形下可能数百安培瞬态）。

## 13.4 EMI 整改流程图（诊断树）

```
传导超标？
 ├─ 低频(<1MHz) → 差模 → 加/加大X电容 → 仍超？查大电解容量与ESR、整流桥并RC缓冲
 └─ 高频(>1MHz) → 共模 → 
      ├─ Y电容从2.2n→4.7n（漏电流允许下）
      ├─ 共模电感感量/级数增加
      ├─ 变压器加屏蔽层
      ├─ MOS漏极串小磁珠/RC snubber(100Ω+1nF跨DS)
      └─ 输出线磁环绕两圈（应急）
辐射超标(30M~1G)？
 ├─ 电缆共模 → 输出线夹磁环、USB口旁路电容
 ├─ 板级 → 开关节点铜皮再缩小、散热器接地、缝隙屏蔽
 └─ 变压器 → 屏蔽层、绕组结构
```

# 第 14 部分：反馈环路补偿定量计算

## 14.1 为什么必须懂补偿——环路不稳的三个表现

| 表现     | 波形特征                | 根因              |
| ------ | ------------------- | --------------- |
| 输出振荡   | 叠加几 kHz~几十 kHz 正弦纹波 | 相位裕量 <0°，环路自激   |
| 阶跃响应振铃 | 负载跳变后输出"打摆"数次才稳     | 相位裕量 20~40°，欠阻尼 |
| 缓慢爬行   | 跳变后缓慢恢复、过冲大         | 带宽太低或太高         |

目标：穿越频率 fc 取开关频率的 1/10~1/20，相位裕量 45°~60°，增益裕量 >10dB。

## 14.2 反激（电流模式）功率级小信号模型要点

电流模式控制把电感"变成受控电流源"，功率级在低频近似单极点系统：

| 极点/零点     | 频率          | 公式                                             |
| --------- | ----------- | ---------------------------------------------- |
| 负载极点 fp   | 输出电容与负载     | fp = 1/(2π×Rout×Cout) ≈ 1/(2π×2.5Ω×1mF) ≈ 64Hz |
| ESR 零点 fz | 输出电容 ESR    | fz = 1/(2π×ESR×Cout) ≈ 1/(2π×0.04×1m) ≈ 4kHz   |
| 采样极点      | 光耦+TL431 带宽 | 数十 kHz~百 kHz（CTR 下降）                           |

补偿网络（TL431 + 光耦，Type II）提供：一个原点极点（积分，拉高低频增益）+ 一个零点（抵消负载极点）+ 一个高频极点（压 ESR 区增益）。

## 14.3 手算流程（工程简化法）

```
① 定穿越频率：fc = fsw/15 ≈ 4.3kHz（取4kHz）
② 采样分压比：H = 2.5/5 = 0.5（-6dB）
③ TL431 跨导 gA=1mA/V，光耦 CTR≈1，需要的中频增益 Gm = (光耦上拉R/((Rup||Rdn)+Zcomp))×... 
   工程简化：直接按"零点 fz_c = fp/2 ≈ 32Hz、极点 fp_c ≈ fz(ESR) ≈ 4kHz"放
④ C_comp = 1/(2π×Rup×fz_c) = 1/(2π×10k×32) ≈ 500nF → 取 470nF
   （R_comp×C_pole = 1/(2π×4k) → 若 R_comp=10k，C_pole≈4nF）
⑤ 验证：4kHz 处相位 ≈ -90°+45°(零点贡献)-<10°(极点) → PM≈50° ✓
```

实测校准：用负载阶跃（电子负载 0.1↔2A）看恢复波形——无振铃、2~3ms 内回到 ±3% 即合格；振铃则增大 C_comp；太慢则减小。有条件用频响分析仪（Bode 100 类）扫曲线。

## 14.4 光耦带宽陷阱

光耦 PC817 的 CTR 随频率下降，-3dB 带宽只有约 100kHz 量级（且与集电极电阻成反比）。三个对策：

1. 原边 FB 上拉电阻别太大（≤10k，常用 4.7k），集电极电容小带宽高；
2. TL431 侧给光耦足够偏置电流（R_bias 保证 ≥1mA），让 CTR 工作在线性区；
3. fc 不要贪高，4~5kHz 是 65kHz 反激的安全区。

PCB 配合：R_bias、光耦、TL431 三角布局紧凑，走线短——这条链路本身就是"信号链"，和运放电路布局一个待遇。

# 第 15 部分：可制造性、测试与量产落地

## 15.1 波峰焊/手焊工艺的 PCB 约束

小批量电源板多用波峰焊或手焊，与 SMT 回流不同：

| 工艺    | PCB 要求                                          |
| ----- | ----------------------------------------------- |
| 波峰焊   | 元件面与焊接面分开、二次侧大铜皮需**开槽隔热/十字花焊盘**（散热太快焊不上）、优选单双面板 |
| 回流焊   | 铜皮不均衡要防"墓碑"（两端焊盘对称）、大铜皮上的焊盘加热区                  |
| 手焊/返修 | 高压元件间距要容得下烙铁头（≥5mm）、测试点直径 ≥1mm                  |

电解电容、变压器、MOS（TO-252）混装是电源板常态，DIP 与 SMT 混合排版时注意二次过波峰的元件方向。

## 15.2 测试点与产线测试

| 测试项           | 测点位置           | 备注                            |
| ------------- | -------------- | ----------------------------- |
| 输出电压精度        | 输出端子 ±         | 电子负载 0/满载两点                   |
| 纹波            | 输出端子 + 短地环     | 20MHz 带宽限制                    |
| Vds 尖峰        | MOS 漏极（留隔离区测点） | 高压探头，检查 ≤80% 耐压               |
| 效率            | 输入功率计 + 输出     | 25/50/100% 负载三点               |
| 安规耐压          | 一次-二次（工装夹具）    | 3000V AC/60s 产线用 100% 电压 1~2s |
| 接地 continuity | CLASS I 才需要    | 本例 CLASS II 免                 |

产线耐压测试是安规**例行检验**（100% 做的），认证测试还包含：接触电流测量、异常操作测试（输出短路、反馈开路、风扇堵转）、灼热丝/针焰（外壳件）。

# 第 17 部分：进阶主题——同步整流、准谐振与待机功耗

## 17.1 副边同步整流（SR）

肖特基 0.5V 压降在 2A 输出时吃掉 0.7W（占总损耗近 35%）。同步整流用低耐压 MOS（如 60~~100V、Rds(on) 10~~20mΩ）替代肖特基：

| 方案                  | 原理               | PCB 影响                         |
| ------------------- | ---------------- | ------------------------------ |
| 自驱 SR               | 副边绕组电压直接驱动 SR 栅极 | 栅极走线短，检测绕组紧贴                   |
| IC 检测 SR（如同步整流控制芯片） | 检测 Vds 过零换向      | 检测走线 Kelvin 接 SR 的 D/S，滤波紧贴 IC |
| 原边集成（部分 PSR 方案）     | 原边控制器预测控制        | 无需副边检测，但精度依赖系统                 |

SR 引入的新问题与对策：

| 问题                  | 对策                                  |
| ------------------- | ----------------------------------- |
| 死区时间直通（原边开通时 SR 未关） | IC 死区自适应；PCB 上检测线必须 Kelvin、滤波 RC 紧贴 |
| 轻载 SR 反向导通          | 强制断续/关断 SR                          |
| 栅极振铃                | 栅极电阻 + 短走线                          |

本例 10W 用肖特基性价比更高；≥18W 的 5V 输出才明显受益（0.5V×3A=1.5W vs 20mΩ×3² =0.18W，省 1.3W）。

## 17.2 准谐振（QR / 谷底开通）

传统硬开关在高压大电流交叠开通。准谐振检测 Vds 谐振谷底（由 Llk 与 Coss 谐振产生，周期性下探到 Vbulk−Vor），在谷点开通把交叠损耗降到最低，且 EMI 频谱能量分散。特征：

- 谷底检测引脚（IC 的 ZCD/DET）经分压电阻接辅助绕组——**该走线是高压感知线，远离干扰、分压电阻紧贴 IC**；
- 频率随负载降低而下降（周期拉长等下一个谷），轻载自动降频 → 待机功耗低；
- 频率上限钳制（如 130kHz，避开 CISPR 150kHz 起测线的谐波密集区）。

## 17.3 待机功耗与能效法规

| 标准/法规                   | 关键条款                                                          |
| ----------------------- | ------------------------------------------------------------- |
| 能效标准（如 DoE VI 级、CoC V5） | 空载功耗：额定输出 ≤49W 的适配器要求 <0.075~0.1W                             |
| 平均效率                    | 5V/2A 档（10W）要求平均效率 ≥ 0.083×ln(10)+0.625 ≈ 81.6%（CoC V5 tier2） |

达标手段清单（从设计端到 PCB 端）：

1. **降低开关频率**（QR/突发模式 Burst）：轻载跳周期；
2. **降低启动电阻损耗**：高压启动由 IC 内部 JFET 完成或启动后断开启动电阻；
3. **X 电容放电阻**：新规可用 X-cap 放电 IC 替代物理电阻（一颗 2MΩ 电阻在 373V 峰值就耗 70mW，直接吃光预算）；
4. **变压器与缓冲优化**：RCD 在轻载损耗占比高，可用 TVS 钳位或"smart snubber"；
5. **PCB 微贡献**：缩短所有功率路径寄生（降低每一环节的固定损耗）。

算例：待机 75mW 预算分配——IC 静态 15mW + 启动网络 10mW + RCD 10mW + 输出假负载/分压 20mW + 其他 20mW。分压电阻从 10k/10k 换成 100k/100k（TL431 偏置另配）可省 1mW 级——可见每个细节都要抠。

## 17.4 一次侧稳压（PSR）的 PCB 差异

无光耦/TL431 的 PSR 方案（副边信息由辅助绕组反射）正在替代传统方案：

| 差异点  | PSR vs 传统光耦方案                      |
| ---- | ---------------------------------- |
| 元件数  | 少 TL431、光耦、七八只阻容，BOM 成本降 0.3~0.5 元 |
| PCB  | 隔离带只剩变压器与 Y 电容；反馈小信号区整个消失          |
| 精度   | ±2~5%（线缆补偿后 ±2%），略差                |
| 关键走线 | 辅助绕组到 IC 的采样线（FB/DET）成为全板最关键信号线    |

# 第 18 部分：布局走查实例（逐区域点评式复盘）

以本例 5V/2A 板（单面板或双面板，47×28mm 典型充电器内板）为对象，从输入端子开始逐区"走查"，把前面所有规则落到具体坐标关系上。

**区域 1：输入端子到保险丝（板左缘）**

- 端子焊盘间距按 L-N ≥3mm 开孔间距设计，端子铜皮加宽承浪涌；
- 保险丝离端子 ≤5mm，MOV 紧跟保险丝之后分叉接入；
- L/N 进入后第一件事是"分道"：两线间距保持 ≥2.5mm 平行走线至共模电感，途中只允许接入 X 电容与 MOV；
- 走查检查点：保险丝前不得有任何分叉支路（含 LED 指示灯），否则保险丝失去保护意义。

**区域 2：共模电感与整流桥**

- 共模电感本体占位约 11×11mm，其正下方及周围 3mm 内无任何走线（含内层）；
- 整流桥四个焊盘的交流侧朝输入、直流侧朝大电解，禁止"交叉翻面"式布局（整流桥走线交叉 = 两个环路叠加）；
- 整流桥下方可铺热地铜皮散热，但注意铜皮与二次侧间距。

**区域 3：大电解与变压器之间（一次侧核心）**

- 电容负极 → MOS 源极采样电阻的返回路径铺铜直接从电容脚下走，宽度 ≥5mm；
- SW 节点：变压器同名端脚到 MOS 漏极脚的铜皮走"直线相邻"，长度控制在 15mm 内，铜宽"够流"即可（本区是全板辐射源，铜皮克制）；
- RCD 三件套塞进变压器-MOS 之间的空档，二极管方向朝钳位电阻，环路直径 <15mm；
- MOS 源极铜皮向板缘扩展成 ≥10×10mm 的散热铺铜 + 6~10 个 0.3mm 过孔拉到下层（若双层板）。

**区域 4：变压器正下方与隔离带**

- 隔离带从变压器中心线下方穿过，带宽 ≥6.4mm（双层板两侧都要开）；
- 带内除 Y 电容焊盘外无任何铜；
- Y 电容焊盘骑在隔离带两侧，热端焊盘接变压器辅助绕组地/大电容负极，冷端接副边地，两只引脚各自走出 ≤5mm 的短粗线。

**区域 5：副边功率区**

- 副边绕组出脚 → SR5100 阳极，≤8mm；SR5100 阴极铺铜 ≥8mm 宽直达 C1 正极；
- C1（470µF）负极铺铜与阴极铜皮在 SR 焊盘附近闭合，闭环直径 <20mm；
- 磁珠+第二只电解沿输出方向排开，端子前 100nF 陶瓷收尾；
- 副边地整片铺铜，TL431 区域靠板中央安静处，光耦骑隔离带。

**区域 6：IC 小信号区**

- IC（SOT23-6/DIP8）放变压器辅助绕组侧、隔离带热端内侧；
- VDD 电解 47µF 与 0.1µF 陶瓷双电容，陶瓷紧贴 IC 引脚 <3mm；
- CS 滤波 RC 紧贴 CS 脚；FB 上拉与光耦集电极之间走线 <10mm；
- COMP（若有）补偿元件紧贴，该网络是环路调参接口，留测试点。

**总走查表（按区打勾）**

| 区      | 面积/距离硬指标                          | 通过 |
| ------ | --------------------------------- | -- |
| 1 输入   | 熔断前无分叉；L-N ≥2.5mm                 | ☐  |
| 2 滤波   | 电感下无走线；整流无交叉                      | ☐  |
| 3 一次功率 | SW 走线 ≤15mm；RCD 环 ≤15mm；MOS 铜皮+过孔 | ☐  |
| 4 隔离带  | ≥6.4mm 全程净空；Y 电容脚 ≤5mm            | ☐  |
| 5 副边功率 | SR-电容闭环 ≤20mm；铺铜载流达标              | ☐  |
| 6 IC 区 | 全部小件距 IC ≤10mm；CS/FB 静区           | ☐  |

# 第 19 部分：第二课——220V 转 12V 反激（功率抬升后的全面重算）

## 19.1 输出电压从 5V 抬到 12V，哪些设计量要跟着变

第二课用同一套反激框架做 12V 输出（典型适配器 12V/2A，24W），核心教学点&#x662F;**"改一个参数，全链重算"**&#x7684;工程习惯。以 12V/2A、匝比 Np:Ns=100:10、fsw=65kHz 为例：

| 设计量       | 5V/2A 版           | 12V/2A 版                            | 变化原因             |
| --------- | ----------------- | ----------------------------------- | ---------------- |
| 反射电压 Vor  | (5+0.5)×100/6≈92V | (12+0.5)×100/10≈125V                | 匝比+输出电压抬升        |
| 副边二极管反向电压 | ≈105V（选 150V）     | 12×10+373/10≈157V（选 200V SR 或 250V） | 反射电压折算变大         |
| 副边峰值电流    | ≈10A              | 2A×同占空比 ≈8~10A（匝比变了电流折算低）           | Np/Ns 变小         |
| 副边整流损耗    | 0.5V×2A≈0.7W      | 肖特基 0.5V×2A≈0.7W（电流没变）              | 但同步整流收益比 5V 版更明显 |
| 输出电容纹波电流  | 高（低占空比大脉冲）        | 略低（匝比改善占空比）                         | 输出级应力略降          |
| 变压器       | EE16              | EE19/EE25（24W 功率）                   | 功率翻倍以上           |
| MOSFET    | 650V/3A           | 650V/5~8A                           | 原边峰值电流增大         |

**手算示范（Vor 变化传导到 MOS 耐压）**：

```
Vds_max = Vbulk_max + Vor + Vspike = 373 + 125 + 100 ≈ 600V
```

5V 版是 ≈550V，12V 版逼近 650V 管子的极限——所以 12V 输出的反激要么把匝比降下来（Ns 减小、副边二极管耐压再往上升），要么上 700V/800V MOS。**匝比是"原边耐压"与"副边耐压"之间的跷跷板**，这是第二课的核心算例。

## 19.2 PCB 层面的差异

| 项      | 5V 版      | 12V 版（24W）                      |
| ------ | --------- | ------------------------------- |
| 板层     | 单面/双面 1oz | 双面 1~2oz，24W 建议双面铺铜             |
| 一次侧环路  | <3cm²     | 同样最小化，电流更大环路面积收益更高              |
| 散热     | MOS 铺铜即可  | MOS+整流桥+肖特基都需要 ≥10×10mm 铺铜+过孔阵列 |
| EMI 滤波 | 单级 π      | 两级 π（X 电容×2 + 共模电感×2 或加大感量）     |
| 输出端子   | 焊盘        | 大电流端子/DC 线，铜皮 2mm+ 承 2A 且降压降    |

## 19.3 第二课强化的三个工程习惯

1. **改动清单法**：任何参数变更（输出电压/电流/频率）后，列"影响传导表"（器件耐压→损耗→温升→布局），逐项重算——课上老师用表格驱动整个重设计流程；
2. **环路面积与温升实测意识**：布局完成后对四个环路做"假想电流路径"走查（用鼠标沿铜皮描一遍回路），同时预估每个发热件的温升（损耗×热阻）；
3. **同平台复用**：与 5V 版共用原理图框架，只改功率级器件值——产品系列化设计的思维（一个平台衍生 5V/9V/12V/15V 全家桶快充，正是工业界的真实做法）。

# 第 20 部分：第三课——300W 户外路灯驱动（PFC + LLC 两级架构）

## 20.1 为什么 300W 必须放弃单级反激

| 限制   | 单级反激在 300W 的困境                                   |
| ---- | ------------------------------------------------ |
| 法规   | EN 61000-3-2 / GB 17625.1：>75W 输入必须做 PFC（谐波电流限制） |
| 器件应力 | 反激原边峰值电流 = 300W 级 → Ipk 超 10A，MOS/变压器/RCD 全线恶化   |
| 电解寿命 | 反激母线电容承受 100Hz 纹波 × 大电流，电解寿命是路灯电源的头号失效源          |
| 效率   | 单级反激在 300W 效率难超 88%，两级（PFC+LLC）可达 92~95%         |

于是 300W 路灯电源的标准架构：

```
L/N ─→ 熔断+MOV+继电器(防浪涌/旁路NTC) ─→ EMI 滤波 ─→ 整流桥 ─→ Boost PFC
     （CrM/DCM 临界导通模式，输出 400V 母线）─→ LLC 半桥谐振 ─→ 变压器
     ─→ 副边同步整流 ─→ 恒流输出（LED 串联，如 200V/1.5A）
```

## 20.2 PFC 级的布局要点

Boost PFC 的功率环路（这是全板第一大环路）：

```
母线(400V) ← 升压二极管 ← MOSFET ← 升压电感 ← 整流桥输出
     └───────── 输出电解电容 ←───────────────────┘（返回路径）
```

| 元件        | 布局规则                                 |
| --------- | ------------------------------------ |
| 升压电感      | 输入端，本体下方无走线，绕组方向使引脚顺应功率流             |
| MOSFET    | 电感与二极管之间，开关节点（0~400V 摆动）铜皮最小化        |
| Boost 二极管 | 紧贴 MOS 与母线电容，关断振铃是 EMI 主源，RC 吸收紧贴    |
| 母线电解      | PFC 输出 400V/大容量，两只串联分担电压/纹波电流，负极铜皮宽  |
| 电流采样      | 采样电阻/互感器 Kelvin 接法进控制器（如 UCC28019 类） |
| 辅助绕组      | 电感辅助绕组给 IC 供电，环路小                    |

**PFC 专属坑**：CrM 模式频率随负载浮动（几十 kHz~数百 kHz），开关节点振铃频谱也随之移动——布局上预留 boost 二极管 RC 吸收焊盘（先不放件，EMC 整改时启用）是标准操作。

## 20.3 LLC 级的布局要点

半桥 LLC：

```
400V 母线 ─ 上管 ─ 中点(半桥开关节点) ─ 谐振电容 Cr ─ 谐振电感 Lr ─ 变压器
              └ 下管 ─ 母线地                                    └ 副边 SR
```

| 规则     | 说明                                              |
| ------ | ----------------------------------------------- |
| 半桥中点铜皮 | 0~~400V 方波（频率 90~~150kHz），铜皮小、走直线到 Cr           |
| 谐振腔三件套 | Cr/Lr/Lm 构成的回路紧凑，Cr 用高频 CBB 电容（耐纹波电流）           |
| 上下管驱动  | 自举电容紧贴上管，驱动环路（驱动变压器或 IC）短而对称                    |
| 变压器    | LLC 变压器是"真变压器"（不像反激储能），EE/EF/PQ 型，一次副边中间        |
| 副边 SR  | 低压大电流（200V/1.5A 输出时副边峰值 10A 级），SR MOS 并联 + 铺铜均流 |
| 输出     | 恒流采样电阻（毫欧级）Kelvin 采样进恒流环                        |

## 20.4 路灯产品的环境与可靠性专项

| 项    | 要求与 PCB 对策                                               |
| ---- | -------------------------------------------------------- |
| 户外雷击 | 差模 6kV/共模 10kV 级浪涌：GDT+MOV 级联、压敏电阻 + 温度保险、泄放通路粗铜         |
| 防水防潮 | 灌胶（conformal coating 或全灌封）→ 板上留灌胶围坝、测试点加盖、高压区留爬电余量（凝露降级） |
| 寿命   | 电解电容按 5000~10000h 设计，远离热源、加大电压裕量；整灯质保 5 年是行业惯例           |
| 输出恒流 | LED 是电流驱动器件，反馈环是恒流环（采样电阻+运放+光耦），布局与恒压反馈同规则               |

# 第 21 部分：第四课——700W 电源（上）：大功率布局设计

## 21.1 700W 级的系统与电流规模

第四/五课是同一块 700W 板的两次直播（先布局后布线）。700W（典型输出 12V/58A 或 48V/15A 档）的架构在 300W 基础上再升级：

```
EMI(两级) ─ 整流桥(桥臂并联或独立整流管) ─ 交错式 PFC(两相 Boost) ─ 400V 母线
        ─ LLC 全桥/半桥 ─ 变压器(平面变压器或 PQ50) ─ 副边 SR(多管并联) ─ 输出
```


电流规模感知（12V/58A 输出假设）：

| 位置                   | 电流               | PCB 对策         |
| -------------------- | ---------------- | -------------- |
| 输入整流后（220V/3.2A RMS） | ~5A 峰值充电脉冲       | 整流桥散热铜、粗铜      |
| PFC 级电感电流            | 5~7A 峰值（两相交错分摊）  | 每相独立环路         |
| 400V 母线到 LLC         | ~2.5A RMS        | 高压细铜即可，重爬电     |
| 副边输出                 | 58A 平均、峰值 100A 级 | 铜皮总线+过孔阵列+多管并联 |

## 21.2 交错 PFC 布局

两相 Boost 交错 180°，纹波互相抵消：

| 规则       | 说明                    |
| -------- | --------------------- |
| 两相布局镜像对称 | 电感、MOS、二极管位置完全镜像，保证均流 |
| 每相独立开关环路 | 各自最小化，不共用 SW 节点铜皮     |
| 母线汇流点    | 两相输出在母线电容处汇合，汇流铜皮对称   |
| 电流采样     | 每相独立采样（互感器/电阻），Kelvin |

## 21.3 大功率板的布局流程（课程演示主线）

700W 板布局与 10W 板的根本区别：**先规划"功率骨架"（铜皮走廊），再放器件**。

1. 划定功率走廊：输入→PFC→母线电容区→LLC→变压器→SR→输出，一条 Z 字形贯穿全板；
2. 大件占位：变压器/PQ50（占 50×50mm）、两只 400V 母线电解（含泄放电阻位）、每相电感、散热器安装位；
3. 散热器决定器件坐标：MOS/SR 全部贴散热器边缘排列（散热器贯穿风道），管子引脚朝向功率走廊；
4. 控制与驱动：控制板独立区域（或独立小板），驱动变压器/驱动 IC 紧贴对应开关管；
5. 辅助电源（待机 5V 反激）独立角落，自成一体；
6. 最后才是小件跟随。

## 21.4 多层板与铜厚

| 项  | 700W 板典型选择                                          |
| -- | --------------------------------------------------- |
| 层数 | 4 层（L1 功率+元件 / L2 地或负母线 / L3 信号 / L4 功率+元件）         |
| 铜厚 | 外层 2oz 起步，大电流板 3oz；内层 1~2oz                         |
| 过孔 | 功率路径过孔阵列（0.4~~0.5mm 孔），孔数按 1~~1.5A/孔 ×80% 降额        |

| 爬电 | 400V 母线区按工作电压 400V（基本绝缘一次侧内 2.5~4mm），一二次隔离仍是 6.4mm+ |

# 第 22 部分：第五课——700W 电源（下）：大电流布线设计

## 22.1 大电流布线的三条主线

**主线一：铜皮宽度与多层并联**

```
58A 输出的载流预算：
单层 2oz 铜 10mm 宽 ≈ 10A（ΔT=20°C）→ 58A 需 60mm 宽或多层并联
L1+L4 各 30mm 铜皮 + 过孔阵列短接 → 双面各 30A，等效 20°C 温升
```

铜皮过窄的后果不是立即烧毁而是**铜皮自身发热 → 板翘曲 → 焊点疲劳**——大电流板是"热-机械"问题而不只是电气问题。

**主线二：过孔阵列的均流**  
电流在过孔阵列中的分配不均（边缘孔电流偏大），规则：阵列覆盖整个铜皮重叠区、孔间距 0.8~1.2mm、避免长条单排（单排=所有孔串在同一电流路径上）。输出端子区域过孔最密（电流汇聚点）。

**主线三：并联 MOS 的对称性**  
副边 SR 四管并联，每管分配 15A：

| 规则                    | 违反后果             |
| --------------------- | ---------------- |
| 各管栅极走线等长（栅极电阻到各管距离一致） | 开关时序错开，先开的管子过流烧毁 |
| 各管漏源路径对称（铜皮分叉等宽）      | 电流不均，某管过热        |
| 各管共用同一散热器基板           | 热耦合均温，缓解轻微不均     |

## 22.2 驱动与采样的精细走线

| 网络        | 规则                                   |
| --------- | ------------------------------------ |
| SR 驱动     | 驱动 IC 置于四管几何中心，四条栅极走线等长、等宽           |
| 半桥/全桥驱动   | 高侧驱动自举电容回路最短；驱动变压器副边绕组到管子等距          |
| 电流互感器输出   | 屏蔽线/包地走线到控制器，远离 SW 节点                |
| 输出电压采样    | 在输出端子处 Kelvin 取样（不在铜皮中途取样，否则铜皮压降进反馈） |
| NTC 温度传感器 | 贴散热器/变压器，走线包地                        |

## 22.3 700W 板的布线顺序（课程复盘）

1. PFC 两相铜皮（先粗后细）；
2. 母线电容区的汇流铜与泄放电阻；
3. LLC 半桥/全桥中点和谐振腔；
4. 变压器副边到 SR 的"总线"铜皮（全板最宽）；
5. 输出端子区过孔阵列 + 均流分叉；
6. 驱动与采样小信号（在功率铜皮定形后的剩余空间里走）；
7. 铺铜完成（地/负母线），DRC，热成像预评估（改板前用损耗模型标注每个发热点）。

# 第 23 部分：第六课——15kW 充电桩模块 PCB 设计

## 23.1 充电桩模块的系统架构

15kW 直流充电模块（充电桩内的核心功率单元）：

```
三相 380V AC ─ EMI 滤波 ─ 三相维也纳(Vienna) PFC / 交错Boost ─ 800V 直流母线
           ─ 隔离级：DAB 双有源桥 / 全桥 LLC ─ 高频变压器(SiC, 50~100kHz)
           ─ 副边整流 ─ 输出 200~1000V DC 宽范围（恒压恒流双环）→ 车电池
```

| 特征   | 数值                            |
| ---- | ----------------------------- |
| 输入   | 三相 380V±15%，功率因数 >0.99，THD<5% |
| 母线   | 直流 650~800V                   |
| 开关器件 | SiC MOSFET（高频高效）或 IGBT（成本）    |
| 功率密度 | 行业 30~60W/in³，走"模块化"路线        |
| 效率   | 96~98%（SiC 两级）                |

## 23.2 分板策略（15kW 不可能一块板搞定）

| 板        | 职责                                | 特点                 |
| -------- | --------------------------------- | ------------------ |
| 功率板（主功率） | PFC 电感、开关管、母线电容、变压器、副边            | 厚铜 3~6oz、大电流、散热器直连 |
| 驱动板      | 每个开关臂一块小驱动板，贴管子                   | 低感驱动环路、隔离供电        |
| 控制板      | DSP（如 TMS320F28 系列）+ 采样 + 通信（CAN） | 独立小信号环境、远离功率板      |
| 连接       | 板对板连接器/铜排/叠层母排                    | 大电流走铜排，不走 PCB      |

**铜排（busbar）与叠层母排**：几百安培的电流不在 PCB 铜皮上走，而是用叠层铜排（正负极夹绝缘层叠压）——电感极低、载流巨大。PCB 与铜排通过螺栓/压接端子连接，压接点周围铜皮加 reinforcing 过孔阵。

## 23.3 功率板设计要点

| 项    | 规则                                                              |
| ---- | --------------------------------------------------------------- |
| 换流环路 | 每个开关桥臂的换流环路（母线电容→上管→下管→回电容）电感最小化，决定 SiC 开关尖峰——层叠设计让正负母线在相邻层平行重叠 |
| 铜厚   | 4oz 起步，或普通铜厚+铜排补强；大电流路径直接局部堆锡/嵌铜块（coin）                         |
| 爬电   | 三相输入 400V 系统按过电压类别 III/IV，间距 5.6~8mm 级；800V 母线、输出 1000V 对应更大距离  |
| 开关管  | 半桥臂布局，管子跨在正负母线之间，驱动板垂直插在管子上方（最短驱动路径）                            |
| 母线电容 | 薄膜电容（不是电解）贴桥臂，C 靠 D/S 环节最短                                      |
| 采样   | 母线电压/输出电流用隔离采样（霍尔/隔离运放），高低压区严格隔离带                               |
| 保护   | 泄放电阻（断电放掉母线）、温度联锁、绝缘监测（BMS/桩控交互）                                |

## 23.4 充电桩场景的特殊工程问题

| 问题                  | 对策                                                         |
| ------------------- | ---------------------------------------------------------- |
| 宽范围输出（200~1000V）    | 副边整流管/开关管耐压按最高档选，或绕组切换继电器                                  |
| 65~100kHz SiC 的 EMI | dv/dt 达 50kV/µs，驱动+环路布局要求比硅管再高一个档次                         |
| 液冷/风冷               | 大功率模块液冷（冷板贴合功率板）、风冷模块风道贯穿散热器                               |
| 并机                  | 多模块并机均流（CAN 通信数字均流），单板输出电流检测精度决定均流质量                       |
| 安规认证                | 充电桩国标 GB/T 18487 / IEC 61851，绝缘距离按reinforced insulation 执行 |
| 热插拔/维护              | 模块化抽取式结构，连接器选大电流盲插型                                        |

## 24.2 六课不变的四条铁律

1. **功率环路面积最小化**：从 10W 反激的 3cm² 到 15kW 桥臂换流回路的叠层母排，物理对象变了，麦克斯韦方程没变；
2. **按功率流向一字布局**：输入到输出的能量走廊在任何功率段都是布局主线；
3. **Kelvin 采样**：电流/电压检测在任何功率段都必须在"真值点"取样；
4. **EMC 从源头治**：滤波器是最后一道防线，环路布局、开关节点控制、dV/dt 管理才是根本——功率越大这条越重要。

## 24.3 系列知识闭环

六课串起来正好构成一个电源工程师的完整成长地图：第一、二课练**器件级计算与布局手感**（每一颗电阻电容都有讲究），第三课引入**系统架构思维**（两级架构、法规驱动设计），第四、五课锤炼**大电流工程能力**（铜皮、均流、热-机械耦合），第六课打开**工业大功率与模块化体系**（分板、铜排、认证）。与平行系列《8 层 RK3588 主板》合看：高速数字板上的每一颗 BUCK 都是一台 mini 反激，而每一个大功率电源的控制系统又是一块小高速板——电源与高速，互为镜像。

# 附录 B：设计 Checklist（打勾即交付前自查）

**安规**

- [ ] 一次-二次爬电 ≥6.4mm、间隙 ≥4.0mm（含开槽等效）

- [ ] 一次主环路面积 <3cm²，铜皮闭合
- [ ] RCD 环路贴变压器+MOS
- [ ] 副边整流环路（肖特基-C1）最小
- [ ] 辅助绕组环路最小
- [ ] 开关节点铜皮最小化，MOS 散热铺铜在源极

- [ ] 共模电感前后走线不平行、下方无走线
- [ ] Y 电容在变压器脚旁，回路最短
- [ ] 输入级一字排开按功率流

- [ ] 分压电阻在输出端子处、单点接地
- [ ] 补偿元件紧贴 TL431
- [ ] 反馈线远离开关节点/变压器
- [ ] VDD、FB 滤波电容紧贴 IC

**热与载流**

- [ ] 功率路径线宽/铺铜满足载流（1oz：1mm≈3A 外层）
- [ ] 发热件铺铜+过孔阵列
- [ ] 电解电容远离热源
- [ ] 各器件损耗核算完成

**输出**

- [ ] DRC 清零 + 安规规则（Net Class 间距）专项复查
- [ ] 3D 干涉检查
- [ ] Gerber 含隔离槽、板边间隙
- [ ] BOM 与原理图一致性

# 附录 E：扩展 FAQ（实战补充）

**Q9：单面板和双面板做电源怎么选？**  
成本敏感的充电器用单面 PCB（FR-1/CEM-1 基材也常见），布线只有一面、无过孔，环路天然难缩小，靠器件摆位硬压缩，副边环路靠粗走线。双面板贵 20~30%，但下层可做地镜像平面+导热过孔，EMI 和热都好一个档次。10W 以上或要过辐射认证的建议双面。

**Q10：共模电感用分立两个差模电感代替行不行？**  
不行。共模电感双绕组在同一磁芯上，共模电流磁通叠加被高感量阻挡、差模（工作）电流磁通抵消不饱和。两个独立电感对工作电流也呈现大感量，会分走电压、发烫。

**Q11：变压器啸叫（可闻噪声）的来源？**  
磁芯磁致伸缩（频率落 20Hz~20kHz 人耳范围）、绕组振动、陶瓷电容逆压电效应。对策：浸漆固定磁芯与绕组、频率避开可闻段（QR 模式轻载降频可能恰好落入，需 IC 有频率钳制）、Y 电容/陶瓷电容换材质。

**Q12：输出电压在额定负载下偏低 0.3V，线损还是环路？**  
先在输出电容脚上量：若此处是准 5V 而端子处 4.7V → 纯走线压降（加宽铜/缩短路径）；若电容脚也低 → 环路问题（分压比、TL431 基准、光耦 CTR 衰减）。带载才偏低且热态更差，优先怀疑光耦 CTR 老化或副边二极管 VF 偏大。

**Q13：批量生产 EMI 良率不稳，设计上怎么留裕量？**  
裕量设计三件套：① 元件公差敏感项（Y 电容、共模电感）选值比临界高 6dB；② PCB 预留并联位（Y 电容、X 电容各多留一对焊盘）；③ 认证扫描时留 ≥6dB 裕量再定型。

**Q14：高压区铺铜和走线的拐角为什么要处理？**  
尖角电场集中，长期工作在高压+潮湿+污染环境下会沿面放电、碳化。铺铜边缘尽量 45°/圆角，高压焊盘改泪滴焊盘，隔离带两侧铜皮边缘倒角。

**Q15：这节课的知识点里，哪些是跳到 RK3588 高速板设计时完全不适用的？**  
安规距离体系（高速板无强电）、Y 电容概念、变压器布局——这些不适用。但完全通用的部分：环路面积最小化思想（换成回流路径连续性）、分区布局思想（换成按功能分区+模块化）、载流与热设计（电源树同样要用）、Kelvin 取样（同样适用于电流检测）。方法论是迁移的，对象变了。

本系列六课以 10W → 24W → 300W → 700W → 15kW 的功率阶梯为载体，把"安规隔离 + 功率环路 + EMI 滤波 + 反馈环路 + 热设计 + 大电流工程 + 模块化架构"七大体系完整过了一遍：第 1~~18 部分是第一课的 10W 反激全流程（体系根基），第 19~~24 部分是第二至六课的功率放大与架构升级。延伸方向：① PFC 深入（图腾柱无桥 PFC、SiC 应用）；② 数字电源（DSP 控制的环路设计与软件补偿）；③ 平行课程《8 层 RK3588 主板 PCB 设计》——数字高速侧的另一极，两课合看即可覆盖"模拟电源 + 数字高速"两大 PCB 设计支柱，这正是企业最稀缺的复合型 PCB 工程师知识结构。
