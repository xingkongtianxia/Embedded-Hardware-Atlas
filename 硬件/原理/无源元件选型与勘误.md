## 电阻：先限制，再算功耗

- E系列是每十倍区间的优选标称值，实际表值经取整；不把10^(n/N)直接当精密实物值。
- 无负载分压 `Vo=Vi R2/(R1+R2)`；负载RL并在R2上时用`R2∥RL`重算。输出等效电阻为`R1∥R2`，不能直接当供电源。
- LED限流`R=(Vs−Vf)/I`，5V、2V、20mA得150Ω，电阻损耗60mW；需再检查Vf和电源容差。
- 检流`Vs=IRs`、`P=Irms²Rs`，Kelvin取样，精度包含TCR、自热、放大器失调和布线。不能把固定“留2倍”替代器件降额曲线。
- 上拉在低态核验`(Vpull−VOL)/R≤IOL`，高态核验漏电与VIH，动态核验RC上升时间。EN高阻输入的上拉稳态电流由漏电决定；不能把V/R都算成流入EN的电流。

## 电容与电感模型

- `1 F=10³mF=10⁶µF=10⁹nF=10¹²pF=10¹⁵fF`；`1 H=10³mH=10⁶µH=10⁹nH`。线性近似下`i=C dv/dt`、`v=L di/dt`、`EC=CV²/2`、`EL=LI²/2`。
- `ZC=ESR+j(ωESL−1/(ωC))`，安装互连也加入回路电感。电容越过自谐振后呈感性，不能把任意高频都看成短路；电感越过自谐振也不能沿用理想模型。
- 纹波选型依据实际波形：电容损耗约`Irms² ESR`；电感同时检查峰值/偏置导致的L下降与RMS温升，Isat和Irms的判据分别查厂商。
- 整流电容的`C≈I/(fripple ΔV)`仅为近似恒流放电的电荷估计。50Hz全波的补充电频率通常100Hz；不能用于任意开关拓扑。
- 互感`M=k√(L1 L2)`，单位H；串联顺/反接为`L1+L2±2M`。磁通Φ单位Wb，与M不同。
- 一阶、近似无负载RC：`fc=1/(2πRC)`；低通输出在电容两端，高通输出在电阻两端。振荡需有源供能；无源LC仅储能交换，谐振不凭空增加净能量。

## 明确修正与边界

| 原件位置/原意 | 分类采用的处理 |
|---|---|
| 电阻L53：按封装给统一最大电流/电压 | 同封装不同系列额定值不同，核对P、限压、过载和端子电流；电阻性负载还受`V≤√(Pallow R)`约束 |
| 电阻L197：EN电流直接按V/R | 按引脚漏电/内部下拉/钳位和上电状态建模，先查EN耐压及阈值 |
| 电阻L292：低通从“电阻端输出” | 若指电阻两端即高通；标准RC低通取电容两端 |
| 电阻L391：音频功放也以阻抗相等为目标 | 最大功率传输定理与电压驱动任务不同；常见音频电压功放希望低输出阻抗，不能强行匹配扬声器阻值 |
| 电阻L425、L456：0Ω当保险丝、必须割地单点 | 普通0Ω无受控熔断保障；是否分地由器件与回流决定，不能割裂高速返回路径 |
| 电感L39：470=47×10¹=470µH | 按该段三位数、单位µH的约定应为47×10⁰=47µH；具体丝印仍查型号 |
| 电感L170：磁珠阻抗随频率始终增加 | 需查R/X/Z频谱、偏置和寄生，超过峰值会下降，不能替代储能电感 |
| 电感L206：M=Φ | 量纲不同，采用上文互感公式 |
| 电感L795：“能量倍增” | 支路电压/电流可因Q放大，但无源网络不产生净能量 |

## 实施与待核验

电容考虑偏压/温度/老化后的有效容量、ESR、纹波和机械应力；安规电容按认证与应用标准选择，不由外形或材料断言“必然开路失效”。电感增大不保证峰值一定更低，启动、饱和与控制模式均需检查。未核实笔记中器件推荐表的制造商/后缀，不将其作为BOM依据。
