## 可复用机理

- 二极管的Vf随电流、温度变化；反向电压、重复峰值、平均整流、浪涌IFSM和结温是不同约束。trr与结电容都会影响动态，不能只用“硅管0.7V”。
- TVS区分VRWM、指定测试电流的VBR、指定脉冲/峰值电流的VC。核验VC加布线寄生过冲仍兼容后级，浪涌源阻抗和器件动态电阻影响实际电流；HBM指标不代替系统IEC试验。
- 齐纳IZT是稳压值测试电流，非自动等于最佳/最大连续工作电流；核验Iz范围、功耗、动态电阻和温漂。
- BJT正向有源区BE正偏、BC反偏；NPN为VC>VB>VE，PNP反向。饱和时两结正偏；截止不能仅靠IB≈0排除漏电。
- `Ic≈βIb`适用于有源区，β随电流/温度/器件变化。开关基极驱动按指定Ic/Ib与VCE(sat)设计，并检查IO驱动和关断存储时间。
- 仅在NPN发射极接地、Rb从VCC接到基极的偏置例中，`Ib≈(VCC−VBE)/Rb`；若有Re/分压网络需重新列KVL。小信号`gm≈Ic/VT`、`rπ≈β/gm`，室温VT约26mV。
- NMOS长沟道简化模型中，VGS>Vth后，VDS<VGS−Vth为欧姆区，VDS≥VGS−Vth为饱和区；功率开关低损耗导通追求低RDS(on)，而非MOS的恒流“饱和区”。PMOS需换电压极性。
- JFET的零栅压饱和漏电流IDSS与增强MOS的数据表关断漏电IDSS不可混为一谈。MOS栅极静态电流小，不等于动态驱动不取电：`Pgate≈Qg Vdrive fs`。

## 明确修正

| 原件位置/原意 | 修正 |
|---|---|
| 三极管L74：集电结是C-E | 集电结是C-B；C-E是跨两结的端口 |
| 三极管L86：VB≈VCC，Ib=VCC/Rb | 对上述单Rb偏置应扣除VBE；VB约VBE，不是VCC |
| 三极管L213、场效应管比较表：由双/单极型直接排序噪声 | 噪声取决于偏置、源阻抗、频率和器件，不能按家族一概排名 |
| 三极管L228：有源区输出电阻无穷大 | 仅理想近似；Early效应使输出电阻有限 |
| 二极管L47：VRM固定为VBR一半 | 无通用二分关系，按准确数据表额定与瞬态裕量选 |
| 二极管L105：同电压不同功率TVS的VC一样 | VC还取决于系列、测试波形、电流与动态电阻，必须逐型号查 |
| 场效应管L253：IDSS、IGSS、跨导/电阻行名及测试条件串位 | 不采纳错位表中的数值为器件事实，回准确型号官方表核对 |
| 场效应管L303：结温按摄氏度最大值80%降额 | 摄氏温标不能这样百分比降额，按允许TJ、温升、热路径和可靠性裕量设计 |
| 场效应管L313：Vth<2.5V即适用5V驱动 | 应有实际栅压/温度下保证的RDS(on)与SOA，阈值不足以判断充分导通 |

## 验证与引用边界

确认制造商、完整后缀、封装、引脚视图、测试条件；把绝对额定与推荐工作条件分开。线性工作/热插拔检查SOA与瞬态热阻，不能只看额定电流与导通电阻。原件里的达林顿/低噪声/耐压型号推荐未逐项获得原厂证据，不照抄数值或“最佳”排序。
