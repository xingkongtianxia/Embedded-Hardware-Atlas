# 运放应用公式与边界

图像修复记录见 [[audit/图片修复报告|图片修复报告]]；本页旧行号均按修复前版本定位，原图名和旧位置见 [[audit/图片修复明细.csv|逐处明细]]。图片可访问不提升技术核验状态。

## 来源与覆盖

《运放》涵盖开环/反馈、轨到轨、LM358系列摘表和失真；《运算放大器经典应用》涵盖比例/加减、积分微分、对数指数、乘除/调制、压控增益、恒流、有源滤波和振荡。原有24和105处缺图位置现已接入对应原版PDF完整页面。反馈方向、节点与阻值须按原页核对，不能从公式反推；此处只编译可由标准拓扑独立推导的关系，其余作为检索线索。

## 线性闭环成立的条件

运放基本关系`Vo=Aol(V+−V−)`是开环模型，不以“已经负反馈”为前提。只有有效负反馈、足够环路增益、共模与输出/电流均未超限、稳定且未压摆受限时，才能用虚短`V+≈V−`；虚断是忽略偏置电流的近似。

## 标准拓扑与公式

| 明确连接的标准电路 | 近似关系 | 约束 |
|---|---|---|
| 反相：Rin接V−，Rf由输出接V−，V+接Vref | `Vo=Vref−(Rf/Rin)(Vi−Vref)` | 必须有直流偏置回路 |
| 同相：Vi接V+，Rg接Vref，Rf反馈 | `Vo=Vref+(1+Rf/Rg)(Vi−Vref)` | 检查噪声增益与最小稳定增益 |
| 反相求和，V+为0V参考 | `Vo=−Rf Σ(Vi/Ri)` | 单电源需相应电平平移 |
| 匹配比值的四电阻差分器 | `Vo=(R2/R1)(V2−V1)`，条件`R2/R1=R4/R3` | 电阻比误差与输入共模限制CMRR |
| 理想反相积分，参考为0 | `Vo(t)=Vo(t0)−(1/RC)∫Vi dt` | 失调/直流积累会饱和，工程上加泄放反馈 |
| 理想反相微分，参考为0 | `Vo=−RC dVi/dt` | 高频噪声/相位需限带 |
| 一阶RC+理想缓冲滤波 | `fc=1/(2πRC)` | 源阻抗与后级负载会改结果 |

对数/指数电路受结温、饱和电流、输入极性、动态范围与补偿影响；乘除电路要确保整个工作范围保持负反馈。恒流源检查合规电压、功率器件SOA与环路。不能只看输出“符合公式”。

## 失真与勘误

- 《运放》L145将非轨到轨输出最低值统一解释为0.6V，不成立。输出级架构、负载方向/大小、供电与温度决定摆幅；LM358不同后缀不可混用。0.6V是特定结压降量级，不是通用下限。
- 有负反馈不保证稳定，也不保证不会饱和；容量性负载、反馈寄生和噪声增益要纳入环路分析。输入是否包含电源轨与输出能否靠轨是两项规格。
- 对近单主极点电压反馈运放，带宽起始估算用`GBW/噪声增益`；反相噪声增益为`1+Rf/Rin`。大信号正弦需`SR≥2πf Vpk`，不是只检查GBW。
- 原件《运算放大器经典应用》L778–784的0.37倍截止与L866增益≥3自激分别依赖其具体二阶拓扑/元件比；不推广成全部二阶滤波器定律。
- 电流反馈运放、去补偿运放与比较器有不同使用条件；运放开环代比较器需核对允许差分输入、恢复时间、相位反转及输出兼容。

## 验证

先核对供电、输入共模、输出摆幅/电流与偏置，再测小信号频响、阶跃与大信号压摆。以准确芯片手册核对LM358/B/BA等后缀；本轮不把笔记摘表的绝对额定当工作条件，不认定回补图像中的电路已验证。
