# 开关电源测量与EMC验证

## 结论与范围

先定义测量对象、工况和仪器链，再比较数值。二次笔记中的带宽、孔径、电流或安规距离均有适用条件；本页组织验证，不替代标准原文或原厂设计工具。

| 验证对象 | 记录内容 | 常见误读 |
|---|---|---|
| 输出纹波与噪声 | 带宽/耦合/探头/负载/接地点 | 20 MHz限制后看不到尖峰就认为没有尖峰 |
| 转换效率 | 同步输入输出功率、线损、仪器精度和温度 | AC非正弦输入用Vrms·Irms当真功率 |
| 环路 | 注入点、激励、小信号范围、输入与负载 | 只看到PM达标就判全工况稳定 |
| 启动/瞬态 | 上电斜率、负载阶跃、限流/打嗝/回馈 | 单次正常启动替代保护测试 |
| 温升 | 环境、风量、热稳态、器件与铜温度 | 热像表温等于芯片结温 |
| EMI/抗扰 | 适用标准、带宽、检波器、端口与布置 | 一条频段或经验距离覆盖所有产品 |

## 实施顺序

1. 固定[[wiki/原理/开关电源拓扑与工作模式|拓扑与模式]]、器件完整型号及板级规格，先限流启动。
2. 纹波用短返回、明确测点与带宽；高压/浮地节点选择合适差分探头、共模范围和额定值，禁止把接地夹误接开关节点。
3. DC效率可用满足波形和精度要求的电压/电流测量；AC输入用真有功测量，不以设备名称替代不确定度分析。
4. 验证[[wiki/原理/开关电源环路与磁件约束|环路与磁件]]，同时查低压大负载、轻载、跨模式和高温。
5. EMC先定位源、路径、接收端，再选差模/共模滤波、阻尼、驱动沿或屏蔽；改变开关沿后重测效率与热。
6. 将波形、测试条件与版本归档到设计记录，按[[wiki/PCB/PCB约束到放行检查|约束到放行]]检查证据。

## 例外与待核验

原件“加强绝缘≥6.4 mm”“每个0.3 mm孔1–2 A”和固定环路注入电平不作为通用规则。输入滤波器可能与恒功率负载发生阻抗交互；增加滤波不一定改善稳定性。目标标准和本板实测尚未补齐。
