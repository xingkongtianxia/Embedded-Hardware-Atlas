# 电源器件选型与验证导航

先判断输入/输出是否跨压、电池体系、是否需要隔离、协议与负载，再选择器件。以下为本地手册提取的候选网络；连接表示可比较的问题，不代表引脚兼容或可以直接替代。

## 从问题进入

| 设计问题 | 知识路径 | 必须补齐的证据 |
|---|---|---|
| 大电流供电 | [[wiki/原理/PI|PI]] → [[wiki/PCB/电源模块|电源模块]] → 下方大电流器件 | 电感饱和、铜箔/过孔、OCP、热与阶跃 |
| 模拟低噪声电源 | [[wiki/原理/模电|模电]] → [[wiki/PCB/模拟与采集模块|模拟与采集]] → LDO | 噪声带宽、压差、PSRR频点、接地 |
| 电池充电和电源树 | [[wiki/原理/芯片手册/电源管理/BQ24074|BQ24074]] → 充电/PMIC候选 | 电芯规格、充电温度、电源路径与时序 |
| 快充输出 | [[wiki/PCB/车载双路快充四层板审查|快充审查]] → 恒流/升降压候选 | 输入总功率、协议控制器、接口额定值 |

## 五项常见误读

1. **器件或开关电流不等于输出电流**：EG11732的80 A、XR2981的12 A、PL32001的逐周期限流必须与板级持续输出分开。
2. **引脚耐压不能跨用**：TPS53355的VIN与VDD不同；EG11731的启动方式改变输入边界。
3. **标题不能覆盖工作条件**：AP2965、NDP1360KC的标题/正文输入范围须并列核对。
4. **应用场景不是协议实现**：写有PD用途的DC/DC不一定包含CC协商；IP6525T列DP/DM协议，不据此声称支持PD。
5. **同系列不等于同规格**：ADP2119/2120、TPS5430/5431、SGM41523后缀、新旧LP2985均需按订货型号核验。
