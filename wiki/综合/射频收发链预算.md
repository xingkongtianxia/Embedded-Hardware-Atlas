# 射频收发链预算

## 范围与输入输出

来源分类稿“收发架构与预算”节；原件定位 §2.1–2.6。输入：频段、带宽、调制/误码/EVM、距离、天线、发射功率、环境、噪声与阻塞要求。输出：分级增益/NF/IP3/P1dB、损耗/隔离/余量预算及每一级验证条件。二次笔记经验值保持待核验。

## 架构选择

| 架构 | 主要收益 | 主要风险 |
|---|---|---|
| 超外差 | IF 选择性与增益分配 | 镜像、LO/IF 泄漏、器件数量 |
| 零中频 | 集成与低 IF 滤波成本 | DC offset、I/Q 失配、LO 泄漏 |
| 低中频 | 避开 DC 附近干扰 | 镜像抑制仍需设计 |
| TDD/FDD | 依协议选择收发时序 | 开关瞬态/双工隔离与接收阻塞 |

## 预算公式与已纠正算例

- `Pr=Pt+Gt+Gr-Lpath-Lother`，dBm/dB 口径；自由空间远场路径损耗 `32.44+20log10(d_km)+20log10(f_MHz)`，室内多径另估。
- 290 K 灵敏度 `-174+10log10(B_Hz)+NF+SNRreq+实现损失` dBm；不能省略带宽、调制/误码和温度条件。
- 线性噪声因子/功率增益：`Ftot=F1+(F2-1)/G1+(F3-1)/(G1G2)+…`；禁止把 dB 直接代入。
- **前级匹配滤波器 2 dB 插损 + LNA 1.2 dB NF，室温下两级 NF=3.2 dB。** 后级另加贡献，原文 2.1 dB 算例不成立。
- 等幅双音、小信号外推区：`P_IM3=3Pout-2OIP3` dBm，`IM3_dBc=2(Pout-OIP3)`。每载波功率必须明确；不能由 OIP3 单独决定阻塞门限。

## 分配与验证

LNA 前损耗通常直接恶化灵敏度，也可缓解强干扰；分配应同时满足噪声、线性度和选择性。PA 单独预算效率、失配、温升和谐波；PLL/VCO 预算相噪、杂散、锁定时间和供电敏感性；AGC 给检测范围、响应时间和稳定性留余量。

按频率/增益状态/温度/供电冻结预算表，先无源损耗与单级增益，再整链 NF、双音/P1dB、阻塞、灵敏度与 EVM/误码。TX 到 RX 泄漏必须与实际阻塞要求比较，不套固定隔离数值。
