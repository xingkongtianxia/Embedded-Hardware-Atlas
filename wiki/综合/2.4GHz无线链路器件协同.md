# 2.4GHz无线链路器件协同

## 范围与判断

本页把协议/收发、匹配、前端和供电连接为候选设计路径；**未验证这些器件直接级联的完整参考设计**。归档手册与二次射频笔记仍需核验，保持 `needs-review`。

| 职责 | 库内器件 | 协同边界 |
|---|---|---|
| 多调制收发 | [[wiki/原理/芯片手册/无线通信/SX1280|SX1280]] | 主控负责命令/协议；−132 dBm仅特定LoRa条件，SPI≤18 MHz |
| 芯片匹配与滤波 | [[wiki/原理/芯片手册/无线通信/2450FM07D0034|2450FM07D0034]] | 芯片侧40 Ω测量参考、天线侧50 Ω；方向/插损不可忽略 |
| PA/LNA与切换 | [[wiki/原理/芯片手册/无线通信/AT2401C|AT2401C]] | 不是收发器；饱和输出不等于线性输出，需检查过驱和切换 |
| Wi-Fi SoC路线 | [[wiki/原理/芯片手册/无线通信/ESP8285|ESP8285]] | NRND、协议不同；裸RF口39+j6 Ω，不是SX1280直接替换 |
| 低压LDO | [[wiki/原理/芯片手册/电源管理/RT9013|RT9013]] | 2.2–5.5 V输入，按热/压差/突发预算 |
| 较高输入LDO | [[wiki/原理/芯片手册/电源管理/MD7218|MD7218]] | 最高工作18 V，1.6 µA仅特定无载条件；大压差先算热 |

## 决策与验证

1. 冻结协议、地区/频段、数据率、包长、延迟、距离与PER；LoRa/FLRC/FSK与Wi-Fi按需求分别选路线。
2. 用 [[wiki/综合/射频收发链预算|收发链预算]] 计算匹配/滤波损耗、PA输入、线性输出、LNA前损耗、NF、阻塞与天线EIRP。驱动裕量和接收过载同样要预算。^[硬件/PCB/射频设计.md]
3. 在端口表记录阻抗/直流等效/隔直、方向、频段和S参数参考面；2450器件40/50 Ω条件不可直接嫁接到AT2401C的50 Ω端口假设。^[硬件/原理/芯片手册/蓝牙与无线.md]
4. 供电以真实TX/RX/启动占空与峰值核算；检查压差、热、突发跌落、PSRR频率条件和共享电源耦合。^[硬件/原理/芯片手册/电源管理.md]
5. 按 [[wiki/PCB/射频布局与屏蔽|布局与屏蔽]]、[[wiki/PCB/射频测试与放行|测试与放行]] 进行单级S参数/功率，再做整链灵敏度、干扰、频谱和热验证。

## 追溯与待确认

器件事实来自无线分类稿2026-10-16各器件段，供电边界来自电源管理分类稿同日段，预算方法来自射频设计分类稿。公开页不引用私人资料。

完整BOM、最新版手册/勘误、AT2401C端口直流描述冲突、ESP8285版本/生命周期、滤波器参考阻抗和整机合规均需关闭；当前是评审网络，不是可直接投板的已验证电路。
