# 电源模块进阶知识条目 16

上级主题： [[wiki/PCB/电源模块/09-测量与故障定位|测量与故障定位]]

**例1：DC-DC 输出到负载的电源通路**

```
  L1(TOP):  [DCDC] ── SW ──[L]──┬── 铺铜块 VOUT
                                 │
                            ●●●●●●●●   <- 过孔阵列 (0.3mm x 6~8)
                                 ↓
  L4(PWR):        ┌──────────────────────┐
                  │   1V0 平面分区        │
                  └──────────┬───────────┘
                             ↓
                        ●●●●●●●●●●        <- 到 BGA 电源球区
  L1(TOP):            FPGA VCCINT 球
```

**例2：地平面的"缝合"。** L2 和 L5 是两个独立的地平面，必须用大量过孔连成"一个地"：
- DC-DC 区域：地铜下密集打孔（间距 2~3mm）；
- BGA 区域：每个 GND 球一个孔；
- 目的：让 L2 和 L5 电位一致，任何信号换层时回流都能"就近跳层"。

**例3：电源过孔数量速查表**

| 电流 | 最少过孔（0.3mm） | 推荐数量 |
|---|---|---|
| 0.5A | 1 | 2 |
| 1A | 1 | 2~3 |
| 2A | 2 | 4~6 |
| 3A | 3 | 6~8 |
| 5A | 5 | 10~12 |
