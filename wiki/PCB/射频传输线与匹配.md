# 射频传输线与匹配

## 范围与核心结论

来源分类稿“传输线、阻抗与匹配”节；原件定位 §1.1、1.5–1.6、3.2–3.10、3.13。二次笔记待核验。每段走线、焊盘、过孔、TVS 和连接器参与实际网络；50 Ω 是指定参考系统，不代表所有芯片差分端口都应接 50 Ω。

## 公式与条件

| 对象 | 表达式与边界 |
|---|---|
| 波长 | λg=c/(f√εeff)，使用目标结构/频率的有效介电常数 |
| 反射 | Γ=(ZL-Z0)/(ZL+Z0)，这里 Z0 为实参考阻抗 |
| S11 与回波损耗 | S11_dB=20log10|Γ|，RL=-20log10|Γ|；-20 dB S11 对应 +20 dB RL |
| VSWR | (1+|Γ|)/(1-|Γ|)，|Γ|=0.1 对应约 1.22 |
| λ/4 变换 | 无损中心频率 Zin=Zt²/ZL，纯阻匹配 Zt=√(RsRl) |
| λ/2 重复 | 理想无损线重复负载阻抗，不自动消除失配 |
| Stub | 开路 -jZ0cot(βl)，短路 jZ0tan(βl)，含端部/损耗后再调 |

## 工程实施

- 微带/带状线/GCPW 按实际叠层求解；GCPW 的 W/G、共面地宽、地孔和阻焊都要建模，不能套固定几何。
- 先量/取目标频率和偏置下的负载，再用 L/π/T、stub 或变换线匹配。LNA 噪声匹配、PA 负载牵引和最大功率匹配分别评估。
- 50 Ω 等分 Wilkinson：两支 70.7 Ω λg/4、输出跨接 100 Ω；理想单路 -3.01 dB 是分功，额外损耗另算。
- 滤波器/耦合器同时检查通带、止带、群时延、方向性和工艺公差；偏置三通主路串隔直电容、偏置支路高 RF 阻抗。
- 选无源件看 Q/SRF/S 参数，仿真含焊盘、走线和罩体。参考地局部挖空/taper 是待验证补偿选项，不是默认工艺。

## 验证、风险与待确认

VNA 在同一参考面/偏置测 S11/S22、S21/S12，扫工作带及带外，检查温度/装配变化。TDR 定位不连续，匹配元件调整后复测全带。

原笔记 S11/RL、阻焊补偿方向及 Wilkinson λ/4 数值混乱，已在分类稿列出；固定其他几何时，阻焊导致 Z0 下降通常需缩窄重算，不能照抄“加宽”。经验线宽、损耗、带宽不进入正式约束，等待板厂/模型/实测。
