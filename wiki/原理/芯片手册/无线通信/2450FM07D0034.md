# 2450FM07D0034

## 范围与核心事实

Johanson Technology 为 [[wiki/原理/芯片手册/无线通信/SX1280|SX1280/SX1281]] 优化的阻抗匹配前端滤波器；不是 MCU 或通用对称 50 Ω 滤波器。手册 Ver.1.2，2019-09-10，4 页；p.1–2 已按渲染图核对表格、标记方向和测试端口。

| 项目 | 本版条件或边界 |
|---|---|
| 工作频段 | 2400–2500 MHz |
| 插损 | 0.75 dB 典型，1.0 dB 最大 |
| 回损 | 14 dB 典型，10 dB 最小 |
| 输入 | 与 SX1280/SX1281 匹配；p.2 测量端口明确为 **40 Ω** |
| 输出 | 天线侧 50 Ω |
| 功率容量 | 3 W 最大 CW；不是收发器输出功率 |
| 外形 | 1.00×0.50 mm，厚度最大 0.40 mm |
| 方向 | 1=IN（红标记，朝芯片）；3=OUT（朝天线）；2/4=GND |

## 工程实施

内部已隔直，手册明确无需外置隔直电容；整条链路其他器件的直流要求仍要逐段确认。天线侧走线按真实叠层计算 50 Ω，不能复制 p.2 示意图线宽。芯片侧匹配与 40 Ω 测量参考必须一起考虑。

将插损计入 [[wiki/综合/射频收发链预算|链路预算]]；接收链中 LNA 前损耗会损害系统噪声系数。替换匹配网络或增加 PA 后需重新检查谐波抑制和端口匹配，方法见 [[wiki/PCB/射频传输线与匹配|射频传输线与匹配]]。

## 验证与风险

用匹配的端口参考阻抗和去嵌入方法测 S 参数；普通双端 50 Ω VNA 测量不能直接等同厂家 40/50 Ω 结果。核对贴装红标记、焊盘和地过孔，再测整机输出、谐波和灵敏度。

待确认：准确包装后缀、官方布局/S 参数文件、实际叠层和量产工艺。首页只说可联系获取 AEC-Q200 合格器件，不能把当前任意订货号认定为车规版本。
