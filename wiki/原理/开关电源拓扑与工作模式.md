# 开关电源拓扑与工作模式

## 选择顺序

先确定输入/输出范围、功率、隔离、瞬态、待机和温升，再比较拓扑。本页来自用户二次总结的分类稿，公式仅适用于注明的理想稳态条件，不能直接生成量产BOM。

| 需求 | 候选 | 主要约束 |
|---|---|---|
| 降压、低噪声小功率 | LDO | 压差、功耗、PSRR与输出电容稳定性 |
| 非隔离降压 | Buck | 占空比/最小导通、峰值限流、轻载模式 |
| 升压 | Boost | 输入电流、输出断开/短路、CCM右半平面零点 |
| 输入跨越输出 | 四开关Buck-Boost | 过渡区、效率、开关回路与限流方式 |
| 反相或特定输入/输出电流连续性 | 反相Buck-Boost、SEPIC、Ćuk、Zeta | 极性、器件应力、耦合磁件与串联电容 |
| 隔离、宽负载 | 反激/正激 | 储能/传能方式、磁复位、漏感钳位和安规 |
| 较高功率、软开关 | 半桥/全桥/LLC/相移全桥 | 循环电流、软开关负载范围、死区与磁件 |
| 市电电流整形 | PFC前端 | 谐波、母线纹波、保持、浪涌与滤波交互 |

## 公式与模式

理想CCM：Buck `D=Vo/Vi`，Boost `D=1−Vi/Vo`，反相Buck-Boost `Vo/Vi=−D/(1−D)`。Buck `ΔIL=Vo(1−D)/(Lfs)`；纹波电流仍需算峰值、RMS、饱和与电容纹波。

DCM变换比与负载相关；PFM/跳脉冲改变频谱及可闻噪声。控制器的最小导通/关断、压差、限流和温升会缩小理论范围，器件标称开关电流不是输出电流。

## 待确认

隔离间距必须按目标标准、污染等级、海拔与电压查表，不能照搬6.4 mm；效率和ZVS也不能从拓扑名称直接推出。
