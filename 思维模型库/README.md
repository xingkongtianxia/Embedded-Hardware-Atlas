# 思维模型库索引

本库是通用思维方法论的维护层，与 `wiki/`（嵌入式硬件领域）平行。本库用于沉淀"思考方式"层面的工具，回答"我该用什么方式思考 / 如何拆解 / 如何判断"。

## 与 `wiki/` 的关系

- `wiki/` 回答**领域内**的问题（电子、PI、SI、EMC、布局布线等硬件知识）；
- 本库回答**跨领域**的方法论问题（如何拆解问题、如何追根因、如何定义目标、如何迭代执行）。
- 两者互不引用 `sources`：硬件 Wiki 不引用本库作为来源，本库也不引用 `硬件/`、`external/`。

## 使用入口

### 元思维层（决定怎么思考）

- [[思维模型库/1-第一性原理|第一性原理]]：还原到公理，拆掉类比与假设，重建方案。
- [[思维模型库/4-系统思维|系统思维]]：看整体、关系与反馈回路，避免头痛医头。

### 根因分析层（追到根因）

- [[思维模型库/2-5-Whys|5 Whys]]：连续追问"为什么"，沿因果链深挖。
- [[思维模型库/8-鱼骨图|鱼骨图]]：把"人/机/料/法/环/测"等类别铺开排查。

### 结构化拆解层（把混沌变有序）

- [[思维模型库/3-MECE|MECE]]：分类拆解时不重不漏。
- [[思维模型库/7-5W2H|5W2H]]：横向问全 Who/What/When/Where/Why/How/How much。

### 执行迭代层（把方向变成推进）

- [[思维模型库/5-OODA|OODA]]：观察-定向-决策-行动的高速闭环。
- [[思维模型库/6-PDCA|PDCA]]：计划-执行-检查-改进的迭代闭环。
- [[思维模型库/11-假设-验证|假设-验证]]：用最小实验验证或推翻假设。

### 辅助决策层（找关键少数与反方向）

- [[思维模型库/9-八二法则|八二法则]]：抓关键少数。
- [[思维模型库/10-逆向思维|逆向思维]]：从结果倒推原因。
- [[思维模型库/12-决策树|决策树]]：把多分支选择结构化。

## 使用约定

1. **方向未明** → 元思维层（第一性原理）。
2. **方向已定、找原因** → 根因分析层（5 Whys / 鱼骨图）。
3. **原因已明、列方案** → 结构化拆解层（MECE / 5W2H）。
4. **执行推进** → 执行迭代层（PDCA / OODA / 假设-验证）。
5. **选优、找关键** → 辅助决策层（八二法则 / 决策树 / 逆向思维）。

## 统一字段

每个模型页除 YAML frontmatter 外，正文固定包含以下字段，方便 AI 检索和组合：

| 字段 | 写法要求 |
| --- | --- |
| 是什么 | 用一段话定义边界，不写课程介绍。 |
| 什么时候用 | 列出触发场景和不适用信号。 |
| 输入 | 写启动模型所需的事实、约束和数据。 |
| 输出 | 写模型运行后应交付的清单、判断或实验结果。 |
| 组合模型 | 至少两个指向本库页面的 Wiki 链接，并说明衔接关系。 |
| 触发词 | 用反引号列出用户提问或现场信号中的关键词。 |
| 怎么用 | 用可执行步骤描述，标注检查点。 |
| 示例 | 使用嵌入式硬件、PCB、电路故障或项目管理的真实工作情境。 |
| 常见误区 | 写出会导致误判的具体做法和纠正方式。 |
| 我的案例与规则 | 记录个人案例，并以“沉淀规则”列出可复用约束。 |

`输入 → 怎么用 → 输出` 是最小可执行闭环；`示例`和`我的案例与规则`用于把抽象方法变成可复用经验。模型页的 `sources` 通常保持为空，方法论页面不引用硬件 Wiki 作为来源。

## 问题到 Wiki 的矩阵

思维模型负责组织问题，结论仍需沉淀到 `wiki/` 的领域页面。AI 访问知识库时，可按下表把模型产物交给对应 Wiki 页面类型：

| 用户问题 | 首选模型组合 | 应写入的 Wiki 产物 |
| --- | --- | --- |
| “这个电路为什么失效？” | [[思维模型库/8-鱼骨图|鱼骨图]] → [[思维模型库/2-5-Whys|5 Whys]] | `principle` / `pcb-method`：现象、因果证据、验证条件 |
| “要不要重做这部分设计？” | [[思维模型库/1-第一性原理|第一性原理]] → [[思维模型库/11-假设-验证|假设-验证]] | `comparison` / `synthesis`：约束、实验数据、适用边界 |
| “如何安排排障和改进？” | [[思维模型库/7-5W2H|5W2H]] → [[思维模型库/6-PDCA|PDCA]] | `pcb-method`：责任人、指标、轮次、复盘结论 |
| “多种器件/方案怎么选？” | [[思维模型库/3-MECE|MECE]] → [[思维模型库/12-决策树|决策树]] | `comparison`：分支条件、成本、风险和备选 |
| “先处理哪些故障？” | [[思维模型库/9-八二法则|八二法则]] → [[思维模型库/10-逆向思维|逆向思维]] | `synthesis`：关键少数、长尾风险、防护措施 |
| “现场情况一直变化怎么办？” | [[思维模型库/5-OODA|OODA]] → [[思维模型库/4-系统思维|系统思维]] | `concept` / `synthesis`：时间线、反馈回路、干预效果 |

矩阵中的 Wiki 页面必须遵守领域来源门禁：引用 `硬件/原理/`、`硬件/PCB/` 或明确标注的 `external/` 资料；思维模型页只提供方法，不替代事实来源。
